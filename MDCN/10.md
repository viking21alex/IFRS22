## 引言与范围（第4.1-4.13段）

 

<a id="s27-Para_4.1"></a>**4.1** IAS 1就财务报表的总体结构提供了指引，包括每张主要报表（财务状况表、损益及其他综合收益表、所有者权益变动表和现金流量表）以及财务报表附注的最低要求。其他会计准则的要求对IAS 1的要求构成补充。

[IAS 1 第1段]。

 

<a id="s27-chap_04_navPoint_3"></a>
### 目标与范围

 

<a id="s27-Para_4.2"></a>**4.2** IAS 1适用于按照国际财务报告准则（IFRS）编制的所有通用目的财务报表。通用目的财务报表是指旨在满足无法要求主体直接向其提供信息的使用者需求的财务报表。IAS 1适用于所有类型的主体，既适用于按照IFRS 10编制的合并财务报表，也适用于按照IAS 27编制的单独财务报表。

[IAS 1 第2段]。[IAS 1 第7段]。

<a id="s27-Para_4.3"></a>**4.3** IAS 1不规范按照IAS 34编制的简明中期财务信息的结构和内容。但IAS 1第15段至第35段规定的“总体考虑”同时适用于年度财务报表和中期财务报告。这些段落涉及公允列报与遵循IFRS准则、持续经营、权责发生制、重要性与汇总以及抵销等事项——即编制和列报财务信息的总体原则，这些原则主要源自理事会的《财务报告概念框架》。

[IAS 1 第4段]。

<a id="s27-Para_4.4"></a>**4.4** IAS 1采用的术语适用于营利性主体，包括公共部门商业主体。IAS 1旨在具备足够的灵活性以供所有主体使用，但部分非营利主体可能需要修改单列项目或财务报表本身的文字描述。

[IAS 1 第5段]。

<a id="s27-Para_4.5"></a>**4.5** 对于不存在IAS 32所定义权益的主体，或股本不属于权益的主体，其成员或基金份额持有人权益在财务报表中的列报需作出相应调整。

[IAS 1 第6段]。

 

<a id="s27-chap_04_navPoint_4"></a>
### 财务报表的目的

<a id="s27-Para_4.6"></a>**4.6** 财务报表的目标是提供关于主体财务状况、财务业绩和现金流量的信息，这些信息对广泛的使用者作出经济决策是有用的。财务报表还反映管理层对其受托管理资源的受托责任履行结果。该目标通过提供有关资产、负债、权益、收益和费用（包括利得和损失）、所有者以其所有者身份进行的投入和向其进行的分配以及现金流量的信息来实现。这些信息有助于预测未来现金流量的金额、时间分布和确定性。

[IAS 1 第9段]。

<a id="s27-chap_04_navPoint_5"></a>
### 整套财务报表

 

<a id="s27-Para_4.7"></a>**4.7** 整套IFRS财务报表包括下列报表，且所有报表均应以同等显著的方式列报：

- 期末财务状况表（资产负债表）。

- 当期损益及其他综合收益表。

- 当期所有者权益变动表。

- 当期现金流量表。

- 附注，包括重要会计政策和其他说明性信息。

适用于自2023年1月1日或之后开始的年度期间的修订（视相关认可程序而定）。允许提前采用，但应披露该事实。新增文本加下划线标示，删除文本加删除线标示：

  

- 附注，包括<u>重要会计政策信息</u>~~重要会计政策~~和其他说明性信息。

  

- 上一期间的比较信息，包括与理解当期财务报表相关的叙述性披露。

- 若主体追溯应用某项会计政策、对其财务报表中的项目进行追溯重述或重分类，则应列报上一期间期初的资产负债表。仅当该重述对期初资产负债表产生重大影响时，才要求提供该信息。

[IAS 1 第10段]。

<a id="s27-Para_4.8"></a>**4.8** 主体可将“损益及其他综合收益表”作为单一报表列报，或作为两张报表列报。在单一报表中，主体应分不同部分列报损益和其他综合收益。损益部分应列报在前，紧随其后列报其他综合收益部分。如果主体列报两张报表，则应在单独的损益表（即利润表）中列报损益部分，该表应紧邻列报综合收益的报表之前。由此，所有收益和费用均将包含在“业绩报表”中。

[IAS 1 第10A段]。

<a id="s27-Para_4.9"></a>**4.9** 主体可以为报表使用其他名称，例如用“综合收益表”代替“损益及其他综合收益表”，或在单独列报损益时使用“利润表”。类似地，主体也可以列报“资产负债表”而非“财务状况表”。在本章中，凡提及“利润表”之处，均包括损益及其他综合收益表中的损益部分。

[IAS 1 第10段]。

<a id="s27-Para_4.10"></a>**4.10** 附注包含除财务状况表、损益及其他综合收益表、所有者权益变动表和现金流量表中所列报信息之外的补充信息。附注提供对上述报表中列报项目的文字说明或细分，以及有关不符合上述报表确认条件项目的信息。

[IAS 1 第7段]。

<a id="s27-Para_4.11"></a>**4.11** IAS 7规定了现金流量表列报和披露的详细要求。[参见第7章第1段](15.md#s45-Para_7.1)。

<a id="s27-Para_4.12"></a>**4.12** 在财务报表之外列报的报告和声明不属于IFRS的范围。IFRS 7允许将特定披露（例如金融工具产生的风险性质和程度以及主体管理这些风险的方法）列报在随附财务报表的单独管理层评述或业务回顾等报告中。这些披露通过在财务报表中交叉索引至该其他报告的方式予以纳入。

[IAS 1 第14段]。

<a id="s27-Para_4.13"></a>**4.13** 理事会的实务公告《管理层评述》为此类评述的列报提供了非强制性指引。

## 总体特征（第4.14-4.54段）

<a id="s28-chap_04_navPoint_7"></a>
### 公允列报

 

<a id="s28-Para_4.14"></a>**4.14** 财务报表应当公允列报主体的财务状况、财务业绩和现金流量。公允列报要求按照《概念框架》中规定的资产、负债、收益和费用的定义及确认标准，如实反映交易、其他事项和情况的影响。应用IFRS准则并在必要时进行补充披露，被推定能够使财务报表实现公允列报。

[IAS 1 第15段]。

<a id="s28-Para_4.15"></a>**4.15** 财务报表附注中应包含一项“明确且无保留的合规声明”。如果主体未遵循IFRS的所有要求，则不得声明其财务报表符合IFRS。财务报表要么符合IFRS，要么不符合，不存在中间地带。

[IAS 1 第16段]。

<a id="s28-Para_4.16"></a>**4.16** IFRS定义为理事会通过的准则和解释公告，包括国际财务报告准则（IFRS）、国际会计准则（IAS）以及国际财务报告准则解释委员会（IFRS IC，或其前身机构）发布的解释公告。

[IAS 1 第7段]。

<a id="s28-Para_4.17"></a>**4.17** 当财务报表使用者有必要了解报告主体的交易或事项时，除特定IFRS准则规定的披露外，还需进行补充披露。披露或解释不能替代恰当的会计处理。

[IAS 1 第18段]。

<a id="s28-Para_4.18"></a>**4.18** 公允列报几乎总是通过遵循适用的IFRS准则来实现。为实现公允列报，主体应当：

- 按照IAS 8选择和应用会计政策；IAS 8规定了在没有具体适用于某项目的IFRS时，管理层应考虑的权威指引层级；

- 以能够提供相关、可靠、可比和可理解信息的方式列报信息（包括会计政策）；以及

- 当遵循IFRS准则中的具体要求不足以使使用者理解特定交易、其他事项和情况对主体财务状况和财务业绩的影响时，提供补充披露。

[IAS 1 第17段]。

 

<a id="s28-chap_04_navPoint_8"></a>
### 公允列报与真实公允偏离原则

 

<a id="s28-Para_4.19"></a>**4.19** IFRS推定，只要财务报表遵循了每一项适用的准则和解释公告，即实现了公允列报。在极其罕见的情况下，如果管理层认为遵循某项IFRS要求会产生极大的误导，以致与《概念框架》中规定的财务报表目标相冲突，且相关监管框架要求或不禁止偏离该要求，则主体应当偏离该项IFRS要求。仅当即使作出补充披露，应用IFRS仍无法实现公允列报时，才必须偏离IFRS。

[IAS 1 第15段]。

<a id="s28-Para_4.20"></a>**4.20** 偏离某项IFRS要求的主体应当披露有关该偏离的信息。这些披露涉及偏离的具体细节、原因及其影响。

[IAS 1 第20段]。

**4****.21** 只有在管理层已考虑为何该项要求的目标在其特定情况下未能实现或不相关之后，主体才可偏离某项IFRS要求。管理层还应考虑主体自身情况与遵循该相关IFRS要求的其他主体有何不同。存在一项可反驳的推定：如果处于类似情况的其他主体遵循了该项要求，则本主体也应予以遵循。

[IAS 1 第24段]。

<a id="s28-Para_4.22"></a>**4.22** 偏离某项IFRS要求可能会影响不止一个会计期间。IAS 1要求披露与任何前期偏离IFRS相关的信息。例如，如果主体偏离了关于资产或负债计量的某项要求，将会对后续期间资产和负债变动的计量产生影响。

[IAS 1 第21段]。

<a id="s28-Para_4.23"></a>**4.23** 主体所处的监管框架可能会禁止管理层认为为实现公允列报所必需的对IFRS的偏离。这种情况极为罕见。在此类情况下，主体应作出特定披露，以尽可能减少遵循该要求所带来的误导性影响。

[IAS 1 第23段]。

 

<a id="s28-chap_04_navPoint_9"></a>
### 持续经营

 

<a id="s28-Para_4.24"></a>**4.24** 除非管理层打算清算主体或停止经营，或者别无其他现实选择而只能如此，否则财务报表应当以持续经营为基础编制。管理层在编制财务报表时，必须评估主体的持续经营能力，且该评估至少应涵盖自报告期末起12个月内的主体前景。考虑主体未来12个月期间是最低要求；例如，如果主体打算在报告期末后18个月停止经营，则不能以持续经营为基础编制财务报表。存在对主体持续经营能力的重大疑虑，本身并不足以构成放弃以持续经营为基础编制财务报表的理由。

[IAS 1 第25段]。

<a id="s28-Para_4.25"></a>**4.25** 持续经营的判断应针对每一个报告主体分别作出。对于某一家个别子公司而言，持续经营基础可能不再恰当，但对于该子公司的母公司以及整个集团而言，持续经营基础可能仍然恰当。

[IAS 1 第25段]。

<a id="s28-Para_4.26"></a>**4.26** 评估主体的持续经营状态通常较为直接。一家盈利且无融资困难的主体几乎必然具备持续经营能力。而在其他情况下，管理层可能需要极其审慎地评估主体偿还到期负债的能力，并可能需要借助详细的现金流量和利润预测，才能使管理层确信主体具备持续经营能力。

[IAS 1 第25段]。

[FAQ 4.26.1 – 财务报表应如何披露影响主体持续经营能力的不确定性？](10.md#s30-FAQ_4.26.1)

<a id="s28-Para_4.27"></a>**4.27** 当存在对主体持续经营能力的重大疑虑时，必须进行披露。即使财务报表仍继续以持续经营为基础编制，也应当披露相关不确定性。披露内容应当：

- 充分描述导致对主体持续经营能力产生重大疑虑的主要事项或情况，以及管理层应对这些事项或情况的计划；以及

- 明确说明存在与可能对主体持续经营能力产生重大疑虑的事项或情况相关的重大不确定性，因此主体可能无法在正常经营过程中变现其资产和清偿其负债。

<a id="s28-Para_4."></a>**4.**<a id="s28-Para_27.1"></a>**27.1** 是否以持续经营为基础编制财务报表是一个非此即彼的二元决策，但主体以持续经营为基础编制财务报表所处的具体情形却可能千差万别。这些情形涵盖从主体盈利且无流动性担忧，到即使考虑了管理层计划的缓解措施后、决定以持续经营为基础编制财务报表仍属“勉强成立（close call）”的各种情况。管理层的决策将建立在可能涉及重大不确定性的假设和判断基础之上。因此，主体不仅应考虑IAS 1第25段中与持续经营相关的具体披露要求，还应考虑IAS 1中的总体披露要求，包括第122段关于对财务报表中确认金额具有最重大影响的判断的披露要求。

IFRS基金会发布了教育材料《持续经营——聚焦披露》，以支持公司实施按照IFRS准则在持续经营基础上编制财务报表的相关要求。

[IAS 1 第25段]。

[IAS 1 第122段]

[FAQ 4.27.1 – 应如何应用IAS 1中关于持续经营假设的要求？](10.md#s30-FAQ_4.27.1)

<a id="s28-Para_4.28"></a>**4.28** 报告期后发生的事项可能表明主体不再具备持续经营能力。如果管理层在年末后的评估表明主体不再持续经营，则主体不得以持续经营为基础编制财务报表。在该评估之后编制的任何财务报表（包括管理层正在作出该评估所对应的财务报表）均不得以持续经营为基础编制。这与IAS 10保持一致，IAS 10要求当持续经营假设不再恰当时，应对会计编制基础作出根本性改变。

[IAS 10 第14段]。

<a id="s28-Para_4.29"></a>**4.29** 财务报表在相关情况下应披露其并非以持续经营为基础编制，并披露主体不再被视为持续经营的原因，同时还应披露所采用的新会计编制基础的详情。

[IAS 1 第25段]。

<a id="s28-Para_4.30"></a>**4.30** 财务报表通常基于报告主体持续经营的假设编制。资产和负债通常按照其账面金额将在正常经营过程中收回或清偿的基础予以确认。例如，不动产、厂场和设备的账面价值由其持续使用和最终处置所产生的预期未来现金流量提供支持。如果企业不再持续经营，该基础将不再适用。如果财务报表按照不同基础编制，则应披露所使用的基础。从持续经营基础变更为非持续经营基础的财务影响可能微乎其微，但财务报表仍应披露主体不再被视为持续经营这一事实。

[IAS 1 第25段]。[概念框架 第3.9段]。

[FAQ 4.30.1 – 非持续经营主体的会计编制基础是什么？](10.md#s30-FAQ_4.30.1)

 

<a id="s28-chap_04_navPoint_10"></a>
### 权责发生制

<a id="s28-Para_4.31"></a>**4.31** 除现金流量信息外，主体应当采用权责发生制编制财务报表。在权责发生制下，收入和成本在赚取或发生时予以确认，而不是在收到或支付现金时确认。

[IAS 1 第27段]。

<a id="s28-Para_4.32"></a>**4.32** 财务报表要素（资产、负债、权益、收益和费用）仅在满足理事会《概念框架》中的定义和确认标准时才予以确认。

[IAS 1 第28段]。

<a id="s28-chap_04_navPoint_11"></a>
### 重要性与汇总

 

<a id="s28-Para_4.33"></a>**4.33** 主体应在财务报表中单独列报每一重大类别的类似项目。性质或功能不同的项目应单独列报，除非其不重要。

[IAS 1 第29段]。

<a id="s28-Para_4.34"></a>**4.34** 不重要的单列项目应在主要报表表内或附注中与其他项目汇总。某项目可能不足以重要到需要在财务报表表内单独列报，但可能足以重要到需要在附注中单独列报。

[IAS 1 第30段]。

<a id="s28-Para_4.35"></a>**4.35** 主体在决定如何汇总信息时，应考虑所有相关事实和情况。主体不得用不重要信息掩盖重要信息，也不得将性质或功能不同的重要项目加以汇总。

[IAS 1 第30A段]。

<a id="s28-Para_4.36"></a>**4.36** 如果某项披露产生的信息不重要，主体无需提供IFRS要求的具体披露。即使相关IFRS准则列明了具体要求清单或将其描述为最低要求，亦是如此。如果遵循特定IFRS要求不足以使使用者理解特定交易、其他事项和情况对主体财务状况和财务业绩的影响，主体应考虑提供补充披露。

[IAS 1 第31段]。

<a id="s28-Para_4.37"></a>**4.37** 自2020年1月1日或之后开始的年度期间起，重要性的定义已作修订。如果省略、错报或掩盖某项信息可以合理预期会影响通用目的财务报表主要使用者基于提供特定报告主体财务信息的该等财务报表作出的决策，则该信息是重要的。

重要性取决于信息的性质或金额大小，或两者兼而有之。某项信息单独或与其他信息结合起来是否重要，应结合主体财务报表整体进行评估。

该修订澄清，提及掩盖信息旨在涵盖其效果类似于省略或错报该信息的情形。

重要项目、交易或其他事项可能被掩盖的部分情形包括：

- 使用含糊或不清楚的表述；

- 将信息分散在财务报表的各个部分；

- 不恰当地汇总不类似的项目、交易或其他事项；

- 不恰当地分拆类似的项目、交易或其他事项；以及

- 通过用不重要信息隐藏重要信息，降低财务报表的可理解性，致使主要使用者无法确定哪些信息是重要的。

[IAS 1 第7段]。

<a id="s28-Para_4.38"></a>**4.38** 财务报告系为对商业和经济活动具有合理知识且认真审阅和分析信息的使用者编制。重要性应以具备合理知识人士的决策为基准进行评估。

上述[第4.37段](10.md#s28-Para_4.37)所述的修订还澄清了通用目的财务报表所面向的“通用目的财务报表主要使用者”的含义，将其定义为必须依赖通用目的财务报表获取其所需大部分财务信息的“现有和潜在投资者、贷款人及其他债权人”。财务报表系为对商业和经济活动具有合理知识且认真审阅和分析信息的使用者编制。

重要性概念在[第3章第11段](09.md#s20-Para_3.11)中有进一步讨论。

[IAS 1 第7段]。

 

<a id="s28-chap_04_navPoint_12"></a>
### 抵销/净额列报

 

<a id="s28-Para_4.39"></a>**4.39** 除非IFRS明确要求或允许，否则主体不得将资产和负债或者收益和费用相互抵销或以净额列报。抵销通常被禁止，因为抵销会削弱使用者全面、恰当理解已发生交易、其他事项和情况以及评估主体未来现金流量的能力。不被视为资产和负债抵销的项目包括累计折旧与摊销、存货跌价准备以及减值准备。

[IAS 1 第32段]。

[FAQ 4.39.2 – 管理层应如何列报出售不动产、厂场和设备产生的利得？ ](10.md#s30-FAQ_4.39.2)  
  
[FAQ 4.39.3 – 用于修复活动的资产（包括使用权资产）折旧能否列报为弃置义务准备的减少？](10.md#s30-FAQ_4.39.3)

<a id="s28-Para_4.40"></a>**4.40** 金融资产和金融负债的抵销在[第47章第15段](78.md#s308-Para_47.15)中有进一步探讨。IAS 12包含关于税务项目抵销的规则，详见[第14章第149段](27.md#s100-Para_14.149)。IAS 20讨论了与资产相关的政府补助的列报，详见[第17章第14段](37.md#s129-Para_17.14)。“收入”的计量（包括商业折扣、批量返利和代理安排的处理）见[第11章](19.md#s64-chap_11)。

 

<a id="s28-chap_04_navPoint_13"></a>
### 报告频率

 

<a id="s28-Para_4.41"></a>**4.41** 财务报表应至少每年列报一次。当主体变更报告期末并列报长于或短于一年的财务报表时，应披露采用非一年期报告期间的原因，同时还应披露比较金额不具可比性这一事实。

[IAS 1 第36段]。

<a id="s28-Para_4.42"></a>**4.42** 允许主体按52周期间（而非精确的一个公历年）编制财务报表。

[IAS 1 第37段]。

 

<a id="s28-chap_04_navPoint_14"></a>
### 比较信息

 

<a id="s28-Para_4.43"></a>**4.43** 主体应对当期财务报表中报告的所有金额列报上一期间的比较信息。如果叙述性和描述性信息与理解当期财务报表相关，也应包括该等信息的比较信息。

[IAS 1 第38段]。

<a id="s28-Para_4.44"></a>**4.44** 主体至少应列报两张资产负债表、两张损益及其他综合收益表、两张单独的损益表（如列报）、两张现金流量表和两张所有者权益变动表，以及相关附注。主体可以提供超出这些最低比较要求的财务报表（参见[第4.51段](10.md#s28-Para_4.51)）。当主体变更会计政策，或进行追溯重述或重分类时，应提供期初财务状况表（参见[第4.48段](10.md#s28-Para_4.48)）。

[IAS 1 第38A段]。

<a id="s28-Para_4.45"></a>**4.45** 对于某些期初与期末余额调节表，存在豁免列报比较数字信息的规定。例如，IAS 37要求提供预计负债期初与期末余额的调节表，但未要求披露比较期间的调节表。IAS 16和IAS 38则要求提供期初与期末余额变动的完整比较信息。所有者权益变动表不存在此类豁免。

[IAS 37 第84段]。

<a id="s28-Para_4.46"></a>**4.46** 如果比较叙述性信息不再相关，主体无需提供。若某项法律纠纷在上一资产负债表日尚未了结且至今仍未解决，则当期财务报表应披露该纠纷的详情及为解决该纠纷已采取的措施。如果某项法律纠纷在年内达成和解，则在需要解释主体当期业绩时应披露该纠纷的结果（参见[第4.123段](10.md#s29-Para_4.123)）。

[IAS 1 第38B段]。

<a id="s28-Para_4.47"></a>**4.47** 主体可能会变更项目的列报或分类。比较数字应与新列报保持一致。主体应披露被重分类的每一项目或每类项目的性质和金额，以及重述比较信息的原因（另参见[第4.53段](10.md#s28-Para_4.53)）。该披露要求同样适用于作为上一期间期初列报的附加资产负债表（见下文）。

[IAS 1 第41段]。

<a id="s28-Para_4.48"></a>**4.48** 当主体追溯应用会计政策变更、对财务报表中的项目进行追溯重述或重分类，且对上一期间期初资产负债表中的信息产生重大影响时，应当列报期初资产负债表。无论主体财务报表是否列报了更早期间的比较信息，该附加资产负债表均应以上一期间期初为基准日列报。主体应列报三张资产负债表，基准日分别为：

- 当期期末；

- 上一期间期末；以及

- 上一期间期初。

[IAS 1 第40A段]。

<a id="s28-Para_4.49"></a>**4.49** 被要求列报上一期间期初资产负债表的主体，无需列报该资产负债表的相关附注。这与主体自愿选择列报额外比较信息的情形不同，在后一种情形下，必须提供相关附注（参见[第4.51段](10.md#s28-Para_4.51)）。

[IAS 1 第40C段]。

[FAQ 4.49.1 – 比较信息的重述是否要求提供20X0年1月1日的期初资产负债表（即附加资产负债表）？](10.md#s30-FAQ_4.49.1)

<a id="s28-Para_4.50"></a>**4.50** 首次采用者应对IFRS 1要求的第三张资产负债表列报完整的比较附注。进一步详情见[第2章第138段](08.md#s16-Para_2.138)。

<a id="s28-Para_4.51"></a>**4.51** 主体可以选择列报第三张综合收益表（列报当期、上一期间以及一个额外的比较期间）。此时，主体还应列报与该额外综合收益表相关的比较附注，但无需列报第三张资产负债表、第三张现金流量表或第三张所有者权益变动表。对于主体自愿提供或根据法规、法律要求提供的额外信息，通常均需提供完整附注。

[IAS 1 第38C段]。

<a id="s28-Para_4.52"></a>**4.52** 当主体变更财务报表项目的列报或分类时，重述比较数字可能切实不可行。在此情况下，主体应披露未重述的原因，以及若重述切实可行时本应作出的调整的性质。如果主体在作出一切合理努力后仍无法应用某项要求，则应用该要求即为“切实不可行”。如果上一期间的数据未按允许重分类的方式收集（且无法重新收集），则主体不进行重分类。

[IAS 1 第42段]。

 

<a id="s28-chap_04_navPoint_15"></a>
### 列报的一致性

<a id="s28-Para_4.53"></a>**4.53** 主体应在各期间保持财务报表项目列报和分类的一致性，除非：

- 在主体经营性质发生重大变化或审阅其财务报表后，显而易见另一种列报或分类能够提供更相关且可靠的信息；或者

- 某项IFRS要求变更列报。

[IAS 1 第45段]。

<a id="s28-Para_4.54"></a>**4.54** 只有当新列报优于先前列报时，主体方可变更列报方式。主体只应变更为在未来期间很可能持续采用的列报方式，以免损害可比性。

[IAS 1 第46段]。

<a id="s29-chap_04_navPoint_16"></a>
## 结构与内容（第4.55-4.164段）

 

<a id="s29-Para_4.55"></a>**4.55** 部分强制性披露应在主要报表表内作出；除非其他准则另有规定，否则其他强制性披露可在附注中或在财务报表表内作出。

[IAS 1 第47段]。

 

<a id="s29-chap_04_navPoint_17"></a>
### 财务报表的识别

<a id="s29-Para_4.56"></a>**4.56** 财务报表应当予以明确识别，并与同一公开出版物中的其他信息区分开来。财务报表使用者必须能够区分按照IFRS列报的信息与作为财务报表补充的其他信息。

[IAS 1 第49段]。

<a id="s29-Para_4.57"></a>**4.57** 符合IFRS的财务报表应当与可能符合或可能不符合IFRS的其他信息区分开来。使用替代业绩指标（通常称为“非GAAP指标”）一直受到监管机构的关注。主体在其公开出版物中列报替代业绩指标时应当审慎，确保将其与IFRS定义或规定的指标区分开来。

[IAS 1 第49段]。

<a id="s29-Para_4.58"></a>**4.58** 主体应当清晰地识别每张财务报表及附注。主体应以显著方式列示下列信息，并在为使所列报信息易于理解而有必要时重复列示：

- 报告主体的名称或其他识别方式，以及自上一报告期末以来该信息的任何变更；

- 财务报表属于个别主体还是主体集团；

- 报告期末的日期，或者财务报表或附注所涵盖的期间；

- IAS 21定义的列报货币；以及

- 所采用的金额舍入单位。

[IAS 1 第51段]。

<a id="s29-Para_4.59"></a>**4.59** 上述要求通常通过为页面、报表和栏次等设置适当标题来满足；但在以电子方式列报财务报表时，可能需要采用其他方式。

[IAS 1 第52段]。

<a id="s29-Para_4.60"></a>**4.60** 主体可以通过以列报货币的千元或百万元为单位列报信息，使财务报表更加清晰。只要说明舍入单位且不遗漏重要信息，这种做法是被允许的。

[IAS 1 第53段]。

**相关信息**

<a id="s29-chap_04_navPoint_18"></a>
### 财务状况表（资产负债表）

<a id="s29-chap_04_navPoint_idp1688824264"></a>
#### 资产负债表表内项目

<a id="s29-Para_4.61"></a>**4.61** 资产负债表表内应当披露下列项目：

- 不动产、厂场和设备。

- 投资性房地产。

- 无形资产。

- 金融资产（不包括(e)、(h)和(i)项下列示的金额）。

- 采用权益法核算的投资。

- 生物资产。

- 存货。

- 应收账款及其他应收款。

- 现金及现金等价物。

- 按照IFRS 5分类为持有待售的资产总额及包含在分类为持有待售处置组中的资产总额。

- 应付账款及其他应付款。

- 预计负债。

- 金融负债。

- IAS 12定义的当期所得税负债和当期所得税资产。

- IAS 12定义的递延所得税负债和递延所得税资产。

- 包含在按照IFRS 5分类为持有待售处置组中的负债。

- 在权益中列报的非控制性权益。

- 归属于母公司所有者的已发行股本和储备。

[IAS 1 第54段]。

<a id="s29-Para_4.62"></a>**4.62** 大多数编制IFRS财务报表的主体都需要在资产负债表表内区分流动资产与非流动资产、流动负债与非流动负债（参见[第4.70段](10.md#s29-Para_4.70)）。准则未规定上述项目的列报顺序或格式。

[IAS 1 第56段]。

<a id="s29-Para_4.63"></a>**4.63** 主体可以列报净资产合计，并列示其等于资本与储备及非控制性权益之和。许多主体则列示资产总计等于负债加资本与储备之和。

[IAS 1 第54段]。

<a id="s29-Para_4.64"></a>**4.64** [第4.61段](10.md#s29-Para_4.61)列明的单列项目构成资产负债表表内的最低内容要求。当IFRS要求，或者某项目或类似项目汇总后的规模、性质或功能使得单独列报与理解主体财务状况相关时，主体应当增设附加单列项目。

[IAS 1 第55段]。

<a id="s29-Para_4.65"></a>**4.65** 单列项目的文字描述及列示顺序可根据主体的性质及其交易进行调整。例如，金融机构可以修改单列项目的描述，以提供与其经营活动相关的信息。

[IAS 1 第57(b)段]。

<a id="s29-Para_4.66"></a>**4.66** 管理层在确定最恰当的列报形式及是否需要单独列示附加单列项目时，应考虑下列因素：

- 资产的性质和流动性。例如，由于性质不同，商誉与其他无形资产通常应在资产负债表表内分别列报。

- 资产的功能。

- 负债的性质、时间分布和金额。在大多数情况下，这将导致（例如）将计息负债与非计息负债分别列报。

[IAS 1 第58段]。

<a id="s29-Para_4.67"></a>**4.67** 主体列报的任何小计均应满足以下要求：

- 由按照IFRS确认和计量的金额所构成的单列项目组成；

- 其列报和标注方式应使构成该小计的单列项目清晰易懂；

- 各期间保持一致（参见[第4.53段](10.md#s28-Para_4.53)）；并且

- 不得比IFRS要求的小计和合计更为显著地展示。

[IAS 1 第55A段]。

<a id="s29-Para_4.68"></a>**4.68** 主体还应评估任何附加单列项目或小计，以确定其是否属于替代业绩指标，以及监管机构是否对此类项目的报告施加了任何限制或额外要求。

<a id="s29-Para_4.69"></a>**4.69** 对资产或负债采用不同的计量基础，表明其性质或功能存在差异。性质或功能不同的项目应作为单独的单列项目列报。例如，某些类别的不动产、厂场和设备可能按成本计量，而其他类别则按重估金额计量。

[IAS 1 第59段]。

<a id="s29-chap_04_navPoint_idp1687140408"></a>
#### 流动/非流动分类

 

<a id="s29-Para_4.70"></a>**4.70** 主体应在资产负债表表内将流动资产和非流动资产、流动负债和非流动负债作为单独类别列报，除非按流动性顺序列报能够提供可靠且更相关的信息。当采用流动性顺序列报时，所有资产和负债均应大致按流动性顺序排列。对于部分主体（如金融机构），“按流动性列报的资产负债表”将更具相关性，因为此类主体并非在清晰可辨认的营业周期内提供商品或劳务。

[IAS 1 第60段]。

<a id="s29-Para_4.71"></a>**4.71** 当主体在清晰可辨认的营业周期内提供商品或劳务时，将流动与非流动资产及负债分开分类是有用的。这种分类能够区分作为营运资金持续周转的净资产与用于主体长期经营的净资产。营业周期是指从取得用于加工的资产至其变现为现金或现金等价物之间的期间。如果正常营业周期无法辨认，则假定其持续时间为12个月。主体是否列报流动/非流动分类资产负债表，很大程度上取决于其所处的行业。

[IAS 1 第62段]。

[FAQ 4.71.1 – 应如何选择资产负债表最相关的列报方式（流动/非流动分类法或流动性顺序法）？](10.md#s30-FAQ_4.71.1)

<a id="s29-Para_4.72"></a>**4.72** 对于同时包含预计在12个月内收回或清偿的金额以及预计在超过12个月后收回或清偿的金额的每一项资产和负债单列项目，主体均须作出额外披露。此要求同时适用于流动性顺序法和流动/非流动分类法。主体应分别披露预计在报告期后12个月内收回或清偿的金额，以及预计在超过12个月后收回或清偿的金额。

[IAS 1 第61段]。

<a id="s29-Para_4.73"></a>**4.73** IAS 1使用“流动”和“非流动”术语，但只要含义清晰，也允许使用替代性描述。

[IAS 1 第67段]。

<a id="s29-Para_4.74"></a>**4.74** 对于某些主体而言，对部分资产和负债采用流动/非流动分类法、而对其他资产和负债采用流动性顺序法列报可能是恰当的。尽管准则指出这种混合列报基础可能出现在主体从事多元化经营的情况下，但并未就如何采用这种混合列报提供具体指引。

[IAS 1 第64段]。

 

<a id="s29-chap_04_navPoint_idp1687202856"></a>
##### 流动资产

 

<a id="s29-Para_4.75"></a>**4.75** 满足下列条件之一的资产属于流动资产：

- 主体预计在其正常营业周期内变现，或者打算出售或消耗该资产；

- 主要为交易目的而持有；

- 主体预计在报告期后12个月内变现该资产；或者

- 该资产为现金或现金等价物（参见[第7章第3段](15.md#s45-Para_7.3)），除非该资产自报告期后至少12个月内被限制用于交换或清偿负债。

所有其他资产均为非流动资产。

[IAS 1 第66段]。

[FAQ 4.75.1 – 应如何确定正常营业周期？ ](10.md#s30-FAQ_4.75.1)  
  
[FAQ 4.75.2 – 见索即付的集团内部应收款项应如何分类？](10.md#s30-FAQ_4.75.2)

<a id="s29-Para_4.76"></a>**4.76** 现金及现金等价物见[第7章第3段](15.md#s45-Para_7.3)。其他金融资产（包括衍生工具）的流动/非流动分类见[第47章第2段](78.md#s307-Para_47.2)及以下各段。

 

<a id="s29-chap_04_navPoint_idp1687216552"></a>
##### 持有待售的非流动资产

 

<a id="s29-Para_4.77"></a>**4.77** 持有待售的非流动资产见[第30章第3段](53.md#s218-Para_30.3)。

 

<a id="s29-chap_04_navPoint_idp1687212840"></a>
##### 所得税资产

 

<a id="s29-Para_4.78"></a>**4.78** 无论预计收回期间长短，递延所得税资产均不得分类为流动资产（[参见第14章第148段](27.md#s100-Para_14.148)）。

[IAS 1 第56段]。

[FAQ 4.78.1 – 主体能否将递延所得税列报为既非流动也非非流动？](10.md#s30-FAQ_4.78.1)

<a id="s29-Para_4.79"></a>**4.79** 应收当期所得税若预计在报告期后12个月内变现，应分类为流动资产；否则，应列示为非流动资产。

[IAS 1 第66(c)段]。

 

<a id="s29-chap_04_navPoint_idp1687234344"></a>
##### 流动负债

 

<a id="s29-Para_4.80"></a>**4.80** 满足下列条件之一的负债属于流动负债：

- 主体预计在其正常营业周期内清偿的负债；

- 主要为交易目的而持有的负债；

- 应在报告期后12个月内到期清偿的负债；或者

- 主体不拥有无条件权利将其清偿推迟至报告期后至少12个月的负债。负债条款中可能由交易对手方选择通过发行权益工具进行清偿的规定，不影响该负债的分类。这意味着，由持有人自行决定行使的转股特征不影响可转换工具负债成分的分类。[参见第47章第7段](78.md#s307-Para_47.7)。

所有其他负债均为非流动负债。

[IAS 1 第69段]。

IASB已发布对IAS 1的修订，修改了将负债分类为流动或非流动的指引。该修订的生效日期为自2023年1月1日或之后开始的年度报告期间。本手册中的指引基于该准则的现行版本。

[FAQ 4.80.1 – 附带控制权变更协议的借款在资产负债表中应如何分类？ ](10.md#s30-FAQ_4.80.1)  
  
[FAQ 4.80.2 – 附带重大不利变化条款和主观加速到期条款的借款应如何分类？](10.md#s30-FAQ_4.80.2)

<a id="s29-Para_4.81"></a>**4.81** 流动负债并不一定是主体预计在报告期后12个月内清偿的负债。将在主体正常营业周期内清偿的负债应分类为流动负债，即使在报告期末主体有权将付款推迟至更晚日期。例如，应付账款以及部分雇员和其他经营成本的预提费用，属于企业正常营业周期内发生的经营性负债。该营业周期可能超过12个月。在报告期末应在报告期后12个月内到期清偿的其他负债，列示为流动负债。

[IAS 1 第70段]。

[FAQ 4.81.1 – 主体在资产负债表中应如何分类产品质量保证准备和环境准备？](10.md#s30-FAQ_4.81.1)

 

<a id="s29-chap_04_navPoint_idp1687248680"></a>
##### 借款及限制性条款（契约）遵守情况

 

<a id="s29-Para_4.82"></a>**4.82** 如果一项金融负债将在年末后12个月内到期清偿，主体应将其分类为流动负债。即使在年末之后、财务报表批准报出之前达成了长期再融资或重新安排付款计划的协议，亦是如此。具体而言，准则要求在资产负债表日后12个月内到期清偿的金融负债应列报为流动负债，即使：

- 原始期限超过12个月；并且

- 在资产负债表日之后、财务报表批准报出之前达成了长期再融资或重新安排付款计划的协议。

 

  

IASB已发布对IAS 1第72–76段（涉及借款及限制性条款遵守情况）的修订。目前，该修订的生效日期为2023年1月1日（视相关认可程序而定）。IASB目前有一个正在进行的项目，预计将在该修订生效前对其进行修改，并将生效日期推迟至2024年1月1日。鉴于该修订可能发生更新，本手册未对现行修订的影响作出示例说明。

  

[IAS 1 第72段]。

<a id="s29-Para_4.83"></a>**4.83** 如果主体不拥有无条件权利将负债的清偿推迟至报告期末后至少12个月，主体应将该负债分类为流动负债。若某项负债虽未安排在报告期末后12个月内偿还，但贷款人可随时无理由要求偿还，则该负债应分类为流动负债。

[IAS 1 第69(d)段]。

<a id="s29-Para_4.84"></a>**4.84** 由贷款人自行决定的年末后债务重新安排或再融资，属于资产负债表日后非调整事项，不影响债务在资产负债表日的流动/非流动分类。如果再融资或展期完全由借款主体自行决定，且主体有能力并打算将债务展期至少一年以上，则该债务可分类为非流动负债。主体必须拥有将义务展期的完全自主决定权；仅存在再融资的可能性并不足以将义务分类为非流动负债。但是，如果主体虽然拥有长期再融资的自主决定权，但预计在12个月内清偿该义务，则该债务可分类为流动负债。

[IAS 1 第73段]。

FAQ 4.84.1 – 再融资协议如何影响银行债务的列报？   
  
[FAQ 4.84.1 – 债务保理安排产生的负债的分类](10.md#s30-FAQ_4.84.1)

<a id="s29-Para_4.85"></a>**4.85** 金融机构通常在借款合同中包含借款限制性条款（契约）。对违反借款限制性条款（契约）的评估侧重于主体的法律权利。但当主体拥有将借款展期或再融资的自主决定权时，主体对清偿时间的预期也会影响负债的分类。在某些借款限制性条款（契约）下，如果违反了与借款人财务状况或经营业绩相关的特定指标，原本属于长期性质的借款将变为立即可要求偿还。这些指标通常是基于主体财务报表计算得出的流动性或偿债能力比率。部分借款包含“交叉违约”条款，即某项借款的条款至少在一定程度上取决于另一项借款限制性条款（契约）的遵守情况。一旦相关借款限制性条款（契约）被违反，附带“交叉违约”条款的借款以及任何类似关联的借款均可能变为立即可要求偿还，从而被分类为流动负债。

[IAS 1 第74段]。

<a id="s29-Para_4.86"></a>**4.86** 如果上述类型的违约发生在报告期末之前，除非贷款人授予了充分的限制性条款（契约）豁免，使借款不会变为立即可要求偿还，否则该借款应分类为流动负债。贷款人可能在报告期后、财务报表批准报出前同意不要求立即偿还借款。贷款人的该项同意通常被视为资产负债表日后非调整事项，因为在报告期末尚未取得贷款人的同意，该借款在当时的状态是立即可要求偿还的。IFRS 7下关于借款协议违约和违反条款的披露见[第47章第67段](78.md#s309-Para_47.67)及以下各段。

[IAS 1 第74段]。

[FAQ 4.86.1 – 当主体在报告期末后才报告违反借款限制性条款（契约）时，借款余额应如何分类？](10.md#s30-FAQ_4.86.1)

<a id="s29-Para_4.87"></a>**4.87** 在发生导致借款立即可要求偿还的违反借款限制性条款（契约）情形后，贷款人有时会同意给予宽限期，以便借款人在该期间内纠正违约行为。贷款人同意在此期间内不要求还款，但如果违约未获纠正，债务将在宽限期结束时变为立即可要求偿还。如果贷款人在资产负债表日之前已同意给予该宽限期，且该宽限期在资产负债表日后至少12个月才结束，则该负债应列示为非流动负债。但是，如果违约发生在资产负债表日之前，而宽限期直至资产负债表日之后才获授予，则该负债应分类为流动负债。主体需要评估贷款人给予的是宽限期，还是永久放弃因当期特定违约所产生的可执行权利的豁免。

[IAS 1 第75段]。

[FAQ 4.87.1 – 当借款协议包含宽限期时，借款余额应如何分类？](10.md#s30-FAQ_4.87.1)  
[FAQ 4.87.2 – 当贷款人在特定报告日之前豁免限制性条款（契约）合规报告要求时，借款应如何列报？](10.md#s30-FAQ_4.87.2)  
[FAQ 4.87.3 – 当贷款人在当期豁免了违反限制性条款（契约）的行为时，借款应如何分类？](10.md#s30-FAQ_4.87.3)

<a id="s29-Para_4.88"></a>**4.88** 如果违反借款限制性条款（契约）发生在资产负债表日之后，该负债应列示为非流动负债。借款的列报取决于其在资产负债表日的状态。资产负债表日后事项可能提供关于该状态的证据，但不会改变该状态。然而，严重的违约可能会影响主体对自身持续经营能力的评估（参见[第4.24段](10.md#s28-Para_4.24)）。

<a id="s29-Para_4.89"></a>**4.89** 报告期后事项不会改变负债的分类，但可能需要作为非调整事项予以披露。如果下列事项发生在报告期末与财务报表批准报出日之间，主体应按照IAS 10将其作为非调整事项予以披露：

- 长期再融资。

- 纠正对长期借款协议的违约。

- 贷款人授予纠正长期借款协议违约的宽限期，且该宽限期在报告期后至少12个月才结束。

[IAS 1 第76段]。

<a id="s29-Para_4.90"></a>**4.90** IAS 1未针对非流动借款的资产负债表日后非调整事项规定具体披露要求。如果此类事项重大（即不披露可能会影响使用者基于财务报表作出的经济决策），主体应就每一此类事项披露下列信息：

- 事项的性质；以及

- 对其财务影响的估计，或无法作出此类估计的说明。

[IAS 10 第21段]。

 

<a id="s29-chap_04_navPoint_idp1684551288"></a>
##### 所得税负债

 

<a id="s29-Para_4.91"></a>**4.91** 无论暂时性差异预计转回期间长短，递延所得税负债均应分类为非流动负债（[参见第14章第148段](27.md#s100-Para_14.148)）。

[IAS 1 第56段]。

<a id="s29-Para_4.92"></a>**4.92** 其他所得税负债若预计在报告期末后12个月内到期清偿，应分类为流动负债；否则，应列示为非流动负债。

[IAS 1 第69(c)段]。

 

<a id="s29-chap_04_navPoint_idp1684559992"></a>
#### 财务状况表附注

 

<a id="s29-Para_4.93"></a>**4.93** 主体应在资产负债表表内或附注中，以适合主体经营活动的方式，披露所列报单列项目的进一步细分。

[IAS 1 第77段]。

<a id="s29-Para_4.94"></a>**4.94** 这种细分的程度取决于所涉及项目的规模、性质和功能，以及其他准则和解释公告中的具体要求。需要细分的项目示例包括：

- 不动产、厂场和设备应按类别列示。

- 应收账款、应收关联方款项、预付款项及其他款项应分别列示。

- 存货应按类别列示。常见分类包括库存商品、生产物料、原材料、在产品和产成品。

- 雇员福利准备应与其他预计负债分别列示。

- 股本和储备应细分为实收资本、股本溢价和各项储备等类别。

[IAS 1 第78段]。

<a id="s29-Para_4.95"></a>**4.95** 准则要求就每一类别的股本以及权益中每一项储备的性质和目的作出具体披露，同时也要求披露主体如何管理其资本资源。参见[第51章第46段及以下各段](85.md#s352-Para_51.46)。

[IAS 1 第79段]。

<a id="s29-Para_4.96"></a>**4.96** 没有股本的主体（如合伙企业或信托）应就每一类别的权益利益，披露与IAS 1对股本所要求信息相当的信息（参见[第51章第48段](85.md#s352-Para_51.48)）。

[IAS 1 第80段]。

<a id="s29-Para_4.97"></a>**4.97** 主体可能会在金融负债和权益之间对特定项目进行重分类。此时，主体应披露重分类转入和转出每一类别（金融负债或权益）的金额，以及进行该重分类的时间和原因。这些披露要求适用于下列类型的工具（[参见第43章第36段](67.md#s277-Para_43.36)）：

- 分类为权益工具的可回售金融工具；或者

- 仅在清算时使主体承担向另一方交付主体净资产按比例份额的义务、且分类为权益工具的工具（例如有限存续期主体发行的部分股份）。

[IAS 1 第80A段]。

<a id="s29-Para_4.98"></a>**4.98** 财务报表的其他附注见[第4.145段](10.md#s29-Para_4.145)及以下各段。

### 损益及其他综合收益表

<a id="s29-Para_4.99"></a>**4.99** 列报单独损益表的主体（参见[第4.8段](10.md#s27-Para_4.8)），不在列报综合收益的报表中列报损益部分。单独的综合收益表应以当期利润作为起始行。

[IAS 1 第81A段]。

<a id="s29-Para_4.100"></a>**4.100** “损益”是指收益减去费用后的总额，不包括其他综合收益的组成部分。“其他综合收益”是指按照IFRS的要求或允许未计入损益的收益和费用总额。“综合收益总额”是指由交易和其他事项引起的权益变动，但不包括与所有者以其所有者身份进行的交易引起的变动。

[IAS 1 第7段]。

<a id="s29-Para_4.101"></a>**4.101** 随附IAS 1的实施指引提供了损益及其他综合收益表的示例，既展示了作为单一报表的综合收益表，也展示了作为两张报表的替代做法：损益表和单独的其他综合收益表。

[IAS 1 第10A段]。

<a id="s29-chap_04_navPoint_idp1684590840"></a>
#### 利润表中应列报的信息

 

<a id="s29-Para_4.102"></a>**4.102** 利润表中应当列报下列项目：

- 收入，单独列报采用实际利率法计算的利息收入。

- 终止确认以摊余成本计量的金融资产产生的利得和损失。

- 财务费用。

- 按照IFRS 9第5.5节确定的减值损失（包括减值损失的转回或减值利得）。

- 采用权益法核算的联营企业和合营企业的损益份额。

- 如果一项金融资产从摊余成本计量类别重分类为以公允价值计量且其变动计入当期损益，该金融资产原摊余成本与重分类日（按IFRS 9的定义）公允价值之间的差额所产生的任何利得。

- 如果一项金融资产从以公允价值计量且其变动计入其他综合收益计量类别重分类为以公允价值计量且其变动计入当期损益，先前计入其他综合收益并重分类至损益的任何累计利得或损失。

- 所得税费用。

- 终止经营合计的单一金额，包括下列两项之和：

- 终止经营的税后损益；以及

- 对构成终止经营的资产或处置组按公允价值减去出售费用后的净额计量或处置时确认的税后利得或损失。

[IAS 1 第82段]。

#### 其他综合收益部分应列报的信息

<a id="s29-Para_4.104"></a>**4.104** 其他综合收益项目应按性质分类，并分组为后续不会重分类进损益的项目，以及在满足特定条件时后续将重分类进损益的项目（参见[第4.134段](10.md#s29-Para_4.134)）。

[IAS 1 第82A段]。

<a id="s29-chap_04_navPoint_idp1684624248"></a>
#### 当期损益

<a id="s29-Para_4.105"></a>**4.105** 除非某项准则或解释公告另有要求或允许，否则当期确认的所有收益和费用项目均应计入当期损益。未计入当期损益的收益和费用项目应在综合收益表中确认为其他综合收益。参见[第4.128段](10.md#s29-Para_4.128)。

[IAS 1 第88段]。

<a id="s29-Para_4.106"></a>**4.106** 主体应披露归属于母公司所有者的持续经营收益和终止经营收益金额。这些披露可在附注中或在利润表中列报。进一步详情见[第30章第41段](53.md#s218-Para_30.41)。

[IFRS 5 第33段]。

<a id="s29-Para_4.107"></a>**4.107** 主体应列报在非控制性权益和母公司所有者之间分配的当期利润总额和综合收益总额。IFRS 10要求非控制性权益在权益内列报，而非作为负债列报。

[IAS 1 第81B段]。

##### 费用分析：按性质分类或按功能分类

 

<a id="s29-Para_4.108"></a>**4.108** 主体应根据费用的性质或其在本主体内的功能，选择能够提供可靠且更相关信息的方法列报费用分析。按性质分类或按功能分类的细分，旨在突出在发生频率、产生利得或损失的潜力以及可预测性方面可能存在差异的财务业绩组成部分。

[IAS 1 第99段]。

<a id="s29-Para_4.109"></a>**4.109** IAS 1鼓励主体在报表表内列报上述附加费用分析。未在报表表内提供该分析的主体，应在附注中提供。

[IAS 1 第100段]。

<a id="s29-Para_4.110"></a>**4.110** 采用“按性质分类”法的主体，按照费用的性质对其进行分类（例如折旧、材料采购、运输费、雇员福利和广告费），而不将这些费用在主体内部的各个功能之间进行分摊。

##### 附加单列项目、标题和小计

 

<a id="s29-Para_4.115"></a>**4.115** 如果附加单列项目、标题或小计与理解主体的财务业绩相关，主体应在损益及其他综合收益表中列报这些项目。“附加单列项目”包括对IAS 1第82段所要求单列项目的细分。这独立于主体在主要报表表内或附注中披露重要收益和费用项目的要求。

[IAS 1 第85段]。

<a id="s29-Para_4.116"></a>**4.116** 主体的各项活动、交易和其他事项在发生频率、产生利得或损失的潜力以及可预测性方面各不相同。披露附加项目有助于使用者理解主体过去的财务业绩并预测未来的财务业绩。

[IAS 1 第86段]。

<a id="s29-Para_4.117"></a>**4.117** 主体需要运用判断来确定是否有必要列报附加单列项目或小计，但须服从IAS 1的总体要求，即以提供相关、可靠、可比和可理解信息的方式列报信息。不同主体可能对最佳列报方式持不同观点。正如某项交易可能存在多种可接受的会计政策一样，也可能存在多种同样有效的列报方法。监管机构通常也会对使用附加单列项目或小计的恰当性持特定意见，因此受监管公司在偏离“标准”列报方式时应当审慎。

[IAS 1 第17(b)段]。

<a id="s29-Para_4.118"></a>**4.118** 如果附加单列项目导致利润表杂乱无章从而掩盖了主体的业绩，则不会提供更易于理解的信息。附加单列项目仅应针对重要项目或汇总后重要的项目组合增设。如使用附加单列项目，通常应将其列示在性质或功能类似的其他项目旁。主体需要确保每一单列项目均包含与该特定单列项目相关的全部收入或费用。

[IAS 1 第85段]。

<a id="s29-Para_4.119"></a>**4.119** 列报小计的主体应确保这些小计：

- 由按照IFRS确认和计量的金额所构成的单列项目组成；

- 其列报和标注方式应使构成该小计的单列项目清晰易懂；

- 各期间保持一致；并且

- 不得比IFRS要求的小计和合计更为显著地展示。

[IAS 1 第85A段]。

<a id="s29-Para_4.120"></a>**4.120** 主体必须在列报损益及其他综合收益的报表中列报单列项目，将所列报的任何附加小计与IFRS要求的小计或合计进行调节。

[IAS 1 第85B段]。

<a id="s29-Para_4.121"></a>**4.121** 禁止主体在损益及其他综合收益表表内或附注中将任何收益和费用项目列示为非常项目。

[IAS 1 第87段]。

#### 其他综合收益

<a id="s29-Para_4.127"></a>**4.127** 除非某项准则或解释公告另有要求或允许，否则当期确认的所有收益和费用项目均应计入当期损益。

[IAS 1 第88段]。

<a id="s29-Para_4.128"></a>**4.128** 损益及其他综合收益表列报当期确认的所有收益和费用项目。未计入损益、而在损益及其他综合收益表中列示为“其他综合收益”的收益和费用项目包括以下各项：

- 不动产、厂场和设备的重估利得和损失。

- 无形资产的重估利得和损失。

- 以公允价值计量且其变动计入其他综合收益的权益工具投资产生的利得和损失。

- 以公允价值计量且其变动计入其他综合收益的金融资产产生的利得和损失。

- 对于以公允价值计量且其变动计入当期损益的特定负债，公允价值变动中归属于该负债信用风险变动的金额。

- 现金流量套期中有效套期部分的套期工具利得和损失。

- 当分拆期权合同的内在价值和时间价值、并仅将内在价值的变动指定为套期工具时，期权时间价值的变动。

- 当分拆远期合同的远期要素和即期要素、并仅将即期要素的变动指定为套期工具时，远期合同远期要素价值的变动，以及当金融工具的外汇基差在指定为套期工具时被排除在外时，该外汇基差价值的变动。

- 在合并财务报表中，当境外经营为子公司时，折算对境外经营净投资产生的外币汇兑利得和损失。

- 将主体经营成果和财务状况从记账本位币折算为列报货币（若不同）产生的外币折算差额。

- 设定受益计划的重新计量。

- 与计入其他综合收益的项目相关的当期和递延所得税费用或收益。

[IAS 1 第7段]。

<a id="s29-Para_4.129"></a>**4.129** 主体应单独列报与分类为持有待售的非流动资产或处置组相关的、在其他综合收益中确认的任何累计收益或费用。进一步详情见[第30章第49段](53.md#s218-Para_30.49)。

[IFRS 5 第38段]。

<a id="s29-Para_4.130"></a>**4.130** 其他综合收益部分列报按性质分类的当期其他综合收益金额单列项目。采用权益法核算的联营企业和合营企业的其他综合收益份额（扣除所得税和非控制性权益后）即为此类单列项目之一。这些单列项目按照其他IFRS准则的规定分为以下两组：

- 后续不会重分类进损益的项目；以及

- 在满足特定条件时后续将重分类进损益的项目。

[IAS 1 第82A段]。

<a id="s29-chap_04_navPoint_idp1695561016"></a>
##### 其他综合收益的所得税

 

<a id="s29-Para_4.131"></a>**4.131** 当期所得税和递延所得税应计入损益，除非其与计入其他综合收益的项目或直接计入权益的项目相关，在此情况下，与该等项目相关的所得税应相应确认为其他综合收益或直接计入权益。

[IAS 12 第61A段]。

<a id="s29-Para_4.132"></a>**4.132** 主体应在损益及其他综合收益表或附注中，披露与其他综合收益每一组成部分（即未计入损益的收益和费用，包括重分类调整）相关的所得税金额。

[IAS 1 第90段]。

<a id="s29-Para_4.133"></a>**4.133** 其他综合收益的各组成部分可在综合收益表表内以扣除相关税务影响后的净额列报，或者以扣除相关税务影响前的金额列报并单列一个金额反映与这些组成部分相关的所得税总额。如果主体以扣除相关税务影响前的金额列报其他综合收益项目并单独列示所得税总额，则应将该所得税在后续可能重分类进损益部分的项目与不会重分类的项目之间进行分摊。IAS 1的示例提供了其他综合收益各组成部分税务影响列报的示例。

[IAS 1 第91段]。

 

<a id="s29-chap_04_navPoint_idp1695698760"></a>
##### 重分类（“转回”）调整

 

<a id="s29-Para_4.134"></a>**4.134** 部分IFRS准则要求将先前在其他综合收益中确认的金额重分类至损益。这些重分类调整在相关调整重分类至损益的当期计入相应的其他综合收益组成部分。主体应在综合收益表或附注中披露与其他综合收益各组成部分相关的“重分类调整”（通常亦称为“转回调整”）。IAS 1的示例提供了其他综合收益重分类列报的示例。

[IAS 1 第92段]。

<a id="s29-Para_4.135"></a>**4.135** 如果主体在附注中披露重分类调整，则在综合收益表中作为其他综合收益各组成部分列报的金额应为扣除任何相关重分类调整后的净额。

[IAS 1 第94段]。

<a id="s29-Para_4.136"></a>**4.136** 重分类调整在处置境外经营时（IAS 21）以及某些被套期预期现金流量影响损益时（IFRS 9）产生。

[IAS 1 第95段]。

<a id="s29-Para_4.137"></a>**4.137** 重估盈余的变动（按照IAS 16或IAS 38确认）或设定受益养老金计划的重新计量（按照IAS 19确认）不会产生重分类调整。这些组成部分在其他综合收益中确认，但在后续期间不会重分类至损益。主体可在资产使用过程中或终止确认时将重估盈余的变动转入留存收益；此类结转将在所有者权益变动表中列示。类似地，主体也可以在权益内部结转在其他综合收益中确认的设定受益计划重新计量金额。

[IAS 1 第96段]。

### 所有者权益变动表

 

<a id="s29-Para_4.138"></a>**4.138** 主体应列报包含所有权益变动的所有者权益变动表，既包括与业绩相关的变动，也包括与所有者相关的权益变动（即由增加或减少权益、但不属于业绩组成部分的交易和事项所引起的变动）。所有者权益变动表应包括以下信息：

- 当期综合收益总额，分别列示归属于母公司所有者和归属于非控制性权益的总额。

- 对于每一权益组成部分，按照IAS 8确认的追溯应用或追溯重述的影响。

- 对于每一权益组成部分，期初与期末账面金额之间的调节表，至少分别披露由下列各项引起的变动：

- 损益；

- 其他综合收益；以及

- 与所有者以其所有者身份进行的交易，分别列示所有者的投入和向所有者的分配，以及不导致丧失控制权的子公司所有者权益变动。

权益组成部分例如包括各类投入股本（如不同类别的股份）、各类其他综合收益的累计余额以及留存收益。

[IAS 1 第106段]。[IAS 1 第108段]。

<a id="s29-Para_4.139"></a>**4.139** 对于每一权益组成部分，主体可在所有者权益变动表中或在附注中按项目列报其他综合收益的分析。

[IAS 1 第106A段]。

<a id="s29-Para_4.140"></a>**4.140** 主体在会计期间内净资产的增加或减少，体现为主体在该期间内权益的变动。权益的总体变动是所有收益和费用（无论该等项目计入损益还是计入其他综合收益）与所有者交易（如发行股份和支付股利）之和。

[IAS 1 第109段]。

<a id="s29-Para_4.141"></a>**4.141** 在切实可行的情况下（且影响重大时），主体应对会计政策变更和所有差错更正进行追溯处理。影响所列报最早比较期间净资产期初余额的追溯调整，应计入留存收益余额，除非另一项准则或解释公告要求或允许采用其他处理方法。所有者权益变动表应单独披露因会计政策变更和差错更正对每一权益组成部分所作的调整。这些调整应针对每一前期以及期初余额分别披露。会计政策的追溯应用和差错更正见[第3章第19段](09.md#s20-Para_3.19)、[第3章第39段](09.md#s22-Para_3.39)以及[第4.47段](10.md#s28-Para_4.47)及以下各段。

### 财务报表附注

<a id="s29-chap_04_navPoint_idp1695753160"></a>
#### 结构

<a id="s29-Para_4.145"></a>**4.145** 主体应在财务报表附注中披露以下内容：

- 财务报表的编制基础及编制财务报表所采用的具体会计政策。

- IFRS要求但未在主要报表中列报的信息。

- 未在主要报表中列报、但与理解主要报表相关的附加信息。

[IAS 1 第112段]。

<a id="s29-Para_4.146"></a>**4.146** 主体应以系统的方式列报附注。在确定系统列报方式时，主体应考虑其对财务报表可理解性和可比性的影响。主要报表中的每一项目均应交叉索引至附注中的任何相关信息。

[IAS 1 第113段]。

<a id="s29-Para_4.147"></a>**4.147** 附注包含对主要报表表内列示金额的更详细分析以及叙述性信息。附注满足其他准则和解释公告的披露要求，并披露为实现财务报表公允列报所必需的任何其他信息。

<a id="s29-Para_4.148"></a>**4.148** 附注系统排序或分组的示例如下：

- 突出主体认为与理解其财务业绩和财务状况最相关的经营活动领域，例如将有关特定经营活动的信息归集在一起；

- 将以类似方式计量的项目的信息归集在一起，例如以公允价值计量的资产；或者

- 遵循损益及其他综合收益表和资产负债表中单列项目的顺序，例如：

- 遵循IFRS的声明（参见[第4.15段](10.md#s28-Para_4.15)）。

- 有关编制基础以及对重大交易和事项选择并应用的具体会计政策的信息。该信息可作为财务报表的单独组成部分列报。

- 与财务报表表内列报的单列项目相关的信息。每一财务报表项目均应交叉索引至相应附注。此类附注应尽可能遵循财务报表中项目的列报顺序（但参见[第4.146段](10.md#s29-Para_4.146)）。

- 其他披露，包括或有事项、合同承诺和其他财务披露，以及非财务披露。

[IAS 1 第114段]。

**FAQ**4.150.2 – 哪些会计政策信息可能对主体的财务报表是重要的？

如果某项会计政策信息与重大交易、其他事项或情况相关，且存在下列情形之一，主体很可能认为该会计政策信息对其财务报表是重要的：

(a) 主体在报告期内变更了会计政策，且该变更导致财务报表中的信息发生重大变化；

(b) 主体从IFRS允许的一个或多个选项中选择了该会计政策——例如，主体选择以历史成本而非公允价值计量投资性房地产；

(c) 该会计政策系在没有具体适用的IFRS时按照IAS 8制定的；

(d) 该会计政策涉及主体在应用会计政策时需要作出重大判断或假设的领域，且主体按照IAS 1第122段和第125段披露了这些判断或假设；或者

(e) 对其所要求的会计处理较为复杂，否则主体财务报表使用者将无法理解这些重大交易、其他事项或情况——例如，主体对某一类重大交易同时适用多项IFRS。

**FAQ 4.150.3** 主体应如何确定是否应披露特定的会计政策信息？

根据自2023年1月1日或之后开始的年度期间生效的IAS 1修订，主体被要求披露对于理解其财务报表而言**重要**的会计政策信息。经修订的IAS 1第117段规定：

“如果会计政策信息在结合主体财务报表中包含的其他信息一并考虑时，能够合理预期会影响通用目的财务报表主要使用者基于该等财务报表作出的决策，则该会计政策信息是重要的。”

即使某项交易或其他事项在金额上是重大的，如果会计政策信息本身对于理解主体对该特定交易或事项的会计处理并不重要，仍可省略该会计政策信息。相反，对于金额不太重大的交易或其他事项，由于相关交易或事项的性质，其会计政策信息也可能是重要的。

在确定会计政策信息是否重要时应考虑的因素可能包括但不限于以下各项：

- 主体在报告期内变更了会计政策，且该变更导致政策信息发生重大变化

- 会计政策是从IFRS下的一组备选方案中选择的

- 特定交易或事项的会计政策在IFRS下未作具体规定，因此主体依据IAS 8.10-12的指引自行制定了会计政策

- 会计政策涉及主体在应用这些政策时需要运用重大判断或假设的领域，且主体按照IAS 1.122和125的要求披露了这些判断

- 特定交易或事项的会计要求较为复杂，因此财务报表主要使用者需要有关会计政策的信息，以理解对该交易或事项的会计处理

具有主体针对性、量身定制的会计政策信息，比通用信息（“样板信息”）对主要使用者理解财务报表更具相关性。

如果披露了不重要的会计政策信息，该信息不得掩盖重要信息。

##### 估计不确定性

 

<a id="s29-Para_4.155"></a>**4.155** 主体应披露其对未来的假设以及报告期末估计不确定性的其他主要来源，这些假设和不确定性具有导致下一会计年度内资产和负债账面金额发生重大调整的重大风险。主体应披露此类资产和负债的性质及其在报告期末的账面金额。

[IAS 1 第125段]。

<a id="s29-Para_4.156"></a>**4.156** 信息的提供方式应有助于财务报表使用者理解管理层在存在估计不确定性时所作的判断。披露类型示例如下：

- 假设或其他估计不确定性的性质。

- 账面金额对其计算所依据的方法、假设和估计的敏感性，包括产生该敏感性的原因。

- 不确定性的预期解决情况，以及受影响资产和负债的账面金额在下一会计年度内合理可能结果的范围。

- 如果不确定性仍未解决，对涉及该等资产和负债的过去假设所作变更的说明。

[IAS 1 第129段]。

<a id="s29-Para_4.157"></a>**4.157** 关于估计不确定性的披露要求不同于关于应用会计政策重大判断的披露要求。估计不确定性披露涉及主体掌握的信息不完整或不完善（通常与未来有关）的情形。而主体即使掌握完整信息，在应用会计政策时仍可能必须运用判断。例如，主体可能完全了解其在另一主体中的所有权和表决权情况，但在复杂情况下，仍须运用判断以确定其是否控制该主体。

[IAS 1 第132段]。

<a id="s29-Para_4.159"></a>**4.159** 主体在作出上述强制披露时，无需披露预算信息或预测数据。

<a id="s29-Para_4.160"></a>**4.160** 准则将披露范围限定在具有导致下一会计年度内发生重大调整重大风险的项目。然而，对资产和负债账面金额的评估并非仅基于对下一会计年度的预期，而是基于该资产收回或该负债清偿的整个期间。因此，在下一会计年度内，对资产在更长期间内的可收回性或负债在更长期间内的清偿情况进行重新评估，也可能导致资产或负债的账面金额在该下一会计年度发生重大调整。

### <a id="s30-FAQ_4.26.1"></a>FAQ 4.26.1 – 财务报表应如何披露影响主体持续经营能力的不确定性？

 

准则索引：IAS 1 第25段  
正文索引：[4.26](10.md#s28-Para_4.26)  

  

**问题**

某主体在过去四年持续发生亏损，且其流动负债超过总资产。该主体违反了借款限制性条款（契约），并一直在与相关金融机构谈判以维持其财务支持。这些因素对该主体的持续经营能力产生重大疑虑。财务报表应如何披露影响主体持续经营能力的不确定性？

**解答**

财务报表应声明存在对主体持续经营能力产生重大疑虑的重大不确定性，且主体可能无法在正常经营过程中变现其资产和清偿其负债。财务报表应描述引起重大不确定性的事项和情况，以及管理层拟采取的补救措施。该披露应包含在编制基础附注中。财务报表还应披露对财务状况的可能影响，或者说明计量此类影响切实不可行。

准则索引：  
正文索引：[4.27](10.md#s28-Para_4.27)   

  

 

![](assets/8.png)

 

情形1：

 

- 主体经营盈利且无流动性担忧，对其持续经营能力不存在重大疑虑。

- 除需要描述编制基础外，不存在与持续经营相关的具体披露要求。

- 得出以持续经营为基础编制财务报表的结论时不太可能涉及重大判断。

 

情形2：

 

- 主体处于亏损状态，对其商品或劳务的需求急剧下降，且其融资额度将在未来12个月内到期。

- 在考虑其计划采取的措施的有效性后，管理层得出结论认为重大不确定性预计将得到缓解——管理层已开始实施扭亏为盈战略，且已有充分证据表明该战略取得成效，包括确定了替代融资来源。

- 在考虑计划采取的缓解措施后，管理层得出结论认为不存在重大不确定性。

- 该结论涉及重大判断。根据IAS 1第22段（译注：原文如此，实指第122段）的要求，有必要对得出不再存在重大不确定性这一结论时所作的判断进行恰当披露。

 

情形3：

 

- 主体处于亏损状态，对其商品或劳务的需求急剧下降，且其融资额度将在未来12个月内到期。

- 对于管理层能否执行其扭亏为盈战略以应对需求下降以及能否续展或替换融资，存在相当大的重大不确定性。

- IAS 1第25段要求主体披露与其持续经营能力相关的重大不确定性。

- 得出以持续经营为基础编制财务报表的结论很可能涉及重大判断。在此情况下，主体还必须应用IAS 1第122段关于“持续经营基础恰当”这一重大判断的披露要求。

 

情形4：

 

- 当管理层打算清算主体或停止经营，或者别无其他现实选择而只能如此时，持续经营编制基础不再恰当。

- 在此类情况下，如果主体按照IFRS编制财务报表，则不得以持续经营为基础编制。

- 如果主体不再持续经营，IAS 1未规定编制财务报表的替代基础。

- IAS 1第25段要求披露财务报表未以持续经营为基础编制这一事实、主体不被视为持续经营的原因，以及编制财务报表所依据的基础。

 

<a id="s30-chap_04_navPoint_27"></a>
### <a id="s30-FAQ_4.30.1"></a>FAQ 4.30.1 – 非持续经营主体的会计编制基础是什么？

 

准则索引：IAS 1 第25段  
正文索引：[4.30](10.md#s28-Para_4.30)  

  

IFRS未规定非持续经营主体的会计编制基础。财务报表可能按清算基础或拆卖基础编制，但有时这并不恰当。例如，主体可能被置于接管/破产管理（administration）状态下，而清算/拆卖只是可能的结果之一。会计编制基础可能由管理人指定。如果相关法律允许，财务报表也可以按照IFRS以外的其他会计框架编制。

非持续经营主体的资产和负债的计量，可能受到因主体清算或停止经营而导致的判断变化的影响。例如，对资产可收回金额的估计可能需要修订，从而可能导致对部分资产的账面价值确认减值。

如果财务报表继续按照IFRS编制（但并非以持续经营为基础），主体应按照《概念框架》和IAS 8中的指引制定其会计政策。例如：

- 在资产出售之前不应确认利润，除非该资产以公允价值计量；

- 处置一项资产或现金产出单元（“CGU”）的预期利得，不能与另一项资产或现金产出单元的减值相抵销；

- 除非在报告日存在现时义务，否则主体不应确认负债（例如与重组或雇员福利相关的负债）；以及

- 主体应考虑待执行合同是否已变为亏损合同。

 

<a id="s30-chap_04_navPoint_28"></a>
### <a id="s30-FAQ_4.39.1"></a>FAQ 4.39.1 – 哪些收益与费用的抵销属于可接受的情形？

 

准则索引：IAS 1 第35段  
正文索引：[4.39](10.md#s28-Para_4.39)  

  

被视为可接受的收益与费用抵销项目包括：

- 不产生收入且附属于主要创收活动的交易的收益及相关费用（当该列报反映交易或事项的实质时），例如：

- 处置非流动投资和经营性资产的处置价款与账面价值。

- 合同协议下的支出及相关补偿（例如供应商的质保协议）。

- 一组类似项目产生的利得和损失（除非重大，重大时须单独列报），例如：

- 外币汇兑利得和损失。

- 为交易而持有的金融工具产生的利得和损失。

- 设定受益养老金成本各组成部分（例如当期服务成本、过去服务成本）的净额列示。（各组成部分及其计入的单列项目在附注中单独披露。）

- 扣除已确认补偿金额后的设定受益计划费用。

- 扣除已确认补偿金额后的与预计负债相关的费用。

 

<a id="s30-chap_04_navPoint_29"></a>
### <a id="s30-FAQ_4.39.2"></a>FAQ 4.39.2 – 管理层应如何列报出售不动产、厂场和设备产生的利得？

 

准则索引：IAS 1 第34段  
正文索引：[4.39](10.md#s28-Para_4.39)  

  

**问题**

某主体从事制造业。当期，该主体出售了其一栋建筑物并确认了出售利得。管理层应如何在综合收益表中列报出售该建筑物的利得？

**解答**

出售价款或利得不应分类为收入。主体应通过将销售收入与该建筑物的账面金额及其他相关费用相抵后的净额来列报该利得。该交易产生的利得应列报在营业利润内（如自愿披露营业利润），因为IAS 1要求营业利润包含所有明显与经营相关的项目（包括存货减记、重组和搬迁费用）。

如果该利得或损失的规模、性质或发生情况要求单独披露，则应单独列报。在恰当的情况下，主体可将该利得与性质或功能类似的金额（例如出售其他不动产、厂场和设备的其他利得或损失）汇总列报。

 

<a id="s30-chap_04_navPoint_30"></a>
### <a id="s30-FAQ_4.39.3"></a>FAQ 4.39.3 – 用于修复活动的资产（包括使用权资产）折旧能否列报为弃置义务准备的减少？

 

准则索引：IFRS 16 第36、48段；IAS 37 第36、59段；IFRIC 1  
正文索引：[4.39](10.md#s28-Para_4.39)  

  

 

**问题**

 

用于修复活动的资产（包括使用权资产）的折旧，能否列报为弃置义务准备的减少，或者与弃置义务准备的变动相抵销？

 

**解答**

 

不能。折旧应列报于损益中，因为资产（包括任何使用权（RoU）资产）的折旧并未促成存货或不动产、厂场和设备（PP&amp;E）等新资产的创造。[IAS 16 第48段]。

此外，IAS 1中并无要求或选项允许将折旧与弃置义务准备的任何减少相抵销。[IAS 1 第32段]。

用于修复的资产折旧通常会导致该准备的减少。该准备的变动应根据主体是按功能还是按性质编制利润表，恰当地列报于损益中。[IAS 1 第99段]。

<a id="s30-chap_04_navPoint_31"></a>
### <a id="s30-FAQ_4.49.1"></a>FAQ 4.49.1 – 比较信息的重述是否要求提供20X0年1月1日的期初资产负债表（即附加资产负债表）？

正文索引：[4.49](10.md#s28-Para_4.49)  

  

**问题**

某宠物食品制造商于20X0年12月收购了一家竞争对手，并在其20X0年12月31日年度财务报表中根据IFRS 3对该企业合并采用了暂估会计处理。该企业合并的会计处理于20X1年最终确定，暂估公允价值相应更新。因此，20X1年年度财务报表对20X0年比较信息进行了调整。该重述是否要求提供20X0年1月1日的期初资产负债表（即附加资产负债表）？

<a id="s30-chap_04_navPoint_32"></a>
### <a id="s30-FAQ_4.71.1"></a>FAQ 4.71.1 – 应如何选择资产负债表最相关的列报方式（流动/非流动分类法或流动性顺序法）？

 

准则索引：IAS 1 第60段  
正文索引：[4.71](10.md#s29-Para_4.71)  

  

**问题**

主体需要确定最相关的列报方式是流动/非流动分类资产负债表还是流动性顺序列报。由此产生的问题是：应如何选择资产负债表最相关的列报方式？

**解答**

大多数工业和零售主体都会列报流动/非流动分类资产负债表，因为其相当大比例的资产和负债将在相对较短的期间内变现或清偿。

房地产开发商采用流动/非流动分类资产负债表的可能性较小（因为其资产和负债可能在较长期间内，有时甚至跨越数年才变现或清偿），除非存在清晰可辨认的营业周期。

实务中通常将正常营业周期视为一年，但报告期末后一年的期间并非确定资产和负债流动/非流动状态的僵化分界点。在超过一年的正常营业周期内可收回的资产仍属于流动资产；在超过一年的正常营业周期内清偿的负债仍属于流动负债。

当经营性资产和负债在非常长的期间内收回或清偿时，按流动性顺序列报可能更为恰当。例如，尽管房地产开发主体可能存在清晰可辨认的营业周期，但在某些情况下，如果开发物业（作为存货持有）很可能要在报告期末后数年才能变现，则将开发物业和应收款项列报为流动资产可能并不合理。

即使资产和负债易于变现或能够立即清偿，流动/非流动分类资产负债表也可能并非最有用的列报形式。例如，投资公司通常持有此类资产和负债，但其变现或清偿的时间不仅取决于其流动性，还取决于投资经理对诸如市场价格预期变动等因素的判断。在此类情况下，区分流动项目与非流动项目并无太大意义。

 

<a id="s30-chap_04_navPoint_33"></a>
### <a id="s30-FAQ_4.75.1"></a>FAQ 4.75.1 – 应如何确定正常营业周期？

 

准则索引：IAS 1 第66段  
正文索引：[4.75](10.md#s29-Para_4.75)  

  

**问题1**

某主体生产飞机。从首次采购用于制造飞机的原材料到完成生产并交付的时间为10个月。该主体在交付后6个月收到飞机货款。

该主体应如何在分类资产负债表中列示其存货和应收账款？

**解答**

从首次采购货物到该货物变现为现金的时间为16个月（10个月 + 6个月）。主体年末持有的存货库龄介于0个月至10个月之间；货物交付后，还需6个月才能收到货款。所有存货均应分类为流动资产，即使部分存货不会在报告期后12个月内变现为现金，因为这些存货是在主体的正常营业周期内变现的。但主体应披露存货的预计收回日期。应收账款将在报告期后12个月内变现为现金，应计入流动资产。

**问题2**

如果生产时间为14个月，且从交付到收款的时间又增加至15个月，问题1的解答是否会有所不同？

**解答**

不会。存货和应收账款仍分类为流动资产。在此情况下，存货的平均库龄更长，但仍是在主体的正常营业周期内变现为现金。类似地，应收账款作为营业周期的一部分变现为现金，即使不会在年末后12个月内变现为现金，仍分类为流动资产。

主体应披露存货的预计收回日期以及应收账款的到期日。

 

<a id="s30-chap_04_navPoint_34"></a>
### <a id="s30-FAQ_4.75.2"></a>FAQ 4.75.2 – 见索即付的集团内部应收款项应如何分类？

 

准则索引：IAS 1 第66段  
正文索引：[4.75](10.md#s29-Para_4.75)  

  

**问题**

母公司向子公司提供一笔借款，年利率为8%，按年付息。该借款见索即付。该应收借款在母公司的资产负债表中应如何分类？

**解答**

见索即付特征可能主要是一种保护性条款或出于税务考虑的借款特征。双方可能预期并打算使该借款在可预见的未来保持未偿还状态。若果真如此，该工具实质上具有长期性质，母公司应将其分类为非流动资产。如果双方打算在报告期后12个月内偿还该借款，则母公司应将其分类为流动资产。而子公司应将该负债分类为流动负债，因为无论双方的意图如何，子公司都不拥有将还款推迟超过12个月的权利。

该工具的分类可能影响其初始确认和后续计量。这可能需要主体管理层运用判断，并可能需要在判断和估计项下作出披露。

 

<a id="s30-chap_04_navPoint_35"></a>
### <a id="s30-FAQ_4.78.1"></a>FAQ 4.78.1 – 主体能否将递延所得税列报为既非流动也非非流动？

 

准则索引：IAS 1 第64段  
正文索引：[4.78](10.md#s29-Para_4.78)  

  

递延所得税资产和负债不得分类为流动项目。我们认为，列报流动/非流动分类资产负债表的主体，不应将递延所得税资产和递延所得税负债列示为单独类别；也就是说，不应将递延所得税资产列示为既非流动也非非流动，对递延所得税负债亦应采取相同做法。

IAS 1指出混合列报在特定情况下可能是恰当的，但递延所得税资产和负债出现在大多数主体的财务报表中。我们认为，准则的本意并非使混合列报适用于所有主体或供所有主体采用。

 

<a id="s30-chap_04_navPoint_36"></a>
### <a id="s30-FAQ_4.80.1"></a>FAQ 4.80.1 – 附带控制权变更条款的借款在资产负债表中应如何分类？

 

准则索引：IAS 1 第69(d)段  
正文索引：[4.80](10.md#s29-Para_4.80)  

  

**问题**

部分借款协议包含控制权变更条款，规定若发生控制权变更事件，借款即到期应还。主体无法阻止控股股东将其股份出售给第三方，即使并不预期未来12个月内会发生控制权变更。附带控制权变更条款的借款在资产负债表中应如何分类？

**解答**

如果在报告期末尚未发生控制权变更事件，控制权变更条款不会导致借款被分类为流动负债。在这方面，控制权变更条款在实质上类似于借款限制性条款（契约）。IAS 1仅在资产负债表日存在实际违约时才要求分类为流动负债，而仅存在潜在违约时并不要求。如果在资产负债表日，交易对手方无权要求在该日后12个月内偿还，则该借款应分类为非流动负债。

 

**相关信息**

<a id="s30-chap_04_navPoint_37"></a>
### <a id="s30-FAQ_4.80.2"></a>FAQ 4.80.2 – 附带重大不利变化条款和主观加速到期条款的借款应如何分类？

 

准则索引：IAS 1 第69(d)段  
正文索引：[4.80](10.md#s29-Para_4.80)  

  

许多借款协议包含“重大不利变化条款”（MAC）或“主观加速到期条款”（SAC），据此贷款人可根据主观标准要求提前偿还借款。

应在资产负债表日对每一条款单独进行分析。如果根据MAC或SAC条款的适用，贷款人在资产负债表日有权要求在资产负债表日后12个月内偿还借款，则该借款应分类为流动负债。换言之，如果贷款人在资产负债表日拥有此项权利，则借款人不拥有无条件权利将借款的清偿推迟至资产负债表日后至少12个月。

另一方面，如果根据资产负债表日借款安排的条款和条件，贷款人在资产负债表日无权在至少12个月内要求偿还借款，则该借款应分类为非流动负债。

 

<a id="s30-chap_04_navPoint_38"></a>
### <a id="s30-FAQ_4.81.1"></a>FAQ 4.81.1 – 主体在资产负债表中应如何分类产品质量保证准备和环境准备？

 

准则索引：IAS 1 第70段  
正文索引：[4.81](10.md#s29-Para_4.81)  

  

- 产品质量保证准备——分类取决于质保条款。对产品性能提供12个月质保期的准备分类为流动负债。涵盖更长期间的质保准备，应结合正常营业周期的长度，拆分为流动部分和非流动部分。

- 环境负债准备——此类准备不太可能属于单一营业周期的一部分，应根据履行环境义务所需支出的可能时间分布，拆分为流动部分和非流动部分。

 

<a id="s30-chap_04_navPoint_39"></a>
### <a id="s30-FAQ_4.84.1"></a>FAQ 4.84.1 – 再融资协议如何影响银行债务的列报？

 

准则索引：IAS 1 第69(d)段  
正文索引：[4.84](10.md#s29-Para_4.84)  

  

**问题1**

某主体在一家银行的定期贷款授信额度下有一笔未偿还借款。该借款将于报告期末后6个月到期偿还。在报告期末之前，主体与该贷款人达成了一项为期三年的新授信协议，主体可将现有借款展期至该新额度内。主体打算在现有借款到期时将其展期至新贷款额度，并在新额度的整个存续期内维持未偿还余额。

该借款在主体的资产负债表中应如何列示？

**解答**

该借款应分类为非流动负债。尽管该借款将于报告期末后6个月内到期偿还，但主体有能力且打算将该义务展期至新贷款额度内。在新的三年期承诺授信额度到期之前，该债务无需清偿。

**问题2**

如果现有借款与新授信额度分属不同银行，解答是否会有所不同？

**解答**

会的。在此情况下，借款再融资将要求（在实质上和事实上）在借入新借款的同时清偿原借款。新借款不能被视为现有借款的展期。该借款在主体资产负债表中应分类为流动负债，但应披露相关情况及新授信额度的可用性。

类似地，如果借款采取商业票据的形式（期限通常为90至180天），则应分类为流动负债，因为备用授信额度很可能由另一家银行提供。

 

<a id="s30-chap_04_navPoint_40"></a>
### <a id="s30-FAQ_4.84.2"></a>FAQ 4.84.2 – 债务保理安排产生的负债的分类

 

准则索引：IAS 1 第73段  
 正文索引：[4.84](10.md#s29-Para_4.84)  

  

  
 

**示例**

主体可能签订保理安排，将其收取应收账款现金的权利转让给第三方（保理商）以换取预付现金。当主体继续确认已保理的应收账款时，从保理商收到的融资被记录为一项负债。需要考虑保理安排的条款，以确定该负债在资产负债表中应如何分类。

考虑在以下两种情形下，与应收账款相关的保理义务应列报为流动负债还是非流动负债：

情形1：

- 主体A签订了一项为期五年的应收账款保理协议，每期可出售合格应收账款。应收账款的信用期为30天。

- 合格应收账款是指合法有效且账龄不超过90天的应收账款。

- 由于主体仍承担几乎全部的风险和报酬，因此未终止确认该应收账款。

- 回款可与同一期间出售新应收账款的提款额相抵销。因此，每期的净现金流入和流出金额均较小。

- 90天内未收回的应收账款将被“返售”给主体，并纳入每期的净额结算中。

情形2：

- 主体B签订了一项为期五年的定期贷款协议，只要未偿还本金不超过合格应收账款，每期均可提取资金。

- 仅当违反限制性条款（契约）（即借款超过合格应收账款）时，主体才需要偿还差额部分。

**分析**

两种情形下各期间的借款余额和现金流量完全相同。在情形1中，主体无法避免清偿每期产生的任何负债。在情形2中，保理安排被构建为定期贷款。然而，主体并不拥有推迟向保理商付款的权利，因为在下一期间与银行之间的现金流量取决于客户的实际付款（及违约未付款）以及未来销售情况。如果主体不拥有无条件权利将负债的清偿推迟至报告期末后至少12个月，主体应将该负债分类为流动负债。如果主体没有自主决定权在现有借款额度（本例中即保理安排）下将负债再融资或展期至资产负债表日后至少12个月，则该负债应分类为流动负债。上述两种保理安排下产生的借款，在资产负债表中均应列报为流动负债。

 

<a id="s30-chap_04_navPoint_41"></a>
### <a id="s30-FAQ_4.86.1"></a>FAQ 4.86.1 – 当主体在报告期末后才报告违反借款限制性条款（契约）时，借款余额应如何分类？

 

准则索引：IAS 1 第74段  
正文索引：[4.86](10.md#s29-Para_4.86)  

  

**问题**

某主体在银行有一笔长期借款。借款条款要求按季度测试特定限制性条款（契约）比率。银行要求主体在限制性条款（契约）计量日后60天内提交合规证明。该主体的财年末为20X0年12月31日。

根据第三季度（即20X0年9月30日）计算的比率，该主体处于可接受的参数范围内。第四季度的限制性条款（契约）测试日为20X0年12月31日。财务业绩于20X1年1月最终确定。据此，该主体在20X0年12月31日违反了其限制性条款（契约）。

该主体将于20X1年3月2日提交显示违约的合规证明。该主体认为，在提交证明之日前并未发生违约，因为在未采取补救措施的情况下，银行最早也要到该日才会要求收回借款。年末该借款余额应如何分类？

**解答**

尽管直至报告期末后才要求报告违约，但该主体在20X0年12月31日实际上已经违反了其限制性条款（契约）。即使所报告的财务数据直至1月份才最终确定，情况也是如此。该主体不拥有无条件权利将借款的清偿推迟至报告期末后至少12个月；因此，该借款应分类为流动负债。

 

<a id="s30-chap_04_navPoint_42"></a>
### <a id="s30-FAQ_4.87.1"></a>FAQ 4.87.1 – 当借款协议包含宽限期时，借款余额应如何分类？

 

准则索引：IAS 1 第75段  
正文索引：[4.87](10.md#s29-Para_4.87)  

  

**问题**

某定期借款协议包含一项条款，要求借款人必须在20X0年12月31日前出售其某一境外分支机构。但协议同时规定，如果借款人未能于该日前出售该分支机构，允许其额外宽限两个月以完成出售。截至20X0年12月31日，借款人尚未找到买方。在其截至20X0年12月31日止期间的财务报表中，该借款应如何分类？

**解答**

主体应继续将该借款余额分类为非流动负债。在额外宽限期届满之前，借款人并未丧失推迟偿还该负债的无条件权利。在本例中，由于违约直至该更晚日期才会发生，主体在该更晚日期之前应继续将该借款列报为非流动负债。

主体应考虑潜在违约的影响，以及在财务报表中就此事项作出披露的恰当性。

 

<a id="s30-chap_04_navPoint_43"></a>
### <a id="s30-FAQ_4.87.2"></a>FAQ 4.87.2 – 当贷款人在特定报告日之前豁免限制性条款（契约）合规报告要求时，借款应如何列报？

 

准则索引：IAS 1 第75段  
正文索引：[4.87](10.md#s29-Para_4.87)  

  

 

**问题**

 

许多借款协议包含要求维持特定最低权益比率或其他比率的限制性条款（契约）。预计其相关比率将低于或接近要求的借款人，可能会在当期测试日之前请求贷款人豁免限制性条款（契约）报告要求。贷款人可能会同意在下一报告期照常测试限制性条款（契约）。在此情况下，主体应如何分类相关借款？

 

**解答**

 

鉴于该豁免在测试日之前已经生效，这实质上修改了借款协议，取消了特定报告日的限制性条款（契约）要求。即使按照原借款条款主体本会违约，但银行已放弃其因限制性条款（契约）要求而产生的可执行权利。无论下一报告期发生违约的可能性（或实际违约情况）如何，在报告期末，该借款均应分类为非流动负债。

 

这种情形不同于宽限期——在宽限期内，违反限制性条款（契约）的情况会被报告，且如果在宽限期结束时违约仍未纠正，贷款人仍可行使因违约触发的借款协议项下权利。在宽限期情形下，宽限期必须在资产负债表日后至少12个月才结束，借款才能列报为非流动负债。

 

请注意，IASB已发布关于负债流动或非流动分类的IAS 1修订，生效日期为2023年1月1日。如果提前采用该修订，上述分析可能得出不同的分类结果。

 

<a id="s30-chap_04_navPoint_44"></a>
### <a id="s30-FAQ_4.87.3"></a>FAQ 4.87.3 – 当贷款人在当期豁免了违反限制性条款（契约）的行为时，借款应如何分类？

 

准则索引：IAS 1 第75段  
正文索引：[4.87](10.md#s29-Para_4.87)  

  

 

**问题**

 

某主体有一笔剩余期限为五年的借款，限制性条款（契约）合规测试日为9月末和3月末。该主体在9月末违反了限制性条款（契约）。银行于10月接受了该违约并出具了豁免函，确认其依法放弃因该次违约产生的所有权利。在截至12月31日止年度的财务报表中，该主体应如何分类该借款？

 

**解答**

 

银行已在报告期末之前豁免了此次违反限制性条款（契约）的行为。因此，在12月末，银行并无可执行权利在未来12个月内要求偿还借款。3月末可能发生的新的违约并不会改变双方在12月末的合同权利。因此，该借款在12月末应分类为非流动负债。

 

IFRS 7下关于借款协议违约和违反条款的披露见[第47章第67段](78.md#s309-Para_47.67)及以下各段。

 

请注意，IASB已发布关于负债流动或非流动分类的IAS 1修订，生效日期为2023年1月1日。如果提前采用该修订，上述分析可能得出不同的分类结果。


 

<a id="s30-chap_04_navPoint_45"></a>
### <a id="s30-FAQ_4.102.2"></a>FAQ 4.102.2 – 单列项目的列报顺序是否为强制性要求？

 

准则索引：IAS 1 第86段  
正文索引：[4.102](10.md#s29-Para_4.102)  

  

单列项目通常按照IAS 1规定的顺序列报。仅当为解释业绩构成要素所必需时，主体才应调整损益单列项目的列报顺序。管理层应考虑相关项目的重要性、性质和功能。

例如，将财务费用作为税前利润之前的最后一个项目列报通常是可接受的且符合实务惯例，以便将融资活动与被融资的活动区分开来。

 

<a id="s30-chap_04_navPoint_46"></a>
### <a id="s30-FAQ_4.102.3"></a>FAQ 4.102.3 – 享有联营企业和合营企业利润的份额应如何列报？

 

准则索引：IAS 1 第82段  
正文索引：[4.102](10.md#s29-Para_4.102)  

  

享有联营企业利润的份额通常在财务费用之后列报。这体现了联营企业利润份额本质上源自投资活动，而非集团经营活动的组成部分。当联营企业（及合营企业）是开展集团经营和实施集团战略不可或缺的载体时，将财务费用列示在享有联营企业和合营企业利润份额之后可能更为恰当。

在此类情况下，增设“财务费用前利润”小计，或将享有联营企业和合营企业利润的份额计入营业利润（如披露）可能是恰当的。然而，将享有联营企业和合营企业的份额计入“收入”（进而计入“毛利”）则是不恰当的，因为联营企业和合营企业的份额并不代表构成“收入”的“经济利益的总流入”。

 

<a id="s30-chap_04_navPoint_47"></a>
### <a id="s30-FAQ_4.102.4"></a>FAQ 4.102.4 – 联营企业和合营企业利润份额相关的所得税应如何列报？

 

准则索引：IAS 1 第82段  
正文索引：[4.102](10.md#s29-Para_4.102)  

  

享有联营企业和合营企业的损益应以扣除其相关所得税后的净额列报。尽管在强制性损益单列项目清单中并未明确说明联营企业和合营企业损益的税务处理，但《IAS 1实施指引》所列示其他综合收益表中“享有联营企业利润的份额”单列项目的脚注指出：“这是指归属于联营企业所有者的联营企业利润份额，即扣除联营企业所得税和非控制性权益后的金额”。

### <a id="s30-FAQ_4.102.5"></a>FAQ 4.102.5 – 衍生工具及其他以公允价值计量且其变动计入当期损益（FVTPL）的金融工具的利息应如何列报？

 

准则索引：IAS 1 第82(a)段  
正文索引：[4.102](10.md#s29-Para_4.102)  
银行与资本市场

  

采用实际利率法计算的利息收入应在利润表表内作为收入的组成部分单独列报。

**问题1：**

如果主体的收入包含利息收益，以公允价值计量且其变动计入当期损益（FVTPL）的金融工具产生的利息，能否计入代表采用实际利率法计算的利息收入的单列项目中？

**解答**

不能。采用实际利率法计算的利息收入单独列报项目（可能标注为“利息收入”或“利息收益”或类似名称）仅包括：

- 按照IFRS 9以摊余成本计量及以公允价值计量且其变动计入其他综合收益计量的金融工具所产生的利息；以及

- 按照IFRS 9或IAS 39应用套期会计的相关合格套期关系所产生的利得和损失。

在IFRS 9下，实际利率法不适用于衍生工具及其他以FVTPL计量的工具。因此，此类工具产生的利息不应计入同一单列项目（按照IFRS 9或IAS 39作为套期核算的相关套期工具产生的利得和损失除外）。即使利息可以通过将实际利率应用于该工具的摊余成本来计算（例如，如果该工具满足SPPI要求，但其业务模式并非“以收取合同现金流量为目标”或“既以收取合同现金流量为目标又以出售为目标”），情况亦是如此。

**问题2：**

除要求的以摊余成本或FVOCI计量工具的利息单列项目外，主体能否选择在利润表表内增设一个或多个单列项目，列报以FVTPL计量工具的“利息”？

**解答**

可以。IAS 1第85段允许主体在相关列报与理解主体财务业绩相关的情况下，在利润表中列报附加单列项目。这与IFRS 7第B5段和第BC34段一致，该等段落设想主体可以将以FVTPL计量的金融资产和金融负债的利息与其他公允价值变动分开列报。

<a id="s30-chap_04_navPoint_49"></a>
### <a id="s30-FAQ_4.110.1"></a>FAQ 4.110.1 – 主体能否将部分费用按功能分类列报，而将其他费用按性质分类列报？

 

准则索引：IAS 1 第99段  
正文索引：[4.110](10.md#s29-Para_4.110)  

  

主体通常不应混合使用“按功能分类”和“按性质分类”两种费用分类方法，例如将存货减记、雇员辞退福利和减值费用等部分费用从其所属的功能分类中剔除。如果同时满足下列全部条件，混合使用按功能与按性质分类并在利润表中增设附加单列项目可能是可接受的：

- 利润表的列报保持中立（无偏见）。[概念框架 第2.15段]。存在偏见的列报（例如对特定单列项目给予不当突出）是不可接受的。

- 在附注中披露按性质分类的费用明细。

- 该列报方式得到一贯应用，并在会计政策中予以说明。

混合列报不得产生低估销售成本和高估毛利的效果。例如，在折旧与已售商品成本明显挂钩的企业（如制造企业）中，折旧通常应计入销售成本。在折旧与已售商品成本并非密切相关的企业中，将折旧排除在销售成本之外可能是恰当的。若如此处理，销售成本应明确标注为不含折旧，且不应报告毛利小计。管理层在确定最恰当的列报方式时，应考虑当地监管要求。

一种或多种性质的费用的集合并不必然构成企业某一功能的费用。例如，重组成本合计（如裁员补偿、存货减记）和占用成本合计（折旧、财产保险）通常不应在按功能分类分析中作为单行项目列示，因为重组和占用均不属于企业的一项功能。采用按功能分类分析的主体，披露的是为实现其商业目标而执行特定活动（如管理或分销）的综合成本。

 

<a id="s30-chap_04_navPoint_50"></a>
### <a id="s30-FAQ_4.110.2"></a>FAQ 4.110.2 – 销售成本、分销费用、管理费用和财务费用分别包含哪些类型的费用？

 

准则索引：IAS 1 第99段  
正文索引：[4.110](10.md#s29-Para_4.110)  

  

IAS 1并未提供具体指引以确定“销售成本”应包含哪些内容。然而，IAS 2第38段规定，“销售成本”应包括先前计入已售存货计量的成本、未分摊的制造费用以及非正常消耗的存货生产成本。视主体具体情况而定，其他金额（如分销费用）也可能计入“销售成本”。“销售成本”应包括与履行IFRS 15下履约义务直接相关的成本。

应计入“销售成本”的费用取决于成本的性质及所履行的履约义务。销售成本可能包括：

- 期初（减期末）存货。

- 未分摊的制造费用以及非正常消耗的存货生产成本。

- 直接材料。

- 其他外部费用（例如生产过程中使用的厂场和机器租赁费或临时工成本）。

- 直接人工。

- 所有直接制造费用，包括不动产、厂场和设备的折旧与减值，以及可合理分摊至生产功能的间接制造费用。

- 先前资本化为无形资产的开发支出的摊销。

- 就“销售成本”支出收到的现金折扣（这不属于抵销，而是项目采购价格的实际减少）。

- 存货减记。

- 当交付商品构成IFRS 15下的单独履约义务时的运输费用。

- 与按照IFRS 15向客户提供广告服务相关的广告费用。

分销费用通常作广义理解，往往包括销售和市场营销费用。可能包含的项目有：

- 销售、市场营销和分销部门的薪酬成本。

- 非为履行IFRS 15下履约义务而发生的广告费用。

- 销售人员的差旅费和业务招待费。

- 产成品仓储费用。

- 分销产成品产生的运输费用。

- 维护销售网点的所有费用。

- 应付代理商佣金。

管理费用通常包括：

- 一般管理费用。

- 维护行政办公楼的所有费用。

- 专业服务费。

如果主体发生了重大的营业费用，且认为不属于“销售成本”、“分销费用”和“管理费用”中的任何一项，主体可以增设附加项目。主体应逐年一贯地、以能提供最相关信息的方式分析其营业费用。如果主体在任何单列项目中计入了某项费用的估计金额，且在后续年度证明该估计超过实际费用，则该“超额费用”的转回应在原费用估计计入的同一单列项目中确认。IAS 2针对存货减记的转回明确规定了此项处理。[IAS 2 第34段]。

财务费用通常包括：

- 银行透支、流动和非流动借款以及租赁负债的利息支出。

- 预计负债折现的转回（利息摊销）。

- 分类为债务的优先股的股利。

- 作为负债的债务工具折价和溢价的摊销。

- 外币借款产生的外币汇兑损失。

- 部分衍生金融工具的公允价值变动。

- 当利息成分可单独辨认时，应交税款的利息。

### <a id="s30-FAQ_4.111.3"></a>FAQ 4.111.3 – 资本化费用应如何处理？

 

准则索引：IAS 1 第99段  
正文索引：[4.111](10.md#s29-Para_4.111)  

  

随附IAS 1的实施指引提供了按性质分类费用的利润表示例。该示例包含“主体自行完成并资本化的工作”作为一个单列项目。当主体采用按性质分类分析费用并在扣除任何资本化金额之前按“总额”基础列报其营业费用时，这是必要的。例如，在此情况下，“耗用的原材料和低值易耗品”单列项目将是所有耗用原材料的总额，即使这些原材料用于建造不动产、厂场和设备（PPE）。某主体耗用C1,000的原材料，其中C100予以资本化，则将在单独的单列项目中分别列示C1,000为“耗用的原材料和低值易耗品”和C100为“主体自行完成并资本化的工作”。（资本化的原材料最终将影响PPE的折旧费用和/或处置损益。）

实施指引中按功能分类分析费用的示例并未包含“主体自行完成并资本化的工作”单列项目。当营业费用按功能列报时，金额应以扣除任何资本化费用后的“净额”列示，以反映归属于特定功能的金额。在上例中，C900将计入销售成本（或耗用未资本化原材料的任何其他功能），而C100则不会在综合收益表中作为单行项目列报。按功能分类分析列示的是分配至每一功能的成本；它不列示各类费用的“总额”减去该等费用分配额。此方法延伸适用于（例如）“分配”至PPE或资本化为开发成本的费用的列报。

我们认为，当采用费用性质法且存在财务费用资本化时，利润表最恰当的做法是以扣除资本化金额后的净额列报财务费用。如果财务费用总额及资本化金额未在报表表内单独列报，则应在财务报表附注中予以披露。如果采用费用性质法的主体按总额列报财务费用，同时将资本化的财务费用纳入“主体自行完成并资本化的工作”汇总总额中，与按净额列报财务费用的主体相比，将会提高从该主体报表中列报或推导出的营业利润指标。但在这一方面，实务中存在一定差异。

 

<a id="s30-chap_04_navPoint_54"></a>
### <a id="s30-FAQ_4.112.1"></a>FAQ 4.112.1 – 哪些项目可分类为其他收益（费用）？

 

准则索引：IAS 1 第101段  
正文索引：[4.112](10.md#s29-Para_4.112)  

  

主体可将以下项目酌情计入其他收益或其他费用：

- 投资利息收益。

- 股利收益。

- 以公允价值计量且其变动计入当期损益的金融资产的公允价值利得和损失。

- 交易性衍生工具的利得和损失。

 

<a id="s30-chap_04_navPoint_55"></a>
### <a id="s30-FAQ_4.113.1"></a>FAQ 4.113.1 – 财务收益应如何列报？

 

准则索引：IAS 1 第82段  
正文索引：[4.113](10.md#s29-Para_4.113)  

  

当赚取利息收益属于主体日常活动的一部分而非附带利益时，利息收益应计入“收入”。例如，通过提供延期信用安排赚取利息收益的零售商应将该利息收益计入“收入”。拥有融资业务的多元化企业集团也应将其财务收益计入“收入”。

主体可能认为，未计入“收入”的财务收益最恰当的做法是计入“其他营业收益”，或作为计算营业利润（如披露）的单独单列项目。主体可能认为，将资金管理活动产生的财务收益（例如短期投资闲置资金的收益）列报在营业利润之外、而将其他类型的财务收益作为营业项目是恰当的。所采用的列报政策应一贯应用，如属重要则应予以披露。

财务收益通常包括以下项目：

- 现金及现金等价物的利息收益。[IFRS 7 第20段]。

- 金融资产折现的转回（利息摊销）。

 

<a id="s30-chap_04_navPoint_56"></a>
### <a id="s30-FAQ_4.113.2"></a>FAQ 4.113.2 – 负利息应如何列报？

 

准则索引：IAS 1 第82段  
正文索引：[4.113](10.md#s29-Para_4.113)  

  

IAS 1要求主体列报收入，并单独列报采用实际利率法计算的利息收入。[IAS 1 第82段]。此外，IFRS 15规定主体应在综合收益表中将融资的影响（利息收入或利息费用）与客户合同收入分开列报。[IFRS 15 第65段]。

主体可将金融资产产生的负实际利息在利润表表内作为单独单列项目列报在“净财务费用”（包括财务收益、财务费用和负利息）内，或作为另一费用类别列报，也可以计入财务费用。

金融负债产生的负实际利息应列报在利息收益或其他收益内。负利息收益或费用可在利润表表内单独列报，或在财务报表附注中单独披露。管理层应一贯应用所选定的列报方式。

 

<a id="s30-chap_04_navPoint_57"></a>
### <a id="s30-FAQ_4.114.1"></a>FAQ 4.114.1 – 外币汇兑利得和损失应如何处理？

 

准则索引：IAS 1 第82段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

主体通常将与借款以及现金及现金等价物相关的外币汇兑利得和损失分类为财务收益/财务费用的一部分。其他外币汇兑利得和损失通常分类为“其他营业利得/损失”、“其他营业收益和费用”或类似单列项目。

主体的会计政策也可以是将所有外币汇兑利得和损失均列报在“其他营业利得/损失”（或类似单列项目）中，或者均列报在“财务收益”/“财务费用”中。

外币汇兑利得和损失（包括应收账款和未开票收入产生的汇兑损益）不应作为收入的一部分列报。

为对境外子公司净投资进行套期而借入的外币借款产生的汇兑利得或损失，如果满足套期会计条件，通常在合并财务报表的其他综合收益中确认。当集团处置该净投资时，这些利得和损失从权益重分类至损益。作为处置或部分处置的一部分重分类至损益的汇兑差额，通常列报在列示处置利得或损失的同一单列项目中——即“其他收益”或“其他费用”。

 

<a id="s30-chap_04_navPoint_58"></a>
### <a id="s30-FAQ_4.114.2"></a>FAQ 4.114.2 – 回购自身债务产生的利得或损失应如何处理？

 

准则索引：IAS 1 第15段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

主体按反映债务市场价值的金额回购自身债务时，将终止确认债务的账面金额与所支付对价之间的差额在利润表中确认为利得或损失。IFRS未规定该利得或损失应在利润表的何处列报。IAS 1要求如实反映交易的影响。对于非金融机构的主体而言，债务回购交易具有融资活动的性质（而非经营活动），因为它改变了主体的借款。因此，终止确认债务产生的利得或损失应分别记入利润表的财务收益或财务费用项下。

 

<a id="s30-chap_04_navPoint_59"></a>
### <a id="s30-FAQ_4.114.3"></a>FAQ 4.114.3 – 衍生工具的利得和损失能否计入“收入”？

 

准则索引：IAS 1 第99段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

仅当用于对收入进行套期的衍生工具处于经指定且高度有效的套期会计关系中时，其利得和损失方可计入收入。

收入现金流量套期有效部分产生的衍生工具利得和损失在其他综合收益中确认，并在确认相关收入的同时重分类至损益。这些重分类的利得和损失可计入客户合同收入。

衍生工具公允价值变动中的无效部分不应计入收入。无效部分立即计入损益，这可能发生在商品或劳务交付且收入确认条件满足之前。套期无效部分的利得或损失通常计入“其他营业收益/成本”。

用于对应收账款进行套期的衍生工具利得或损失不应计入收入，因为应收账款初始确认后的变动通常与利率或汇率风险敞口相关，而非与原始收入交易相关。此类利得和损失通常计入“其他营业收益/成本”。

IFRS 9引入了“套期成本”概念。如果主体采用套期成本模型，可将衍生工具远期点、货币基差和时间价值的公允价值变动计入其他综合收益，并在被套期项目影响损益时重分类至损益。当这些衍生工具用于对收入进行套期时，重分类调整可计入收入。其他可接受的替代处理包括列报于“其他营业收益/成本”或“财务收益/费用”。

IFRS 15将“收入”（利润表的强制性单列项目）定义为“在主体日常活动过程中产生的收益”。IFRS 15还要求主体单独披露从客户合同中确认的收入以及其他来源的收入。主体可在利润表中或在附注中披露这些项目。不属于有效现金流量套期的衍生工具利得和损失并非源自客户合同，因此不应计入“客户合同收入”。

我们认为上述两种观点均属可接受，主体就交付日是否确认收入及相关销售成本拥有会计政策选择权。我们还认为所选择的会计政策应一贯应用。此外，我们预期主体应在附注中披露其所采用的方法。

该议程决定还涉及主体采购商品并因而就该非金融项目确认存货的情形。适用相同的原则：对于不符合自用范围例外并按照IFRS 9以FVTPL计量的衍生工具，既不允许也不要求作会计分录冲回其累计公允价值利得或损失。

### <a id="s30-FAQ_4.114.5"></a>FAQ 4.114.5 – 其他衍生工具的利得和损失应如何列报？

 

准则索引：IAS 1 第99段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

处于经指定套期会计关系中的衍生工具利得和损失，通常计入相关被套期项目所在的同一单列项目。关于收入套期，参见[FAQ 4.114.3](10.md#s30-FAQ_4.114.3)。

主体可能持有部分未处于经指定套期会计关系中、但仍被管理层用于缓解金融风险的衍生工具（通常称为“经济套期”）。IFRS不承认“经济套期”。在IFRS 9下，套期会计仅适用于满足套期会计条件的套期（IFRS 9第6.4.1段）；所有其他衍生工具在会计上均不属于套期，即使管理层将其视为套期。

交易性衍生工具以及不属于经指定套期会计关系的衍生工具的结果，通常最恰当的做法是列示在“其他营业利得和损失”或“其他营业收益和费用”中，如果金额重大则作为单独单列项目列示（例如衍生工具利得或损失）。

然而，主体也可以选择将每类主要衍生工具分别分类。例如，主体可以制定一项会计政策，将所有利率衍生工具（无论是否处于套期会计关系中）均计入财务费用。商品衍生工具的利得和损失不应分类为财务费用的一部分，因为它们与融资活动无关。

此外，主体还可能在不同功能中使用衍生工具；例如，部分衍生工具可能用于交易，目标在于最大化交易收益，而其他衍生工具则用于风险管理活动，目标在于降低主体的现金流量或公允价值风险敞口。主体也可以选择根据其不同功能分别列报此类衍生工具（例如，将交易性衍生工具与风险管理衍生工具分行列报）。这通常仅在此类功能界限清晰且每项功能均独立管理的情况下才是恰当的。

 

<a id="s30-chap_04_navPoint_62"></a>
### <a id="s30-FAQ_4.114.6"></a>FAQ 4.114.6 – 现金流量套期关系中的套期无效部分在利润表中应如何列报？

 

准则索引：IAS 1 第85段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

 

**问题**

 

IFRS 7第24C(a)(i)、(ii)段和(b)(ii)、(iii)段要求主体在附注中单独披露套期无效部分的金额，以及综合收益表中包含已确认套期无效部分的单列项目。

 

然而，IFRS中并无具体指引说明套期无效部分应在综合收益表的哪一单列项目中列报。现金流量套期关系中的套期无效部分在利润表中应如何列报？

 

**解答**

 

主体应运用判断，就套期无效部分的列报制定恰当的会计政策。我们认为，主体关于套期无效部分列报的会计政策，应与主体关于交易性衍生工具以及不属于经指定套期会计关系的衍生工具结果的列报政策保持一致。这可能意味着套期无效部分、失效套期或经济套期的结果计入相关被套期项目影响所在的同一单列项目。参见[FAQ 4.114.5](10.md#s30-FAQ_4.114.5)。

 

例如，就某航空公司对燃油成本进行的套期而言，如果该套期符合套期会计条件且有效性为85%，则利得或损失中15%的无效部分计入损益，并可计入销售成本。如果该套期有效性降低（且不再符合套期会计条件），则该衍生工具利得和损失的列报应与主体对其他非套期衍生工具的政策保持一致。

 

然而，将无效部分计入IFRS 15下的“客户合同收入”是不恰当的（进一步指引参见[FAQ 4.114.3](10.md#s30-FAQ_4.114.3)），即使套期工具的有效部分在重分类至损益时最终调整了客户合同收入。类似地，对IFRS 9下“利息收入”变动性进行套期的衍生工具的无效部分，不应计入利息收入（进一步指引参见FAQ 4.102.5）。


 

<a id="s30-chap_04_navPoint_63"></a>
### <a id="s30-FAQ_4.114.7"></a>FAQ 4.114.7 – 对于以现金结算的非利率相关衍生工具，已实现利得和损失能否与未实现利得和损失分开列报？

 

准则索引：IAS 1 第85段  
正文索引：[4.114](10.md#s29-Para_4.114)  

  

 

**问题**

 

主体可能持有部分未处于经指定套期会计关系中、但仍被管理层用于缓解金融风险的衍生工具（通常称为“经济套期”）。详情参见[FAQ 4.114.5](10.md#s30-FAQ_4.114.5)。

 

对于经济套期中以现金（即金融方式）结算的非利率相关衍生工具，将已实现利得和损失与未实现利得和损失拆分并在利润表内不同单列项目中列报是否可接受？

 

**解答**

 

不可接受。对于未指定在套期关系中且以现金（即金融方式）结算的非利率相关衍生工具，衍生工具利得和损失的全部变动应在利润表内的同一单列项目中列报。

 

未指定在套期关系中的衍生工具按照IFRS 9以公允价值计量且其变动计入当期损益。衍生工具的现金支付或收取是对衍生金融资产或负债公允价值的结算。为了将衍生工具公允价值的变动拆分为已实现和未实现利得或损失，未实现金额需作为倒挤差额计算。例如，考虑一家以公历年为财年的主体，其持有一份于20X1年1月1日到期的远期合同，在20X0年12月31日存在CU1,000的损失。假定该衍生工具的价值在12月31日至1月1日期间未发生变化，如果主体将衍生工具利得和损失拆分为已实现和未实现利得和损失，则其在截至20X0年12月31日止期间将列示CU1,000的未实现损失，然后在20X1年就必须列示CU1,000的已实现损失和CU1,000的未实现利得，才能使该衍生工具在20X1年的公允价值变动等于CU0。

 

尽管IAS 1第85段允许对损益内的单列项目进行细分，但在20X1年并不存在（按照IFRS确定的）可供拆分的“未实现”利得，因为该衍生工具仅给主体带来了损失。因此，在利润表表内进行这种拆分通常是不恰当的。然而，主体在采用间接法调节净利润与经营活动现金流量时，可以在附注中提供类似信息。

 

本FAQ针对以现金结算的合同。以实物交割的衍生工具适用不同的考虑因素，详见[FAQ 4.114.4 – 主体应如何列报按照IFRS 9（或IAS 39）作为衍生金融工具核算的商品合同的公允价值变动和销售价款？](10.md#s30-FAQ_4.114.4)。

 

利率衍生工具也适用不同的考虑因素，详见[FAQ 4.102.5 – 衍生工具及其他以公允价值计量且其变动计入当期损益（FVTPL）的金融工具的利息应如何列报？](10.md#s30-FAQ_4.102.5)。

### <a id="s30-FAQ_4.122.1"></a>FAQ 4.122.1 – 弥补收入损失的政府补助能否列报为客户合同收入或租赁收入？

 

准则索引：IAS 1 第97段  
正文索引：[4.122](10.md#s29-Para_4.122)  

  

**问题**

主体A是一家房地产主体。主体A在日常活动中收取租金收益并将其列报为收入。由于政府出台新法规，主体A的客户群萎缩且收入低于预期。主体A收到C3百万的政府补助，作为对此项租金收入损失的补偿。该笔款项的收取是无条件的，因此主体A有合理保证能够保留该笔补助。假定主体在当年确认部分该补助，该项补偿在主体A的利润表中应如何列报？

**解答**

政府补助应当在主体将补助拟补偿的相关成本确认为费用的各期间内，按系统基础在利润表中确认。与收益相关的政府补助有时在损益表中列报为贷方项目（单独列报或在“其他收益”等一般标题下列报）；或者，也可以在报告相关费用时从中扣除。

[IAS 20 第29段]。

政府补助既不符合客户合同收入的定义（IFRS 15第6段），也不符合租赁收益的定义（IFRS 16第81段）。IAS 20中的净额列报选项系针对从相关费用中扣除补助收益的情形而制定，从而列示主体承担的净费用。将此方法类推适用于旨在弥补收入损失的补助是不可接受的，因为这会导致补助收益被不恰当地分类（例如计入客户合同收入或租赁收益中）。

然而，主体将用于弥补收入损失的补助列报在“其他收益”、“其他收入”或“补助收入”中是可接受的。我们认为以下列报备选方案可能是恰当的：

- 主体可在采用总额法时，将这些补助作为营业利润内收入之外的“其他收益”列报，与其他政府补助收益的列报位置一致。

- 主体也可以认为该补助符合更广泛的收入定义，从而将其列报在更广泛的收入类别中。这是因为IFRS 15将收入定义为在主体日常活动过程中产生的收益。因此，如果主体系因在正常经营过程中提供商品/劳务而发生收入损失进而有权获得该补助，则将该补助列报于总收入中可能是可接受的。如果该补助在利润表中作为总收入的一部分列报，则应与IFRS 15范围内的客户合同收入和IFRS 16范围内的租赁收入分开列报。这种单独列报可通过细分总收入的不同组成部分来实现。

[IAS 20 第29段]。

无论采用哪种方式，主体均应就所遵循的列报方法制定清晰的会计政策。

### <a id="s30-FAQ_4.122.2"></a>FAQ 4.122.2 – 主体应如何列报与处置业务相关的财务担保合同账面价值的变动？

 

准则索引：IAS 1 第97段  
正文索引：[4.122](10.md#s29-Para_4.122)  

  

**问题**

某制造主体于20X1年12月31日（会计期间最后一天）出售了一项业务。被出售的业务租赁了若干房产。根据租赁条款，出租人在租赁的特定期间内就未付租金对该主体享有追索权。

该主体将该追索安排确认为一项财务担保，并在处置日按公允价值C100,000记录该负债，使利润表中列示的处置利得从C900,000减少至C800,000。该金融负债于20X2年12月31日重新计量，在该日资产负债表中列示为C80,000。

该业务的买方在特定期间（现已届满）的最后一期租赁付款中违约；因此，在20X3年，该主体被要求支付C85,000。主体应在利润表中如何列报财务担保账面价值的变动及违约产生的损失？

**解答**

该财务担保是处置交易的内在组成部分，因此对其账面价值的后续调整应计入早年列示处置利得的同一报表行项目，无论其属于持续经营还是终止经营的一部分。

在20X2年，主体应确认C20,000（C100,000 − C80,000）作为处置利得。在20X3年，主体应确认C5,000（C85,000 − C80,000）作为处置损失。因此，三年内处置该业务的总体利得/损失为C815,000，即C900,000的“担保前利得”减去根据担保支付的C85,000。这恰当地反映了该处置交易的整体盈利能力。

### <a id="s30-FAQ_4.123.1"></a>FAQ 4.123.1 – 处置子公司的利得在合并财务报表中应如何列报？

 

准则索引：IAS 1 第98段  
正文索引：[4.123](10.md#s29-Para_4.123)  

  

**问题**

主体A拥有一家境外子公司B，并于当期将其出售。处置子公司B的利得占集团当年利润的80%。该处置利得在主体A的合并财务报表中应如何处理？

**解答**

在其合并财务报表中，主体A应在利润表表内单独列报处置该子公司的利得。由于所涉及金额的性质和规模，必须单独列报。其在报表中的列报位置取决于该子公司是否构成IFRS 5下的终止经营。

**持续经营**

不构成终止经营的子公司处置利得或损失，如果披露营业利润，通常在营业利润内列示；如果不披露营业利润，则在财务费用之前的单列项目中列示（如下所示）。但是，如果明确表明该处置属于一次性交易（即预计主体未来不会发生类似交易，且历史上也没有类似交易），则处置利得或损失可在营业利润之后、财务费用之前列示。

**终止经营**

构成终止经营的子公司处置利得或损失，应计入由(i)终止经营的税后损益和(ii)对构成终止经营的资产或处置组按公允价值减去出售费用后的净额计量或处置时确认的税后利得或损失之和所构成的单一金额中。

要求对该单一金额作进一步分析，但可在报表表内或附注中提供。选择在利润表表内作出披露的主体，应将其列报于报表的单独部分，不得与持续经营的业绩相混淆。特别地，不允许（例如）将总收入列示为持续经营收入与终止经营收入之和。“收入”仅指持续经营产生的收入。IAS 1规定了终止经营在利润表中的列报位置；不允许主体将该披露的组成部分提升至报表中更靠前的位置。

### <a id="s30-EX4.124.1"></a>EX 4.124.1 – 与雇员福利费用相关的实务问题

 

准则索引：IAS 1 第104段  
 正文索引：[4.124](10.md#s29-Para_4.124)  

  

  
 当雇员显然为某一主体工作、但其服务合同却与另一主体（例如控股主体）签订时，可能会产生实务问题。如果该另一主体向这些雇员支付工资和薪金，情况会进一步复杂化。主体仅披露其正式雇佣人员的成本可能会产生误导。在此类情况下，主体应披露补充信息，以使其财务报表实现公允列报。

以下示例涉及雇员福利费用和雇员人数的披露。IFRS下并无披露雇员人数的要求，但主体可以自愿披露或为满足当地法律要求而披露。

**示例1 – 与另一集团主体签订服务合同**

雇员全职为某子公司工作并由该子公司支付薪酬，但其服务合同系与母公司签订。

如果子公司财务报表中未披露雇员福利费用，将会产生误导。子公司向这些雇员支付的工资和薪金应在其财务报表中作为“雇员福利费用”予以披露。子公司财务报表附注应说明这些员工与另一集团主体签订了服务合同，同时还应说明为何在财务报表中披露其薪酬及人数（如提供）。

母公司的合并财务报表将列示整个集团的雇员福利费用。母公司的单独财务报表应说明，部分与本主体签订服务合同的雇员完全为某子公司工作并由该子公司支付薪酬。应披露雇员福利费用，且主体可披露雇员人数。

服务合同也可能是与同级子公司签订的。该同级子公司应在其财务报表附注中披露，部分与本主体签订服务合同的雇员完全为另一同级子公司工作并由该另一同级子公司支付薪酬。应披露雇员福利费用，且主体可披露雇员人数。

母公司（或同级子公司）可能按“费用性质法”编制综合收益表。报表表内列示的雇员福利费用将是该母公司（或同级子公司）为其雇员承担的成本。在上述情形下，该金额将小于支付给与其签订服务合同人员的金额，这一点应在财务报表附注中予以说明。

**示例2 – 子公司承担管理费**

雇员全职为子公司工作，但并非由子公司支付薪酬，也未与子公司签订服务合同。子公司向支付雇员薪酬的主体承担有关雇员服务的管理费，并且能够确定管理费中与雇员福利费用相关的比例。

如果子公司财务报表未披露任何关于雇员成本的信息，可能会产生误导。将管理费中与雇员福利费用相关的比例在子公司财务报表中作为雇员福利费用予以披露可能是恰当的。财务报表附注应说明这些雇员未与本主体签订服务合同，同时还应说明为何在财务报表中披露其成本及人数（如提供）。

母公司的合并财务报表将列示整个集团的雇员福利费用。服务合同可能是与母公司签订且雇员由母公司支付薪酬。母公司的单独财务报表应披露其全部雇员的雇员福利费用，并可披露雇员人数。母公司的单独财务报表还应披露向子公司转嫁的雇员福利费用的详情，并可披露为该子公司工作的雇员人数。

雇员的服务合同也可能是与同级子公司签订且由同级子公司支付薪酬。该同级子公司的财务报表应披露其全部雇员的雇员福利费用，并可披露雇员人数。子公司财务报表还应披露转嫁给同级子公司的雇员成本详情，并可披露为该同级子公司工作的雇员人数。

**示例3 – 子公司承担非特定管理费**

事实与示例2相同，但子公司无法拆分管理费以确定其中与雇员福利费用相关的部分。

母公司的合并财务报表将列示整个集团的雇员福利费用。如果母公司支付雇员薪酬，其单独财务报表应将雇员薪酬披露于其雇员福利费用中。附注可披露涉及的雇员人数，并应说明这些雇员为某子公司工作，且本主体将其雇佣成本作为管理费的一部分转嫁给该子公司。

子公司财务报表附注应说明雇员的服务合同系与母公司签订，且其薪酬已计入母公司的财务报表。附注还应说明母公司收取的管理费包含这些雇员的成本，但无法单独确定管理费中与雇员福利费用相关的部分。

雇员的服务合同也可能是与同级子公司签订且由该同级子公司支付薪酬。该同级子公司的财务报表应将雇员薪酬披露于其雇员福利费用中。附注可披露涉及的雇员人数，并应说明这些雇员为另一同级子公司工作，且本主体将其雇佣成本作为管理费的一部分转嫁给该同级子公司。

**示例4 – 子公司不承担管理费**

事实与示例2相同，但未就雇员的服务收取管理费。这种情况常发生于员工全职或兼职为小型公司工作的情形。

关联方交易是指报告主体与关联方之间资源、劳务或义务的转移，而不论是否收取价款。[IAS 24 第9段]。

尽管未收取管理费，子公司仍获得了由另一集团主体（即关联方）付费的雇员服务所带来的利益。子公司财务报表附注应说明，本主体未就为其工作的雇员所提供的服务被收取费用。附注还应在恰当情况下指明，这些雇员的费用已计入母公司的合并财务报表；如果能够获取相关信息，披露该项费用的金额可能是恰当的。

母公司可能雇佣并支付这些雇员的薪酬。其单独财务报表应将这些雇员的成本计入其雇员福利费用。财务报表附注应在恰当情况下说明，这些雇员为某子公司工作，但未就其服务向该子公司收取管理费。

同级子公司也可能雇佣并支付这些雇员的薪酬。其财务报表应将这些雇员的成本计入其雇员福利费用。财务报表附注应在恰当情况下说明，这些雇员为另一同级子公司工作，但未就其服务向该主体收取管理费。涉及的雇员人数可酌情在母公司单独财务报表或同级子公司财务报表中予以披露。

### <a id="s30-FAQ_4.124.2"></a>FAQ 4.124.2 – 主体应如何披露未签订雇佣合同的董事和关键管理人员的成本？

 

准则索引：IAS 1 第104段  
正文索引：[4.124](10.md#s29-Para_4.124)  

  

董事和其他关键管理人员（按IAS 24的定义）可能未与主体签订雇佣合同。例如，主体聘请一名非执行董事，并向其“服务主体”支付服务费，而该董事同时向多家公司提供类似服务。

雇员福利在IAS 19中定义；就IAS 19而言，雇员包括董事和其他管理人员。[IAS 19 第7段]。

这可以解释为要求将聘请董事和关键管理人员的所有成本（无论是否签订雇佣合同）均计入雇员福利费用。最重要的考虑因素是披露的透明度及其年度间的一致性。

IFRS要求就董事和关键管理人员作出额外披露。无论是否在雇员福利费用内披露，支付给董事和关键管理人员的款项均应在附注中予以披露。

### <a id="s30-FAQ_4.140.1"></a>FAQ 4.140.1 – 哪些与所有者的交易应在所有者权益变动表中列报？

 

准则索引：IAS 1 第106段  
正文索引：[4.140](10.md#s29-Para_4.140)  

  

**问题**

哪些与所有者的交易应在所有者权益变动表中列报？

**解答**

主体应在所有者权益变动表中列报下列与所有者（以其所有者身份）进行的交易：

- 股份发行与赎回。

- 库存股的购回与出售。

- 所发行可转换债券的权益成分。

- 分类为权益的工具的股利。

- 反映与以权益结算的股份支付安排相关的权益工具发行的贷方分录。

- 不导致控制权变更的与非控制性权益之间的交易。

### <a id="s30-FAQ_4.140.2"></a>FAQ 4.140.2 – 享有合营企业和联营企业所有者权益变动的份额应如何列报？

**问题**

享有合营企业和联营企业所有者权益变动的份额应如何列报？

### <a id="s30-FAQ_4.157.1"></a>FAQ 4.157.1 – 哪些领域可能需要就估计不确定性作出披露？

 

准则索引：IAS 1 第125段  
正文索引：[4.157](10.md#s29-Para_4.157)  

  

**问题**

哪些领域可能需要就估计不确定性作出披露？

**解答**

IAS 1第125段要求披露的部分假设，也是其他准则所要求披露的。可能需要就估计不确定性作出披露的领域包括以下各项：

- 不动产、厂场和设备的可收回金额。

- 重估不动产、厂场和设备项目的公允价值。

- 技术过时对存货的影响。

- 估计以公允价值计量的金融资产和金融负债公允价值时所应用的重大假设。

- 影响各类预计负债的关于未来事项的主要假设。

- 用于确定设定受益义务现值的重大精算假设。

- 应收账款的可收回金额。

- 递延所得税资产的可收回性。

 

<a id="s30-chap_04_navPoint_74"></a>
### <a id="s30-FAQ_4.157.2"></a>FAQ 4.157.2 – 关键会计估计可能需要披露哪类信息？

 

准则索引：IAS 1 第125段  
正文索引：[4.27](10.md#s28-Para_4.27)   

  

 

IAS 1第125段要求主体披露其对未来的假设以及估计不确定性的其他主要来源的相关信息，前提是假设的变动存在导致下一会计年度内相关资产和负债账面金额发生重大调整的重大风险。该要求针对的是需要管理层作出最困难、主观和复杂判断的估计。关于假设的信息应以有助于财务报表使用者理解管理层所运用判断的方式列报。为满足上述要求可能需要披露的信息取决于具体事实和情况。如果会计估计对某一项估计输入值高度敏感，管理层披露该估计输入值以及会计估计对该特定输入值的相关敏感性可能是有用的。对于对多项假设变动均敏感的会计估计，信息目标可通过管理层将假设与近期实际业绩相联系的定性描述来实现。准则不要求主体列报预算信息。

 

示例：某石油和天然气公司对若干油田计提了减值。这些油田的现金流量将持续20至30年。减值计算中最重要的假设是长期油价。该公司在前两年使用远期油价，但对其余年份自行估计长期油价。不同石油公司实际采用的长期油价可能存在显著差异。

 

在考虑IAS 1第125段的要求时，该公司确定应提供有关其如何制定长期油价估计的信息。这是因为在下一年度内该假设的合理变动将导致账面金额发生重大调整，而且在远期价格数据之外估计油价是困难、主观且复杂的。主体可包含有关所考虑的不同情景以及各情景权重的信息。此外，主体通常还会提供有关价格假设本身的定量信息，例如第5年、第10年和第15年的油价。该公司通常还会披露账面金额对不同价格假设的敏感性。关于管理层如何将气候风险及相关未来监管规定纳入情景的信息，也可能是相关信息。

 

<a id="s30-chap_04_navPoint_75"></a>
### <a id="s30-FAQ_4.158.1"></a>FAQ 4.158.1 – 对于以公允价值计量且在下一年度可能面临重大市场波动的资产和负债，主体应如何披露估计不确定性？

 

准则索引：IAS 1 第125段  
正文索引：[4.158](10.md#s29-Para_4.158)  

  

以公允价值计量的资产和负债，如果其公允价值系基于相同资产或负债在活跃市场中的报价（按照IFRS 13），则几乎不产生估计不确定性。此类资产和负债的市场价值在下一会计年度内可能发生变化，但其在资产负债表日的估值是准确的。IAS 1不要求识别在下一年度可能面临重大市场波动的资产和负债。仅当资产负债表日的公允价值本身存在估计不确定性时，才要求披露。

IFRS 13对以公允价值计量的资产和负债的公允价值计量规定了具体的披露要求（参见[第5章第142段](11.md#s34-Para_5.142)）。
