## 引言

 

<a id="s356-Para_A1.1"></a>**A1.1** 涉及同一控制下主体或业务的企业合并被排除在 IFRS 3 的适用范围之外。本附录阐述同一控制交易及类似交易中产生的一些常见问题。

[IFRS 3 第2段]。[IFRS 3 第2A段]。

 



<a id="s357"></a>

<a id="s357-chap_Appendix_1_navPoint_2"></a>
## 定义

 

<a id="s357-Para_A1.2"></a>**A1.2** IFRS 3 将涉及同一控制下主体或业务的合并定义为：“参与合并的所有主体或业务在企业合并前后均最终受同一方或相同的多方控制，且该控制并非暂时性的企业合并”。

[IFRS 3 附录B 第B1段]。

 

<a id="s357-chap_Appendix_1_navPoint_3"></a>
### 控制方

 

<a id="s357-Para_A1.3"></a>**A1.3** 控制方是指控制参与合并的主体或业务的一方。

<a id="s357-Para_A1.4"></a>**A1.4** 同一控制下主体或业务的定义并不局限于由另一主体实施的控制；控制权也可以由单个自然人或一组自然人持有。当一组自然人“根据合同安排”集体控制某主体时，该组自然人即被视为控制该主体。当参与合并的主体由一组自然人治理时，仅仅存在共同的股东群体是不够的。在缺乏合同协议的情况下，一组自然人不具有集体治理的权力，除非该控制群体内的所有自然人均属于同一近亲属家庭群体。

[IFRS 3 附录B 第B2段]。

<a id="s357-Para_A1.5"></a>**A1.5** 家族拥有或管理的企业可能由若干独立主体组成，这些主体并非由任何单个自然人控制，也未根据合同安排受到集体控制。配偶及其子女之间通常推定存在控制群体。涉及兄弟姐妹的控制群体应根据具体事实和情况予以考虑。在其他情况下，需要存在合同协议才能得出存在控制群体的结论。如果存在控制群体，涉及由该群体控制的主体的企业合并将被视为同一控制下企业合并。

[EX A1.5.1 – 评估涉及家族拥有或管理企业的交易中的同一控制](86.md#s361-EXA1.5.1)  
[EX A1.5.2 – 评估涉及高度共同持股主体的交易中的同一控制](86.md#s361-EXA1.5.2)

<a id="s357-Para_A1.6"></a>**A1.6** 当参与合并的主体由通过合同安排（即合营安排）对其实施共同控制的主体所拥有时，IFRS 3 关于涉及同一控制下主体或业务的合并的豁免同样适用。这些主体中的任何一方均不拥有单独的整体控制权。

[EX A1.6.1 – 涉及两家合营企业的同一控制交易](86.md#s361-EXA1.6.1)

 

<a id="s357-chap_Appendix_1_navPoint_4"></a>
### 暂时性控制

 

<a id="s357-Para_A1.7"></a>**A1.7** 同一控制下主体或业务合并的定义要求，参与合并的主体或业务在合并前后均最终受同一方或相同的多方控制，且“该控制并非暂时性的”。设置该条件的原因在于防止利用“包装（grooming）”交易——即在合并前极短的一段时间内，使参与合并的主体或业务处于同一控制之下。否则，原本应当按照 IFRS 3（即采用购买法）进行会计处理的企业合并，就可能被构造为存在临时性的同一控制。

[EX A1.7.1 – 属于暂时性的同一控制](86.md#s361-EXA1.7.1)

<a id="s357-Para_A1.8"></a>**A1.8** 当参与合并的主体或业务在合并前已处于同一控制之下达一段时间时，同一控制并非暂时性的。为促成分拆或首次上市而在集团内部进行的重组，属于同一控制下企业合并，即使母公司在交易后不久即丧失控制权。

[IFRIC Update – 2006年3月]。

 

<a id="s357-chap_Appendix_1_navPoint_5"></a>
### 非控制性权益

 

<a id="s357-Para_A1.9"></a>**A1.9** IFRS 3 将非控制性权益定义为“子公司中不直接或间接归属于母公司的权益”。

[IFRS 3 附录A]。

<a id="s357-Para_A1.10"></a>**A1.10** 同一控制下企业合并的关键特征是，交易并未导致参与合并主体的最终控制权发生变化。参与合并的各主体在企业合并前后非控制性权益的持股比例，与确定该合并是否属于同一控制下企业合并不相关。

[IFRS 3 附录B 第B4段]。

[EX A1.10.1 – 非控制性权益与同一控制](86.md#s361-EXA1.10.1)

## 会计处理

 

<a id="s358-Para_A1.11"></a>**A1.11** 目前，国际财务报告准则（IFRS）中尚无关于同一控制下主体或业务合并会计处理的专门指引。

<a id="s358-Para_A1.12"></a>**A1.12** IAS 8 要求，在没有专门适用的准则或解释的情况下，管理层应当制定一项与使用者的经济决策需要相关且可靠的会计政策。主体首先应考虑其他国际准则和解释中处理类似问题的要求和指引，其次应考虑国际会计准则理事会（IASB）《财务报告概念框架》（《概念框架》）的内容。管理层也可以考虑采用与 IASB 类似概念框架的其他准则制定机构发布的公告，前提是这些公告不与 IASB 的指引来源相冲突。

[IAS 8 第10段]。[IAS 8 第11段]。[IAS 8 第12段]。

<a id="s358-Para_A1.13"></a>**A1.13** 除非某项准则或解释专门要求或允许对可能适用不同政策的项目进行分类，否则应对类似交易、其他事项和情况一致地应用会计政策。根据特定同一控制下企业合并的具体事实和情况，管理层选择适当的会计政策，并在各期间内将其一致地应用于所有在性质上被视为类似的同一控制下企业合并（关于分析具体事实和情况时应考虑的标准，参见[第A1.17段和第A1.18段](86.md#s358-Para_A1.17)）。随后，管理层对该类类似交易采用购买法（参见[第A1.14段](86.md#s358-Para_A1.14)）或账面价值法（前任会计法）（参见[第A1.15段](86.md#s358-Para_A1.15)）之一。例如，将所有参与合并的主体或业务重述为公允价值的新起点法（fresh start policy）是不可接受的，因为该方法既未得到企业合并会计原则的支持，也未得到《财务报告概念框架》（《概念框架》）的支持。

[IAS 8 第13段]。

 

<a id="s358-chap_Appendix_1_navPoint_7"></a>
### 合并财务报表中的会计处理

<a id="s358-chap_Appendix_1_navPoint_idp1689361448"></a>
#### 购买法

 

<a id="s358-Para_A1.14"></a>**A1.14** 在考虑事实和情况（参见[第A1.17段和第A1.18段](86.md#s358-Para_A1.17)）后，管理层在确定同一控制下企业合并的会计政策时可参考 IFRS 3，并决定采用购买法作为其会计政策。IFRS 3 是适用于大多数企业合并的准则。尽管同一控制下主体或业务的合并被排除在 IFRS 3 的适用范围之外（参见[第A1.1段](86.md#s356-Para_A1.1)），管理层仍可选择采用 IFRS 3 的购买法。此时应当完整应用 IFRS 3 的所有要求（参见第29章）。应用 IFRS 3 要求管理层识别哪一主体为购买方、哪一主体为被购买方。在涉及新设公司的情况下，根据事实和情况，新设公司可能是也可能不是购买方。参见第29章第39段至第41段。

[IFRS 3 附录B 第B18段]。

 

<a id="s358-chap_Appendix_1_navPoint_idp1689378472"></a>
#### 账面价值法（前任会计法）

 

<a id="s358-Para_A1.15"></a>**A1.15** 在考虑事实和情况（[参见第A1.17段和第A1.18段](86.md#s358-Para_A1.17)）后，管理层可采用广义上称为账面价值法（前任会计法）的方法。账面价值法（前任会计法）的原则如下：

- 被收购主体的资产和负债按前任账面价值列报（[参见第A1.19段至第A1.21段](86.md#s358-Para_A1.19)），不要求按公允价值计量。

- 在账面价值法（前任会计法）下不产生新的商誉。

- 交易日所支付对价与被收购主体资产和负债账面价值总额之间的任何差额，均计入权益中的留存收益或单独的储备项目。

<a id="s358-Para_A1.16"></a>**A1.16** 合并财务报表中账面价值法（前任会计法）的常用列报方法包括：

- 追溯列报法。将被收购主体的经营成果和资产负债表并入合并报表，视同两个主体（收购方与被收购方）自始即已合并，或者当任一主体加入集团的日期较晚时，自该较晚日期起采用其经营成果。

- 未来适用列报法。自同一控制下企业合并发生之日起，未来适用地并入被收购主体的经营成果和资产负债表。

<a id="s358-Para_A1.17"></a>**A1.17** 管理层选择的会计政策取决于特定同一控制下企业合并的实质及具体事实和情况。对于性质类似的交易应当采用一致的会计政策。在确定哪项会计政策最能反映每项同一控制下企业合并的实质时，可考虑以下标准：

- 非控制性权益的存在：如果非控制性权益受到影响，这可能表明购买法是一项适当的会计政策。相反，如果参与合并的主体均为全资拥有，则可能表明账面价值法（前任会计法）更为适当。

- 转让对价：如果以现金全额支付主体或业务的公允价值，这可能表明购买法是一项适当的会计政策。相反，如果转让对价按转让方账面上的现有账面价值确定，则可能表明账面价值法（前任会计法）更为适当。

- 参与合并主体的管理方式：如果参与合并的主体在合并前后均由同一管理层共同管理，这可能表明账面价值法（前任会计法）是一项适当的会计政策。相反，如果参与合并的主体或业务虽同受同一最终控制方控制但并未共同管理，则购买法可能更为适当。

- 交易目的：如果该交易系为配合首次公开募股（IPO）或其他控制权变更或重大所有权变更事项而进行，这可能表明购买法是一项适当的会计政策。相反，如果该交易系为实现内部架构简化或出于内部税务筹划策略而进行，则可能表明账面价值法（前任会计法）更为适当。

<a id="s358-Para_A1.18"></a>**A1.18** 上述标准清单并非穷尽性的。管理层可能需要作出判断，并按照 IAS 1 的要求在关键判断披露中披露所选择的政策及其理由。采用购买法并非可以自由选择的会计政策，而要求管理层证明交易具有经济实质。如果交易不具有经济实质，则采用购买法不被视为适当。在选择政策时注重实质，可能会导致报告主体对两项同一控制下企业合并采用不同的会计处理——前提是具体事实和情况表明这两项交易在性质上并不相似且需要采用不同处理。

[IAS 1 第125段]。

<a id="s358-Para_A1.19"></a>**A1.19** 如[第A1.11段](86.md#s358-Para_A1.11)和[第A1.12段](86.md#s358-Para_A1.12)所述，IFRS 中尚无关于同一控制下企业合并处理的指引；但 IASB 目前正在讨论该议题。此前已有多项问题提交至国际财务报告准则解释委员会（IFRS IC），随后 IASB 决定将该议题纳入一项更广泛的项目予以解决，并预计于2020年底发布讨论稿。目前，在账面价值法（前任会计法）与购买法之间进行选择需要遵循 IAS 8 的指引，在采用账面价值法（前任会计法）时确定所采用的账面价值亦然。前任账面价值是指与被收购主体相关的账面价值，通常取自实施同一控制的最高层级主体所编制的合并财务报表中被收购主体资产和负债的账面金额。该金额包括在合并层面就该被收购主体确认的任何商誉（及其他公允价值调整）。这是因为该交易受该控制方控制，交易中实际是在集团内移动该控制方的一部分业务。

<a id="s358-Para_A1.20"></a>**A1.20** 控制方可能未编制合并财务报表。在此情况下，所采用的账面价值通常取自可获得的最高层级合并财务报表。如果未编制任何合并财务报表，则所采用的价值应取自被收购主体自身的财务报表。

<a id="s358-Para_A1.21"></a>**A1.21** 鉴于 IFRS 缺乏明确指引，即使更高层级编制了合并财务报表，也可能存在支持采用其他价值作为前任价值（例如取自中间次级集团财务报表或被收购主体自身财务报表的账面价值）的情形。需要仔细分析事实和情况，以确定选择此类替代价值是否更有意义。例如，我们认为在确定用作前任价值的适当价值时，以下考量通常具有相关性：

- 为上市作准备的交易。  
如果同一控制下企业合并系为上市或出售作准备，则最高层级合并财务报表中的价值通常更具相关性。为上市作准备的交易可通过多种方式进行。例如，两家现有子公司可能合并为一家，随后由存续子公司上市。或者，交易可能涉及新设公司，此时会计处理可能更为复杂，因为该交易可能并不构成同一控制下企业合并。由于 IFRS 缺乏指引，因此需要考虑交易的实质，以确定该交易属于同一控制下企业合并还是资本重组。参见下文[第A1.22段至第A1.23段](86.md#s358-Para_A1.22)以及[第A1.47段至第A1.49段](86.md#s359-Para_A1.47)。

- 财务报表使用者的身份。  
如果现已包含被转让业务的报告主体的财务报表使用者，正是先前依赖被转让业务财务报表的使用者，则被转让业务自身的账面价值可能更具相关性。

- 交易的时点。  
应结合接收方暨报告主体现已取得控制权的业务最初由整个集团设立或收购的时间来考虑交易时点。如果该业务一直作为更广泛集团的一部分受到指导和运营，间隔时间越长，该业务自身财务报表中的价值就越可能缺乏相关性。

[EX A1.21.1 – 并非取自最高层级合并财务报表的账面价值（前任价值）](86.md#s361-EXA1.21.1)

<a id="s358-Para_A1.22"></a>**A1.22** 选择采用账面价值法（前任会计法）还是购买法的政策，仅在存在两项或两项以上同一控制下业务的合并时才具有相关性。此类情形可能出现在单独财务报表中（当一项业务向上转让至本身即构成业务的现有主体时），也可能出现在已收购同样构成业务的子公司的主体的合并财务报表中。

<a id="s358-Para_A1.23"></a>**A1.23** 如果涉及新设公司，则在分析新设公司是否具有实质（如有）以及其所扮演的角色时必须谨慎，因为该交易可能并不构成同一控制下企业合并：

- 如果新设公司不构成业务，则将一项业务向上转让或将一家子公司出售给新设公司，其实质可能属于资本重组。参见[EX A1.42.1](86.md#s361-EXA1.42.1)，该示例中设立了一家新设公司以承接另一集团主体并取得外部融资。

- 相反，也可能存在买方为自身利益设立一家新公司作为收购载体的情形。在此情况下——正如[EX 29.40.1](51.md#s215-EX29.40.1)步骤 C 中对 VCP Acq Co 所阐述的——该新设收购公司将在企业合并中被视为购买方，并应采用 IFRS 3 购买法进行会计处理。

- 还可能出现如下情形：与上述第一点类似，新设公司本身不具有实质，但其从同一控制集团内部收购了两项独立且分开的业务。在此情况下，由于合并了两项或两项以上业务，参与合并的其中一项业务将被识别为购买方，另一项被识别为被购买方。因此，该交易构成企业合并，与 EX 29.39.1 类似，可以采用购买法。或者，由于该情形属于同一控制下，也可以采用账面价值法（前任会计法）。会计政策的选择应基于具体事实和情况（参见上文[第A1.17段](86.md#s358-Para_A1.17)）。

<a id="s358-Para_A1.24"></a>**A1.24** 被收购方可能此前系由控制方在企业合并中收购取得。控制方当时已采用购买法，并按照 IFRS 3 确认了资产和负债（包括商誉）。在账面价值法（前任会计法）下，取自最高层级同一控制主体的金额将不同于被收购方单体财务报表中的账面金额。在 IFRS 下，这些金额不会下推至被收购方的财务报表中。

[EX A1.24.1 – 取自最高层级合并财务报表的账面价值（前任价值）](86.md#s361-EXA1.24.1)

<a id="s358-Para_A1.25"></a>**A1.25** 参与合并的主体是从控制方所作转让的角度来看待的。该交易不被视为在企业合并日发生的等价交换及控制权变更。因此，除控制方就该被收购方原已记录的商誉外，不会产生新的商誉。

<a id="s358-Para_A1.26"></a>**A1.26** 采用追溯列报法时，即使企业合并发生在年度中间，合并财务报表也反映两个主体的全年经营成果。上一年度的比较金额反映两个主体的合并经营成果，即使该交易直至本年度才发生。这反映了以下观点：该交易涉及受同一控制方控制的两个主体；财务报表从该控制方的角度反映相关数据，并涵盖该控制方拥有控制权的期间。在并入被收购方的经营成果时，主体还应如[第A1.15段](86.md#s358-Para_A1.15)所述，一并纳入在账面价值法（前任会计法）下承接的合并调整对损益的影响。

<a id="s358-Para_A1.27"></a>**A1.27** 采用未来适用列报法时，合并财务报表不反映被收购主体在交易发生前期间的经营成果，也不重述上一年度的比较金额。除[EX A1.27.1](86.md#s361-EXA1.27.1)中对账面价值法（前任会计法）与购买法的比较外，[FAQ A1.44.1](86.md#s361-FAQ_A1.44.1)还总结了账面价值法（前任会计法）、购买法与资本重组会计之间的主要区别。

[EX A1.27.1 – 账面价值法（前任会计法）与购买法的比较](86.md#s361-EXA1.27.1)

<a id="s358-Para_A1.28"></a>**A1.28** 在某些司法管辖区，当地监管机构可能规定必须采用某种特定方法。部分司法管辖区（例如英国或美国）允许甚至要求对集团重组及其他同一控制交易采用账面价值法（前任会计法）。

### 单独财务报表中的会计处理

 

<a id="s358-Para_A1.29"></a>**A1.29** 同一控制下的交易主要通过两种方式发生：

- 在集团内部转让权益投资；或

- 在集团内部转让子公司的底层业务活动和资产。

<a id="s358-Para_A1.30"></a>**A1.30** 主体在单独财务报表中收购子公司的权益投资不属于企业合并。收购方按照 IAS 27 将其在被收购方中的权益确认为对子公司的投资。

[IAS 27 第10段]。

<a id="s358-Para_A1.31"></a>**A1.31** 仅当主体收购未独立法人化的业务或符合业务定义的一组活动和资产时，单独财务报表中才会发生企业合并。

 

<a id="s358-chap_Appendix_1_navPoint_idp1689451048"></a>
#### 将业务从子公司转让至母公司（向上剥离交易）

 

<a id="s358-Para_A1.32"></a>**A1.32** 将子公司的业务（一组活动和资产）转让至其母公司通常称为“向上剥离（hive-up）”。对价通常通过集团内部往来账户支付。如果子公司为100%全资拥有，则从集团角度来看，该交易不会导致任何变化。需要解决的问题是如何在单独财务报表中对该交易进行会计处理。

<a id="s358-Para_A1.33"></a>**A1.33** 主体可以采用账面价值法（前任会计法）（参见[第A1.15段](86.md#s358-Para_A1.15)）或购买法（参见[第A1.14段](86.md#s358-Para_A1.14)）对该交易进行会计处理。

<a id="s358-Para_A1.34"></a>**A1.34** 如果向上剥离在收购后立即发生，从实务上看，对向上剥离采用购买法所产生的会计处理结果与采用账面价值法（前任会计法）相同。

[EX A1.34.1 – 收购后立即进行的向上剥离](86.md#s361-EXA1.34.1)  
[EX A1.34.2 – 原始收购一段时间后进行的向上剥离](86.md#s361-EXA1.34.2)

<a id="s358-Para_A1.35"></a>**A1.35** 在每种情况下确定会计政策时，均应结合具体事实和情况以及当地法规予以考虑。

 

<a id="s358-chap_Appendix_1_navPoint_idp1689468200"></a>
#### 将业务从母公司转让至子公司（向下剥离交易）

<a id="s358-Para_A1.36"></a>**A1.36** 在“存续”法律主体为子公司的向下剥离情形下，其会计处理结果与向上剥离相同。该方法反映了交易的实质而非其法律形式。

<a id="s358-chap_Appendix_1_navPoint_idp1689209640"></a>
#### 在集团内部转让子公司或业务

 

<a id="s358-Para_A1.36.1"></a>**A1.36.1** 集团可能通过以低于投资账面金额的价格在集团内部转让子公司或业务的方式进行重组。可能不存在阻止集团以低于公允价值的价格转让子公司的法律限制或税务影响。例如，投资可能按子公司净资产的账面金额转让，或无偿转让。这在表面上可能导致母公司对转让方的投资发生减值。IFRS 对此类交易的会计处理没有专门指引。主体可根据 IAS 8 制定一项反映交易经济实质的会计政策并一贯应用。

#### 通过股利分配转让子公司

 

<a id="s358-Para_A1.37"></a>**A1.37** 转让子公司可以通过在同一控制下的主体之间转让权益工具来实现。此类转让的适当会计处理应基于交易的实质。应运用判断以确定被投资方向母公司的分配属于资本回报（股利收入）还是资本返还（投资成本的冲减或重新分摊）。另见[第28章第32段](49.md#s200-Para_28.32)和第33段以及[FAQ 28.33.1](49.md#s205-FAQ_28.33.1)“以对子公司投资的形式进行的分配如何进行会计处理？”。

[IFRS 9 附录B 第B5.7.1段]。

<a id="s358-Para_A1.38"></a>**A1.38** 受让方应在损益中确认股利收入，且通常按公允价值入账。但是，如果股利收入涉及收取对子公司（该子公司构成业务）的投资，则存在会计政策选择：既可按转让日该投资在转让方单独财务报表中的账面金额（即“前任价值”）确认所收到的投资及相应的股利收入，也可按公允价值确认。

[IFRS 9 第5.7.1A段]。

<a id="s358-Para_A1.39"></a>**A1.39** IFRS 中没有专门指引处理同一控制下主体之间分配符合业务定义的非现金资产的情形。受让方管理层应选择采用购买法或账面价值法（前任会计法），并按照[第A1.14段](86.md#s358-Para_A1.14)及之后段落所述应用该政策。

<a id="s358-Para_A1.40"></a>**A1.40** 转让方在会计政策上可以选择按所分配投资的账面价值或公允价值确认股利。IFRIC 17 要求对某些交易采用公允价值法；然而，IFRIC 17 不适用于在分配前后最终受同一方或相同的多方控制（即同一控制）的非现金资产分配。该豁免适用于实施分配的主体的单独财务报表、个别财务报表及合并财务报表。关于集团内部转让子公司（包括集团重组引发的减值问题）的进一步指引，参见上文[第A1.36.1段](86.md#s358-Para_A1.36.1)。

[IFRIC 17 第5段]。

<a id="s358-chap_Appendix_1_navPoint_9"></a>
### 同一控制交易中的新设公司

 

<a id="s358-Para_A1.41"></a>**A1.41** 当同一控制交易涉及集团为实现同一控制下主体合并而设立的新设公司时，可能会出现复杂情况。新设公司与单一报告主体的合并不太可能符合 IFRS 3 语境下企业合并的定义。新设公司不会是购买方，且其本身不构成业务，因此无法适用反向购买会计原则（因为反向购买属于 IFRS 3 的应用）。如果购买法和账面价值法（前任会计法）均不适用，则该交易作为资本重组进行会计处理。

<a id="s358-Para_A1.42"></a>**A1.42** 即使重组发生在年度中间，新设公司的合并财务报表也应包含现有主体的全年经营成果（包括比较期间）。这反映了以下观点：该交易涉及受同一控制方控制的两个主体，财务报表反映该控制方拥有控制权的期间。现有主体的资产和负债按合并前账面金额并入，不进行公允价值调增。这是基于交易未发生实质性经济变化的前提。

[EX A1.42.1 – 涉及新设公司的交易](86.md#s361-EXA1.42.1)

<a id="s358-Para_A1.43"></a>**A1.43** 还存在涉及设立新设公司并合并两个以上主体的其他同一控制情形。在此类情形下，需要在采用账面价值法（前任会计法）与购买法之间作出选择（参见上文[第A1.17段和第A1.18段](86.md#s358-Para_A1.17)）。对于被识别为购买方的主体的财务报表，将采用资本重组会计（另见[第A1.45段](86.md#s358-Para_A1.45)）。

<a id="s358-Para_A1.44"></a>**A1.44** 新设公司可能与同一控制下的多个主体合并。在新设公司的合并财务报表中，前提是该交易符合企业合并的定义，管理层将必须根据具体事实和情况决定是按照 IFRS 3 采用购买法还是采用账面价值法（前任会计法）。如果采用购买法，新设公司不会被识别为购买方，而是由参与合并的某一现有主体作为购买方。在新设公司的合并财务报表中，对被识别为购买方的主体按其合并前账面价值确认，不进行公允价值调增；而被收购业务的资产和负债（包括商誉）则在购买日按照 IFRS 3 以公允价值在新设公司的财务报表中确认。

[IFRS 3 附录B 第B18段]。

[FAQ A1.44.1 – 账面价值法（前任会计法）、购买法与资本重组会计之间的主要区别是什么？](86.md#s361-FAQ_A1.44.1)

<a id="s358-Para_A1.45"></a>**A1.45** 被合并至新设公司旗下的同一控制下各项业务，可能在某一层级受单一管理层管理或监督。这些业务可能被视为一个单一报告主体。此时，该交易不构成企业合并，而是构成现有报告主体的资本重组（进一步参见[第A1.41段及之后段落](86.md#s358-Para_A1.41)以及第29章第39段至第41段）。

[EX A1.45.1 – 新设公司收购不同的报告主体](86.md#s361-EXA1.45.1)

<a id="s358-Para_A1.46"></a>**A1.46** 股东或母公司可以注册成立一家新主体，并通过发行股份将其设为现有集团的母公司。该新主体可能是为配合计划中的剥离出售而设立的。从新主体的合并角度来看，根据事实和情况，此类交易可能不符合 IFRS 3 下企业合并的定义，在此情况下将作为资本重组进行会计处理。国际财务报告准则解释委员会（IFRS IC）于2011年7月和9月讨论了该议题，但未将其列入理事会议程，而是建议在理事会更广泛的同一控制下企业合并项目中一并处理。尽管目前指引尚不明确，但仍可能存在表明构成了非同一控制下企业合并的事实和情况。在此情况下，作为剥离出售一部分而设立的新主体将在其合并财务报表中采用公允价值会计。管理层应结合具体事实和情况运用判断；若该判断具有重大影响，应提供相关披露。

[EX A1.46.1 – 首次公开募股（IPO）前将子公司移至新设公司旗下](86.md#s361-EXA1.46.1)

## 示例与实务指引

<a id="s361-chap_Appendix_1_navPoint_13"></a>
### 定义

<a id="s361-chap_Appendix_1_navPoint_idp1689299240"></a>
#### 控制方

<a id="s361-chap_Appendix_1_navPoint_idp1689301416"></a>
##### <a id="s361-EXA1.5.1"></a>EX A1.5.1 – 评估涉及家族拥有或管理企业的交易中的同一控制

 

准则索引：IFRS 3 第2段  
正文索引：[A1.5](86.md#s357-Para_A1.5)

  

**示例：**

  
史密斯家族经营零售业务。零售门店由七家公司运营，这些公司由史密斯先生、其妻子及三名子女按不同比例持有。任何一位家庭成员在任何一家经营公司中的持股比例均不超过50%，且家庭成员之间不存在合同安排。上述公司此前均未向家庭成员收购过任何业务。

该家族接受建议，出于税务目的整合其持股架构。为此新设一家控股公司 X 主体，由其向史密斯夫妇及其三名子女发行股份以收购全部经营公司。交易完成后，每位家庭成员将持有 X 主体 20% 的股权。

**分析：**

史密斯家族整体在交易前后均控制所有参与合并的主体。该重组属于同一控制下企业合并。参与合并的主体为 X 主体和现有各经营公司。尽管不存在赋予该家族同一控制的合同安排，但在许多情况下，由于存在紧密的家庭关系，此类安排被推定存在。

在此情况下，如果这是收购方的首次同一控制下企业合并，管理层应根据交易的实质及具体事实和情况选择会计政策——采用购买法或账面价值法（前任会计法）。如果采用购买法，则适用 IFRS 3 的全部要求。X 主体不能成为购买方（参见[第A1.44段](86.md#s358-Para_A1.44)）。

如果为通过发行权益工具实施企业合并而设立新主体，则应应用 IFRS 3 的指引，将企业合并前即已存在的某一参与合并主体识别为购买方。如果所有现有公司作为一项单一业务共同管理，则应将所有现有公司整体识别为购买方。在所有公司整体被识别为 IFRS 3 下的购买方的情况下，其会计处理结果将与账面价值法（前任会计法）相似。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689324968"></a>
##### <a id="s361-EXA1.5.2"></a>EX A1.5.2 – 评估涉及高度共同持股主体的交易中的同一控制

 

准则索引：IFRS 3 第2段  
正文索引：[A1.5](86.md#s357-Para_A1.5) 

  

  
**示例：**

A 主体由三名无关联股东（S1、S2 和 S3）分别持股 40%、40% 和 20%。不存在赋予任何单一股东或股东群体控制权的合同协议。B 主体的公允价值与 A 主体相等，由股东 S1、S2、S3 和 S4 分别持股 30%、30%、30% 和 10%。

A 主体设立一家新主体 X 主体，由 X 主体发行股份收购 A 主体和 B 主体 100% 的股份。交易后，股东 S1、S2、S3 和 S4 分别持有 X 主体 35%、35%、25% 和 5% 的股份。

**分析：**

这不属于同一控制下企业合并。不存在赋予任何单一股东或股东群体对 A 主体或 B 主体控制权的合同协议。在此事实情形下应采用购买法，并应将 A 主体或 B 主体识别为购买方（参见第29章第39段）。

实务中可能出现两个或两个以上主体或自然人有时集体行动以管理和运营另一主体活动的情形。在 IFRS 11 的定义语境下，此类安排可能构成合营安排。关于涉及两家合营企业的同一控制交易，参见[EX A1.6.1](86.md#s361-EXA1.6.1)。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689352232"></a>
##### <a id="s361-EXA1.6.1"></a>EX A1.6.1 – 涉及两家合营企业的同一控制交易

 

准则索引：IFRS 3 第2段、第2A段  
正文索引：[A1.6](86.md#s357-Para_A1.6)  

  

  
**示例：**

![](assets/218.png)

  
S1、S2 和 S3 之间订有两份合营企业协议：一份确立对 A 主体的共同控制，另一份确立对 B 主体的共同控制。S1、S2 和 S3 可以是订立两份独立合营企业协议以治理 A 主体和 B 主体的自然人股东或主体。合营企业协议要求对相关活动的决策须经一致同意。该控制并非暂时性的（参见[第A1.7段](86.md#s357-Para_A1.7)）。A 主体收购 B 主体。该交易应如何进行会计处理？

**分析：**

A 主体收购 B 主体不在 IFRS 3 的适用范围内，因为合营企业协议确立了对每个主体的共同控制。由于 A 主体和 B 主体受相同股东集体控制，该收购属于同一控制下主体或业务的企业合并。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689420456"></a>
#### 暂时性控制

<a id="s361-chap_Appendix_1_navPoint_idp1689432232"></a>
##### <a id="s361-EXA1.7.1"></a>EX A1.7.1 – 属于暂时性的同一控制

 

准则索引：IFRS 3 第2段  
正文索引：[A1.7](86.md#s357-Para_A1.7)  
 

  

  
**示例：**

D 主体和 P 主体在北海提供油田服务。D 主体由一组自然人持有，其中无人拥有控制权，且他们之间没有集体控制协议。P 主体由单一自然人 X 先生持有。D 主体和 P 主体的所有者决定合并两家主体，对价将以 P 主体的股份结算。

P 主体向其控股股东 X 先生发行相当于其已发行股本 30% 的新股。X 先生随后将这些股份转让给 D 主体的所有者，以换取其在 D 主体中的权益。此时，X 先生同时控制 D 主体和 P 主体，持有 D 主体 100% 的股权和 P 主体 70% 的股权。随后，X 先生将其持有的 D 主体控股权投入 P 主体。X 先生在该投入前后均持有 D 主体和 P 主体的控股权。D 主体与 P 主体的合并是否属于同一控制下企业合并？

**分析：**

否。这不属于同一控制下企业合并。X 先生在企业合并前对两个主体的控制是暂时性的。该交易的实质是 P 主体取得了对 D 主体的控制权。P 主体应按照 IFRS 3 采用购买法将该交易作为企业合并进行会计处理。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689442728"></a>
#### 非控制性权益

<a id="s361-chap_Appendix_1_navPoint_idp1689444136"></a>
##### <a id="s361-EXA1.10.1"></a>EX A1.10.1 – 非控制性权益与同一控制

 

准则索引：IFRS 3 附录B 第B4段  
正文索引：[A1.10](86.md#s357-Para_A1.10) 

  

  
**示例：**

B 主体是子公司 C、D 和 E 的中间母公司。B 主体存在 10% 的非控制性权益，其余股份由最终母公司 A 主体持有。A 主体还拥有另一家直接子公司 X 主体。B 主体进行了两项交易：

第一，B 主体将 C 主体的所有权转让给 E 主体，以换取 E 主体（向 B 主体）发行的股份。

第二，B 主体将 E 主体（现已拥有 C 主体）转让给 X 主体，以换取 X 主体发行的股份。

E 主体和 X 主体均编制合并财务报表。

![](assets/219.png)

  
该交易的两个阶段是否构成同一控制下企业合并？

**分析**

交易 1 —— 是。在第一项交易（将 C 主体转让给 E 主体）中，非控制性权益不受影响，因为以 B 主体为首的次级集团的构成未发生变化。在 E 主体的合并财务报表中，与 C 主体的合并符合 IFRS 3 关于同一控制下企业合并的豁免条件，因为参与合并的主体（E 主体和 C 主体）在合并前后均受同一方（A 主体）控制。

交易 2 —— 是。在第二项交易中，E 主体及其子公司 C 主体移出了 B 主体次级集团；B 主体对 E 主体（及其子公司 C 主体）的投资被替换为对 X 主体的投资（但 X 主体并未成为 B 主体的子公司）。B 主体的非控制性权益处置了 B 主体次级集团的一部分。参与合并的主体（X 主体和 E 主体）在合并前后均受同一方（A 主体）控制。尽管非控制性权益发生了变动，该转让仍符合 IFRS 3 关于同一控制下主体的豁免条件。

### 会计处理

<a id="s361-chap_Appendix_1_navPoint_idp1689459880"></a>
#### 合并财务报表中的会计处理

<a id="s361-chap_Appendix_1_navPoint_idp1689468584"></a>
##### 账面价值法（前任会计法）

<a id="s361-chap_Appendix_1_navPoint_idp1689469352"></a>
###### <a id="s361-EXA1.21.1"></a>EX A1.21.1 – 并非取自最高层级合并财务报表的账面价值（前任价值）

 

准则索引：  
正文索引：[A1.21](86.md#s358-Para_A1.21)  

  

**示例：**

A 公司是一家上市公司，拥有众多具有实质性经营业务的子公司。其中一家子公司 G 公司发行了公开上市的债务工具。G 公司有三家子公司——X 公司、Y 公司和 Z 公司，分别构成其在三个不同国家的业务。为筹备首次公开募股（IPO），X 公司收购了 Z 公司。假设 A 公司和 G 公司对 Z 公司资产记录的账面价值不同。X 公司在其合并财务报表中应采用何种前任价值？

**分析：**

同一控制下企业合并通常应采用最高层级的合并数据（参见[第A1.19段](86.md#s358-Para_A1.19)）。这意味着 X 公司应采用 A 公司合并财务报表中就 Z 公司记录的价值。然而，鉴于此次重组完全发生在 G 公司的合并业务范围内，且 G 公司的财务报表存在第三方利益相关者，在本案例中采用 G 公司合并财务报表中的价值可能更具相关性。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689215912"></a>
###### <a id="s361-EXA1.24.1"></a>EX A1.24.1 – 取自最高层级合并财务报表的账面价值（前任价值）

 

准则索引：  
正文索引：[A1.24](86.md#s358-Para_A1.24) 

  

  
**示例：**

以 A 主体为首的集团于 20X1 年收购了以 X 主体为首的集团，该收购采用购买法进行会计处理。

20X3 年，以 X 主体为首的次级集团被转让给 B 主体（A 主体的全资子公司），作为对价，B 主体向其母公司 A 主体发行权益股份。

![](assets/220.png)

  
A 主体和 B 主体均编制合并财务报表，且所有公司均为全资拥有。在 A 主体和 B 主体的合并财务报表中应如何对该交易进行会计处理？

**分析**

将 X 主体转让给 B 主体不影响 A 主体的合并财务报表，因为 X 主体在转让前后均为 A 主体的全资子公司。

与 X 主体次级集团的合并反映在 B 主体的合并财务报表中。由于 B 主体和 X 主体在合并前后均受 A 主体控制，这属于同一控制下企业合并，不在 IFRS 3 的适用范围内。因此，如果符合其针对此类交易的会计政策，B 主体可采用账面价值法（前任会计法）核算与 X 主体的合并。

采用账面价值法（前任会计法）时，所采用的账面价值通常为最终母公司合并财务报表中的账面价值，除非存在支持采用其他价值作为前任价值的情形（参见[第A1.19段至第A1.21段](86.md#s358-Para_A1.19)）。

在本示例中，假设管理层运用适当指标作出判断（参见[第A1.21段](86.md#s358-Para_A1.21)），认为应采用的账面价值为 A 主体合并财务报表中包含的账面价值，而非 X 主体次级集团的历史数据。这意味着所采用的账面价值将反映 A 主体收购 X 主体次级集团时产生的公允价值调整和商誉。

 

<a id="s361-chap_Appendix_1_navPoint_idp1689229992"></a>

**示例：**

###### <a id="s361-EXA1.36.1.2"></a>EX A1.36.1.2 – 基于相对价值的投资转让

**示例：**

在许多情况下，将对转让方子公司的全部投资账面金额转移至受让方子公司是不适当的，因为转让方可能保留了其他资产（例如对其他子公司的投资）。

[IAS 36 第86段]。[IAS 36 第87段]。

##### 通过股利分配转让子公司

<a id="s361-chap_Appendix_1_navPoint_idp1702097048"></a>
###### <a id="s361-EXA1.40.1"></a>EX A1.40.1 – 子公司向母公司分配股份时的投资计量

 

准则索引：IFRIC 17 第5段  
正文索引：[A1.40](86.md#s358-Para_A1.40) 

  

 

**示例：**

 

母公司 A 主体持有澳大利亚控股公司 B 主体 100% 的权益以及新西兰公司 C 主体 100% 的权益。B 主体和 C 主体各自拥有一家贸易子公司，分别为 D 主体和 E 主体。母公司 A 主体正在重组其业务，使 E 主体由母公司 A 主体直接持有。为完成重组，C 主体将其持有的 E 主体股份分配给母公司 A 主体。C 主体此前从未分配过非现金资产，因此尚未就此类交易的会计处理制定政策。在本案例中，该分配的实质被视为资本回报（即股利收入——[参见第A1.37段](86.md#s358-Para_A1.37)）。

 

交易日 E 主体的公允价值为 C20m。交易日 C 主体对 E 主体投资的账面价值为 C10m。

 

**分析：**

 

由于这属于同一控制交易且 IFRIC 17 不适用，C 主体拥有会计政策选择权，可以按所分配非现金资产的账面金额或交易日的公允价值确认此类交易。如果按投资的账面价值入账，则不会产生差额，因为 C 主体将终止确认其对 E 主体的投资，并相应借记留存收益。如果按公允价值确认，C 主体将按 C10m 终止确认其投资，借记留存收益 C20m，并在损益中确认利得 C10m。

 

母公司 A 主体在其账簿中，可按公允价值 C20m 确认对 E 主体的投资并确认股利收入 C20m。作为替代会计政策选择，母公司 A 主体也可按前任价值 C10m 记录股利收入以及相应的对 E 主体的投资。母公司 A 主体还应评估其对 C 主体的投资是否发生减值。

##### 以非公允价值转让子公司

<a id="s361-chap_Appendix_1_navPoint_idp1683467496"></a>
###### <a id="s361-FAQ_A1.40.1.1"></a>FAQ A1.40.1.1 – 在同一控制交易中，公司应如何确定以非公允价值转让的含业务子公司的投资成本？

 

准则索引：  
正文索引：[A1.40.1](86.md#s358-Para_A1.40.1) 

  

**问题：**

在同一控制交易中，公司应如何确定以非公允价值转让的含业务子公司的投资成本？

**解答：**

在集团重组中，母公司以非公允价值（包括换股交易）将含业务的子公司转让给受让方十分常见。

IAS 27 未对“成本”作出定义，也未规定主体应如何确定同一控制交易中对子公司投资的成本。根据《概念框架》，历史成本是指取得或创建资产所发生之成本的价值，包括为取得或创建资产所支付的对价加上交易费用。

2011年9月，国际财务报告准则解释委员会（IFRS IC）最终确定了其议程决定的措辞，对于不符合 IAS 27 第13段和第14段条件的重组，应采用“确定对子公司投资成本的常规基础”。相较于初步决定中所提议的原始措辞——“所付出对价的公允价值”，这一细微调整表明公允价值未必始终是计量成本的唯一适当基础。

2019年1月，IFRS IC 认可，对于因从 IFRS 9 投资分步增持而形成的对子公司投资，在现行 IFRS 下可以选择采用“以公允价值作为认定成本法”或“成本累积法”作为会计政策进行核算。综上所述，在这些情形下确定成本并非显而易见。

目前尚无决定性指引强制要求在同一控制下接收含业务子公司的受让方在其单独财务报表中只能按公允价值计量成本。因此，主体在此情形下自行制定会计政策是可接受的。

在同一控制交易中以非公允价值转让含业务子公司的情况下，受让方在其单独财务报表中按合同对价的公允价值（即交易价格）或按被转让子公司的公允价值记录对该子公司的投资均是可接受的。另一种方法是采用前任价值，即按该投资在转让方单独财务报表中的账面金额计量该投资。

管理层应选择适当的会计政策，予以披露，并将其一贯应用于所有此类交易。

###### <a id="s361-FAQ_A1.40.1.2"></a>FAQ A1.40.1.2 – 公司应如何对以非公允价值转让子公司（无论是否涉及名义资本投入或资本分配）进行会计处理？

 

准则索引：  
正文索引：[A1.40.1](86.md#s358-Para_A1.40.1)   

  

**问题：**

控制方的影响通常是导致子公司以非公允价值转让的因素，而与第三方进行的交易几乎总是推定按公允价值进行。在部分司法管辖区，按等于子公司现有账面价值或前任价值的金额进行交易既合法又常见。因此，同一控制下主体之间交易的“成本”可视为由两部分组成：所支付的对价，以及名义资本投入或资本分配。公司应如何对以非公允价值转让子公司（无论是否涉及名义资本投入或资本分配）进行会计处理？

**解答：**

鉴于 IFRS 对名义资本投入或资本分配的会计处理没有指引，如[FAQ A1.40.1.1](86.md#s361-FAQ_A1.40.1.1)所述，受让方（接收主体）可以接受按以下三种方式之一记录子公司的转让：（i）合同对价的公允价值（即交易价格），或（ii）子公司的公允价值，或（iii）转让方单独财务报表中的账面金额（即前任价值）。一旦作出会计政策选择，主体应对所有涉及转让子公司投资的交易采用一致的处理基础。如果主体选择按公允价值而非交易价格或前任价值核算投资转让，其应根据 IAS 8 第13段考虑与母公司及其他同一控制下主体之间的所有其他非互惠交易（例如存货、不动产、厂场和设备以及其他资产的出售）是否也应按类似基础进行会计处理。

通常，将一项投资无偿（零对价）从一个主体转让给另一个主体，发生在不存在非控制性权益的同一控制集团架构中。该交易系应最终母公司的要求而发生。在此情况下，该交易的实质往往表现为转让方向上的资本回报以及向受让方作出的向下资本投入。在此情形下，接收主体按公允价值记录该转让可能是适当的，因为实质上发生了一项分配和一项投入。作为替代会计政策选择，接收主体也可按前任价值记录该转让及相应的对受让主体的投资。在非同一控制的商业情形中，转让实质属于真正赠与的情况较为罕见——若属于真正赠与且无须支付对价，[第22章第41段](39.md#s142-Para_22.41)提及了按公允价值或零值记录赠与的会计政策选择。在所有情况下，均应考虑协议的实质以确定适当的会计政策。

在考虑投资转让方是否应确认任何利得或损失时，管理层应评估该交易是否具有实质。IAS 16 第25段中关于商业实质的指标可能有助于此项分析。该段指出，判断一项交易是否具有商业实质，取决于该交易预计在多大程度上改变主体的未来现金流量。关于判断交换交易是否具有商业实质的进一步指引，[参见第22章第38段](39.md#s142-Para_22.38)。该交易还可能表明存在先前未确认的减值，该减值应计入损益。关于资产减值会计处理的指引，[参见第24章](41.md#s153-chap_24)。

##### <a id="s361-EXA1.42.1"></a>EX A1.42.1 – 涉及新设公司的交易

 

准则索引：  
正文索引：[A1.42](86.md#s358-Para_A1.42) 

  

  
**示例：**

B 主体由 A 主体拥有。集团设立了一家新设公司（New Co），该公司向金融机构安排了贷款融资。New Co 使用该贷款以现金对价向 A 主体收购 B 主体。

在 New Co 的财务报表中应如何对该交易进行会计处理？这是否属于同一控制下主体或业务的合并？

![](assets/222.png)

  
**分析**

这是同一控制下主体的合并：New Co 和 B 主体均受 A 主体控制。

然而，根据 IFRS 3，该交易不符合企业合并的定义，因为 New Co 不构成业务（与 IFRS 3 附录B 第B19段一致）。在 New Co 的财务报表中，该交易作为 B 主体的资本重组进行会计处理。

在资本重组下，New Co 的合并财务报表将反映 B 主体合并前的账面价值，并列报 B 主体所有期间的比较信息。这不同于采用前任价值的同一控制下企业合并——在后者中，主体可以选择未来适用地而非追溯地核算对被收购方的收购。在资本重组中，由于未发生实质性经济变化，现有主体合并前的账面价值直接结转至 New Co 的财务报表中。

##### <a id="s361-EXA1.45.1"></a>EX A1.45.1 – 新设公司收购不同的报告主体

 

准则索引：  
正文索引：[A1.45](86.md#s358-Para_A1.45)  
 

  

  
**示例：**

控股公司 A Hold Co 由 X 先生 100% 持有。该公司拥有一组业务 B1、B2、B3 和 B4（“B 业务组”），并计划将其出售。目前已确定若干潜在买方。A Hold Co 管理层正在进行谈判，并为出售 B 业务组做准备。管理层注册成立了一家新设公司（New Co），由 New Co 发行股份以收购构成 B 业务组的各个法律主体 100% 的股权。

VCP 最终竞标胜出并达成协议。VCP 设立了一家新公司 VCP Acq Co，以收购 B 业务组为条件筹集了大额债务资金。VCP Acq Co 以现金向 A Hold Co 购买了 New Co 75% 的股份。

New Co 应如何对该交易进行会计处理？

**分析：**

由于 New Co 被置入作为若干构成业务的主体（“B 业务组”）的中间母公司，该交易属于同一控制下企业合并。因此，New Co 必须确定在其合并财务报表中对该交易采用何种方法：购买法还是账面价值法（前任会计法）。

购买法

如果采用购买法，New Co 不能被识别为购买方，因为 New Co 是为在企业合并中发行权益工具而设立的。现有的 B 业务之一（很可能是按公允价值计规模最大的 B1）将被识别为购买方。购买方（B1）的资产和负债按其在 B1 财务报表中的合并前账面金额并入 New Co 的合并财务报表，不进行任何公允价值调增。对其他被收购业务（B2 至 B4）采用购买法，其资产和负债在 New Co 的合并财务报表中调增至公允价值。该交易将自合并日起未来适用地进行会计处理。

账面价值法（前任会计法）

如果 New Co 采用前任价值，则 B 业务组（即 B1 至 B4）将按[第A1.19段](86.md#s358-Para_A1.19)确定的金额列报。假设 A Hold Co 过去曾编制合并财务报表，则应采用这些账面价值（包括任何商誉）来计量 New Co 所收购的资产和负债。

New Co 的合并财务报表可以：

- 将被收购主体的资产负债表和经营成果并入，视同所有主体（New Co 和 B 业务组）自始即已合并（或者当相关主体加入集团的日期较晚时，自该较晚日期起并入其经营成果），包括列报比较期间的合并资产负债表和合并经营成果；或

- 自同一控制下企业合并发生之日起，未来适用地并入被收购主体的经营成果和资产负债表。由于该合并按未来适用法处理，比较信息仅就其中一家主体列报。

该交易属于企业合并而非资本重组，因为所合并的是不同的报告主体。

尽管 New Co 将该交易作为同一控制下企业合并进行会计处理，但执行了若干实质性合并前活动的 VCP Acq Co 将被确定为会计上的购买方，并对全部 B 业务组采用购买法。

##### <a id="s361-EXA1.46.1"></a>EX A1.46.1 – 首次公开募股（IPO）前将子公司移至新设公司旗下

 

准则索引：  
正文索引：[A1.46](86.md#s358-Para_A1.46) 

  

  
**示例：**

B 集团业务的现有投资者希望将其持股比例从 100% 降至 25%。其对包含 B 集团业务的 B 公司的权益投资由 A Holding Co 持有，A Holding Co 没有其他经营业务。B 集团业务由一套单一管理层管理，并被视为单一报告主体。

为促成首次公开募股（IPO）并吸引潜在投资者，A Holding Co 将设立一家新主体 New Co，并将其持有的 B 公司股权转让给 New Co，以换取 New Co 的股份。如果找到潜在投资者，New Co 将在未来的 IPO 中发行股份，使散户投资者持有 75% 的权益，A Holding Co 持有 25% 的权益。New Co 应如何在其分部合并（次级合并）财务报表中对该交易进行会计处理？

**交易前架构**

**交易后架构**

![](assets/224.png)

  
**分析：**

在此情形下，New Co 与 B 集团业务的合并很可能属于同一控制下主体的合并，因为 New Co 是由控股公司为控股公司自身利益而设立的。

IFRS 3 第B1段定义了同一控制下企业合并并将其排除在 IFRS 3 的适用范围之外。由于 IFRS 3 排除了同一控制下企业合并，需要制定一项会计政策。通常，会根据哪种方法更能反映交易实质，选择账面价值法（前任会计法）或完整应用 IFRS 3。然而，在本案例中，这两种选择均不适当：

完整应用 IFRS 3

该合并发生在同一控制下，且表面上似乎符合 IFRS 3 附录A 中企业合并的定义：购买方取得对被购买方的控制权。New Co 是取得对被购买方 B 控制权的主体，且 B 符合业务的定义。然而，IFRS 3 第B18段解释称，新设主体未必是购买方；相反，如果新设主体通过发行股份实现企业合并，则 B 将被视为 New Co 的购买方，而 New Co 为会计上的被购买方。表面上看这似乎会导致反向购买会计，但由于 New Co 不构成业务，其不能成为 IFRS 3 下的被购买方。IFRS 3 第B19段要求，在反向购买中，会计上的被购买方必须符合业务的定义。因此，此事实情形不构成反向购买，从而不能应用 IFRS 3。

账面价值法（前任会计法）

账面价值法（前任会计法）将导致在 New Co 的新次级合并报表中采用 B 和 New Co 的前任价值，不确认公允价值调增。即使不应用 IFRS 3，仍需确定会计上的购买方和会计上的被购买方。类比 IFRS 3，由于会计上的被购买方 New Co 不构成业务，不应采用账面价值法（前任会计法）。

因此，最适当的政策是将该交易作为 B 集团业务的资本重组进行会计处理。这将使 New Co 报告 B 集团业务当期及前期资产和负债的账面金额（参见[EX A1.49.1](86.md#s361-EXA1.49.1)）。

请注意，如果 B 集团业务代表不止一个报告主体，则该交易将被视为企业合并。在此情况下，应适用[EX A1.45.1](86.md#s361-EXA1.45.1)中的指引。

如[第A1.46段](86.md#s358-Para_A1.46)所述，这是一个复杂领域，目前指引有限。在其他情形下，New Co 也可能被视为购买方。

正文索引：[A1.49](86.md#s359-Para_A1.49)  
 

  

  
**示例：**

A 主体被一家上市非经营性主体 B 主体以 C188m（A 主体的公允价值）的对价收购。对价由 B 主体的权益股份组成。B 主体净资产的公允价值为 C2m，全部为现金余额。交易后，A 主体的股东持有合并后上市主体 94% 的权益，其余 6% 由 B 主体的股东持有。该交易应如何进行会计处理？

**分析：**

该交易的实质是 A 主体的股东：

- 向 B 主体的股东让渡了其在 A 主体中 6% 的权益（6% × C188m）；并且

- 获得了 C2m 现金的 94% 以及一家上市主体。

视同发行股份的认定成本为 C12m（C188m × 6% / 94%）。该金额代表：如果该交易在法律形式上采取由 A 主体收购 B 主体 100% 股份的方式，为使合并后主体的所有权权益比例保持一致，A 主体原本需要发行的股份的公允价值。
