## 引言与范围（第21.1 - 21.8段）

<a id="s133-Para_21.1"></a>**21.1** 本章阐述国际财务报告准则（IFRS）对无形资产的如下要求：

- 无形资产的初始确认。

- 无形资产的初始计量。

- 初始确认后的后续计量，包括成本模式和重估模式。

- 摊销。

- 终止确认。

- 披露。

无形资产的减值由 IAS 36 规范（参见[第24章第3段](41.md#s154-Para_24.3)）。公允价值由 IFRS 13 规范（参见[第5章第8段](11.md#s33-Para_5.8)）。

<a id="s133-Para_21.2"></a>**21.2** 初始确认和计量、后续计量（包括重估、折旧和减值）、终止确认以及披露要求均由 IAS 38 规范。

[IAS 38 第1段]。

<a id="s133-Para_21.3"></a>**21.3** 可直接归属于符合资本化条件的资产的购置、建造或生产的借款费用构成该资产成本的一部分。[IAS 23 第1段]。在某些情况下，无形资产可能属于符合资本化条件的资产（参见[第22章第45段](39.md#s142-Para_22.45)）。

<a id="s133-chap_21_navPoint_2"></a>
### 范围

<a id="s133-Para_21.4"></a>**21.4** 无形资产被定义为“没有实物形态的可辨认非货币性资产”。

[IAS 38 第8段]。

<a id="s133-Para_21.5"></a>**21.5** 本准则不适用于：

- 在正常经营过程中持有待售的无形资产，例如 IAS 2 规范的存货（[参见第25章第2段](44.md#s164-Para_25.2)）以及根据 IFRS 15 确认的客户合同产生的资产（参见[第11章](19.md#s64-chap_11)）。

- IAS 12 规范的递延所得税资产（参见[第14章第4段](27.md#s96-Para_14.4)）。

- 属于 IFRS 16 范围内的租赁产生的资产（参见[第15章第3段](33.md#s107-Para_15.3)，或关于 IAS 17 参见[第15A章第2段](33.md#s107-Para_15.2)）。

- IAS 19 规范的职工薪酬产生的资产（参见[第12章第3段](23.md#s78-Para_12.3)）。

- IFRS 3 规范的企业合并产生的商誉（参见第29章第26段）。

- 属于 IFRS 4 范围内的保险合同下，保险人合同权利产生的递延获取成本和无形资产（参见[第50章第3段](81.md#s326-Para_50.3)）。不属于 IFRS 4 范围内的递延获取成本属于 IAS 38 的适用范围。IAS 38 的披露要求适用于所有此类无形资产。

- 根据 IFRS 5 分类为持有待售的无形资产（参见[第30章第9段](53.md#s218-Para_30.9)）。

- IAS 32 定义的金融资产（参见[第40章第8段](61.md#s250-Para_40.8)）。

- IFRS 6 规范的勘探与评价资产，以及矿产、石油、天然气和类似非再生资源的开发与开采支出。一旦确定开采非再生资源的技术可行性和商业可行性（开发阶段），则需要应用 IAS 38 中针对内部发生成本的确认标准。[IFRS 6 第10段]。

[IAS 38 第2段]。[IAS 38 第3段]。

<a id="s133-Para_21.6"></a>**21.6** 广告、培训、开办以及研究与开发（R&amp;D）支出均属于 IAS 38 的适用范围。研发活动旨在开发知识。这些活动可能会产生实物资产，但该资产的实物要素相对于其无形要素而言是次要的。在某些情况下，开发支出可能会产生一项无形资产（参见[第21.30段](38.md#s134-Para_21.30)）。

[IAS 38 第5段]。

<a id="s133-Para_21.7"></a>**21.7** 租赁中的标的资产在性质上可能是无形的。租赁交易中的无形资产是否根据 IFRS 16 进行会计处理，取决于无形资产的类型以及主体是承租人还是出租人。更多详情参见[第15章第3段](33.md#s107-Para_15.3)。

[IAS 38 第6段]。

<a id="s133-Para_21.8"></a>**21.8** 承租人根据电影、录像、戏剧、手稿、专利权和版权等项目的许可协议持有的权利属于 IAS 38 的适用范围，并被排除在 IAS 17/IFRS 16 的范围之外。

[IAS 38 第6段]。

<a id="s134-chap_21_navPoint_3"></a>
## 确认（第21.9 - 21.40段）

<a id="s134-chap_21_navPoint_4"></a>
### 一般规则

<a id="s134-Para_21.9"></a>**21.9** 如果某项目符合无形资产的定义（参见[第21.4段](38.md#s133-Para_21.4)）并满足确认标准（参见[第21.16段](38.md#s134-Para_21.16)），则应在财务报表中确认为一项无形资产。

[IAS 38 第18段]。

<a id="s134-Para_21.10"></a>**21.10** 无形资产的关键特征在于：

- 它是主体控制的、预期能为主体带来未来经济利益的资源；

- 没有实物形态；且

- 具有可辨认性，以便与商誉相区分。

[IAS 38 第8段]。

<a id="s134-Para_21.11"></a>**21.11** 如果主体有能力获取标的资源带来的未来经济利益，并能限制他人获取这些利益，则该主体控制该项资产。控制通常由具有法律强制力的合同权利或其他权利（例如法定所有权或牌照）证明。在缺乏法定权利的情况下，证明控制更具挑战性。主体可能通过其他方式控制资产（例如，可以通过保密来控制专有技术带来的利益）。

[IAS 38 第13段]。

[EX 21.11.1 – 客户关系](38.md#s139-EX21.11.1)  
[EX 21.11.2 – 加密货币及其他加密资产的分类和计量](38.md#s139-EX21.11.2)

<a id="s134-Para_21.12"></a>**21.12** 主体通常对其员工队伍所产生的预期未来经济利益缺乏足够的控制，因此不能将员工队伍确认为无形资产。

[IAS 38 第15段]。

[EX 21.12.1 – 支付给新员工的签约奖金](38.md#s139-EX21.12.1)

<a id="s134-Para_21.13"></a>**21.13** 未来经济利益可能包括销售商品或提供服务的收入、成本节约，或主体因使用该资产而获得的其他利益。

[IAS 38 第17段]。

<a id="s134-Para_21.14"></a>**21.14** 某些无形资产可能包含在实物载体中或附着于实物载体上，例如光盘（计算机软件）或法律文件（牌照或专利权）。在这些情况下，实物要素和非实物要素可能无法分离，需要运用判断来确定哪一要素更为重要。如果无形要素更为重要，则该资产应作为无形资产处理。

[IAS 38 第4段]。

[EX 21.14.1 – 将资产归类为有形资产或无形资产](38.md#s139-EX21.14.1)

<a id="s134-Para_21.15"></a>**21.15** 无形资产在满足以下条件之一时具有可辨认性：

- 具有可分离性（即能够从主体中分离或者划分出来，并能单独或者与相关合同、资产或负债一起用于出售、转移、授予许可、租赁或交换）；或

- 源自合同性权利或其他法定权利，无论这些权利是否可以从主体或其他权利和义务中转移或者分离。

[IAS 38 第12段]。

[EX 21.15.1 – 资产的可辨认性](38.md#s139-EX21.15.1)  
  
[EX 21.15.2 – 不可出售或交换的分销网络地图](38.md#s139-EX21.15.2)

<a id="s134-Para_21.16"></a>**21.16** 无形资产的确认标准为：

- 归属于该资产的预期未来经济利益很可能流入主体；且

- 该资产的成本能够可靠计量。

[IAS 38 第21段]。

[FAQ 21.16.1 – 什么是“很可能产生的经济利益”？](38.md#s139-FAQ_21.16.1)

<a id="s134-Para_21.17"></a>**21.17** 主体应使用合理且有依据的假设来评估预期未来经济利益的可能性。这些假设应代表管理层对该资产使用寿命内将存在的一系列经济状况的最佳估计。[IAS 38 第22段]。在评估未来经济利益时，主体可以使用现金流量模型。参见第5章。

<a id="s134-Para_21.18"></a>**21.18** 在根据初始确认日可获得的证据评估使用该资产所预期经济利益流入的确定程度时，需要运用判断。管理层应更多地依赖外部证据。

[IAS 38 第23段]。

[EX 21.18.1 – 外部证据](38.md#s139-EX21.18.1)

<a id="s134-Para_21.19"></a>**21.19** 如果该资产仅在与其他资产组合时才能产生经济利益，则应应用 IAS 36 中关于现金产出单元（CGU）的概念。

[IAS 38 第60段]。

<a id="s134-Para_21.20"></a>**21.20** 主体可能通过多种方式取得无形资产：

- 以货币性或其他对价单独取得；

- 作为企业合并的一部分取得；

- 通过与其他非货币性资产交换取得；

- 通过政府补助取得；或

- 通过内部开发或产生该资产。

在上述每种情况下，确认标准的应用方式有所不同。主体在确定是否满足确认标准时可获得的证据的充分性和可靠性，因具体情况而异。例如，在上述前三种情况中，均存在交换交易，这为经济利益很可能流入主体提供了证据。

<a id="s134-chap_21_navPoint_5"></a>
### 对外购资产应用确认标准

<a id="s134-Para_21.21"></a>**21.21** 对于单独取得的无形资产，始终假定其满足可能性确认标准。支付的价格反映了关于该资产未来经济利益将流入主体的可能性的预期。支付的价格越高，对从该资产获得的未来经济利益的预期就越高。[IAS 38 第25段]。企业合并是一项交换交易。企业合并中取得的无形资产的确认在第29章第110段中阐述。

### 内部产生的无形资产

<a id="s134-Para_21.22"></a>**21.22** 确定内部产生的无形资产是否符合确认条件可能具有挑战性，原因如下：

- 该无形资产能否产生预期未来经济利益存在不确定性；且

- 可能无法可靠地确定该资产的成本，或无法将归属于该资产的成本与维持或提升主体内部产生商誉的成本或开展主体日常经营活动的成本区分开来。

### 研究与开发

<a id="s134-Para_21.23"></a>**21.23** 产生无形资产的过程分为研究阶段和开发阶段。

[IAS 38 第52段]。

<a id="s134-Para_21.24"></a>**21.24** 如果无法区分这两个阶段，则该资产上的所有支出均应归属于研究阶段。

[IAS 38 第53段]。

<a id="s134-Para_21.25"></a>**21.25** “研究”定义为“……为获取新的科学或技术知识和理解而进行的独创性和有计划的调查”。“开发”定义为“……在开始商业性生产或使用前，将研究成果或其他知识应用于某项计划或设计，以生产新的或具有实质性改进的材料、装置、产品、工艺、系统或服务”。

[IAS 38 第8段]。

<a id="s134-chap_21_navPoint_idp1714673896"></a>
#### 研究阶段

<a id="s134-Para_21.26"></a>**21.26** 研究活动的示例包括：

- 旨在获取新知识的活动。

- 寻找研究成果或其他知识的适当应用、评估这些应用并最终选择适当应用的活动。

- 寻找材料、装置、产品、工艺、系统或服务的替代方案。

[IAS 38 第56段]。

[EX 21.26.1 – 研究活动](38.md#s139-EX21.26.1)

<a id="s134-Para_21.27"></a>**21.27** 内部项目研究阶段的支出应在发生时计入当期费用。不得确认由研究或内部项目研究阶段产生的无形资产。

[IAS 38 第54段]。

<a id="s134-Para_21.28"></a>**21.28** 在研究阶段，主体无法证明将会产生未来经济利益。缺乏未来经济利益的可能性意味着该支出既不符合无形资产的定义，也不满足确认标准。

[IAS 38 第55段]。

[EX 21.28.1 – 用于研究与开发项目的无形资产](38.md#s139-EX21.28.1)

<a id="s134-Para_21.29"></a>**21.29** 作为企业合并的一部分取得的研究项目的处理有所不同。[IAS 38 第34段]。在这种情况下，通常会确认一项资产。参见[第21.40段](38.md#s134-Para_21.40)。

[EX 21.29.1 – 企业合并中取得的研究项目](38.md#s139-EX21.29.1)

<a id="s134-chap_21_navPoint_idp1714702696"></a>
#### 开发阶段

<a id="s134-Para_21.30"></a>**21.30** 开发活动的示例包括：

- 生产前或使用前的原型和模型的设计、建造和测试。

- 含新技术的工具、夹具、模具和冲模的设计。

- 不具有商业性生产经济规模的试生产设施的设计、建造和运营。

- 新的或经改进的材料、装置、产品、工艺、系统或服务的所选替代方案的设计、建造和测试。

[IAS 38 第59段]。

<a id="s134-Para_21.31"></a>**21.31** 随着项目进入开发阶段，未来经济利益可能会变得更加明显。项目的开发阶段比研究阶段更为推进。在某些情况下，主体可以在开发阶段识别出一项无形资产。

[IAS 38 第58段]。

[EX 21.31.1 – 研究与开发费用资本化的计量单元](38.md#s139-EX21.31.1)

<a id="s134-Para_21.32"></a>**21.32** 如果主体能够证明以下全部条件，则应确认由开发或内部项目开发阶段产生的无形资产：

- 完成该无形资产以使其能够使用或出售在技术上具有可行性。

- 具有完成该无形资产并使用或出售它的意图。

- 具有使用或出售该无形资产的能力。

- 无形资产产生很可能实现的未来经济利益的方式。除其他因素外，主体必须能够证明运用该无形资产生产的产品存在市场，或者无形资产自身存在市场；如果该资产将在内部使用，则必须能够证明该无形资产的有用性。

- 有足够的技术、财务和其他资源支持，以完成该无形资产的开发，并有能力使用或出售该无形资产。

- 能够可靠地计量归属于该无形资产开发阶段的支出。

[IAS 38 第57段]。

[EX 21.32.1 – 确认标准在产品生命周期各阶段的应用](38.md#s139-EX21.32.1)  
[EX 21.32.2 – 确认标准在制药行业中的应用](38.md#s139-EX21.32.2)  
[EX 21.32.3 – 考虑业务性质及正在开发产品的性质](38.md#s139-EX21.32.3)

<a id="s134-Para_21.33"></a>**21.33** 在项目满足确认为无形资产的标准之前发生的费用，必须在发生时计入当期损益。即使项目后来达到了必须确认资产的阶段，此前已核销的成本也不得恢复为该无形资产的一部分。

[IAS 38 第71段]。

### 不能资本化为内部产生的无形资产的支出

<a id="s134-Para_21.34"></a>**21.34** 对于某些类型的无形资产，无法满足内部产生的无形资产的确认标准。这些项目包括内部产生的品牌、报刊名、出版物标题、客户名单及实质上类似的项目。将这些项目的成本与整个业务的开发成本区分开来极为困难。准则禁止将这些项目确认为无形资产。[IAS 38 第63段]。

<a id="s134-Para_21.35"></a>**21.35** 无法与整个业务的开发成本相区分且应计入当期费用的成本类型示例包括：

- 开办成本，除非根据 IAS 16 计入有形固定资产的成本。应在发生时计入费用的成本包括设立法律主体的筹办费、开设新设施或新业务的支出（开业前成本）以及启动新业务运营或推出新产品或新工艺的支出。

- 培训成本。

- 广告和促销成本，包括邮购目录。

- 搬迁费用。

- 全部或部分主体的重组成本。

<a id="s134-chap_21_navPoint_9"></a>
### 企业合并中取得的资产

<a id="s134-Para_21.37"></a>**21.37** 无论被购买方在企业合并前是否已确认该资产，购买方均应确认被购买方的无形资产。

[IAS 38 第34段]。

<a id="s134-Para_21.38"></a>**21.38** 对于企业合并中取得的无形资产，始终假定其满足可能性确认标准。无形资产的公允价值反映了市场参与者在购买日对蕴含在该资产中的预期未来经济利益将流入主体的可能性的预期。

[IAS 38 第33段]。

<a id="s134-Para_21.39"></a>**21.39** 对于企业合并中取得的无形资产，可靠计量标准将始终得到满足（参见[第21.39段](38.md#s134-Para_21.39)）。如果取得的资产具有可分离性或源自合同性权利，则存在足够的信息以可靠地计量该资产的公允价值。

[IAS 38 第33段]。

<a id="s134-Para_21.40"></a>**21.40** 如果被购买方的在研研究与开发项目满足以下条件，则应予以确认：

- 符合资产的定义；且

- 具有可辨认性（即具有可分离性，或源自合同性权利或其他法定权利）。

### 云计算安排中的成本

<a id="s134-Para_21.40.1"></a>**21.40.1** 云计算是一种通过基于网络的工具和应用程序交付信息技术服务的模式。软件即服务（SaaS）就是其中的一个例子。在此类合同中，客户通常既不取得软件许可，也无权占有该软件。合同授予客户在合同期内访问供应商应用软件的权利。该访问权并未向客户提供软件资产，因此，对软件的访问是客户在合同期内接受的一项服务。软件通常保留在卖方的硬件上，买方仅通过互联网连接访问该软件。

国际财务报告准则解释委员会（IFRS IC）于2019年3月发布了关于 SaaS 安排处理的议程决议。2019年3月的议程决议从整体上考虑了 SaaS 安排的会计处理。它指出了安排在何种情况下可能作为服务进行会计处理（如果主体未获得占有软件的权利，云计算通常属于此类情况），以及在何种情况下可能构成无形资产或租赁。

[IFRIC 议程决议 2019年3月]。

<a id="s134-chap_21_navPoint_11"></a>
### 什么是云计算安排中的配置或定制成本（CC）？

<a id="s134-Para_21.40.2"></a>**21.40.2** 许多主体会为 SaaS 安排支付费用，并在接受服务前支付额外款项，以根据自身特定需求配置和/或定制这些服务。例如，主体可能签订了人力资源系统的 SaaS 安排，但希望对其进行定制以创建额外的报告功能。在促成该议程决议的讨论文件中，国际会计准则理事会（IASB）工作人员将配置或定制成本定义如下：

(i) 配置：典型的配置涉及在软件内设置各种“标记（flags）”或“开关（switches）”，或定义某些值或参数，以针对软件的现有功能实现特定设置。配置不涉及修改或编写额外的软件代码，而是涉及设置软件的现有代码，使其以特定方式运行以使主体受益。

(ii) 定制：典型的定制涉及修改应用程序中的现有软件代码或编写额外代码。大幅更改或添加软件代码的效果通常是改变软件内的功能或创建额外功能，从而使其能够提供预期利益。

配置或定制可能由客户自身、SaaS 提供商或第三方执行，并且相对于 SaaS 安排的总成本而言，往往构成一项重大成本。

[IFRIC 议程决议 2021年3月]。

### 根据 IAS 38 进行资本化

<a id="s134-Para_21.40.4"></a>**21.40.4** SaaS 系统的实施通常很复杂，可能会发生多种成本。确定其中某些成本是否符合 IAS 38 第8–17段的定义需要运用判断。IFRS IC 指出，在提交请求所述的 SaaS 安排中，客户通常不会确认与请求中定义为配置或定制活动相关的无形资产。这是因为主体不控制所配置或定制的软件，且配置或定制活动并未创造出独立于该软件的、由客户控制的资源。

SaaS 安排可能由 SaaS 接受方自行配置或定制，如果满足 IAS 38 第57段的标准，与配置或定制及其他设置成本相关的支出将计入符合资本化条件的成本。主体应以与任何其他研发项目相同的方式，考虑这些成本是否会产生内部产生的无形资产并满足资本化标准（[IAS 38 第57段]）。

### 配置或定制服务是否可与 SaaS 安排明确区分？

<a id="s134-Para_21.40.5"></a>**21.40.5** 如果主体得出结论认为该成本不符合无形资产的定义，则应评估该成本能否资本化为预付款项，还是必须在发生时计入费用。IAS 38 要求主体在接受服务时将服务成本计入费用。当供应商按照合同履行服务时（而非主体使用该服务时），即视为接受了服务。

[IAS 38 第69段]。[IAS 38 第69A段]。

IAS 38 并未就“由供应商履行”的含义提供任何指引，也未就识别从供应商处接受的服务提供指引。IFRS IC 建议主体参考 IFRS 15《客户合同收入》中的标准，以确定可能影响供应商何时履行服务的服务性质。主体应了解是谁在履行该服务（第三方还是 SaaS 提供商），并按照 IFRS 15 中的标准判断该服务是否可与 SaaS 履约义务明确区分，从而得出服务何时履行的结论。

为确定配置或定制服务是否可与 SaaS 安排明确区分，主体应参考 IFRS 15 中的标准。如果承诺可明确区分，定制成本将在定制期间确认；如果承诺不可明确区分，定制成本将确认为预付款项，并在整个 SaaS 安排期间分摊。在某些情况下，作出这一判断可能具有挑战性，因为 IFRS 15 中的标准是出于收入确认的目的而制定的，而非从客户角度出发的成本资本化。

根据 IFRS 15，如果同时满足以下两项条件，则向客户承诺的商品或服务是可明确区分的：

- 客户能够从该商品或服务本身或从该商品或服务与其他易于获得的资源一起使用中受益（即该商品或服务本身能够明确区分）；且

- 主体向客户转让该商品或服务的承诺与合同中的其他承诺可单独区分（即在合同的语境下，转让该商品或服务的承诺是可明确区分的）。

因此，评估商品或服务是否可明确区分包含两个要素；该商品或服务必须同时满足：(a) 本身能够明确区分；且 (b) 可单独区分。

[IFRS 15 第27段]。

如果配置或定制风险与 SaaS 服务风险不可明确区分，主体将得出结论认为尚未收到与配置或定制付款相关的服务。因此，为配置或定制支付的款项将构成与合并 SaaS 安排相关的预付款项。该预付款项将在根据 SaaS 安排提供合并商品或服务时确认为费用。

[IFRIC 议程决议 2021年3月]。[IAS 38 第69段]。

## 初始计量（第21.41 - 21.71段）

<a id="s135-Para_21.41"></a>**21.41** 无形资产在初始确认时应按成本计量。

[IAS 38 第24段]。

<a id="s135-Para_21.42"></a>**21.42** 成本定义为在取得或建造某项资产时所支付的现金或现金等价物的金额，或所付出的其他对价的公允价值。或者，在适用情况下，成本为根据其他国际财务报告准则（如 IFRS 2）的具体要求在初始确认时归属于该资产的金额。

[IAS 38 第8段]。

<a id="s135-chap_21_navPoint_17"></a>
### 单独取得的无形资产的计量

<a id="s135-Para_21.43"></a>**21.43** 单独取得的无形资产（包括在研研究与开发项目）的成本通常能够可靠计量。对于以现金取得的资产而言尤其如此。

[IAS 38 第26段]。

<a id="s135-Para_21.44"></a>**21.44** 单独取得的无形资产的成本包括：

- 购买价款，包括进口关税和不可退还的购买税费，扣除商业折扣和回扣；以及

- 为使该资产达到预定用途而发生的任何直接归属成本。

[IAS 38 第27段]。

<a id="s135-Para_21.45"></a>**21.45** 直接归属成本包括但不限于：

- 使资产达到工作状态而直接产生的职工薪酬成本（如 IAS 19 所定义）（参见[第21.63段](38.md#s135-Para_21.63)）。

- 专业服务费。

- 测试资产是否正常运转的成本。

[IAS 38 第28段]。

[FAQ 21.45.1 – 关于直接归属成本的指引是否适用于单独取得的资产？](38.md#s139-FAQ_21.45.1)

<a id="s135-Para_21.46"></a>**21.46** 不构成无形资产成本的支出包括：

- 引入新产品或新服务的成本，包括广告费和促销活动费用。

- 在新地点或面向新客户群体开展业务的成本，包括培训成本。

- 行政管理费和其他一般间接费用。

[IAS 38 第29段]。

<a id="s135-Para_21.47"></a>**21.47** 当资产能够按照管理层意图的方式运行时，符合条件的成本应停止资本化。使用该资产或将其重新部署至其他用途或其他地点的成本不予资本化。此类成本包括在资产能够按照管理层意图的方式运行期间发生的任何成本，以及任何初始经营亏损（例如在资产产出的市场需求逐步形成期间可能发生的亏损）。

[IAS 38 第30段]。

<a id="s135-Para_21.48"></a>**21.48** 在开发无形资产的过程中，可能会发生一些并非使资产达到预定工作状态所必需的活动。与这类非必需的附带经营活动相关的收益和支出不应资本化，而应计入当期费用。

[IAS 38 第31段]。

<a id="s135-chap_21_navPoint_18"></a>
### 购买无形资产的可变或或有对价的处理

<a id="s135-Para_21.49"></a>**21.49** 主体可能以一笔初始付款加上视未来事项、结果或所购资产最终售价高于门槛价格而定的约定额外付款来取得一项无形资产。如果未来事项或条件发生，主体通常负有支付额外款项的合同义务或法定义务。这通常被称为资产的可变或或有对价。IFRS IC 曾讨论过资产或有对价的会计处理。委员会认定该议题过于宽泛，未将其列入议程。特别是，委员会未能就主体（购买方）“是在购买资产之日就取决于其未来活动的可变付款确认一项负债，还是仅在相关活动发生时才确认此类负债”达成共识。委员会还指出，“关于购买资产后可变付款的会计处理存在疑问”。委员会建议 IASB 对此问题进行全面研究。

[IFRIC 议程决议 – 2016年3月]。

<a id="s135-Para_21.50"></a>**21.50** 需要仔细分析该安排，以确定未来付款是否与资产成本相关。与资产成本无关的成本应在发生时计入费用。委员会决定不以解释公告或议程决议的形式就如何应用现有指引提供指导。因此，没有具体适用于此类交易的国际财务报告准则。如果确定未来付款与资产成本相关，主体应遵循 IAS 8《会计政策、会计估计变更和差错》，为取得无形资产的或有对价制定会计政策。实务中对取得资产的或有对价的会计处理存在差异，有三种可能的方法：

1. 金融负债模式

无形资产在取得时按包含未来或有付款公允价值的金额初始确认，同时按相同的公允价值确认一项金融负债。此后，该金融负债按照 IFRS 9 的要求以摊余成本计量。每当现金流量估计发生修订时，主体应调整金融负债的账面价值，以反映实际和更新后的估计现金流量。主体按照该金融工具的原始实际利率（或如适用，根据 IFRS 9 第 B5.4.6 段计算的经修订实际利率）计算估计未来现金流量的现值，从而重新计算负债的账面价值。负债计量的后续变动与资产成本无关。因此，该调整作为收益或费用计入损益。

2. 成本累积模式

无形资产在取得日按已支付的成本初始确认。取得时资产的账面价值不包含可变付款，也不就或有对价确认负债。主体不确认负债是因为根据议程决议，在不确定性消除之前并不明确存在义务。委员会在2016年议程决议中也指出，关于后续付款的会计处理尚有未决问题。因此，主体可以选择在支付可变付款时将其资本化为资产成本的一部分，理由是这些付款代表了直接取得成本。这种处理通常仅在可变付款的变动是由资产的效用引起时才可接受。如果变动是由与资产无关的其他因素引起的，则该部分可变付款的会计处理通常应遵循国际财务报告准则的适用指引。

[IAS 38 第25段]。

3. IFRIC 1 方法

无形资产在取得日按包含对未来预期可变成本的估计金额初始确认。同时确认一项负债。该负债随后以摊余成本计量，与上述方法1类似。然而，负债的后续变动将针对资产成本予以确认。这种处理通常仅在可变付款的变动是由资产的效用引起时才可接受。如果变动是由与资产无关的其他因素引起的，则成本变动通常应遵循国际财务报告准则的适用指引。

[IFRIC 1 第4段]。[IFRIC 1 第5段]。

在对可变或或有对价进行会计处理时，上述所有方法均可接受。这是一项会计政策选择，应对所有类似交易一贯应用并予以适当披露。进一步讨论参见[第22章第32段](39.md#s142-Para_22.32)。

### 延期付款条款

<a id="s135-Para_21.51"></a>**21.51** 如果购买无形资产的付款期限超出正常信用条件，该资产的成本为其现金价格等价物，即折现后的金额。

[IAS 38 第32段]。

<a id="s135-Para_21.52"></a>**21.52** 折现金额与总付款额之间的差额在信用期内作为应付利息处理，除非其符合 IAS 23 规定的资本化条件。[IAS 38 第32段]。关于借款费用资本化，参见第22章第42段。

<a id="s135-chap_21_navPoint_20"></a>
### 以发行股份取得的资产

<a id="s135-Para_21.53"></a>**21.53** 以发行股份取得的无形资产的成本根据 IFRS 2 计量。以股份换取的商品或服务应按所取得商品或服务的公允价值计量。对于与职工以外的各方进行的交易，存在一项可反驳的假定，即公允价值能够可靠计量。但是，如果所取得商品或服务的公允价值无法可靠计量，主体应参照所授予权益工具的公允价值间接计量其公允价值。

[IFRS 2 第13段]。

[EX 21.53.1 – 发行股份作为取得无形资产的对价](38.md#s139-EX21.53.1)

<a id="s135-chap_21_navPoint_21"></a>
### 以非货币性资产交换取得的资产

<a id="s135-Para_21.54"></a>**21.54** 以非货币性资产或非货币性资产与货币性资产组合交换取得的无形资产，应按公允价值初始确认，除非：

- 该交换交易不具有商业实质；或

- 换入资产和换出资产的公允价值均不能可靠计量。

[IAS 38 第45段]。

[EX 21.54.1 – 专利权交换](38.md#s139-EX21.54.1)  
[EX 21.54.2 – 对价包含非货币性资产和货币性资产的组合](38.md#s139-EX21.54.2)

<a id="s135-Para_21.55"></a>**21.55** 交易是否具有商业实质取决于主体未来现金流量预期因该交易而发生变动的程度。“现金流量配置”是指现金流量的风险、时间和金额。如果满足以下条件之一，则交换交易具有商业实质：

- 换入资产的现金流量配置与换出资产的现金流量配置不同；或

- 受交易影响的主体某部分经营活动的特定主体价值因该交换而发生变动，

且上述任一情况下的差额相对于所交换资产的公允价值而言是重大的。

[IAS 38 第46段]。

[EX 21.55.1 – 以研究与开发项目交换营销权](38.md#s139-EX21.55.1)

<a id="s135-Para_21.56"></a>**21.56** “特定主体价值”定义为“……主体预期因持续使用某项资产并在其使用寿命结束时处置该资产而产生的现金流量的现值，或者预期因清偿一项负债而发生的现金流量的现值”。

[IAS 38 第8段]。

[EX 21.56.1 – 电话牌照交换](38.md#s139-EX21.56.1)

<a id="s135-Para_21.57"></a>**21.57** 现金流量分析的结果可能显而易见，主体无需进行详细计算。

[IAS 38 第46段]。

[EX 21.57.1 – 交换交易产生的利得或损失](38.md#s139-EX21.57.1)

<a id="s135-Para_21.58"></a>**21.58** 缺乏市场交易并不意味着无法确定公允价值。如果满足以下条件之一，换出资产或换入资产的公允价值仍能可靠计量：

- 公允价值的合理估计区间变动不重大（即该区间较为狭窄）；或

- 合理估计区间并不狭窄，但能够合理评估该区间内各种估计的概率，并将其用于估计公允价值。

如果换出资产和换入资产的公允价值均能以同等可靠性进行估计，则采用换出资产的公允价值来计量换入资产的成本。

[IAS 38 第47段]。

<a id="s135-chap_21_navPoint_22"></a>
### 政府补助

<a id="s135-Para_21.59"></a>**21.59** 无形资产有时可能通过政府补助免费或以名义金额取得。示例包括机场着陆权和进口配额的分配。此类无形资产可以按公允价值或名义金额确认。这是 IAS 20 下的一项会计政策选择。主体为使资产达到预定用途而发生的任何直接归属支出也应计入该无形资产的初始计量。如果主体选择按公允价值确认该资产，则应使用适当的方法确定公允价值。政府补助由 IAS 20 规范（参见[第17章第2段](37.md#s125-Para_17.2)）。

[IAS 38 第44段]。

<a id="s135-chap_21_navPoint_23"></a>
### 受赠资产的成本

<a id="s135-Para_21.60"></a>**21.60** 在特殊情况下，主体可能通过无偿捐赠或出资（无对价且未发行股份）取得某项资产。国际财务报告准则对此类交易没有具体指引。主体应制定会计政策并一贯应用。实务中通常观察到两种方法：在主体获得资产控制权时按公允价值确认资产；或按零值确认资产。

<a id="s135-chap_21_navPoint_24"></a>
### 内部产生的无形资产的计量

<a id="s135-Para_21.61"></a>**21.61** 符合确认标准的内部产生的无形资产的成本，是为创建、生产和准备该资产使其能够按照管理层意图的方式运行而发生的直接归属支出之和。

[IAS 38 第66段]。

<a id="s135-Para_21.62"></a>**21.62** 直接归属成本的示例包括：

- 在产生无形资产过程中使用或消耗的材料和服务成本。

- 产生该资产直接引起的职工薪酬成本（如 IAS 19 所定义）。

- 为注册法定权利而支付的费用，如专利注册费。

- 用于产生该资产的专利权和牌照的摊销。

- 符合条件可资本化为成本一部分的借款费用。借款费用由 IAS 23 规范（参见第22章第42段）。

[IAS 38 第66段]。

[FAQ 21.62.1 – 哪些职工薪酬成本可以资本化？](38.md#s139-FAQ_21.62.1)

<a id="s135-Para_21.63"></a>**21.63** 测试某项目是否正常运转的成本是单独取得的无形资产的直接归属成本。[IAS 38 第28段]。对于内部产生的无形资产而言，测试成本也构成有效的成本。

<a id="s135-Para_21.6"></a>**21.64** 只有可直接归属于产生无形资产的成本才能资本化。非“直接归属”的一般经营成本不属于内部产生的无形资产的成本组成部分，包括以下各项：

- 销售费、行政管理费和其他一般间接费用，除非这些费用能够直接归属于使资产达到使用状态的准备工作。

- 在资产达到计划性能之前发生的低效率损失和初始经营亏损。

- 培训将操作该资产的员工的成本。

[IAS 38 第67段]。

[EX 21.64.1 – 与主体数据库相关的促销成本和经营亏损](38.md#s139-EX21.64.1)

<a id="s135-Para_21.65"></a>**21.65** 当资产“能够按照管理层意图的方式运行”时，成本资本化即应停止。一项资产可能已内部产生（建造完成）并能够立即以该方式运行，但尚未投入使用。资产闲置期间发生的成本不得资本化。

[IAS 38 第30段]。

[EX 21.65.1 – 员工成本何时可以资本化](38.md#s139-EX21.65.1)

<a id="s135-Para_21.66"></a>**21.66** 初始经营亏损（例如在项目产出的市场需求逐步形成期间可能发生的亏损）不应资本化。

[IAS 38 第30段]。

<a id="s135-chap_21_navPoint_25"></a>
### 网站成本

<a id="s135-Para_21.67"></a>**21.67** 为供内部或外部访问而开发的网站属于 IAS 38 下内部产生的无形资产。SIC-32 对该议题提供了进一步指引。相关成本必须满足 IAS 38 中无形资产的确认标准，方有资格确认为资产。参见[第21.31段](38.md#s134-Para_21.31)。

<a id="s135-Para_21.68"></a>**21.68** 能够产生收入（包括来自电子商务的直接收入）的网站将满足未来很可能产生经济利益的要求。网站本身可能包含所销售的产品（如信息），并可能通过收费注册的方式提供访问权限。仅为推广或宣传主体产品或服务而开发的网站不符合确认标准。所有支出均在发生时计入费用。

[SIC-32 第8段]。[IAS 38 第57(d)段]。

<a id="s135-Para_21.69"></a>**21.69** 必须评估开发网站各阶段发生的成本，以确定应在发生时计入费用还是予以资本化。SIC-32 包含一份详细的附录，说明了各阶段可能发生的支出的性质以及相应的会计处理。

[SIC-32 第8段]。

[EX 21.69.1 – 开发网站各阶段发生成本的会计处理](38.md#s139-EX21.69.1)

<a id="s135-chap_21_navPoint_26"></a>
### 企业合并中取得的无形资产的计量

<a id="s135-Para_21.70"></a>**21.70** 企业合并中取得的无形资产的成本为其购买日的公允价值。

[IAS 38 第33段]。

<a id="s135-Para_21.71"></a>**21.71** 购买方的意图或特定情况与公允价值的计量无关，因为公允价值并非特定于主体的。购买方在确认和计量公允价值时采用其他市场参与者方法。公允价值应假定市场参与者对该资产的最佳用途进行计量。参见[第5章第8段](11.md#s33-Para_5.8)。

[IFRS 3 附录 B 第 B43 段]。

## 初始确认后的后续计量（第21.72 - 21.133段）

<a id="s136-chap_21_navPoint_28"></a>
### 后续支出

<a id="s136-Para_21.72"></a>**21.72** 许多无形资产的性质决定了通常不存在对资产的增置或部分替换。大多数后续支出很可能是为维持资产而发生的，通常不符合确认为资产的标准。往往很难将后续支出归属于某项特定的无形资产，而非归属于整个业务。大多数后续支出将在发生时计入费用。品牌、报刊名、出版物标题、客户名单及实质上类似项目的后续支出始终在发生时计入费用。无论该资产最初是外购的还是内部产生的，均适用此规定。

[IAS 38 第20段]。

<a id="s136-Para_21.73"></a>**21.73** 针对研究与开发项目所取得的无形资产的后续成本，遵循 IAS 38 中关于内部产生的无形资产的指引。这意味着后续支出按如下方式进行会计处理：

- 后续研究支出在发生时计入费用。

- 不满足确认为资产条件的后续开发支出计入费用。

- 满足确认为资产条件的后续开发支出计入该无形资产的账面价值。

[IAS 38 第43段]。

<a id="s136-chap_21_navPoint_29"></a>
### 成本模式与重估模式简介

<a id="s136-Para_21.74"></a>**21.74** 主体可以在初始确认后选择成本模式或重估模式作为其会计政策。只有在无形资产存在活跃市场的情况下才能采用重估模式，因此重估模式并不常用。该政策应应用于整个类别的无形资产，而不仅仅是某类别中的单项资产，除非某项单项资产不存在活跃市场。

[IAS 38 第72段]。

<a id="s136-Para_21.75"></a>**21.75** 成本模式要求无形资产在初始确认后，以成本减去累计摊销和减值损失后的金额列示。

[IAS 38 第74段]。

<a id="s136-Para_21.76"></a>**21.76** 重估模式要求无形资产在初始确认后，以参照活跃市场确定的公允价值列示。重估应具有足够的规律性，以使资产在资产负债表日的账面价值不致与使用公允价值确定的金额存在重大差异。

[IAS 38 第75段]。

<a id="s136-chap_21_navPoint_30"></a>
### 无形资产的类别

<a id="s136-Para_21.77"></a>**21.77** 主体可以采用符合以下定义的资产类别：“在主体经营中具有相似性质和用途的一组资产”。

[IAS 38 第73段]。

<a id="s136-Para_21.78"></a>**21.78** 除排除按地理区域划分的资产类别外，这一定义具有相当的灵活性。主体可以采用适合其业务的有意义的类别。大多数公司拥有若干宽泛划分的无形资产类别。无形资产类别的示例包括：

- 品牌名称。

- 报刊名和出版物标题。

- 牌照和特许经营权。

- 版权、专利权和其他工业产权、服务权及经营权。

- 配方、公式、模型、设计和原型。

- 开发中的无形资产。

- 排放权。

- 商誉。

[IAS 38 第119段]。

<a id="s136-Para_21.79"></a>**21.79** 如果进一步细分或合并上述清单中的项目能为财务报表使用者提供更相关的信息，则可以进行细分或合并。

[IAS 38 第119段]。

[EX 21.79.1 – 无形资产的进一步分类](38.md#s139-EX21.79.1)

<a id="s136-chap_21_navPoint_31"></a>
### 重估模式的应用

<a id="s136-Para_21.80"></a>**21.80** 只有在无形资产按成本初始确认和计量后，才能采用重估模式对其进行计量。该方法不能用于在初始确认时以成本以外的价值记录无形资产。该方法不能应用于此前未确认为无形资产的无形资产。

[IAS 38 第76段]。

[EX 21.80.1 – 此前未确认为无形资产的牌照](38.md#s139-EX21.80.1)

<a id="s136-Para_21.81"></a>**21.81** 重估模式也可以应用于通过政府补助取得并在初始确认时按名义金额计量的资产。如果资产是免费取得的，该名义金额可能为零（参见[第21.60段](38.md#s135-Para_21.60)）。

[IAS 38 第77段]。

<a id="s136-Para_21.82"></a>**21.82** 活跃市场可能不再存在，且重估资产的公允价值可能无法再参照活跃市场确定。此时账面价值应冻结在最近一次估值日的重估金额。随后该账面价值按正常方式进行摊销和减值处理。当无法再参照活跃市场计量时，此前确认的重估盈余不得转回。

[IAS 38 第82段]。

<a id="s136-Para_21.83"></a>**21.83** 缺乏活跃市场可能是减值的迹象，需要执行减值测试。

[IAS 38 第83段]。

<a id="s136-Para_21.84"></a>**21.84** 如果此后可以再次参照活跃市场对该资产进行估值，则应自该日起按照其所属类别所采用的重估模式对该资产进行重估。

[IAS 38 第84段]。

<a id="s136-Para_21.85"></a>**21.85** 唯一允许的估值基础是参照活跃市场确定的公允价值。活跃市场的定义包含在 IFRS 13 中（[参见第5章第92段](11.md#s33-Para_5.92)）。只有少数类型的无形资产存在活跃市场，重估模式仅在存在此类市场时方可使用。在某些司法管辖区，可自由转让的出租车牌照、捕鱼许可证或生产配额可能存在活跃市场。排放权如果存在活跃市场，也是一个例子。

[IAS 38 第78段]。

[FAQ 21.85.1 – 网站能否采用重估模式？](38.md#s139-FAQ_21.85.1)

<a id="s136-Para_21.86"></a>**21.86** 品牌、报纸报刊名、音乐和电影版权、专利权或商标不可能存在活跃市场，因为每一项此类资产都是独一无二的。尽管此类独特的无形资产可以买卖，但价格是由单个买方和卖方协商确定的，而非在活跃市场上报价。此类买卖交易相对较少。在一项交易中为某项资产支付的价格可能不足以作为另一项资产公允价值的良好指引。

[IAS 38 第78段]。

[EX 21.86.1 – 香烟品牌名称的购买与出售](38.md#s139-EX21.86.1)

<a id="s136-chap_21_navPoint_32"></a>
### 重估频率

<a id="s136-Para_21.87"></a>**21.87** 估值应保持最新才能具有意义。重估应具有足够的规律性，以使资产负债表日的账面价值不致与公允价值存在重大差异。

[IAS 38 第75段]。

<a id="s136-Para_21.88"></a>**21.88** 重估频率取决于无形资产公允价值的变动情况。某些无形资产的市场价格可能出现重大且剧烈的波动，因而需要每年进行估值。市场价格应当相对容易获取，年度重估也较为直接（参见第5章）。市场价格相对稳定的无形资产可能不需要如此频繁的估值。

[IAS 38 第79段]。

<a id="s136-chap_21_navPoint_33"></a>
### 重估模式下累计摊销的处理

<a id="s136-Para_21.89"></a>**21.89** 当对该无形资产进行重估时，资产的账面价值调整为重估金额。在重估日，该资产按以下方式之一进行处理：

- 以与资产账面价值重估一致的方式调整账面总额（例如，可以参照可观察市场数据重述账面总额，或按账面价值的变动比例重述）。重估日的累计摊销经调整后，等于考虑累计减值损失后的账面总额与资产账面价值之间的差额。

- 将累计摊销与资产账面总额相抵销。

[IAS 38 第80段]。

<a id="s136-Para_21.90"></a>**21.90** 累计摊销的调整金额构成账面价值增加或减少的一部分，作为重估利得或损失的一部分进行会计处理。

[IAS 38 第80段]。

<a id="s136-chap_21_navPoint_34"></a>
### 重估利得

<a id="s136-Para_21.91"></a>**21.91** 重估增值应计入其他综合收益（OCI），并在权益中以重估盈余项目累计，除非其转回了同一项资产此前确认为费用的重估减值。此前重估减值的转回，在原减值确认为费用的范围内贷记损益。

[IAS 38 第85段]。

<a id="s136-Para_21.92"></a>**21.92** 计入权益的重估盈余可以在盈余实现时（即资产报废或处置时）直接转入留存收益。

[IAS 38 第87段]。

<a id="s136-Para_21.93"></a>**21.93** 随着主体使用该资产（即随着盈余的实现），部分盈余也可以直接转入留存收益。转入金额为基于资产重估账面价值计算的摊销与基于资产原始成本计算的摊销之间的差额。该金额可以直接从重估盈余转入留存收益（储备结转）。

[IAS 38 第87段]。

**相关信息**

<a id="s136-chap_21_navPoint_35"></a>
### 重估损失

<a id="s136-Para_21.94"></a>**21.94** 重估减值应计入损益。如果同一项资产在重估盈余中存在贷方余额，则减值应计入其他综合收益（OCI）。计入其他综合收益（OCI）的减值同时冲减权益中在重估储备项目下累计的金额。

[IAS 38 第86段]。

<a id="s136-chap_21_navPoint_36"></a>
### 摊销

<a id="s136-Para_21.95"></a>**21.95** 摊销定义为“无形资产的可折旧金额在其使用寿命内的系统分摊”。可折旧金额定义为资产的“成本或替代成本的其他金额减去其残值”。

[IAS 38 第8段]。

<a id="s136-Para_21.96"></a>**21.96** 除使用寿命不确定的无形资产外，所有无形资产（无论是按成本还是按公允价值持有）均适用摊销。

[IAS 38 第89段]。

<a id="s136-Para_21.97"></a>**21.97** 资产一旦可供使用——即处于能够按照管理层意图的方式运行所需的地点和状态时，即应开始摊销。

[IAS 38 第97段]。

[EX 21.97.1 – 产品分销权的摊销](38.md#s139-EX21.97.1)

<a id="s136-Para_21.98"></a>**21.98** 摊销应在无形资产终止确认之日与根据 IFRS 5 分类为持有待售之日两者中较早者停止。无形资产的终止确认自[第21.134段](38.md#s137-Para_21.134)起讨论。当无形资产满足 IFRS 5 规定的分类条件时，按该准则分类为持有待售（参见[第30章第10段](53.md#s218-Para_30.10)）。

[IAS 38 第97段]。

<a id="s136-Para_21.99"></a>**21.99** 当资产仍被保留但不再使用时，摊销并不停止，除非该资产已全额摊销或根据 IFRS 5 分类为持有待售。

[IAS 38 第117段]。

<a id="s136-Para_21.100"></a>**21.100** 使用寿命不确定的无形资产不应摊销。

[IAS 38 第107段]。

<a id="s136-chap_21_navPoint_37"></a>
### 使用寿命——有限与不确定

<a id="s136-Para_21.101"></a>**21.101** 使用寿命定义为：

- 主体预期资产可供使用的期间；或

- 主体预期从资产中获得的产量或类似计量单位数。

[IAS 38 第8段]。

[FAQ 21.101.1 – 使用寿命涵盖哪些期间？](38.md#s139-FAQ_21.101.1)

<a id="s136-Para_21.102"></a>**21.102** 管理层应评估无形资产的使用寿命是有限的还是不确定的。如果根据所有相关因素分析，无法预见该资产预期为主体产生现金净流入的期限，则该无形资产应视为使用寿命不确定。

[IAS 38 第88段]。

<a id="s136-Para_21.103"></a>**21.103** IAS 38 提供了估计使用寿命时需考虑因素的指引，包括：

- 主体对该资产的预期使用情况，以及另一管理团队能否有效管理该资产。

- 该资产的典型产品生命周期，以及以类似方式使用的类似资产使用寿命的公开信息。

- 技术、工艺、商业或其他类型的过时。

- 该资产所在行业的稳定性，以及该资产产出或相关产品或服务的市场需求变化。

- 现实或潜在竞争对手的预期行动。

- 维持该资产运营能力所需的维护水平，以及管理层是否打算实施该水平的维护。

- 主体对该资产拥有控制权的期间，以及对该资产使用的任何法定或类似限制。

- 该资产的使用寿命是否依赖于主体其他资产的使用寿命。

[IAS 38 第90段]。

[EX 21.103.1 – 估计资产使用寿命时需考虑的其他因素](38.md#s139-EX21.103.1)  
[EX 21.103.2 – 购买方不打算使用或打算以不同于其他市场参与者的方式使用的无形资产的使用寿命](38.md#s139-EX21.103.2)

<a id="s136-Para_21.104"></a>**21.104** 许多类型的无形资产（包括计算机软件和网站）易受技术快速变革导致的技术过时的影响。其使用寿命很可能是有限的且相对较短。

[IAS 38 第92段]。[SIC-32 第10段]。

<a id="s136-Para_21.105"></a>**21.105** 不确定性为谨慎估计使用寿命提供了理由，但并不构成选择不切实际地过短的使用寿命的理由。

[IAS 38 第93段]。

<a id="s136-Para_21.106"></a>**21.106** 除明显通过消耗而使用的资产（如矿产资源）外，使用寿命通常参照时间期限确定。经济因素和法定因素均可能影响无形资产的使用寿命。经济因素决定了主体将获得未来经济利益的期限。某些无形资产的使用寿命受合同性权利或其他法定权利持有期限的限制。此类资产的使用寿命为经济因素所决定的期限与合同性或其他法定因素所决定的期限两者中的较短者。

[IAS 38 第95段]。

[EX 21.106.1 – 版权的法定寿命超过经济寿命](38.md#s139-EX21.106.1)

<a id="s136-Para_21.107"></a>**21.107** 合同性权利或法定权利通常在有限期间内授予。仅当法定权利可续期且有证据支持主体无需付出重大成本即可续期时，相关无形资产的使用寿命方可超过该期间。

[IAS 38 第94段]。

<a id="s136-Para_21.108"></a>**21.108** 支持无需付出重大成本即可续期的证据如下：

- 证明合同性权利或法定权利将获续期的证据（可能基于以往经验）。这包括在需要第三方同意的情况下，证明将获得此类同意的证据。

- 证明获得续期所需的任何条件均将得到满足的证据。

- 证明与预期因续期而流入主体的未来经济利益相比，主体为续期付出的成本并不重大的证据。

[IAS 38 第96段]。

<a id="s136-Para_21.109"></a>**21.109** 如果与预期流入主体的未来经济利益相比续期成本重大，则该续期成本在实质上是在续期日取得一项新无形资产的成本。

[IAS 38 第96段]。

[EX 21.109.1 – 如何对被替换资产的账面价值及续期成本进行会计处理](38.md#s139-EX21.109.1)  
[EX 21.109.2 – 广播牌照的确定续期](38.md#s139-EX21.109.2)  
[EX 21.109.3 – 无续期保证的广播牌照](38.md#s139-EX21.109.3)

<a id="s136-Para_21.110"></a>**21.110** 企业合并中重新取得的权利（例如购买方此前授予被购买方的特许经营权）的使用寿命为该权利授予的剩余合同期限，不应包括续期期间。

[IAS 38 第94段]。

<a id="s136-Para_21.111"></a>**21.111** “不确定（Indefinite）”并不等同于“无限（infinite）”（即在范围上没有尽头）。无形资产的使用寿命仅反映维持初始估计该资产使用寿命时所评估的运营能力所必需的未来维护水平（以及管理层实施此类维护的能力和意图）。估计使用寿命时不考虑超出维持该资产运营能力所需水平的任何计划未来支出。

[IAS 38 第91段]。

[EX 21.111.1 – 确定使用寿命不确定时的其他考虑因素](38.md#s139-EX21.111.1)  
[EX 21.111.2 – 客户关系的使用寿命](38.md#s139-EX21.111.2)  
[EX 21.111.3 – 主要行业中常见的使用寿命特征](38.md#s139-EX21.111.3)

<a id="s136-chap_21_navPoint_38"></a>
### 使用寿命评估的复核

<a id="s136-Para_21.112"></a>**21.112** 使用寿命有限的无形资产的使用寿命至少应于每个财务年度末进行复核。使用寿命的变更应按照 IAS 8 作为会计估计变更进行会计处理。

[IAS 38 第104段]。

<a id="s136-Para_21.113"></a>**21.113** 会计估计变更采用未来适用法进行会计处理，变更的影响在当期及未来期间确认。

[IAS 8 第38段]。

<a id="s136-Para_21.114"></a>**21.114** 使用寿命不确定的无形资产应每年进行复核，以确认事项和情况是否继续支持使用寿命不确定的假设。如果不再支持，使用寿命从不确定变更为有限应按照 IAS 8 作为会计估计变更进行会计处理，如前一段所述。

[IAS 38 第109段]。

[EX 21.114.1 – 使用寿命不确定商标的预期未来现金流量变动](38.md#s139-EX21.114.1)

<a id="s136-Para_21.115"></a>**21.115** 使用寿命从不确定变更为有限是 IAS 36 下的一项减值迹象。如果使用寿命从不确定变更为有限，主体必须根据 IAS 36 执行减值测试，并将可收回金额低于账面价值的任何差额确认为减值损失。

[IAS 38 第110段]。

[EX 21.115.1 – 商标使用寿命从不确定变更为有限](38.md#s139-EX21.115.1)

<a id="s136-chap_21_navPoint_39"></a>
### 残值

<a id="s136-Para_21.116"></a>**21.116** 残值定义为“假定资产已达到使用寿命结束时的预期年限和预期状态，主体目前从该资产处置中扣除估计处置费用后可获得的估计金额”。

[IAS 38 第8段]。

<a id="s136-Para_21.117"></a>**21.117** 使用寿命有限的无形资产的残值应假定为零，除非：

- 第三方承诺在该资产使用寿命结束时购买该资产；或

- 该无形资产存在活跃市场，且：

- 可以参照该市场确定残值；并且

- 在该资产使用寿命结束时该市场很可能存在。

[IAS 38 第100段]。

[EX 21.117.1 – 具有承诺残值的专利权的使用寿命](38.md#s139-EX21.117.1)

<a id="s136-Para_21.118"></a>**21.118** 残值大于零意味着假定主体不会在该资产的整个经济寿命（相对于使用寿命而言）内使用该资产。

[IAS 38 第101段]。

<a id="s136-Para_21.119"></a>**21.119** 残值的确定假定某项资产已达到其使用寿命结束时，且其运营方式与所考虑的实际资产类似。

[IAS 38 第102段]。

[EX 21.119.1 – 确定残值时应考虑的因素](38.md#s139-EX21.119.1)

<a id="s136-Para_21.120"></a>**21.120** 残值至少应于每个财务年度末进行复核。残值的变更应按照 IAS 8 作为会计估计变更进行会计处理。

[IAS 38 第102段]。

<a id="s136-Para_21.121"></a>**21.121** 残值可能会增加至等于或大于无形资产账面价值的金额。在此情况下，摊销费用为零，除非且直至残值降至低于账面价值。

[IAS 38 第103段]。

[FAQ 21.121.1 – 无形资产的残值何时可能大于零？](38.md#s139-FAQ_21.121.1)

<a id="s136-chap_21_navPoint_40"></a>
### 摊销方法

<a id="s136-Para_21.122"></a>**21.122** 摊销方法有多种，包括直线法、余额递减法和产量法。

[IAS 38 第98段]。

<a id="s136-Para_21.123"></a>**21.123** 所采用的摊销方法应反映主体预期消耗该资产未来经济利益的方式。如果无法可靠确定该消耗方式，则必须采用直线法进行摊销。

[IAS 38 第97段]。

[EX 21.123.1 – 摊销方法的选择](38.md#s139-EX21.123.1)  
[EX 21.123.2 – 直线法的应用](38.md#s139-EX21.123.2)

<a id="s136-Para_21.124"></a>**21.124** 存在一项可反驳的假定，即摊销方法不得基于包含使用无形资产在内的活动所产生的收入。所产生的收入通常反映了与消耗无形资产中所蕴含的经济利益无直接关联的因素。例如，收入受其他投入和流程、销售活动以及销量和价格变动的影响。收入的价格组成部分可能受通货膨胀影响，而通货膨胀与资产的消耗方式毫无关系。

[IAS 38 第98A段]。

<a id="s136-Para_21.125"></a>**21.125** 如果满足以下条件之一，则可以反驳以收入为基础的摊销方法不恰当的假定：

- 无形资产以收入的计量方式表示；或

- 能够证明收入与无形资产经济利益的消耗之间存在高度相关性。

[IAS 38 第98A段]。

[EX 21.125.1 – 无形资产固有的主要限制因素](38.md#s139-EX21.125.1)

<a id="s136-chap_21_navPoint_41"></a>
### 摊销方法的变更

<a id="s136-Para_21.126"></a>**21.126** 摊销方法应在各期间一贯应用，除非这些未来经济利益的预期消耗方式发生变更。使用寿命有限的无形资产的摊销方法至少应于每个财务年度末进行复核。所采用方法的变更应按照 IAS 8 作为会计估计变更进行会计处理。

[IAS 38 第104段]。

[FAQ 21.126.1 – 未来经济利益预期消耗方式发生变更的可能性有多大？](38.md#s139-FAQ_21.126.1)

<a id="s136-Para_21.127"></a>**21.127** 摊销费用应确认为当期费用，除非 IAS 38 或其他准则允许或要求将其计入另一项资产的账面价值。

[IAS 38 第97段]。

<a id="s136-Para_21.128"></a>**21.128** 与无形资产相关的摊销费用可能计入存货或不动产、厂场和设备的成本。如果该无形资产用于生产另一项资产，则其摊销费用可能符合计入该另一项资产成本的条件。

[IAS 38 第99段]。

[EX 21.128.1 – 其他摊销方法以及与残值和使用寿命相关规则的应用](38.md#s139-EX21.128.1)

<a id="s136-chap_21_navPoint_42"></a>
### 减值

<a id="s136-Para_21.129"></a>**21.129** 无形资产的减值由 IAS 36 规范。主体应在每个报告日评估是否存在无形资产发生减值的任何迹象。如果存在此类迹象，主体应估计该资产的可收回金额。该资产应减记至其可收回金额（参见[第24章第9段](41.md#s157-Para_24.9)）。

[IAS 38 第111段]。

<a id="s136-Para_21.130"></a>**21.130** 使用某项无形资产生产的产品的预期未来售价下降，可能表明预期该资产存在技术或商业过时；这反过来可能反映出蕴含在该资产中的未来经济利益的减少。

[IAS 38 第92段]。

<a id="s136-Para_21.131"></a>**21.131** 无论是否存在减值迹象，使用寿命不确定的无形资产均应每年进行减值测试。

[IAS 38 第108段]。

<a id="s136-Para_21.132"></a>**21.132** 用于研究与开发活动的无形资产在完成或放弃之前分类为使用寿命不确定（尚未可供使用）的资产。在后续期间，这些无形资产需每年进行减值测试。

[IAS 38 第108段]。

<a id="s136-Para_21.133"></a>**21.133** 无形资产使用寿命的估计从不确定变更为有限是一项减值迹象，届时需要进行减值测试。

[IAS 38 第110段]。

[EX 21.133.1 – 减值迹象](38.md#s139-EX21.133.1)

<a id="s137-chap_21_navPoint_43"></a>
## 无形资产的终止确认（第21.134 - 21.142段）

<a id="s137-Para_21.134"></a>**21.134** 无形资产在满足以下条件之一时应终止确认：

- 已被处置；或

- 预期通过其使用或处置不能产生未来经济利益。

[IAS 38 第112段]。

<a id="s137-Para_21.135"></a>**21.135** 无形资产终止确认（即处置或报废停用）产生的利得或损失为处置净收益与账面价值之间的差额。

[IAS 38 第113段]。

<a id="s137-Para_21.136"></a>**21.136** 计入无形资产终止确认所产生利得或损失的对价金额，按照 IFRS 15 第47–72段关于计算交易价格的要求确定。计入利得或损失的估计对价金额的后续变动，按照 IFRS 15 关于交易价格变动的要求进行会计处理。

[IAS 38 第116段]。

<a id="s137-Para_21.137"></a>**21.137** 终止确认产生的利得或损失应在终止确认发生当期的利润表中确认。唯一的例外是 IAS 17/IFRS 16 对售后租回交易要求采用不同处理的情形。

[IAS 38 第113段]。

<a id="s137-Para_21.138"></a>**21.138** 处置无形资产产生的利得和损失不应确认为收入。它们通常作为利得和损失计入其他收益。

[IAS 38 第113段]。

<a id="s137-Para_21.139"></a>**21.139** 如果利得或损失的金额、性质或发生频率使其披露对于理解主体当期业绩具有相关性，则应单独披露该项目的性质和金额。IAS 1 将不动产、厂场和设备项目的处置作为可能引起单独披露利得或损失的示例。这同样适用于无形资产的处置。

[IAS 1 第86段]。[IAS 1 第87段]。

<a id="s137-Para_21.140"></a>**21.140** 无形资产的处置可以通过多种方式发生，包括出售、签订融资租赁（作为出租人）以及捐赠。处置日是接受方按照 IFRS 15 中确定履约义务何时履行的要求取得该资产控制权的日期。IFRS 15 在第11章中阐述。IAS 17/IFRS 16 适用于售后租回方式的处置，并在[第15章](33.md#s106-chap_15)中阐述。

[IAS 38 第114段]。

<a id="s137-Para_21.141"></a>**21.141** 对主体不再有任何用途的无形资产应予终止确认，因为预期通过该资产的继续使用或处置均无法产生未来经济利益。

[IAS 38 第112(b)段]。

#### <a id="s139-EX21.8.1"></a>EX 21.8.1 – 区分无形资产与金融资产

参考准则：IAS 32 第11段  
参考正文：[21.8](38.md#s133-Para_21.8)

区分无形资产与金融资产可能存在一定难度。

示例1

如果主体购买了某足球俱乐部从门票销售中产生的一定比例收入的权利，则其通常取得了一项金融资产而非无形资产。如果主体对门票的定价或销售没有决定权，而仅有权获得门票销售产生的现金，则构成一项金融资产，即收取现金的合同权利。[IAS 32 第11段]。另一方面，如果主体购买了为足球俱乐部销售门票的权利，并负责自行销售门票以产生收入，则构成一项无形资产。

示例2

创造并将知识产权（例如专利权）资本化的主体，以收取费用为条件将该知识产权的使用权授予第三方。持有知识产权的主体负责吸引客户（第三方）并决定费用的计算方式。该费用可以是固定的定期费用，也可以是第三方收入的一定比例。特许权使用费收入流代表知识产权产生的经济利益。知识产权本身是一项无形资产。

### 确认

#### <a id="s139-EX21.11.1"></a>EX 21.11.1 – 客户关系

参考准则：IAS 38 第13段  
参考正文：[21.11](38.md#s134-Para_21.11)

客户关系是一类可能难以确立对预期未来经济利益控制权的无形资产。如果客户关系是基于合同的（例如，销售合同载明了客户名称和地址、待供应的商品以及约定的合同期限），则控制权可能得到证明。然而，对于客户关系产生的预期未来经济利益，主体通常缺乏足够的控制权。仅当存在针对相同或类似非合同客户关系的交换交易（作为企业合并一部分的除外）时，非合同关系的控制权证据才可能充分。任何此类交换交易也将为这些关系具有可分离性提供证据（参见[第21.15段](38.md#s134-Para_21.15)）。实务中针对非合同客户关系的交换交易极为罕见。

<a id="s139-chap_21_navPoint_idp1714797800"></a>
#### <a id="s139-EX21.11.2"></a>EX 21.11.2 – 加密货币及其他加密资产的分类和计量

参考准则：IAS 38 第13段  
参考正文：[21.11](38.md#s134-Para_21.11)

目前尚未形成单一、公认的加密资产分类框架。因此，也不存在普遍适用的加密资产定义。这反映了实务中交易特征的多样性和定制化性质。但是，根据我们目前的观察，存在一些可用于将加密资产归类为相似类型的特征。我们认为，相似类型的加密资产应以相似的方式进行会计处理。

**加密货币**

在2019年6月的国际财务报告准则解释委员会（IC）会议上，IC 发布了一项议程决议，讨论了国际财务报告准则如何适用于持有的加密货币。出于该议程决议的目的，IC 认为加密货币具有以下特征：

- 记录在分布式账本上并使用密码学确保安全的数字或虚拟货币；

- 并非由司法管辖区当局或其他方发行；且

- 不在持有人与另一方之间产生合同。

IC 得出结论，在正常经营过程中持有待售的加密货币属于 IAS 2 的适用范围。在 IAS 2 不适用的情况下，主体应适用 IAS 38。

在作出这一决议时，IC 指出加密货币不是现金，因为加密货币尚未作为交换媒介（即未用于商品或服务的交换）或作为商品或服务定价的货币单位被广泛使用到足以成为财务报表中计量或确认所有交易的基础。由于加密货币既不是现金，也不提供收取现金或交换其他金融资产的合同权利，也不是另一主体的权益工具，因此加密货币也不属于金融资产。

作为加密货币经纪贸易商的主体应考虑 IAS 2 第3(b)段的指引，并可能被要求按公允价值减去出售费用后的金额计量加密货币存货。在正常经营过程中出售加密货币但并非经纪贸易商的主体，应按成本与可变现净值孰低计量加密货币。根据 IAS 38 对加密货币进行会计处理的其他主体，应制定会计政策，采用成本模式或重估模式记录其持有的加密货币。如果按成本模式记录，主体需要根据 IAS 36 评估减值。

**除加密货币以外的加密资产**

在考虑除加密货币以外的加密资产的会计处理时，适用类似的思考过程。这些加密资产包括证券型代币、资产支持型代币和实用型代币。每种加密资产的具体条款可能都是独特的，因此在应用国际财务报告准则时仔细考虑其特征非常重要。

与加密货币一样，其他类型的加密资产在国际财务报告准则下也不太可能被视为现金。但是，某些类型的加密代币可能赋予持有人获取现金或金融资产（例如某主体的权益份额）的权利。在这种情况下，该加密资产可能符合 IAS 32 下金融资产的定义，主体需要遵循 IFRS 9 的指引进行计量。

在正常经营过程中持有加密资产的主体可能将这些资产视为存货。与加密货币类似，这些资产的计量将取决于主体是否应适用 IAS 2 中关于经纪贸易商的指引。但是，如果主体出于投资目的（即资本增值）而长期持有加密代币，则很可能不符合存货的定义。

某些加密资产赋予持有人获取未来商品或服务的权利。这些代币实质上是未来商品或服务的预付款项，其会计处理可能与其他预付资产类似。其他类型的加密资产（通常称为“资产支持型代币”）可能赋予持有人获取标的资产的权利。如果这些代币赋予持有人获取该标的资产的权利，其会计处理很可能由标的资产的性质和相关会计准则决定。

**代他人持有的加密资产**

主体也可能代表其客户持有加密资产。例如，运营允许客户交换不同加密资产或用法定货币兑换加密资产的交易平台的主体，以及为客户的加密资产提供托管服务的主体。一个关键的会计问题是，此类代持的加密资产应记录在主体的资产负债表内还是表外。

目前没有国际财务报告准则直接就主体代他人持有的加密资产是否应在资产负债表内列报提供指引。我们认为，此类主体在为此类资产制定会计政策时，应考虑 IAS 8《会计政策、会计估计变更和差错》中的一般指引。

在确定代表客户持有加密资产的主体是否应在资产负债表上确认一项资产和一项负债时，主体应考虑：

- 主体是否拥有（明示或默示的）“借用”这些加密资产用于自身目的的权利。如果主体拥有此类权利，则似乎符合资产的定义。

- 如果主体被清算，客户对其代持的加密资产所享有的权利。特别是，如果客户将处于无担保债权人的地位，对主体代其持有的加密资产不享有优先求偿权，则这是一个强有力的迹象，表明加密资产和相应负债应在资产负债表上确认，因为这似乎符合《概念框架》中负债的定义。

**首次代币发行（ICO）**

首次代币发行（ICO）是一种利用加密资产和基于区块链的交易进行的融资形式。ICO 向投资者/认购者分配代币而非股份。这些 ICO 代币通常不代表主体的所有权权益，但它们通常提供访问某个平台（在开发完成时）的权限，且通常可以作为加密货币处理。一次 ICO 中的 ICO 代币数量通常是固定的。每次 ICO 都是定制的，具有独特的条款和条件。对于发行方而言，审查伴随 ICO 代币发行的白皮书或基础文件以了解向投资者/认购者提供的具体内容至关重要，因为这将对确定适用于该 ICO 的会计准则起到关键作用。

<a id="s139-chap_21_navPoint_idp1714880744"></a>
#### <a id="s139-EX21.12.1"></a>EX 21.12.1 – 支付给新员工的签约奖金

参考准则：IAS 38 第15段  
参考正文：[21.12](38.md#s134-Para_21.12)

某主体从事零售银行业务。该银行的战略是实现服务多元化并扩大客户群。管理层计划设立一个投资银行部门。该银行意识到需要招募知名员工以迅速吸引新业务。该银行已向十名个人发出录用通知，这些通知均已获接受。合同期限为五年，并包含大额签约奖金，且如果员工在合同期内离职，不设任何追回条款。该银行希望就这些签约奖金支付确认一项无形资产。

该签约奖金支付不能确认为无形资产，而应在发生时计入费用。签约奖金支付并未确立该银行所控制的未来利益的权利。新员工可能在合同期内离职。如果合同中存在具有法律强制力的竞业限制条款，禁止竞争对手雇用该员工，则可能可以确认一项无形资产。

<a id="s139-chap_21_navPoint_idp1714646760"></a>
#### <a id="s139-EX21.14.1"></a>EX 21.14.1 – 将资产归类为有形资产或无形资产

参考准则：IAS 38 第14段  
参考正文：[21.14](38.md#s134-Para_21.14)

将一项资产归类为有形资产还是无形资产可能具有挑战性。无形资产通常包含在实物载体中或附着于实物载体上。例如包含计算机软件的光盘、证明专利权或牌照的法律文件、附带营业执照的建筑物、包含电影录像的 DVD，或包含数据库的计算机系统。

例如，如果一台机器没有特定软件就无法运行，则该软件被视为该机器不可或缺的组成部分，并作为有形资产处理。相反，如果某项有形资产附属于一项无形资产，则有形要素和无形要素均作为无形资产处理。这包括有形资产仅作为承载软件或其他无形资产的载体而无其他用途的情况（例如，承载软件的光盘）。

也可能存在这样的情况：尽管有形要素和无形要素无法彼此独立运行，但各自的成本均很重大。此时分别对每个要素进行会计处理可能是恰当的。例如，某数据库可能存储在昂贵的计算机硬件上，且硬件成本可以与数据库成本单独区分。每个要素可能具有不同的使用寿命（例如，硬件可能过时，而数据库可以转移到另一套计算机系统中）。在这种情况下，将计算机数据库的两个组成部分分别进行会计处理，将硬件分类为有形资产、将数据库本身分类为无形资产是恰当的，因为它们都是重要组成部分。

<a id="s139-chap_21_navPoint_idp1714662120"></a>
#### <a id="s139-EX21.15.1"></a>EX 21.15.1 – 资产的可辨认性

参考准则：IAS 38 第12段  
参考正文：[21.15](38.md#s134-Para_21.15)

能够单独或与另一项资产一起分离并出售的无形资产，被视为满足可辨认性标准。

源自合同性权利或法定权利的资产也具有可辨认性，即使它们无法从业务中分离。例如，在某些司法管辖区，业务中的某些牌照可能不可转让，除非将整个业务一并出售。

某项资产本身可能不具有可分离性，也不源自合同性或法定权利。然而，如果存在此类资产的交换交易（例如出售非合同客户关系组合），则被视为满足可辨认性标准。相同或类似资产的交换交易能够证明主体拥有控制权且该项目具有可分离性。

<a id="s139-chap_21_navPoint_idp1714675432"></a>
#### <a id="s139-EX21.15.2"></a>EX 21.15.2 – 不可出售或交换的分销网络地图

参考准则：IAS 38 第12段  
参考正文：[21.15](38.md#s134-Para_21.15)

某主体从事电信业务，拥有需要维护的庞大分销网络。管理层维护分销系统的地图，使维护人员能够识别和定位构成该系统的资产。该主体在开发这些地图时发生了重大成本。这些地图无法出售或交换，因为它们仅对该主体有价值。该主体希望就预期从这些地图中获得的未来经济利益确认一项资产。

尽管这些地图不具有可分离性，但管理层对地图所代表的知识产权拥有控制权。这些地图受版权保护。该知识产权源自合同性或法定权利，因此满足可辨认性标准。经济利益可能来自主体因能够使用这些地图而实现的维护成本节约。如果满足作为开发支出资本化的全部标准（参见[第21.32段](38.md#s134-Para_21.32)），开发这些地图所发生的成本可以确认为一项内部产生的无形资产。

<a id="s139-chap_21_navPoint_idp1714688360"></a>
#### <a id="s139-FAQ_21.16.1"></a>FAQ 21.16.1 – 什么是“很可能产生的经济利益”？

参考准则：IAS 37 第23段  
参考正文：[21.16](38.md#s134-Para_21.16)

IAS 38 并未对“很可能产生的经济利益”中的“很可能”作出定义。该准则也没有就如何评估预期未来经济利益提供更多细节。

管理层应为无形资产制定会计政策，并作为该会计政策的一部分，确定何为“很可能产生的经济利益”。管理层应考虑成功的可能性以及预期经济利益的金额。

IAS 37 将“很可能”定义为“可能性大于不可能”。在出于解释成功可能性的目的而考虑何为“很可能”时，可以采用这一定义。如果管理层认为预期未来经济利益流入主体的可能性大于不可能，并且能够提供充分证据予以证实，则该部分标准即得到满足。

<a id="s139-chap_21_navPoint_idp1714702568"></a>
#### <a id="s139-EX21.18.1"></a>EX 21.18.1 – 外部证据

参考准则：IAS 38 第23段  
参考正文：[21.18](38.md#s134-Para_21.18)

IAS 38 中提及需要赋予外部证据更大权重，这一点非常重要。整个准则都提到交换交易可为无形资产的可分离性提供证据。交换交易还可能为预期未来经济利益提供外部证据。其他外部证据可能包括行业预测、外部专家提供的市场和竞争对手分析，以及有关预期通货膨胀率和国家增长率的一般信息。

<a id="s139-chap_21_navPoint_idp1714707688"></a>
#### <a id="s139-EX21.21.1"></a>EX 21.21.1 – 交换交易中取得资产的可能性标准

参考准则：IAS 38 第25段  
参考正文：[21.21](38.md#s134-Para_21.21)

以非货币性资产交换取得的无形资产，与以货币性对价取得的无形资产一样，被视为满足可能性确认标准。在非货币性交换中取得的资产按所付出对价的公允价值计量，而公允价值反映了关于未来经济利益流入主体可能性的预期。

<a id="s139-chap_21_navPoint_idp1714719464"></a>
#### <a id="s139-EX21.21.2"></a>EX 21.21.2 – 企业合并中取得资产的可靠计量标准

参考准则：IAS 38 第33段  
参考正文：[21.21](38.md#s134-Para_21.21)

企业合并是一项交换交易。企业合并中支付的价格反映了对被收购业务整体预期未来经济利益的预期。它并不直接反映对作为合并一部分取得的单项资产的预期。

<a id="s139-chap_21_navPoint_idp1714746344"></a>
#### <a id="s139-EX21.21.3"></a>EX 21.21.3 – 通过政府补助取得资产的可靠计量标准

参考准则：IAS 20 第7、8段  
参考正文：[21.21](38.md#s134-Para_21.21)

无形资产可能免费取得或以名义对价取得（例如通过政府补助）。可能通过政府补助取得的资产包括机场着陆权、排放权、广播或电视台运营牌照、进口许可证和配额。此类资产可按成本（即零或名义金额）或按公允价值确认（参见[第21.60段](38.md#s135-Para_21.60)）。

如果主体选择按公允价值确认这些资产，管理层需要评估是否可以按公允价值确认该补助。为此，应当有合理保证表明主体将遵守补助所附条件。

在通过政府补助取得无形资产的情况下，不存在交换交易。IAS 38 未就通过政府补助取得的无形资产如何应用确认标准作出规定。然而，IAS 20 规定，在有合理保证表明主体将遵守非货币性补助所附条件且将收到该补助之前，不得按公允价值确认该补助。收到补助本身并不能为已满足或将满足补助所附条件提供确凿证据。

<a id="s139-chap_21_navPoint_idp1714761832"></a>
#### <a id="s139-EX21.22.1"></a>EX 21.22.1 – 无法归属于特定产品的研究与开发成本

参考准则：IAS 38 第51段  
参考正文：[21.22](38.md#s134-Para_21.22)

某大型糖果生产供应商拥有两条业务线：巧克力和糖果。巧克力部门拥有五个品牌，糖果部门拥有三个品牌。管理层持续寻求创新并吸引新客户。该主体发生了与新产品研究与开发相关的支出，例如调查客户偏好、设计现有产品的衍生款以及设计新产品。本年度巧克力部门发生研究与开发支出 C100万（C1 million），糖果部门发生 C160万（C1.6 million）。这些支出无法分摊至任何特定产品，但可以与某条业务线相关联。

该研究与开发成本不应资本化为内部产生的无形资产。一项无形资产必须是可辨认的，并且可归属于特定产品或项目，才能满足无形资产的确认标准。管理层应能够识别其确认的每一项单独无形资产将产生的未来经济利益。如果管理层无法识别单个产品或项目，则不可能满足无形资产的确认标准。

<a id="s139-chap_21_navPoint_idp1714768488"></a>
#### <a id="s139-EX21.22.2"></a>EX 21.22.2 – 内部开发的客户名单与企业合并中取得的客户名单的可靠计量标准

参考准则：IAS 38 第51段  
参考正文：[21.22](38.md#s134-Para_21.22)

主体 A 经营多年，建立了一份当前与之交易的客户名单。该名单在客户信息方面庞大且完整。管理层认为该名单具有重大价值。

主体 A 收购了一家中型竞争对手，该竞争对手也拥有一份庞大的客户名单，包含姓名、地址、联系方式和平均购买金额等信息。该客户名单具有价值，管理层可将其出售给第三方。其公允价值能够可靠计量，且不存在阻碍客户信息被交换或交易的实质性法律原因。

主体 A 希望就上述两份客户名单确认无形资产，因为两者均是主体控制的、预期为主体带来未来经济利益的资源。

如果企业合并中取得的客户名单的公允价值能够可靠计量，主体 A 应将其确认为一项无形资产。能够出售或交换该名单证明其可与收购中产生的商誉相分离。

然而，尽管内部产生的客户名单显然满足控制标准，主体 A 仍不能将其确认为无形资产。除满足准则确认条件的开发支出外，IAS 38 明确禁止确认内部产生的无形资产。这是因为该名单的成本无法与开发整个业务的成本区分开来。

<a id="s139-chap_21_navPoint_idp1714781800"></a>
#### <a id="s139-EX21.26.1"></a>EX 21.26.1 – 研究活动

参考准则：IAS 38 第56段  
参考正文：[21.26](38.md#s134-Para_21.26)

旨在获取新知识的活动示例包括：研究特定基因的存在如何影响人类特定疾病发病率的生物技术研究。

寻找研究成果适当应用的示例包括：利用治疗的可能有效性、成本以及现有替代疗法等标准，确定某种化学物质相互作用的发现是否可用于开发特定疾病的治疗方法。

寻找材料和工艺替代方案的示例包括：作为主体提升企业社会责任努力的一部分，寻找更环保的替代方案。

研究被定义为与科学或技术知识相关的活动。在发生时将成本计入费用的相同会计处理同样适用于其他形式的调查，例如市场或客户调研。

<a id="s139-chap_21_navPoint_idp1695650392"></a>
#### <a id="s139-EX21.28.1"></a>EX 21.28.1 – 用于研究与开发项目的无形资产

参考准则：IAS 38 第58段  
参考正文：[21.28](38.md#s134-Para_21.28)

主体可能购买用于研究与开发项目的专利权及其他工艺权利。尽管这些权利被用于研究活动，但它们仍符合作为单独取得的无形资产予以确认的条件。在单独取得无形资产时，假定“未来经济利益”标准自动满足。

<a id="s139-chap_21_navPoint_idp1695658968"></a>
#### <a id="s139-EX21.29.1"></a>EX 21.29.1 – 企业合并中取得的研究项目

参考准则：IAS 38 第34段  
参考正文：[21.29](38.md#s134-Para_21.29)

单独取得或作为企业合并一部分取得的研究与开发项目，如果能够可靠计量，则确认为无形资产。这导致许多此类资产的确认时点早于其作为内部产生资产时的确认时点。

示例

主体 A 在一个开发新型燃料的项目上发生了 C100,000 的研究支出，并将这些成本计入了费用。主体 B 以 C150,000 购买了该项目（包括主体 A 已注册的若干专利权），并确认了一项无形资产。此后，主体 B 发生 C200,000 的支出以完成研究阶段，并决定将该产品商业化开发。主体 B 又发生了 C300,000 的成本，使该产品达到满足将开发成本确认为内部产生的无形资产条件的阶段。随后又发生了 C100万（C1 million）的成本，使该产品达到能够按照管理层意图的方式使用的状态。在该产品实现广泛分销之前，发生了 C200,000 的营销成本和初始亏损。

主体 B 可以资本化哪些成本？

- 主体 B 将 C150,000 确认为所取得研究项目的成本。[IAS 38 第24段]。[IAS 38 第25段]。

- 后续研究成本 C200,000 在发生时计入费用。[IAS 38 第42段]。[IAS 38 第54段]。

- 后续发生的开发成本 C300,000 不满足确认条件，在发生时计入费用。[IAS 38 第42段]。[IAS 38 第57段]。

- 后续开发成本 C100万（C1 million）必须予以确认，因为它们满足确认为无形资产的条件。[IAS 38 第42(b)段]。[IAS 38 第57段]。此前已核销的开发成本不得恢复。[IAS 38 第71段]。

- 营销成本和初始亏损 C200,000 在发生时计入费用。[IAS 38 第67段]。[IAS 38 第69段]。

当该产品开始生产和销售时，该无形资产的账面价值为 C1,150,000。

<a id="s139-chap_21_navPoint_idp1690515560"></a>
#### <a id="s139-EX21.31.1"></a>EX 21.31.1 – 研究与开发费用资本化的计量单元

参考准则：IAS 38 第58段  
参考正文：[21.31](38.md#s134-Para_21.31)

为了确认、计量以及摊销或后续减值测试的目的，研究与开发项目应在项目层面（计量单元）进行资本化。

<a id="s139-chap_21_navPoint_idp1690523496"></a>
#### <a id="s139-EX21.32.1"></a>EX 21.32.1 – 确认标准在产品生命周期各阶段的应用

参考准则：IAS 38 第57段  
参考正文：[21.32](38.md#s134-Para_21.32)

管理层应考虑产品生命周期，并在该周期的每个阶段应用 IAS 38 第57段列出的确认标准，如下所示。

假设某制造工厂正在开发一项新技术。该过程可分为以下阶段：

- 识别对新技术的需求/利益。

- 委托开展一个调查该新技术的项目。

- 调查市场上可用的其他技术。

- 调查竞争对手对其他技术的使用情况。

- 委托设计不同类型的新技术替代方案，并向制造车间征求可行性意见。

- 根据委托阶段的结果编制替代方案候选清单并编制成本估算。

- 为新技术编制预算，并同意候选清单及技术替换方案。

- 将候选清单发送给一线经理征求意见，并根据反馈列出三个替代方案。

- 将最终三个方案提交董事会进行最终选择。

- 为最终选定的方案敲定开发计划。

- 开发新技术。

- 测试新技术。

- 就新技术对员工进行培训。

- 将新技术推广至生产线。

应在每个阶段考虑确认标准，以确定何时全部满足标准。从该时点起，主体应将所有直接归属成本资本化。参见[第21.61段](38.md#s135-Para_21.61)。

第5阶段：标准 (a) 和 (c) 已满足，因为完成该无形资产以供使用的可行性以及主体使用该资产的能力已获确认。

第7阶段：在本阶段结束时，标准 (a)、(c)、(d) 和 (e) 均已满足，因为已编制预算、已同意推进技术替换，且拥有充足资源完成开发。

第10阶段：在此阶段全部标准均已满足，因为除上述条件外，董事会已批准该项目（完成资产意图的证据——标准 (b)），且基于预算编制的开发计划证明了可靠计量支出的能力（标准 (f)）。

<a id="s139-chap_21_navPoint_idp1690559464"></a>
#### <a id="s139-EX21.32.2"></a>EX 21.32.2 – 确认标准在制药行业中的应用

参考准则：IAS 38 第57段  
参考正文：[21.32](38.md#s134-Para_21.32)

从事新药或疫苗开发的主体可能会发生重大的研究与开发成本，并可能达到对产品成功非常有信心的阶段。对此类内部开发成本的资本化并没有绝对的起点。管理层必须根据每个项目的事实和情况运用判断。

新药的上市受到立法的严格监管，在获准上市前必须通过若干临床试验。主体在获得监管机构对药品的最终批准之前，通常无法将开发支出资本化。这是因为在此阶段之前，主体无法证明完成该项目的技术可行性。这些主体可能不得不将所有研究与开发支出计入费用，直至能够证明产品的技术可行性。

然而，当主体向监管机构提交最终批准申请时，便出现了该主体已满足 IAS 38 确认标准的强烈迹象。这是证明完成该项目的技术可行性（这是最难证明的标准）的有力证据。

<a id="s139-chap_21_navPoint_idp1690571496"></a>
#### <a id="s139-EX21.32.3"></a>EX 21.32.3 – 考虑业务性质及正在开发产品的性质

参考准则：IAS 38 第57–64段  
参考正文：[21.32](38.md#s134-Para_21.32)

许多主体在开发方面发生重大支出。确认为无形资产的金额差异很大，取决于业务的性质以及正在开发的产品的性质。

例如，考虑一家主营长期合同业务的主体，该业务涉及为客户开发大型计算机系统。合同条款可能规定该产品或系统的开发活动是履约义务的一部分。这些开发成本通常不根据 IAS 38 进行会计处理，而是作为根据 IFRS 15 履行履约义务的一部分进行处理。但是，如果开发活动不属于履约义务的一部分，但仍明确可向客户收费（例如，因为相关知识在履行履约义务时被使用，但其本身不属于履约义务），则应分析适用 IFRS 15 关于合同履约成本的指引（IFRS 15 第95段）还是适用 IAS 38。

另一家主体可能生产面向大众销售的产品，例如汽车。该主体可能在新车型的开发上发生重大支出。只要满足确认标准，该主体就应将在满足标准后发生的开发成本予以资本化，因此可能会将大额开发成本作为无形资产列示。

在制药等特定行业中，监管要求是限制主体满足确认标准能力的重要因素。然而，此类限制在其他行业中的影响可能较小。例如，新型列车需满足安全法规的要求本身不太可能阻止主体得出未来经济利益很可能流入主体的结论。列车是一种成熟的交通工具，并非全新的产品。设计中的缺陷可以通过整改以满足安全要求。相反，全新产品若未能满足监管要求，则可能导致整个项目失败。

<a id="s139-chap_21_navPoint_idp1712722600"></a>
#### <a id="s139-FAQ_21.33.1"></a>FAQ 21.33.1 – 推出新产品或新系统如何影响现有产品或系统的未来经济利益？

参考准则：IAS 38 第71段  
参考正文：[21.33](38.md#s134-Para_21.33)

新产品或新系统可能会替代主体拥有的现有产品或系统，或使其过时。主体应重新评估被替代或以其他方式受新产品或新系统影响的产品或系统所带来的利益。计划中的替代很可能是 IAS 36 下的一项减值迹象。新产品可能导致现有资产发生减值或缩短现有资产的使用寿命。一个例子是引入数字技术替代模拟技术（[参见第21.130段](38.md#s136-Para_21.130)）。

<a id="s139-chap_21_navPoint_idp1712728488"></a>
#### <a id="s139-EX21.33.2"></a>EX 21.33.2 – 根据欧盟 REACH（化学品注册、评估、授权和限制）法规发生的成本

参考准则：IAS 38 第8段  
参考正文：[21.33](38.md#s134-Para_21.33)

REACH 法规要求制造商、进口商和下游用户对现有和新的化学品及物质进行注册。该法规还要求对高度关注物质（根据欧洲化学品管理局公布的清单）进行授权。主体不得制造或进口未注册的化学品，也不得使用未经授权的物质。

注册费和授权费符合无形资产的定义，只要所发生的成本可直接归属于注册或授权（即能够与日常经营成本相区分）且能够可靠计量，即可予以资本化。

欧盟以外的司法管辖区已经制定或正在制定与类似环境问题相关的法规。按照这些司法管辖区的立法要求发生的类似成本，也可以资本化为无形资产。

同样，主体为取得认证标志（IFRS 3 附录中定义为“用于证明商品或服务的地理来源或其他特征”，例如英国标准协会认证）而自主发生的成本，如果满足确认标准，也可以资本化为无形资产。如果主体认为该资产很可能为主体带来未来经济利益（通过增加销售额），且该特定认证受到法律或注册保护，则取得该特定认证的成本可确认为无形资产。

<a id="s139-chap_21_navPoint_idp1712739496"></a>
#### <a id="s139-EX21.34.1"></a>EX 21.34.1 – 客户忠诚度计划

参考准则：IAS 38 第63段  
参考正文：[21.34](38.md#s134-Para_21.34)

某超市是主导市场的三大连锁超市之一。市场竞争激烈，导致产品利润率较低。

该超市推出了一项客户忠诚度计划以努力提高市场份额。加入该计划的客户会获得会员卡，可根据其消费金额赚取可兑换积分。积分可用于抵扣未来消费或兑换奖品。该超市希望将建立该计划的成本资本化为一项无形资产。

该计划的支出无法与开发整个业务的成本区分开来。客户忠诚度计划是内部产生的，因此不能确认为无形资产。

#### <a id="s139-EX21.34.2"></a>EX 21.34.2 – 企业合并中取得的不得确认为无形资产的内部产生项目

参考准则：IFRS 3 附录 B 第 B32 段  
参考正文：[21.34](38.md#s134-Para_21.34)

IFRS 3 列出了在企业合并中取得的、符合无形资产定义且若其公允价值能够可靠计量则应独立于商誉确认为无形资产的项目清单。以下项目在企业合并中不得确认为无形资产：

- 客户服务能力：主体的客户服务能力不符合单独确认为无形资产的可辨认性标准。主体的客户服务能力依赖于其员工，而员工不代表主体控制的资源。

- 主体无法辨认的客户群体（客户群），例如零售商的散客：零售商的散客群不符合单独确认为无形资产的可辨认性标准。缺乏合同性或法定权利，加上零售商无法辨认或联系客户，意味着主体对预期从客户获得的经济利益缺乏足够的控制权。

- 在特定地理市场或地点的业务存在：在特定地理市场或地点的业务存在不符合单独确认为无形资产的可辨认性标准。没有任何限制可以阻止其他第三方进入该地理市场或地点，因此主体无法控制与特定地点或地理市场相关的利益。

- 非工会状态或良好的劳资关系：非工会状态或良好的劳资关系不符合单独确认为无形资产的可辨认性标准。尽管主体可能能够识别来自非工会状态的未来经济利益（例如减少员工行政和薪酬成本），但员工不代表主体控制的资源。

- 持续的培训或招聘计划：培训成本支出应在发生时计入费用，因为这些成本无法与开发整个业务的成本相区分（参见第21.64段）。主体可能能够识别持续培训和招聘计划带来的可产生未来经济利益的增量员工技能；然而，员工不代表主体控制的资源，因此主体不能确认单独的无形资产。

- 优异的信用评级或进入资本市场的渠道：优异的信用评级或进入资本市场的渠道不符合单独确认为无形资产的可辨认性标准。信用评级或公司的信用状况不受合同性或法定权利保护。主体对预期因有利信用评级/进入资本市场而获得的任何经济利益缺乏足够的控制权。有利的信用评级或进入资本市场的渠道也不具有可分离性，因为它们不能出售给第三方。

- 良好的政府关系：良好的政府关系不符合单独确认为无形资产的可辨认性标准。政府不代表主体控制的资源。在某些司法管辖区，主体积极游说政府是常见做法，这可能会为公司带来某些经济利益。

- 现有的员工队伍：现有的员工队伍不符合单独确认为无形资产的可辨认性标准。主体无法控制现有员工队伍带来的利益，因为主体无法阻止员工队伍构成的变化。

<a id="s139-chap_21_navPoint_idp1695817224"></a>
#### <a id="s139-EX21.35.1"></a>EX 21.35.1 – 广告支出与产品目录的处理

参考准则：IAS 38 第69段  
参考正文：[21.35](38.md#s134-Para_21.35)

不符合确认标准的支出包括维持业务的一般日常支出，例如工资和薪金、维护费、广告支出和产品目录。

广告和促销活动用于增强或创建品牌或客户关系，进而产生收入。为用于广告或促销活动而取得的商品或服务没有其他用途。这些商品或服务的唯一利益是开发品牌或客户关系，进而产生收入。内部产生的品牌和客户关系不确认为无形资产。

主体不应就尚未发布的广告确认资产。因发布广告而可能流入主体的唯一经济利益，与该广告所增强或创建的品牌或客户关系可能带来的经济利益相同。主体不应将其就未来广告或促销活动所收到的商品或服务确认为资产。[IAS 38 第BC46B段]。[IAS 38 第BC46C段]。

邮购目录的主要目的是向客户宣传商品，而非建立分销网络。邮购目录属于广告活动的示例，不得资本化。[IAS 38 第BC46G段]。

<a id="s139-chap_21_navPoint_idp1695822344"></a>
#### <a id="s139-EX21.36.1"></a>EX 21.36.1 – 市值超过净资产价值

参考准则：IAS 38 第50段  
参考正文：[21.36](38.md#s134-Para_21.36)

主体的市值与其净资产价值之间可能存在差异，有时甚至很大。这种差异可能代表影响主体价值的多种因素，包括管理层的专业能力或声誉、内部产生的品牌价值、按成本列示的外购品牌价值的增长，以及收购传闻。然而，此类差异不代表主体控制的可辨认无形资产。[IAS 38 第50段]。

#### <a id="s139-EX21.40.2"></a>EX 21.40.2 – 营销相关无形资产

参考准则：IFRS 3 第 IE18、IE20–IE22 段  
参考正文：[21.40](38.md#s134-Para_21.40)

营销相关无形资产主要用于产品或服务的营销或推广。它们通常受到法律手段保护，若单独取得或在企业合并中取得，一般符合单独确认为无形资产的合同-法定标准。[IFRS 3 第IE18段]。

商标、商号和其他标志通常在政府机构注册，或者虽未注册但以其他方式受到保护。无论是否注册，只要以其他方式受到保护，商标、商号和其他标志均享有一定的法律保护，从而满足合同-法定标准。如果商标或其他标志未受法律保护，但存在类似出售或交换的证据，则该商标或其他标志将满足可分离性标准。[IFRS 3 第IE20段]。

品牌一词通常用于指代与商标或商号相关的一组资产。如果一组互补性资产（例如品牌）具有相似的使用寿命，并且满足合同-法定标准或可分离性标准之一，购买方可以将其作为一项单一资产独立于商誉予以确认。[IFRS 3 第IE21段]。

商业外观是指产品的独特颜色、形状或包装。[IFRS 3 第IE18段]。如果受到法律保护，商业外观满足合同-法定标准。如果商业外观未受法律保护，但存在类似出售的证据，或者该商业外观与相关资产（如商标）一并出售，则其满足可分离性标准。

报纸报刊名通常像商标一样受到法定权利保护，并满足合同-法定标准。如果未受法律保护，公司需考察是否存在报刊名的交换或出售，以确定是否满足可分离性标准。互联网域名是用于标识特定互联网网站或互联网地址的唯一名称。这些域名通常已注册，并满足合同-法定标准。[IFRS 3 第IE22段]。

竞业限制（“不竞争”）协议是通常禁止个人或企业在特定期限内于特定市场与某公司竞争的法律安排。被购买方在购买时可能已存在既有的竞业限制协议。这些协议满足合同-法定标准，并代表一项取得的资产，应作为企业合并的一部分予以确认。竞业限制协议的条款、条件和可执行性可能会影响分配给该无形资产的公允价值，但不会影响其确认。支付给前员工的其他可能被描述为竞业限制付款的款项，实际上可能是合并后期间服务的报酬，应当予以审慎核查。

<a id="s139-chap_21_navPoint_idp1695600440"></a>
#### <a id="s139-EX21.40.3"></a>EX 21.40.3 – 客户相关无形资产

参考准则：IFRS 3 第 IE23、IE27 段  
参考正文：[21.40](38.md#s134-Para_21.40)

客户相关无形资产包括但不限于：(i) 客户合同及相关客户关系，(ii) 非合同客户关系，(iii) 客户名单，以及 (iv) 未履行订单或生产积压订单。[IFRS 3 第IE23段]。被购买方与其客户之间的关系可能涵盖不止一种类型的无形资产（例如，客户合同及相关客户关系、客户名单和积压订单）。与同一客户相关的各类无形资产之间的相互关系可能会给客户相关无形资产的确认和计量带来挑战。归属于其他无形资产（如品牌名称和商标）的价值也可能影响客户相关无形资产的估值。此外，由于各项资产的使用寿命以及经济利益消耗方式可能不同，可能需要分别确认涵盖单一客户关系的各项无形资产。[IFRS 3 第IE27段]。

<a id="s139-chap_21_navPoint_idp1695612472"></a>
#### <a id="s139-EX21.40.4"></a>EX 21.40.4 – 合同基础无形资产

参考准则：IFRS 3 第 IE34 段  
参考正文：[21.40](38.md#s134-Para_21.40)

合同基础无形资产代表源自合同安排的权利的价值。客户合同是合同基础无形资产的一种类型。合同基础无形资产包括：(i) 许可协议、特许权使用费协议和暂停协议；(ii) 广告、建造、管理、服务或供应合同；(iii) 施工许可证；(iv) 特许经营协议；(v) 经营权和广播权；(vi) 金融资产服务合同；(vii) 雇佣合同；(viii) 使用权；以及 (ix) 若适用 IFRS 16 时的租赁协议。[IFRS 3 第IE34段]。条款被视为处于市场平价水平的合同，以及条款相对于市场有利的合同，均可能产生合同基础无形资产。如果合同条款相对于市场不利，购买方应确认在企业合并中承担的一项负债。

<a id="s139-chap_21_navPoint_idp1684492920"></a>
#### <a id="s139-EX21.40.5"></a>EX 21.40.5 – 客户相关无形资产：客户奖励或忠诚度计划

参考准则：IFRS 3 第 IE23 段  
参考正文：[21.40](38.md#s134-Para_21.40)

在评估与客户奖励或忠诚度计划相关的任何无形资产的确认和计量时，应予以审慎考虑。与这些计划相关的条款和条件范围可能各不相同。

客户奖励或忠诚度计划可能在被购买方与客户之间建立某种关系。此类计划可能提升客户相关无形资产的价值。由于双方已同意某些条款和条件，或此前曾存在合同关系，或两者兼而有之，这些计划预计符合“合同性”一词的含义。除评估针对这些计划确认和计量客户相关无形资产的必要性外，购买方还必须在购买日单独评估确认和计量与这些计划相关的任何所承担负债的必要性。

<a id="s139-chap_21_navPoint_idp1684507000"></a>
#### <a id="s139-EX21.40.6"></a>EX 21.40.6 – 客户相关无形资产：客户合同及相关客户关系

参考准则：IFRS 3 第 IE28 段  
参考正文：[21.40](38.md#s134-Para_21.40)

如果满足以下条件，则公司与其客户之间存在客户关系：(i) 公司拥有关于该客户的信息并与其保持定期联系，且 (ii) 客户有能力直接联系该公司。[IFRS 3 第IE28段]。如果主体习惯通过合同与客户建立关系，则即使在购买日没有有效合同（例如采购订单或销售订单），该客户关系也满足单独确认为无形资产的合同-法定标准。销售或服务代表定期联系的惯例也可能产生客户关系。如果客户关系满足合同-法定标准或可分离性标准，则可能表明存在一项应予确认的无形资产。[IFRS 3 第IE28段]。

示例1 – 可撤销和不可撤销的客户合同

某被收购业务是商用机械及相关售后零部件的制造商。被购买方的商用机械约占其销售额的70%，通过不可撤销的合同销售。其售后零部件占销售额的其余30%，同样通过合同销售，但客户可随时撤销合同。

被购买方习惯于就商用机械的销售以及售后零部件的销售与客户建立合同关系。购买售后零部件的客户随时撤销合同的能力将纳入该无形资产的计量考虑，但从确认角度来看，并不影响是否满足合同-法定标准。

示例2 – 购买日正在谈判的潜在合同

在购买日，被购买方正与若干新客户谈判合同，双方尚未就定价、产品规格和其他关键条款等实质性条款达成一致。

尽管购买方可能认为这些预期合同具有价值，但与新客户的潜在合同不满足合同-法定标准，因为在购买日不存在与之相关的合同性或法定权利。潜在合同也不满足可分离性标准，因为它们不能被出售、转移或交换，且无法与被收购业务分离。这些潜在合同的价值归入商誉。购买日之后潜在合同状态的变化不会导致将商誉重分类为无形资产。

<a id="s139-chap_21_navPoint_idp1684523896"></a>
#### <a id="s139-EX21.40.7"></a>EX 21.40.7 – 客户相关无形资产：“重叠客户”

参考准则：IFRS 3 附录 B 第 B33 段  
参考正文：[21.40](38.md#s134-Para_21.40)

购买方可能与被购买方拥有相同的客户（有时称为“重叠客户”）。如果客户关系满足合同-法定标准或可分离性标准，即使购买方本身可能已经与这些相同客户存在关系，仍应就被购买方的客户关系确认一项无形资产。此类关系的估值可能取决于多种因素，包括市场参与者是否会从这些相同的关系中受益。

<a id="s139-chap_21_navPoint_idp1684527480"></a>
#### <a id="s139-EX21.40.8"></a>EX 21.40.8 – 客户相关无形资产：非合同客户关系

参考准则：IFRS 3 附录 B 第 B33 段  
参考正文：[21.40](38.md#s134-Para_21.40)

非合同客户关系不满足合同-法定标准。但是，可能存在这样的情况：这些关系无需出售被收购业务即可单独出售或以其他方式交换，从而满足可分离性标准。如果非合同客户关系满足可分离性标准，则该关系应确认为无形资产。[IFRS 3 第IE31段]。

非合同客户关系具有可分离性的证据包括相同或类似类型资产的交换交易。非合同客户关系独立于商誉确认为无形资产并不要求此类交易频繁发生。相反，确认取决于非合同客户关系是否能够被分离并出售、转移等。[IFRS 3 附录 B 第 B33 段]。未单独确认的非合同关系（例如客户群、市场份额和无法辨认的“散客”）应作为商誉的一部分。

<a id="s139-chap_21_navPoint_idp1684538744"></a>
#### <a id="s139-EX21.40.9"></a>EX 21.40.9 – 客户相关无形资产：客户名单

参考准则：IFRS 3 第 IE24 段  
参考正文：[21.40](38.md#s134-Para_21.40)

客户名单代表已知、可辨认客户的清单，包含有关这些客户的信息（如姓名和联系信息）。客户名单也可以采取数据库的形式，包含有关客户的其他信息（例如订单历史和人口统计信息）。

客户名单通常不源自合同性权利或其他法定权利，因此通常不满足合同-法定标准。然而，客户名单经常被出租或交换。因此，在企业合并中取得的客户名单通常满足可分离性标准。[IFRS 3 第IE24段]。如果保密条款或其他协议禁止被购买方出租或以其他方式交换其客户信息，则取得的客户名单不满足可分离性标准。

<a id="s139-chap_21_navPoint_idp1684556024"></a>
#### <a id="s139-EX21.40.10"></a>EX 21.40.10 – 客户相关无形资产：客户群

参考准则：IFRS 3 第 IE25 段  
参考正文：[21.40](38.md#s134-Para_21.40)

客户群代表一组未知或不可辨认的客户（例如在报摊购买报纸的人，或快餐特许经营店或加油站的客户）。客户群也可称为“散客”。如果获取了有关各个客户的信息，客户群可能构成客户名单。

客户群通常不单独确认为无形资产，因为它不源自合同性或法定权利，也不具有可分离性。

<a id="s139-chap_21_navPoint_idp1684558328"></a>
#### <a id="s139-EX21.40.11"></a>EX 21.40.11 – 客户相关无形资产：未履行订单或生产积压订单

参考准则：IFRS 3 第 IE25 段  
参考正文：[21.40](38.md#s134-Para_21.40)

未履行订单或生产积压订单源自尚未履行的采购或销售订单合同，在制造业或建筑业等特定行业可能较为重大。在企业合并中取得的未履行订单或生产积压订单满足合同-法定标准，即使采购或销售订单合同是可撤销的，也可单独确认为无形资产。但是，合同可撤销这一事实可能会影响相关无形资产公允价值的计量。[IFRS 3 第IE25段]。

示例 – 基于采购订单识别客户相关无形资产

主体 M 在企业合并中被主体 Y 收购，拥有以下两位客户：

- 客户 A 是经常性客户，通过采购订单与主体 M 进行交易，在购买日有若干尚未履行的采购订单。

- 客户 B 是经常性客户，通过采购订单与主体 M 进行交易，但在购买日没有尚未履行的采购订单。

主体 Y 评估被收购客户可能存在的整体客户关系的各个组成部分。主体 Y 将基于合同-法定标准为客户 A 和客户 B 确认无形资产。与客户 A 的客户关系满足合同-法定标准，因为在购买日存在有效的合同或协议。客户 B 的客户关系也满足合同-法定标准，因为主体 M 有与该客户使用采购订单的历史，即使在购买日没有尚未履行的采购订单。

<a id="s139-chap_21_navPoint_idp1684569208"></a>
#### <a id="s139-EX21.40.12"></a>EX 21.40.12 – 艺术相关无形资产

参考准则：IFRS 3 第 IE32–IE33 段  
参考正文：[21.40](38.md#s134-Para_21.40)

艺术相关无形资产是通常受版权或其他合同及法律手段保护的创意资产。如果艺术相关无形资产源自合同性或法定权利（例如版权），则应单独确认。[IFRS 3 第IE33段]。艺术相关无形资产包括：(i) 戏剧、歌剧、芭蕾舞剧；(ii) 书籍、杂志、报纸、其他文学作品；(iii) 音乐作品，如乐曲、歌词、广告配乐；(iv) 图片、照片；以及 (v) 视频和视听资料，包括电影或影片、音乐视频和电视节目。[IFRS 3 第IE32段]。版权可以部分转让或许可给他人。只要各组成资产具有相似的使用寿命，受版权保护的无形资产及相关转让或许可协议可以作为一项单一的互补性资产予以确认。[IFRS 3 第IE33段]。

<a id="s139-chap_21_navPoint_idp1684586104"></a>
#### <a id="s139-EX21.40.13"></a>EX 21.40.13 – 合同基础无形资产：有利及不利合同条款

参考准则：IFRS 3 附录 B 第 B30 段  
参考正文：[21.40](38.md#s134-Para_21.40)

对于条款相对于当前市场条款有利或不利的某些合同，可能需要确认无形资产或负债。应将合同条款与购买日的市场价格进行比较，以确定是否应确认无形资产或负债。如果所取得合同的条款相对于市场价格有利，则确认一项无形资产。如果所取得合同的条款相对于市场价格不利，则确认一项负债。[IFRS 3 第IE34段]。

计量有利和不利合同时的一个重要判断领域是是否应包括合同续期或延期条款。在考虑是否包括续期或延期时，应考虑以下因素：

- 续期或延期是否可由一方自行决定而无需重新谈判关键条款，或者是否在被购买方的控制范围内。如果条款对购买方有利，被购买方控制范围内的续期或延期很可能会被包括在内。

- 续期或延期是否为续期权持有人带来经济利益。续期权持有人（无论是被购买方还是交易对手方）很可能会按照自身最佳利益行事。

- 是否存在表明合同可能续期或不会续期的任何其他因素（例如续期历史）。

每项安排均应单独确认和计量。有利合同和不利合同产生的金额不得相互抵销。与有利和不利合同条款相关的无形资产或负债的公允价值通常采用现值技术确定。需计算剩余合同期限（包括任何预期续期）内合同价格与当前市场价格之间的差额，然后进行折现以得出净现值金额。该无形资产或负债的公允价值随后将在剩余合同期限（包括续期，如适用）内摊销。

示例1 – 有利采购合同

主体 N 在企业合并中收购了主体 O。主体 O 通过一份采购合同购买电力，该合同为五年期安排，目前处于第3年。在原合同期满时，主体 O 可自行决定将采购合同延长五年。原合同下的年度电力成本为每年 C80，五年延期期间的年度成本为每年 C110。购买日当前的年度市场电价为 C200。预计未来市场价格将保持稳定。主体 N 未将该合同作为衍生工具进行会计处理。

主体 O 的电力采购合同是有利合同。原合同和延期条款均允许主体 O 以低于当前市场价格的金额购买电力。主体 N 很可能会行使选择权，将合同再延长五年。

示例2 – 不利采购合同

假设事实与上述相同，但购买日当前的年度市场电价为每年 C50，且预计未来市场价格不会变动。

主体 O 的采购合同是不利合同。在这种情况下，原合同和延期条款均要求其支付高于当前年度市场价格 C50 的金额。主体 N 应就原合同剩余的两年期限确认并计量一项负债。在计量该不利合同时不考虑延期期间，因为主体 N 可以选择不延长该合同。

平价合同也应评估是否存在可能需要单独确认的无形资产。平价合同条款反映了购买日的市场条款。该合同可能具有价值，市场参与者愿意为其支付溢价，因为它能提供未来经济利益。[IFRS 3 附录 B 第 B30 段]。主体应考虑其他定性原因或特征，例如：(i) 合同或租赁资产的独特性或稀缺性，(ii) 合同的独特特征，(iii) 卖方迄今为取得和履行合同所付出的努力，或 (iv) 未来合同续期或延期的潜力。这些特征的存在可能使合同更具价值，从而使市场参与者愿意为该合同支付溢价。机场登机口租赁和家庭安防行业的客户合同是在可观察交换交易中买卖的平价合同示例，且已导致单独无形资产的确认。

<a id="s139-chap_21_navPoint_idp1684613112"></a>
#### <a id="s139-EX21.40.14"></a>EX 21.40.14 – 合同基础无形资产：金融资产服务合同

参考准则：IFRS 3 第 IE35–IE36 段  
参考正文：[21.40](38.md#s134-Para_21.40)

如果满足以下条件之一，金融资产服务合同应单独确认为无形资产：(i) 标的金融资产（例如应收款项）被出售或证券化，且卖方保留了服务合同；或 (ii) 服务合同被单独购买或承担。[IFRS 3 第IE35段]。如果不满足这些标准，即使服务是所有金融资产所固有的，也不能单独确认无形资产。

金融资产服务合同可能包括：

- 向借款人收取本金、利息和托管付款；

- 从托管资金中支付税款和保险费；

- 监控逾期情况；

- 执行止赎程序；

- 在分配前对资金进行临时投资；

- 向担保人、受托人和其他服务提供方汇付费用；以及

- 核算并向金融资产受益权益持有人汇付本金和利息付款。

如果在企业合并中同时取得了抵押贷款、信用卡应收款项或其他金融资产以及这些资产的服务合同，则上述标准均未满足，服务权不会单独确认为无形资产。然而，服务权包含在标的抵押贷款、信用卡应收款项或其他金融资产的公允价值计量中。

[IFRS 3 第IE36段]。

#### <a id="s139-EX21.40.15"></a>EX 21.40.15 – 合同基础无形资产：雇佣合同

参考准则：IFRS 3 附录 B 第 B37 段  
参考正文：[21.40](38.md#s134-Para_21.40)

雇佣合同极少产生合同基础无形资产或负债。[IFRS 3 第IE37段]。雇佣合同可能与服务合同一样高于或低于市场水平。实务中很少确认雇佣合同无形资产和负债；因为员工可以选择在相对较短的通知期内离职，雇佣合同通常不予强制执行，且难以证实特定员工的市场薪酬水平。参见第29章第193段。

一个例外情况可能是收购职业运动队。球员合同很可能产生雇佣合同无形资产和负债。运动员通常在职业限制下工作，为了维持职业地位，他们不能随意离开签约球队而为另一支球队效力。球员合同也可能具有可分离性，因为它们经常成为可观察市场交易的对象。被收购业务中既有的雇佣合同还可能包含竞业限制条款。这些竞业限制条款可能具有价值，当此类合同属于企业合并的一部分时，应将其单独评估为无形资产。

#### <a id="s139-EX21.40.16"></a>EX 21.40.16 – 合同基础无形资产：使用权

参考准则：IFRS 3 第 IE38 段  
参考正文：[21.40](38.md#s134-Para_21.40)

使用权（如钻探权、取水权、航空权、采矿权、采伐权和航线许可权）属于合同基础无形资产。使用权的独特之处在于它们可能同时具有有形资产和无形资产的特征。使用权应根据其性质按有形资产或无形资产以公允价值确认。

[IFRS 3 第IE38段]。

#### <a id="s139-EX21.40.17"></a>EX 21.40.17 – 技术基础无形资产

参考准则：IFRS 3 第 IE39、IE41–IE44 段  
参考正文：[21.40](38.md#s134-Para_21.40)

技术基础无形资产通常代表产品或服务的创新，但也可以包括以电子方式保存的信息集合。[IFRS 3 第IE39段]。

专利技术受法律保护，满足单独确认为无形资产的合同-法定标准。非专利技术通常不受法律或合同手段保护，不满足合同-法定标准。然而，非专利技术经常与其他无形资产（如商号或秘密公式）一并出售。由于其经常与相关资产一并出售，非专利技术通常满足可分离性标准。

商业秘密是指因不为公众所知悉而具有独立经济价值、并已采取合理措施保密的信息，包括公式、图案、配方、汇编、程序、装置、方法、技术或工艺。如果企业合并中取得的商业秘密所带来的未来经济利益受到法律保护，则该资产满足合同-法定标准。即使不受法律保护，企业合并中取得的商业秘密也很可能因满足可分离性标准而具有可辨认性。只要商业秘密能够出售或许可给他人，即使出售不频繁或购买方无意出售或许可，也应确认一项资产。[IFRS 3 第IE44段]。

掩模作品是永久存储在只读存储芯片上的软件。掩模作品、计算机软件和程序格式通常通过专利权、版权或其他法律手段受到保护。如果受到法律保护，它们满足合同-法定标准。如果未受法律或合同手段保护，但存在相同或类似类型资产的出售或交换证据，这类资产仍可能满足可分离性标准。[IFRS 3 第IE41段]。

数据库是通常以电子方式存储的信息集合。有时，包含原创著作作品的数据库可以通过版权等法律手段获得保护；如果受到此类保护，则满足合同-法定标准。更常见的是，数据库是在正常业务运营中收集的信息，例如客户信息、科学数据或信用信息。与客户名单类似，数据库经常向他人出售或出租，因此满足可分离性标准。[IFRS 3 第IE42段]。

#### <a id="s139-EX21.40.18"></a>EX 21.40.18 – 互补性无形资产及其他无形资产的分组

参考准则：IFRS 3 附录 B 第 B32(b) 段  
参考正文：[21.40](38.md#s134-Para_21.40)

单独的无形资产可能协同工作或相辅相成。购买方可能希望将这些互补性无形资产归为一组，以便在购买日计量其初始公允价值以及进行后续摊销和减值测试。品牌或品牌名称即为一例。国际财务报告准则仅允许有限度的分组。

品牌是一个通用营销术语，指一组互补性无形资产，例如商标及其相关的商号、公式、配方和技术。如果构成该组合的资产符合准则中单独确认的可辨认性标准且具有相似的使用寿命，购买方可以将其作为一项单一无形资产予以确认。[IFRS 3 第IE21段]。购买方也可以将其他互补性无形资产组合确认为一项单一资产。这一结论也可能适用于其底层组成资产具有相似使用寿命的其他资产。如果使用寿命相似，可以作为一项单一资产确认的资产示例包括：

- 核电站及运营该核电站的牌照。[IFRS 3 附录 B 第 B32(b) 段]。

- 版权无形资产及任何相关的转让或许可协议。[IFRS 3 第IE33段]。

- 海港及运营该海港的任何相关许可证或牌照。

- 支撑天然气管道的一系列地役权。

购买方应识别各组成资产并确定每项组成资产的使用寿命，以评估这些使用寿命是否相似。

租赁协议是指在一定期间内将资产的使用权让与以换取对价的合同或合同的一部分。购买日存在的租赁安排可能导致确认各种资产和负债，包括基于合同-法定标准单独确认的无形资产。租赁的类型（例如经营租赁与融资租赁）以及被购买方在租赁下是承租人还是出租人，将影响在企业合并中可能确认的各类资产和负债。

被购买方为承租人

购买方对按照 IFRS 16 识别的租赁确认使用权资产和租赁负债，除非该租赁在购买日起12个月内结束，或根据 IFRS 16 标的资产属于低价值资产。购买方按剩余租赁付款额的现值计量租赁负债，视同所取得的租赁在购买日为一项新租赁。购买方应按与租赁负债相同的金额计量使用权资产，并进行调整以反映与市场条款相比的有利或不利租赁条款。[IFRS 3 第28A段]。[IFRS 3 第28B段]。

被购买方为出租人

购买方根据租赁条款计量出租人受经营租赁约束的资产在购买日的公允价值。[IFRS 3 附录 B 第 B42 段]。与有利或不利条款相关的单独无形资产或负债以及与“既有”租赁相关的任何价值虽获确认，但包含在租赁资产的价值中。然而，将与有利或不利租赁条款相关的金额单独摊销可能是恰当的。[IAS 16 第44段]。

被收购主体也可能是融资租赁的出租人。购买方确认并计量代表其在租赁中剩余投资净额的应收款项。此类投资应根据租赁安排的条款按照 IFRS 3 予以确认。

当被购买方为出租人时，在企业合并中承担的租赁产生的资产和负债按购买日的公允价值计量（参见第29章第100段）。租赁开始日确定的租赁分类不应因企业合并而改变，除非租赁条款被修改。[IFRS 3 第17段]。租赁期的确定是在合同开始日确立租赁分类的一项关键假设。例如，在租赁开始日将续租选择权纳入租赁期可能会影响初始租赁分类。

<a id="s139-chap_21_navPoint_idp1712296664"></a>
#### <a id="s139-FAQ_21.40.20"></a>FAQ 21.40.20 – 配置或定制成本（CC）是否符合无形资产的定义？

参考准则：IFRIC 议程决议 2021年3月  
参考正文：[21.40.3](38.md#s134-Para_21.40.3)

无形资产被定义为“没有实物形态的可辨认非货币性资产”[IAS 38 第8段]。资产是由主体控制的资源。如果主体有能力获取标的资源带来的未来经济利益，并能限制他人获取这些利益，则该主体控制该项资产。

2021年3月，IFRS IC 指出，在提交请求所述的 SaaS 安排中，客户通常不会确认无形资产，因为客户不控制所配置或定制的软件，且这些活动并未创造出独立于该软件的资产。然而，在某些情况下，该安排可能产生例如额外代码，客户有能力从该额外代码中获取未来经济利益并限制他人获取这些利益。在这种情况下，客户需评估该额外代码是否具有可辨认性并满足 IAS 38 中的确认标准，以将该额外代码确认为无形资产。

如果符合无形资产的定义，且由 SaaS 提供商或第三方执行配置或定制（“CC”），则该无形资产不属于内部产生的无形资产，而符合作为单独取得的无形资产予以确认的条件。[IAS 38 第25段]。

如果主体自行执行配置或定制且符合无形资产的定义，则需要评估所发生的成本是否满足资本化标准。在这些成本得以资本化之前必须满足的具体标准载于 IAS 38 第57段，如下：

“由开发（或内部项目开发阶段）产生的无形资产，当且仅当主体能够证明以下全部条件时，方应予以确认：

(a) 完成该无形资产以使其能够使用或出售在技术上具有可行性。

(b) 具有完成该无形资产并使用或出售它的意图。

(c) 具有使用或出售该无形资产的能力。

(d) 无形资产产生很可能实现的未来经济利益的方式。除其他因素外，主体能够证明运用该无形资产生产的产品存在市场，或者无形资产自身存在市场；如果该无形资产将在内部使用，则能够证明该无形资产的有用性。

(e) 有足够的技术、财务和其他资源支持，以完成该无形资产的开发，并有能力使用或出售该无形资产。

(f) 能够可靠地计量归属于该无形资产开发阶段的支出。”

<a id="s139-chap_21_navPoint_idp1712330456"></a>
#### <a id="s139-EX21.40.21"></a>EX 21.40.21 – 迁移至基于云的 IT 基础设施模式所发生的成本

参考准则：IFRIC 议程决议 2021年3月；IAS 38 第8段  
参考正文：[21.40.4](38.md#s134-Para_21.40.4)

某报告主体此前使用“本地部署”软件模式，于本年度切换至 SaaS 模式。在实施这一变更过程中，该主体在本期发生了 CU105 的设置成本。这些成本不属于年度服务费的一部分，而是本期为建立新的 SaaS 运营模式而发生的。该主体对成本评估汇总如下：

CU5 用于数据清理和转移；

CU5 用于员工培训；

CU45 用于 SaaS 软件的配置，即设置软件的标记、开关及参数；以及

CU50 用于各类 ERP 工具、门户和报告功能之间的接口（这些接口是为主体量身定制的，且主体控制该软件）。主体自行开发了这些接口。

**问题**

本期发生的 CU105 成本应如何进行会计处理？

**解答**

用于数据清理和转移的 CU5 并未创造出主体将从中获得经济利益的资源。这是因为数据原本已经存在，且未以任何方式得到增强。主体发生此项成本仅是为了保留数据，以便其在新系统中可用。因此，数据转移成本不符合无形资产的定义，应在发生时计入费用。

CU5 的培训成本无法与开发整个业务的成本区分开来，应在发生时计入费用。[IAS 38 第15段]。[IAS 38 第69段]。

对于为配置 SaaS 协议而发生的 CU45，主体不应确认无形资产，因为主体不控制所配置的软件，且这些配置活动并未创造出独立于该软件的、由主体控制的资源。然而，如果这些成本是在提供相关服务之前预付的，则可能符合作为预付款项予以资本化的条件（关于预付款项的详细讨论，参见第[21.45](38.md#s135-Para_21.45)段和第[21.46](38.md#s135-Para_21.46)段）。

对于为创建接口而发生的 CU50，主体创造了一项由其控制的资产，该资产是预期能为主体带来未来经济利益的资源。该资产可单独辨认，且由于受主体控制，符合无形资产的定义。[IAS 38 第8段]。[IAS 38 第11段]。[IAS 38 第12段]。主体应考虑是否满足开发成本的确认标准。[IAS 38 第57段]。如果满足这些标准，主体应将 CU50 资本化为无形资产，并在其使用寿命内摊销。

#### <a id="s139-EX21.40.22"></a>EX 21.40.22 – 与 SaaS 不可分割的 SaaS 源代码定制

参考准则：IFRIC 议程决议 2021年3月；IAS 38 第69段  
参考正文：[21.40.5](38.md#s134-Para_21.40.5)

某银行业客户实施了一项 SaaS 安排，以促进银行顾问与其客户之间的互动。由于当前平台未能涵盖所有监管要求，双方同意需要对基础解决方案进行定制，并通过介入源代码纳入某些功能，例如：

- 开发新的数据字段以收集个人数据，如投资目标（例如，投资目标可以是为退休储蓄）；

- 建立文档库以存放提供给客户的文档；以及

- 为客户添加一个用于与其客户沟通的信箱。

上述活动由 SaaS 提供商执行，客户预付了这些成本。

**问题**

该主体能否将定制成本资本化？

**解答**

客户得出结论，配置或定制（“CC”）服务与 SaaS 服务不可明确区分，因为配置或定制显著修改了将提供的服务。相关风险不可分割，因为如果不进行修改以满足监管要求，就无法提供 SaaS 服务。

配置或定制成本应资本化为预付款项，并在 SaaS 合同期内摊销。

<a id="s139-chap_21_navPoint_idp1718476024"></a>
#### <a id="s139-EX21.40.23"></a>EX 21.40.23 – 确定第三方在实质上是否为分包商

参考准则：IFRIC 议程决议 2021年3月  
参考正文：[21.40.6](38.md#s134-Para_21.40.6)

确定第三方在实质上是否为分包商可能涉及运用重大判断。在考虑第三方在实质上是否可能为 SaaS 提供商的分包商时，主体可以考虑包括但不限于以下因素（此清单并非详尽或决定性的）：

- SaaS 提供商与第三方之间的合同及工作关系如何；例如，SaaS 提供商是否对第三方如何执行工作有一定发言权（或以某种方式作出指示）？

- 第三方在主 SaaS 协议项下有哪些义务（如有）？

- 该合同是否为客户、SaaS 提供商和第三方之间的三方安排？

- SaaS 提供商的合同条款是否以第三方完成配置或定制（“CC”）为条件或依赖于此，反之亦然？

- 第三方提供商的客户是谁？是 SaaS 提供商还是底层 SaaS 服务的用户？

- SaaS 提供商在聘用第三方过程中参与程度如何（即 SaaS 提供商是否确定了第三方工作的规格和范围）？

- 谁对第三方提供的服务负主要责任（即如果出现与配置或定制相关的问题，客户会联系谁）？

如果第三方被视为实质上是 SaaS 提供商的分包商，主体接下来需要评估配置或定制服务是否可与 SaaS 协议明确区分，如[第21.40.6段](38.md#s134-Para_21.40.6)所述。

<a id="s139-chap_21_navPoint_idp1718494968"></a>
#### <a id="s139-EX21.40.24"></a>EX 21.40.24 – 第三方是 SaaS 提供商的分包商

参考准则：IFRIC 议程决议 2021年3月  
参考正文：[21.40.6](38.md#s134-Para_21.40.6)

某主体正在为其人力资源职能实施一项新的 SaaS 安排。作为该安排的一部分，主体需要在提供 SaaS 服务之前发生大额配置或定制（“CC”）成本。由第三方提供该配置或定制服务。SaaS 提供商必须在开始履行 SaaS 履约义务之前批准第三方的工作，以确保 SaaS 服务将按预期运行，并且如果为了提供 SaaS 服务而需要进一步修改，SaaS 提供商对此负责。

**问题**

该第三方是否充当 SaaS 提供商的分包商？

**解答**

SaaS 提供商必须在开始履行 SaaS 履约义务之前批准第三方的工作，并对所执行工作的充分性负责。因此，主体很可能得出结论认为该第三方在实质上是 SaaS 提供商的分包商。

**相关信息**

#### <a id="s139-EX21.40.25"></a>EX 21.40.25 – 第三方不是 SaaS 提供商的分包商

参考准则：IFRIC 议程决议 2021年3月  
参考正文：[21.40.6](38.md#s134-Para_21.40.6)

某主体正在为其人力资源职能实施一项新的 SaaS 安排。作为该安排的一部分，主体需要在提供 SaaS 服务之前发生大额配置或定制（“CC”）成本。由第三方提供该配置或定制服务。配置或定制合同是在第三方与主体之间签订的，SaaS 提供商未参与其中。如果因配置或定制导致提供 SaaS 服务出现问题，第三方负责解决这些问题直至主体满意。

**问题**

该第三方是否充当 SaaS 提供商的分包商？

**解答**

SaaS 提供商并非第三方与主体之间合同的当事方，也不负责解决有关配置或定制服务的任何问题。因此，主体很可能认定该第三方在实质上并非充当 SaaS 提供商的分包商，而是作为主体的供应商。

<a id="s139-chap_21_navPoint_idp1718530808"></a>
#### <a id="s139-FAQ_21.40.26"></a>FAQ 21.40.26 – 额外代码何时可以资本化为无形资产？

参考准则：IFRIC 议程决议 2021年3月；IAS 38 第8段  
参考正文：[21.40.4](38.md#s134-Para_21.40.4)

在平台即服务（PaaS）安排中，客户通常会在供应商提供的基础设施和中间件之上自行开发（或委托他人开发）其应用程序。在 SaaS 安排中，客户在实施 SaaS 期间也经常在 SaaS 核心代码之上自行开发（或委托他人开发）额外代码。在这两种情况下，客户都应仔细评估其是否将该额外代码作为独立于 PaaS 或 SaaS 的无形资产予以控制。下面的示例演示了 SaaS 情况下的分析。类似原则同样适用于 PaaS 情况。

**示例 1.1 – SaaS 实施期间开发的额外代码。**

**背景**

主体 A 和主体 B 分别与 SaaS 供应商 S 签订了 SaaS 安排。

主体 A 委托第三方开发者为额外模块开发额外代码，以使 SaaS 解决方案能够与主体 A 的现有系统集成。主体 A 拥有该特定代码的副本，并将其部署至 SaaS 供应商的云环境中。主体 A 负责该额外代码的维护和更新，以确保其能够继续与 SaaS 解决方案及主体 A 的现有系统协同工作。在主体 A 验收该额外代码后，主体 A 还向该第三方开发者采购了后续维护和更新服务。

主体 B 的事实模式相同，不同之处在于主体 B 在 SaaS 安排之外单独委托 SaaS 供应商 S 开发该额外代码，并提供后续维护和更新服务。一旦主体 B 验收该额外代码，SaaS 供应商 S 仅负责维护和更新。如果 SaaS 安排发生故障，不被视为额外代码维护和更新服务的违约。同样，如果额外代码的维护和更新服务发生故障，也不被视为 SaaS 安排的违约。

该额外代码仅适用于供应商 S 提供的 SaaS 解决方案。

作为整体 SaaS 安排的一部分，SaaS 供应商 S 将在其云环境中托管该额外代码。主体 A 和主体 B 在托管期间随时拥有占有该额外代码的实质性权利。

**解答**

主体 A 和主体 B 均应将直接归属于该额外代码的成本确认为一项无形资产。该额外代码符合无形资产的定义，因为它是独立于 SaaS 的可辨认资产，且分别由主体 A 和主体 B 控制。确认标准也得到满足。

在某些情况下，可能难以确定 SaaS 提供商是在为主体开发一项单独的无形资产，还是仅仅在增强将向主体提供的 SaaS 服务。在本例中，当 SaaS 提供商为主体 B 开发额外代码时，使用该额外代码的许可独立于 SaaS 安排，因为履约风险是分离的。额外代码的使用依赖于 SaaS 环境这一事实不影响该控制权评估，但在评估该无形资产的使用寿命时将予以考虑（参见 [FAQ 21.40.27 – 独立于 SaaS 确认的无形资产的摊销期限是多久？](38.md#s139-FAQ_21.40.27)）。

<a id="s139-chap_21_navPoint_idp1718554488"></a>
#### <a id="s139-FAQ_21.40.27"></a>FAQ 21.40.27 – 独立于 SaaS 确认的无形资产的摊销期限是多久？

参考准则：IFRIC 议程决议 2021年3月；IAS 38 第8段  
参考正文：[21.40.4](38.md#s134-Para_21.40.4)

主体应适用 IAS 38 来评估独立于 SaaS 的无形资产（例如根据 [FAQ 21.40.26 – 额外代码何时可以资本化为无形资产？](38.md#s139-FAQ_21.40.26) 资本化的额外代码）的使用寿命。这将包括对以下因素（除其他因素外）的估计：

- 如果该无形资产的使用依赖于 SaaS，则需考虑持续访问兼容 SaaS 解决方案的期限（例如，是否预期 SaaS 安排将续期）；以及

- SaaS 解决方案及该单独无形资产的技术过时情况。

<a id="s139-chap_21_navPoint_idp1718424952"></a>
#### <a id="s139-FAQ_21.40.28"></a>FAQ 21.40.28 – 与软件即服务（SaaS）安排实施相关的设计成本能否资本化为无形资产？

参考准则：IFRIC 议程决议 2021年3月；IAS 38 第8段  
参考正文：[21.40.4](38.md#s134-Para_21.40.4)

实施大型、复杂的 SaaS 解决方案通常需要投入大量精力来设计针对特定公司的解决方案，包括：

- 对开箱即用 SaaS 解决方案的定制或配置；

- 对公司现有系统和流程的增强和升级；以及

- 将定制或配置后的 SaaS 解决方案与增强和升级后的系统和流程进行集成。

IFRS IC 讨论了 SaaS 安排中定制和配置成本的会计处理。委员会指出，主体通常不会确认无形资产，因为它不控制所配置或定制的软件，且这些活动并未创造出独立于该软件的资产。IFRS IC 并未具体讨论设计成本的会计处理，包括与确定所需 SaaS 定制和配置适当程度相关的成本。

当单独评估这些成本时，只有当它们代表由主体控制的可辨认资产并满足确认标准时，才能予以资本化。主体可能需要运用重大判断，以确定是否存在可辨认资产以及设计文档是否提供可辨认的未来经济利益。

一项资产在满足以下条件之一时具有可辨认性：

- 具有可分离性，即能够从主体中分离或划分出来，并能单独或与相关合同、可辨认资产或负债一起用于出售、转移、授予许可、租赁或交换，无论主体是否打算这样做；或

- 源自合同性权利或其他法定权利，无论这些权利是否可以从主体或其他权利和义务中转移或分离。

确定系统设计是否具有可辨认性需要运用判断。关键考虑因素可能包括：

- 设计文档是否能够与 SaaS 解决方案以及企业的持续日常活动相分离。企业不需要打算出售、转移或授权该设计蓝图，但为了使该设计被视为具有可分离性，它需要以一种形式存在，使得如果主体选择进行此类交易，该交易在实务上是可行的。在作出这一判断时，主体考虑如果其在企业合并中被收购，该设计成本是否会被识别为一项单独的无形资产可能会有所帮助。

- 主体需要仔细考虑就设计活动授予的任何法定或合同性权利是否具有实质性。例如，与第三方签订的合同可能会为主体提供在实施过程中创建的知识产权的永久许可。该合同权利应旨在为主体提供对该设计的法定/合同性权利，而不仅仅是为第三方提供在其他类似项目中使用该知识产权的保护。确定这些权利的性质以及它们是否支持 IAS 38 下的无形资产定义需要运用判断。

如果确定该资产具有可辨认性，主体还需要考虑除了实施本身之外的预期未来经济利益是否很可能实现。无形资产带来的未来经济利益可能包括销售产品或服务的收入、成本节约或主体使用该资产产生的其他利益。

如果识别出一项无形资产，评估哪些成本代表作为资产成本一部分予以资本化的开发支出非常重要。在研究或评估阶段为评估不同方案而发生的成本应计入费用。

如果设计成本不能整体确认为无形资产，在某些情况下，将设计成本在实施项目的不同要素之间进行分摊，并将与另一项无形资产相关的部分设计成本予以资本化可能是可行的。例如，部分设计活动可能与开发由主体控制且独立于 SaaS 的软件无形资产有关，或与增强现有软件无形资产有关。在这种情况下，将直接归属于该单独软件无形资产开发的那部分设计成本予以资本化可能是恰当的。

#### <a id="s139-FAQ_21.40.29"></a>FAQ 21.40.29 – 托管软件安排何时包含从供应商处取得的单独软件（或软件许可）？

参考准则：IFRIC 议程决议 2019年3月  
参考正文：[21.40.1](38.md#s134-Para_21.40.1)

**背景：**

在供应商提供托管软件的安排中，客户（主体）并不占有供应商所许可的软件；相反，托管软件驻留在供应商或供应商选定的第三方的基础设施上，主体远程访问该软件。

某些托管软件安排可能作为服务进行会计处理，例如软件即服务（SaaS）安排。但是，该安排也可能是软件（或软件许可）的销售加上该软件的单独托管服务。一项安排并不仅仅因为软件托管在供应商（或供应商聘用的第三方）的基础设施上就必然是 SaaS 安排。

**问题**：托管软件安排何时包含从供应商处取得的软件（或软件许可）？

**解答：**

主体应评估其是否控制独立于托管服务的软件（或软件许可）。如果主体拥有在托管期内随时占有该软件的合同权利，且该权利具有实质性，则该软件通常会被视为独立于托管服务的单独计量单元。

例如，如果满足以下条件，该权利将具有实质性：

- 主体有能力在不支付重大罚金的情况下占有该软件；且

- 主体自行运行该软件或与第三方（与供应商无关）签订托管服务合同在实务上是可行的。

重大罚金既可能是提取软件交付的重大成本，也可能是如果单独使用该软件时其效用或价值的重大减损。

主体可能需要运用判断来确定该权利是代表取得软件（或软件许可）控制权的选择权，还是表明主体已经控制了该软件（或软件许可）。例如，SaaS 合同中允许终止剩余 SaaS 合同期限并签订该软件本地部署版本许可协议的选择权，并不一定证明主体在合同开始时就控制了一项单独的软件许可。

#### <a id="s139-EX21.53.1"></a>EX 21.53.1 – 发行股份作为取得无形资产的对价

参考准则：IFRS 2 第10、13段  
参考正文：[21.53](38.md#s135-Para_21.53)

某主体发行 100,000 股每股面值 C1 的普通股，以取得一项包含若干权利的无形资产。类似的无形资产经常在现金交易中交换，且该主体曾收到一份以 C300,000 的现金价格购买类似资产的报价。这与类似交易中支付的价格一致。交易日该主体普通股的价格为 C2.95。该无形资产应按何种价值初始确认？

该资产应按所取得权利的公允价值确认。类似资产存在交换交易和现金价格，意味着这些权利的公允价值能够可靠地确定为 C300,000。该资产按此金额入账。

如果这些权利的公允价值无法可靠计量，则该资产将按 C295,000 入账，即所发行权益工具的公允价值。

#### <a id="s139-EX21.54.1"></a>EX 21.54.1 – 专利权交换

参考准则：IAS 38 第45段  
参考正文：[21.54](38.md#s135-Para_21.54)

主体 A 持有一项账面价值为 C3,000 的专利权。主体 A 同意以其专利权交换主体 B 的专利权。双方均评估主体 A 专利权的公允价值为 C5,000。主体 B 的专利权无法可靠计量。该交换中不包含额外的货币性或非货币性对价。

主体 A 将以 C5,000 的成本记录其取得的专利权。如果另一项资产的公允价值无法可靠计量，双方均采用能够可靠计量的那项资产的公允价值作为对价的价值。该交易产生 C2,000 的利得，由主体 A 在利润表中确认。该金额为主体 A 原专利权的账面价值（C3,000）与换出专利权的公允价值（C5,000）之间的差额。专利权本质上是独一无二的，因此该交换具有商业实质。

<a id="s139-chap_21_navPoint_idp1721225688"></a>
#### <a id="s139-EX21.54.2"></a>EX 21.54.2 – 对价包含非货币性资产和货币性资产的组合

参考准则：IAS 38 第45段  
参考正文：[21.54](38.md#s135-Para_21.54)

当收到或付出的对价包含非货币性资产和货币性资产的组合时，公允价值应按付出或收到的货币性资产（例如现金）金额进行调整。

某主体将其在日本分销某产品的权利（账面价值为 C100万（C1 million），但公允价值为 C120万（C1.2 million））交换为 C500,000 现金以及在欧洲分销同一产品的权利（公允价值为 C700,000）。C500,000 的现金实质上是所交换资产公允价值的差额（C120万 – C700,000）。欧洲分销权按 C700,000 入账，等于日本分销权的公允价值 C120万 减去收到的现金 C500,000。该交易产生 C200,000 的利得，在利润表中确认。

#### <a id="s139-EX21.55.1"></a>EX 21.55.1 – 以研究与开发项目交换营销权

参考准则：IAS 38 第46段  
参考正文：[21.55](38.md#s135-Para_21.55)

主体可能以一项研究与开发项目交换营销某项专利产品的权利。已开发产品的现金流量配置与研究与开发项目的现金流量配置不同（例如，不再有开发支出的现金流出）。该交换具有商业实质。

#### <a id="s139-EX21.56.1"></a>EX 21.56.1 – 电话牌照交换

参考准则：IAS 38 第46段  
参考正文：[21.56](38.md#s135-Para_21.56)

某主体提供固定电话服务，依据五年前从政府取得的牌照运营。根据牌照条款，该主体需在第7年之前达到特定区域至少67%的服务覆盖率。未能达到该标准将导致罚款并可能被吊销牌照。目前，该主体仅实现了31%的覆盖率。政府正在向新进入者发放新牌照，持新牌照可同时提供固定电话和移动电话服务，且无最低覆盖率要求。现有运营商有权将其原有牌照更换为新牌照。尽管管理层不打算拓展移动电话服务业务，但仍决定更换其牌照。

该交换交易被视为具有商业实质。该主体不太可能达到现有牌照下的最低覆盖率要求，届时将面临罚款并可能被吊销牌照。由于该交换，受交易影响的主体那部分经营活动的特定主体价值发生了变化。主体不打算根据新的固定/移动牌照将业务拓展至移动电话服务这一事实并不相关。

#### <a id="s139-EX21.57.1"></a>EX 21.57.1 – 交换交易产生的利得或损失

参考准则：IAS 38 第46段  
参考正文：[21.57](38.md#s135-Para_21.57)

如果主体在交易后处于与交易前相同的状况且其净资产未发生重大变化，则交换交易不确认利得或损失。新资产的成本为换出资产的账面价值。

但是，换入资产的公允价值可能为换出资产产生利得或发生减值提供证据。如果换入资产的价值不同，则该交换具有商业实质。在这种情况下，取得的资产应按公允价值入账。

如果取得资产的价值低于换出资产的价值，则应确认处置损失。

#### <a id="s139-FAQ_21.62.1"></a>FAQ 21.62.1 – 哪些职工薪酬成本可以资本化？

参考准则：IAS 19 第4、7段 参考正文：[21.62](38.md#s135-Para_21.62)

职工薪酬定义为主体为换取职工提供的服务而给予的所有形式的对价。[IAS 19 第7段]。薪酬类型包括：

- 短期职工薪酬，如工资、薪金和社会保障缴款、带薪年假和带薪病假、利润分享和年度奖金，以及非货币性福利（如医疗保健、住房和免费或补贴的商品或服务）。

- 离职后福利，如养老金、其他退休福利、离职后人寿保险和离职后医疗保健。

- 其他长期职工福利，包括长期服务假或学术休假、周年庆或其他长期服务福利、长期伤残福利以及递延奖金或利润分享和其他递延薪酬。

- 辞退福利。

[IAS 19 第4段]。

员工股份计划成本、社会保障成本以及主体养老金缴款可能被视为直接归属成本。如果这些成本是为使资产达到按照管理层意图的方式运行所需的条件而发生的，则属于直接归属成本。

使资产达到工作状态而直接产生的职工薪酬成本无需是增量成本。无需为使资产达到预定用途而专门雇用某员工，其职工薪酬成本即可资本化。只要该员工在相关项目上投入了工作时间即可。

辞退福利极少（甚至从不）与资本化相关。按定义，辞退福利提供给即将离职或已经离职的员工，这些员工不太可能对资产的开发作出贡献。

#### <a id="s139-EX21.64.1"></a>EX 21.64.1 – 与主体数据库相关的促销成本和经营亏损

参考准则：IAS 28 第67段  
参考正文：21.64

某主体开发了一个包含在2014年至2020年间年满25周岁的专业人士姓名和地址的数据库。管理层打算通过向为初级管理人员提供生活品质提升产品和解决方案的供应商出售这些信息来开发利用该数据库。该主体正在发生向此类解决方案供应商（如探险度假公司）推广该数据库的成本。由于存在大额行政管理成本且尚无收入，该主体也在发生亏损。既然在建立客户群之前该数据库无法按管理层意图运行，该主体能否将促销成本和经营亏损资本化？

促销成本不符合作为无形资产成本一部分予以资本化的条件。该数据库已经能够按照管理层意图的方式运行（即能够提供管理层希望开发利用的信息）。尽管建立客户群对于确保实现预期从该资产获得的未来经济利益至关重要，但并非数据库运行所必需。开办亏损也不符合资本化条件，因为它们并非生成该数据库的直接归属成本。

#### <a id="s139-EX21.65.1"></a>EX 21.65.1 – 员工成本何时可以资本化

参考准则：IAS 38 第30段  
参考正文：[21.65](38.md#s135-Para_21.65)

项目开发阶段的员工成本可能满足资本化标准。然而，一旦开发项目完成，如果这些员工随后开始从事另一个研究项目的工作，其成本就不能再予以资本化。

#### <a id="s139-EX21.80.1"></a>EX 21.80.1 – 此前未确认为无形资产的牌照

参考准则：IAS 38 第76段  
参考正文：[21.80](38.md#s136-Para_21.80)

多年来，某主体可能以名义对价积累了若干在活跃市场上交易的同类牌照。由于这些牌照在取得时单项金额不重大，该主体并未确认无形资产。近期此类牌照的市场价格大幅上涨，该主体持有的牌照价值显著增加。然而，IAS 38 禁止该主体对这些牌照采用重估模式，因为它们此前未被确认为资产。

<a id="s139-chap_21_navPoint_idp1721364312"></a>
#### <a id="s139-FAQ_21.85.1"></a>FAQ 21.85.1 – 网站能否采用重估模式？

参考准则：IAS 38 第78段  
参考正文：[21.85](38.md#s136-Para_21.85)

网站通常按成本减去摊销列示。IAS 38 允许的重估模式不适用。网站地址是独一无二的，网站不存在活跃市场。

#### <a id="s139-EX21.97.1"></a>EX 21.97.1 – 产品分销权的摊销

参考准则：IAS 38 第97段  
参考正文：[21.97](38.md#s136-Para_21.97)

某主体于 20X0 年 1 月 1 日取得牌照和商标，包括产品分销权。在该日，牌照和产品分销权仍需获得某些监管批准。20X0 年 3 月 1 日，该主体获得分销产品的监管批准。管理层提议自 20X0 年 3 月 1 日起开始摊销这些权利。摊销将在无形资产可供使用时开始。

所取得无形资产的摊销只能推迟至该无形资产达到可供使用状态之时。所取得的权利将自 20X0 年 3 月 1 日起的一段期间内被消耗，因此应在该期间内进行摊销。

<a id="s139-chap_21_navPoint_idp1721388376"></a>
#### <a id="s139-FAQ_21.101.1"></a>FAQ 21.101.1 – 使用寿命涵盖哪些期间？

参考准则：IAS 38 第8段  
参考正文：[21.101](38.md#s136-Para_21.101)

使用寿命包括取得后资产已能够按照管理层意图的方式运行、但尚未投入使用的任何期间。

资产使用寿命的结束并不一定是其经济寿命的结束。经济寿命是指无论当时由谁使用，资产产生经济利益的期间。使用寿命是指主体使用该资产的期间。如果主体以 C100 购买了一项经济寿命为十年的资产，但主体仅打算使用该资产六年，则主体为该资产确定的使用寿命应为六年而非十年。届时有必要估计六年末的残值（参见[第21.118段](38.md#s136-Para_21.118)）。

#### <a id="s139-EX21.103.1"></a>EX 21.103.1 – 估计资产使用寿命时需考虑的其他因素

参考准则：IAS 38 第90段  
参考正文：[21.103](38.md#s136-Para_21.103)

管理层在确定资产的使用寿命时会考虑诸多因素。

以下是与[第21.103段](38.md#s136-Para_21.103)所列因素相关的示例：

- 该资产的典型产品生命周期。这可以通过与从事类似业务并使用类似资产的公司财务报表中披露的使用寿命进行比较来确定。

- 维持该资产运营能力所需的维护水平。例如，维持商标价值所需的广告支出。

#### <a id="s139-EX21.103.2"></a>EX 21.103.2 – 购买方不打算使用或打算以不同于其他市场参与者的方式使用的无形资产的使用寿命

参考准则：IAS 38 第90段  
参考正文：[21.103](38.md#s136-Para_21.103)

在企业合并中取得的、购买方不打算积极使用但打算阻止他人使用的无形资产，通常称为“防御性资产”或“锁定资产”。该资产很可能有助于增加购买方拥有的其他资产的现金流量。购买方既不打算使用、也不打算阻止他人使用的无形资产不属于防御性资产。

区分防御性无形资产与一般无形资产（示例1）

主体 A 是一家消费品制造商，收购了一家销售与主体 A 某现有产品竞争的产品的实体。主体 A 计划在未来六个月内停止销售该竞争产品。主体 A 将以极低成本保留该商号的权利，以防止竞争对手使用它。主体 A 现有产品的市场份额预计将会增加。主体 A 目前没有在未来重新推出所收购商号的计划。

该商号符合防御性无形资产的定义，因为主体 A 不打算积极使用所收购的商号，但打算持有该商号的权利以阻止其竞争对手使用。该商号的使用寿命应为主体 A 打算持有该商号权利的期间。

区分防御性无形资产与一般无形资产（示例2）

主体 A 收购了一项业务，所收购的资产之一是被购买方为自用而开发的计费软件。主体 A 计划在六个月过渡期后停止使用该内部开发的计费软件。主体 A 确定，市场参与者会将该计费软件与资产组中的其他资产一起在其全部剩余经济寿命内使用。主体 A 不打算以最佳用途方式使用该资产。主体 A 认为该软件无法在不附带其他所收购资产的情况下出售给第三方。

主体 A 并非为了阻止竞争对手使用而持有该内部开发的软件。该内部开发的软件资产不符合防御性无形资产的定义。这将该内部开发的软件可供主体 A 使用的期间限制为六个月。参见 [FAQ 21.101.1](38.md#s139-FAQ_21.101.1)。

#### <a id="s139-EX21.106.1"></a>EX 21.106.1 – 版权的法定寿命超过经济寿命

参考准则：IAS 38 第95段  
参考正文：[21.106](38.md#s136-Para_21.106)

某主体取得一项剩余法定寿命为50年的版权。该主体确定该版权的经济寿命仅为30年（即仅在30年内产生经济利益）。该主体必须在30年内摊销该版权。使用经济寿命定义为主体预期使用该资产的期间，此处限于30年。主体在30年后将不再使用该资产，并且必须在预期通过其使用不再产生未来经济利益时终止确认该资产（参见[第21.134段](38.md#s137-Para_21.134)）。

<a id="s139-chap_21_navPoint_idp1698035672"></a>
#### <a id="s139-EX21.109.1"></a>EX 21.109.1 – 如何对被替换资产的账面价值及续期成本进行会计处理

参考准则：IAS 38 第96段  
参考正文：[21.109](38.md#s136-Para_21.109)

被替换无形资产的账面价值应在续期日之前全额摊销完毕，如果满足确认标准，续期成本随后作为一项新无形资产予以资本化。

<a id="s139-chap_21_navPoint_idp1698044376"></a>
#### <a id="s139-EX21.109.2"></a>EX 21.109.2 – 广播牌照的确定续期

参考准则：IAS 38 第96段  
参考正文：[21.109](38.md#s136-Para_21.109)

某主体取得了一项五年后到期的广播牌照。该牌照只需极少成本即可续期，且过去已成功续期两次。没有任何因素表明该牌照不会再次获准续期，且主体打算续期。该牌照预计将无限期地为主体的现金流量作出贡献。

该无形资产的使用寿命按不确定处理，且该牌照不予摊销。如果法定寿命有限的无形资产无需付出重大成本即可由主体续期且预期将会续期，则可以将其使用寿命视为不确定。

<a id="s139-chap_21_navPoint_idp1698057944"></a>
#### <a id="s139-EX21.109.3"></a>EX 21.109.3 – 无续期保证的广播牌照

参考准则：IAS 38 第96段  
参考正文：[21.109](38.md#s136-Para_21.109)

某主体取得了一项五年后到期的广播牌照。该牌照的续期既无保证，甚至也不太可能。广播监管机构决定，未来在牌照到期续期时将采用拍卖方式，而非自动续期。广播监管机构是在该牌照尚余三年期限时作出这一决定的。

该牌照在剩余的三年内进行摊销，因为续期及续期成本均存在不确定性。

<a id="s139-chap_21_navPoint_idp1698071256"></a>
#### <a id="s139-EX21.111.1"></a>EX 21.111.1 – 确定使用寿命不确定时的其他考虑因素

参考准则：IAS 38 第91段  
参考正文：[21.111](38.md#s136-Para_21.111)

“不确定（Indefinite）”并不等同于“无限（infinite）”（在范围上没有尽头）。不确定意味着无法预见该资产预期为报告主体的现金流量作出贡献的期限。

无形资产使用寿命不确定通常要求相关业务、行业和产品具有稳定的历史记录和较高的市场准入门槛。此外，还需要管理层承诺持续进行长期投资，以延长该无形资产预期继续提供经济利益的期间。对于已经证明能够经受变化考验的成熟品牌，使用寿命不确定可能是合理的。而对于其他相对较新的品牌、依赖个人声誉（例如电影明星）的品牌，或在波动性较大、更易受时尚或技术变化影响的行业中运营的品牌，有限的使用寿命可能更为恰当。

<a id="s139-chap_21_navPoint_idp1698072664"></a>
#### <a id="s139-EX21.111.2"></a>EX 21.111.2 – 客户关系的使用寿命

参考准则：IAS 38 第91段  
参考正文：[21.111](38.md#s136-Para_21.111)

主体 A 收购了运营一家电视频道的主体 B。主体 B 直接与广告商（大多为大型公司）协商播出时间的销售。广告合同每年协商一次，管理层认为这些关系很可能会无限期持续下去。

主体 A 的管理层提议将客户关系确认为无形资产，并赋予该关系不确定的使用寿命。

当无法预见资产预期产生现金流入的期限时，该资产才具有不确定的使用寿命。[IAS 38 第88段]。客户关系不太可能具有不确定的使用寿命，因为客户的所有权可能发生变化、战略可能发生变化，且更多竞争对手可能进入主体 B 的市场。

管理层应考虑所有相关因素，例如历史经验、合同期限、竞争对手和生命周期，以确定客户关系的使用寿命。

客户关系的使用寿命预计是有限的，应综合考虑所有相关因素（如上所述）进行估计。

<a id="s139-chap_21_navPoint_idp1698177496"></a>
#### <a id="s139-EX21.114.1"></a>EX 21.114.1 – 使用寿命不确定商标的预期未来现金流量变动

参考准则：IAS 38 示例  
参考正文：[21.114](38.md#s136-Para_21.114)

一项十年前取得的商标此前被评估为使用寿命不确定。然而，竞争加剧使预期未来现金流入减少了20%。该商标及相关业务仍预计将无限期持续，因为尽管现金流入将减少20%，该业务仍将为主体产生现金净流入。该无形资产仍被视为具有不确定的使用寿命。对于使用寿命不确定的无形资产，任何情况变化均应仔细考虑，以判断使用寿命不确定的处理是否仍然合理。

<a id="s139-chap_21_navPoint_idp1698180568"></a>
#### <a id="s139-EX21.115.1"></a>EX 21.115.1 – 商标使用寿命从不确定变更为有限

参考准则：IAS 38 示例  
参考正文：[21.115](38.md#s136-Para_21.115)

一项数年前取得的商标一直按使用寿命不确定进行处理。管理层曾预期无限期持续相关业务，且作为使用寿命不确定无形资产处理的所有其他条件均已满足。然而，管理层现已决定在未来四年内终止该业务。该无形资产应在主体使用该资产的剩余四年内进行摊销。如果对无形资产使用寿命的评估从不确定变更为有限，则应在该剩余有限使用寿命内对该资产进行摊销。当使用寿命从不确定变更为有限时，还必须对该资产进行减值测试。

<a id="s139-chap_21_navPoint_idp1698186584"></a>
#### <a id="s139-EX21.117.1"></a>EX 21.117.1 – 具有承诺残值的专利权的使用寿命

参考准则：IAS 38 第100段  
参考正文：[21.117](38.md#s136-Para_21.117)

主体 A 取得一项经济寿命为15年的专利权。主体 A 预计使用该专利权五年，并打算在五年后将其出售给主体 B。主体 B 已承诺以主体 A 成本的60%购买该专利权。主体 A 在五年内（即主体 A 的使用寿命）摊销该无形资产的可折旧金额。由于残值为60%，可折旧金额为该资产成本的40%。

可折旧金额即待摊销金额（即成本减去残值）。由于第三方已承诺在五年后购买该资产，因此可以反驳残值为零的假定。

<a id="s139-chap_21_navPoint_idp1698196184"></a>
#### <a id="s139-EX21.119.1"></a>EX 21.119.1 – 确定残值时应考虑的因素

参考准则：IAS 38 第8、100段  
参考正文：[21.119](38.md#s136-Para_21.119)

残值基于作出残值估计之日的现行价格。该价值不考虑作出估计之日后的预期未来通货膨胀。

如果第三方已承诺在资产使用寿命结束时购买该资产，则其残值应为第三方应付的金额，并经调整以剔除未来通货膨胀的影响。

<a id="s139-chap_21_navPoint_idp1698213208"></a>
#### <a id="s139-FAQ_21.121.1"></a>FAQ 21.121.1 – 无形资产的残值何时可能大于零？

参考准则：IAS 38 第103段  
参考正文：[21.121](38.md#s136-Para_21.121)

仅当“假定残值为零”规则的两项例外情况之一适用时，才会出现这种情况（[参见第21.117段](38.md#s136-Para_21.117)）：

- 第三方承诺在该资产使用寿命结束时购买该资产；或

- 可以参照该无形资产的活跃市场确定残值，且在该资产使用寿命结束时该市场很可能存在。

使用寿命有限的无形资产无需摊销的可能性微乎其微。

<a id="s139-chap_21_navPoint_idp1698225240"></a>
#### <a id="s139-EX21.123.1"></a>EX 21.123.1 – 摊销方法的选择

参考准则：IAS 38 第97段  
参考正文：[21.123](38.md#s136-Para_21.123)

摊销方法的选择基于无形资产未来经济利益的预期消耗方式。如果未来经济利益的消耗是随时间推移进行的（例如在固定年限内运营的专利权和牌照），则直线法通常是最恰当的方法。

如果未来经济利益的消耗是通过使用或生产进行的（例如开采矿产资源），则产量法很可能是最恰当的方法。所采用的摊销方法取决于主体对该资产经济利益消耗的预期，以及主体可靠计量该资产预期使用量或产量的能力。如果无法可靠确定消耗方式，默认方法为直线法。

<a id="s139-chap_21_navPoint_idp1698229208"></a>
#### <a id="s139-EX21.123.2"></a>EX 21.123.2 – 直线法的应用

参考准则：IAS 38 第97段  
参考正文：[21.123](38.md#s136-Para_21.123)

直线法摊销是指将资产的成本或重估金额减去其残值后的金额，在资产的使用寿命内系统地分摊至各会计期间。除非使用寿命或残值发生变化，否则每个期间计提的金额相同。

<a id="s139-chap_21_navPoint_idp1698235736"></a>
#### <a id="s139-EX21.125.1"></a>EX 21.125.1 – 无形资产固有的主要限制因素

参考准则：IAS 38 第98A段  
参考正文：[21.125](38.md#s136-Para_21.125)

主体在确定恰当的摊销方法时，可以考察无形资产固有的主要限制因素。无形资产的使用可能受限于特定时间期限或特定产量。然而，主要限制因素也可能被确定为收入。例如，主体可能拥有运营一条收费公路的权利，直至累计收取的通行费达到固定的总收入金额。鉴于收入是主要限制因素，预期产生的收入可能是摊销该无形资产的恰当基础。

<a id="s139-chap_21_navPoint_idp1697987928"></a>
#### <a id="s139-FAQ_21.126.1"></a>FAQ 21.126.1 – 未来经济利益预期消耗方式发生变更的可能性有多大？

参考准则：IAS 38 第104段  
参考正文：[21.126](38.md#s136-Para_21.126)

无形资产的消耗方式在其使用寿命内不太可能发生重大变化，因此摊销方法的变更应当很少见。

示例 – 专利权未来经济利益的预期消耗方式

某主体近期将一种药物开发至生产阶段。该主体为该药物申请了十年期专利。在这十年内，该主体是该药物的唯一销售商。该主体预计需要两年时间建立市场份额。在专利期临近结束时，由于仿制药公司可能挑战该专利，销售额将会下降。

该专利在十年期内提供排他性权利和溢价现金流量。经济利益随时间按比例消耗。

该专利的限制因素是时间。无论该药物成为畅销药超出预期，还是仅实现盈亏平衡，该专利的经济利益都将随时间均匀消耗。

直线法摊销恰当地反映了经济利益的消耗。

#### <a id="s139-EX21.133.1"></a>EX 21.133.1 – 减值迹象

参考准则：IAS 38 第111段  
参考正文：[21.133](38.md#s136-Para_21.133)

如果因预期资产不再产生未来经济利益而不再使用该资产，或如果某项资产暂时闲置，则这将构成相关现金产出单元（CGU）发生减值的迹象，应执行减值复核。

<a id="s139-chap_21_navPoint_idp1714376408"></a>
#### <a id="s139-EX21.141.1"></a>EX 21.141.1 – 资本化支出的终止确认

参考准则：IAS 38 第112(b)段  
参考正文：[21.141](38.md#s137-Para_21.141)

某主体正在开发一套新的 IT 系统，该系统在上一年度满足了作为内部产生的无形资产予以资本化的确认标准。管理层决定在本年度终止该 IT 系统的开发。该主体取消了开发该 IT 系统的合同，并解雇了参与该开发项目的员工。部分完成的 IT 系统没有替代用途，也没有销售价值。

该主体应在本年度终止确认该资产。
