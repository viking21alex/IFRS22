## 引言与范围（第32.1段 - 第32.22段）

 

<a id="s230-Para_32.1"></a>**32.1** 合营安排是指由两方或多方通过合同协议约束并共享控制权的经济合作安排。主体可能出于多种原因与另一方达成合营安排：例如，投资方可能拥有互补的技能；可能需要分担项目的风险；若涉及两方或多方投资方，项目可能受益于规模经济；或者项目规模可能超出单个主体的能力范围。合营安排的目的可能是分担成本，也可能是以盈利为导向。

[IFRS 11 附录A]。

<a id="s230-Para_32.2"></a>**32.2** 合营安排分为两类：共同经营和合营企业。具体归类取决于投资方的权利和义务。共同经营方享有与该安排相关资产的权利，并承担与该安排相关负债的义务。合营方享有与该安排净资产相关的权利。

[IFRS 11 第IN7段]。

<a id="s230-Para_32.3"></a>**32.3** 安排的分类决定了其会计处理方法。共同经营的会计处理是确认共同经营方在相关资产、负债、收入和费用中享有的份额。合营企业则采用权益法进行会计处理。

[IFRS 11 第IN8段]。

<a id="s230-Para_32.4"></a>**32.4** IFRS 11 在要求对合营企业采用权益法核算时，援引了 IAS 28 中的相关规定。

[IFRS 11 第IN10段]。

 

<a id="s230-chap_32_navPoint_2"></a>
### 范围

 

<a id="s230-Para_32.5"></a>**32.5** 合营安排是指两方或多方之间的经济安排，其中共享共同控制的投资方对相关活动作出决策。

[IFRS 11 附录A]。

<a id="s230-Para_32.6"></a>**32.6** 参与方可能出于其他原因参与合营安排，但未必享有共同控制。本准则适用于合营安排的所有参与方，无论其是否对该安排行使共同控制。本准则不适用于合营安排本身的会计处理。

[IFRS 11 第3段]。

[FAQ 32.6.1 – IFRS 11是否适用于合营安排本身的会计处理：共同经营？](57.md#s234-FAQ_32.6.1)  
[FAQ 32.6.2 – 合营安排应如何对其投资方在设立时或其他时间投入的业务进行会计处理？](57.md#s234-FAQ_32.6.2)

<a id="s230-Para_32.7"></a>**32.7** 共同控制与控制是相互排斥的。共同控制的定义隐含着至少必须有两方共享对该安排的控制权。如果单独一方能够控制该安排，则该安排不属于合营安排，不在 IFRS 11 的适用范围内。“当投资方因涉入被投资方而享有可变回报的风险或权利，并且有能力通过其对被投资方的权力影响该回报时，投资方即控制了被投资方。”管理层在得出存在共同控制的结论之前，应首先评估自身是否单独控制该安排。

[IFRS 10 附录A]。

#### 共同控制

 

<a id="s230-Para_32.9"></a>**32.9** “共同控制是指按照合同约定对某项安排所共有的控制，并且该安排的相关活动必须经过分享控制权的参与方一致同意后才能决策。”共同控制的存在并不要求共同经营方和合营方在主体中持有相等的股份。

[IFRS 11 第7段]。

[EX 32.9.1 – 不等额权益](57.md#s234-EX32.9.1)

 

<a id="s230-chap_32_navPoint_idp1686736584"></a>
##### 合同协议

 

<a id="s230-Para_32.10"></a>**32.10** 如果没有具有强制执行力的合同协议，就不可能存在共同控制。该协议证明任何单独一方均无法控制该合营安排。

[IFRS 11 第5(a)、(b)段]。

<a id="s230-Para_32.11"></a>**32.11** 会议纪要和讨论记录也可以作为存在具有强制执行力的合同协议的证据。该协议不必采用书面形式。然而，当合营安排通过单独主体达成时，具有法律约束力的文件通常会以某种书面形式存在，例如公司章程、特许状或内部规章制度。

[IFRS 11 附录B第B2段]。

[EX 32.11.1 – 通过公司章程存在的合同安排](57.md#s234-EX32.11.1)  
  
[EX 32.11.2 – 通过非正式协议存在的合同安排](57.md#s234-EX32.11.2)

<a id="s230-Para_32.12"></a>**32.12** 该协议的目的不仅在于确立对该安排的共同控制，还在于规定合营安排运作的条款和条件。确立共同控制的合同安排中常见的一些条款包括：

- 合营安排的目的、活动和期限。

- 董事会（或合营安排的类似治理机构）成员的任命方式。

- 决策程序。

- 对各参与方的出资或其他投入要求。

- 各参与方如何分享由合营安排产生的资产、负债、收入和费用或损益。

[IFRS 11 附录B第B4段]。

[FAQ 32.12.1 – 合同安排中的常见条款有哪些？](57.md#s234-FAQ_32.12.1)

 

<a id="s230-chap_32_navPoint_idp1686757448"></a>
##### 相关活动

 

<a id="s230-Para_32.13"></a>**32.13** 共同控制应当针对“相关活动”的决策。相关活动定义为“对被投资方的回报产生重大影响的被投资方活动”。

了解是在哪一层级对相关活动作出决策至关重要。有关相关活动的指引，请参见[第26章第33段](45.md#s170-Para_26.33)。

[IFRS 10 附录A]。

 

<a id="s230-chap_32_navPoint_idp1686755528"></a>
##### 一致同意

 

<a id="s230-Para_32.14"></a>**32.14** 合同协议必须要求对相关活动的决策达成一致同意，但这并不意味着所有参与方都需要对每一项决策都达成一致。要求所有享有共同控制的投资方参与开展该安排经济活动所需的每一项决策是不切实际的。在评估共同控制时，应考虑需要一致同意的决策的性质。

[IFRS 11 第5段]。

[EX 32.14.1 – 指定其中一方合营伙伴负责日常活动对判断共同控制的影响](57.md#s234-EX32.14.1)

 

<a id="s230-chap_32_navPoint_idp1686763080"></a>
#### 评估投资方权利时需考虑的其他因素

<a id="s230-chap_32_navPoint_idp1686766408"></a>
##### 潜在表决权

 

<a id="s230-Para_32.15"></a>**32.15** 投资方可能持有某些工具，一旦行权或转换，将赋予主体对另一主体相关活动的表决权；这些权利被称为“潜在表决权”。潜在表决权是指“获得被投资方表决权的权利，例如源自可转换工具或期权（包括远期合同）的权利”。潜在表决权可能采取多种形式，包括认股权证、股票看涨期权、远期合同以及可转换为普通股的债务或权益工具。

[IFRS 10 附录B第B47段]。

<a id="s230-Para_32.16"></a>**32.16** 潜在表决权的存在可能会逆转在投资方之间确立共同控制的合同安排的效力。例如，两方之间的股东协议规定了对相关活动的共同决策。在同一协议中，一方投资方拥有购买另一方投资方所持权益的实质性期权。该期权逆转了对相关活动共同决策的效力，因此并未确立共同控制。请参见[第26章第75段](45.md#s170-Para_26.75)。

[IFRS 10 附录B第B48段]。

[EX 32.16.1 – 潜在表决权](57.md#s234-EX32.16.1)

 

<a id="s230-chap_32_navPoint_idp1686776648"></a>
##### 参与方是否集体控制该安排？

 

<a id="s230-Para_32.17"></a>**32.17** 管理层可能得出结论，认为一组参与方或所有投资方集体控制了该安排。管理层应确定享有集体控制的参与方中是否有任何一方行使共同控制。当所有参与方或一组参与方作为一个整体能够主导相关活动时，即存在集体控制。只有当这些参与方受合同协议（无论正式还是非正式确立）的约束，必须就影响相关活动的所有决策达成一致同意时，才存在共同控制。集体控制的存在本身并不产生共同控制。

[IFRS 11 附录B第B6段]。

<a id="s230-Para_32.18"></a>**32.18** 合同安排可能要求作出决策所需的最低表决权比例。如果该比例可以通过不止一种参与方组合实现，则该安排不属于合营安排，除非合同明确指定哪些参与方应当达成一致。例如，股东A、B和C分别持有50%、25%和25%的股权，而作出决策需要75%的批准，此时A和B或者A和C达成一致即可。因此不存在共同控制。

[IFRS 11 附录B第B8段]。

 

<a id="s230-chap_32_navPoint_idp1686779976"></a>
##### 隐含的共同控制

 

<a id="s230-Para_32.19"></a>**32.19** 当一组参与方建立合营安排（例如为合并其业务而结成战略联盟）时，决策程序可能会明确写入合同中，要求一致同意。共同控制也可以通过隐含方式实现。例如，A持有60%的股份，B持有40%的股份，而作出决策需要75%的批准。尽管未明确要求一致同意，但由于必须A和B双方同意才能作出决策，因此隐含着共同控制。

[IFRS 11 附录B第B7段]。

[EX 32.19.1 – 两名股东之间的隐含共同控制：股东为决策机构](57.md#s234-EX32.19.1)  
[EX 32.19.2 – 两名以上股东之间的隐含共同控制：股东为决策机构](57.md#s234-EX32.19.2)  
[EX 32.19.3 – 两名股东之间的隐含共同控制：董事为决策机构](57.md#s234-EX32.19.3)

 

<a id="s230-chap_32_navPoint_idp1686788296"></a>
##### 仲裁

 

<a id="s230-Para_32.20"></a>**32.20** 合营安排的参与方还可能规定仲裁程序，以防其无法就相关活动的决策达成一致。用于解决争议的仲裁程序的存在可以作为共同控制的有力证据；而缺乏此类条款可能表明并非所有关键决策都需要一致同意，从而不存在共同控制。

[IFRS 11 附录B第B10段]。

 

<a id="s230-chap_32_navPoint_idp1686792904"></a>
##### 否决权与保护性权利

 

<a id="s230-Para_32.21"></a>**32.21** 在存在共同控制的情况下，行使共同控制的投资方对相关决策拥有否决权。投资方不能单独就相关活动作出决策，但可以阻止其他投资方作出决策。管理层应考虑该安排所产生的权利是实质性权利还是保护性权利。对相关活动决策的否决权决定了共同控制的存在，而对保护性权利的否决权则不然。保护性权利（例如对关闭主体的否决权）也是其他投资方（如少数股东）可能拥有的权利。

[IFRS 11 附录B第B9段]。

 

<a id="s230-chap_32_navPoint_idp1686806344"></a>
##### 共同控制的持续评估

<a id="s230-Para_32.22"></a>**32.22** 判断是否存在共同控制可能需要参与方作出重大判断。如果事实与情况发生变化，主体应重新评估其是否仍然享有共同控制。

[IFRS 11 第13段]。

## 分类（第32.23段 - 第32.50段）

<a id="s231-chap_32_navPoint_4"></a>
### 合营安排的类型

 

<a id="s231-Para_32.23"></a>**32.23** 就财务会计目的而言，合营安排分为两类：

- 共同经营；以及

- 合营企业。

分类取决于合同安排所产生的权利和义务。享有共同控制的主体需要审视合同安排的实质并运用判断，以确定其是共同经营的参与方还是合营企业的参与方。

[IFRS 11 第14段]。

<a id="s231-Para_32.24"></a>**32.24** 当合同协议赋予享有共同控制的参与方对资产的权利和对负债的义务时，该安排为共同经营。对共同经营享有共同控制的参与方称为共同经营方。

[IFRS 11 第15段]。

<a id="s231-Para_32.25"></a>**32.25** 当协议赋予参与方对该安排净资产的权利时，该合营安排为合营企业。对合营企业享有共同控制的参与方称为合营方。提及“净资产”表明合营方对该安排拥有一项投资。合营方在合营企业中也可能涉及净负债。

[IFRS 11 第16段]。

<a id="s231-Para_32.26"></a>**32.26** 管理层应评估参与方在“正常经营过程中”因该安排而产生的权利和义务。在“正常经营过程”以外的情况下（如清算和破产）产生的法律权利和义务相关性较低。例如，如果某主体进入清算，有担保债权人对资产拥有优先受偿权；合营伙伴仅对清偿所有第三方债务后剩余的净资产享有权利。该主体仍可能被分类为共同经营，因为在“正常经营过程中”，合营伙伴对资产和负债享有直接权益。

[IFRS 11 附录B第B14段]。

[FAQ 32.26.1 – 有限责任公司能否被分类为共同经营？](57.md#s234-FAQ_32.26.1)

<a id="s231-Para_32.27"></a>**32.27** 如果事实与情况发生变化，主体应重新评估合营安排的类型是否发生了变化。

[IFRS 11 第19段]。

 

<a id="s231-chap_32_navPoint_5"></a>
### 涵盖多项活动的协议

 

<a id="s231-Para_32.28"></a>**32.28** 有时，参与方会订立一项框架协议，在该协议下建立多项合营活动，或者可能在一个单独法律主体内置入多项活动。“合营安排的会计计量单元是两方或多方同意共同控制的活动。”管理层应分别评估每项活动，以确定其应分类为共同经营还是合营企业。管理层可能得出结论，认为部分活动属于共同经营，而其他活动属于合营企业。当参与方在一项安排中同时识别出共同经营和合营企业时，应对每项活动分别进行会计处理。

[IFRS 11 第18段]。[IFRS 11 第BC35段]。

#### A. 该安排是否通过单独主体达成？

<a id="s231-chap_32_navPoint_idp1711679432"></a>
##### 未通过单独主体达成的合营安排

 

<a id="s231-Para_32.30"></a>**32.30** 本准则将单独主体定义为“……可单独辨认的财务架构，包括单独的法人主体或法律认可的主体，无论这些主体是否具有法人资格”。单独主体具有清晰的架构，例如组织或机构。它通常是一个独立于其成员存在的组织。示例包括公司、合伙企业、信托、政府机构或部门、大学或任何其他组织或人员团体。

[IFRS 11 附录A]。

<a id="s231-Para_32.31"></a>**32.31** 未通过单独主体达成的合营安排属于共同经营。共同经营中的每一参与方通常使用自身的资源，独立于其他参与方的活动来开展其在共同经营中的那部分业务。每一参与方承担自身的费用并自行筹集资金。

[IFRS 11 附录B第B16段]。

<a id="s231-Para_32.32"></a>**32.32** 规范该项经营的合同安排通常会明确规定收入、共同费用以及资产和负债如何在共同经营方之间分配。例如，两方或多方投资方在共同经营中结合各自的业务、资源和专业技能，以共同制造某项特定产品。每一参与方负责制造流程的不同部分。每一参与方承担自身成本，并按照合同安排确定的份额分享销售该产品所产生的收入。

[IFRS 11 附录B第B17段]。

[EX 32.32.1 – 未通过单独主体达成的共同经营](57.md#s234-EX32.32.1)

<a id="s231-Para_32.33"></a>**32.33** 参与方可能同意共同分享和运营一项资产。此类共同经营涉及对不构成单独主体的资产的共同所有权。确定哪些成本和收入项目由各方分摊、哪些由各方单独承担至关重要。

<a id="s231-chap_32_navPoint_idp1711701064"></a>
##### 通过单独主体达成的合营安排

 

<a id="s231-Para_32.34"></a>**32.34** 通过单独主体达成的合营安排既可能是共同经营，也可能是合营企业。有时可能难以区分合营企业和共同经营，例如，当出于税务或其他原因使用单独法律主体来“承载”共同经营时。

[IFRS 11 附录B第B19段]。

<a id="s231-Para_32.35"></a>**32.35** 合营安排的参与方必须分析相关合同协议，以确定该安排是赋予对资产的权利和对负债的义务，还是赋予对净资产的权利。

[IFRS 11 附录B第B20段]。

<a id="s231-Para_32.36"></a>**32.36** 参与方的相关权利和义务需要在以下背景下进行考量：

- 单独主体的法律形式；

- 约束享有共同控制的参与方的合同协议条款；以及

- 其他相关事实（包括对参与方施加的任何限制、安排的客户群以及参与方的出资义务）。

[IFRS 11 第17段]。

<a id="s231-Para_32.37"></a>**32.37** 当事实发生变化时，先前的结论可能不再适用。因此，管理层必须重新评估主体是共同经营的参与方还是合营企业的参与方。
[IFRS 11 第19段]。

 

<a id="s231-chap_32_navPoint_idp1711713352"></a>
#### B. 法律形式是否赋予安排参与方对资产的直接权利和对负债的直接义务？

 

<a id="s231-Para_32.38"></a>**32.38** 参与方需要评估合营安排的法律形式是否将该合营安排的资产和负债与投资方的资产和负债相隔离。

[IFRS 11 附录B第B22段]。

<a id="s231-Para_32.39"></a>**32.39** 如果法律形式未能使投资方与主体之间形成隔离，即合营方仍直接享有该合营安排的资产权利并承担其负债义务，则该安排属于共同经营。无需进一步评估即可得出分类结论。例如，如果合伙人在正常经营过程中对资产享有直接权利并对合伙企业的负债承担直接义务，则合伙企业不会与合伙人形成隔离。同样，无限责任主体通常会赋予合营伙伴直接的权利和义务，具体取决于相关事实与情况。在不同的司法管辖区，相同的法律形式可能会因当地法律法规的不同而导致不同的结果。

[IFRS 11 附录B第B24段]。

#### C. 参与方之间的合同安排是否赋予其对资产的直接权利和对负债的直接义务？

<a id="s231-chap_32_navPoint_idp1711720136"></a>
##### 合同安排的条款

 

<a id="s231-Para_32.40"></a>**32.40** 合营安排的法律形式是一个重要因素，但可能不足以提供将该合营安排分类为合营企业的充分证据。合营方约定的条款和其他事实可能会逆转法律形式所赋予的隔离。对合同协议条款的评估应重点分析每一参与方的权利和义务。

[IFRS 11 附录B第B23段]。

<a id="s231-Para_32.41"></a>**32.41** 参与方在合同协议中约定其希望共享的权利和义务。他们很可能会选择一种与这些权利和义务相辅相成且不与之矛盾的法律形式。

[IFRS 11 附录B第B25段]。

<a id="s231-Para_32.42"></a>**32.42** 当地法律可能要求安排以特定的法律架构设立。参与方可能希望拥有不同的权利和义务，因此合同条款可能会修改由法律形式所产生的权利和义务。

[IFRS 11 附录B第B26段]。

<a id="s231-Para_32.43"></a>**32.43** 规定共同经营或合营企业的合同安排中的常见条款如下：

<table style="width:100%; border-collapse:collapse"><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">对资产的权利和对负债的义务</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">合营企业的参与方通常会将其投入合营安排的资产的法定所有权转移给该合营安排。合营企业后续取得的任何资产均属于合营企业，而非属于合营方。合营安排中产生的任何负债均属于合营企业的负债。合营方对其在该主体中的投资之外不承担责任。例如，如果合营企业未能履行对其债权人的义务，这些债权人无权强制要求合营方履行这些义务。</p><p style="background-color:transparent">当参与方将相关资产投入单独法律主体时，参与方可能保留对这些相关资产的权利和法定所有权。该合营安排虽为单独法律主体，但并不拥有投入的资产。合同协议规定了参与方分享合营安排资产产出的比例。此类安排可能是也可能不是共同经营。</p><p style="background-color:transparent">对于未通过单独法律主体达成的共同经营，参与方将按规定比例共享与该合营安排相关资产的全部权益。</p><p style="background-color:transparent">共同经营的参与方对共同经营的债务和义务承担责任。如果合营安排无法清偿第三方提出的索赔，而需要由合营安排的参与方来清偿，则该安排可能被分类为共同经营。合同协议通常会包含详细规定各参与方对合营安排义务承担责任比例的条款。</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">收入、费用、损益</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">参与方需要评估其分享收入、费用、损益以及资产和负债的方式。合营企业在合同协议中赋予投资方对净资产的权利，因此参与方有权享有该主体的净损益。对于共同经营，合同会规定收入和费用的分配方式。例如，分配份额可以基于各参与方提供的产能，也可以按各共同经营方提供的现金比例确定。该份额未必代表在合营安排单独主体中的所有权比例。即使所有权比例与收入和费用的分配比例相同，也未必意味着该主体是合营企业。最终结论取决于对资产的权利和对负债的义务。</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">担保</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">投资方可能向合营安排的债权人、客户和其他利益相关方提供担保。担保的存在本身并不能决定合营安排的分类。管理层需要分析其是否承担与该安排相关负债的义务。</p></td></tr></table>

  
[IFRS 11 附录B第B27段]。

<a id="s231-Para_32.44"></a>**32.44** 合营方对合营企业未清偿的债务和义务不承担责任。在权益法下，投资方确认其应分担的合营企业亏损，直至投资账面价值减记至零。只有当合营方负有合同或法定义务承担合营企业亏损时，投资方才确认进一步的亏损。这种弥补合营企业亏损或承担该负债的担保本身并不表明该安排属于共同经营。

[IAS 28 第28段]

<a id="s231-Para_32.45"></a>**32.45** 如果参与方得出结论认为合同安排的条款和条件赋予了其与该安排相关资产的权利并产生了相关负债的义务，则该安排属于共同经营。本准则不要求参与方再去分析其他事实。

[IFRS 11 附录B第B28段]。

#### D. 其他事实与情况

 

<a id="s231-Para_32.46"></a>**32.46** 合同协议中的条款和条件并不总是能提供充分证据来确定参与方所订立合营安排的类型。参与方应审视与合营安排存在相关的其他事实。被投资方的设计和目的可以为该安排的性质提供进一步证据。

[IFRS 11 附录B第B29段]。

[EX 32.46.1 – 设立作为委托人代理人的合营安排](57.md#s234-EX32.46.1)

<a id="s231-Para_32.47"></a>**32.47** 管理层应考虑阻止合营安排向其他市场参与者出售其产出的协议，因为这可能会导致该安排被分类为共同经营。参与方必须负有具有法律强制执行力和约束力的义务去购买全部产出，该安排才符合共同经营的条件。在存在具有约束力的协议的情况下，该安排的目的和设计符合共同经营的性质。如果参与方仅拥有购买产出的权利，他们可能决定在某一年购买这些产出，而在另一年出售给外部第三方。该安排的目的和设计并非确保产出始终由参与方购买，因此该安排可能属于合营企业。

[IFRS 11 附录B第B31段]。

<a id="s231-Para_32.48"></a>**32.48** 当合营安排的参与方符合以下条件时，通过其他事实与情况享有该合营安排资产的权利：

- 享有该安排资产的几乎全部经济利益（产出）的权利；以及

- 负有购买这些经济利益的义务，从而承担与这些经济利益相关的风险。

[IFRS 11 附录B第B30段]。

<a id="s231-Para_32.49"></a>**32.49** 当参与方符合以下条件时，通过其他事实与情况承担合营安排负债的义务：

- 作为其对合营安排资产享有权利和承担义务的结果，参与方提供了用于清偿合营安排负债的现金流；以及

- 负债的清偿是持续进行的。

### 合营安排的其他参与方

 

<a id="s231-Para_32.50"></a>**32.50** 合营安排的参与方可能因各种原因而不享有共同控制。主体可能对共享资产（例如管道）持有所有权权益，但由于使用群体过于广泛，实行共同控制在实务中并不可行。主体也可能参与某项安排，希望保留影响力和获取信息的途径，但不希望积极分享共同控制。参与合营安排但不享有共同控制的参与方，应根据其权利和参与程度对其投资进行分类。参与共同经营但不享有共同控制的参与方，如果对资产享有权利并对负债承担义务，则应确认其在共同经营资产和负债中享有的份额。

## 计量——会计处理（第32.51段 - 第32.93段）

 

<a id="s232-Para_32.51"></a>**32.51** 合营安排的会计处理取决于其被分类为共同经营还是合营企业。共同经营方对其在该安排中的资产、负债、收入和费用份额进行会计处理。合营安排本身的会计处理不在 IFRS 11 的适用范围内。

[IFRS 11 第IN9段]。

### A. 共同经营方

#### 初始确认

 

<a id="s232-Para_32.53"></a>**32.53** 当共同经营方取得共同经营的权益时，其会计处理取决于所取得的共同经营的活动是否构成一项业务。（请参见第29章第6段。）如果共同经营的活动构成一项业务，共同经营方应按其份额适用企业合并的会计处理原则。这既适用于取得构成业务的共同经营的初始权益，也适用于取得该共同经营的追加权益。

[IFRS 11 第21A段]。

  
 

[EX 32.53.1 – 取得不构成业务的共同经营权益](57.md#s234-EX32.53.1)

<a id="s232-Para_32.54"></a>**32.54** 当主体取得构成业务的共同经营权益时，与 IFRS 11 指引不冲突且应当适用的企业合并会计处理原则示例如下：

- 按公允价值计量可辨认资产和负债，但 IFRS 3 或其他准则规定例外的除外。

- 将所有与收购相关的费用计入当期损益，除非该费用与发行债务证券或权益证券相关。此类费用按照 IAS 32 和 IFRS 9 进行确认。

- 确认因初始确认资产或负债而产生的递延所得税资产和递延所得税负债，但因初始确认商誉而产生的递延所得税负债除外。

- 将转让对价超过购买日取得的可辨认资产与承担的负债净额的部分确认为商誉。

- 按照 IAS 36 的要求，每年对商誉进行减值测试。

#### 后续计量

 

<a id="s232-Para_32.59"></a>**32.59** 当主体参与共同经营时，投资方通过确认以下项目对其权利和义务进行会计处理：

“a. 其资产，包括其对任何共同持有资产所享有的份额；  
b. 其负债，包括其对任何共同承担负债所应承担的份额；  
c. 出售其享有的共同经营产出份额所产生的收入；  
d. 共同经营因出售产出所产生的收入中其享有的份额；以及  
e. 其费用，包括其对任何共同发生费用所应承担的份额。”

#### 逆流交易

#### 顺流交易

 

<a id="s232-Para_32.65"></a>**32.65** 如果共同经营是单独法律主体，共同经营方可能向共同经营投入资产，或者向共同经营出售资产（“顺流交易”）。当共同经营方向共同经营投入资产或与其订立销售协议时，它实际上是在与其他投资方进行交易。如果该项投入在共同经营方的账簿中产生了利得或损失，则仅应就其他参与方在共同经营中所占权益份额的范围内确认该利得或损失。如果共同经营方在共同经营中使用自身的资产并保留对这些资产的完全所有权和控制权，则不会产生会计影响。共同经营方在资产负债表上保留其资产和负债。

[IFRS 11 附录B第B34段]。

<a id="s232-Para_32.66"></a>**32.66** 如果该交易提供了已存在减值的证据，投资方必须在其账簿中确认任何减值损失。此时推定该资产在出售给共同经营之前就已经发生了减值。

[IFRS 11 附录B第B35段]。

[FAQ 32.66.1 – 共同经营方应如何对投入共同经营且其他共同经营方随之享有权利的资产进行会计处理？](57.md#s234-FAQ_32.66.1)  
[EX 32.66.2 – 设立共同经营时投入已减值资产](57.md#s234-EX32.66.2)

 

<a id="s232-chap_32_navPoint_10"></a>
### B. 合营方

 

<a id="s232-Para_32.67"></a>**32.67** 合营方采用权益法核算其对合营企业的投资。权益法核算在 IAS 28 中予以规范。

[IFRS 11 第24段]。

<a id="s232-Para_32.68"></a>**32.68** IAS 28 规定了以下免于适用权益法核算的范围豁免：

- 豁免编制合并财务报表。[IAS 28 第17段]。

- 风险投资机构。[IAS 28 第18段]。[IAS 28 第19段]。

- 分类为持有待售。[IAS 28 第20段]。[IAS 28 第21段]。

有关上述豁免的更多详情，请参见[第31章第3段](56.md#s224-Para_31.3)。

 

<a id="s232-chap_32_navPoint_idp1686664904"></a>
#### 初始确认

 

<a id="s232-Para_32.69"></a>**32.69** 初始确认时，对合营企业的投资按成本确认。成本可包括购买价款、或有对价和收购费用。有关采用权益法核算的投资成本的更多详情，请参见[第31章第22段](56.md#s225-Para_31.22)。

[IAS 28 第10段]。

<a id="s232-Para_32.70"></a>**32.70** 成本是指“为购建一项资产在取得或建造时支付的现金或现金等价物的金额，或付出的其他对价的公允价值；或在适用时，按照其他国际财务报告准则（如 IFRS 2）的具体要求在初始确认时归属于该资产的金额”。

[IAS 16 第6段]。

<a id="s232-Para_32.71"></a>**32.71** 投资方在取得联营企业投资时，需要执行类似于“购买法会计处理”的程序。如果成本超过应享有合营企业可辨认资产和负债净公允价值的份额，差额作为名义商誉进行会计处理。该商誉包含在投资的账面价值中。如果成本低于主体应享有被投资方可辨认资产和负债净公允价值的份额，差额计入当期损益，作为主体在取得当期应享有合营企业损益的一部分（“负商誉”）。有关采用权益法核算的投资初始购买会计处理的更多详情，请参见第31章第37段。

[IAS 28 第32段]。

<a id="s232-Para_32.72"></a>**32.72** 投资方可能将应收贷款或其他金融资产指定为对合营企业净投资的一部分。此类长期权益按照 IFRS 9 进行会计处理。有关长期权益会计处理的更多详情，请参见[第31章第20段](56.md#s225-Para_31.20)。

[IAS 28 第38段]。

<a id="s232-Para_32.73"></a>**32.73** 合营方通常通过向合营企业投入或出售非货币性资产的方式投资于合营企业。这导致合营方在取得合营企业权益的同时处置了一项资产或业务。有关向合营企业投入或出售非货币性资产的会计处理的更多详情，请参见[第31章第25段](56.md#s225-Para_31.25)。

[IAS 28 第30段]。

[FAQ 32.73.1 – 合营企业的设立：合营方基于先前投资设立合营企业时应如何进行会计处理？](57.md#s234-FAQ_32.73.1)  
[FAQ 32.73.2 – 合营企业的设立：主体应如何对投入业务的公允价值与其他合营方投入资产的公允价值之间的差额进行会计处理？](57.md#s234-FAQ_32.73.2)  
[EX 32.73.3 – 合营方向合营企业转让业务以换取股权：IAS 28 下的会计政策](57.md#s234-EX32.73.3)  
[EX 32.73.4 – 合营方向合营企业转让业务以换取股权：IFRS 10 下的会计政策](57.md#s234-EX32.73.4)

 

<a id="s232-chap_32_navPoint_idp1686691528"></a>
#### 后续计量

<a id="s232-Para_32.74"></a>**32.74** 初始确认后，对合营企业投资的账面价值应就以下项目进行调整：

- 确认投资方应享有的合营企业损益份额；

- 扣除向投资方分配的股利或利润；以及

- 确认投资方应享有的其他综合收益变动份额；相应的调整应直接计入投资方的其他综合收益。

[IAS 28 第10段]。

<a id="s232-Para_32.75"></a>**32.75** 应对合营企业的业绩进行调整，以使投资方与被投资方采用统一的会计政策。

[IAS 28 第27段]。

<a id="s232-Para_32.76"></a>**32.76** 应享有合营企业利润的份额需进行调整，以反映初始取得合营企业的影响。例如，如果在取得合营企业时，评估所取得可辨认资产的公允价值导致不动产、厂场和设备的公允价值调增，则应就该调增所产生的额外折旧对利润进行调整。

[IAS 28 第32段]。

<a id="s232-Para_32.77"></a>**32.77** 合营方在其合并财务报表中对合营企业的投资在资产负债表上作为单独项目列示。该投资初始按成本确认，后续按应享有合营企业的损益和其他综合收益份额进行调整。请参见[第31章第80段](56.md#s227-Para_31.80)。

[IAS 28 第10段]。

<a id="s232-Para_32.78"></a>**32.78** 当使用合营企业的财务报表将其业绩纳入投资方财务报表时，其报告日期最好与投资方的报告日期一致。如果合营企业编制的年度财务报表具有不同的会计年度末，则需要编制截至合营方会计年度末的特殊目的财务报表。

[IAS 28 第33段]。

<a id="s232-chap_32_navPoint_idp1686801224"></a>
#### 逆流交易与顺流交易

 

<a id="s232-Para_32.79"></a>**32.79** 投资方可能向合营企业出售或投入资产，合营企业也可能向投资方出售资产。投资方与合营企业之间此类“顺流”和“逆流”交易产生的利得和损失，仅应就非关联投资方在合营企业中所占权益份额的范围内在投资方财务报表中确认。投资方在逆流和顺流交易中应享有的合营企业利得或损失份额予以抵销。

[IAS 28 第28段]。

<a id="s232-Para_32.80"></a>**32.80** 如果该交易提供了已存在减值的证据，投资方必须在其账簿中全额确认减值损失。此时推定该资产在出售给合营企业之前就已经发生了减值。

[IAS 28 第29段]。

<a id="s232-Para_32.81"></a>**32.81** 合营方可能向合营企业投入非货币性资产（如不动产、厂场和设备）以换取股权。如果该交易缺乏商业实质（如 IAS 16 所述，参见[第22章第38段](39.md#s142-Para_22.38)），则全部利得或损失均不予确认。相关利得或损失冲减对合营企业的投资。

[IAS 28 第31段]。

<a id="s232-Para_32.82"></a>**32.82** 如果主体除取得股权外还收到了货币性资产或非货币性资产，则投资方应将非货币性资产投入所产生利得或损失中与所收到货币性资产或非货币性资产相关的部分，全额计入当期损益。有关采用权益法核算的投资所涉逆流和顺流交易的更多详情，请参见[第31章第53段](56.md#s226-Para_31.53)。

[IAS 28 第30段]。

 

<a id="s232-chap_32_navPoint_idp1686818248"></a>
#### 所有者权益变动及丧失共同控制

 

<a id="s232-Para_32.83"></a>**32.83** 当主体不再行使共同控制时，管理层应停止采用权益法核算，除非保留的权益构成对联营企业的投资（对此同样适用权益法）。丧失共同控制可能以不同方式发生：

- 主体取得原合营企业的控制权。投资方适用 IFRS 3 和 IFRS 10 确定该交易的会计处理。原持有被投资方的权益按公允价值重新计量，并构成取得控制权所转让对价的一部分。有关企业合并的更多信息，请参见第29章第166段。

- 主体保留的权益既不是子公司也不是联营企业。该权益按照 IFRS 9 作为金融资产进行会计处理。丧失共同控制时保留权益的公允价值成为按照该准则初始确认时的公允价值。

[IAS 28 第22段]。

<a id="s232-Para_32.84"></a>**32.84** 当主体丧失对合营企业的共同控制但仍保留重大影响时，该主体成为联营企业的投资方。该主体继续按照 IAS 28 采用权益法核算其权益，不对其继续持有的所有者权益按公允价值重新计量。

[IAS 28 第24段]。

<a id="s232-Para_32.85"></a>**32.85** 当所有者权益比例下降且该投资变为联营企业或继续作为合营企业（即在持股比例下降的情况下保留共同控制）时，如果处置相关资产和负债要求将任何利得或损失重分类至损益，则主体可能需要将根据[第32.74段](57.md#s232-Para_32.74)确认为其他综合收益的利得或损失按相应比例重分类至损益。有关采用权益法核算的投资的所有者权益变动以及丧失共同控制时会计处理的更多详情，请参见[第31章第30段](56.md#s225-Para_31.30)。

[IAS 28 第25段]。

[FAQ 32.85.1 – 保留共同控制权情况下的所有权比例变动会产生哪些影响？](57.md#s234-FAQ_32.85.1)

 

<a id="s232-chap_32_navPoint_idp1686835016"></a>
#### 减值

 

<a id="s232-Para_32.86"></a>**32.86** 当存在减值迹象时，应对联营企业和合营企业投资进行减值评估。减值迹象详见 IAS 28 第41A至41C段。有关采用权益法核算的投资减值的更多详情，请参见[第31章第61段](56.md#s226-Para_31.61)。

[IAS 28 第40段]。

[FAQ 32.86.1 – 实质上构成净投资一部分的长期权益应如何计量？](57.md#s234-FAQ_32.86.1)

<a id="s232-Para_32.87"></a>**32.87** 投资的整个账面价值应按照 IAS 36 进行减值测试，以确定减值损失金额。该账面价值包括股权权益以及构成主体净投资一部分的任何长期权益。包含在合营企业投资账面价值中的商誉不每年进行减值测试，也不单独进行测试，而是作为整个投资的一部分进行考虑。有关采用权益法核算的投资减值的更多详情，请参见[第31章](56.md#s223-chap_31)。

[IAS 28 第42段]。

 

<a id="s232-chap_32_navPoint_idp1686843720"></a>
#### 合营方的经济利益或单独财务报表

 

<a id="s232-Para_32.88"></a>**32.88** 主体应在其合并财务报表中采用权益法核算对合营企业的投资。但是，如果主体没有任何子公司，也应在其财务报表中采用权益法核算对合营企业的投资，即使这些财务报表可能不被称为“合并财务报表”。此类报表被称为“经济利益财务报表”。有关经济利益财务报表的更多指引，请参见[第28章第7段](49.md#s198-Para_28.7)。

[IAS 28 第IN8段]。

<a id="s232-Para_32.89"></a>**32.89** 在合营方的单独财务报表中，对合营企业的权益按成本、按照 IFRS 9 或采用权益法进行计量。单独财务报表中投资的会计处理在[第28章第14段](49.md#s199-Para_28.14)中讨论。

[IFRS 11 第26(b)段]。

<a id="s232-Para_32.90"></a>**32.90** 因 IAS 28 或 IFRS 10 中的豁免规定而免于合并或采用权益法核算投资的合营方，可以将单独财务报表作为其唯一财务报表列报——在此情况下，其无需对合营企业采用权益法核算。

[IFRS 10 第4段]。[IAS 27 第8段]。

 

<a id="s232-chap_32_navPoint_11"></a>
### C. 不享有共同控制的合营安排参与方

<a id="s232-chap_32_navPoint_idp1686849480"></a>
#### 共同经营的参与方

 

<a id="s232-Para_32.91"></a>**32.91** 不享有共同控制的参与方应评估其是否对单项资产享有权利并对负债承担义务，因为他们需要在财务报表中对此进行会计处理。其会计处理将类似于共同经营方。不享有共同控制的参与方可能并不对资产享有直接权利或对负债承担直接义务。例如，当一方为共同经营提供资金以换取享有共同经营产出份额的权利，而非对资产的直接权利或对负债的直接义务时，就可能出现这种情况。对单项资产不享有权利的参与方应按照相关的国际财务报告准则对其投资进行会计处理。

[IFRS 11 第23段]。

<a id="s232-Para_32.92"></a>**32.92** 共同经营的投资方（包括不享有共同控制的投资方）应对其权利和义务进行会计处理。他们在其合并财务报表和单独财务报表中均确认因该合营安排产生的资产和义务。

[IFRS 11 第27(a)段]。

 

<a id="s232-chap_32_navPoint_idp1686860872"></a>
#### 合营企业的参与方

 

<a id="s232-Para_32.93"></a>**32.93** 不享有共同控制的合营企业参与方，应在其合并财务报表中按照 IFRS 9 对其投资进行会计处理；如果该参与方具有重大影响，则按照 IAS 28 进行会计处理。

[IFRS 11 第25段]。

## 披露（第32.94段 - 第32.97段）

 

<a id="s233-Para_32.94"></a>**32.94** IFRS 12 包含对子公司、合营安排、联营企业和未纳入合并财务报表范围的结构化主体的强制性披露要求。披露应帮助财务报表使用者评估与主体在子公司、联营企业、合营安排及未纳入合并财务报表范围的结构化主体中的权益相关的性质、风险和财务影响。

[IFRS 12 第1段]。

<a id="s233-Para_32.95"></a>**32.95** 报告主体应披露为实现这一目标所需的任何额外信息。

[IFRS 12 第3段]。

<a id="s233-Para_32.96"></a>**32.96** 披露要求可归纳为以下三类：

- 重大判断和假设。[IFRS 12 第7–9段]。

- 在合营安排中投资的性质、程度和财务影响。[IFRS 12 第20–22段]。

- 与合营企业相关的风险。[IFRS 12 第23段]。

<a id="s233-Para_32.97"></a>**32.97** IFRS 12 概述的披露要求不适用于不享有共同控制的合营安排参与方，除非这些参与方对该安排具有重大影响。

[IFRS 12 第6(c)段]。

## 示例文本

<a id="s234-chap_32_navPoint_14"></a>
### <a id="s234-FAQ_32.6.1"></a>FAQ 32.6.1 – IFRS 11是否适用于合营安排本身的会计处理：共同经营？

 

准则索引：IFRS 11 第3段  
正文索引：[32.6](57.md#s230-Para_32.6)  
 

  

  
不适用。IFRS 11 仅适用于共同经营方的会计处理，而不适用于作为共同经营的单独主体本身的会计处理。因此，该单独主体的财务报表应按照适用的准则进行编制。

各国的法律要求可能要求共同经营编制其自身的财务报表。当管理层得出结论认为合营安排是通过单独主体达成的共同经营时，就会出现一个问题：共同经营方和共同经营本身是否均应在其各自的财务报表中确认相同的资产、负债、收益和费用。

资产和负债在法律主体的账簿中可能满足确认条件，因为该单独主体拥有资产的法定所有权并承担负债的法定义务。来自资产的经济利益以收入的形式归属于该法律主体。这些收入是来自第三方还是来自共同经营方并不相关。

当法律主体以自身名义签订合同时，即对相关负债负有义务。尽管共同经营方可能为这些义务提供资金，但这并不意味着该法律主体不再对这些负债负有义务。

当部分或全部经济利益转移给共同经营方时，资产的账面价值应相应减记。该计量应基于合营安排的合同条款。

共同经营可能拥有资产的法定所有权，但它是代表投资方作为代理人行事。此时，共同经营自身的财务报表应反映作为代理人的会计处理。例如，当共同经营从供应商处采购存货时，它确认一笔应付供应商的应付款项，以及一笔相应的应收款项（代表应向共同经营方收取的金额）。由共同经营方在其财务报表中确认实际存货及相关费用，同时确认应付共同经营的相应款项。

 

<a id="s234-chap_32_navPoint_15"></a>
### <a id="s234-FAQ_32.6.2"></a>FAQ 32.6.2 – 合营安排应如何对其投资方在设立时或其他时间投入的业务进行会计处理？

 

准则索引：IFRS 11 第3段  
正文索引：[32.6](57.md#s230-Para_32.6)  
 
  

合营方可能在合营企业设立时投入资产或资产组。主体应评估投资方投入资产是否符合 IFRS 3 下企业合并的定义（参见第29章第6段）。

国际财务报告准则并未规定合营安排应如何对其投资方在设立时投入的业务进行会计处理。

唯一相关的指引是，合营企业的设立不在 IFRS 2 和 IFRS 3 的适用范围内。IFRS 3 将合营安排的设立排除在其适用范围之外。[IFRS 3 第2段]。在合营企业设立时投入业务也不在 IFRS 2 的适用范围内。

[IFRS 2 第5段]。

合营企业对于设立时投入的业务的会计处理享有会计政策选择权。合营企业可以：

- 按公允价值（包括商誉）记录投入的业务；或者

- 按合营方财务报表中先前的账面价值记录该业务。

此后任何以投入资产换取股份的交易很可能属于 IFRS 2 的适用范围。IFRS 2 要求以发行权益工具取得的商品按公允价值确认。

 

<a id="s234-chap_32_navPoint_16"></a>
### <a id="s234-EX32.7.1"></a>EX 32.7.1 – 拥有决定票（裁决票）的董事长

 

准则索引：IFRS 11 第B5段  
正文索引：[32.7](57.md#s230-Para_32.7) 

  

  
主体A和主体B通过签署联合经营协议设立了一家合营企业——主体J。双方投资方各自向主体J的董事会委派三名董事。决策由简单多数通过。在出现僵局的情况下，董事长（主体B的一名董事）拥有决定票（裁决票）。

因此，主体B很可能对主体J拥有控制权，因为主体A无法阻止代表主体B作出的决策。

 

<a id="s234-chap_32_navPoint_17"></a>
### <a id="s234-EX32.7.2"></a>EX 32.7.2 – 拥有决定票（裁决票）的轮值董事长

 

准则索引：IFRS 11 第B5段  
正文索引：[32.7](57.md#s230-Para_32.7) 

  

  
主体A和主体B通过签署联合经营协议设立了一家合营企业——主体J。双方投资方各自向主体J的董事会委派三名董事。决策由简单多数通过。董事长拥有决定票（裁决票）。董事长实行轮值制。主体A任命当年上半年的董事长，主体B任命当年下半年的董事长。

主体A和主体B均不太可能单独控制主体J。该权利是对称的，因此并未赋予主体A或主体B单独控制权。主体A和主体B对主体J行使共同控制。

 

<a id="s234-chap_32_navPoint_18"></a>
### <a id="s234-FAQ_32.7.3"></a>FAQ 32.7.3 – 如果对安排施加了经营限制，共同控制的评估是否会发生变化？

 

准则索引：IFRS 11 第B5段  
正文索引：[32.7](57.md#s230-Para_32.7) 

  

  
视情况而定。如果合营安排在限制条件下运营，共同控制可能不存在或可能终止。主体应考虑以下情况对其行使共同控制能力的影响。这些影响的严重程度将决定它们在多大程度上影响主体是否享有共同控制：

- 主体进入破产管理/接管程序。

- 政府对将货币汇出境外的限制。

- 对该国实施的重大国际制裁，且直接影响主体开展贸易和/或将利润汇出境外的能力。

需要仔细审视具体情况，因为尽管发生了这些事件，共同控制仍有可能继续存在。

 

<a id="s234-chap_32_navPoint_19"></a>
### <a id="s234-EX32.9.1"></a>EX 32.9.1 – 不等额权益

 

准则索引：IFRS 11 第7段  
正文索引：[32.9](57.md#s230-Para_32.9)  
 

  

  
在参与方权益不相等的情况下，共同控制仍然可能存在。然而，参与方之间的权益划分如果极不均衡（例如90:10），则可能会削弱存在共同控制的论断。

管理层在此情况下应特别谨慎，以了解实行共同控制的商业理由，以及大股东为何愿意接受共享控制权。例如，当大股东在境外设立安排，而当地法规要求政府或当地投资方参与并达到共同控制程度时，就可能出现这种情况。

管理层可能需要运用判断来得出是否存在共同控制的结论。如果在合同协议中明确规定了共同控制，则结论非常直接。但在某些情况下，主体需要审视其他事实，以判断是否存在共同控制。请考虑以下示例：

股东A和股东B共同设立一家新主体J，该主体将投资于若干投资性房地产。股东A和股东B分别持有主体J 35%和65%的股权。根据股东协议的条款，关于主体J所有相关活动的重大决策均需股东一致同意。对主体J而言，部分重大决策的示例包括批准预算和商业计划、签订重大租赁合同以及购买或出售房地产的决策。

在本例中，对涉及所有相关活动的重大决策要求一致同意，意味着主体J受共同控制。

然而，在参与方之间的权益划分明显不均衡的情况下，了解共同控制的商业理由非常重要。在本例中，股东A在主体J运营所在地区的房地产行业拥有丰富的经验，而股东B经验非常有限，但能够提供主体J所需的大部分资本投入。

 

<a id="s234-chap_32_navPoint_20"></a>
### <a id="s234-EX32.11.1"></a>EX 32.11.1 – 通过公司章程存在的合同安排

 

准则索引：IFRS 11 第5段  
正文索引：[32.11](57.md#s230-Para_32.11) 

  

  
股东A和股东B设立了一项新的合营安排（主体J）。主体J的公司章程包含一项条款，规定所有股东必须就主体的相关活动达成一致同意。股东们并未签订任何其他协议来管理主体J的活动。

**问题**

是否存在合同安排？

**回答**

存在。合同安排的条件已满足，主体J符合合营安排的定义，即使没有单独的合营协议。只要主体J的公司章程具有法律约束力，公司章程中的该条款就足以满足合营安排的定义。

 

<a id="s234-chap_32_navPoint_21"></a>
### <a id="s234-EX32.11.2"></a>EX 32.11.2 – 通过非正式协议存在的合同安排

 

准则索引：IFRS 11 第5段  
正文索引：[32.11](57.md#s230-Para_32.11) 

  

  
投资方A、B、C、D有限公司是投资方A、B、C和D之间为提供房地产开发服务而进行的战略合作。投资方A、B、C、D有限公司是一家注册成立的公司，各投资方的持股比例分别为20:30:25:25。现有一项正式的合同协议，要求所有相关活动均需经多数表决通过。投资方A、B和C已非正式地同意共同投票。该协议体现在三方之间的往来信函和会议纪要中，且该非正式协议在实务中一直有效执行。

**问题**

是否存在合同安排？

**回答**

存在。要作出决策，只需四名投资方中的任意三名同意即可；在此情况下，任何单一投资方均无法阻止多数决策。然而，其中三名投资方已同意共同作出一致决策。因此，投资方A、B和C对投资方A、B、C、D有限公司享有共同控制。投资方D可能具有重大影响。只要有证据证明其存在，投资方A、B和C之间的协议不必采用正式书面文件。

 

<a id="s234-chap_32_navPoint_22"></a>
### <a id="s234-FAQ_32.12.1"></a>FAQ 32.12.1 – 合同安排中的常见条款有哪些？

 

准则索引：IFRS 11 第B4段  
正文索引：[32.12](57.md#s230-Para_32.12) 

  

  
合同安排中包含的常见条款如下：

- 合营安排的目的、活动和期限。  
例如，协议可能说明参与方创建该合营安排的原因以及打算运营该安排的期限。它还会明确哪些参与方创建了该合营安排、哪些参与方行使共同控制以及哪些参与方不行使共同控制。

- 董事会（或合营安排的类似治理机构）成员的任命方式。  
协议可以规定参与方如何提名董事会成员、他们的职责是什么以及如何罢免董事。它还会规定每位董事会成员的表决权。

- 决策程序。  
这通过决策程序确立了共同控制的存在。它可能详细说明哪些活动构成“相关活动”。这些活动需要行使共同控制的参与方一致同意。

- 对各参与方的出资或其他投入要求。

- 各参与方如何分享由合营安排产生的资产、负债、收入和费用或损益。  
这是确定该安排分类为共同经营还是合营企业的关键因素。

- 将主体的日常运营委托给合营安排的其中一方。

- 向新参与方或在现有参与方之间转让权益。

- 仲裁程序，这在参与方无法达成一致意见时尤为重要。

 

<a id="s234-chap_32_navPoint_23"></a>
### <a id="s234-EX32.14.1"></a>EX 32.14.1 – 指定其中一方合营伙伴负责日常活动对判断共同控制的影响

 

准则索引：IFRS 11 第B9段  
正文索引：[32.14](57.md#s230-Para_32.14)  
 

  

  
协议可能指定其中一方合营伙伴负责业务的日常管理。这并不意味着该方将控制该安排。只要这些决策代表企业日常管理中出现的较次要事项，且是在行使共同控制的参与方所设定的参数范围内作出的，就不会影响共同控制的存在。

房地产公司A有限公司（房地产公司A）拥有一家全资子公司主体A，主体A持有一组楼宇组合。房地产公司A希望降低其在该市场的风险敞口，于是将其在主体A中50%的投资出售给了投资银行A。

房地产公司A和投资银行A签订了一项合同协议，约定关于主体A相关活动的决策由双方共同作出。房地产公司A继续担任主体A的资产管理人并收取规定费用，其决策均遵循主体A预先批准的预算和商业计划作出。

房地产公司A和投资银行A共同控制主体A，因为双方必须就相关活动达成一致同意。尽管房地产公司A继续担任资产管理人，但它必须按照房地产公司A与投资银行A一致同意的决策来管理主体的运营。

 

<a id="s234-chap_32_navPoint_24"></a>
### <a id="s234-EX32.16.1"></a>EX 32.16.1 – 潜在表决权

 

准则索引：IFRS 10 第B48、B5段  
正文索引：[32.16](57.md#s230-Para_32.16)  
 

  

  
主体A和主体B决定在一个新地区共同制造产品。主体C将使用主体A和主体B提供的零部件在该地区开展制造流程。主体A和主体B各自拥有主体C 50%的表决权；双方有权享有50%的股利以及清算时50%的资产。

主体C的公司章程规定，其运营应按照经股东一致批准的年度商业计划开展。股东按其持股比例任命六名董事来管理主体C的活动。因此，主体A和主体B在董事会中各有三名董事。董事长由主体A和主体B轮流担任，且没有决定票（裁决票）。

公司章程列明了需要董事一致同意的相关活动类型，其中包括批准该安排的商业计划。

主体A拥有一项购买主体B所持主体C股份的期权。如果主体A和主体B无法就某项战略决策达成一致，主体A可随时行使该期权。该期权被视为实质性权利。

**问题**

是否存在共同控制？

**回答**

不存在。不存在共同控制，因为主体A可以购买主体B在主体C中的股份，从而取消合营企业协议。主体A拥有控制权。按照 IFRS 10 评估的潜在表决权可以逆转确立共同控制的合同安排的效力。

 

<a id="s234-chap_32_navPoint_25"></a>
### <a id="s234-EX32.19.1"></a>EX 32.19.1 – 两名股东之间的隐含共同控制：股东为决策机构

 

准则索引：IFRS 11 第B7段  
正文索引：[32.19](57.md#s230-Para_32.19) 

  

  
主体A和主体B在电信行业运营，双方订立了一项合营安排以合并其4G接入网络。该安排的目的是降低双方的运营成本、节约资本基础设施投入，并通过共同管理和维护合并后的网络获得规模经济效益。

所有关于战略性投资和筹资活动的重大决策均由表决权的简单多数决定。主体A和主体B在决策过程中各有一票表决权。

该安排是否属于合营安排？

是。关于相关活动的所有决策均需双方同意，因此该安排属于合营安排。尽管合同安排并未明确要求一致同意，但所有决策必须由多数通过的事实导致了隐含的共同控制。

 

<a id="s234-chap_32_navPoint_26"></a>
### <a id="s234-EX32.19.2"></a>EX 32.19.2 – 两名以上股东之间的隐含共同控制：股东为决策机构

 

准则索引：IFRS 11 第B7段  
正文索引：[32.19](57.md#s230-Para_32.19) 

  

  
有限责任公司A由众多股东拥有，持股情况如下：

- 股东A持有51%。

- 股东B持有30%。

- 其余股份由其他投资方分散持有，合计占19%。

有限责任公司A的公司章程要求75%的多数同意方可批准关于主体任何相关活动的决策。章程还规定，每位股东有权按其各自的持股比例进行表决。

**问题：**
有限责任公司A是否属于合营安排？

**回答：**

是。有限责任公司A由股东A和股东B共同控制；基于二者的持股比例（合计81%），他们必须共同行动才能就有限责任公司A的相关活动作出决策。股东A并未控制有限责任公司A，因为需要75%的多数同意，它无法单方面作出决策。

 

<a id="s234-chap_32_navPoint_27"></a>
### <a id="s234-EX32.19.3"></a>EX 32.19.3 – 两名股东之间的隐含共同控制：董事为决策机构

 

准则索引：IFRS 11 第B7段  
正文索引：[32.19](57.md#s230-Para_32.19) 

  

  
主体A和主体B设立了一家主体并签署了联合经营协议。董事会包含由每一主体委派并代表其利益的三名董事。董事会是该主体的主要决策机构。决策由简单多数通过。各方在产生的净利润中各享有50%的权益。

是否存在合营安排？

存在。主体A和主体B很可能享有共同控制，因为各方在净利润中享有50%的权益，且双方均有权委派三名董事。这是因为代表单一股东的三名董事通常会被推定按照该股东的意愿投票。因此，作出决策需要主体A和主体B双方的同意，这构成了共同控制。

然而，如果董事没有义务代表单一股东，则决策将由简单多数通过。有可能出现主体A的一名董事与主体B的三名董事达成一致，并作出违背主体A利益的决策的情况。尽管这种情况在实务中预计不太可能发生，但此类情形不构成共同控制。

 

<a id="s234-chap_32_navPoint_28"></a>
### <a id="s234-FAQ_32.26.1"></a>FAQ 32.26.1 – 有限责任公司能否被分类为共同经营？

 

准则索引：IFRS 11 第B14段  
正文索引：[32.26](57.md#s231-Para_32.26) 

  

可以。在清算或破产的情况下，有担保债权人始终对有限责任公司的资产享有优先受偿权。合营伙伴（以股东身份）仅对清偿所有第三方债务后的剩余净资产享有权利。虽然这看似意味着有限责任公司永远不能被分类为共同经营，但此类主体仍可能根据其他事实与情况被分类为合营企业或共同经营。这是因为本准则规定，对权利和义务的评估应基于其在正常经营过程中的存在状态，而非在此类极端情况下。

 

<a id="s234-chap_32_navPoint_29"></a>
### <a id="s234-EX32.32.1"></a>EX 32.32.1 – 未通过单独主体达成的共同经营

 

准则索引：IFRS 11 第B17段  
正文索引：[32.32](57.md#s231-Para_32.32) 

  

  
三家独立的航空航天公司结成联盟，共同制造一架飞机。它们各自负责不同的专业领域，例如：

- 制造发动机；

- 制造机身和机翼；以及

- 空气动力学设计。

这些公司负责制造流程的不同部分，各自使用自身的资源和专业技能，共同制造、营销和分销飞机。三家主体分享销售飞机产生的收入并共同承担费用。收入和共同成本按照联合体合同的约定进行分配。

各参与方还各自承担自身单独发生的成本，例如人工成本、制造成本、耗材、未使用的零部件存货以及在产品。每一参与方全额确认其单独发生的成本。

该安排被分类为共同经营，原因如下：

- 该安排未通过单独主体达成；

- 每一参与方对其单独发生的成本承担义务；以及

- 合同协议规定，每一参与方有权按照预先确定的协议，分享飞机销售产生的收入并分担相关成本。

 

<a id="s234-chap_32_navPoint_30"></a>
### <a id="s234-EX32.33.1"></a>EX 32.33.1 – 石油和天然气行业中的共同经营示例

 

准则索引：IFRS 11 第15段  
正文索引：[32.33](57.md#s231-Para_32.33) 

  

  
石油、天然气和矿产开采行业的许多活动都涉及共同运营和共同拥有的资产。一个常见的例子是，拥有相邻油井的两家石油公司共同建设并运营一条将石油输送至炼油厂的管道。共享项目是该管道，包括建造成本、维护费用、未来弃置费用以及第三方使用可能产生的收入。各方单独发生的成本包括通过管道输送的石油存货成本，以及为自身管道份额融资而产生的任何负债。该管道由参与方直接拥有，而非通过单独主体持有。

 

<a id="s234-chap_32_navPoint_31"></a>
### <a id="s234-EX32.39.1"></a>EX 32.39.1 – 法律形式提供隔离

 

准则索引：IFRS 11 第B24段  
正文索引：[32.39](57.md#s231-Para_32.39) 

  

  
一家大型电信企业（电信公司A）寻求在通信环境相对欠发达的地区开展业务。该国国内规定不允许外国公司控制持有电信牌照的当地主体。电信公司A与一名当地投资方共同设立了一家单独公司，以使电信公司A能够进入该市场。该公司的法律形式将资产的权利和负债的义务赋予了该公司本身。电信公司A与当地投资方订立了股东协议，要求所有决策均须共同作出。该协议还确认：

- 该安排的资产归该公司所有。任何一方均不得出售、质押、转让或抵押这些资产。

- 各参与方的责任仅限于其未缴付的出资额。

- 该公司的利润将在电信公司A与投资方之间按60:40的比例分配。

**问题：**

该安排是否属于合营企业？

**回答：**

是。该安排属于合营企业。

首先需要考虑的是该安排的法律形式。该安排是通过单独法律主体达成的。根据该国当地法律，该安排的法律形式在所有者（安排的参与方）与主体本身之间提供了隔离。该安排的资产和负债被隔离在公司内部。参与方对公司的债务或索赔仅以未缴付的出资额为限承担责任。

其次需要考虑的是合同权利。股东协议并未改变该安排法律形式的特征，且确认了参与方对该安排的净资产享有权利。

 

<a id="s234-chap_32_navPoint_32"></a>
### <a id="s234-FAQ_32.39.2"></a>FAQ 32.39.2 – 如果一项安排通过单独主体达成而另一项未通过单独主体达成，两项安排的分类是否可能不同？

 

准则索引：IFRS 11 第B24段  
正文索引：[32.39](57.md#s231-Para_32.39) 

  

可能，因为单独主体的法律形式会影响合营安排参与方的权利和义务。不同的会计处理并不与“经济实质”的概念相冲突。单独主体的存在在确定参与方权利和义务的性质、进而确定该安排的经济实质方面起着重要作用。

例如，主体A和主体B希望共同运营一条输油管道。双方同意从该安排中获得净利润。主体A和主体B均无义务购买该安排的几乎全部产出。

主体A和主体B正在探讨如何设立该安排：

- 通过签订一项运营协议，载明双方如何共同运营该资产。不设立单独主体。

- 通过设立一家有限责任公司。股东协议将载明两名股东如何共同运营该管道。

情况（1）下的运营协议和情况（2）下的股东协议均将确立共同控制。

在情况（1）下，由于不存在单独主体，该安排始终属于共同经营。

在情况（2）下，由于存在单独主体，合同协议并未推翻该安排的法律形式，且任何股东均无义务购买几乎全部产出，因此该安排属于合营企业。

 

<a id="s234-chap_32_navPoint_33"></a>
### <a id="s234-EX32.42.1"></a>EX 32.42.1 – 合同协议逆转法律形式的影响

 

准则索引：IFRS 11 第B26段  
正文索引：[32.42](57.md#s231-Para_32.42) 

  

  
一家大型电信企业（电信公司A）寻求在通信环境相对欠发达的地区开展业务。该国国内规定不允许外国公司控制持有电信牌照的当地主体。电信公司A与一名当地投资方共同设立了一家单独公司，以使电信公司A能够进入该市场。该公司的法律形式将资产的权利和负债的义务赋予了该公司本身。电信公司A与当地投资方订立了股东协议，要求所有决策均须共同作出。该协议还确认：

- 该安排的资产归各合营方所有。所有法定所有权均由投资方保留。

- 合营方对合营安排的义务承担责任。

- 该公司的利润将按60:40的比例分配给电信公司A和投资方。

尽管该安排通过单独法律主体达成，但该主体本身并不拥有任何资产。各参与方对该公司的所有义务和索赔承担责任。该安排属于共同经营。

 

<a id="s234-chap_32_navPoint_34"></a>
### <a id="s234-EX32.45.1"></a>EX 32.45.1 – 确定合营安排的分类

 

准则索引：IFRS 11 第B27段  
正文索引：[32.45](57.md#s231-Para_32.45) 

  

  
三家独立的航空航天公司设立了一家单独主体J，以共同制造一架飞机。它们各自负责不同的专业领域，例如：

- 制造发动机；

- 制造机身和机翼；以及

- 空气动力学设计。

这些公司负责制造流程的不同部分，各自使用自身的资源和专业技能，共同制造、营销和分销飞机。三家主体分享销售飞机产生的收入并共同承担费用。收入和共同成本按照联合体合同的约定进行分配。

各参与方还各自承担自身单独发生的成本，例如人工成本、制造成本、耗材、未使用的零部件存货以及在产品。每一参与方全额确认其单独发生的成本。

主体J保持独立的会计记录。联合体协议包括以下内容：

- 主体J将代表投资方向客户开具发票。飞机销售收入按投资方的权益比例进行分配。

- 主体J发生的所有管理费用由各参与方按其权益比例分摊；主体J将按无额外加价的方式向各方转收这些费用。

- 各公司负责制造流程的不同部分，各自使用自身的资源和专业技能，共同制造、营销和分销飞机。

- 每一公司各自承担自身单独发生的成本，例如人工成本、制造成本、耗材、未使用的零部件存货以及在产品。每一公司全额确认其单独发生的成本。

该安排被分类为共同经营，因为每一公司对该安排的资产享有直接权利并对负债承担直接义务。参与方之间的合同协议逆转了法律形式所赋予的隔离。

 

<a id="s234-chap_32_navPoint_35"></a>
### <a id="s234-EX32.46.1"></a>EX 32.46.1 – 设立作为委托人代理人的合营安排

 

准则索引：IFRS 11 第B29段  
正文索引：[32.46](57.md#s231-Para_32.46) 

  

  
主体A和主体B同意通过单独主体J设立一项合营安排。设立主体J的目的是代表投资方持有资产。主体J的设立仅仅是为了担任其委托人（即投资方）的代理人，代表投资方管理资产和负债，并将其收入和成本转嫁给投资方。

**问题：**

主体J是否属于合营企业？

**回答：**

不是。尽管主体J是在单独主体中设立的，但这在确定合营安排的分类时并非决定性因素。该安排的设计以及合同协议旨在使主体J担任投资方的代理人。主体A和主体B对主体J的资产享有权利并对其负债承担义务。因此，主体J属于共同经营。

注：认定主体J担任投资方的代理人，很可能会影响合营安排内部交易的分类。例如，按照 IFRS 15，收入将按净额而非总额记录。

 

<a id="s234-chap_32_navPoint_36"></a>
### <a id="s234-EX32.49.1"></a>EX 32.49.1 – 共同建设和使用管道

 

准则索引：IFRS 11 第B33段  
正文索引：[32.49](57.md#s231-Para_32.49) 

  

  
主体A和主体B共同设立了一家有限责任公司，用于建造和使用一条天然气输送管道。每一主体持有该公司50%的权益。根据合同条款，主体A和主体B必须各自使用50%的管道运力。未使用的运力按与已使用运力相同的价格收费。主体A和主体B无需其他投资方同意即可将其享有的运力份额出售给第三方。主体A和主体B为天然气输送支付的价格的确定方式，确保了该公司发生的所有成本均能得到收回。

该合营安排通过单独主体达成。各方在该公司中持有50%的权益。合同条款要求各方达到特定水平的使用量，并且由于定价机制的原因，各主体对该公司的负债承担义务。尽管其法律形式如此，该主体仍可能属于共同经营。

### <a id="s234-FAQ_32.49.3"></a>FAQ 32.49.3 – 对“其他事实与情况”的评估是否应仅基于具有合同约束力和法律强制执行力的条款？

 

准则索引：IFRS 11 第B33段  
正文索引：[32.49](57.md#s231-Para_32.49) 

  

涉及具有合同约束力和法律强制执行力条款的事实与情况被认为与分类决策最为相关。

权利和义务本质上具有强制执行力。国际财务报告准则解释委员会得出结论，评估“其他事实与情况”对合营安排分类的影响时，应基于具有强制执行力的条款。

 

<a id="s234-chap_32_navPoint_39"></a>
### <a id="s234-FAQ_32.49.4"></a>FAQ 32.49.4 – 合营安排按市场价格向参与方出售产出是否会妨碍其被分类为共同经营？

 

准则索引：IFRS 11 第B33段  
正文索引：[32.49](57.md#s231-Para_32.49) 

  

按市场价格出售产出本身并非决定合营安排分类的决定性因素；需要运用判断，考虑参与方是否对合营安排的资产享有权利并对其负债承担义务。

国际财务报告准则解释委员会指出，若要基于其他事实与情况将合营安排分类为共同经营，必须证明：

- 参与方对安排资产的几乎全部经济利益（如产出）享有权利并承担义务；以及

- 参与方通过法定或合同义务向该安排提供现金，用于持续清偿合营安排的负债。

参与方按市场价格购买产出所提供的现金流，可能不足以确保该安排的负债得到持续清偿。这可能表明参与方没有清偿负债的义务。

设想一项生产黄金的合营安排，必须按伦敦金属交易所（London Metal Exchange）当时的黄金市场价格向参与方出售产出。市场价格可能波动至使该安排无利可图的水平。这可能表明该安排无法持续清偿其债务。

相反，如果价格按成本加成或盈亏平衡基础确定，这可能被视为不仅赋予了参与方获得全部产出的权利，还使其（在实质上）承担了持续清偿合营安排负债的义务。

 

<a id="s234-chap_32_navPoint_40"></a>
### <a id="s234-FAQ_32.49.5"></a>FAQ 32.49.5 – 在评估其他事实与情况时，哪些因素可能相关性较低？

 

准则索引：IFRS 11 第B33段  
正文索引：[32.49](57.md#s231-Para_32.49)  
 

  

产出的性质

国际财务报告准则解释委员会指出，产出的性质（无论是可替代产品还是定制产品）并不影响对其他事实与情况的评估。考量对负债的义务时，重点在于参与方与共同经营之间的现金流，而非产品本身的性质。

紧密且全面参与的参与方

对其他事实与情况的考量并非检验合营安排的参与方是否紧密或全面参与了单独主体的运营，而是评估其他事实与情况是否推翻了单独主体的法律形式赋予参与方的权利和义务。

来自第三方的融资

第三方融资的存在本身不应决定合营安排的分类。如果预期现金流足以向第三方融资提供方偿还债务，则不应影响合营安排的分类。

 

<a id="s234-chap_32_navPoint_41"></a>
### <a id="s234-FAQ_32.49.6"></a>FAQ 32.49.6 – 在确定“几乎全部产出”时，应以产出的数量还是货币价值为基础？

 

准则索引：IFRS 11 第B33段  
正文索引：[32.49](57.md#s231-Para_32.49) 

  

合营安排的参与方应当享有该安排资产几乎全部“经济利益”的权利，才构成“对资产的直接权利”。

例如，某合营安排生产：

- 产品A，单位价值较高且产量较小；以及

- 产品B，单位价值较低且产量较大。

国际财务报告准则解释委员会指出，经济利益与参与方对资产的权利和义务所产生的现金流相关。因此，更具相关性的是产出的货币价值，而非实物数量（产量）。

如果上述合营安排的产出按货币价值计算主要由产品A的销售额构成，那么尽管产品B的产量更高，在确定“几乎全部产出”时仍应考虑产品A。

### <a id="s234-EX32.50.1"></a>EX 32.50.1 – 合营安排的参与方

 

准则索引：IFRS 11 第25段  
正文索引：[32.50](57.md#s231-Para_32.50) 

  

  
主体A、B和C通过设立单独法律主体J订立了一项合营企业。各方对合营安排的出资如下：

- 主体A投入一项公允价值为C500的房地产。

- 主体B投入一台公允价值为C400的设备。

- 主体C投入现金C100。

公司章程按各方的出资比例赋予所有参与方表决权——即主体A拥有五票，主体B拥有四票，主体C拥有一票。主体A和主体B必须就主体J的生产、投资和筹资活动一致作出决策。

主体C是该合营安排的参与方，但对其不享有共同控制，因为关于相关活动的决策不需要其同意。尽管主体C在董事会中占有一个席位，但由于主体A和主体B积极行使共同控制，其10%的持股比例并不推定产生重大影响。因此，主体C按照 IFRS 9 将其在主体J中的投资作为金融资产进行会计处理。

### <a id="s234-EX32.53.1"></a>EX 32.53.1 – 取得不构成业务的共同经营权益

 

准则索引：IFRS 11 第B21段  
正文索引：[32.53](57.md#s232-Para_32.53) 

  

  
两名投资方（原油公司A和石油公司A）以普通合伙企业形式设立了一项合营安排，用于石油勘探和最终生产。该合伙企业处于早期勘探阶段，因此仅持有一项资产——勘探许可证。此外，原油公司A注意到以下情况：

- 该合伙企业取得的许可证的公允价值为C150。

- 原油公司A为取得其在该合伙企业中的份额投入了现金C90，并发生了交易费用C10。

假设原油公司A已对该安排进行分析并确定以下事项：

- 共同控制已明确确立，分类为共同经营是恰当的。

- 根据 IFRS 3，该合伙企业不构成一项业务。

**问题：**

原油公司A应如何对其取得该合伙企业权益进行会计处理？

**回答：**

原油公司A应将其在许可证中享有的50%权益按所支付的成本（C100 = 出资额 + 交易费用）确认为一项无形资产。不确认递延所得税或商誉。

### <a id="s234-FAQ_32.56.3"></a>FAQ 32.56.3 – 导致共同控制的丧失控制权交易会产生哪些会计影响？

 

准则索引：IFRS 11 第B34段  
正文索引：[32.56](57.md#s232-Para_32.56)   

  

  
国际财务报告准则解释委员会（IC）讨论了当主体丧失对一项业务，或丧失对不构成业务的资产或资产组的控制权时，是否应对其在共同经营资产和负债中保留的权益进行重新计量。

IC 讨论了 IFRS 11 指引与 IFRS 10 指引之间可能存在的冲突：IFRS 11 规定，主体向共同经营出售或投入资产所产生的利得或损失仅应就其他参与方在共同经营中所占权益份额的范围内予以确认；而 IFRS 10 规定，主体在丧失对子公司的控制权时应对任何保留权益进行重新计量。

IASB 近期推迟了针对 IFRS 10 和 IAS 28《在联营企业中的投资》拟议修订的生效日期，并决定在日后一并考虑若干相关问题。

基于此，IC 指出，对 IFRS 10 和 IFRS 11 的实施后审议将为理事会提供一个机会，以考量丧失控制权交易以及向联营企业或合营企业出售或投入资产的会计处理问题。

报告主体应为此类交易制定会计政策并一贯应用。该政策选择应在财务报表中予以披露。

 

<a id="s234-chap_32_navPoint_50"></a>
### <a id="s234-FAQ_32.57.1"></a>FAQ 32.57.1 – 取得构成业务的共同经营控制权会产生哪些会计影响？

 

准则索引：IFRS 11 第B33C段；IFRS 3 第42A段  
正文索引：[32.57](57.md#s232-Para_32.57) 

  

  
当投资方取得构成业务的共同经营的控制权时，主体应适用 IFRS 3。

当该业务包含在法律主体内时，上述处理方法在实务中得到了一贯应用。

而当该业务未包含在法律主体内（通常为通过合同设立的共同经营）时，实务中存在分歧，因为适用 IFRS 3 中的部分原则会产生问题。

例如，另一投资方在该业务中保留的所有权可能不符合非控制性权益（NCI）的定义（例如，另一投资方不持有股权权益，但确实保留了所有权权益）。

实务中对许多此类交易采用的会计处理是以下方法或其变体：

- 仅就控制方所占份额的范围内按公允价值确认资产/负债。

- 相对于已确认的资产和负债金额确认递延所得税和商誉。

- 不确认非控制性权益（NCI）。

无论该共同经营是否通过单独主体达成，任何先前持有的权益均应重新计量。

### <a id="s234-FAQ_32.57.3"></a>FAQ 32.57.3 – 取得不构成业务的共同经营控制权会产生哪些会计影响？

 

准则索引：IFRS 3 第2(b)段  
正文索引：[32.57](57.md#s232-Para_32.57)   

  

  
先前对共同经营行使共同控制或作为共同经营参与方的主体，可能取得该共同经营的控制权。

先前作为共同经营参与方且对该共同经营的资产享有权利并对其负债承担义务的主体，可能因权益变动而取得该共同经营的共同控制权。

如果上述交易涉及不构成业务定义的资产组，则不应对先前持有的权益进行重新计量。

主体应采用资产收购法。所支付的对价连同发生的任何直接费用，在资产负债表上确认为相关资产的成本累计额。

2016年1月，国际财务报告准则解释委员会指出，IFRS 3 第2(b)段说明了对不构成业务定义的资产或资产组收购的会计处理要求。解释委员会指出，IFRS 3 第2(b)段规定在核算资产收购时应采用基于成本的方法；而在基于成本的方法下，现有资产通常不予重新计量。

 

<a id="s234-chap_32_navPoint_53"></a>
### <a id="s234-EX32.59.1"></a>EX 32.59.1 – 非同一会计年度末

 

准则索引：IFRS 11 第20段  
正文索引：[32.59](57.md#s232-Para_32.59) 

  

  
IFRS 11 未就共同经营方与共同经营编制不同会计年度末的财务报表提供指引。

我们认为，应遵循 IAS 28 中关于合营企业的原则。

因此，用于将业绩纳入投资方财务报表的共同经营财务报表，最好与投资方的财务报表具有相同的报告日期。如果共同经营编制的年度财务报表具有不同的会计年度末，则需要编制截至共同经营方会计年度末的特殊目的财务报表。

如果编制与投资方报告日期一致的特殊目的财务报表不切实可行，则可以使用共同经营自身的财务报表，前提是其编制日期距投资方报告期末不超过三个月（之前或之后）。

当共同经营财务报表的报告期与投资方的报告期不一致时，管理层应确定两个报告日期之间是否发生了任何重大交易或事项。如果发生了此类事项且影响重大，管理层应在将共同经营纳入共同经营方合并财务报表之前，对共同经营的财务报表作出调整。

此类调整可能需要针对合营安排向投资方支付的股利以及公司间余额的结算进行。在合营安排报告日与投资方报告日之间发生的其他重大事项也可能需要调整。

我们认为，共同经营方应披露共同经营财务报表的报告期末日期，以及使用不同日期或期间的原因。

 

<a id="s234-chap_32_navPoint_54"></a>
### <a id="s234-FAQ_32.60.1"></a>FAQ 32.60.1 – 对共同经营方单独财务报表会产生哪些会计影响？

 

准则索引：IFRS 11 第26段  
正文索引：[32.60](57.md#s232-Para_32.60)  
 

  

  
共同经营方必须对其与共同经营相关的权利和义务进行会计处理。无论编制单独财务报表还是合并财务报表，这些权利和义务都是相同的。因此，共同经营方的合并财务报表和单独财务报表要求采用相同的会计处理。

2015年3月，国际财务报告准则解释委员会指出，共同经营方不会在其单独财务报表或合并财务报表中额外核算其在作为共同经营的单独主体中的股权；这是因为它已被要求在自身的财务报表中核算该共同经营的活动。

### <a id="s234-FAQ_32.62.3"></a>FAQ 32.62.3 – 投资方应如何对具有法律隔离特征的共同经营进行会计处理？

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62) 

  

  
共同经营计量的第一步是确定应当计量的内容。当共同经营包含在具有法律隔离特征的主体（例如有限责任公司）中时，这一确定过程会更加复杂。

当法律形式被投资方之间的合同条款（参见[第32.40段](57.md#s231-Para_32.40)）或对“其他事实与情况”的评估（参见[第32.46段](57.md#s231-Para_32.46)）所取代时，通过单独主体达成的合营安排可以属于共同经营。无论哪种情况，确定“计量什么”都可能很复杂。

法律形式被合同权利所取代

我们预计，在这些情况下，合同会包含足够详细的内容，以明确哪一方投资方对特定资产享有直接权利和/或对特定负债承担义务。

然而，对于合同未明确规定的任何项目，投资方可能难以明晰“其份额”。

法律形式被“其他事实与情况”所取代

当一项安排因“其他事实与情况”而被分类为共同经营时，可能需要运用重大判断以如实反映该安排及其潜在经济实质。当产出份额与所有权比例不同时，这一点尤为相关。

企业可以基于以下全部因素来界定“份额”（前提是合同或法律安排中未作明确规定）：

- 购买产出的数量（通常以百分比表示）。

- 所有权比例。

- 表决权比例（如与所有权比例不同）。

- 收入或利润的分配比例（如合同约定的比例与上述其他百分比不同）。

由于合同条款的规定，某些情况甚至可能通过上述项目的组合来最佳反映——例如，收入/费用按合同协议分摊，而资产和负债的份额则默认按所有权比例确定。

判断应一贯地应用于所有类似交易。类似的事实模式应得出类似的结果。

 

<a id="s234-chap_32_navPoint_59"></a>
### <a id="s234-EX32.62.4"></a>EX 32.62.4 – 具有法律隔离的主体：投资方有义务购买全部产出

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62) 

  

  
汽车供应商A和汽车供应商B是两家专门生产机动车制动部件（如制动盘和制动片）的汽车供应商。双方各自出资现金，共同设立了一家共同控制的有限责任公司（LLC），用于生产定制制动片。该安排使双方能够整合技术并实现各自单独运营无法达到的规模经济。

该安排被分类为共同经营，因为股东协议要求投资方按估计市场价格购买100%的产出。具体而言，协议要求汽车供应商A购买年产量的60%，汽车供应商B购买年产量的40%。利润按所有权比例（50/50）分配。

汽车供应商A和汽车供应商B同意购买全部产出，因为双方各自拥有强大的分销网络，可以有效利用这些网络而无需在有限责任公司内建立新的流程。双方各自投入了同等水平的初始资本。双方同意基于各自现有的分销网络按不成比例的份额购买产出；但是，产出的分配比例每年均可调整。

所有采购均按估计市场价格进行，为有限责任公司创造了基于市场的回报。

**问题**：

汽车供应商A在该共同经营中的份额是多少？

**回答**：

管理层在确定份额时，需要考虑所有权比例与产出水平之间存在差异的原因：

- 为何要求投资方购买全部产出？  
因为双方各自拥有强大的分销网络，可以有效利用这些网络而无需在有限责任公司内建立新的流程。

- 是否有一方投资方比另一方投入了更多的初始资本或资产？  
没有。

- 购买产出的分配比例是否会随时间变化？  
会，每年均可调整。上述事实表明，各方在该安排中各享有50/50的份额（所有权和经济利益似乎是平均分享的）。

 

<a id="s234-chap_32_navPoint_60"></a>
### <a id="s234-FAQ_32.62.5"></a>FAQ 32.62.5 – 当全部产出均由共同经营方购买时，会计处理是什么？

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62) 

  

  
共同经营方不应就共同经营向其他共同经营方出售产出确认任何金额。如果全部产出均由参与方购买且构成共同经营，则共同经营方仅在将其产出出售给第三方时才确认收入。

参与方A和参与方B设立一家公司以建造和使用一条天然气输送管道。参与方A持有该公司40%的所有权权益，参与方B持有该公司60%的所有权权益。该安排被分类为共同经营，因为股东协议要求投资方按成本加成价格购买100%的产出。

在此情景下，任何一方均不应确认其应享有的共同经营出售产出所产生的收入份额；如果确认，将意味着确认向自身出售产出所产生的收入。参与方A和参与方B仅在将其从共同经营购买的产出份额出售给第三方时才确认收入。

 

<a id="s234-chap_32_navPoint_61"></a>
### <a id="s234-FAQ_32.62.6"></a>FAQ 32.62.6 – 当购买产出的份额与所有权比例不同时，会计处理是什么？

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62) 

  

  
参与方A和参与方B设立一家公司以建造和使用一条天然气输送管道。参与方A持有该公司40%的所有权权益，参与方B持有该公司60%的所有权权益。参与方A和参与方B必须各自使用50%的管道运力。这一产出份额与所有权比例不同。

共同经营方在共同经营中进行的重大投资可能与其所有权比例不同。这可能表明存在其他要素或协议。识别这些其他要素可能为确定如何对所有权比例与产出份额之间的差异进行会计处理提供相关信息。为理解所有权比例与产出份额之间的这种脱节，需要考虑的问题包括：

- 为何要求参与方购买全部产出？

- 是否有一方比另一方投入了更多的初始资本或资产？

- 购买产出的分配比例是否会随时间变化？如果会，原因是什么？

合同要求参与方以覆盖该安排成本的价格购买全部产出，这赋予了参与方对相关资产的权利并使其承担了该安排负债的义务。这决定了其分类为共同经营。

参与方A最初投入的权益资本少于参与方B。在这种情况下，参与方A在共同经营中的份额在实质上部分由参与方B提供资金。合同条款要求参与方A在该安排清算时结清所占运力权益与所有权比例之间产生的差额。因此，双方按照其产出份额或管道运力份额对该经营进行会计处理。参与方A按50%确认其享有的资产和负债份额。这一比例与其向共同经营投入的40%权益资本之间产生的差额，构成应付参与方B的应付款项。

参与方B也将按50%确认其享有的共同经营资产和负债份额。这与其投入的60%之间的差额，构成应收参与方A的应收款项。参与方A将在该安排清算时向参与方B偿还该笔融资。

 

<a id="s234-chap_32_navPoint_62"></a>
### <a id="s234-EX32.62.7"></a>EX 32.62.7 – 共同经营中作业方的会计处理

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62)   

  

  
共同经营在石油和天然气行业非常普遍。未通过单独主体达成的共同经营的参与方通常会指定其中一方共同经营方担任“作业方”。此类架构通常具有以下特征：

- 作业方被赋予与各方签订合同的职责。

- 共同经营方之间的股东协议通常规定，作业方代表合营安排发生的任何支出均由其他共同经营方予以报销。

作业方可能代表其合作伙伴签订明示或隐含的租赁合同，且作业方可能是面对资产所有者的主要义务人。

例如，持有30%份额且担任油田作业方的合作伙伴可能与天然气处理设施的所有者签订独家处理协议。作业方可能对100%的处理付款承担责任，并有权向其合作伙伴收回其中70%的付款。

第15章第27段规定，在 IFRS 16 下，合营安排或代表合营安排行事的一方可以成为租赁中的承租人（IAS 17 下无同等指引）。由此产生的问题是，如何在作业方及其他共同经营方的财务报表中对该租赁进行会计处理。

IFRS 11 要求共同经营方根据合同安排确认资产和负债。

共同经营方需要确认其资产和负债，包括其对共同持有资产所享有的份额。[IFRS 11 第20段]。

在共同经营方代表共同经营与第三方签订租赁合同的情况下，该共同经营方应确认其在租赁协议下单独负责向第三方出租人支付的付款义务。与第三方签订租赁合同的作业方通常单独负责租赁协议下的全部付款，因此将确认全部租赁负债。

主体应评估其是否已将租赁资产的控制权转移给合营安排，还是保留了对租赁资产的控制权。如果控制权已转移，租入该资产的共同经营方可以按照 IFRS 16 将使用权资产的转移作为转租赁进行会计处理（参见[第15章 FAQ 15.113.1](35.md#s114-FAQ_15.113.1)）。如果签订租赁合同的作业方保留了对租赁资产的控制权，则其会计处理应类似于共同经营方在共同经营活动中使用自有不动产、厂场和设备并从其他共同经营方获得报销的情况。在此情况下，签订第三方租赁合同的作业方通常将按照权责发生制核算其根据联合经营协议有权获得的报销款项。

合同协议可能包含会影响会计处理的附加条款。例如，当共同经营的所有参与方均为租赁协议的当事方并对租赁付款承担连带责任时，由各共同经营方分别确认其应享有的使用权资产和租赁负债份额可能更为恰当。所有参与方共同签订租赁协议并承担连带责任的交易，与其中一方共同经营方作为唯一签署方与第三方签订租赁协议、同时另行签订由共同经营其他参与方报销的协议的交易之间，存在实质性差异。

 

<a id="s234-chap_32_navPoint_63"></a>
### <a id="s234-EX32.62.8"></a>EX 32.62.8 – 实际取得的产出与有权享有的产出不同（“超提与欠提”）

 

准则索引：IFRS 11 第20段  
正文索引：[32.62](57.md#s232-Para_32.62) 

  

  
 

主体A和主体B共同控制一处处于生产阶段的油气资产。主体A持有70%的权益，主体B持有30%的权益。根据协议，每一主体均需按其份额向共同经营报销共同经营发生的成本，并有权按与其所有权比例相称的比例取得共同经营生产的石油。
在本期间内，共同经营共生产了1,000桶石油，其中主体A有权享有700桶，主体B有权享有300桶。出于运营原因，主体B“超提”了50桶石油（即其实际取得的石油比根据联合经营协议有权取得的石油多50桶）。主体A“欠提”（即其实际取得的石油比有权取得的石油少50桶），但仍按其70%的权益比例支付了70%的成本。相应地，主体A取得并出售了650桶，主体B取得并出售了350桶。

根据联合经营协议，实际取得产出的任何不平衡均须在后续期间以实物结算，且任何一方均无权选择以现金结算该不平衡（即即使出现不再继续生产的情况，超提部分也必须以实物结算）。

假设该期间石油的市场价格为每桶CU 100，且这也是每一共同经营方在取得石油后向客户出售的价格。每一主体一旦从共同经营取得其产出，即按市场价格将石油交付给客户。

**问题：**

每一共同经营方应如何对这种不平衡进行会计处理？

**回答：**

2019年3月，国际财务报告准则解释委员会指出，在上述事实模式下，每一主体仅应在向其客户出售时确认 IFRS 15 收入。相应地，主体A将确认收入 CU 65,000（650桶 × CU 100），主体B将确认收入 CU 35,000（350桶 × CU 100）。

通常，油气资产的折耗基于“产量法”计算。欠提方对折耗成本的递延可通过减少产量法折耗费用来实现（即反映欠提方未来有权享有超过其份额的产量）。

超提/欠提安排在某些情况下可能允许以现金结算，即使这并非预期的结算方式。如果共同经营协议在任何情况下允许以现金结算不平衡部分，主体将需要评估是否适合在 IFRS 9 的范围内确认一项金融资产或金融负债。此类资产或负债源于与其他共同经营方之间的交易，通常不适合将该交易记录为来自客户合同的收入。但是，如果欠提方确认了应收其他共同经营方的金融资产，其可能会贷记“其他收入”。

### <a id="s234-EX32.64.1"></a>EX 32.64.1 – 逆流交易：销售存货

### <a id="s234-FAQ_32.73.2"></a>FAQ 32.73.2 – 合营企业的设立：主体应如何对投入业务的公允价值与其他合营方投入资产的公允价值之间的差额进行会计处理？

 

准则索引：IAS 28 第32段  
正文索引：[32.73](57.md#s232-Para_32.73)  
 

  

管理层应按所投入资产或业务的公允价值（包括任何相关商誉）对合营企业进行初始会计处理。当所投入资产或业务的公允价值超过合营方应享有其他合营方所投入资产公允价值的份额时，超出部分为商誉（实质上是与另一合营方在设立合营企业时所投入资产的公允价值进行比较）。合营方不对其自身投入合营企业的资产中所享有的权益进行重新估值。以这种方式确认的任何商誉仅为名义商誉，不在合营方的资产负债表上确认为单独资产。

合营企业未必会在其资产和负债的账面价值中确认合营方所识别的任何公允价值调整。在采用权益法核算其对合营企业的权益时，合营方需要调整合营企业的业绩，以考虑任何名义公允价值调整的影响。

 

<a id="s234-chap_32_navPoint_70"></a>
### <a id="s234-EX32.73.3"></a>EX 32.73.3 – 合营方向合营企业转让业务以换取股权：IAS 28 下的会计政策

 

准则索引：IAS 28 第32段  
正文索引：[32.73](57.md#s232-Para_32.73) 

  

  
主体A与主体B订立了一项合营企业。双方在该合营安排中的相对权益比例分别为60%和40%。合营方同意以股权转让的方式投入由子公司持有的业务，具体如下：

- 主体A持有包含该业务的子公司投资的账面价值为C200（包括可辨认净资产C100和商誉C100），该业务的公允价值为C300。在其单独财务报表中，主体A以C200的成本持有对该子公司的投资。

- 主体B持有包含该业务的子公司投资的账面价值为C150（包括账面价值为C100的可辨认净资产和C50的商誉），该业务的公允价值为C200。

该合营安排全部可辨认净资产的公允价值为C270，包括主体A可辨认净资产的公允价值C150和主体B可辨认净资产的公允价值C120。该合营企业业务的公允价值为C500。

主体A的会计政策是遵循 IAS 28 的规定，因此仅就另一投资方所占份额的范围内确认顺流交易产生的利得/损失（即抵销自身份额）。

每一合营方对合营企业投资的成本应与其应享有另一合营方所投入可辨认净资产公允价值的份额进行比较。投资成本超过净资产公允价值的差额代表商誉。

### <a id="s234-FAQ_32.85.1"></a>FAQ 32.85.1 – 保留共同控制权情况下的所有权比例变动会产生哪些影响？

 

准则索引：IAS 28 第32段  
正文索引：[32.85](57.md#s232-Para_32.85)  
 

  

  
IFRS 11 和 IAS 28 并未规范在保留共同控制权的情况下增加合营企业所有权比例的会计处理。我们认为，追加权益的成本应计入现有账面价值中。名义商誉通过将追加权益的成本与应享有合营企业可辨认净资产和负债的相应份额进行比较来计算。由于未发生重新计量事项，不对先前持有的权益按公允价值调增。

 

<a id="s234-chap_32_navPoint_73"></a>
### <a id="s234-FAQ_32.86.1"></a>FAQ 32.86.1 – 实质上构成净投资一部分的长期权益应如何计量？

 

准则索引：IAS 28 第40段  
正文索引：[32.86](57.md#s232-Para_32.86)  
 

  

  
2016年6月，IASB 初步决定最终定稿对 IAS 28《在联营企业和合营企业中的投资》的拟议修订。该修订明确，IFRS 9《金融工具》适用于对联营企业或合营企业的长期权益。长期权益是指实质上构成净投资一部分、但未采用权益法核算的权益。

理事会还初步决定在 IAS 28 中明确：

- 在适用 IAS 28 的亏损分担和减值要求之前，应先对长期权益适用 IFRS 9 的要求；以及

- 主体在适用 IFRS 9 的要求时，不应考虑因适用 IAS 28 而对长期权益账面价值作出的任何调整。

理事会初步决定制定教育材料，以说明 IAS 28 与 IFRS 9 在长期权益方面的相互关系。

理事会初步决定将生效日期定为2019年1月1日，允许提前采用。需按照 IAS 8 进行追溯调整。对于在首次采用 IFRS 9 之后再采用该修订的主体，其过渡要求将与 IFRS 9 中关于分类和计量的过渡要求类似。
