#### <a id="s113-FAQ_15.3.1"></a>FAQ 15.3.1 – 属于IAS 19范围的公务用车使用安排是否也可能属于IFRS 16的范围？

准则索引：IFRS 16 第3段  
正文索引：[15.3](33.md#s107-Para_15.3)  

**问题**

属于IAS 19范围的公务用车使用安排是否也可能属于IFRS 16的范围？

**解答**

雇主与租赁公司签订一份为期36个月的汽车租赁协议。同时，雇主与员工签订协议，允许员工在相同期间内将该汽车作为公务用车使用，并按优惠标准收取费用（从工资中扣除）。汽车的使用完全由员工自行决定（即员工决定将汽车用于私人和/或公务用途）。

如果员工在协议期满前离职，员工有义务将汽车归还给雇主。雇主作为主要责任人行事，因而是主租赁中的承租人。每辆汽车均固定分配给特定员工，且不存在实质性替换权，因此存在已识别资产。

雇主与员工之间的协议包含一项IAS 19下的员工福利。

我们认为，目前尚不明确雇主是否还需要根据IFRS 16考虑是否存在向员工转租该汽车的情形。因此，我们认为雇主可在以下选项之间作出会计政策选择：

- 将该汽车视为整体薪酬方案的一部分。此时适用更为相关的IAS 19准则，雇主不适用IFRS 16（即不考虑是否存在IFRS 16下向员工转租汽车的情形）。

- 认为IFRS 16与IAS 19的范围并非相互排斥。因此，雇主除核算IAS 19下的员工福利外，还需适用IFRS 16以确定是否存在IFRS 16下的转租赁。

所选择的会计政策应当一贯应用并予以披露。如果该项选择构成关键会计判断，主体应当考虑IAS 1的披露要求。详见[第4章第152段](10.md#s29-Para_4.152)。

#### <a id="s113-FAQ_15.3.2"></a>FAQ 15.3.2 – 地下空间是否属于IFRS 16的范围？

准则索引：IFRS 16 第9段  
正文索引：[15.3](33.md#s107-Para_15.3)  

**背景**

客户取得在10年内于某地下空间铺设资产（如管道）的权利，并支付对价。合同明确规定了该资产铺设所在地下空间的确切位置与尺寸（路径、宽度及深度）。土地所有者保留使用管道上方地表的权利，但在整个使用期间内无权进入或以其他方式改变该指定地下空间的用途。客户将运营该管道并执行检查、维修和维护工作（包括在必要时更换受损管段）。

**问题**

该项安排是否属于IFRS 16的范围？

**解答**

是的。国际财务报告准则解释委员会（IC）于2019年6月讨论了该问题。

解释委员会认定，该地下空间不符合无形资产的定义，因而不适用IFRS 16中针对无形资产的可选范围豁免，因为界定清晰的地下空间本质上属于有形资产。因此，该合同涉及一项已识别有形资产的使用，客户应当评估该合同是否为租赁或包含租赁。如果合同让渡了在一定期间内控制一项已识别资产使用的权利以换取对价，则该合同为租赁或包含租赁。

在该事实模式下，租赁的定义得以满足，原因如下：

- 该地下空间在物理上可区分且在地理位置上已明确指定；

- 不存在实质性替换权，因为迁移管道的成本高昂；

- 客户在一定期间内对该地下空间享有排他性使用权；

- 合同已预先确定了该地下空间的使用方式及使用目的；

- 客户通过享有执行检查、维修和维护工作的权利，拥有主导该指定地下空间运营的权利；以及

- 在20年使用期间内，客户作出关于该指定地下空间使用的一切可作出的决策。

因此，该合同属于IFRS 16的范围。

出租人和承租人（在承租人未选择适用IFRS 16第15段实务权宜措施的情况下）均应当考虑合同中的其他权利（例如为进行检查、维修和维护而进入土地的权利）是否构成应单独核算的可区分非租赁组成部分。

#### <a id="s113-FAQ_15.5.1"></a>FAQ 15.5.1 – 如何解释“对价”一词？

准则索引：IFRS 16 第9段  
正文索引：[15.5](33.md#s107-Para_15.5)  

**问题**  
如何解释“对价”一词？

**解答**  
如果合同让渡了在一定期间内控制已识别资产使用的权利以换取对价，则该合同为租赁或包含租赁。“对价”一词应当作广义解释，包括收取付款的可能性。除符合租赁付款额定义并须根据IFRS 16第27段计入租赁负债计量的付款外，它还涵盖例如不取决于指数或比率的可变付款额。因此，即使全部付款均为不取决于指数或比率的可变付款额，只要满足其他条件，该合同仍然符合租赁的定义。

<a id="s113-chap_15_navPoint_idp1714725992"></a>
#### <a id="s113-FAQ_15.5.2"></a>FAQ 15.5.2 – 如何解释“一定期间”一词？

准则索引：IFRS 16 第10段  
正文索引：[15.5](33.md#s107-Para_15.5)  

**问题**  
如何解释“一定期间”一词？

**解答**  
不应过于字面地解释“一定期间”一词。

标的资产的使用量（例如某台设备将生产的产量）同样可以表述IFRS 16第9段所要求的“一定期间”。

<a id="s113-chap_15_navPoint_idp1687983512"></a>
#### <a id="s113-FAQ_15.5.3"></a>FAQ 15.5.3 – 永久期间是否属于“一定期间”？

准则索引：IFRS 16 第9段  
正文索引：[15.5](33.md#s107-Para_15.5)  

**问题**  
永久期间是否属于“一定期间”？

**解答**  
为了符合租赁的定义，一项安排必须让渡在“一定期间”内使用一项已识别资产的权利。然而，某些合同（如特定的土地地役权）对时间期限没有限制（即属于永久期间）。由于IFRS 16未对“一定期间”一词作出定义，永久使用权是否涵盖在该术语范围内尚不明确。

一种观点认为，真正意义上的永久使用权并非在（特定的）“一定期间”内，因此不符合IFRS 16第9段中的租赁定义。但是，主体必须考虑合同实质以判断其是否真正属于永久性的。例如，如果合同约定持续付款，且仅通过停止付款即可终止该安排，则该期限并非真正意义上的永久性。同样，长期土地租赁（例如999年租赁）不应被视为永久性的。对于真正的永久使用权，需要分析确定是否应根据其他准则（如IAS 16或IAS 38）确认一项资产。

另一种观点认为，尽管对时间期限没有限制，但“永久期限”仍然属于“一定期间”。按照这一观点，只要满足租赁定义的其他所有要件，永久使用权即符合租赁的定义。

我们认为，在IFRS 16缺乏具体指引的情况下，上述两种方法均可接受，因此主体拥有会计政策选择权。所选择的会计政策应当一贯应用并予以披露。如果该项选择构成关键会计判断，主体应当考虑IAS 1的披露要求。详见[第4章第152段](10.md#s29-Para_4.152)。

#### <a id="s113-FAQ_15.9.1"></a>FAQ 15.9.1 – 当安排的履行依赖于某项资产的使用时，是否存在已识别资产？

准则索引：IFRS 16 附录B第B13段  
正文索引：[15.9](33.md#s107-Para_15.9)  

**问题**  
主体A签订了一项向某钢铁厂出售电力的协议。为履行该协议，主体A在钢铁厂旁建造了一座发电站。主体A没有其他可使用的发电资产。该发电站是否为已识别资产？

**解答**  
是的。很明显，该协议的履行依赖于建在钢铁厂旁的发电站的使用。

<a id="s113-chap_15_navPoint_idp1687995544"></a>
#### <a id="s113-FAQ_15.10.1"></a>FAQ 15.10.1 – 评估出租人是否因替换资产而获得经济利益时应考虑哪些因素？

准则索引：IFRS 16 附录B第B14段  
正文索引：[15.10](33.md#s107-Para_15.10)  

**问题**  
评估出租人是否因替换资产而获得经济利益时应考虑哪些因素？

**解答**  
“利益”一词应当作广义解释。例如，只要不存在重大成本，供应方通过不时替换租赁资产而能够更高效地调配资产池这一事实，就可能产生足够的利益。“重大”是参照相关利益进行评估的（即成本必须低于利益；仅成本较低或对主体整体而言不重大并不足够）。尤其是当标的资产为客户量身定制时，可能会产生重大成本。例如，租赁飞机可能具有由客户规定的特定内部和外部规格。在此情景下，在整个租赁期内替换飞机可能会产生重大成本，从而阻碍供应方进行替换。

<a id="s113-chap_15_navPoint_idp1688013208"></a>
#### <a id="s113-FAQ_15.14.1"></a>FAQ 15.14.1 – 仅在特定时点或特定事件发生时才享有的替换权是否应纳入考量？

准则索引：IFRS 16 附录B第B15段  
正文索引：[15.14](33.md#s107-Para_15.14)  

**问题**  
合同为租赁或包含租赁的条件之一是合同让渡了控制已识别资产使用的权利。即使合同中指定了某项资产，根据IFRS 16，如果供应方拥有实质性替换权，该资产也不是已识别资产。如果供应方仅在特定日期或特定事件发生日或之后才有权或有义务替换该资产，则供应方的替换权不具有实质性，因为供应方在整个使用期间内并不具备替换替代资产的实际能力。

在以下情景中，供应方是否拥有实质性替换权，从而导致合同不符合租赁的定义？

**解答**

**示例1**

客户与供应方签订合同，取得在六年内控制某项资产使用的权利。供应方仅有权在合同开始三年后的某一特定日期替换标的资产（即在任何其他时点均无替换权）。

由于供应方仅有权在某一特定日期替换该资产，而非在整个使用期间内，因此该替换权不具有实质性。本例中的租赁期为六年。

**示例2**

客户与供应方签订合同，取得在六年内控制某项资产使用的权利。供应方有权在合同期限内于某一特定事件发生时替换标的资产。

由于供应方仅有权在特定事件发生时替换该资产，而非在整个使用期间内，因此该替换权不具有实质性。本例中的租赁期为六年。

#### <a id="s113-FAQ_15.18.1"></a>FAQ 15.18.1 – 识别租赁时应考虑哪些经济利益？

准则索引：IFRS 16 第IE2段（示例9）  
正文索引：[15.18](33.md#s107-Para_15.18)  

**问题**  
客户向供应方租用一座太阳能发电场。供应方获得与太阳能发电场所有权相关的税收抵免，而客户因使用该发电场获得可再生能源积分。在评估客户是否取得使用已识别资产所产生的几乎全部经济利益时，应当考虑哪些经济利益？

**解答**  
在此情景下，主体仅考虑可再生能源积分，因为税收抵免并非与太阳能发电场的使用相关，而是与资产的所有权相关。

#### <a id="s113-FAQ_15.24.1"></a>FAQ 15.24.1 – 分析在租赁开始日前作出的决策时应考虑哪些因素？

准则索引：IFRS 16 附录B第B24段  
正文索引：[15.24](33.md#s107-Para_15.24)  

**问题**  
分析在租赁开始日前作出的决策时应考虑哪些因素？

**解答**  
当决策是在租赁开始日前作出时，应用IFRS 16中“预先确定”的概念可能非常复杂且涉及重大判断。在分析此类决策时，需要考虑若干问题，包括：

- 是否存在任何未预先确定的决策，且这些决策对资产的使用方式和使用目的产生重大影响？

- 这些决策是预先确定了已识别资产的使用方式和使用目的，还是仅仅确立了保护性权利？

- 合同中的哪一方作出了这些决策？

<a id="s113-chap_15_navPoint_idp1690434744"></a>
#### <a id="s113-FAQ_15.24.2"></a>FAQ 15.24.2 – 当关于资产使用方式和使用目的的许多（但非全部）决策已预先确定时，如何解释“预先确定”？

准则索引：IFRS 16 附录B第B24段  
正文索引：[15.24](33.md#s107-Para_15.24)  

**问题**  
主体A就一项已识别资产签订合同，该合同赋予主体A取得使用该资产所产生的几乎全部经济利益的权利。关于该资产使用方式和使用目的的许多（但非全部）决策已在合同中预先确定。主体A有权在整个使用期间内作出关于该资产使用方式和使用目的的其余决策。

主体A是在整个使用期间内有权主导该资产的使用，还是主导使用的权利已被预先确定？

**解答**

在评估哪一方有权主导资产的使用，或主导使用的权利是否已被预先确定时，主体A应当识别所有可能影响使用资产所产生经济利益的相关决策权。凡是影响使用资产所产生经济利益的决策权，均为相关决策权（参见IFRS 16第B25段）。

如果所有相关决策均在使用期间之前作出，则主体A适用“预先确定”指引。

如果一项或多项相关决策是在使用期间内作出的，则不适用“预先确定”指引。此时，主体A应当评估总体上哪一方在使用期间内主导该资产的使用。在此评估中，在使用期间之前作出的决策应予忽略（参见[第15.25段](33.md#s107-Para_15.25)）。

<a id="s113-chap_15_navPoint_idp1690451128"></a>
#### <a id="s113-EX15.26.1"></a>EX 15.26.1 – 将租赁定义应用于零售铺位

准则索引：IFRS 16 第IE2段（示例4）、附录B第B31段  
正文索引：[15.26](33.md#s107-Para_15.26)  

**示例**  
客户签订了一项合同，取得在五年期间内使用某明确指定零售铺位的权利。物业所有者可以要求客户搬迁至另一处零售铺位；存在若干品质与规格相似的零售铺位可供使用。

由于物业所有者必须承担所有搬迁费用，只有当有新承租人希望以足以覆盖搬迁费用的租金价格承租大面积零售空间时，物业所有者才能从要求客户搬迁中获得经济利益。上述情形虽有可能发生，但被认为不太可能发生。

合同要求客户在大型商业空间的营业时间内销售其商品。客户决定所售商品的组合、商品的定价以及持有的存货数量。此外，客户在整个五年使用期间内控制对该零售铺位的物理进出权限。

客户需支付的租金包括固定金额加上该零售铺位销售额的一定比例。

**分析**

是否存在已识别资产？该零售铺位在合同中明确指定。物业所有者虽享有替换该资产的权利，但该替换权不具有实质性，因为物业所有者仅在被认为不太可能发生的特定情形下才能从行使该权利中获益。因此，该零售铺位是一项已识别资产。

客户是否有权取得使用该零售铺位所产生的几乎全部经济利益？客户在整个使用期间内享有该零售铺位的排他性使用权。将使用该铺位所收到现金流量的一部分作为对价支付给物业所有者这一事实，并不妨碍客户享有取得使用该零售铺位所产生的几乎全部经济利益的权利。

客户是否有权主导该零售铺位的使用？在使用期间内，关于该零售铺位使用方式和使用目的的所有决策均由客户作出。仅能在大型商业空间营业时间内销售商品的限制界定了合同的范围，但并未限制客户主导该零售铺位使用的权利。

该合同包含一项零售铺位租赁。

#### <a id="s113-EX15.26.2"></a>EX 15.26.2 – 将租赁定义应用于铁路货车

准则索引：IFRS 16 第IE2段（示例1）、附录B第B31段  
正文索引：[15.26](33.md#s107-Para_15.26)  

**示例1**

客户签订了一项合同，取得在四年内使用一辆明确指定的铁路货车的权利。客户决定何时、何地以及使用该铁路货车运输何种货物。当该铁路货车未使用时，其停放在客户场地内，并可用于其他用途（例如仓储）。但客户不得运输特定类型的货物，如爆炸物。

如果该铁路货车需要保养或维修，供应方须对其进行替换。除此之外，供应方在使用期间内不得收回该铁路货车。

**分析**

是否存在已识别资产？该铁路货车在合同中明确指定。除保养或维修外，供应方在使用期间内不得替换该铁路货车。供应方因维修或维护而替换资产的权利或义务，并不妨碍客户享有使用已识别资产的权利。因此，该铁路货车是一项已识别资产。

客户是否有权取得使用该铁路货车所产生的几乎全部经济利益？客户在整个使用期间内享有该铁路货车的排他性使用权，包括其未用于运输客户货物的时间。因此，客户有权取得使用该铁路货车所产生的几乎全部经济利益。

客户是否有权主导该铁路货车的使用？在使用期间内，关于该铁路货车使用方式和使用目的的所有决策均由客户作出。对可运输货物的限制界定了合同的范围，但并未限制客户主导该铁路货车使用的权利。

该合同包含一项铁路货车租赁。

**示例2**

客户签订了一项合同，要求供应方在四年期间内按照规定时刻表，使用特定类型的铁路货车运输指定性质和数量的货物。规定的时刻表和货物数量相当于一辆铁路货车四年的运力。供应方拥有大量可用于履行合同要求的铁路货车车队。当铁路货车未使用时，停放在供应方场地内。

**分析**

是否存在已识别资产？合同中提及的铁路货车不符合已识别资产的定义，因为供应方拥有替换该铁路货车的实质性权利。首先，供应方具备替换铁路货车的实际能力（因为存在可供替代的铁路货车，且供应方替换铁路货车无需客户批准）。其次，供应方将因替换货车而获得经济利益。由于供应方在其场地内停放有大量铁路货车，替换仅会产生极低成本（如有）。供应方将从替换中获益，因为这使其能够更高效地调配其铁路货车车队（例如，根据位置使用该铁路货车运输另一客户的货物，或使用因客户未使用而原本处于闲置状态的铁路货车）。

该合同不包含租赁。

#### <a id="s113-EX15.26.3"></a>EX 15.26.3 – 将租赁定义应用于光缆

准则索引：IFRS 16 第IE2段（示例3）、附录B第B31段  
正文索引：[15.26](33.md#s107-Para_15.26)  

**示例1**

一项合同让渡了在两年内排他性使用一条大型光缆中三条明确指定且在物理上可区分的暗光纤的权利。客户通过将光纤两端连接至其电子设备（即客户“点亮”光纤）来作出关于这些光纤使用的全部决策。此外，客户决定光纤传输哪些数据以及传输多少数据。供应方拥有多余的光纤，但仅能因维修、维护或故障原因替换客户的光纤。

**分析**

是否存在已识别资产？这些光纤在合同中明确指定，且在物理上与光缆中的其他光纤可区分。除维修、维护或故障原因外，供应方在合同期内不得替换这些光纤。供应方因维修或维护而替换资产的权利或义务，并不妨碍客户享有使用已识别资产的权利。这些光纤符合已识别资产的定义。

客户是否有权取得使用这些光纤所产生的几乎全部经济利益？客户在整个使用期间内享有这些光纤的排他性使用权，从而取得使用这些光纤所产生的几乎全部经济利益。

客户是否有权主导这些光纤的使用？在使用期间内，关于这些光纤使用方式和使用目的的所有决策均由客户作出。客户决定何时或是否点亮光纤，以及光纤将传输哪些数据和多少数据。因此，客户有权主导这些光纤的使用。

该合同包含对这三条光纤的租赁。

**示例2**

客户签订了一项合同，取得在两年内使用一条包含10条光纤的光缆中指定容量份额的权利；该容量相当于使用光缆中三条光纤的全部容量。供应方作出关于数据传输的决策（即由供应方“点亮”光纤、决定使用哪些光纤来传输客户的数据流量，并决定连接至光纤的电子设备）。

**分析**

是否存在已识别资产？该容量份额在物理上与光缆的其余容量不可区分，且不代表光缆的几乎全部容量。因此，不存在已识别资产。

该合同不包含租赁。

#### <a id="s113-EX15.26.4"></a>EX 15.26.4 – 将租赁定义应用于船舶

准则索引：IFRS 16 第IE2段（示例6）、附录B第B31段  
正文索引：[15.26](33.md#s107-Para_15.26)  

**示例1**

客户与船东签订了一项货物运输合同。合同中明确指明了该船舶，且船东没有替换权。该批货物将占据该船舶几乎全部的载货容量。

合同规定了将要运输的货物、装货日期和地点以及交货日期和地点。船东在合同期内负责运营该船舶，且禁止客户雇佣其他运营商或自行运营该船舶。

**分析**

是否存在已识别资产？该船舶在合同中明确指定，且船东没有替换权。该船舶是一项已识别资产。

客户是否有权取得使用该船舶所产生的几乎全部经济利益？由于货物将占据该船舶几乎全部的载货容量，客户取得了使用该船舶所产生的几乎全部经济利益。

客户是否有权主导该船舶的使用？该船舶的使用方式和使用目的已在合同中预先确定，客户无权更改。合同明确规定了将运输哪些货物、何时运输以及运往何处。由于客户未参与设计该船舶或其组成部分，且无权运营该船舶，因此客户无权主导该船舶的使用。

该合同不包含租赁。

**示例2**

事实同上，但客户在整个使用期间内决定将运输哪些货物，以及船舶是否航行、何时航行及驶往哪些港口。

**分析**

在此情景下，船舶的使用方式和使用目的不再由合同预先确定，而是由客户决定。因此，客户有权主导该船舶的使用。

该合同包含一项船舶租赁。

#### <a id="s113-FAQ_15.27.1"></a>FAQ 15.27.1 – 应如何评估合营安排是否有权控制已识别资产的使用？

准则索引：IFRS 16 附录B第B11段  
正文索引：[15.27](33.md#s107-Para_15.27)  

**问题**  
应如何评估合营安排是否有权控制已识别资产的使用？

**解答**  
合营安排可以采取共同经营或合营企业的形式。视合营安排是否具有独立的法律主体资格而定，合同可能由合营安排本身签署，或者由合营安排的一个或多个参与方代表合营安排签署。

如果合营安排的参与方作为一个整体符合租赁的定义，则该合同包含租赁。不能以合营安排的单个参与方自身未取得已识别资产所产生的几乎全部经济利益且未主导标的资产的使用为由，主张该合同不包含租赁。

FAQ 32.62.7 讨论了作业者和其他共同经营者应当如何对租赁进行会计处理。

#### <a id="s113-FAQ_15.29.1"></a>FAQ 15.29.1 – 出租人如何根据IFRS 16和IFRS 15分拆合同组成部分？

准则索引：IFRS 16 附录B第B32段  
正文索引：[15.29](33.md#s107-Para_15.29)  

**问题**  
出租人应当如何根据IFRS 16和IFRS 15分拆合同组成部分？

**解答**  
IFRS 15包含了关于出租人如何评估向客户承诺的商品或服务是否可明确区分的指引。

对于包含（或可能包含）租赁的多要素安排，出租人须按如下步骤进行评估：

- 应用IFRS 16的指引，评估合同是否包含一个（或多个）租赁组成部分。

- 应用IFRS 16的指引，评估不同的租赁组成部分是否须单独进行会计处理。

- 在根据IFRS 16识别租赁组成部分之后，应当根据IFRS 15评估非租赁组成部分是否构成单项履约义务。

IFRS 16中关于分拆租赁组成部分的标准，与IFRS 15中关于分析向客户承诺的商品或服务是否可明确区分的标准相似。

<a id="s113-chap_15_navPoint_idp1696041896"></a>
#### <a id="s113-FAQ_15.33.1"></a>FAQ 15.33.1 – 如果出租人向承租人销售耗材，应如何分摊对价？

准则索引：IFRS 16 第17段  
正文索引：[15.33](33.md#s107-Para_15.33)  

**问题**  
主体A（供应方）是一家医疗器械公司，向医院（客户）提供标准医疗器械以及与该器械配套运行所需的耗材。供应方既可以出售这些医疗器械，也可以将其在约定期间内出租给客户。市场上存在其他供应方提供与该机器配套使用的耗材。主体A签订了一项安排，其主要特征如下：

- 主体A免费授予客户在36个月内使用该医疗器械的权利。设备的所有权仍归主体A所有，且该器械将在合同期满时归还。

- 合同并未要求客户必须购买耗材（即无最低采购量要求），但如果客户确实购买耗材，则须在合同开始后的36个月内向主体A采购。

- 耗材的采购价格等于市场价格。

- 根据以往经验，主体A预计客户每年将消耗5,000件耗材。主体A拥有此类安排的历史经验，能够可靠地估计相应数量。消耗量极有可能超过每年4,000件耗材。

- 即使该机器未被使用，主体A也无权将其收回。

- 主体A已对在36个月内使用该医疗器械的权利进行了评估，确定其符合租赁的定义且应分类为经营租赁。

- 在同一时间或相近时间，客户订购且主体A交付了1,000件耗材。

**因销售耗材而产生的付款中，是否有任何部分需要分摊至租赁合同？**

**解答**  
在此情景下，购买1,000件耗材与医疗器械的租赁直接相关，因为双方在同一时间或相近时间签订了两份协议，且耗材的对价金额取决于初始合同中约定的价格。该合同包含租赁组成部分（医疗器械的使用权）和非租赁组成部分（交付耗材），应当分别进行会计处理。[IFRS 16 第12段]。IFRS 16第17段要求主体A应用IFRS 15第73至90段分摊合同对价（即按照租赁组成部分与非租赁组成部分的相对单独售价进行分摊）。

对于后续的耗材订单，可以认为不存在租赁变更，因为租赁范围或对价均未发生原条款之外的变化。因此，在合同期内订购额外耗材时，不会调整租赁付款额。

或者，也可以认为额外订单改变了整体对价，应当参照合同变更进行会计处理。基于这一理由，将后续订单对价中的一部分分摊至租赁要素也是可以接受的。如果主体采用该替代方法，分摊至租赁要素的任何对价均构成可变租赁付款额，在实际发生时（即相关耗材交付之日）确认为收入。如果主体选择该替代方法，仅影响利润表中的列报（即列报为租赁收入还是客户合同收入的金额），而不影响所确认收入的金额或时点。

### 合同的合并

<a id="s113-chap_15_navPoint_idp1696065832"></a>
#### <a id="s113-EX15.35.1"></a>EX 15.35.1 – 基于单独合同提供的临时建筑解决方案的会计处理

准则索引：IFRS 16 附录B第B2段  
正文索引：[15.35](33.md#s107-Para_15.35)  

**示例**  
某主体向客户提供临时建筑解决方案。这些解决方案包括在固定期间内使用临时建筑的权利、搭建和安装临时建筑（即安装水、电、暖气和家具）以及在合同期满时拆除临时建筑。该主体就租赁临时建筑、搭建安装以及拆除分别与客户签订了单独的合同。

**分析**  
这些合同是作为一揽子交易以实现整体商业目的而进行谈判的。客户租赁的不仅仅是一栋建筑物，而是一栋配备水、电、暖气和家具的建筑物。因此，安装这些设施（以及后续的拆除）是该安排不可分割的组成部分。所以，第一步应当根据IFRS 16第B2(a)段将这三份单独的合同合并。

第二步需要考虑安装和拆除是否应当分拆并作为单独的服务进行会计处理。根据IFRS 16第B33段，“……承租人就未向承租人转让商品或服务的活动和成本所应支付的金额……”不构成单独的服务组成部分，但构成总对价的一部分。为使租赁资产达到承租人可使用状态所必需的活动不属于单独的服务。出租人执行的活动（例如安装服务、在客户场地组装或定制）是否为使用租赁资产所必需，取决于具体事实和情况。作出评估时需考虑的因素包括：

- 资产的类型（标准型还是专用型）以及所涉及安装服务的复杂程度；

- 这些活动在实务中是否可由客户或第三方供应商执行（合同限制通常不相关）；以及

- 从客户的角度来看，交付的是一项“已安装资产”，还是一项未安装资产加上安装服务。

在本例中，如果没有出租人执行的安装，客户无法使用该临时建筑；安装服务是出租人提供可供使用资产之义务的不可分割组成部分。租赁期满时的拆除同样未向承租人转让商品或服务。因此，临时建筑的安装和拆除不属于单独的服务。

### 租赁期

<a id="s113-chap_15_navPoint_idp1696081704"></a>
#### <a id="s113-FAQ_15.37.1"></a>FAQ 15.37.1 – 终止租赁选择权如何影响租赁期的长度？

准则索引：IFRS 16 附录B第B34段、第B35段  
正文索引：[15.37](33.md#s107-Para_15.37)  

**问题**  
终止租赁选择权如何影响租赁期的长度？

**解答**  
关于终止租赁选择权，存在三种可能的情景：

- 仅承租人拥有终止租赁选择权：仅当承租人合理确定不会行使终止租赁选择权时，该终止租赁选择权所涵盖的期间才计入租赁期。

- 仅出租人拥有终止租赁选择权：该终止租赁选择权所涵盖的期间属于不可撤销租赁期间的一部分。

- 双方均拥有终止租赁的权利：只要各方均有权在不经另一方许可的情况下终止租赁，且罚款金额不重大，则终止租赁选择权所涵盖的期间不属于租赁期的一部分。

<a id="s113-chap_15_navPoint_idp1696090152"></a>
#### <a id="s113-FAQ_15.37.2"></a>FAQ 15.37.2 – 如果一方拥有的终止租赁选择权伴随重大罚款，应如何确定租赁期？

准则索引：IFRS 16 第18段  
正文索引：[15.37](33.md#s107-Para_15.37)  

**问题**

某主体（承租人）于20X1年1月1日与出租人签订了一份建筑物租赁合同。合同未规定具体合同期限，而是无限期持续，直至任意一方发出终止通知。承租人和出租人各自有权在不经另一方许可的情况下，自20X2年6月30日起于每个日历年的6月底终止合同，并需提前六个月发出终止通知（即最早可在20X2年6月30日行使终止权，六个月的通知期意味着终止将于20X2年12月31日生效）。

如果承租人在第10年结束前终止合同，须向出租人支付相当于两年租赁付款额的终止罚款，该罚款金额重大。如果承租人在该期间之后终止租赁，则不产生罚款。对出租人而言，无论何时终止合同均不产生终止罚款（关于“罚款”一词的解释，参见[FAQ 15.37.4](34.md#s113-FAQ_15.37.4)）。

该合同在租赁期开始日的租赁期是多少？

**解答**

下图说明了租赁期以及相关的不可撤销期间和可执行期间。

![](assets/74.png)

确定租赁期时需考虑以下因素：

- IFRS 16第B34段解释称，当承租人和出租人各自均有权在不经另一方许可的情况下终止租赁，且罚款金额不重大时，该租赁不再具有可执行性。在10年之前，承租人终止租赁将产生重大罚款。10年之后，双方均可终止租赁且罚款金额不重大。因此，可执行期间为10年。

- 不可撤销期间为24个月，因为承租人最早只能在20X2年12月31日使租赁终止生效（考虑通知期）。

- 应当应用关于承租人终止租赁选择权的指引，在最短不可撤销期间2年（18个月 + 6个月通知期）与最长可执行期间（10年）之间确定租赁期。

- 如果承租人并非合理确定在前10年内继续租赁该建筑物（即并非合理确定不行使终止租赁选择权），则承租人在合同前10年内的终止权会影响租赁期。[IFRS 16 附录B第B37段]。如果承租人合理确定在整个可执行期间内继续租赁（在考虑了产生不行使终止租赁选择权的经济激励的所有相关事实和情况后），则租赁期为10年。相反，如果承租人在某一时点并非合理确定继续租赁（尽管存在终止罚款），则租赁期在该时点结束（需考虑通知期）。

- 在评估承租人是否合理确定不终止租赁时，终止罚款是一项相关因素。[IFRS 16 附录B第B37(c)段]。另见[第15.39段](33.md#s107-Para_15.39)。在本例中，罚款的金额很可能使承租人合理确定在10年之前不终止租赁，但主体应当考虑所有相关事实和情况。

<a id="s113-chap_15_navPoint_idp1695082856"></a>
#### <a id="s113-FAQ_15.37.3"></a>FAQ 15.37.3 – 包含双边终止租赁选择权的永久租赁合同应如何进行会计处理？

准则索引：IFRS 16 附录B第B34段  
正文索引：[15.37](33.md#s107-Para_15.37)  

**问题1**  
主体A签订了一份零售空间租赁合同。该租赁永久存续，但出租人和承租人均拥有终止租赁选择权。该终止租赁选择权可随时行使；行使方承担的罚款金额不重大。两项选择权均设有通知期：

- 如果承租人行使其选择权，终止将在行权六个月后生效。

- 如果出租人行使其选择权，终止将在行权18个月后生效。

该合同在租赁期开始日的租赁期是多少？

**解答**  
根据IFRS 16第18段，主体应当将租赁期确定为租赁的不可撤销期间，加上续租选择权涵盖的期间（如果承租人合理确定将行使该选择权）以及终止租赁选择权涵盖的期间（如果承租人合理确定不会行使该选择权）。

首先，主体A应当确定不可撤销期间，本例中为六个月。其次，主体A应当确定可执行期间。当承租人和出租人各自均有权在不经另一方许可的情况下终止租赁，且罚款金额不重大时，该租赁不再具有可执行性。[IFRS 16 附录B第B34段]。

在本例中，租赁期开始日的可执行期间为18个月。这是从租赁期开始日至双方均可在罚款金额不重大的情况下终止合同的最早时点之间的期间。

应当应用关于承租人终止租赁选择权的指引，在最短不可撤销期间（六个月，即承租人的通知期）与最长可执行期间（18个月）之间确定租赁期。如果承租人合理确定继续（即不终止）租赁18个月，则租赁期为18个月。

**问题2**

何时重新评估租赁期？

**解答**

在租赁期开始日，合同的不可撤销期间为六个月（承租人的终止通知期），可执行期间为18个月。可执行期间实质上是从租赁期开始日至双方均可在不经另一方许可且罚款金额不重大的情况下退出合同及其合同义务的最早时点之间的期间。因此，租赁期将根据承租人特有的事实和情况，在六个月至18个月之间确定。

根据IFRS 16第21段，如果租赁的不可撤销期间发生变化，则应当修订租赁期。在本例中，只要任何一方未终止合同，租赁的不可撤销期间就始终维持在六个月（因此不可撤销期间的截止日每天顺延一天），可执行期间也始终维持在18个月（因此可执行期间的截止日也每天顺延一天）。租赁期可以修订，但根据承租人特有的事实和情况，其将始终至少为六个月。

**问题3**

事实模式与问题1类似，但承租人合理确定将继续租赁60个月（前提是出租人不行使其终止租赁选择权）。

**解答**

合理确定继续租赁60个月的承租人在该期间内具有留在租赁场地内的经济激励（IFRS 16第B37段）。因此，如果承租人在60个月期满前终止合同，将遭受重大罚款；根据IFRS 16第B34段，该合同的可执行期间为60个月。因此，租赁期为60个月（即承租人合理确定留在租赁场地内的期间）。

<a id="s113-chap_15_navPoint_idp1695121896"></a>
#### <a id="s113-FAQ_15.37.4"></a>FAQ 15.37.4 – 在IFRS 16第B34段的语境下如何解释“罚款”？

准则索引：IFRS 16 第B34段  
正文索引：[15.37](33.md#s107-Para_15.37)  

**问题**  
在IFRS 16第B34段的语境下如何解释“罚款”？

**解答**  
根据IFRS 16第B34段，当承租人和出租人各自均有权在不经另一方许可的情况下终止租赁，且罚款金额不重大时，该租赁不再具有可执行性。IFRS 16未对“罚款”一词作出专门定义。

国际财务报告准则解释委员会（“IC”）曾被问及如何确定可撤销或可续期租赁的租赁期，以及第B34段中的“罚款”是仅包括合同约定的终止罚款支付额，还是也应考虑合同更广泛的经济实质。[IFRIC 2019年11月会议纪要]。

解释委员会指出，应当考虑合同更广泛的经济实质，而不仅仅是合同约定的罚款支付额。此类考量包括，例如拆除或弃置租赁改良支出的成本、与终止合同相关的成本（例如寻找替代租赁、重新谈判或搬迁的成本）以及该资产对承租人经营的重要性。因此，如果任意一方在任何时点终止租赁所遭受的罚款金额超过不重大水平，则可执行期间应当包含这些期间。

与解释委员会的决定一致，在解释“罚款”一词时，主体也可以参考美国公认会计原则（US GAAP）中关于租赁的指引ASC 842，其中包含若干非合同经济罚款的示例，并对罚款作出如下定义：  
“租赁协议或租赁协议之外的因素对承租人施加或可能施加的要求承租人履行以下任何一项的义务：

- 支付现金

- 发生或承担负债

- 提供服务

- 放弃或转让资产或对资产的权利，或以其他方式放弃经济利益，或遭受经济损失。在确定是否可能遭受经济损失时需考虑的因素包括但不限于以下全部内容：

- 标的资产的用途或位置的独特性

- 可比替代资产的可获得性

- 标的资产对承租人业务线持续经营或向客户提供服务的相对重要性或重大性

- 存在因承租人搬离或停止使用标的资产而导致价值减损的租赁改良或其他资产

- 不利的税务后果

- 承租人承担按市场租金率搬迁或替换标的资产相关成本的能力或意愿，或容忍其他方使用标的资产的能力或意愿。”


<a id="s113-chap_15_navPoint_idp1695143016"></a>
#### <a id="s113-EX15.37.5"></a>EX 15.37.5 – 什么是可执行期间？

<table style="border-collapse:collapse"><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><span style="font-style:italic">准则索引：</span>IFRS 16 第B34段</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><span style="font-style:italic">正文索引：</span><a href="33.md#s107-Para_15.37">15.37</a></p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"></td></tr></table>

**示例1**

主体A与主体B签订了一份初始期限为五年的租赁合同。合同约定，初始期限届满后，租赁将无限期持续，直至任意一方发出终止通知。合同中没有约定终止付款。根据以往类似租赁的经验，主体A通常使用类似资产10年。主体A投资了经济寿命为10年的不可移除租赁改良，预期能够继续使用该租赁资产10年，尽管从法律上讲主体B可以选择在五年后终止租赁。

分析

考虑合同更广泛的经济实质，主体A在五年后具有不终止租赁的激励，因为终止租赁将导致其不得不放弃租赁改良。在应用IFRS 16第B34段时，该激励被视为一项罚款。

假设该罚款金额重大，则该租赁在五年之后仍具有可执行性。该租赁将持续具有可执行性，直至该罚款变得不重大；这将是基于具体事实和情况的判断，但在本例中，可执行期间可能为10年，因为这是主体A预期使用该租赁改良的期间。

**示例2**

主体B于20X0年1月1日签订了一份办公物业租赁合同。合同规定了两年初始期限，在此期间双方均不得退出合同。合同中没有续租选择权，且对两年期满后双方的权利和义务未作规定。

当地法律框架规定：“租赁期满后，承租人继续占用物业超过10天且出租人未提出异议的，该租赁自动续期。在此情况下，租赁续期一年，或若初始租赁期短于一年，则按初始租赁期续期。该续期后的租赁同样适用续期规定。”假设根据当地法律框架，该租赁可以无限期续期。

假设主体B建造了经济寿命为六年的租赁改良，如果在两年后终止租赁，则必须放弃这些租赁改良。假设如果主体B在两年后终止租赁，将遭受重大罚款。

分析

该租赁的不可撤销期间为两年。主体B需考虑两年不可撤销期间之后的期间，因为当地法律框架就该物业赋予了承租人和出租人额外的法定权利。尽管合同对两年期满后双方的权利和义务未作规定，但根据当地法律框架，如果主体B在合同期满后继续留在物业内达10天且出租人未提出异议，则合同仍然具有可执行性。在评估可执行期间时，主体B需要在租赁期开始日考虑，如果在不可撤销期间结束后终止租赁，是否会遭受重大罚款。在本例中，由于主体B将不得不放弃剩余经济寿命为四年的租赁改良，在两年不可撤销期间结束后终止租赁将会遭受重大罚款，因此该租赁在不可撤销期间之后仍具有可执行性。该租赁将持续具有可执行性，直至该罚款变得不重大；这将是基于具体事实和情况的判断，但在本例中，可能额外延续四年，因为这是主体B预期使用该租赁改良的期间。

如果不存在当地法律框架，则应当考虑具体事实和情况。如果确实不存在任何法律框架，可执行期间可能等于合同约定的期限，而不会超出该合同期限。然而，应当考虑事实和情况以及合同更广泛的经济实质，因为可能存在需要纳入考量的其他权利，例如非书面条款。关于书面合同之外的可执行性的详细讨论，参见[FAQ 15.39.5](34.md#s113-FAQ_15.39.5)。

<a id="s113-chap_15_navPoint_idp1695167720"></a>
#### <a id="s113-FAQ_15.39.1"></a>FAQ 15.39.1 – 提前终止条款如何影响租赁期？

准则索引：IFRS 16 附录B第B37段  
正文索引：[15.39](33.md#s107-Para_15.39)  

**问题**  
提前终止条款如何影响租赁期？

**解答**  
如果租赁包含提前终止条款（即承租人在某一时点之后终止租赁的权利），租赁期的长度取决于承租人是否合理确定不会行使该选择权。

如果承租人享有无需支付罚款或无其他经济激励的提前终止条款，承租人更有可能行使终止选择权。除非承租人合理确定不会行使终止租赁选择权，否则租赁期将为租赁期开始日至提前终止选择权最早生效日之间的期间。

如果承租人的提前终止条款要求承租人支付终止付款以补偿出租人（有时称为“约定损失价值”），从而确保出租人收回其在租赁中的剩余投资，则承租人不太可能行使该终止条款。如果承租人合理确定不会行使终止租赁选择权，则租赁期将包括终止租赁选择权所涵盖的期间。

<a id="s113-chap_15_navPoint_idp1695182696"></a>
#### <a id="s113-FAQ_15.39.2"></a>FAQ 15.39.2 – 续租选择权如何影响租赁期？

准则索引：IFRS 16 附录B第B37段  
正文索引：[15.39](33.md#s107-Para_15.39)  

**问题**  
续租选择权如何影响租赁期？

**解答**  
如果续租选择权的条款设定为预期显著低于公平市场租金的水平，则除非存在其他因素表明承租人并非合理确定将行使续租选择权，否则合理假设承租人将基于自身商业利益行使续租权。在此情形下，租赁期将同时包括不可撤销期间和续租期间。

如果续租选择权的条款基于公平市场租金，以致乍看之下承租人并无令人信服的商业理由续租，主体仍须分析可能影响承租人决策的其他因素。在确定续租期间是否应计入租赁期时，可能需要考虑的其他因素包括其他形式的商业强制力，例如罚款或业务中断，或其他形式的经济激励。如果承租人因未能续租或行使购买选择权而需支付罚款，或者租赁中规定的归还条件过于不利，继续租赁该资产可能符合承租人的利益。同样，如果承租人的业务依赖于该资产，以致移除该资产的成本及业务中断损失与继续租赁的成本不成比例，则续租期间更可能计入租赁期。

<a id="s113-chap_15_navPoint_idp1695190248"></a>
#### <a id="s113-FAQ_15.39.3"></a>FAQ 15.39.3 – 应如何权衡“合理确定”的各项指标？

准则索引：IFRS 16 附录B第B37段  
正文索引：[15.39](33.md#s107-Para_15.39)  

**问题**  
应如何权衡“合理确定”的各项指标？

**解答**  
准则中并未就确定承租人是否“合理确定”将行使某项选择权时如何权衡各个单项因素提供指引。例如，考虑一家位于黄金地段且备受追捧的旗舰店。在确定门店的优越地理位置或其他因素（例如终止罚款和租赁改良）是否表明承租人合理确定将续租该门店时，需要作出重大判断。

<a id="s113-chap_15_navPoint_idp1695488056"></a>
#### <a id="s113-FAQ_15.39.4"></a>FAQ 15.39.4 – 评估承租人是否“合理确定”行使选择权时，是否包括非货币性经济激励？

准则索引：IFRS 16 第B37段  
正文索引：[15.39](33.md#s107-Para_15.39)  

**问题**  
评估承租人是否“合理确定”行使选择权时，是否包括非货币性经济激励？

**解答**  
在确定租赁期时，主体需考虑为承租人行使或不行使续租或终止租赁选择权创造经济激励的所有相关事实和情况。经济激励是否必须是货币性的（可以是合同约定的或非合同的），还是也应将非货币性方面纳入考量？

只要非货币性方面反映的是经济激励而非非理性行为，即应纳入分析。非货币性方面的示例包括：

- 更换出租人并签订新合同所需的时间；以及

- 更换出租人并签订新合同所带来的不便。

承租人的过往惯例可能提供有助于评估承租人是否合理确定行使或不行使选择权的信息。然而，关键在于理解该过往惯例背后的经济原因。如果存在此类经济原因，则在评估租赁期时必须予以考虑。[IFRS 16 附录B第B40段]。

#### <a id="s113-FAQ_15.39.5"></a>FAQ 15.39.5 – 应如何考虑书面合同之外的可执行性？

准则索引：IFRS 16 第B34段  
正文索引：[15.39](33.md#s107-Para_15.39)  

**问题**  
承租人与关联方签订了一份总部办公楼租赁合同，期限为一年。书面合同期限为一年，合同中未赋予任何一方延长租赁期的选择权。租金按市场费率支付。

租赁期满时，双方均预期就下一年签署一份新的一年期租赁合同，并在可预见的未来持续如此操作。任何新租赁均仅在上一份租赁期满时签署（即无需提前通知）。承租人已投入重大的租赁改良，尽管未来可以使用其他物业作为总部，但搬迁总部在经济上存在不利激励。

在应用IFRS 16时，是否应当采用一年期的合同租赁期，还是需要考虑其他因素？

**解答**

IFRS 16未针对关联方租赁提供任何专门指引。关联方关系不会自动改变租赁期的评估，但在考虑可执行权利时应当将其纳入考量。

作为起点，双方首先应当关注书面协议，并根据书面协议确定具有法律可执行性的租赁期。如果书面协议的条款与交易的经济实质不一致，双方应当考虑承租人是否享有书面协议之外的可执行权利。

在本例中，承租人预期在可预见的未来将该物业用作总部，且已投入重大的租赁改良，这反映了其对能够继续使用该物业的预期。因此，一年期的书面合同租赁期与交易的经济实质不一致。

书面协议之外的可执行权利的潜在来源包括但不限于关联方之间的口头协议或谅解/陈述（例如双方之间提供了支持函），以及当地法律法规。

双方应当考虑咨询法律顾问的意见，以判断额外权利的任何潜在来源是否具有可执行性。例如，背景中提到安排下一年租赁无需提前通知；双方应当考虑在合同租赁期的最后一天，适用于具体事实和情况的当地法律是否确实允许出租人拒绝同意新租赁并在不提前通知的情况下驱逐承租人。

如果存在任何额外的可执行权利，双方应当根据这些权利的性质进行会计处理。例如，如果这些权利赋予承租人一项可执行的续租选择权，则应当应用关于续租选择权的指引。

主体需要遵守常规的IFRS 16披露要求，并且由于存在关联方关系，可能还需要根据IAS 24进行额外披露。

如果确定哪些权利具有可执行性涉及重大判断，主体应当考虑IAS 1的披露要求（详见[第4章第152段](10.md#s29-Para_4.152)）。

同样的原则也适用于非关联方之间的租赁——如果合同租赁期与交易的经济实质不一致，双方应当考虑是否存在任何非合同的可执行权利。

#### <a id="s113-EX15.43.1"></a>EX 15.43.1 – 哪些在承租人控制范围内的重大事件或情况变化可能导致重新评估租赁期？

准则索引：IFRS 16 附录B第B41(c)段  
正文索引：[15.43](33.md#s107-Para_15.43)  

某主体租赁一栋建筑物，期限为10年，并拥有5年续租选择权。在租赁期开始日，该主体得出结论认为并非合理确定将行使续租选择权，因此将租赁期确定为10年。

**示例1**

在使用该建筑物七年后，该主体决定将该建筑物转租给另一方，并签订了一份为期八年的转租赁合同。该主体是否需要重新评估租赁期？

签订转租赁合同是承租人控制范围内的重大事件，且影响主体关于其是否合理确定将行使续租选择权的评估。承租人须在该重大事件发生时重新评估主租赁的租赁期。

**示例2**

在使用该建筑物七年后，该主体编制了一份经董事会批准的五年商业计划。该五年商业计划假设承租人将在初始期限届满时行使续租选择权。该主体是否需要重新评估租赁期？

董事会批准商业计划在承租人的控制范围内。判断是否发生了重大事件或情况变化需要运用判断。例如，考虑以下情形：

**示例2a**

在租赁开始日，该建筑物是该主体为一个新的独立业务分部设立的唯一工厂。在租赁期开始日，续租期间未计入租赁期，因为该主体可能合理选择不续租、终止新分部的运营或搬迁至另一家工厂（例如更大的工厂或位于不同地理区域的工厂）。

在批准商业计划之前，该主体评估了其各项方案，并决定在初始期限届满时续租现有工厂。尽管该主体尚未实际续租，但其现在将基于继续使用该工厂作出商业安排（例如延长供应合同）。该项商业决策表明情况发生了重大变化，在此情况下，该主体应当重新评估租赁期。

**示例2b**

该建筑物为一般性办公总部。随着时间的推移，寻找新办公场所、谈判及搬迁的成本将提高该主体续租的可能性。临近初始租赁期结束时，这种可能性将持续增加，直至达到合理确定。该主体预期会续租，但该特定建筑物对商业计划并不重要，且在编制商业计划及随后由董事会批准的过程中，留在同一地点仅作为一项假设，并未进行专门讨论和披露。

上述事实表明并未发生重大事件或情况变化，在此情况下，该主体不重新评估租赁期。

但是，如果留在同一地点的决策经过了专门的详细讨论，并作为商业计划的关键假设向董事会披露，则表明发生了导致重新评估租赁期的重大事件。

#### <a id="s113-EX15.47.1"></a>EX 15.47.1 – 包含终止租赁选择权的永久租赁合同能否符合短期租赁的条件？

准则索引：IFRS 16 第5段、第7段  
正文索引：[15.47](33.md#s108-Para_15.47)  

**示例1**

主体A签订了一份小型办公空间租赁合同。该租赁永久存续，但出租人和承租人均拥有终止租赁选择权。该终止租赁选择权可随时行使，通知期为三个月。行使终止租赁选择权的一方承担的罚款金额不重大。

对承租人而言，该合同是否符合短期租赁的条件？

分析

短期租赁是指在租赁期开始日，租赁期不超过12个月的租赁。

租赁期是指租赁的不可撤销期间，加上续租选择权涵盖的期间（如果承租人合理确定将行使该选择权）以及终止租赁选择权涵盖的期间（如果承租人合理确定不会行使该选择权）。当承租人和出租人各自均有权在不经另一方许可的情况下终止租赁，且罚款金额不重大时，租赁的可执行期间在双方均可退出合同及其合同义务的最早时点结束。评估租赁合同的可执行性不需要评估何为“合理确定”。

在本例中，承租人和出租人均拥有通知期为三个月的终止权，且行使方承担的罚款金额不重大。因此，租赁期仅为三个月，故该租赁在租赁期开始日符合短期租赁的条件。

**示例2**

事实模式与示例1相同，但仅承租人拥有终止租赁选择权。

该合同是否符合短期租赁的条件？

分析

如果仅承租人拥有终止租赁选择权，则租赁期取决于承租人是否合理确定（以及在多长时间内合理确定）不会行使该终止租赁选择权。根据这一分析，如果租赁期为12个月或以下，该租赁可能符合短期租赁的条件。

因此，例如，如果承租人合理确定在第57个月末之前不会行使终止租赁选择权（于第60个月末生效），则租赁期为五年。如果承租人仅在前九个月内合理确定不会行使终止租赁选择权，则该合同符合短期租赁的条件。

**示例3**

事实模式与示例1相同，但仅出租人拥有终止权。此外，现假设该租赁的合同期限为10年。

该合同是否符合短期租赁的条件？

分析

如果仅出租人有权终止租赁，则租赁的不可撤销期间包括终止租赁选择权涵盖的期间（参见IFRS 16附录B第B35段）。因此，租赁期等于租赁的合同期限（即10年）。

该租赁合同不符合短期租赁的条件。

**示例4**

事实模式与示例1（原文为Example A）相同，但该租赁于20X8年1月1日签订，且仅能在每年12月31日终止生效。双方仍享有通知期为三个月的终止权（即如果双方均未在20X8年9月30日前发出终止租赁通知，则直至20X9年12月31日方可终止）。

在第一年，由于租赁期短于12个月，该租赁符合短期租赁的条件。双方均未在20X8年9月30日前发出终止租赁通知。在20X8年10月1日，该租赁是否继续符合短期租赁的条件？

分析

在20X8年10月1日，租赁期已发生变化，承租人须将其作为一项新租赁处理。此时租赁期为15个月，因此不再符合短期租赁的条件。


<a id="s113-chap_15_navPoint_idp1695563192"></a>
#### <a id="s113-FAQ_15.47.2"></a>FAQ 15.47.2 – 如果存在非连续使用期间，租赁期应如何确定？

准则索引：IFRS 16 附录A  
正文索引：[15.47](33.md#s108-Para_15.47)  

**问题**  
客户公司与供应商公司签订了一项合同，授予客户公司在五年期间内的每年9月和10月排他性使用某特定粮食仓储设施的权利。由于客户公司在使用期间内有权控制该已识别资产的使用，该合同根据IFRS 16作为租赁进行会计处理。

租赁期是多少？

**解答**  
IFRS 16附录A将“使用期间”定义为“用于履行与客户所签合同而使用资产的总期间（包括任何非连续期间的总和）”。

为履行合同而使用该仓库的总期间为10个月（五年期间内每年两个月）。租赁期为10个月，因此该租赁可以符合短期租赁的条件。

相反，如果该租赁为每年三个月，总计15个月，则由于租赁期超过12个月，其不符合短期租赁的条件。

[FAQ 15.81.1](35.md#s114-FAQ_15.81.1) 讨论了对于具有非连续使用期间的租赁，承租人应当在何时确认租赁费用。

#### <a id="s113-FAQ_15.50.1"></a>FAQ 15.50.1 – IFRS 16如何定义“低价值”一词？

准则索引：IFRS 16 附录B第B3段  
正文索引：[15.50](33.md#s108-Para_15.50)  

**问题**  
IFRS 16如何定义“低价值”一词？

**解答**  
准则未对“低价值”一词作出定义，但结论基础解释称，国际会计准则理事会（IASB）在制定准则时所设想的是全新状态价值不超过5,000美元的资产。然而，5,000美元的金额并非定量门槛，而是IASB用于说明一般原则的一个示例。

为评估租赁资产是否符合低价值资产豁免条件，主体应当关注资产的性质。低价值资产的示例可包括IT设备（平板电脑和个人电脑）、办公家具或电话。汽车不符合低价值资产的条件，因为一辆新车通常不属于低价值资产。如果由于技术或市场发展导致特定类型资产的价格发生变化，符合低价值资产豁免条件的资产类型可能会随时间推移而改变。美元外币汇率或通货膨胀率的变动本身并不影响某项资产是否属于该豁免的范围。

<a id="s113-chap_15_navPoint_idp1695585848"></a>
#### <a id="s113-EX15.53.1"></a>EX 15.53.1 – 承租人如何评估租赁资产是否满足低价值资产标准？

准则索引：IFRS 16 附录B第B5段  
正文索引：[15.53](33.md#s108-Para_15.53)  

只有当承租人能够从单独使用该资产或将其与其他易于获得的资源一起使用中获利，且该资产与其他资产不存在高度依赖或高度关联关系时，该租赁资产才能符合低价值资产的条件。以下示例说明了如何在实务中应用这些标准：

**示例1 – 酒店客房设备租赁**

某酒店签订了一份客房设备租赁合同，包括电视机、其他音视频设备以及小型物品（例如自动售货机、咖啡机、干手机和布草）。上述每项物品在全新状态下的价值均低于5,000美元。

承租人能否对这些租赁设备应用低价值资产豁免？

**分析**  
承租人可以对这些租赁的客房设备应用低价值资产豁免。客房设备的不同组成部分之间不存在高度依赖或高度关联关系。尽管在实务中其中部分设备在同一个酒店客房内共同使用，但承租人可以从酒店客房中移除部分设备，且仍然能够将该客房出租给客户。此外，承租人能够从单独使用每项租赁资产中获利。

**示例2 – 汽车租赁**

某主体签订了一份汽车租赁合同。

假设汽车的各个独立组成部分（例如发动机和轮胎）在全新状态下的价值均低于5,000美元，承租人能否对汽车的这些独立组成部分应用低价值资产豁免？

**分析**  
承租人不能对汽车的独立组成部分应用低价值资产豁免。汽车的不同组成部分之间高度依赖，因为从技术上讲，只有当汽车包含其全部组成部分时才能使用。例如，没有轮胎或发动机，承租人无法使用该汽车。

<a id="s113-chap_15_navPoint_idp1695606584"></a>
#### <a id="s113-FAQ_15.58.1"></a>FAQ 15.58.1 – 如果承租人采用IFRS 16第15段的实务权宜措施不单独核算非租赁组成部分，在计算租赁内含利率时应使用哪些租赁付款额？

准则索引：IFRS 16 第15段、第26段  
正文索引：[15.58](33.md#s109-Para_15.58)  

**问题**  
承租人签订了一份包含租赁组成部分和非租赁组成部分的租赁合同。承租人采用IFRS 16第15段的实务权宜措施，不将非租赁组成部分从租赁组成部分中分拆，并将支付给出租人的全部金额作为一项租赁进行会计处理。

假设承租人能够容易地确定租赁内含利率，如[第15.58段](33.md#s109-Para_15.58)所述。

用于计算租赁内含利率的租赁付款额是否应当包括针对非租赁组成部分的付款？

**解答**

IFRS 16未明确规定用于计算租赁内含利率的租赁付款额是否应包含非租赁组成部分，但我们认为应当剔除非租赁组成部分。

如果包含非租赁组成部分，租赁内含利率的计算将把标的资产的公允价值和余值与既包含标的资产使用又包含额外服务的租赁付款额进行比较。剔除非租赁组成部分能够反映出租人视角下合同的定价方式，而这正是IFRS 16的目标。

租赁内含利率特定于某项租赁。我们认为，选择不分拆非租赁组成部分的承租人应当采用与出租人相同的方法计算租赁内含利率，而IFRS 16要求出租人在计算租赁内含利率时将非租赁组成部分从租赁付款额中剔除。

##### <a id="s113-FAQ_15.59.1"></a>FAQ 15.59.1 – 如果租赁内含利率为负，承租人应使用哪项折现率？

准则索引：IFRS 16 第BC160段  
正文索引：[15.59](33.md#s109-Para_15.59)  

**问题**  
承租人租赁一台设备，租期为10年。年租金为固定金额每年C100,000，外加该设备所产生收入的2%作为可变金额。未担保余值为C1,000,000，设备的公允价值为C2,500,000。无初始直接费用。

由于取决于所产生收入的可变付款额不计入租赁付款额，计算得出的租赁内含利率为负值（–2.79%）。主体所处经济环境中的无风险利率为正值。

承租人是否应当使用租赁内含利率来计算其租赁负债？

**解答**  
根据IFRS 16第BC160段，IASB的目标是规定一个能够反映合同定价方式的折现率。如果按照IFRS 16的要求计算出的租赁内含利率为负值（例如，因为付款中有很大一部分为可变付款额，不符合租赁付款额的定义），则不应使用该利率。相反，承租人应当使用其增量借款利率（IBR）。

<a id="s113-chap_15_navPoint_idp1687110840"></a>
##### <a id="s113-FAQ_15.60.1"></a>FAQ 15.60.1 – 承租人在确定增量借款利率时应考虑哪些因素？

准则索引：IFRS 16 附录A  
正文索引：[15.60](33.md#s109-Para_15.60)  

**问题**  
承租人在确定增量借款利率时应考虑哪些因素？

**解答**  
增量借款利率（IBR）是指承租人在类似经济环境下为获得与使用权资产价值接近的资产，在类似期间以类似抵押条件借入资金须支付的利率。

鉴于IFRS 16附录A以及IFRS 16第BC160至BC162段中的定义，承租人在计算增量借款利率时，应当考虑以下因素：

- 所计算的利率应当是主体能够借入资金的利率。该利率不应反映权益融资成本，因此使用加权平均资本成本（WACC）（或除债务成本外还包含“资本成本”组成部分的任何其他利率）是不恰当的。使用物业收益率同样不可接受。但在某些情景下，只要作出适当调整，这些利率可以作为起点使用。

- 该利率应当反映主体在租赁期内能够借入的金额。它应当是主体为取得与使用权资产价值接近的资产而借款的利率，而非为取得整项标的资产而借款的利率。例外情况是租赁期占标的资产使用寿命的几乎全部。

- 该利率应当反映以类似资产（指使用权资产，而非标的资产）作为抵押的担保借款利率，而非无担保借款或一般授信额度的利率。

- 该利率应当反映主体的信用状况以及其在类似经济环境下借款的利率。例如，如果某公司的功能货币为英镑且通常以英镑借款，但签订了一项美元租赁合同，则增量借款利率将反映借入美元的成本。

<a id="s113-chap_15_navPoint_idp1687132216"></a>
##### <a id="s113-FAQ_15.60.2"></a>FAQ 15.60.2 - 承租人在确定增量借款利率时是否必须反映租赁付款分布特征？

准则索引：IFRS 16 附录A  
正文索引：[15.60](33.md#s109-Para_15.60)  

**问题**  
承租人在确定增量借款利率（IBR）时，是否必须反映租赁付款分布特征？

**解答**  
承租人签订了一项租赁合同，无法容易地确定租赁内含利率，因此采用其增量借款利率（IBR）作为折现率。

IFRS 16未规定估计IBR的具体方法。视事实和情况而定，承租人可考虑的一种方法是以一项易于观察的利率作为起点（然后再根据IBR定义中规定的因素对其进行调整）。

国际财务报告准则解释委员会（“IC”）曾被问及承租人的IBR是否应当反映与租赁具有类似到期日和付款分布特征的贷款利率。[IFRIC 2019年9月会议纪要]。

解释委员会指出，IFRS 16并未明确要求IBR反映与租赁付款额具有类似付款分布特征的贷款利率。尽管如此，在运用判断确定IBR时，如果与租赁具有类似付款分布特征的贷款利率易于观察，则以该利率作为起点符合理事会制定IBR定义时的目标。

确定IBR涉及考虑诸多因素的估计，并应当基于主体易于获得的信息，考虑与相关租赁有关的事实和情况。

解释委员会的议程决定提及具有与租赁“类似付款分布特征”的易于观察利率。如果承租人可以获得与租赁具有类似付款分布特征的易于观察的分期摊还贷款利率，我们通常预期承租人将以该利率作为确定IBR的起点。

但在实务中，具有类似付款分布特征的利率对主体而言可能并不易于获得，或者可能与租赁的付款分布特征不完全匹配。承租人需要运用判断，决定一个与租赁付款分布特征不完全匹配的可观察利率是否构成计算IBR的合理起点。在作出该判断时，承租人可以考虑例如：

- 付款时间：付款时间与租赁存在显著差异的利率不太可能提供合理的起点；

- 到期期限：到期期限存在显著差异的利率不太可能提供合理的起点；以及

- 收益率曲线的形状：如果收益率曲线相对平坦，不同的付款分布特征产生的影响较小，因此该利率更有可能成为合理的起点。

易于观察的利率需要进行调整以计算IBR（[参见第15.60段](33.md#s109-Para_15.60)）。调整幅度越大、涉及的判断越多，最终IBR中的估计不确定性就越大。

如果估计IBR构成关键会计估计，主体应当考虑IAS 1的披露要求。详见[第4章第152段](10.md#s29-Para_4.152)。

以下示例说明了在不同情景下可用于估计IBR的合理方法，但其他方法也可能被接受：

**示例1**

承租人签订了一份为期五年的租赁合同，按月等额支付租金。承租人可以容易地观察到一项按季等额还款的五年期分期摊还贷款的借款利率。

尽管付款时间不完全相同，但二者较为相似，因此该可观察利率可以作为估计IBR的合理起点。

**示例2**

承租人签订了一份为期13个月的租赁合同，按月等额支付租金。承租人可以容易地观察到一项按月等额还款的12个月期分期摊还贷款的借款利率。

尽管到期期限不完全相同，但二者较为相似，因此该可观察利率可以作为估计IBR的合理起点。

**示例3**

信用评级较差的承租人签订了一份为期五年的租赁合同，按月等额支付租金。承租人无法容易地观察到具有类似信用评级的实体所取得的相同付款分布特征的贷款利率。承租人可以容易地观察到信用评级显著更优的实体所取得的按月等额还款的五年期分期摊还贷款的借款利率。该承租人近期借入了一笔按月等额还款的四年期分期摊还贷款。

承租人所处经济环境的无风险利率相对较低且收益率曲线相对平坦，因此四年期与五年期利率之间的差异对IBR的影响，小于反映承租人信用评级所需的信用调整。

尽管可观察的五年期贷款完全匹配租赁的付款分布特征，但确定IBR可能需要对该可观察利率进行重大调整，从而导致最终IBR存在重大估计不确定性。主体近期借入的四年期贷款利率已经反映了主体的信用评级，因此对其进行调整以估计五年期利率，可能使最终IBR的估计不确定性更低。主体近期借入的四年期贷款可以作为计算IBR的合理起点。从该起点确定IBR时，需要进行调整以反映五年期租赁期与四年期贷款期限之间的差异。

**示例4**

承租人签订了一份为期九年的租赁合同，每年年末等额支付租金。

承租人无法容易地观察到与租赁到期期限类似的分期摊还贷款，但可以容易地观察到一系列不同到期期限的到期一次性还本贷款（到期一次性还本贷款定期支付利息，但本金仅在期末偿还，因此未反映本租赁的付款时间）。

正如国际财务报告准则解释委员会所指出的，IFRS 16并未明确要求增量借款利率反映与租赁付款额具有类似付款分布特征的贷款借款利率。尽管如此，解释委员会指出，在运用判断确定IFRS 16定义的增量借款利率时，承租人以一项易于观察的、与租赁具有类似付款分布特征的贷款利率作为起点，符合理事会制定增量借款利率定义时的目标。

一种选择可以是确定一个折现率，该折现率反映根据可观察的到期一次性还本贷款利率所构建的收益率曲线上各时点对应的特定久期利率。

另一种选择可以是采用与租赁付款额加权平均期限相对应的单一折现率。如果承租人经营所在环境的收益率曲线相对平坦，这可能是一个合理的近似值。在本例中，租赁付款额的加权平均期限为五年，因此对应于五年期到期一次性还本贷款的单一利率可以作为计算IBR的合理起点。

在所有情况下，如果确定IBR构成估计不确定性的主要来源，均应当根据IAS 1第125段进行披露。

##### <a id="s113-FAQ_15.61.1"></a>FAQ 15.61.1 – 承租人应如何对出租人就租赁改良支付的补偿进行会计处理？

准则索引：IFRS 16 第27段  
正文索引：[15.61](33.md#s109-Para_15.61)  

**问题**  
承租人应如何对出租人就租赁改良支付的补偿进行会计处理？

**解答**  
为确定出租人就租赁改良向承租人支付的款项是否构成租赁激励，主体应当评估该改良的性质并确定其代表承租人资产还是出租人资产。IFRS未就如何作出该判断提供精确指引。我们认为，以下方法紧密遵循了交易的经济实质。

一般而言，如果租赁并未明确要求承租人进行某项改良，则该改良不应被视为出租人的资产。如果租赁要求承租人进行某项改良，表明其属于出租人资产的因素可能包括：

- 应付金额基于承租人就特定改良实际发生的成本（相反，如果出租人同意在承租人提供支出凭证后向承租人支付固定金额或按公式计算的金额，而不论其性质如何，则合理得出结论认为该改良代表承租人资产）；

- 该改良并非专门针对承租人的预期用途，且很可能由后续承租人使用；

- 从出租人的角度来看，该改良增加了标的资产的公允价值；以及

- 改良的经济寿命相对于租赁期的长度。

如果某项改良代表承租人资产，则出租人的付款属于租赁激励，应当作为租赁付款额的扣减（针对应收租赁激励）或仅作为使用权资产的扣减（针对已收租赁激励）入账。另一方面，针对属于出租人资产的改良所支付的补偿不属于租赁激励，而应当作为对承租人代垫出租人资产成本的报销/补偿入账。

##### <a id="s113-FAQ_15.61.2"></a>FAQ 15.61.2 – 承租人应如何对保险费、房产税或维护费等成本进行会计处理？

准则索引：IFRS 16 第27段  
正文索引：[15.61](33.md#s109-Para_15.61)  

**问题**  
房地产安排通常要求承租人向出租人补偿与租赁资产相关的某些成本，例如保险费、房产税或由出租人提供的公共区域维护费。

这些付款应如何进行会计处理？

**解答**  
分为三个步骤。

首先，必须识别合同中的所有租赁组成部分和非租赁组成部分（参见[第15.28段](33.md#s107-Para_15.28)及以下段落）。在本例中，将存在（至少）一个租赁组成部分（房地产的使用权）和一个非租赁组成部分（公共区域维护）。然而，针对保险费和房产税的付款通常不涉及转让单独的服务，一般不构成单独的组成部分。

其次，需要确定合同中的总对价。这将包括针对租赁组成部分的付款，还可能包括针对非租赁组成部分的付款和/或不构成单独组成部分的付款。在某些房地产安排中，针对房产税和保险费的付款可能是可变付款额。[FAQ 15.66.3](34.md#s113-FAQ_15.66.3) 解释了在确定总对价时如何计量这些可变付款额。

最后，按照已识别组成部分的相对单独价格，将合同总对价分摊至已识别的租赁组成部分和非租赁组成部分。在本例中，由于保险费和房产税不构成单独的组成部分，因此不会向其分摊任何付款；付款仅分摊至已识别的租赁组成部分和非租赁组成部分。

##### <a id="s113-FAQ_15.61.3"></a>FAQ 15.61.3 - 承租人应如何对出租人卖出选择权进行会计处理？

准则索引：IFRS 16 第27段  
正文索引：[15.61](33.md#s109-Para_15.61)  

**问题**

承租人与出租人签订了一份租赁期为10年的租赁合同。该租赁合同包含一项卖出选择权，据此出租人可以要求承租人在租赁期满时以固定价格购买租赁资产。

承租人在租赁期开始日应如何对该出租人卖出选择权进行会计处理？

**解答**

无论是否预期该选择权将被行使，承租人均应当将出租人卖出选择权的行权价格计入租赁付款额。该卖出选择权对出租人而言构成一项余值担保，对承租人而言具有类似于按出租人意愿购买整项资产之义务的效果。它也可以被视为出租人将租赁延长至标的资产整个剩余使用寿命的权利。根据IFRS 16，如果仅出租人有权终止租赁，则租赁的不可撤销期间包括该选择权涵盖的期间[IFRS 16 附录B第B35段]，因为承租人承担了为使用该资产的权利付款的无条件义务。[IFRS 16 第BC128段]。因此，比照出租人终止租赁选择权的处理方式（承租人对此予以忽略），承租人将出租人卖出选择权的行权价格计入租赁付款额。

由于租赁负债和使用权资产的计量已考虑了出租人卖出选择权的行使，使用权资产应当在标的资产的使用寿命内计提折旧。[IFRS 16 第32段]。

##### <a id="s113-FAQ_15.63.1"></a>FAQ 15.63.1 – 如何解释“指数或比率”一词？

准则索引：IFRS 16 第27段  
正文索引：[15.63](33.md#s109-Para_15.63)  

**问题**

根据IFRS 16，如果可变租赁付款额取决于指数或比率，则计入租赁负债的计量。[IFRS 16 第27(c)段]。IFRS 16第28段列举了指数或比率的三个示例：消费者价格指数、基准利率（如LIBOR）以及市场租金率。这些均为基于市场的指数或比率的示例。

基于物业价值变动、税率变动或未来谈判的付款，是否应当被视为取决于“指数或比率”？

**示例1**

根据某项物业租赁合同的条款，租赁付款额按合同约定的（固定）百分比乘以物业价值计算。在租赁开始日，物业价值由评估专家确定。在后续期间，付款额根据调整后的物业价值进行调整。所有调整均自相关年度的4月1日起生效。调整基于以下方式之一：

- 政府机构发布的、反映相关地区截至12月31日平均物业价值年度变动的指数；

- 私营房地产公司发布的、反映全国截至3月31日物业市场价格年度变动的指数；或

- 评估专家定期（例如每五年）确定的单个物业市场价值的变动。

**解答**

所有三种情景均反映了一项指数或比率，因为变动主要与市场价格的变动相关。即使变动是由截至12月31日（而非3月31日）的市场价格变动驱动，或者是由单个物业的价值变动驱动，此类付款仍反映市场价格。以下事实进一步支持了这一结论：单个物业的标的价值与该物业的市场租金（或某地区的市场租金）通常高度相关，且“为反映市场租金率变化而变动的付款额”正是IFRS 16第28段中取决于指数或比率的可变付款额的示例之一。

**示例2**

租赁付款额包括固定付款额加上可变付款额，其中可变付款额基于市政府设定的税率乘以固定物业价值（在租赁期内不变）。该税率可能定期变动（例如，由市政府确定并受各种非市场因素（如相关市政府的资金需求）影响的房产税）。

**解答**

一种观点认为，上述税率并非“比率”，因为“比率”一词仅指基于市场的比率，例如CPI、利率等（参见IFRS 16第28段及第BC163(a)段）。这一观点与US GAAP一致，在ASC 842-10-55-142的示例12中，房产税不属于基于指数或比率的付款额。

另一种观点认为，仅随税率变动的付款符合负债的定义，因为它们是不可避免的，且不取决于承租人的任何未来活动；任何不确定性仅与负债的计量有关，而与其是否存在无关。[IFRS 16 第BC165段]。按照这一观点，本例中的房产税取决于指数或比率，因此应当计入租赁负债。

我们认为，IFRS 16未明确规定上述房产税是否应当被视为指数或比率，因此主体拥有会计政策选择权。所选择的会计政策应当一贯应用并予以披露。如果该项选择构成关键会计判断，主体应当考虑IAS 1的披露要求。详见[第4章第152段](10.md#s29-Para_4.152)。

**示例3**

部分房地产租赁（包括土地租赁）设有续租期间，且续租期间的租金金额将在未来日期确定。租赁协议规定，双方将在合理行事的前提下协商应付金额，在某些情况下还规定，如果双方无法就续租期间的金额达成一致，则可提交仲裁。租赁协议未说明该金额将基于市场租金或根据续租时租赁资产的市场价值进行调整。由于资产的性质，承租人存在重大的续租经济激励，因此合理确定承租人将行使其续租选择权。

在合同条款未明确要求租金按市场费率确定的情况下，这些合同条款是否被视为取决于指数或比率的可变租赁付款额？

**解答**

我们将此类付款视为与指数或比率挂钩的可变付款额。尽管合同未明确说明，但双方必须就续租期间的租金达成一致这一事实，将反映该物业市场租金率的变动（包括对物业的任何改良，例如投资性房地产建筑物的使用）。从实质上看，除协商反映（因而挂钩于）市场租金率变动的续租费率外，不存在现实的经济替代方案。因此，这些付款属于取决于指数或比率的可变租赁付款额。

##### <a id="s113-FAQ_15.63.2"></a>FAQ 15.63.2 – 承租人是否应将增值税计入租赁负债和使用权资产？

准则索引：IFRS 16 第68段；IAS 16 第16(a)段  
正文索引：[15.63](33.md#s109-Para_15.63)  

**问题**  
承租人是否应将增值税计入租赁负债和使用权资产？

**解答**  
主体通常向客户收取需上缴给第三方的款项（例如向政府机构代收代缴税款）。向客户收取的税款可能包括销售税、使用税、增值税（VAT）以及部分消费税。在许多法域，出租人向承租人开具租金发票时收取增值税即属此类情况。

IFRS 16未就增值税及类似税费的会计处理提供专门指引。管理层需要审视相关税种的实质特征以及相关法域的税法规定，以确定出租人是主要纳税义务人，还是该税款系向承租人征收。

例如，考虑这样一种法域：出租人在租赁付款额发票中包含增值税，且仅在承租人支付发票款项的范围内，出租人才须向税务机关缴纳增值税。在此情形下，出租人实质上是在增值税方面充当政府的代收代理人。此情形下的增值税并非与使用标的资产相关的付款，也不是对出租人拥有标的资产所产生成本的补偿。

在此情景下，由于增值税不属于租赁付款额，承租人不将其计入租赁负债。无论承租人是否预期能够抵扣或收回该增值税，均如此处理。

我们认为，如果承租人无法从税务机关抵扣或收回部分或全部增值税，则应当适用IFRIC 21（参见[第16章第77至83段](36.md#s120-Para_16.77)）。不可抵扣增值税代表承租人的资源流出，直接源于政府征收并由出租人代政府开票收取的税费。因此，承租人应当在义务事件发生时确认增值税负债，即在法律界定的触发承租人缴纳该税费的活动发生之日予以确认。

当增值税负债被触发时，IFRIC 21并未规定该负债是产生一项资产还是费用。承租人首先应当考虑该不可抵扣增值税是否属于初始直接费用，如果是，则应资本化计入使用权资产。否则，如果该资产是购入（而非租赁）的，IAS 16可能允许将其资本化计入资产成本。如[FAQ 15.74.2](34.md#s113-FAQ_15.74.2)所述，我们认为承租人拥有会计政策选择权，可以选择比照IAS 16将此类成本资本化，或将其确认为费用。

考虑以下示例：

**示例1**

承租人签订了一份为期5年的租赁合同，年租金为CU 100。该租赁适用20%的增值税税率，且全部增值税（即CU 100 × 5年 × 20%）均在租赁期开始日支付。应用IFRIC 21，在该法域内，任何不可抵扣增值税的负债均在租赁期开始日触发。

承租人必须决定在其具体情况下，该不可抵扣增值税是否符合初始直接费用的定义。该增值税是作为签订租赁的后果而在租赁期开始日支付的，因此在许多法域内符合初始直接费用的定义，并资本化计入使用权资产。

否则，承租人必须决定在其具体情况下，如果该资产是购入（而非租赁）的，IAS 16是否允许将任何不可抵扣增值税资本化，从而决定承租人能否选择比照IAS 16进行资本化。

**示例2**

与示例1类似，但在该法域内，增值税按20%的税率适用于每张月度发票。应用IFRIC 21，在该法域内，任何不可抵扣增值税的负债均由每张发票触发。

由于该增值税仅在开具每张发票时触发，因此不属于取得租赁的成本，从而不属于初始直接费用。如果该资产是购入（而非租赁）的，在资产达到预定可使用状态的地点和条件之后发生的成本不能资本化，因此，在资产达到预定可使用状态的地点和条件之后，任何不可抵扣增值税均不能比照IAS 16资本化。每个月，当根据IFRIC 21确认不可抵扣增值税负债时，均计入当期费用。

##### <a id="s113-EX15.65.1"></a>EX 15.65.1 – 取决于指数或比率的可变租赁付款额如何进行初始计量？

准则索引：IFRS 16 第27段  
正文索引：[15.65](33.md#s109-Para_15.65)  

**示例1**

某在通胀环境下经营的主体签订了一份为期10年的租赁合同，年租赁付款额为C50,000，于每年年初支付。每两年根据前24个月消费者价格指数（CPI）的变动对租赁付款额进行调整。在租赁期开始日，CPI为125。预计在第三年年初（首次调整日），CPI将为135。租赁负债应如何进行初始计量？

在初始确认时，租赁负债根据每年C50,000的合同租赁付款额进行计算。

**示例2**

事实模式与示例1相同，但租赁付款额并非根据CPI的变动进行调整，而是每年根据可观察利率LIBOR进行调整。在租赁期开始日，LIBOR利率为2.0%。

在初始确认时，租赁负债根据每年C50,000的合同租赁付款额进行计算。

关于后续计量，参见[FAQ 15.77.2](35.md#s114-FAQ_15.77.2)。

##### <a id="s113-FAQ_15.65.2"></a>FAQ 15.65.2 – 以外币计价的租赁付款额应如何进行会计处理？

准则索引：IFRS 16 第BC196段  
正文索引：[15.65](33.md#s109-Para_15.65)、[49.26](80.md#s321-Para_49.26)  

**问题**  
20X6年1月1日，主体A（功能货币为欧元）签订了一份为期10年的租赁合同，租赁付款额以美元计价。

以美元计价的租赁付款额应如何进行会计处理？

**解答**  
IFRS 16未就以外币计价的租赁付款额的会计处理提供专门指引。然而，结论基础解释称，承租人的租赁负债是一项货币性项目，与其他金融负债一致，要求在每个报告期末采用期末汇率重新计量。[IFRS 16 第BC196段]。由此产生的账面价值变动计入损益。[IFRS 16 第BC198段]。基于此，以外币计价的租赁付款额不被解释为取决于指数或比率的可变租赁付款额。

在初始确认日（20X6年1月1日），租赁负债采用租赁期开始日的即期汇率计量；在随后的每个报告日，剩余租赁负债采用报告日的美元/欧元即期汇率折算为欧元，并按照与任何其他货币性负债相同的方式应用IAS 21进行计量。

由于使用权资产属于非货币性项目，其后续不予重新折算。因此，外币汇率变动对使用权资产和租赁负债的影响是不对称的。

<a id="s113-chap_15_navPoint_idp1689069048"></a>
##### <a id="s113-FAQ_15.65.3"></a>FAQ 15.65.3 – 完全取决于指数或比率的租赁付款额应如何进行会计处理？

准则索引：IFRS 16 第27段  
正文索引：[15.65](33.md#s109-Para_15.65)  

**问题**  
某主体与一家管道运输公司签订了一份为期10年的合同，以获取原油运输服务。由于该主体是使用该管道的唯一客户，并在整个合同期内主导其使用方式和使用目的，该合同符合租赁的定义。

月度对价按当月运输原油量的1%乘以当月原油现行即期价格计算。合同约定每月最低输送量为100桶。与原油即期价格的挂钩符合嵌入衍生工具的定义；就本例而言，假设该嵌入衍生工具与主合同紧密相关。

计入租赁负债计量的租赁付款额是多少？

**解答**  
取决于指数或比率的可变租赁付款额构成租赁负债的一部分。即使付款额完全取决于指数或比率，情况也是如此。在上述示例中，存在每月100桶的最低输送量。为在租赁期开始日计量租赁负债，该最低输送量应采用租赁期开始日的原油即期价格进行计算。

因预期输送量超过每月100桶最低输送量而产生的任何对价，均不计入租赁负债的初始计量。原因在于这些额外付款取决于两个变量——即实际输送量和原油即期价格——二者相乘挂钩，而其中一个变量并非指数或比率（参见[FAQ 15.66.2](34.md#s113-FAQ_15.66.2)）。

在上述示例中，计入租赁负债的租赁付款额计算为：每月100桶 × 12个月 × 10年 × 租赁期开始日的原油即期价格。

未来原油即期价格的变动在导致现金流量发生变化（即对租赁付款额的调整生效）时，将引起租赁负债的重新计量（并对使用权资产作出相应调整）。

##### <a id="s113-EX15.65.4"></a>EX 15.65.4 – 如果存在按市场租金率定价的续租选择权，应如何确定租赁付款额？

准则索引：IFRS 16 第27段  
正文索引：[15.65](33.md#s109-Para_15.65)  

20X1年1月1日，主体A（承租人）签订了一份零售空间租赁合同。不可撤销租赁期为七年。第一年年租赁付款额为CU10,000，此后每年递增5%；且CU10,000反映了租赁期开始日的市场租金。主体A拥有将租赁期再延长五年的选择权。在租赁期开始日，主体A得出结论认为其合理确定将行使该续租选择权。

在以下情景中，主体A如何确定计入租赁负债的租赁付款额？

**示例A**

续租期间的修订后租金将由出租人和承租人在行使选择权之日根据届时的市场租金协商确定。但是，修订后租金不得超过前一期间末租金的105%。

由于主体A合理确定将行使续租选择权，租赁期为12年。该期间内的全部租赁付款额均计入租赁负债。

由于出租人和承租人双方须就续租期间的修订后租金达成一致，可以假定该租金为届时的市场租金。取决于指数或比率的可变租赁付款额（例如为反映市场租金率变化而变动的付款额），在初始计量时应当根据租赁期开始日的指数或比率确定。[IFRS 16 第27段]。因此，计入租赁负债初始计量的续租期间租赁付款额为续租期间每年CU10,000（租赁期开始日的市场租金）。

##### <a id="s113-EX15.66.1"></a>EX 15.66.1 – 不与指数或比率挂钩的可变付款额有哪些示例？

准则索引：IFRS 16 第27段  
正文索引：[15.66](33.md#s109-Para_15.66)  

不与指数或比率挂钩的可变付款额包括，例如与承租人源于标的资产的绩效挂钩的付款额（如按零售门店销售额的一定百分比支付的付款额，或基于太阳能发电场或风力发电场发电量支付的付款额）。另一个示例是与标的资产使用量挂钩的付款额，例如承租人驾驶租赁汽车超过规定里程时需支付的付款额。

**示例1**

某汽车按一份三年期合同租赁。只要在该期间内行驶里程不超过规定里程，租赁租金即为固定金额。超出规定里程的任何行驶里程须按每英里加收额外费用。初始计量时应如何计算计入租赁负债的租赁付款额？

租赁负债仅应包括固定租金。超里程费用属于不取决于指数或比率的可变租赁付款额，且不符合实质固定付款额的标准。

**示例2**

参见[FAQ 15.33.1](34.md#s113-FAQ_15.33.1)所述情景。

如[FAQ 15.33.1](34.md#s113-FAQ_15.33.1)所述，这些付款既可以被视为完全针对耗材的付款，也可以被视为包含租赁付款额成分。假设其中一部分付款被视为租赁付款额，则这些付款属于不与指数或比率挂钩且非实质固定的可变付款额，因此不计入租赁负债的初始计量。

##### <a id="s113-FAQ_15.66.2"></a>FAQ 15.66.2 – 取决于多个变量的可变租赁付款额应如何进行会计处理？

准则索引：IFRS 16 第27段  
正文索引：[15.66](33.md#s109-Para_15.66)  

**问题1**

承租人签订了一份为期10年的零售铺位租赁合同，其租赁付款额包含可变组成部分。该可变组成部分取决于该零售铺位的收入金额以及自租赁期开始日以来市场租金的变动。计算公式如下：

租赁付款额 = （过去12个月该零售铺位收入的2%）×（付款日市场租金 ÷ 租赁期开始日市场租金）

租赁付款额须于每年年末（12月31日）支付。

这些可变付款额是否构成租赁负债的一部分？

**解答**

取决于指数或比率（例如市场租金——参见IFRS 16第28段）的可变付款额计入租赁负债，而所有其他可变付款额均不计入（前提是其不符合实质固定付款额的定义）。如果某项付款取决于多个变量，且其中至少有一个变量并非指数或比率（并且该可变付款额不符合实质固定租赁付款额的定义），主体须分析不同变量之间是如何关联的：

- 如果取决于各个变量的付款相互独立，则分别计算。仅将取决于指数或比率（或符合实质固定付款额定义）的付款计入租赁负债。

- 如果取决于各个变量的付款并非相互独立，则整笔付款均不构成租赁负债的一部分（除非其符合实质固定租赁付款额的定义）。

在本例中，其中一个变量并非基于指数或比率（收入）。此外，由于两个变量相乘，二者并非相互独立。因此，全部可变付款额均不计入租赁负债，而是在实际发生或成为实质固定付款额时予以确认。

**问题2**

事实模式与问题1相同。但租赁付款额的计算方式变更为两个变量不再相乘：

租赁付款额 = （过去12个月该零售铺位收入的2%）+（付款日市场租金 – 租赁期开始日市场租金）

**解答**

由于两个变量不再相乘，取决于收入的可变付款额与取决于市场租金变动的可变付款额可以分别计算。

在租赁期开始日，取决于市场租金变动的可变付款额计入租赁负债。由于取决于指数或比率的可变租赁付款额基于租赁期开始日的指数或比率计量，因此计入初始租赁负债的可变租赁付款额金额为零。当因市场租金变动导致现金流量发生变化时，承租人应当根据届时的市场租金对剩余租赁期的租赁负债进行重新计量。

取决于收入的可变付款额并非基于指数或比率，因此不构成租赁负债的一部分，而是在实际发生或成为实质固定付款额时予以确认。

##### <a id="s113-FAQ_15.66.3"></a>FAQ 15.66.3 – 房产税和保险费的可变付款额应如何计量？

准则索引：IFRS 16 第27段  
正文索引：[15.66](33.md#s109-Para_15.66)  

**问题**  
房产税和保险费的可变付款额应如何计量？

**解答**  
承租人有义务向出租人补偿房产税和保险费。应用IFRS 16第B33段，承租人确定在其具体情况下，针对房产税和保险费的付款并未转让单独的商品或服务，因此不作为单独的非租赁组成部分进行会计处理。该租赁合同不包含服务或其他非租赁组成部分，因此这些税费和保险费付款被分摊作为租赁付款额。

通常，向出租人补偿房产税和保险费的付款是可变的。视每项租赁和每个法域的具体事实和情况而定，引起变动的原因可能有所不同。下文列示了可能的可变付款额类型及其计量方法，但其中涉及重大判断。

**房产税示例**

房产税按物业的计税价值乘以固定比例计算。物业的计税价值根据税法的具体规定确定，因此并非市场价值。计税价值会定期重新核定。

尽管物业估值可能考虑市场指数或比率，但其本身并非指数或比率。因此，这些付款应当作为不取决于指数或比率的可变租赁付款额进行会计处理。仅将已属于实质固定的付款计入租赁负债的初始计量。例如，如果第一年的房产税已知，而从第二年起将重新核定，则初始仅将第一年的房产税计入租赁负债，未来期间的付款在实际发生或成为实质固定付款额时予以确认。

**保险费示例**

保险费的初始金额为双方所知悉，但未在合同中明确列明。此外，该金额可能因市场价值以外的原因而随时间变动（例如，保险公司对风险的评估发生变化，或出租人更换至另一家保险公司）。

保险费金额在后续期间可能变动，因此承租人的付款符合可变租赁付款额的定义。然而，它们不被解释为取决于指数或比率。仅将已属于实质固定的付款计入租赁负债的初始计量。例如，如果第一年的保险费已知，而从第二年起将发生变动，则初始仅将第一年的保险费计入租赁负债，未来期间的付款在实际发生或成为实质固定付款额时予以确认。

对于初始未计入租赁负债的付款，如果其可变性在较后时点得以消除（例如，即将到来的年度的保险费变为已知且不可避免），则根据IFRS 16第B42段，这些付款在该时点成为实质固定付款额。

<a id="s113-chap_15_navPoint_idp1698060888"></a>
##### <a id="s113-FAQ_15.67.1"></a>FAQ 15.67.1 – 可变租赁付款额在何时符合实质固定付款额的定义？

准则索引：IFRS 16 附录B第B42段  
正文索引：[15.67](33.md#s109-Para_15.67)  

IFRS 16未包含解释可变付款额何时符合实质固定付款额定义的明确指引。必须结合所有相关事实对每份合同进行审慎评估。该分析具有高度判断性。以下示例说明了实质固定付款额的原则。

**问题1**

承租人签订了一份为期10年的零售空间租赁合同，约定每年租赁付款额为C1，但若该年度期间的销售额超过C1,000，则年租赁付款额为C1,000,000。承租人须在正常营业时间内营业，因此销售额低于C1,000不具有真实可能性。该C1,000,000的或有租赁付款额是否符合实质固定付款额的定义？

**解答**  
在本例中，C1,000,000的付款属于实质固定付款额。该租赁条款的起草方式使租赁付款额表面上看似基于绩效。但由于门槛极低，销售额低于C1,000显然不具有真实可能性，该租赁付款额在实质上是不可避免的。因此，该合同包含每年C1,000,000的实质固定付款额。

**问题2**

承租人签订了一份为期10年的物业租赁合同，约定租赁付款额为承租人利用该租赁物业所产生销售额的3%。承租人的年销售额一直保持稳定，在过往年度持续超过C1,000,000，且预计在可预见的未来将继续增长。承租人计入租赁负债的租赁付款额金额是多少？

**解答**  
尽管根据相关历史和经验，发生概率看似很高，但本例中的可变租赁付款额完全基于绩效并随绩效直接变动。这使得承租人应付和出租人应收的付款额存在真实可变性。因此，这些付款不属于实质固定的可变租赁付款额。

**问题3**

主体T是一家电信公司，与主体S签订了一份租赁合同，排他性使用一条用于海外通信的海底光缆。合同期限为10年，与该光缆的经济寿命一致。租赁付款额取决于光缆的使用率，100%使用率时上限为每年C1,000万，使用率在60%或以下时最低额（下限）为每年C600万。主体T的管理层估计，该光缆的平均使用率约为85%，预计年均租赁付款额为C850万。应如何计算租赁付款额？

**解答**  
计算租赁付款额时，应当计入每年C600万的年租赁付款额，这是主体T按合同必须支付的金额。主体T不应将可变租金的最佳估计数计入租赁付款额。主体T预计每年额外支付的C250万属于可变租金，因为其根据租赁资产的未来使用情况而变动。

**问题4**

某公用事业公司（客户）与一家电力公司（供应方）签订了一项合同，在20年期间内购买一座太阳能发电场生产的全部电力。合同无最低采购量要求。但是，如果该太阳能发电场发电，客户必须购买所生产的全部电力。该太阳能发电场是否发电及发多少电完全取决于日照时长和强度。作为电力供应的对价，双方约定租赁付款额随发电量直接变动（即每千瓦时C1），未约定固定付款额。客户评估了合同条款并得出结论认为，该合同包含租赁，且客户享有在20年内使用该太阳能发电场的权利。

客户是否必须确认租赁负债？

**解答**  
随太阳能发电场发电量（由日照水平驱动）变动而变动的租赁付款额，应当按照与问题2中基于承租人销售额的可变租赁付款额相同的方式处理。触发这些付款的条件超出客户的控制范围这一事实，并不影响上述结论。因此，这些付款不属于实质固定的可变租赁付款额。

**问题5**  
承租人签订了一份为期10年的租赁合同，使用某购物中心内的一间指定门店。年租赁付款额为固定金额。但是，如果某一主力租户搬离该购物中心，剩余租赁期的租赁付款额将修订为承租人年总销售额的5%（共同租户条款）。

承租人计入租赁负债的租赁付款额金额是多少？

**解答**  
承租人需要考虑合同中设置共同租户条款的经济合理性，因为单纯为实现特定会计结果而加入的条款，相比具有正当商业理由的条款，不太可能具有真实性。评估主力租户搬离可能性时需考虑的因素可能包括主力租户的剩余不可撤销租赁期（如已知）以及主力租户的财务状况（以评估潜在破产风险）。在许多情况下，在租赁期开始日，主力租户在承租人的租赁期内搬离购物中心可能并不现实。在这些情况下，共同租户条款纯粹是一项保护性权利，租赁付款额不存在真实可变性，因此承租人应当基于固定付款额对租赁负债进行初始计量。

在其他情况下，主力租户在承租人的租赁期内搬离该物业可能是现实的。在这些情况下，承租人应当考虑哪些情景是现实的。忽略任何不现实的情景，承租人应当基于（按现值计算）合计金额最低的现实情景对租赁负债进行初始计量。

**问题6**  
某电信运营商（承租人）签订了一份租赁合同，使用某座通信铁塔上的指定挂高位置。年租赁付款额为固定金额。但是，如果有一家或多家其他电信运营商在同一座铁塔上租赁挂高位置，则剩余租赁期将享受租金折扣。

承租人在计量租赁负债时应如何对该折扣进行会计处理？

**解答**  
承租人无法控制其他电信运营商是否会在同一座铁塔上租赁挂高位置。然而，在许多情况下，此类合同背后的经济逻辑是预期将有不止一家主体共址使用该铁塔。在这些情况下，很可能存在承租人在租赁期内获得折扣的现实情景。承租人应当考虑哪些情景是现实的。忽略任何不现实的情景，承租人应当基于（按现值计算）合计金额最低的现实情景对租赁负债进行初始计量。

##### <a id="s113-FAQ_15.69.1"></a>FAQ 15.69.1 – 余值担保下的应付金额应如何计量？

正文索引：[15.69](33.md#s109-Para_15.69)  

**问题**  
余值担保下的应付金额应如何计量？

**解答**  
结论基础指出，余值担保的计量应当反映主体对将支付金额的合理预期。计量余值担保属于一项估计，主体应当运用判断为其租赁确定恰当的估计值。

#### 初始计量 – 使用权资产

<a id="s113-chap_15_navPoint_idp1698107608"></a>
##### <a id="s113-EX15.71.1"></a>EX 15.71.1 – 与租赁资产相关的复原成本的会计处理

准则索引：IFRS 16 第24段、第25段、第BC148段；IAS 16 第16段  
正文索引：[15.71](33.md#s109-Para_15.71)  

**问题**  
某零售商租赁了一间零售门店，且作为租赁合同的一部分，其有义务在归还门店时使其恢复至接收时的相同状态。

当该零售商根据IAS 37确认一项预计负债时，对应的借方分录应当资本化还是确认为费用？

**解答**  
IFRS 16第24(d)段规定，使用权资产的初始计量包括拆卸和复原成本，这与IAS 16第16(c)段中的指引相类似。

**夹层楼板**

该零售商安装了一层夹层楼板，并根据IAS 37确认了一项预计负债，以便在租赁期满时将其拆除。应用IFRS 16第24(d)段，零售商将对应的分录作为使用权资产的一部分入账。

尽管第24(d)段的指引位于初始计量部分，但第25段规定，零售商应当在承担复原成本义务时将其确认为使用权资产成本的一部分。例如，如果该夹层楼板是在租赁期中途安装的，我们认为零售商仍然可以将其资本化计入使用权资产。

**磨损与损耗**

在租赁期内，该零售商产生了需在租赁期满时修复的磨损与损耗，并在整个租赁期内确认了一项预计负债（参见FAQ 16.85.5）。

我们认为，零售商应当将对应的分录确认为费用。针对磨损与损耗计提的预计负债并未创造一项资产。IFRS 16结论基础解释称，按成本计量使用权资产旨在与IAS 16保持一致，而IAS 16仅允许将与资产安装、建造或购置相关的复原和拆卸成本资本化（参见FAQ 22.28.2）。

<a id="s113-chap_15_navPoint_idp1698135640"></a>
##### <a id="s113-FAQ_15.74.1"></a>FAQ 15.74.1 – 哪些成本通常符合初始直接费用的条件？

准则索引：IFRS 16 附录A  
正文索引：[15.74](33.md#s109-Para_15.74)  

**问题**  
哪些成本通常符合初始直接费用的条件？

**解答**  
IFRS 16将初始直接费用定义为“为达成租赁所发生的增量成本，若未达成该租赁则不会发生”。这意味着无论最终是否达成租赁均须支付的成本，不能资本化为初始直接费用。

以下成本不符合IFRS 16中初始直接费用的定义：

- 不属于增量的内部行政管理费用和间接费用。

- 虽属增量但即使租赁未能最终达成也仍须支付的外部费用（例如法律费、安排费和经纪人佣金）。

符合IFRS 16中初始直接费用定义的成本示例包括：

- 在双方已承诺签订租赁之后（例如签署具有约束力的条款清单之后），为最终敲定租赁合同而发生的外部法律费用。

- 对承租人而言，仅在签署租赁合同时才须支付的安排费和经纪人佣金（即成功费）。

- 对出租人而言，仅在签署租赁合同时才须向员工支付的佣金。

新承租人向原承租人支付的款项也可能符合初始直接费用的条件。

<a id="s113-chap_15_navPoint_idp1698151768"></a>
##### <a id="s113-FAQ_15.74.2"></a>FAQ 15.74.2 – 承租人能否将不符合初始直接费用条件的成本资本化？

准则索引：IFRS 16 第24段、第BC149段  
正文索引：[15.74](33.md#s109-Para_15.74)  

**问题**  
承租人签订了一项租赁合同，并向第三方发生了与租赁有形资产相关的成本，例如将该资产运输至初始预期地点以使承租人能够按预期方式使用该资产，或对其进行安装。

承租人应如何对这些成本进行会计处理？

**解答**  
由于这些成本并非为达成租赁而发生的成本，因此不符合IFRS 16中的初始直接费用条件。

承租人首先应当考虑是否有任何其他会计准则适用于这些成本，例如IAS 16（参见[第22章第19段及以下](39.md#s142-Para_22.19)）。

如果这些成本不属于任何其他会计准则的范围，IFRS 16未就如何核算这些成本提供指引。我们认为，承租人可在以下两种会计政策之间作出选择：

a) 类比适用IAS 16

应用IAS 8第11段，IAS 16中存在类似且相关的问题。如果这些成本在IAS 16下可以资本化，则承租人可以将与租赁资产相关的同等成本资本化。关于IAS 16及可能符合资本化条件的成本性质的指引，参见[第22章第19段及以下](39.md#s142-Para_22.19)。

方案A得到了IFRS 16第BC149段的支持，该段表明为租赁资产资本化的成本应当与购置资产具有可比性。

b) 在发生时费用化

IFRS 16未提供允许将这些成本资本化的指引。考虑到概念框架中费用的定义，这些成本可被视为导致权益减少的负债（应付账款）增加，因此在发生时计入费用。

所选择的会计政策应当一贯应用并予以披露。如果该项选择构成关键会计判断，主体应当考虑IAS 1的披露要求。详见[第4章第152段](10.md#s29-Para_4.152)。
