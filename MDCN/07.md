## 引言——当前财务报告环境（第1.1-1.13段）

<a id="s7-chap_01_navPoint_2"></a>
### 当今财务报告

<a id="s7-Para_1.1"></a>**1.1** 近年来，全球财务报告领域发生了重大变化。国际财务报告准则（IFRS®准则）或其本地衍生版本正在全球范围内日益成为强制性要求。国际会计准则理事会（理事会）一直致力于加强与全球证券监管机构、准则制定机构及其他相关方的合作关系，以促进现有国际财务报告准则的一致应用，并深化在国际财务报告准则未来制定工作中的合作。

[FAQ 1.1.1 – 有多少个国家使用国际财务报告准则或《中小主体国际财务报告准则》？](07.md#s10-FAQ_1.1.1)

<a id="s7-chap_01_navPoint_3"></a>
### 全球趋同——国际财务报告准则与美国公认会计原则

<a id="s7-Para_1.2"></a>**1.2** 理事会积极推动全球会计准则的协调趋同。在经历了一个趋同时代（包括就收入准则和租赁准则开展联合制定工作）之后，尽管美国支持以其他方式吸纳国际财务报告准则，但在可预见的未来，预计美国不会强制改用国际财务报告准则。

<a id="s7-Para_1.3"></a>**1.3** 美国财务会计准则委员会（FASB）与理事会均已将工作重心转向各自的准则制定议程。理事会正转向更加多边化的合作方式，借助会计准则咨询论坛（ASAF）与全球各地的准则制定机构（包括 FASB）开展合作。

<a id="s7-Para_1.4"></a>**1.4** 理事会制定的《中小主体国际财务报告准则》（IFRS for SMEs®准则）继续在全球范围内得到广泛采用。本手册面向完整版国际财务报告准则的使用者，不详细涵盖《中小主体国际财务报告准则》。

<a id="s7-chap_01_navPoint_4"></a>
### 国际财务报告架构

<a id="s7-Para_1.5"></a>**1.5** 理事会网站列明了当前用于制定国际财务报告准则的组织架构，并说明了参与国际准则制定、治理与监督以及公众问责的各机构的职责。这些机构包括国际财务报告准则基金会（IFRS®基金会，含理事会及国际财务报告准则解释委员会）、国际财务报告准则基金会受托人、国际财务报告准则咨询委员会、会计准则咨询论坛（ASAF）以及国际财务报告准则基金会监督委员会。

[www.ifrs.org]。

<a id="s7-chap_01_navPoint_5"></a>
### 国际会计准则理事会（IASB）

<a id="s7-Para_1.6"></a>**1.6** 理事会确立的目标是“出于公众利益，制定一套高质量、可理解、可执行且基于清晰阐述的原则并获全球公认的财务报告准则”。关于理事会的组成及其职能的更多信息（包括国际会计准则的制定程序及其未来工作计划），可访问理事会网站查阅。

[www.ifrs.org]

<a id="s7-Para_1.7"></a>**1.7** 理事会同时发布完整版国际财务报告准则和《中小主体国际财务报告准则》。

<a id="s7-Para_1.8"></a>**1.8** 国际财务报告准则旨在规范所有营利性主体的通用目的财务报表及其他财务报告，同时也可能对非营利性主体具有参考价值。通用目的财务报表提供有关财务业绩、财务状况和现金流量的信息，这些信息对包括股东、债权人、员工和社会公众在内的广泛使用者作出经济决策具有有用性。

<a id="s7-Para_1.9"></a>**1.9** 国际财务报告准则自准则规定的日期起生效，并在适用时遵循过渡性规定。理事会的一般政策是对所有相关交易追溯适用新准则，无论该等交易发生在准则发布之前还是之后。这可能会对先前已协商订立的合同或协议产生影响；负责协商订立该等合同或协议的各方应自行就未来准则变化作出适当约定。在若干特定情形下，理事会可能规定对新准则采用未来适用法，具体情况按个案逐项考量。

<a id="s7-Para_1.10"></a>**1.10** 《中小主体国际财务报告准则》是一项独立准则，可适用于中小主体的通用目的财务报表及其他财务报告。中小主体是指：（1）不负有公众受托责任，且（2）向外部使用者发布通用目的财务报表的主体。

<a id="s7-Para_1.11"></a>**1.11** 完整版国际财务报告准则与《中小主体国际财务报告准则》之间的主要差异包括：

- 省略了若干与中小主体不相关的准则（如每股收益、分部报告和中期财务报告）。

- 简化了部分领域的计量要求。

- 减少了披露要求。

- 简化了准则表述语言。

[www.ifrs.org：关于《中小主体国际财务报告准则》]。

<a id="s7-chap_01_navPoint_6"></a>
### 国际财务报告准则解释委员会

<a id="s7-Para_1.12"></a>**1.12** 国际财务报告准则解释委员会（IFRS IC，前身为国际财务报告解释委员会或“IFRIC”）负责处理在国际准则得以修订或发布之前需要及时关注的新兴实务问题。作为国际会计准则理事会下属的委员会，其职责包括：在出现相互冲突或不够恰当的准则理解时，对国际财务报告准则作出解释，并就国际财务报告准则尚未涵盖的问题提供及时指引。该委员会不发布独立准则；但根据《国际会计准则第1号》，其发布的解释公告具有权威性。

[www.ifrs.org]。

<a id="s7-chap_01_navPoint_7"></a>
### 国际财务报告准则的本地采用

<a id="s7-Para_1.13"></a>**1.13** 理事会发布的准则在部分司法管辖区自动生效适用；但在许多司法管辖区，准则须先经过本地认可程序方可正式生效。

## 国际财务报告准则会计框架——概念与原则（第1.14-1.63段）

<a id="s8-Para_1.14"></a>**1.14** 构成国际财务报告准则基础的核心概念载于理事会于2018年3月发布的《财务报告概念框架》（以下简称“概念框架”）。2018年3月版概念框架所反映的修订内容，旨在解决实务中引发问题的领域，或根据理事会在其他项目中发展形成的概念作出更新。这些修订包括：

- 更新资产、负债、收益和费用的定义，包括取消可能性门槛；

- 新增资产和负债的终止确认标准；

- 更新有关计量基础的计量讨论；

- 提供有关管理层受托责任的信息；

- 重新引入谨慎性概念；

- 新增“财务报表与报告主体”以及“列报与披露”两章内容；以及

- 更新基础性概念（包括计量单元（会计单元）、持续经营和资本保全）。

<a id="s8-chap_01_navPoint_11"></a>
### 概念框架的地位与目的

<a id="s8-Para_1.16"></a>**1.16** 概念框架体现了为外部使用者编制和列报财务报表所依据的基本概念。其目的在于：

- 协助理事会基于一致的原则制定未来的国际会计准则。

- 在没有准则适用于某项特定交易或事项，或当准则允许选择会计政策时，协助财务报表编制者应用国际会计准则。

- 协助各方理解和解释各项准则。

[概念框架 SP 1.1]。

<a id="s8-Para_1.17"></a>**1.17** 概念框架本身并非一项准则，也不凌驾于任何具体准则之上。

[概念框架 SP 1.2]。

<a id="s8-Para_1.18"></a>**1.18** 概念框架规范对广泛使用者有用的通用目的财务报告。概念框架将主要使用者界定为必须依赖通用目的财务报告获取信息的现有及潜在投资者、贷款人和其他债权人。其他各方（如员工、供应商、客户、政府及其机构、监管机构和公众）也可能发现通用目的财务报告有用，但通用目的财务报告并非主要面向这些各方。

[概念框架 SP 1.5]。[概念框架 SP 1.10]。

<a id="s8-chap_01_navPoint_13"></a>
### 通用目的财务报告的目标、有用性与局限性

<a id="s8-Para_1.19"></a>**1.19** 理事会将通用目的财务报告的目标界定为：“提供有关报告主体的财务信息，该信息对于现有和潜在的投资者、贷款人及其他债权人就向该主体提供资源作出决策具有有用性。这些决策涉及：（a）购买、出售或持有权益工具和债务工具；（b）提供或清偿贷款及其他形式的信贷；或（c）行使投票权或以其他方式影响管理层涉及主体经济资源使用的行为。”

[概念框架 SP 1.2]。

<a id="s8-Para_1.20"></a>**1.20** 现有及潜在投资者关于购买、出售或持有权益工具和债务工具、提供或清偿贷款及其他形式信贷以及行使投票权或以其他方式影响管理层行为的决策，取决于其对该等金融工具预期产生的回报（即股利、本金和利息偿付以及市场价格上涨）。对回报的预期则取决于对主体未来现金净流入的金额、时间分布和不确定性的评估，以及对管理层受托责任履行情况的评估。

[概念框架 第1.3段]。

<a id="s8-Para_1.21"></a>**1.21** 为作出上述决策，使用者需要了解主体的经济资源、针对主体的要求权、经济资源和要求权的变动情况，以及管理层和治理层使用主体资源的效率和效果。

[概念框架 第1.4段]。

[FAQ 1.21.1 – 评估未来现金净流入前景需要哪些信息，原因是什么？](07.md#s10-FAQ_1.21.1)

<a id="s8-Para_1.22"></a>**1.22** 概念框架将通用目的财务报告的主要使用者（即通用目的财务报告的指向对象）界定为无法要求主体直接向其提供信息、因而必须依赖通用目的财务报告来满足其信息需求的现有及潜在投资者、贷款人和其他债权人。

[概念框架 第1.5段]。

<a id="s8-Para_1.23"></a>**1.23** 通用目的财务报告的目的并非反映报告主体的价值，而是提供信息以协助现有及潜在投资者、贷款人和其他债权人估计报告主体的价值。

[概念框架 第1.7段]。

<a id="s8-Para_1.24"></a>**1.24** 概念框架确立了财务报告所依赖的估计、判断和模型所依据的基本概念。

[概念框架 第1.11段]。

<a id="s8-chap_01_navPoint_14"></a>
### 权责发生制会计

<a id="s8-Para_1.25"></a>**1.25** 权责发生制会计在交易、事项和情况对经济资源和要求权产生影响的当期反映这些影响，无论由此产生的现金收付发生在何时。

[概念框架 第1.17段]。

<a id="s8-Para_1.26"></a>**1.26** 如果收益和费用的确认源于资产和负债的变动，则收益和费用可能会同时确认，例如以现金销售商品时，同时确认收益（源于确认一项资产——现金）和费用（源于终止确认另一项资产——所售商品）。然而，这种成本与收益的“配比”并非概念框架的目标。概念框架不允许在资产负债表中确认不符合资产、负债或权益定义的项目。

[概念框架 第5.5段]。

<a id="s8-chap_01_navPoint_15"></a>
### 受托责任

<a id="s8-Para_1.27"></a>**1.27** 关于主体经济资源及针对该等资源的要求权的信息，对于投资者、债权人和其他使用者评估管理层对主体经济资源的受托责任具有有用性。

[概念框架 第1.13段]。

<a id="s8-Para_1.28"></a>**1.28** 为评估受托责任，有用的信息有助于财务报表使用者区分主体经济资源和要求权的变动是源于财务业绩，还是源于发行债务工具或权益工具等其他事项。关于过往财务业绩和受托责任的信息有助于预测未来回报。

[概念框架 第1.15段]。[概念框架 第1.16段]。

<a id="s8-Para_1.29"></a>**1.29** 在评判受托责任时，财务报表使用者还会考量管理层履行其对主体资源管理职责的效率和效果。评估受托责任同样需要有用信息，以便结合管理层预期为实现相关结果所作出的贡献，来预测未来现金流量和经济资源的使用情况。

[概念框架 第1.22段]。[概念框架 第3.2段]。

<a id="s8-chap_01_navPoint_16"></a>
### 有用财务信息的质量特征

<a id="s8-Para_1.30"></a>**1.30** 财务信息要具备有用性，就必须具有相关性，并且必须如实反映其所拟反映的内容。如果财务信息还具备可比性、可验证性、及时性和可理解性，则其有用性将得到增强。相关性和如实反映被视为财务信息的基本质量特征。对不相关现象的如实反映，或对相关现象的不如实反映，都无法帮助使用者作出良好的决策。

[概念框架 第2.4段]。[概念框架 第2.5段]。[概念框架 第2.21段]。

<a id="s8-Para_1.31"></a>**1.31** 相关性意味着财务信息能够通过帮助使用者评价过去、现在或未来的事项，或者证实先前的评价，从而影响使用者的经济决策。如果财务信息具有预测价值、证实价值或兼而有之，则被认为能够对使用者的决策产生影响。

[概念框架 第2.6段]。[概念框架 第2.7段]。

<a id="s8-Para_1.32"></a>**1.32** 重要性是相关性的从属概念。参见[第1.33段](07.md#s8-Para_1.33)。

[概念框架 第2.11段]。

<a id="s8-Para_1.33"></a>**1.33** 实质重于形式的概念内嵌于如实反映的概念之中。概念框架认识到，尽管经济现象的实质与其法律形式可能一致，但在许多情况下，实质与法律形式并不一致。在这些情形下，“仅提供有关法律形式的信息将无法如实反映该经济现象”。

[概念框架 第2.12段]。

<a id="s8-Para_1.34"></a>**1.34** 信息要具备有用性，不仅必须列报交易及其他事项和情况的相关影响，还必须如实反映其所拟反映的交易及其他事项和情况的影响。要做到完美的如实反映，需要具备以下三项特征：（1）完整性，（2）中立性，以及（3）无差错。理事会的目标是在可能的范围内最大限度地实现这些质量特征。

[概念框架 第2.12段]。[概念框架 第2.13段]。

<a id="s8-Para_1.35"></a>**1.35** 完整性是指包含使用者理解所描述的交易及其他事项和情况所需的全部信息，包括所有必要的说明和解释。在某些情况下，完整性“还可能需要解释有关项目质量和性质的重大事实、可能影响其质量和性质的因素和情况，以及用于确定数值表述的过程”。

[概念框架 第2.14段]。

<a id="s8-Para_1.36"></a>**1.36** 中立性是指在选择或列报财务信息时不存在偏见。财务信息“不偏斜、不加权、不刻意强调或淡化，也不以其他方式加以操纵，以提高财务信息被使用者正面或负面接受的概率”。中立性并不意味着信息没有目的或对行为没有影响。

[概念框架 第2.15段]。

<a id="s8-Para_1.37"></a>**1.37** 谨慎性是中立性的从属概念，是指在不确定条件下作出判断时保持审慎。审慎地运用谨慎性意味着资产和负债既不被高估，也不被低估。对于资产和收益的确认与负债和费用的确认，并不存在系统性地要求资产和收益具备更具说服力证据的需要。然而，特定准则可能会包含不对称的要求，以支持提供具有相关性和如实反映的信息。

[概念框架 第2.16段]。[概念框架 第2.17段]。

<a id="s8-Para_1.38"></a>**1.38** 如实反映并不意味着信息在所有方面都完全精确。无差错是指在对交易及其他事项和情况的影响进行描述时不存在差错或遗漏，并且用于生成报告信息的程序在选择和应用过程中没有差错。

[概念框架 第2.18段]。

<a id="s8-Para_1.39"></a>**1.39** 当货币金额无法直接观察时，主体需要作出合理估计。如果对这些估计作出清晰准确的说明，它们便可以是有用的。高度不确定性并不排除使用估计，但重要的是需要考量其他信息是否会更有用。

[概念框架 第2.19段]。[概念框架 第2.20段]。

<a id="s8-Para_1.40"></a>**1.40** 概念框架指出，应用基本质量特征（相关性和如实反映）最有效且最具效率的方式是遵循以下三步流程：

- 识别能够为财务信息使用者提供有用信息的经济现象。

- 识别关于该现象的最具相关性的财务信息类型。

- 确定该信息是否可获取，以及该信息是否能够如实反映该经济现象。

[概念框架 第2.21段]。

<a id="s8-Para_1.41"></a>**1.41** 在应用相关性和如实反映这两项基本质量特征时，可能需要作出权衡（例如，当被认为高度相关的信息包含具有高度计量不确定性的估计时）。在某些情况下，确认估计金额并在附注中提供适当的补充信息可能是有用的；而在另一些情况下，采用高度不确定的估计进行确认可能并不恰当，此时更适宜采用另一种估计方法，和/或在附注中提供适当信息。

[概念框架 第2.22段]。

<a id="s8-chap_01_navPoint_17"></a>
### 增强性质量特征

<a id="s8-Para_1.42"></a>**1.42** 概念框架认为，可比性、可验证性、及时性和可理解性这四项质量特征能够增强具备相关性且如实反映的信息的有用性。当两种方式均能产生同等相关且如实反映的信息时，这些特征也有助于确定应采用哪种方式来描述某项交易、其他事项或情况。

[概念框架 第2.23段]。

<a id="s8-Para_1.43"></a>**1.43** 第一项增强性质量特征是可比性，包括跨期可比性以及不同主体之间的可比性。

[概念框架 第2.24段]。

<a id="s8-Para_1.44"></a>**1.44** 概念框架并未赋予主体内部可比性或主体间可比性何者优先。但《国际财务报告准则第1号》（IFRS® 1）在首次采用国际财务报告准则的语境下作出了此类区分：主体首份国际财务报告准则财务报表内部的可比性，比与已采用国际财务报告准则的其他主体之间的可比性更为重要。

<a id="s8-Para_1.45"></a>**1.45** 一致性不得与可比性相混淆。“一致性是指对相同项目采用相同的方法，无论是在同一报告主体内跨期应用，还是在单一期间内跨主体应用。可比性是目标；一致性有助于实现这一目标。”

[概念框架 第2.26段]。

<a id="s8-Para_1.46"></a>**1.46** 可验证性这一增强性质量特征有助于向使用者保证，信息如实反映了其所拟反映的经济交易及其他事项和情况。它意味着“不同具备专业知识且独立的观察者能够达成共识（尽管不一定完全一致），认为某项特定描述构成了如实反映”。

[概念框架 第2.30段]。

<a id="s8-Para_1.47"></a>**1.47** 及时性是指决策者能够在信息尚具决策影响力之前及时获取信息。未能及时提供的信息对使用者作出决策的有用性较低。

[概念框架 第2.33段]。

<a id="s8-Para_1.48"></a>**1.48** 清晰简明地对信息进行分类、界定特征和列报，能够使信息具备可理解性。某些现象本身具有内在复杂性，无法使其变得浅显易懂。剔除这类信息的报告可能更易于理解，但会因此变得不完整，从而可能产生误导。

[概念框架 第2.34段]。[概念框架 第2.35段]。

<a id="s8-Para_1.49"></a>**1.49** 应用增强性质量特征是一个反复权衡的过程，并无既定顺序。在实务中可能需要作出取舍，例如当未来适用一项能够提升相关性和如实反映的新准则时，可能会导致可比性暂时降低。充分披露可在一定程度上弥补可比性的暂时损失。

[概念框架 第2.38段]。

<a id="s8-chap_01_navPoint_18"></a>
### 成本约束

<a id="s8-Para_1.50"></a>**1.50** 提供既具相关性又能如实反映其所拟反映内容的财务信息所发生的成本，是提供有用财务信息的一项普遍约束。由于成本效益评估具有内在主观性，不同人士对报告财务信息的成本与效益的评价各不相同，因此理事会力求从财务报告的整体层面（而非仅针对单个报告主体）来考量成本与效益。

[概念框架 第2.39段]。[概念框架 第2.43段]。

<a id="s8-chap_01_navPoint_19"></a>
### 重要性

<a id="s8-Para_1.51"></a>**1.51** 如[第1.29段](07.md#s8-Para_1.29)所述，重要性是相关性的从属概念。重要性设定了判断某项目是否相关的门槛，其定义如下：“如果省略或错报某项信息可能影响通用目的财务报告的主要使用者基于该报告（该报告提供关于特定报告主体的财务信息）作出的决策，则该信息具有重要性。”2018年10月31日，国际会计准则理事会发布了对《国际会计准则第1号》和《国际会计准则第8号》中“重要性”定义的修订。[参见第4章第37段](10.md#s28-Para_4.37)。“换言之，重要性是相关性在特定主体层面的体现，它基于单个主体财务报告语境下信息所涉及项目的性质、金额大小或两者兼而有之。”

[概念框架 第2.11段]。

### 财务报表与报告主体

<a id="s8-chap_01_navPoint_idp1684609784"></a>
#### 财务报表

<a id="s8-Para_1.52"></a>**1.52** 财务报表（除非另有说明，否则与“通用目的财务报表”互换使用）是通用目的财务报告的组成部分。财务报表提供有关报告主体的经济资源、针对该主体的要求权以及该等资源和要求权变动的信息。

[概念框架 第3.1段]。

<a id="s8-Para_1.53"></a>**1.53** 财务报表包括财务状况表、财务业绩表以及其他报表和附注。

[概念框架 第3.3段]。

<a id="s8-chap_01_navPoint_idp1684620280"></a>
#### 报告期间

<a id="s8-Para_1.54"></a>**1.54** 财务报表提供某一报告期间（特定时间段）的信息。财务报表应至少提供一个前期报告期间的比较信息，以协助识别和评估变动及趋势。

[概念框架 第3.4段]。[概念框架 第3.5段]。

#### 前瞻性信息

<a id="s8-Para_1.55"></a>**1.55** 如果有关未来可能发生的交易和事项的前瞻性信息与报告期末或报告期间存在的资产、负债或权益相关，或者与报告期间的收益或费用相关，并且对财务报表使用者有用，则该等信息应包含在财务报表中。有关估计未来现金流量的信息即属于前瞻性信息的示例。

[概念框架 第3.6段]。[概念框架 第2.4段]。

<a id="s8-chap_01_navPoint_idp1684623608"></a>
#### 报告期后事项

<a id="s8-Para_1.56"></a>**1.56** 如果提供有关报告期末后发生的交易和事项（期后事项）的信息对于实现财务报表的目标是必要的，则该等信息应包含在财务报表中。

[概念框架 第3.6段]。[概念框架 第2.2段]。

#### 持续经营假设

<a id="s8-Para_1.57"></a>**1.57** 财务报表是在假设“……主体处于持续经营状态并将在可预见的未来继续经营”的基础上编制的。《国际会计准则第1号》也对此作出了规范。

[概念框架 第3.9段]。[概念框架 第4.33段]。[概念框架 第4.34段]。

#### 报告主体

<a id="s8-Para_1.58"></a>**1.58** 报告主体可以是单一主体、某主体的组成部分，也可以包含多个主体，且不一定是一个法律主体。

[概念框架 第3.10段]。

<a id="s8-chap_01_navPoint_idp1684671000"></a>
#### 合并财务报表、非合并财务报表及汇总财务报表

<a id="s8-Para_1.59"></a>**1.59** 合并财务报表将母公司（控制主体）及其子公司的财务报表作为单一报告主体的财务报表予以合并列报。

[概念框架 第3.11段]。[概念框架 第3.15段]。

<a id="s8-Para_1.60"></a>**1.60** 非合并财务报表包括仅涵盖母公司的财务报表。此类报表可以提供有用信息——例如，当针对母公司的要求权并不构成对子公司的要求权，或当针对母公司的权益要求权仅取决于母公司自身的可分配储备时。此外，仅涉及母公司的信息也可以在合并财务报表附注中提供。母公司可能被要求或选择在编制合并财务报表之外另行编制非合并财务报表。

[概念框架 第3.11段]。[概念框架 第3.17段]。[概念框架 第3.18段]。

<a id="s8-Para_1.61"></a>**1.61** 汇总财务报表包含并非全部通过母子公司关系相联系的两个或多个主体的财务报表。

[概念框架 第3.12段]。

<a id="s8-chap_01_navPoint_21"></a>
### 财务报表要素

<a id="s8-Para_1.62"></a>**1.62** 财务报表要素主要分为两大类。第一类与计量主体的财务状况相关，包括资产、负债和权益。第二类包括与计量主体财务业绩相关的要素，即收益和费用。分类是指为了列报和披露的目的，依据共同特征（如项目的性质或功能）对资产、负债、权益、收益或费用进行归类。

[概念框架 第4.1段]。[概念框架 第7.7段]。

<a id="s8-Para_1.63"></a>**1.63** 概念框架采用资产负债观模式；也就是说，收益和费用的定义及确定取决于（衍生自）资产和负债（及其变动）的定义。

[概念框架 第4.7段]。

<a id="s9-chap_01_navPoint_22"></a>
## 资产与负债（第1.64-1.108段）

<a id="s9-Para_1.64"></a>**1.64** 资产是指“……主体因过去事项而控制的现时经济资源”。经济资源进而定义为“具有产生经济利益潜力的权利”。

[概念框架 第4.3段]。[概念框架 第4.4段]。

<a id="s9-Para_1.65"></a>**1.65** 概念框架对资产定义的三个核心要素——权利、产生经济利益的潜力以及控制——阐述如下：

- 权利得以确立。权利可以采取多种形式，可能对应另一方向主体转移经济资源的义务；或者，权利可能代表对实物资产的权利或使用知识产权的权利。在某些情况下，某项权利是否存在可能具有不确定性，这种存在不确定性可能需要加以解决（例如，通过法院裁决）。存在不确定性是要素计量中的考量因素。

[概念框架 第4.6段]。[概念框架 第4.13段]。

- 该权利具有产生未来经济利益的潜力。收到未来经济利益的可能性较低并不必然排除确认，但它是决定是否确认该资产以及如何计量该资产时的考量因素。

[概念框架 第4.14段]。[概念框架 第4.15段]。[概念框架 第4.17段]。

- 主体能够控制该经济资源。控制是指主导经济资源的使用并从中获取可能流入的经济利益的现时能力。控制还包括阻止其他方主导该经济资源并从中获取利益的现时能力。

[概念框架 第4.19段]。

[FAQ 1.65.1 – 主体是否应确认由另一方控制的所持股份？](07.md#s10-FAQ_1.65.1)

<a id="s9-Para_1.66"></a>**1.66** 资产通常通过现金支出产生；然而，支出并不总是形成资产，即使预期会有经济利益流入亦然。这通常是因为发生支出的主体无法控制任何预期利益。

[概念框架 第4.18段]。

[FAQ 1.66.1 – 已发生的成本是否满足确认为资产的标准？](07.md#s10-FAQ_1.66.1)  
[FAQ 1.66.2 – 已发生的成本是否导致对资源的控制？](07.md#s10-FAQ_1.66.2)  
[FAQ 1.66.3 – 政府投入资产的会计处理](07.md#s10-FAQ_1.66.3)

<a id="s9-Para_1.67"></a>**1.67** 负债的定义是“主体因过去事项而承担的转移经济资源的现时义务”。

[概念框架 第4.26段]。

<a id="s9-Para_1.68"></a>**1.68** 负债定义中的三项核心标准详述如下：

- 现时义务得以确立。义务有时通过合同确立并具有法律强制执行力。然而，义务也可能源于主体的惯常做法、公开政策或声明；如果主体实际上没有能力避免该等义务，则称之为“推定义务”。

[概念框架 第4.29段]。[概念框架 第4.31段]。

- 该义务要求转移经济资源。即使转移经济资源的可能性较低，某项义务仍可能符合负债的定义。较低的可能性应在确认、计量及相关附注中予以考量。

[概念框架 第4.37段]。[概念框架 第4.38段]。

- 该现时义务因过去事项而存在。如果主体已经获得经济利益或已采取将使其有权获得经济利益的行动，且作为这些过去事项的结果，主体负有转移经济资源的义务，则满足该项标准。即使经济资源的转移要到未来日期才可强制执行，现时义务仍然可能存在。

[概念框架 第4.43段]。[概念框架 第4.46段]。

**相关信息**

### 计量单元（会计单元）

<a id="s9-Para_1.69"></a>**1.69** 计量单元（会计单元）是指“应用确认标准和计量概念的权利或权利组、义务或义务组，或者权利和义务组”。有时，确认可能适用一个计量单元，而计量适用另一个计量单元，例如合同按单项确认但作为合同组合的一部分进行计量。主体需要考虑列报和披露目的下的汇总或拆分程度，以及需在财务报表附注中提供的相关信息。

[概念框架 第4.48段]。[概念框架 第4.49段]。

<a id="s9-Para_1.70"></a>**1.70** 有时，权利和义务可能源于同一来源。如果这些权利和义务相互依存且无法分离，则它们构成单一计量单元。待执行合同即属于此类单一计量单元的示例。将一组权利和义务作为单一计量单元处理，不同于将资产和负债予以抵销。

[概念框架 第4.53段]。[概念框架 第4.54段]。

<a id="s9-chap_01_navPoint_24"></a>
### 合同

<a id="s9-Para_1.71"></a>**1.71** 为如实反映合同的实质，主体应考虑一组或一系列合同旨在实现整体商业效果的情形；在此类情形下，可能需要将该组或该系列合同所产生的权利和义务作为单一计量单元处理。

[概念框架 第4.62段]。

<a id="s9-chap_01_navPoint_25"></a>
### 权益

<a id="s9-Para_1.72"></a>**1.72** 权益是一项剩余项目（即主体资产扣除全部负债后的剩余权益）。然而，权益可以进一步细分为各类资本和储备，这些分类能够反映法律限制或不同所有者的不同权利。

[概念框架 第4.63段]。[概念框架 第4.64段]。[概念框架 第4.65段]。

<a id="s9-chap_01_navPoint_26"></a>
### 确认

<a id="s9-Para_1.73"></a>**1.73** 确认是将某项目纳入财务报表予以反映的过程。确认也将资产负债表和损益表中的各要素联系起来。

[概念框架 第5.1段]。[概念框架 第5.3段]。

[FAQ 1.73.1 – 某项特定准则禁止确认资产](07.md#s10-FAQ_1.73.1)

<a id="s9-Para_1.74"></a>**1.74** 当项目符合资产、负债、权益、收益或费用的定义，且基于相关性和如实反映能够向财务报表使用者提供有用信息时，即予以确认。

[概念框架 第5.6段]。

<a id="s9-Para_1.75"></a>**1.75** 基本的成本效益约束同样适用于确认决策。由于视具体事实和情况而定，某项信息可能对部分使用者有用而对其他使用者无用，因此可能需要运用职业判断，并且理事会各项准则之间及同一准则内部的确认要求可能存在差异。

[概念框架 第5.8段]。

<a id="s9-Para_1.7"></a>**1.76** 确认的两项标准中的第一项——相关性——取决于对若干因素的考量，包括资产或负债是否存在的不确定性程度，以及经济利益流入或流出的可能性水平。主体在确定财务报表中的确认时，应考虑这些因素及其他可能存在的因素。权利或义务存在的可能性较低，或相关经济利益的可能性较低，本身并不排除资产或负债的确认，但属于确认、计量以及就该等不确定性提供信息时的考量因素。此类信息可能包括：

- 可能的流入或流出金额，

- 可能的时间分布，以及

- 影响发生可能性的因素。

[概念框架 第5.13段]。[概念框架 第5.14段]。[概念框架 第5.15段]。[概念框架 第5.16段]。

<a id="s9-Para_1.77"></a>**1.77** 确认的第二项标准——如实反映——取决于对计量不确定性及其他因素的考量。计量不确定性包括对估计以及与估计相关的计量不确定性程度的考量，含可能结果的区间、估计的敏感性和复杂性。其他因素包括相关信息的反映方式以及附注中提供的信息。

[概念框架 第5.19段]。[概念框架 第5.20段]。

<a id="s9-Para_1.78"></a>**1.78** 收益的确认标准如下：“收益是指导致权益增加的资产增加或负债减少，但与权益要求权持有者的出资相关的除外。”

[概念框架 第4.68段]。

[FAQ 1.78.1 – 资产负债观——何时应确认资产？](07.md#s10-FAQ_1.78.1)

<a id="s9-Para_1.79"></a>**1.79** 费用的确认标准与收益的确认标准相对应：“费用是指导致权益减少的资产减少或负债增加，但与向权益要求权持有者的分配相关的除外。”

[概念框架 第4.69段]。

<a id="s9-Para_1.80"></a>**1.80** 资产负债观已取代配比概念，成为财务报表中资产、负债、收益和费用确认的驱动原则。然而，概念框架指出，有关收益和费用的信息与有关资产和负债的信息同等重要。

[概念框架 第4.71段]。

<a id="s9-Para_1.81"></a>**1.81** 2018年3月版概念框架取消了将可能性作为判断资产或负债是否存在的决定性标准，转而将可能性考量纳入更广泛的不确定性框架之中。具体而言，概念框架指出：“即使经济利益流入或流出的可能性较低，资产或负债仍可能存在。”

[概念框架 第5.15段]。

<a id="s9-Para_1.82"></a>**1.82** 在极少数情况下，计量不确定性可能高到——即便对于所有相关计量方法而言——均无法提供关于该资产或负债的有用信息。概念框架指出：“在这些有限的情况下，不应确认该资产或负债。”无论是否确认该资产或负债，主体均应考虑提供有关计量不确定性的解释性信息，以提供具备相关性和如实反映的有用信息。

[概念框架 第5.22段]。[概念框架 第5.23段]。

<a id="s9-chap_01_navPoint_27"></a>
### 终止确认

<a id="s9-Para_1.83"></a>**1.83** 终止确认（即从财务报表中移除全部或部分已确认的资产或负债）的标准为：

- 对于资产：当主体丧失对已确认资产的全部或部分的控制权时；以及

- 对于负债：当主体不再对已确认负债的全部或部分负有现时义务时。

[概念框架 第5.26段]。

<a id="s9-chap_01_navPoint_28"></a>
### 计量

<a id="s9-Para_1.84"></a>**1.84** 概念框架并未规定具体的计量基础，而是对各类计量基础进行了阐述，并指出对质量特征的考量可能会导致对不同的资产、负债、收益和费用选择不同的计量基础。

[概念框架 第6.1段]。[概念框架 第6.2段]。

<a id="s9-Para_1.85"></a>**1.85** 计量基础包括历史成本和现行价值（其中现行价值包括公允价值、资产的使用价值与负债的履约价值，以及现行成本）。

[概念框架 第6.4–6.22段]。[概念框架 表6.1]。

<a id="s9-Para_1.86"></a>**1.86** 选择计量基础时需考量的因素包括：

- 该计量基础将在财务报表中提供的信息的性质。

- 不同计量基础下该项目信息的相关性和如实反映程度。

- 资产或负债的特征，包括对市场因素或其他风险的敏感性。

- 资产或负债公允价值的变动是否反映了市场参与者预期的变化及其风险偏好的变化。

- 结果不确定性和计量不确定性的程度。

[概念框架 第6.43–6.62段]。

<a id="s9-Para_1.87"></a>**1.87** 可比性、可理解性和可验证性等增强性质量特征以及成本约束（成本效益）是选择计量基础时的其他考量因素。对相同项目一贯采用相同的计量基础有助于增强可比性；然而，如果其他因素的重要性超过可理解性和可比性的降低，则变更计量基础可能是合理的。

[概念框架 第6.63段]。[概念框架 第6.65段]。[概念框架 第6.66段]。

<a id="s9-Para_1.88"></a>**1.88** 权益的账面总金额不进行直接计量，而是等于已确认资产总额减去已确认负债总额后的差额。

[概念框架 第6.87段]。

<a id="s9-Para_1.89"></a>**1.89** 当计量金额无法直接观察时，有时会采用基于现金流量的计量技术来估计资产或负债。

[概念框架 第6.91段]。

<a id="s9-chap_01_navPoint_29"></a>
### 资本保全

<a id="s9-Para_1.90"></a>**1.90** 大多数主体采用财务资本保全概念，其核心在于保全主体所有者投入的财务资本。选择何种适当的资本保全概念取决于使用者的需求。除非存在恶性通货膨胀等异常情况，否则理事会不规定特定的会计模式。

[概念框架 第8.1段]。[概念框架 第8.9段]。

<a id="s9-chap_01_navPoint_30"></a>
### 资本保全概念与利润

<a id="s9-Para_1.91"></a>**1.91** 资本保全是利润计量的核心。存在两种资本概念，分别对应两种资本保全概念：

- 财务资本概念及相关的财务资本保全概念指出，在扣除当期向权益持有者（所有者）的分配及权益持有者（所有者）的出资后，如果期末净资产的财务（货币）金额超过期初净资产的财务（货币）金额，则赚取了利润。

- 财务资本概念是编制财务报表时最广泛采用的资本概念。

- 实物资本概念（例如营运能力）及相关的实物资本保全概念根据期末主体实物生产能力（营运能力）（或实现该能力所需的资源或资金）在扣除当期向权益持有者（所有者）的分配及权益持有者（所有者）的出资后超过期初金额的程度来计量利润。

[概念框架 第8.1段]。[概念框架 第8.2段]。[概念框架 第8.3段]。

<a id="s9-Para_1.92"></a>**1.92** 所选定的资本保全概念为计量利润提供了参照基准，并区分了主体的资本回报与资本返还。利润是收益扣除费用（包括资本保全调整，如有）后的剩余金额。如果费用超过收益，则该剩余金额界定为亏损。

[概念框架 第8.4段]。

<a id="s9-Para_1.93"></a>**1.93** 计量基础与资本保全概念的选择共同决定了编制财务报表所采用的会计模式。概念框架适用于多种会计模式，除非在恶性通货膨胀经济等特殊情况下，理事会不规定某一种特定模式。

[概念框架 第8.9段]。

[FAQ 1.93.1 – 资本保全的两种概念](07.md#s10-FAQ_1.93.1)

<a id="s9-chap_01_navPoint_31"></a>
### 历史成本

<a id="s9-Para_1.94"></a>**1.94** 资产的历史成本是指取得或形成该资产所发生成本的价值加上交易费用；负债的历史成本是指因承担或接收该负债所收到对价的价值减去交易费用。历史成本会随时间推移进行更新，以反映：资产的全部或部分消耗（或负债的全部或部分履行）；导致资产减值或增加履行义务所需转移经济资源价值的事项；以及相关融资成分的利息计提。

[概念框架 第6.5段]。[概念框架 第6.6段]。[概念框架 第6.7段]。[概念框架 第6.8段]。

<a id="s9-chap_01_navPoint_32"></a>
### 现行价值

<a id="s9-Para_1.95"></a>**1.95** 现行价值计量利用更新后反映计量日情况的信息，提供有关资产、负债及相关收益和费用的货币信息。现行价值计量基础包括公允价值、资产的使用价值和负债的履约价值，以及现行成本。

<a id="s9-chap_01_navPoint_33"></a>
### 公允价值

<a id="s9-Para_1.96"></a>**1.96** 公允价值定义为“市场参与者在计量日发生的有序交易中，出售一项资产所能收到或者转移一项负债所需支付的价格”。在某些情况下，公允价值可通过观察活跃市场中的价格直接确定；在其他情况下，则需间接确定，例如通过基于市场参与者对资产和负债定价视角的现金流量计量技术来确定。公允价值不因交易费用或处置费用而增加（对资产而言）或减少（对负债而言），此类费用应单独处理。

[概念框架 第6.12段]。[概念框架 第6.13段]。[概念框架 第6.14段]。[概念框架 第6.15段]。[概念框架 第6.16段]。[国际财务报告准则第13号 第9段]。

<a id="s9-chap_01_navPoint_34"></a>
### 使用价值与履约价值

<a id="s9-Para_1.97"></a>**1.97** 使用价值是指主体预期通过使用某项资产（包括其最终处置）所产生的现金流量或其他经济利益的现值。履约价值是指主体预期因向交易对手履行负债而有义务转移的现金或其他经济资源，以及主体预期为使其能够向交易对手履行该负债而有义务向其他方转移的任何金额的现值。使用价值和履约价值反映主体特定假设，无法直接观察；因此，它们采用基于现金流量的计量技术确定，其所反映的因素与公允价值确定时相同，只是从主体特定视角而非市场参与者视角出发。

[概念框架 第6.17段]。

<a id="s9-Para_1.98"></a>**1.98** 尽管部分准则纳入了公允价值的运用（例如《国际会计准则第19号》、《国际财务报告准则第9号》、《国际会计准则第40号》、《国际会计准则第41号》和《国际财务报告准则第2号》），但许多资产（如不动产、厂场和设备、无形资产和存货）以及大多数负债通常仍按历史成本入账。金融机构通常对其相当大比例的资产采用公允价值基础。然而，对于绝大多数采用国际财务报告准则的报告主体而言，公允价值基础仅限于其资产中的一小部分，即其部分金融资产。

<a id="s9-chap_01_navPoint_35"></a>
### 现行成本

<a id="s9-Para_1.99"></a>**1.99** 资产的现行成本是指计量日同等资产的成本，包括当日需支付的对价加上当日将发生的交易费用。负债的现行成本则相反。现行成本属于“投入价值”，因为它反映了取得一项资产或承担一项负债的市场价格。

[概念框架 第6.21段]。

<a id="s9-chap_01_navPoint_36"></a>
### 列报与披露

<a id="s9-chap_01_navPoint_idp1687854088"></a>
#### 作为沟通工具的列报与披露

<a id="s9-Para_1.100"></a>**1.100** 在财务报表中有效沟通信息能够使信息更具相关性并更如实反映情况，从而提升其有用性。因此，财务报表在列报和披露方面旨在实现以下目标：

- 侧重于列报和披露的目标与原则，而非具体规则；

- 通过将相似项目归类并将不同项目分列的方式对信息进行分类；以及

- 对信息进行汇总，但避免因不必要的细节或过度汇总而掩盖重要信息。

[概念框架 第7.1段]。[概念框架 第7.2段]。

<a id="s9-chap_01_navPoint_idp1687852552"></a>
#### 成本效益考量

<a id="s9-Para_1.101"></a>**1.101** 成本效益考量同样适用于有关列报和披露的决策，正如其普遍适用于财务报告一样。

[概念框架 第7.3段]。

<a id="s9-chap_01_navPoint_idp1687866120"></a>
#### 列报与披露的目标及原则

<a id="s9-Para_1.102"></a>**1.102** 理事会在准则制定活动中力求在两方面之间取得平衡：一方面提供灵活性，使主体能够提供其认为具有相关性和如实反映的信息；另一方面确立相应要求，使信息对于同一报告主体而言具有跨期可比性，并在同一报告期间内具有跨主体可比性。理事会将在准则中纳入列报和披露目标，以帮助主体识别有用信息并决定如何以最有效的方式沟通该等信息。

[概念框架 第7.4段]。[概念框架 第7.5段]。

<a id="s9-chap_01_navPoint_idp1687865224"></a>
#### 资产与负债的分类

<a id="s9-Para_1.103"></a>**1.103** 分类：

- 为列报和披露之目的，根据共同特征对财务报表中的项目——资产、负债、权益、收益或费用——进行归类；

- 避免将性质不同的项目合并列示；以及

- 适用于为该资产或负债所选定的计量单元。

[概念框架 第7.7段]。[概念框架 第7.8段]。[概念框架 第7.9段]。

<a id="s9-chap_01_navPoint_idp1687871368"></a>
#### 抵销

<a id="s9-Para_1.104"></a>**1.104** 抵销是指将资产和负债作为单独的计量单元予以确认，并在资产负债表中将其合并为单一净额列示。这不同于将一组权利和义务作为单一计量单元处理。概念框架指出：“抵销将不同项目归为一类，因此通常不恰当。”

[概念框架 第7.10段]。[概念框架 第7.11段]。

<a id="s9-chap_01_navPoint_idp1687875336"></a>
#### 权益的分类

<a id="s9-Para_1.105"></a>**1.105** 如果权益要求权具有不同特征，可能需要对其进行分别分类。此外，如果权益的某些组成部分受特定法律、监管或其他要求的约束，则可能需要将其分列以提供有用信息。

[概念框架 第7.12段]。[概念框架 第7.13段]。

<a id="s9-chap_01_navPoint_idp1687888392"></a>
#### 收益与费用、损益及其他综合收益的分类

<a id="s9-Para_1.106"></a>**1.106** 收益和费用根据与资产或负债（或资产或负债的组成部分）相关的计量单元进行分类，并计入损益表或其他综合收益。

[概念框架 第7.14段]。[概念框架 第7.15段]。

<a id="s9-Para_1.107"></a>**1.107** 损益表是衡量财务业绩的主要指标。

[概念框架 第7.16段]。

<a id="s9-Para_1.108"></a>**1.108** 理事会可能要求将部分收益和费用项目递延计入其他综合收益。尽管原则上计入其他综合收益的收益和费用将在未来期间重分类至损益表，但有时可能不存在明确的基础以识别该未来期间。在此类情况下，相关金额可能不会从其他综合收益中重分类至损益。

[概念框架 第7.17段]。[概念框架 第7.18段]。[概念框架 第7.19段]。

### <a id="s10-FAQ_1.1.1"></a>FAQ 1.1.1 – 有多少个国家使用国际财务报告准则或《中小主体国际财务报告准则》？

正文索引：[1.1](07.md#s7-Para_1.1)  

理事会网站列出了166个“司法管辖区概况”（截至2018年4月），载明了每个国家对国际财务报告准则的使用情况及公开承诺。该网站就这些概况提出了若干观察结果，包括：

- 144个司法管辖区要求其资本市场中的所有或绝大多数境内负有公众受托责任的主体（即上市公司和金融机构）采用国际财务报告准则；以及

### <a id="s10-FAQ_1.21.1"></a>FAQ 1.21.1 – 评估未来现金净流入前景需要哪些信息，原因是什么？

准则依据：概念框架 第1.4、1.13、1.15、6.15段  
正文索引：[1.21](07.md#s8-Para_1.21) 

评估未来现金净流入前景需要以下信息：

- 关于管理层履行其职责情况的信息，有助于有权对管理层行为行使投票权或施加影响的现有投资者、贷款人和其他债权人作出决策。

- 关于经济资源和要求权的性质及金额的信息，有助于识别主体的财务优势与劣势，支持评估主体的流动性和偿债能力、额外融资需求以及成功筹集该等资金的可能性。此类信息还能帮助使用者评估管理层对主体经济资源的受托责任。关于现有要求权的优先顺位和偿付要求的信息，有助于使用者预测未来现金流量将如何在对报告主体享有要求权的各方之间进行分配。

- 报告主体经济资源和要求权的变动源于主体的财务业绩以及发行债务工具或权益工具等其他事项或交易。使用者需要能够区分这些变动，以评估产生未来现金流量的潜力。

- 财务业绩信息对于理解主体利用可用资源所产生的回报至关重要。它能够深入揭示管理层履行高效且有效使用资源职责的情况。关于回报波动性及其构成要素的信息，有助于评估未来现金流量的不确定性。

- 某一期间的现金流量信息有助于使用者评估主体产生未来现金净流入的能力。它展示了现金的获取和使用情况，包括借款与偿还债务、向投资者分配现金以及可能影响主体流动性或偿债能力的其他因素。

### <a id="s10-FAQ_1.51.1"></a>FAQ 1.51.1 – 哪些项目无论其单项金额大小通常均具有重要性？

准则依据：  
正文索引：[1.51](07.md#s8-Para_1.51) 

财务报表中报告的以下项目，无论其金额大小，通常均具有重要性。

信息的性质和重要性会影响其相关性，而信息本身的性质有时即足以决定其相关性。判断信息是否具有重要性属于职业判断事项。以下项目无论其单项金额大小，通常均符合重要性标准：

- 关联方交易。

- 使利润变为亏损或使亏损变为利润的交易或调整。

- 使主体从流动资产净额转为流动负债净额（或反之）的交易或调整。

- 影响主体达成分析师一致预期的交易或调整。

- 掩盖盈利或其他趋势变化的交易或调整。

- 涉及已被识别为在主体经营或盈利能力中发挥重大作用的分部或主体其他组成部分的交易或调整。

- 影响主体遵守借款契约条款或其他合同要求的交易或调整。

- 具有增加管理层薪酬效果的交易或调整（例如，通过满足奖金发放条件）。

- 法律法规的变化。

- 违反法律法规的行为。

- 对主体处以的罚款。

- 法律诉讼案件。

- 与个别或群体主要供应商、客户或员工关系的恶化。

- 对特定供应商、客户或员工的依赖。

<a id="s10-chap_01_navPoint_42"></a>
### <a id="s10-FAQ_1.51.2"></a>FAQ 1.51.2 – 哪些项目不具有重要性？

准则依据：  
正文索引：[1.51](07.md#s8-Para_1.51) 

不具有重要性的项目不具有相关性，无法影响使用者的决策，且无需在财务信息中报告。如果在财务信息中报告不重要的项目，可能会干扰决策，因为过多的细节可能掩盖相关信息。（2018年10月31日，国际会计准则理事会发布了对《国际会计准则第1号》和《国际会计准则第8号》中“重要性”定义的修订，明确指出提及“掩盖信息”旨在解决其影响类似于省略或错报该信息的情形。这些修订适用于2020年1月1日或之后开始的年度期间，允许提前采用。）然而，确定何为重要属于职业判断事项，设定固定的货币限额或规则并不恰当。

<a id="s10-chap_01_navPoint_43"></a>
### <a id="s10-FAQ_1.65.1"></a>FAQ 1.65.1 – 主体是否应确认由另一方控制的所持股份？

准则依据：概念框架 第4.4段  
正文索引：[1.65](07.md#s9-Para_1.65) 

主体A订立了一项法律安排，作为主体B的受托人代主体B持有上市股份。主体B作出所有投资决策，主体A将按照主体B的指示行事。主体A因持有该等股份而收取受托管理费。该等投资产生的任何股利或损益均归属于主体B。主体A是否应确认其代主体B持有的股份？

主体A不应将该等上市股份确认为自身资产，尽管其实际持有该等股份。主体A并未控制该项投资的未来经济利益。该等投资产生的利益流向主体B，而无论股份表现如何，主体A均收取持有股份的受托管理费。因此，该等上市股份不符合在主体A资产负债表中确认为资产的标准。

<a id="s10-chap_01_navPoint_44"></a>
### <a id="s10-FAQ_1.66.1"></a>FAQ 1.66.1 – 已发生的成本是否满足确认为资产的标准？

准则依据：概念框架 第4.14段；国际会计准则第38号 第57段  
正文索引：[1.66](07.md#s9-Para_1.66) 

主体C发生了开办费（筹建费用），但尚未满足（《国际会计准则第38号》第57段规定的）确认自行建造无形资产成本的标准。主体C可能预期其支出将产生经济利益，因为该活动可能会形成一项无形资产，并进一步预期这将导致经济利益（利润）流入主体。这些开办费是否满足确认为资产的标准？

在进入开发阶段之前，主体C对可能流入的任何经济利益均不具备充分的预期或控制，因此该支出不符合资产的定义。

<a id="s10-chap_01_navPoint_45"></a>
### <a id="s10-FAQ_1.66.2"></a>FAQ 1.66.2 – 已发生的成本是否导致对资源的控制？

准则依据：概念框架 第4.19段  
正文索引：[1.66](07.md#s9-Para_1.66) 

主体D正在精简其业务运营。其决定将一座工厂迁往亚洲以降低运营成本，并借此大幅减少未来现金流出。作为搬迁计划的一部分，主体D向原工厂现有员工支付了辞退福利（遣散费）。该等辞退福利能否确认为一项资产？

该等辞退福利不应确认为资产。尽管该支出使主体D减少了未来现金流出，但支付辞退福利并未赋予主体D对某项资源的控制权。只有当主体控制特定资源时，方能确认资产。

<a id="s10-chap_01_navPoint_46"></a>
### <a id="s10-FAQ_1.66.3"></a>FAQ 1.66.3 – 政府投入资产的会计处理

准则依据：概念框架 第4.14段；国际会计准则第20号 第23段  
正文索引：[1.66](07.md#s9-Para_1.66) 

作为政府促进本国旅游业发展举措的一部分，主体E从政府获得一处不动产用于开发休闲公园。该不动产的公允价值能够可靠计量，且主体E控制该休闲公园的开发和运营。主体E应如何对该不动产进行会计处理？

政府授予该不动产构成一项政府补助；因此，该不动产应按公允价值或名义金额计量。[国际会计准则第20号 第23段]。

主体E控制该不动产，且当休闲公园投入运营时，预期未来经济利益将流入主体E。该不动产的价值亦能可靠计量。资产的定义和确认标准均已满足。

该政府补助应按照《国际会计准则第20号》的规定在资产负债表中列报。

<a id="s10-chap_01_navPoint_47"></a>
### <a id="s10-FAQ_1.73.1"></a>FAQ 1.73.1 – 某项特定准则禁止确认资产

准则依据：概念框架 第1.2段；国际会计准则第38号 第21(b)段、第63段  
正文索引：[1.73](07.md#s9-Para_1.73) 

主体F从事饮料业务，其品牌享誉全球。该品牌可以出售且具有市场价值。主体F能否在其资产负债表中将该品牌确认为一项资产？

管理层不应将该品牌确认为资产，即使它符合资产的定义。准则禁止管理层确认内部产生的品牌、报头、出版物名称、客户名单以及实质上类似的项目。《国际会计准则第38号》对无形资产的确认标准作出了更严格的界定，仅限于成本能够可靠计量的资产，而非成本或价值能够可靠计量。此类项目的成本无法与开发整体业务的成本相区分。由于成本无法可靠计量，此类项目不得确认为无形资产。

当从第三方购入类似资产时，为取得该等资产而支付的对价可以与开发整体业务的一般成本相区分，因此，只要该等资产同时满足控制及未来经济利益很可能流入的标准，即可予以确认。

<a id="s10-chap_01_navPoint_48"></a>
### <a id="s10-FAQ_1.78.1"></a>FAQ 1.78.1 – 资产负债观——何时应确认资产？

准则依据：概念框架 第4.68、5.5、1.17段  
正文索引：[1.78](07.md#s9-Para_1.78) 

主体G是一家电信主体，按月向客户开具通话费账单。3月初，主体G向客户发出的账单总额为C500,000。这些账单对应客户在2月份发生的通话。客户应于4月底前支付账单款项。主体G应于何时确认客户通话产生的收益？

主体G应于2月底在损益表中确认C500,000的收益，并同时在资产负债表中确认相应的资产（应收账款）增加。

在权责发生制会计下，交易和其他事项的影响在其发生时予以确认，并在其所属期间的财务报表中报告。收入不因匹配收到现金或开具账单的时间而被提前或递延。
