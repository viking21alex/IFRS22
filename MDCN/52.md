##### <a id="s216-EX29.159.2"></a>EX 29.159.2 – 包含优先股的企业合并中非控制性权益的计量

准则索引：IFRS 3 第19段   
正文索引：[29.159](50.md#s209-Para_29.159)   

**示例**

主体B已发行1,000股普通股和100股优先股（每股优先股面值为C1）。该优先股恰当地分类为权益。该优先股赋予持有人在向普通股持有人支付任何股利之前优先获得股利的权利。在主体B清算时，优先股持有人有权在普通股持有人之前优先获得每股C1的清偿款。优先股持有人在清算时不享有任何其他权利。

主体A收购了主体B的800股普通股，从而取得对主体B的控制权。优先股在购买日的公允价值为每股CU1.2。

主体A应如何计量包含优先股在内的非控制性权益？

**分析**

主体A可以选择按照公允价值或者按照在主体B可辨认净资产中所占的份额，来计量与200股普通股相关的非控制性权益。

与主体B优先股相关的非控制性权益（包含优先股）应当按照公允价值计量。在发生清算时，该优先股并不赋予其持有人按比例享有主体B净资产份额的权利。主体A必须按照优先股在购买日的公允价值CU120（100股优先股 × 每股CU1.2）对其进行计量。

##### 确定控制权对非控制性权益的影响

<a id="s216-chap_29_navPoint_idm495455528"></a>
###### <a id="s216-FAQ_29.161.1"></a>FAQ 29.161.1 – 控制权对非控制性权益的计量有何影响？

准则索引：IFRS 3 第B45段   
正文索引：[29.161](50.md#s209-Para_29.161)   

**问题**

控制权对非控制性权益（NCI）的计量有何影响？

**解答**

控制权溢价通常是指新控股股东为获得控制被购买方资产和现金流量的利益而支付的金额。购买方所获得的控制权要素可分为：（i）将购买方资产与被购买方资产整合所产生的潜在协同效应带来的利益；以及（ii）购买方控制被购买方经营、财务或公司治理特征的能力。

协同效应往往会使被购买方整体受益，包括非控制性权益。然而，非控制性权益股东不会从仅使购买方受益的协同效应中获益，因为控股股东可能不决定分配股利，或者可能控制被购买方的利润。主体应当评估转移对价是否包含控制权溢价，以及部分或全部控制权溢价是否应延伸适用于非控制性权益。

为了从控制性权益的价值推导出非控制性权益的价值，可能需要考虑非控制性（少数股东权益）折价。主体不应在未考虑与交易相关的事实和情况是否表明控制性权益价值与非控制性权益价值之间存在差异的情况下，机械地对控制性权益适用非控制性折价。

在评估是否存在控制权溢价时，了解被购买方与购买方之间谈判的演变过程是有帮助的——例如，如果谈判涉及多个竞标方，了解在确定转移对价金额时所考虑的因素。此外，了解谈判中所涉及的重大事项以及这些事项最终如何解决，也将为确定是否存在控制权溢价提供有价值的参考。IFRS 13中也提供了关于控制权溢价的指引，详见[第5章第128段](11.md#s34-Para_5.128)。

##### 与非控制性权益相关的看涨期权和看跌期权

<a id="s216-chap_29_navPoint_idm495441448"></a>
###### <a id="s216-EX29.162.1"></a>EX 29.162.1 – 发起要约收购的法定义务

准则索引：IFRS 3   
正文索引：[29.162](50.md#s209-Para_29.162)   

**示例**

某主体收购了一家上市主体的控制性权益。根据当地法律，该主体有义务就剩余股份发起要约收购。该主体是否需要根据IAS 32就该义务确认一项金融负债，或者根据IAS 37确认一项预计负债？

**分析**

不需要。金融负债源于金融工具一方（发行方）向另一方（持有人）交付现金的合同义务[IAS 32 第17段]。发起要约收购的法定要求是一项法定义务，而非合同义务。就IAS 37而言，发起要约收购的法定要求产生了一项以一项资产（如现金）交换另一项资产（如被购买方的股份）的义务，因此其性质属于待执行合同。待执行合同被排除在IAS 37的范围之外。因此，除非该合同成为亏损合同，否则IAS 32和IAS 37均不要求确认负债。

然而，将该项收购与按要约金额确认的金融负债作为一揽子关联交易进行确认是一种可接受的处理方法。这反映了与强制要约收购相关的经济利益预计将会流出。此外，解释委员会和国际会计准则理事会（IASB）于2013年5月讨论了该事项。虽然未达成结论，但指出发起要约收购的义务在经济上类似于签出的针对非控制性权益的看跌期权。因此，按照类似于IAS 32下针对非控制性权益签出的看跌期权的方式确认负债，将为财务报表使用者提供相关信息。

管理层应当披露所采用的会计处理方法；在确认了负债的情况下，还应披露该负债的性质及其计量方法。

##### 反向收购中的非控制性权益

<a id="s216-chap_29_navPoint_idm495425064"></a>
###### <a id="s216-EX29.164.1"></a>EX 29.164.1 – 包含非控制性权益的反向收购

准则索引：IFRS 3 第B24段   
正文索引：[29.164](50.md#s209-Para_29.164)   

**示例**

大型非上市企业主体B与小型上市企业主体A进行了合并。合并前，主体A已发行100股股份，股权分布广泛；主体B已发行60股股份，由B家族持有。该项合并旨在使主体B获得证券交易所上市地位。

该合并通过主体A发行2.5股新股换取主体B每股普通股的方式完成。主体B的股东将其54股股份交换为主体A的股份。因此，主体A发行了135股普通股以换取主体B的54股普通股。

**分析**

该交易构成反向收购，因为主体B的股东在主体A的235股股份中拥有135股（占57.4%），而主体A的股东在235股股份中拥有100股（占42.6%）。主体B能够提名董事会成员并控制主体A。主体B仍发行在外的6股股份将继续享有表决权，但仅作为非控制性权益持有人。

主体B是会计上的购买方，但由于主体B中持有6股股份的股东未参与换股交易，因此存在非控制性权益。他们在合并后的主体中不享有权益，其权益仅限于主体B。

在主体A的合并财务报表中，非控制性权益比例为10%（主体B已发行60股中的6股）。非控制性权益应当反映非控制性权益股东在法律上子公司合并前净资产账面金额中所占的比例份额。

由于主体B是会计上的购买方，其资产仍按合并前账面金额列报，而非控制性权益则按主体B合并前净资产账面金额的10%计量。

无论是否存在非控制性权益，实质上转移对价的公允价值都是相同的，因为法律上母公司（会计上的被购买方）的所有股东均参与了换股交易。

### 确认和计量商誉或廉价购买利得

<a id="s216-chap_29_navPoint_idm499772760"></a>
#### 商誉

<a id="s216-chap_29_navPoint_idm499762136"></a>
##### <a id="s216-EX29.171.1"></a>EX 29.171.1 – 构成商誉的组成部分

准则索引：IFRS 3 第B64(e)段   
正文索引：[29.171](50.md#s210-Para_29.171)   

**示例**

某拥有一项现有业务的主体从另一主体收购了一项业务。该交易中确认的商誉总额为C100。购买方管理层预计将从企业合并的协同效应中受益，具体包括成本节约和市场份额的增加。所收购的业务还包括已组建的员工队伍以及不可分离的非合同客户关系。这些项目不属于可辨认资产，并被并入商誉之中。

**分析**

上述商誉的组成部分应当在企业合并附注中予以披露。准则并不要求对商誉的各个组成部分进行单独量化[IFRS 3 附录B 第B64(e)段]。

<a id="s216-chap_29_navPoint_idm499757016"></a>
##### <a id="s216-EX29.173.1"></a>EX 29.173.1 – 确认的商誉取决于非控制性权益的计量方式

准则索引：IFRS 3 第32段   
正文索引：[29.173](50.md#s210-Para_29.173)   

商誉作为剩余金额进行计量。当主体收购某项业务不足100%的权益时，商誉可能为两个不同金额之一，这取决于主体在决定如何计量非控制性权益（NCI）时所作出的选择。非控制性权益可以采用公允价值法或比例份额法进行计量。主体可以按每项企业合并交易为基础在这两种处理方法之间作出选择（进一步参见[第29.159段](50.md#s209-Para_29.159)）：

- 当非控制性权益按其在被购买方可辨认净资产中所占的比例份额计量时，商誉仅包含与购买方在所收购业务中的权益相关的金额。

- 当非控制性权益按公允价值计量时，商誉将同时包含与购买方在所收购业务中的权益以及非控制性权益相关的金额。

**示例**

主体A以C150百万现金购买了主体B 60%的股权，从而收购主体B。按照IFRS 3计量的可辨认资产和负债净额经确定为C50百万。

基于非控制性权益的两种计量基础，应分别确认多少商誉？

**分析**

按在被购买方可辨认净资产中所占的比例份额计量

主体A决定按照非控制性权益在主体B可辨认净资产中所占的比例份额（40%）对其进行计量。

按照IFRS 3确认的商誉代表主体A在归属于主体B的总商誉中所占的60%份额。它不包含归属于40%非控制性权益的任何商誉金额。

##### <a id="s216-EX29.173.2"></a>EX 29.173.2 – 廉价购买利得取决于非控制性权益的计量方式

准则索引：IFRS 3 第19段   
正文索引：[29.173](50.md#s210-Para_29.173)   

当可辨认净资产大于转移对价的公允价值与非控制性权益（NCI）确认金额之和时，应当在损益表中确认廉价购买利得。

#### 廉价购买

<a id="s216-chap_29_navPoint_idm499453336"></a>
##### <a id="s216-FAQ_29.176.1"></a>FAQ 29.176.1 – 购买方在确认廉价购买利得之前应当做什么？

准则索引：IFRS 3 第36段   
正文索引：[29.176](50.md#s210-Para_29.176)   

**问题**

购买方在确认廉价购买利得之前应当做什么？

**解答**

廉价购买利得预计很少发生。某项业务的公允价值之所以低于已确认的净资产，可能是因为市场参与者预计需要进行重大的重组活动。然而，在这种情况下，应当仔细考虑资产的可收回金额。一家亏损、业绩不佳或需要重组的企业，其净资产价值不太可能高于为收购整个企业所支付的价格。购买方应当重新评估其是否已正确识别并计量了所取得的资产和所承担的负债。

应当重新评估可辨认资产、负债及或有负债的公允价值。这可能包括检查可辨认资产的公允价值是否存在减值，以及检查可辨认负债的公允价值以确保没有遗漏或低估。购买方应确保其已确认所有或有负债并按公允价值进行了计量。因该重新评估工作而导致的所收购净资产的任何减少，都将减少或消除廉价购买利得。

### 计量期间调整

<a id="s216-chap_29_navPoint_idm499440408"></a>
#### <a id="s216-EX29.180.1"></a>EX 29.180.1 – 对商誉的抵销调整

准则索引：IFRS 3 第48段   
正文索引：[29.180](50.md#s210-Para_29.180)   

**示例**

购买方可能承担了一项与被购买方某设施发生事故相关的损害赔偿负债，该赔偿的部分或全部在被购买方的保险单承保范围之内。

**解答**

如果购买方在计量期间获得了关于该负债在购买日公允价值的新信息，则因该负债暂估金额变动而导致的商誉调整，可能会被因应收保险人理赔款暂估金额变动而导致的相应商誉调整（全部或部分）抵销。

<a id="s216-chap_29_navPoint_idm499435160"></a>
#### <a id="s216-EX29.182.1"></a>EX 29.182.1 – 计量期间调整

准则索引：IFRS 3 第50段、第IE51–IE53段   
正文索引：[29.182](50.md#s210-Para_29.182)   

**示例**

主体A于20X4年10月1日收购了主体B。主体A委托独立评估机构对合并中取得的一项设备进行评估。然而，截至主体A完成其20X4年财务报表时，该项评估尚未最终完成。主体A在其20X4年财务报表中为该资产确认了C30,000的暂估公允价值，并为商誉确认了C100,000的暂估价值。该设备在购买日的剩余使用寿命为5年。

购买日六个月后，主体A收到了独立评估报告，报告估计该设备在购买日的公允价值为C40,000。该信息应当如何在财务报表中反映？

**分析**

购买方需要自购买日起确认因完成初始会计处理而对暂估价值作出的任何调整。本例忽略公允价值调整的税务影响。

应当对该设备于20X5年1月1日的期初账面金额作出调整。该调整按购买日的公允价值调整额C10,000（即C40,000 – C30,000）减去假定自购买日起即按购买日公允价值确认该设备本应确认的额外折旧额（截至20X4年12月31日止三个月的折旧C500）计量；即总体增加C9,500。

主体A在其20X4年财务报表中披露，该项企业合并的初始会计处理仅系暂估确定。

##### 原有关系与重新取得的权利

<a id="s216-chap_29_navPoint_idm499296536"></a>
###### <a id="s216-EX29.192.1"></a>EX 29.192.1 – 涉及重新取得的权利的原有关系结算

准则索引：IFRS 3 第B53段   
正文索引：[29.192](50.md#s211-Para_29.192)   

**示例1 – 重新取得的特许经营权**

主体M收购了主体N。主体M向主体N所有者支付金额的公允价值为C10百万。四年前，主体M授予了主体N一项为期10年的特许经营权，允许其在中国开展业务。该特许经营权的成本为C250,000。合同允许任何一方支付未到期初始费用加20%的代价终止该特许经营权。在购买日，结算金额为C180,000（(C250,000 × 6/10) + 20%）。

主体M收购主体N是因为它看中了中国市场的巨大潜力并希望加以开发。主体M经测算认为，在当前经济条件下按当前价格，其授予一项为期六年的特许经营权的价格为C450,000。

作为企业合并的一部分，该特许经营权应如何进行会计处理？

**分析**

该特许经营权按C450,000（即基于剩余合同期限、按市场价格确定的特许经营权公允价值）予以确认。

该合同的结算利得或损失为下列两项中的较低者：

- C300,000，即与市场条款相比，该权利对主体M不利的金额。这是主体M授予类似权利可收取的金额（C450,000）与当初授予该权利的价格（C150,000，即C250,000 × 6/10）之间的差额。

- C180,000，即主体M在购买日终止该权利所需支付的金额。

该合同的结算损失为C180,000。因此，在所支付的C10百万中，C9,820,000作为企业合并的对价进行会计处理，C180,000单独作为重新取得的权利的结算损失进行会计处理。

**示例2 – 重新取得的权利**

主体C生产高规格消费电子产品，并通过由4,000家授权经销商和综合电器商店组成的网络进行销售。每家授权经销商购买为期五年的主体C产品经销权，作为回报，其可获得营销和技术支持。五年期经销权的费用为C5百万，该金额被认为反映了在整个五年期间所获支持服务的公允价值，且于合同开始时一次性支付。该经销权费用多年来一直保持不变。任何一方在支付C1百万违约金后均可取消经销协议。如果协议由主体C终止，则还必须按剩余期限比例退还部分C5百万的费用。

主体C决定收购其中一家经销商——主体D。主体D的经销合同还剩三年期限。该经销协议在购买日的公允价值为C3百万。该合同不存在不利或有利因素。

主体C应当如何对所收购的经销权进行会计处理？

**分析**

由于不存在不利或有利因素，主体C不确认任何合同结算利得或损失（参见[第29.190段](50.md#s211-Para_29.190)）。主体C将在收购会计处理中确认一项C3百万的无形资产，并在剩余三年期限内进行摊销。

取得重新取得的权利可能伴随取得其他无形资产，这些其他无形资产应当与重新取得的权利和商誉分别单独确认。例如，某主体向特许经营商授予一项在特定国家开展业务的特许经营权。该特许经营协议包括使用该主体商号和专有技术的权利。数年后，该主体决定通过企业合并收购该特许经营商以重新取得该特许经营权，而所支付的金额高于一项新特许经营权的公允价值。转移价值超过特许经营权的部分表明，可能随重新取得的权利一并取得了其他无形资产（例如客户关系、客户合同和额外技术）。

<a id="s216-chap_29_navPoint_idm499265688"></a>
#### 竞业禁止协议

<a id="s216-chap_29_navPoint_idm499267992"></a>
##### <a id="s216-FAQ_29.193.1"></a>FAQ 29.193.1 – 购买方应如何对竞业禁止协议进行会计处理？

准则索引：IFRS 3 第B55(h)段   
正文索引：[29.193](50.md#s211-Para_29.193)   

**问题**

购买方应如何对竞业禁止协议进行会计处理？

**解答**

如果竞业禁止协议是由购买方或代表购买方订立的，或者主要是为了购买方的利益而订立的，则应当与企业合并分开进行会计处理[IFRS 3 第52段]。作为企业合并一部分进行谈判的竞业禁止协议，通常是由购买方发起，以保护购买方及合并后主体的利益。

竞业禁止协议也可能是企业合并前业已存在的雇佣合同的一部分。在这些情况下，因控制权变更或员工离职而触发的竞业禁止协议构成被收购业务的一项资产。

竞业禁止协议因满足合同权利或其他法定权利标准，通常符合作为无形资产单独确认的条件[IAS 38 第12段]。然而，合并后主体应当考虑该款项中是否有任何组成部分与未来服务相关，如有，则应当按照IAS 19进行会计处理。

竞业禁止协议通常具有有限使用寿命，需要对该资产进行摊销。摊销期应当反映从竞业禁止协议中获得经济利益的期间，该期间通常为合同期间。

#### 员工薪酬安排

<a id="s216-chap_29_navPoint_idm499116696"></a>
##### <a id="s216-EX29.196.1"></a>EX 29.196.1 – 雇佣关系终止时自动丧失的或有对价安排

准则索引：IFRS 3 第B55段   
正文索引：[29.196](50.md#s211-Para_29.196)   

在分析向员工或出售方股东支付的款项时，应当考虑IFRS 3第B55段列示的所有迹象。但是，如果或有付款在雇佣关系终止时自动丧失，则准则要求将其作为合并后服务的薪酬处理，而非作为企业合并对价的组成部分。

**示例**

主体B（被购买方）由一名单一股东拥有，该股东同时也是主体B的首席执行官。主体B在一项企业合并中被主体A（购买方）收购。

如果主体A在收购后的两年期间内达到特定的息税折旧摊销前利润（EBITDA）水平，主体B的单一股东将获得额外的收购对价。主体A认为，至少在两年内留任该单一股东对于平稳过渡主体B的持续经营业务至关重要。该安排同时规定，如果该股东在两年期满时不再是主体B的员工，则将丧失获得额外对价的任何权利。该安排属于合并后服务的薪酬，还是收购主体B的对价？

**分析**

该安排属于合并后服务的薪酬，因为如果雇佣关系终止，相关付款将自动丧失。

因达到特定EBITDA水平而向主体B原股东支付的任何款项，均在主体A的合并后财务报表中作为薪酬费用进行会计处理。

<a id="s216-chap_29_navPoint_idm499098776"></a>
##### <a id="s216-EX29.196.2"></a>EX 29.196.2 – 与持续服务无关的或有对价安排

准则索引：IFRS 3 第B55段   
正文索引：[29.196](50.md#s211-Para_29.196)   

**示例**

主体C以C250百万现金对价收购了主体D。如果主体D在收购后的三年中每一年均达到预定的销售量目标，主体C必须向出售方股东（“出售方”）支付额外款项。主体D共有四名股东，他们在企业合并前均为主体D的员工，并在合并后继续担任合并后主体的员工。只有在所有目标均达成的情况下，才会于三年期满时支付款项。

除上述背景外，其他事实如下：

- 出售方保持与同级别其他员工相近的薪资水平；

- 出售方无需在这三年期间保持受雇状态即可获得该额外款项；

- 对主体D进行的独立估值将该业务的价值确定在C250百万至C300百万之间；以及

- 出售方将按其此前持有的股权比例获得付款。

该额外款项是对价还是薪酬？

**分析**

由于付款不会因雇佣关系终止而丧失，因此应当分析其他迹象。不含额外款项的薪酬水平与其他员工相比显得合理。由于收购价格处于独立估值区间的下限，该或有付款似乎是对最低预付对价的补偿。

这些因素表明，该款项是为换取主体D而向出售方支付的对价，因此应计入购买对价。

<a id="s216-chap_29_navPoint_idm499077656"></a>
##### <a id="s216-EX29.196.3"></a>EX 29.196.3 – 与员工留任挂钩、在多名股东之间分配的现金

准则索引：IFRS 3 第B55段   
正文索引：[29.196](50.md#s211-Para_29.196)   

**示例**

主体C以C250百万现金对价收购了主体D。如果主体D在收购后的三年中每一年均达到预定的销售量目标，主体C必须向出售方股东（“出售方”）支付额外款项。主体D共有四名股东，他们在企业合并前均为主体D的员工，并在合并后继续担任合并后主体的员工。只有在所有目标均达成的情况下，才会于三年期满时支付款项。

除上述背景外，其他事实如下：

- 与其他员工相比，出售方的薪资水平较低；

- 如果出售方继续受雇，他们能够影响销售收入；

- 如果某位出售方辞职，该员工将丧失其应得的付款份额（该份额由其余出售方分享）；

- 如果在三年期满时没有任何出售方仍处于受雇状态，但所有销售目标均已达成，则该额外款项按此前的所有权比例分配给所有出售方；

- 对主体D进行的独立估值将该业务的价值确定在C250百万至C300百万之间；以及

- 出售方将按其此前持有的股权比例获得付款。

该额外款项是对价还是薪酬？

**分析**

虽然在所有出售方均终止雇佣关系的情况下，或有付款不会自动丧失，但每位出售方均可通过继续受雇来控制其赚取该额外款项份额的能力。

与同级别其他员工相比，出售方的薪资水平较低，且如果继续受雇，他们有能力影响销售目标。

该协议的商业实质是激励出售方继续留任。所有出售方均终止雇佣关系的情形被认为缺乏商业实质，因为最后一名在职的出售方不太可能放弃全部款项。

这些因素表明，该额外款项应当作为出售方合并后员工服务的薪酬进行会计处理。

<a id="s216-chap_29_navPoint_idm499063960"></a>
##### <a id="s216-EX29.196.4"></a>EX 29.196.4 – 黄金降落伞与留任奖金安排

准则索引：IFRS 3 第B55段   
正文索引：[29.196](50.md#s211-Para_29.196)   

与关键员工签订的雇佣协议通常包含这样一种安排：当关键员工的雇佣关系终止时，该员工将获得现金或权益形式的奖金。这些安排通常由企业合并（控制权变更）触发，通常被称为“黄金降落伞”安排。

可能因收购而明确化的负债示例包括源于原有合同安排的负债，例如董事服务合同中在所有权发生变更时触发的补偿条款。一旦企业合并很可能发生，这些负债即成为被购买方的合并前负债，并记录在被购买方的账簿中。在购买日尚未结算的范围内，该负债作为企业合并的组成部分成为所承担的负债。

需要对这些安排进行评估，以确定它们代表对合并前服务还是合并后服务的付款。一般而言，如果该安排在筹划收购之前即已包含在雇佣协议中，且不要求提供合并后服务，则其与合并前安排相关。相关费用通常于购买日在被购买方的财务报表中确认。

以下示例说明了黄金降落伞和留任奖金安排。关于竞业禁止协议的讨论，参见[第29.193段](50.md#s211-Para_29.193)及后续段落。
**示例1 – 黄金降落伞安排**

主体B首席执行官的雇佣合同规定，如果主体B被收购且首席执行官一直受雇至购买日，则首席执行官将获得C5百万现金付款（即“黄金降落伞”安排）。在雇佣合同签订数年后，主体B被主体A收购。首席执行官没有义务在购买日后继续受雇。该安排应如何进行会计处理？

**分析**

主体A需要评估向首席执行官支付的C5百万现金究竟属于（1）应当纳入企业合并会计处理的所承担义务，还是（2）应当与企业合并分开进行会计处理的合并后费用。

交易的原因：C5百万的付款最初是由主体B纳入首席执行官雇佣合同的，目的是在主体B未来被收购的情况下，确保首席执行官留任至购买日。

交易的发起方：该付款由主体B安排，目的是在发生收购的情况下，在截至购买日的期间内为主体B带来利益。

交易的时机：该雇佣合同在企业合并之前即已存在。

向首席执行官支付的款项并非主要为了主体A的经济利益。此外，首席执行官无需向主体A提供持续服务即可获得该付款。因此，该付款在主体B的合并前财务报表中作为薪酬费用记录。如果在购买日尚未支付，则该付款在购买日作为被收购业务的一项负债予以记录。

**示例2 – 留任奖金安排**

主体C收购了主体D，且主体C同意，如果主体D的各位关键员工自购买日起在合并后主体中继续受雇至少一年，则向每位关键员工支付C1百万现金。如果关键员工在购买日满一周年之前辞职，将丧失该C1百万现金付款。在收购前，主体D关键员工的合同中不包含类似条款。

**分析**

主体C需评估向每位关键员工支付的C1百万现金究竟属于（1）为被购买方转移的对价，还是（2）在企业合并之外进行会计处理的合并后费用。

交易的原因：C1百万的付款由主体C向主体D的关键员工提供，以促进收购后的平稳过渡进程。

交易的发起方：该付款由主体C安排，目的是在收购后的第一年为主体C带来利益。

交易的时机：该安排系结合企业合并进行谈判的，并未包含在关键员工原有的雇佣协议中。

向主体D关键员工支付的款项似乎主要是为了主体C的经济利益而安排的。如果关键员工未在购买日后至少一年内向合并后主体提供服务，则将丧失该款项。因此，这些款项不属于为主体D转移的对价，而是在合并集团的合并后财务报表中作为薪酬费用记录。

**示例3 – 由控制权变更和解雇构成的双重触发条件安排**

主体D在一项企业合并中收购了主体E。主体E与其一名关键员工之间存在一项原有雇佣协议，规定如果在购买日后18个月内发生控制权变更且雇佣关系终止（有时被称为“双重触发条件”），则向该员工支付C1百万。只有当该员工随后在无正当理由的情况下被解雇，或基于雇佣协议所界定的正当理由离职时，该员工才能获得规定金额。截至企业合并日，主体D已决定不向主体E的该名关键员工提供雇佣岗位，从而实质上在购买日终止了雇佣关系，并将于交割时向主体E的该名前员工支付C1百万。

**分析**

主体D需评估于交割时向该关键员工支付的C1百万现金究竟属于（1）收购主体E转移的对价，还是（2）在企业合并之外进行会计处理的合并后费用。

向该员工支付的辞退款项仅在雇佣协议中列明的两项条件均得到满足时（即控制权变更以及雇佣关系终止）才会发生。由于解雇该员工的决定不受主体E控制，因此在购买日主体E仅满足了两项条件之一。因此，主体E就该关键员工的实质性解雇确认负债是不恰当的。

主体D应当在其合并后期间将C1百万确认为费用，作为与企业合并分开的交易处理。如上所述，向该员工支付的款项以被购买方控制权变更及购买方终止雇佣关系为双重条件。主体D的决定是出于其自身利益作出的，根据IFRS 3第B50段的规定，应当与企业合并分开记录。因此，主体D在收购会计处理中不确认负债，而是于企业合并后解雇该员工的期间确认相关费用。

<a id="s216-chap_29_navPoint_idm499028888"></a>
##### <a id="s216-FAQ_29.198.1"></a>FAQ 29.198.1 – 购买方应如何确认支付给投资银行的、既提供咨询服务又负责企业合并融资的费用？

准则索引：IFRS 3 第53段   
正文索引：[29.198](50.md#s211-Para_29.198)   

**问题**

购买方应如何确认支付给投资银行的、既提供咨询服务又负责企业合并融资的费用？

**分析**

当投资银行在企业合并相关业务中同时提供过桥融资或承销服务时，支付给投资银行的费用必须在收购的直接成本与企业合并融资或承销相关成本之间进行分摊。例如，主体A以70%的现金以及其余部分的优先股和债务收购主体B，并且主体A聘请投资银行负责融资和承销服务。支付给投资银行的费用应当在两类服务之间进行分摊：与企业合并融资或承销相关的费用（通常作为债务或权益发行成本的一部分入账），以及所有其他服务（如咨询服务）的费用（应当在发生时费用化）。

<a id="s216-chap_29_navPoint_idm499018904"></a>
##### <a id="s216-EX29.200.1"></a>EX 29.200.1 – 对出售方因企业合并发生的交易费用所产生的承接负债的会计处理

准则索引：IFRS 3 第52(c)段   
正文索引：[29.200](50.md#s211-Para_29.200)   

**示例**

主体A收购了主体B 100%的股权。与该交易相关，主体B发生了出售业务的费用，包括法律费用。截至购买日，主体B在其购买日资产负债表中记录了数笔应付给协助此次出售的律师及其他顾问的未付发票款项。出售方发生的费用并非为了买方的利益。

主体A是否应当在收购会计处理中将主体B的未付应付款项确认为所承担的负债？

**分析**

是的。购买方发生的收购相关费用被视为单独交易，应当在发生时费用化。但是，在本事实情形下，这些费用是由出售方出于自身利益发生的。因此，只要未付应付款项不包含购买方的任何收购相关费用（即主体A与主体B并未协商由主体B支付主体A的交易费用），主体A就应当在收购会计处理中将该未付应付款项确认为所承担的负债，其处理方式与主体A承接主体B正常经营活动产生的其他应付账款余额相同。

如果主体A与主体B确实协商由主体B支付主体A的交易费用，则该等费用属于企业合并之外的事项。因此，主体A提供的补偿不属于转移对价，而应由主体A在费用发生期间确认为费用。

<a id="s216-chap_29_navPoint_idm499004824"></a>
#### 购买方因筹划企业合并而订立的金融工具

<a id="s216-chap_29_navPoint_idm499008664"></a>
##### <a id="s216-FAQ_29.202.1"></a>FAQ 29.202.1 – 购买方在应用套期会计时应当考虑哪些因素？

准则索引：IFRS 9 第6.3.1段（IAS 39 第78段）   
正文索引：[29.202](50.md#s211-Para_29.202)   

**问题**

购买方在应用套期会计时应当考虑哪些因素？

**解答**

在满足条件并应用现金流量套期会计的极少数情况下，套期工具的公允价值变动会累计计入权益，直至企业合并日。当套期工具在企业合并日平仓时，就产生了如何处理该金额的问题。就套期工具支付或收取的任何现金均不属于向出售方支付的对价。然而，国际财务报告准则解释委员会（IFRS IC）得出结论认为，该金额应当作为对商誉的基准调整处理（即计入应付对价的组成部分）。

因筹划企业合并而对其他项目进行的套期（例如，与为收购融资而拟发行债务相关的预期利息费用，或与潜在被购买方相关的预期销售），通常也不符合套期会计的条件，应当与企业合并分开进行会计处理。与外汇风险套期一样，尽管在理论上可以主张套期会计应当是可以接受的，但在实务中，鉴于准则要求预期交易必须极可能发生，应用套期会计可能无法实现。

#### 在企业合并时偿还被购买方的债务

##### <a id="s216-EX29.203.1"></a>EX 29.203.1 – 购买方与被购买方之间债务的结算

准则索引：IFRS 3 第B52段   
正文索引：[29.191](50.md#s211-Para_29.191)、[29.203](50.md#s211-Para_29.203)   

**示例**

被购买方可能曾向购买方借款。被购买方与购买方之间的债权债务关系是原有关系的另一种形式。如果该原有关系是购买方向被购买方发行的债务，则适用IFRS 9（IAS 39）中的指引。如果债务在到期前结算（消除），结算债务所支付的金额可能不同于当时该债务的账面金额。例如，如果被购买方持有对购买方债务证券的投资，其公允价值为C110，而购买方账簿中该债务的账面金额为C100，购买方应当如何对该结算进行会计处理（假定按C110结算）？

**分析**

应当就重新取得价格（公允价值或合同列明的结算金额，如有）与债务账面金额之间的差额在损益表中确认债务消除利得或损失。购买方在购买日确认C10的结算损失（基于该债务按C110结算的假设）。

[IFRS 9 第3.3.3段]。[IAS 39 第41段]。

如果实质上结算的原有关系是被购买方向购买方发行的债务融资，则购买方实质上是在结算一项应收款项，应采用与上述类似的方法进行会计处理。

<a id="s216-chap_29_navPoint_idm498976280"></a>
##### <a id="s216-EX29.203.2"></a>EX 29.203.2 – 在企业合并时偿还被购买方的银行债务

准则索引：IFRS 3 第51段   
正文索引：[29.203](50.md#s211-Para_29.203)   

在企业合并时偿还被购买方的银行债务可能有多种原因，例如：

- 购买方希望更换被购买方的贷款机构，以使其新子公司符合集团的银行融资安排；

- 被购买方的银行债务包含控制权变更条款，在企业合并时触发还款；或

- 购买方希望以无债务方式购买被购买方，因此将还款条款写入买卖协议中。

购买方可能会向被购买方划转现金，以便在企业合并时偿还第三方债务；或者，购买方可能会直接向银行还款。由于这属于购买方集团的现金支出，购买方在商业上可能会将其视为企业合并对价的组成部分。然而，由于该款项并非为换取被购买方控制权而向出售方转移的对价的组成部分，从IFRS 3的角度来看，不能将其作为企业合并对价的组成部分处理。这是因为IFRS 3第51段要求，如果相关金额“不属于购买方与被购买方（或其原所有者）在企业合并中交换的内容，即不属于为换取被购买方而支付的金额”，则必须将其作为单独交易处理。下述示例说明了该事项对企业合并会计处理的影响。此类交易在现金流量表中的分类应当按照IAS 7确定，详见[第7章第37段](15.md#s46-Para_7.37)。

**示例 – 因控制权变更条款而偿还被购买方的债务**

目标公司Y不含债务的可辨认净资产为C5百万。它还负有第三方银行债务，其账面价值和公允价值均为C1百万。该银行债务包含控制权变更条款。

购买方X收购目标公司Y。其向原所有者支付C6百万，并直接向银行偿还C1百万银行债务。

**分析**

该项企业合并的对价为支付给原所有者的C6百万。目标公司Y有一项可辨认负债，即C1百万的银行债务。确认的商誉为C2百万，即对价C6百万与包含银行债务在内的可辨认净资产C4百万之间的差额。

如果（错误地）将债务偿还计入应付对价，所计算出的商誉金额将是相同的：企业合并对价将包含支付给银行的C1百万，而目标公司Y将被视为以无债务方式被收购；确认的商誉仍为C2百万，即总对价C7百万与不含银行债务的可辨认资产C5百万之间的差额。

从企业合并的角度看，主要差异在于对所取得可辨认净资产以及应付总对价的披露。关于IAS 7下现金流量表的处理，参见[第7章第37段](15.md#s46-Para_7.37)。

#### 补偿资产

<a id="s216-chap_29_navPoint_idm498950808"></a>
##### <a id="s216-EX29.211.1"></a>EX 29.211.1 – 未按公允价值计量的被补偿负债

准则索引：IFRS 3 第28段   
正文索引：[29.211](50.md#s212-Para_29.211)   

**示例**

主体G于20X8年收购了主体H。主体H正就其20X5年纳税申报表与当地税务机关发生争议。主体G从主体H的出售方获得一项补偿承诺，以涵盖该税务争议的结果。主体G确定与该税务案件相关的经济利益流出很可能发生，并估计预期支付金额为C2.5百万，即税务机关主张的全额。该负债的公允价值为C1.74百万。

**分析**

在企业合并会计处理中，按照IAS 12确认C2.5百万的负债。如果税务机关要求支付该金额，主体H的出售方将向主体G支付全额C2.5百万。主体G认为，鉴于出售方的信用状况，该补偿资产完全可以收回。

主体G确认C2.5百万的补偿资产，并与被补偿负债采用相同基础计量，因为无需就可收回性或合同对补偿金额的限制进行任何调整。

### 后续计量与会计处理

<a id="s216-chap_29_navPoint_idm498931352"></a>
#### 所得税

<a id="s216-chap_29_navPoint_idm498932248"></a>
##### <a id="s216-EX29.214.1"></a>EX 29.214.1 – 收购后递延所得税资产得以实现

准则索引：IAS 12 第68段   
正文索引：[29.214](50.md#s213-Para_29.214)   

**示例**

主体A收购了子公司主体B，主体B存在C500的可抵扣暂时性差异。收购时的税率为30%。由于主体A认为由此产生的C150递延所得税资产不可收回，因此未予确认。收购九个月后，主体A评估认为，未来应纳税所得额很可能足以使集团收回全部可抵扣暂时性差异的利益。主体A应如何对该资产可收回性估计的变更进行会计处理？

**分析**

主体A首先考虑导致该利益变得很可能收回的情况在购买日是否业已存在。如果业已存在，则主体A确认C150的递延所得税资产，并将商誉减少C150。相关调整追溯至购买日；如果该项收购发生在上一会计期间，且影响重大，则应重述财务报表中的比较信息。

如果导致该利益变得很可能收回的情况是在企业合并日之后发生的，则主体A确认C150的递延所得税资产和C150的所得税收益。商誉不作调整。

<a id="s216-chap_29_navPoint_idm498926744"></a>
#### 补偿资产

<a id="s216-chap_29_navPoint_idm498925848"></a>
##### <a id="s216-FAQ_29.217.1"></a>FAQ 29.217.1 – 购买方应如何对企业合并中确认的补偿资产进行后续会计处理和计量？

准则索引：IFRS 3 第57段   
正文索引：[29.217](50.md#s213-Para_29.217)   

**问题**

购买方应如何对企业合并中确认的补偿资产进行后续会计处理和计量？

**解答**

补偿资产可能与被收购业务的任何负债或或有负债相关。被补偿项目可能是按照IAS 19计量的雇员福利义务、按照IAS 37计量的预计负债，或不确定税务处理。主体应当采用与相关项目相同的基础计量补偿资产，但受限于合同条款中的任何限制（例如应付金额的上限）或针对出售方信用状况的任何调整。采用相同基础计量包括恰当地确认任何利得或损失。例如，如果被补偿负债是一项设定受益养老金负债，则补偿资产的重新计量可能部分计入其他综合收益，部分计入损益。

被补偿项目可能是一项或有负债。如果该或有负债变得很可能发生，则会对其进行重新计量，并因此重分类且按照IAS 37作为预计负债进行计量。如果该或有事项的全额均在补偿范围内且变得很可能发生，则此前记录的金额与未来流出的最佳估计数之间的差额应记录为负债和补偿资产的增加。如果出售方无需付款即被解除义务（例如，如果该或有事项并未成为现实），则终止确认该或有负债；补偿资产与负债均予以终止确认。

因补偿资产与被补偿项目价值变动而作出的调整可以在综合收益表中抵销。也就是说，在这种情况下，在综合收益表中净额列报是可以接受的。然而，如果被补偿项目是一项税务负债，则进行净额抵销是不恰当的。所得税费用是IAS 12中界定的术语。与被补偿税务项目相关的补偿资产变动不符合所得税费用的定义，因此不应在所得税费用内抵销。关于损益表列报的进一步指引，参见[第29.244段](50.md#s214-Para_29.244)。

出售方补偿可能涉及在购买日未入账的被补偿项目。例如，某项或有负债可能因无法可靠计量而未在购买日确认。如果该或有负债随后成为一项负债，则予以确认（参见[第29.215段](50.md#s213-Para_29.215)）。无论该确认是否发生在计量期间内（参见[第29.177段](50.md#s210-Para_29.177)），均应当在确认该负债的同时，采用与该负债相同的基础确认一项补偿资产（受限于合同对补偿金额的限制以及管理层对可收回性的评估）。
<a id="s216-chap_29_navPoint_idm498899736"></a>
#### 或有对价

<a id="s216-chap_29_navPoint_idm498899224"></a>
##### <a id="s216-FAQ_29.223.1"></a>FAQ 29.223.1 – 购买方应如何对或有对价的公允价值变动进行会计处理？

准则索引：IFRS 3 第58(b)段   
正文索引：[29.223](50.md#s213-Para_29.223)   

**问题**

购买方应如何对或有对价的公允价值变动进行会计处理？

**解答**

IFRS 3并未就或有对价公允价值变动应当在损益表中何处列报提供任何指引。IFRS 9（IAS 39）对此亦未作出规定。公允价值变动可能源于多种原因——例如，关于作为应付或有对价基础的未来利润水平的假设发生变动，或者为反映货币时间价值而进行的折现转回。多种替代方法均可能是可接受的。

理想情况下，公允价值变动的列报应当遵循或有对价的性质和目的。如果公允价值变动主要是由关于未来利润水平的假设变动所致，则将其整体分类于营业利润中可能是恰当的，因为该公允价值变动与集团的经营业绩直接相关。如果所收购子公司的业绩优于原先预期，则该子公司经营所增加的营业利润将被或有对价价值的增加所抵销或部分抵销。如果公允价值变动主要是由于货币时间价值所致，则将公允价值变动整体列报于财务费用中可能是恰当的。

在实务中，很少观察到应收出售方的或有对价。但是，将以现金或其他金融资产结算的应收或有对价属于金融资产，并按照IFRS 9（IAS 39）进行分类。

与应收或有对价相关的现金流量不太可能仅代表对本金和利息的支付。理解应收或有对价的现金流量为何会发生变化非常重要，尽管并非决定性因素，但也可能需要考虑或有事项的触发条件。应收或有对价通常会根据经营业绩或其他因素发生变化。这不属于基本借贷安排的特征。按照IFRS 9，应收或有对价最可能的分类是以公允价值计量且其变动计入当期损益（FVTPL）。

或有对价预计很少落入IAS 37的范围，因为它几乎总是源于转移现金或其他金融资产的合同要求。但是，如果应收或应付或有对价落入IAS 37的范围——可能是因为它与非金融资产相关，或者源于某种推定义务——则其按公允价值初始确认，后续变动按照IAS 37进行会计处理。属于IAS 37范围的负债按预计支付金额的最佳估计数折现至资产负债表日进行计量。因折现转回引起的负债变动作为利息费用入账并计入损益。预期现金流出的变动计入损益。

### 反向收购

<a id="s216-chap_29_navPoint_idm498882968"></a>
#### <a id="s216-EX29.229.1"></a>EX 29.229.1 – 反向收购会计处理

准则索引：IFRS 3 第B22段   
正文索引：[29.229](50.md#s214-Para_29.229)   

在反向收购中适用以下会计处理：

- 法律上子公司（会计上的购买方）的资产和负债在合并财务报表中按其合并前的账面金额确认和计量。

- 法律上母公司（会计上的被购买方）的可辨认资产和负债在购买日按照IFRS 3（即通常按公允价值）确认。商誉按照IFRS 3确认，合并对价按[第29.60段](50.md#s208-Para_29.60)所述方法计算。

- 合并财务报表中确认的留存收益和其他权益余额为法律上子公司紧接企业合并前的余额。

- 合并财务报表中作为已发行权益工具确认的金额，通过将按照IFRS 3确定的法律上母公司的公允价值（基于视为由法律上子公司发行的权益份额数量，详见[第29.60段](50.md#s208-Para_29.60)）加上法律上子公司紧接企业合并前的已发行权益来确定。然而，合并财务报表中列示的权益结构（即已发行权益工具的数量和种类）应当反映法律上母公司的权益结构，包括法律上母公司为实施合并而发行的权益工具。法律上子公司的权益结构应当使用收购协议中确立的换股比例进行重述，以反映法律上母公司在反向收购中发行的股份数量。

- 非控制性权益详见[第29.163段](50.md#s209-Para_29.163)。

**分析**

计算企业合并转移对价的公允价值

通常采用会计上的购买方（法律上子公司）权益工具在购买日的公允价值来确定合并对价（参见[第29.60段](50.md#s208-Para_29.60)）。由于法律上子公司（主体B）的权益工具存在公开报价，因此采用该报价确定企业合并对价。

主体B的股东拥有合并后主体已发行股份的60%（250百万股已发行股份中的150百万股）。其余40%由主体A的原股东拥有。如果主体B向主体A的股东增发股份以换取其在主体A中的股份，为了使合并后主体的所有权比例保持不变，主体B必须增发40百万股股份。届时，主体B的股东将在主体B的100百万股已发行股份中持有60百万股，从而拥有合并后主体60%的股权。

主体B为收购主体A支付的企业合并对价为C1,600百万（即40百万股主体B股份，每股公允价值为C40）。

合并财务报表中就已发行权益确认的金额，通过将法律上母公司的公允价值（C1,600百万）加上法律上子公司紧接企业合并前的已发行权益（C600百万）来确定[IFRS 3 附录B 第B22(d)段]。然而，合并财务报表中列示的权益结构应当反映法律上母公司的权益结构，包括法律上母公司为实施合并而发行的权益工具。法律上子公司的权益结构应当在企业合并日使用收购协议中确立的换股比例进行重述，以反映法律上母公司发行的股份数量。即60百万股 × 2.5 = 150百万股，加上法律上母公司在合并前业已发行的100百万股。

企业合并发生所在报告期末的权益结构（即已发行权益工具的数量和种类）反映法律上母公司的权益结构。因此，它将包含法律上母公司的全部权益工具（即合并前业已存在的权益工具，以及法律上母公司为实施合并而发行的权益工具）。与此财务报表列报保持一致，每股收益的计算也基于法律上购买方的资本结构[IFRS 3 附录B 第B25段]。[IFRS 3 附录B 第B26段]。[IFRS 3 附录B 第B27段]。

更多信息参见[EX 29.229.3](52.md#s216-EX29.229.3)。

#### <a id="s216-FAQ_29.229.2"></a>FAQ 29.229.2 – 反向收购会计处理中应如何列报比较信息？

准则索引：IFRS 3 第B22段   
正文索引：[29.229](50.md#s214-Para_29.229)   

**问题**

反向收购会计处理中应如何列报比较信息？

**解答**

在上一年度，合并财务报表中列报的比较信息应当是法律上子公司的信息。然而，对支持该权益价值的已发行权益工具数量和种类的披露，应当予以重述以反映法律上母公司的股本。该重述使用收购协议中确立的换股比例进行（[参见EX 29.229.1](52.md#s216-EX29.229.1)）。

当地法规可能决定比较期末股本及其他权益项目的列报方式。如果不存在司法管辖区要求，则应考虑管理层或其他相关利益方的偏好。

已发行权益工具的数量和种类可以反映法律上母公司的股本。这反映了法律上子公司是购买方、因此上一年度数据仅与法律上子公司相关的实质。

或者，已发行权益工具的数量和种类也可以反映法律上子公司的股本。这反映了合并层面股本与以前期间的一致性。

当交易发生时，法律上母公司将发行股份以换取法律上子公司的股份。因该换股交易导致的权益结构变动，自交易发生时起采用未来适用法在合并财务报表中反映。权益结构的变动在财务报表附注中予以说明。

<a id="s216-chap_29_navPoint_idm495075240"></a>
#### <a id="s216-EX29.229.3"></a>EX 29.229.3 – 反向收购中的每股收益

准则索引：IFRS 3 第B27段   
正文索引：[29.229](50.md#s214-Para_29.229)   

在确定每股收益时，反向收购后合并财务报表中的权益结构反映法律上购买方的权益结构，包括用于实施企业合并的权益工具。

为计算反向收购发生期间发行在外普通股的加权平均数（分母）：

- 自该期间期初至购买日的发行在外普通股股数，视为该期间法律上被购买方（会计上的购买方）发行在外的普通股股数乘以企业合并协议确立的换股比例。

- 自购买日至该期间期末的发行在外普通股股数，为该期间法律上母公司实际发行在外的普通股股数。

在反向收购后合并财务报表中为每个比较期间披露的基本每股收益，通过将法律上被购买方在各该期间归属于普通股股东的损益，除以法律上被购买方历史发行在外普通股的加权平均数乘以企业合并协议确立的换股比例计算得出。

在比较期间以及当期截至反向收购日的期间内，法律上被购买方已发行普通股的股数可能发生变化，从而对每股收益产生影响。相应地，每股收益的计算应当予以调整，以考虑法律上子公司在这些期间内已发行普通股股数变动的影响。

##### <a id="s216-FAQ_29.237.1"></a>FAQ 29.237.1 – 编制备考（模拟）信息的指引是什么？

准则索引：IFRS 3 第B64(q)(ii)段   
正文索引：[29.237](50.md#s214-Para_29.237)   

**问题**

编制备考（模拟）信息的指引是什么？

**解答**

IFRS 3包含一项要求，即披露实质上属于备考（模拟）数据的信息。除非披露不切实可行，否则准则要求就每项企业合并（或对单项不重大的企业合并汇总）披露以下信息：

- 合并后主体当期的收入，假定当期发生的所有企业合并的购买日均为该报告期期初。

- 合并后主体当期的损益，假定当期发生的所有企业合并的购买日均为该报告期期初。

该准则未就如何计算备考（模拟）信息提供指引。在实务中，可能存在多种方法，从简单的业绩汇总，到更复杂（但可以说更有意义）的汇总，后者包括就会计政策统一、调整后的债务结构及其他类似因素进行的调整。

我们认为，在根据IFRS 3披露的备考（模拟）信息中进行调整时，相关调整应当：

- 清晰列示并予以说明。

- 直接归属于相关交易，且不涉及未来事项或决策。

- 具有事实依据支持。

清晰列示并说明调整可能包括需要列明：

- 调整所依据的假设。

- 存在重大不确定性时的结果区间。

- 相关金额的来源。

- 调整如何汇总或分摊至财务报表项目（如相关）。

下文摘要列出了可能对备考（模拟）信息进行的若干常见调整，并指出了其中哪些调整就IFRS 3第B64(q)(ii)段的披露目的而言通常是可接受的。当地市场惯例及当地监管机构的指引可能会影响这些调整的可接受性。

**常见调整**

- 会计政策的统一：对被购买方合并前期间的业绩进行调整，以反映集团会计政策与被购买方自身会计政策之间的差异。这与合并后期间对被购买方业绩所作的调整保持一致。

- 抵销购买日之前的集团内部交易：抵销合并前期间集团与被购买方之间的销售（包括任何利润），除非相关商品随后已销售至集团外部。这与合并后期间对被购买方业绩所作的调整保持一致。

- 公允价值调整：如果这些调整具有事实依据支持，则予以调整——鉴于公允价值调整在收购后已予确定，通常具备事实依据。其基本原则是，如果收购会计处理导致收购时对资产和负债进行公允价值调整并产生商誉余额，这些调整将对合并集团的合并后盈利产生影响。相关调整反映公允价值调整的影响，如同这些调整发生在报告期期初一样——例如，因收购时某项不动产、厂场和设备公允价值增加而导致的全年折旧费用增加。

- 收购相关费用：交易费用应当予以反映，如同其发生在年度报告期期初一样。

- 为收购融资而借入的款项——如果收购发生在年初，这些借款本应在年初借入。因此，可以在合并前期间计入额外的财务费用，以反映假定收购发生在年初时企业合并本应产生的影响。

- 上述调整的税务影响（即归属于收购的调整所产生的税务影响）予以反映。税务调整并非简单地适用发行人的有效税率，而是需要考察收购的增量影响。

**通常不被认为可接受的调整**

- 协同效应收益：协同效应收益通常依赖于交易后的未来行动，因此在编制备考（模拟）财务信息时不对协同效应进行调整。通常无法以事实依据支持将协同效应收益追溯至财务年度期初本应实现的金额，因此不对报告业绩进行调整。假设说明应明确这一点。

- 成本消除：某些成本可能得以消除（例如被收购主体的董事袍金）。假定这些成本将被消除可能是合理的，但交易往往还会导致其他无法以事实依据支持的成本增加。因此，我们认为成本消除属于协同效应的一种形式，不应作为备考（模拟）调整处理。

- 将收购后实施的套期策略追溯至期初：IFRS 9（IAS 39）禁止追溯指定套期文件。不应调整备考（模拟）财务信息以反映假定合并发生在年初时管理层本可能实施的套期策略。

- 结转的税务亏损：如果自期初起即可实现协同效应收益，这些税务亏损本可能更快地得到利用，但在合并后期间并不存在对应的调整。

备考（模拟）信息并不代表当年的实际业绩。必须明确标明其为备考（模拟）信息，且所作假设应当清晰披露并具有事实依据支持。

<a id="s216-chap_29_navPoint_idm494966440"></a>
#### 现金流量表列报与披露

<a id="s216-chap_29_navPoint_idm494962088"></a>
##### <a id="s216-FAQ_29.242.1"></a>FAQ 29.242.1 – 在企业合并中，现金流量列报和披露有哪些要求？

准则索引：IAS 7 第40段   
正文索引：[29.242](50.md#s214-Para_29.242)   

**问题**

在企业合并中，现金流量列报和披露有哪些要求？

**解答**

IAS 7要求就收购业务的现金流量影响作出以下具体披露：

- 购买对价总额，以及其中以现金及现金等价物构成的金额。

- 被收购业务中现金及现金等价物的金额。

- 被收购业务的资产和负债（现金及现金等价物除外），按各主要类别列示。

第一项要求与IFRS 3中披露应付对价构成要素的要求一致。同样，第二项和第三项要求也与IFRS 3的要求一致。因此，主体可以通过提供一项合并披露来同时满足IFRS 3和IAS 7的披露要求。

<a id="s216-chap_29_navPoint_idm495219752"></a>
#### 损益表列报与披露

<a id="s216-chap_29_navPoint_idm495215016"></a>
##### <a id="s216-FAQ_29.244.1"></a>FAQ 29.244.1 – 在企业合并中，损益表列报和披露有哪些要求？

准则索引：IAS 1 第85–86段   
正文索引：[29.244](50.md#s214-Para_29.244)   

**问题**

在企业合并中，损益表列报和披露有哪些要求？

**解答**

准则要求披露所确认的各类利得或损失的金额，并指明该金额在综合收益表中确认的报表项目。企业合并产生的利得和损失也可以汇总并记录在一个单独的报表项目中（例如，“与企业合并相关的利得和损失”）。该报表项目需要恰当描述，并在附注中提供适当的补充说明，同时遵循IAS 1关于公允列报的总体要求。应当透明地披露单列项目中包含了哪些利得和损失。如果附有恰当的说明和充分的附注披露，将多项企业合并产生的利得、损失和费用汇总于同一单列项目中也是可接受的。

选择将企业合并产生的利得和损失在单一报表项目中列报的主体，也可以将收购相关费用包含在该单列项目中。然而，主体并没有义务将所有收购相关费用单独归集于单一报表项目中，而且主体可能会选择不这样做，特别是在采用“按性质分类”列报方式时。关于收购相关费用的进一步讨论，[参见第29.198段](50.md#s211-Para_29.198)及后续段落。

IFRS 3对收购相关费用的定义包括（除其他项目外）“……一般管理费用，包括维持内部收购部门的成本……”[IFRS 3 第53段]。此类内部成本可能包括负责评估潜在收购目标的独立部门的成本、因交易成功支付的奖金，以及参与谈判的高级管理人员成本的分摊。主体应当制定一项会计政策，考虑哪些内部成本与特定交易相关，以确定将这些成本计入该单列项目的程度。

一项合理政策的示例是仅计入因企业合并产生的增量费用，或者计入增量成本以及基于所耗费时间分摊的持续性成本。如果将100%的内部成本计入该单列项目，将导致主体在并未发生企业合并的期间也列报“企业合并产生的利得、损失和费用”。因此，尽管准则并未禁止此做法，但这可能无法提供有意义的信息。

在某些情况下，单项利得和损失可能会单独列报（而不与其他报表项目汇总）。廉价购买利得就是一个例子。廉价购买利得的性质和重要性可能需要单独列报，以符合IAS 1关于披露重大收益和费用项目的原则[IAS 1 第85、86段]。应当透明地披露哪些利得和损失包含在单列项目中、哪些未包含在内，包括其他利得和损失在综合收益表中的反映位置。

IAS 1不要求列报“营业利润”，尽管许多主体都会列报该项目。如果就与企业合并相关的利得和损失列报了单一报表项目，则将其分类为营业项目还是非营业项目，应当与其他收益和费用项目的列报保持一致。管理层应当考虑在没有发生企业合并的情况下，此类金额本会在何处列报。例如，如果综合收益表中列报了营业利润项目，且收购相关费用包含在该单列项目中，则表明该单列项目应当包含在营业利润内，因为在没有企业合并的情况下，此类费用本会反映在营业利润中。

使用单一报表项目列报更符合“按功能分类”的损益表列报方式。但是，在满足以下条件的前提下，“按性质分类”的损益表也可以采用这种列报方式：

- 员工成本报表项目（在综合收益表表内）明确标明不含与企业合并相关的员工成本；

- 按照IAS 1在财务报表中披露员工成本总额，包括分摊至与企业合并相关的利得和损失的金额；以及

- 披露关于哪些内部成本与特定交易相关并计入该单列项目的会计政策。

按性质分类或按功能分类列报的综合收益表通常优于混合列报方式。然而，如果提供了透明的披露，混合列报也是可接受的（更多信息[参见FAQ 4.110.1](10.md#s30-FAQ_4.110.1)）。

除所得税补偿外，因补偿资产与被补偿项目价值变动而作出的调整通常可以在综合收益表中抵销。补偿资产会随着被补偿项目（通常是IAS 12、IAS 19或IAS 37范围内的负债）的变动而变动，尽管它也可能与应收款项或存货等资产相关（[进一步参见第29.146段及后续段落](50.md#s209-Para_29.146)）。

IAS 37包含关于已确认预计负债补偿款的指引，指出预计负债的费用和补偿款的收益可以在综合收益表中以净额列报[IAS 37 第54段]。当负债按照IAS 37计量时，被补偿负债的变动可以与补偿资产的变动相互抵销。IAS 19中也有类似指引，专门针对设定受益计划费用的补偿款；因此，通过类比，在综合收益表中抵销与IAS 19负债相关的补偿资产变动是可以接受的[IAS 19 第104A段]。

单独的补偿资产和负债几乎永远（甚至从未）无法满足IAS 1关于在资产负债表内抵销的条件，因此应当以总额列报。

补偿的一种常见形式是针对所得税负债的补偿。所得税费用是IAS 12中界定的术语，并在IAS 1中作为必列报表项目予以引用[IAS 12 第5段]。[IAS 1 第82段]。税务补偿资产的变动不计入所得税报表项目，因为它不符合IAS 12中所得税费用的定义。如果主体选择将与企业合并相关的利得和损失在单一报表项目中列报，则因企业合并产生的税务补偿资产变动应反映在该单列项目中，并附以恰当的附注披露。

<a id="s216-chap_29_navPoint_idm494901784"></a>
#### 比较信息

<a id="s216-chap_29_navPoint_idm494904728"></a>
##### <a id="s216-FAQ_29.244.2"></a>FAQ 29.244.2 – 在企业合并中，对比较信息的披露有哪些要求？

准则索引：IAS 1 第38段   
正文索引：[29.244](50.md#s214-Para_29.244)   

**问题**

在企业合并中，对比较信息的披露有哪些要求？

**解答**

IFRS 3并未提及是否应当提供有关企业合并的比较信息，因为该准则并未专门涉及比较信息的披露。我们认为，IFRS 3的披露要求适用于当期发生的企业合并。这意味着，在合并后的期间内，无需重复进行IFRS 3的披露。例如，这适用于IFRS 3第B64段中的披露，包括资产和负债的公允价值以及合并后业绩的披露。然而，在当期仍需就以前期间的企业合并提供某些披露，包括披露与过往企业合并相关的任何计量期间调整。

<a id="s216-chap_29_navPoint_idm494885016"></a>
#### 收购当期及后续期间的利得和损失

<a id="s216-chap_29_navPoint_idm494888600"></a>
##### <a id="s216-FAQ_29.244.3"></a>FAQ 29.244.3 – 对合并后利得和损失的披露有哪些要求？

准则索引：IFRS 3 第B67(e)段   
正文索引：[29.244](50.md#s214-Para_29.244)   
**问题**

对合并后利得和损失的披露有哪些要求？

**解答**

在收购后首个期间披露的被收购业务业绩，可能并不完全代表该等业务的持续业绩。例如，这些业绩可能受到购买方在收购后不久引入的变更的影响。IFRS 3要求购买方披露当期确认的符合以下条件的任何利得或损失的金额及其说明：

- 与当期或以前期间实现的企业合并中所取得的可辨认资产或所承担的负债相关；以及

- 其金额、性质或发生频率使该披露与理解合并后主体的财务业绩相关。

该披露适用于每项重大的企业合并，或者汇总适用于单项不重大但合计重大的企业合并。上述披露要求与IAS 1中单独披露重大收益和费用项目的性质和金额的要求一致。项目的金额或性质，或两者的结合，均可决定该项目是否重大。参见[第4章第33段](10.md#s28-Para_4.33)。

IFRS 3并未举例说明哪些情形可能需要作出此类披露。以下情形可能需要予以披露：

- 因收购时将存货重估至公允价值而导致的异常交易毛利。

- 因购买方将亏损长期合同扭转为盈利合同而产生的重大利得。

- 因或有资产或或有负债最终实现金额与其所分摊的公允价值不同而产生的重大利得或损失。

- 处置在企业合并中取得但未被持续经营集团保留的非流动资产所产生的利得。

IFRS 3并未具体要求披露因对被收购业务进行重组、重构和整合而发生的合并后费用。此类费用可能需要根据IAS 19或IAS 37的要求予以披露。如果未落入具体准则范围，此类费用若属重大，则须按照IAS 1单独披露。IAS 1第98段将主体经营活动的重组列为需要单独披露的情形之一。

### 资产收购

<a id="s216-chap_29_navPoint_idm494870680"></a>
#### <a id="s216-FAQ_29.247.1"></a>FAQ 29.247.1 – 公司应如何确定资产收购的成本？

准则索引：IFRS 3 第2(b)段   
正文索引：[29.247](50.md#s214-Para_29.247)   

**问题**

公司应如何确定资产收购的成本？

**解答**

IFRS 3未就如何确定收购一组资产的成本提供具体指引。一般而言，交易成本按转移对价的公允价值计量。这将包括向出售方支付的现金以及所承担的任何金融负债的公允价值（[进一步参见第29.47段及后续段落](50.md#s208-Para_29.47)）。IAS 2、IAS 16、IAS 38和IAS 40等准则将交易费用计入总体成本的一部分。在购买一组资产时，与资产会计处理相关的交易费用通常计入交易成本。如果发行了权益工具，则可能适用IFRS 9（IAS 39）和IFRS 2的计量原则。

非货币性资产可能作为交易对价的一部分进行交换。以一项或多项非货币性资产交换取得的项目的成本，通常按公允价值计量，除非适用特定例外情形。（参见[第22章第37段](39.md#s142-Para_22.37)。）

#### <a id="s216-EX29.247.2"></a>EX 29.247.2 – 资产收购的计量

准则索引：IFRS 3 第2(b)段   
正文索引：[29.247](50.md#s214-Para_29.247)   

**示例**

某主体以C1,000现金和一处仓库设施换取了一台定制专用机器和一项专利权。仓库设施的公允价值为C600，账面价值为C100。专用机器和专利权的公允价值分别估计为C750和C1,250。该专用机器和专利权与一项近期实现商业化的产品相关。该产品的市场尚处于发展阶段且存在不确定性。

假定该主体未发生任何交易费用。本例忽略相关利得的税务影响。该交易应如何进行会计处理？

资产收购的成本根据所付出资产的公允价值确定，除非所取得资产的公允价值能够更可靠地确定。

该主体得出结论认为，仓库设施的公允价值计量比专用机器和专利权的公允价值估计更为可靠。所付出对价的公允价值根据各项资产的相对估计公允价值分摊至单项资产。因此，该主体将收购专用机器和专利权的成本记录为C1,600（即转移对价的公允价值总额）。该主体就仓库设施的公允价值与账面价值之间的差额确认C500的利得。专用机器和专利权按其相对公允价值入账。记录该交易的会计分录如下：

#### <a id="s216-FAQ_29.247.3"></a>FAQ 29.247.3 – 企业合并与资产收购在会计处理上有哪些较常见的差异？

准则索引：   
正文索引：[29.247](50.md#s214-Para_29.247)   

**问题**

企业合并与资产收购在会计处理上有哪些较常见的差异？

**解答**

下表说明了企业合并与资产收购在会计处理上产生差异的较常见领域（请注意，本表并非旨在涵盖所有会计差异）：

<table style="width:100%; border-collapse:collapse"><thead><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top; background-color:#e5e5e5"><p style="background-color:transparent"><b>主题</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top; background-color:#e5e5e5"><p style="background-color:transparent"><b>企业合并</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top; background-color:#e5e5e5"><p style="background-color:transparent"><b>收购一组资产</b></p></td></tr></thead><tbody><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><b>资产和负债的计量</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">按公允价值入账。</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">按成本入账。成本根据购买日各项可辨认资产和负债的相对公允价值分摊至单项可辨认资产和负债。</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><b>无形资产（包括商誉）</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">如果无形资产符合可辨认标准，则按公允价值确认。商誉确认为一项单独的资产[IFRS 3 第13段]。[IFRS 3 第32段]。</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">无形资产参照其相对公允价值，根据交易总成本的分摊结果进行确认和计量。不确认商誉。</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><b>用于研发活动的无形资产（称为“正在进行中的研发项目”或IPR&amp;D）</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">企业合并中取得的IPR&amp;D使用市场参与者假设按公允价值计量，并资本化为尚未可供使用的资产。资本化的研发资产在未来期间将计提减值或进行摊销，具体取决于购买方在合并后期间使用所取得研发成果的能力。</p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent">如果与资产相关的预期未来经济利益很可能流入主体且其公允价值能够可靠计量，购买方将IPR&amp;D项目确认为一项资产。对于单独取得的IPR&amp;D资产，可能性标准始终被视为已满足[IAS 38 第25段]。</p></td></tr><tr><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt; vertical-align:top"><p style="background-color:transparent"><b>或有负债</b></p></td><td style="border:0.75pt solid #000000; padding-right:5.03pt; padding-left:5.03pt;
