## 引言与范围（第31.1段 - 第31.8段）

 

<a id="s224-Para_31.1"></a>**31.1** 对联营企业和合营企业的投资按照 IAS 28 规定的权益法进行会计处理，但某些例外情形除外。联营企业是指投资方对其具有重大影响的被投资方。合营企业是指投资方对其实施共同控制，但并不对资产享有直接权利或对负债承担直接义务的合营安排（参见[第32章第25段](57.md#s231-Para_32.25)）。相关披露要求在 IFRS 12 中予以规定（参见[第31.84段](56.md#s227-Para_31.84)）。

 

<a id="s224-chap_31_navPoint_2"></a>
### 范围

<a id="s224-Para_31.2"></a>**31.2** 投资方采用权益法核算其在合营企业和联营企业中的权益。

<a id="s224-chap_31_navPoint_3"></a>
### 免于采用权益法的例外情形

 

<a id="s224-Para_31.3"></a>**31.3** 除非符合以下情形之一，否则对联营企业或合营企业的投资必须按照 IAS 28 采用权益法核算：

- 该投资按照 IFRS 5 分类为持有待售。[IAS 28 第20段]。

- 报告主体属于免于编制合并财务报表或经济利益财务报表的母公司。[IAS 28 第17段]。

- 对联营企业或合营企业的投资由以下机构持有（或通过以下机构间接持有）：

- 风险投资机构；或

- 共同基金、单位信托及类似主体（包括投资连结保险基金）。

如果上述第三项中的投资按照 IFRS 9（IAS 39）以公允价值计量且其变动计入损益，则可适用免于采用权益法的豁免。参见[第42章第7段](63.md#s265-Para_42.7)。主体可在初始确认时对每一项联营企业或合营企业单独作出该项选择。

[IAS 28 第18段]。[IAS 28 第19段]。

<a id="s224-Para_31.4"></a>**31.4** 投资方对分类为持有待售的联营企业或合营企业，应当按照分类为持有待售之日的账面价值与公允价值减去出售费用后的净额两者孰低进行计量。一旦联营企业或合营企业被分类为持有待售，即停止采用权益法核算。有关处置的进一步内容，请参见[第30章第68段](53.md#s220-Para_30.68)。

<a id="s224-chap_31_navPoint_4"></a>
### 免于编制合并财务报表或经济利益财务报表

 

<a id="s224-Para_31.5"></a>**31.5** 某些母公司以及对子公司、联营企业或合营企业拥有投资的投资方，可以豁免编制合并财务报表或经济利益财务报表的要求。因此，这些母公司和投资方无需对其权益进行合并及采用权益法核算。参见[第26章第11段](45.md#s169-Para_26.11)。

[IAS 28 第17段]。

<a id="s224-Para_31.6"></a>**31.6** 非母公司但对联营企业或合营企业拥有投资的主体，必须编制在权益法核算基础上包含该联营企业或合营企业的财务报表。本章将该类财务报表称为“经济利益”财务报表。

[IAS 28 第16段]。

<a id="s224-Para_31.7"></a>**31.7** 如果满足特定条件，仅对联营企业或合营企业拥有投资的主体可以豁免编制“经济利益”财务报表的要求。这些条件（必须同时满足）包括：

- 该主体是另一主体的全资子公司或部分持股子公司，且其其他所有者已被告知且不反对该主体不采用权益法。

- 该主体的债务工具或权益工具未在公开市场交易，且该主体未在公开市场备案发行任何类别的金融工具，也未处于备案发行过程中。

- 该主体的最终母公司或任何中间母公司编制了可供公众使用的、符合国际财务报告准则（IFRS）的合并财务报表。

[IAS 28 第17段]。

[FAQ 31.7.1 – 免于编制合并财务报表或经济利益财务报表的适用条件](56.md#s228-FAQ_31.7.1)  
[FAQ 31.7.2 – 该豁免是否适用于经济利益财务报表？](56.md#s228-FAQ_31.7.2)

<a id="s224-Para_31.8"></a>**31.8** 免于编制经济利益财务报表的主体将其“单独”财务报表作为其唯一的财务报表。单独财务报表采用成本法、按照 IFRS 9（IAS 39）或采用本章所述的权益法对子公司、联营企业和合营企业进行核算。有关单独财务报表的进一步内容，请参见[第28章第3段](49.md#s198-Para_28.3)。

[IAS 27 第10段]。

## 联营企业或合营企业的分类与计量（第31.9段 - 第31.39段）

<a id="s225-chap_31_navPoint_6"></a>
### 重大影响与共同控制

 

<a id="s225-Para_31.9"></a>**31.9** 联营企业是指投资方对其具有重大影响的被投资方。重大影响是指参与决策的权力，但并不构成控制或共同控制。合营企业是指合营方对其实施共同控制且对该合营安排的净资产享有权利的合营安排。投资方采用权益法核算其在联营企业和合营企业中的权益。有关共同控制及合营安排分类的讨论，请参见[第32章第29段](57.md#s231-Para_32.29)。

[IAS 28 第3段]。

<a id="s225-Para_31.10"></a>**31.10** 投资方直接或间接持有另一主体 20% 或以上表决权的，推定其对该主体具有重大影响。当主体能够证明其具有或不具有重大影响时，持有 20% 或以上投资即具有重大影响的推定可以被推翻。同样，对于持股比例低于 20% 的投资，也可能证明存在重大影响。另一主体拥有实质性或多数所有权，并不必然排除投资方具有重大影响。

[IAS 28 第5段]。

[FAQ 31.10.1 – 什么是表决权的概念？](56.md#s228-FAQ_31.10.1)

<a id="s225-Para_31.11"></a>**31.11** 主体可以通过以下方式证明其对一项投资具有重大影响：

- 在被投资方的董事会或类似权力机构中派有代表。

- 参与政策制定过程，包括参与股利或其他分配决策。

- 主体与被投资方之间发生重要交易。

- 管理人员互换。

- 提供关键技术信息。

[IAS 28 第6段]。

<a id="s225-chap_31_navPoint_7"></a>
### 潜在表决权

 

<a id="s225-Para_31.12"></a>**31.12** 在评估主体是否具有重大影响时，应当考虑当期可执行或当期可转换的潜在表决权（包括其他主体持有的潜在表决权）的存在及其影响。当主体拥有认股权证、股票看涨期权、可转换为普通股的债务工具或权益工具，或其他类似工具，且这些工具（在行权或转换时）有可能赋予主体对另一主体财务和经营政策的额外表决权或降低另一方的相对表决权时，即存在潜在表决权。

[IAS 28 第7段]。

### 权益法下的计量

<a id="s225-chap_31_navPoint_9"></a>
### 权益法概述

 

<a id="s225-Para_31.13"></a>**31.13** 权益法在资产负债表中以单行项目列报对联营企业或合营企业的投资。该投资初始按成本确认，其后根据投资方应享有联营企业或合营企业净资产的收购后变动份额（“应享有经营成果份额”）进行调整。

[IAS 28 第3段]。

<a id="s225-Para_31.14"></a>**31.14** 权益法概述如下：

- 该投资作为单行项目列报，初始按成本确认（参见[第31.22段](56.md#s225-Para_31.22)）。

- 类似于企业合并会计处理，进行名义（模拟）收购对价分摊，以确认任何必要的公允价值调整（参见第31.37段）。

- 投资方在利润表中确认其当期应享有联营企业或合营企业的损益份额，并相应调整该投资的账面价值。

- 投资方应享有的损益份额应根据初始确认时名义（模拟）收购对价分摊产生的公允价值调整的影响，以及为统一会计政策所作的任何调整进行调整。

- 对逆流交易和顺流交易产生的任何未实现利润或损失作出适当调整。

- 从联营企业或合营企业收到的任何分配均冲减该投资的账面价值。

- 投资方直接在其其他综合收益中确认其应享有联营企业或合营企业的其他综合收益份额。计入其他综合收益的金额可能源自例如不动产、厂场和设备的重估、设定受益净负债的重新计量或外币折算差额。

- 当存在 IAS 28 第41A段至第41C段（原 IAS 39）所述的减值迹象时，采用 IAS 36 中的计量指引对联营企业和合营企业投资进行减值测试。

- 当不再具有重大影响或共同控制时，停止采用权益法核算。

[IAS 28 第10段]。

[FAQ 31.14.1 – 权益法基本原则的应用](56.md#s228-FAQ_31.14.1)  
[FAQ 31.14.2 – 权益法调整的类型](56.md#s228-FAQ_31.14.2)  
[FAQ 31.14.3 – 获取联营企业财务信息受限的影响](56.md#s228-FAQ_31.14.3)

<a id="s225-Para_31.14.1"></a>**31.14.1** 在某些情况下，投资方的联营企业或合营企业可能发生不影响损益或其他综合收益的净资产变动。IAS 28 对此类交易未作明确规定。2012年，国际会计准则理事会（IASB）将此议题作为一项单独修订（而非年度改进项目）列入议程。由于赞成该修订的票数不足，IASB 决定不再推进该修订，并可能根据权益法会计研究项目的结果重新考虑该问题。

### 分拆计量会计处理

 

<a id="s225-Para_31.15"></a>**31.15** 投资方可能通过风险投资机构，或共同基金、单位信托及类似主体间接持有其在联营企业中的权益（或部分权益）。投资方可以选择按照 IFRS 9（IAS 39）将该部分权益以公允价值计量且其变动计入损益（参见第31.3段）。即使投资方对该投资具有重大影响，仍可采用该处理方法。其余投资则采用权益法核算。

[IAS 28 第19段]。

<a id="s225-chap_31_navPoint_11"></a>
### 权益法的初始确认与应用

 

<a id="s225-Para_31.16"></a>**31.16** 权益法核算自一项投资成为联营企业或合营企业之日起开始。权益法所采用的许多程序与 IFRS 3 下的购买法会计处理及 IFRS 10 下的合并程序相同。

[IAS 28 第32段]。

<a id="s225-Para_31.17"></a>**31.17** 对联营企业或合营企业的投资初始按成本确认。投资方可以通过多种方式取得其在联营企业或合营企业中的权益，每种方式均会影响初始确认时成本的确定。对联营企业或合营企业的权益可能通过以下方式取得：

- 以现金或其他金融资产换取；

- 通过非货币性资产交换，包括在设立联营企业或合营企业时向其投入资产；

- 通过丧失对一项业务的控制权并保留赋予投资方重大影响或共同控制的权益；或

- 通过增持现有股权，从而使投资方获得重大影响或共同控制（分步收购）。

[FAQ 31.17.1 – 取得股权的方式](56.md#s228-FAQ_31.17.1)

<a id="s225-Para_31.18"></a>**31.18** 投资成本与投资方应享有被投资方可辨认资产和负债公允价值份额之间的任何差额，按以下方式进行会计处理：

- 与联营企业或合营企业相关的名义商誉包含在该投资的账面价值中。

- 廉价购买利得或负商誉（即“主体应享有联营企业可辨认资产和负债公允价值净额的份额超过投资成本的部分”）在取得该投资的当期计入投资方应享有联营企业或合营企业损益的份额。

[IAS 28 第32段]。

<a id="s225-Para_31.19"></a>**31.19** 在初始确认时确认廉价购买利得后，对联营企业或合营企业投资的账面价值将高于其成本。账面价值超过市场价格属于 IAS 28 下的减值迹象。因此，在确认廉价购买利得后，应对联营企业或合营企业投资进行减值测试。

[IAS 28 第41C段]。

 

<a id="s225-chap_31_navPoint_12"></a>
### 向联营企业或合营企业提供的长期贷款

 

<a id="s225-Para_31.20"></a>**31.20** 投资方可能对联营企业或合营企业拥有其他金融权益，这些权益在实质上构成对联营企业或合营企业净投资的组成部分。此类权益可能采取不同的法律形式，例如优先股、长期应收款以及既无结算计划也不大可能在可预见的未来结算的贷款。此类长期权益是对联营企业或合营企业净投资的组成部分，但应按照 IFRS 9（IAS 39）而非权益法进行会计处理。

[IAS 28 第38段]。

<a id="s225-Para_31.21"></a>**31.21** 长期权益由投资方按照 IFRS 9（IAS 39）以公允价值初始确认为金融资产，并按照该准则进行后续计量。

[IAS 28 第14段]。[IAS 28 第14A段]。

<a id="s225-chap_31_navPoint_13"></a>
### 初始确认时的成本

<a id="s225-Para_31.22"></a>**31.22** 准则并未定义成本，但通常理解为购买方支付的现金或其他对价的公允价值。在 IFRS 的大多数资产准则中，成本包含交易费用。因此，在初始确认时将此类费用计入对联营企业或合营企业投资的成本是合理的。

[IAS 28 第10段]。

<a id="s225-chap_31_navPoint_14"></a>
### 以现金或其他金融资产收购联营企业或合营企业

 

<a id="s225-Para_31.23"></a>**31.23** 对联营企业或合营企业投资在初始确认时的成本通常包含按公允价值估计的任何或有对价。或有对价是指金额不确定或支付取决于未来事项结果的应付给卖方的额外对价。最常见的或有对价形式是购买方同意在被收购公司达到特定业绩水平时以现金或股份支付额外对价（有关或有对价安排的指引，请参见第29章第62段）。

[IAS 28 第10段]。

<a id="s225-Para_31.24"></a>**31.24** 投资方对于或有对价在结算前价值的后续变动拥有会计政策选择权。投资方可以类比收购资产时的可变对价（参见[第22章第32段](39.md#s142-Para_22.32)），采用成本累积法，将或有对价的所有变动均调整对联营企业或合营企业的投资。或者，投资方可以类比适用 IFRS 3，将或有对价的所有变动均计入利润表（参见第29章第218段）。

[FAQ 31.24.1 – 联营企业投资成本的确定及或有对价的处理](56.md#s228-FAQ_31.24.1)

 

<a id="s225-chap_31_navPoint_15"></a>
### 投入资产或业务

 

<a id="s225-Para_31.25"></a>**31.25** 投资方可能在设立联营企业或合营企业时向其投入资产或业务。投资方也可能丧失对一项业务的控制权并保留对联营企业或合营企业的权益。这些在经济上属于相似的交易。除换取联营企业或合营企业的股权外，投资方还可能因投入资产而从其他投资方处收取额外对价（现金或其他资产）。投入或处置资产与投入或处置业务的会计处理有所不同。在投入业务时，投资方还拥有进一步的会计政策选择权。进一步讨论请参见[第31.27段](56.md#s225-Para_31.27)。

[IAS 28 第31段]。

<a id="s225-Para_31.26"></a>**31.26** 主体投入非货币性资产（不构成业务）以换取联营企业或合营企业股权的，仅就无关联第三方享有的权益份额确认交易产生的利得或损失。与第三方进行的交换推定具有商业实质。如果缺乏商业实质，则任何利得或损失均属于未实现（有关商业实质的说明，请参见[第22章第38段](39.md#s142-Para_22.38)）。对联营企业或合营企业投资的成本等于所投入资产的成本加上已确认部分的利得或损失，再加上任何交易费用或或有对价。

[IAS 28 第28段]。

<a id="s225-Para_31.27"></a>**31.27** 主体可能向合营企业或联营企业投入一项受其控制的业务，或者减持其在一项受控业务中的股权使其变为对联营企业或合营企业的投资。关于此类交易的会计处理，IFRS 10 与 IAS 28 的要求之间存在冲突。这一公认的冲突产生了会计政策选择权。

[IAS 28 第31段]。

<a id="s225-Para_31.28"></a>**31.28** IFRS 10 要求对保留的联营企业或合营企业权益按公允价值重新计量，并将处置利得和持有期间利得均计入利润表。IAS 28 则要求按投资方享有的权益份额抵销投资方与其联营企业或合营企业之间产生的利得。因此，投资方可以选择采用 IAS 28 的方法确认部分利得，或者采用 IFRS 10 的方法确认全部利得。所选会计政策应对类似交易一贯适用，并予以清晰披露。

[IAS 28 第30段]。

<a id="s225-Para_31.29"></a>**31.29** IASB 已发布对 IFRS 10 和 IAS 28 的修订，以解决上述冲突并明确：投资方在投入业务时应确认全部利得或损失，而在投入不符合业务定义的资产时应确认部分利得或损失。该修订可供主体采用，但 IASB 已无限期推迟该修订的强制生效日期，以待其关于权益法的研究项目最终完成。

[IAS 28 第31A段]。

### 由投资分步收购形成联营企业或合营企业

<a id="s225-Para_31.30"></a>**31.30** 分步收购联营企业或合营企业（即分步收购）存在会计政策选择权。进一步讨论请参见[第31.31段](56.md#s225-Para_31.31)。投资方可以采用成本法，将所有购买批次的成本（包括交易费用）累积以确定该投资的金额。或者，投资方可以采用公允价值作为认定成本的方法，在该投资成为联营企业或合营企业之日将其原持有的投资重估至公允价值。对联营企业投资的成本等于新收购股权所支付对价的公允价值加上原持有投资的公允价值。第二种方法系类比 IFRS 3，交易费用不计入以公允价值作为认定成本的金额（参见第29章第166段）。

### 增持现有联营企业股权且仍保持重大影响

 

<a id="s225-Para_31.32"></a>**31.32** 投资方增持现有联营企业或合营企业股权且仍保持重大影响的，采用成本累积法进行会计处理。收购新增股权的成本（包括任何直接归属的费用）计入该联营企业的账面价值。新增股权的名义公允价值（包括因购买新增股权产生的名义商誉）应当采用取得新增权益之日的公允价值信息进行计算。由于投资的性质未发生变化，不对原持有权益进行公允价值调增或重新计量。同样原则适用于联营企业股权转变为合营企业投资的情形。（有关确定共同控制的进一步讨论，请参见[第32章第23段](57.md#s231-Para_32.23)。）

[IAS 28 第24段]。

<a id="s225-Para_31.32.1"></a>**31.32.1** 当投资方新增享有的被投资方可辨认资产和负债公允价值净额份额超过收购新增股权的成本时，可能会产生廉价购买（有时称为名义负商誉）。当先前收购已产生名义商誉并包含在该廉价购买前投资的账面价值中时，IAS 28 对此次廉价购买的会计处理并未作出明确规定。我们认为，对于收购新增股权产生的廉价购买，存在两种可接受的会计处理方法：

- 将分批收购中产生的任何廉价购买视为一项单独的计量单元。在此情况下，收购新增股权产生的廉价购买单独计入损益[IAS 28 第32段]。

- 或者，构成对联营企业净投资账面价值组成部分的名义商誉并不单独确认。因此，包含在联营企业投资中的任何名义商誉构成一个单一的计量单元。收购新增股权产生的廉价购买代表该单一资产（即包含在联营企业中的名义商誉）累计成本的减少。任何廉价购买应首先从先前名义商誉的账面价值中扣减。扣减后如仍有净廉价购买利得，则将该净廉价购买利得计入损益。[IAS 28 第42段]。

所选择的会计政策应当一贯适用。

### 联营企业转变为子公司

 

<a id="s225-Para_31.33"></a>**31.33** 主体取得对现有联营企业或合营企业的控制权时，可能是分步收购一项业务或一项资产。当收购一项业务时，主体应适用 IFRS 3 的要求（参见第29章第166段）。对于取得对不符合 IFRS 3 业务定义的现有联营企业或合营企业的控制权的情形，准则并无具体指引。我们认为，该资产可按以下两种方式之一进行初始确认：

- 将原持有权益重新计量至公允价值；或

- 采用成本累积法。

[IFRS 3 第41段]。[IAS 28 第22(a)段]。

### 减持现有联营企业股权且仍保留重大影响

<a id="s225-Para_31.34"></a>**31.34** 投资方可能减少其在联营企业或合营企业中的所有权权益，但仍保留重大影响或共同控制。投资方应终止确认相应比例的账面价值，并根据相关资产或负债处置时储备应当如何重分类的规定，将先前计入其他综合收益的利得或损失按相应比例重分类至损益或在权益内部结转。例如，与境外经营联营企业或合营企业相关的、先前计入其他综合收益的任何累计汇兑差额，在投资方停止采用权益法时重分类至损益。同样，先前计入其他综合收益的任何重估盈余（在资产处置时将直接转入留存收益），应按该联营企业已处置的比例直接转入留存收益。

### 名义（模拟）收购对价分摊

 

**3**<a id="s225-Para_1.37"></a>**1.37** 投资方应当进行“名义（模拟）”收购对价分摊，如同收购一项业务一样辨认并评估联营企业或合营企业的资产和负债。由于投资本身以单行项目列报，这些公允价值调整并不单独入账。但是，所确定的公允价值构成后续年度在投资方应享有经营成果份额中反映的额外折旧、摊销及类似调整的基础。名义（模拟）收购对价分摊中的调整包括联营企业或合营企业未确认的资产（例如内部研发的无形资产、自然资源储量及类似资产）。也可能需要作出调整，以确认被投资方按成本计量的资产（例如不动产、厂场和设备）的公允价值，以及按适当金额确认负债。

## 联营企业或合营企业的份额（第31.40段 - 第31.75段）

 

<a id="s226-Para_31.40"></a>**31.40** 投资方记录其应享有每家联营企业或合营企业经营成果的份额。当投资方仅在联营企业或合营企业中持有单一投资（即一定数量的普通股），且不存在其他已发行股份类别或潜在表决权时，应核算的“份额”可能较为直接。然而，集团其他成员的持股、潜在表决权、交叉持股及类似问题可能会使确定投资方应享有的经营成果“份额”变得复杂。集团在联营企业或合营企业中的份额是母公司及其子公司在该项投资中持股的总和，不考虑通过其他联营企业或合营企业持有的任何股份。投资方需要确定其拥有联营企业或合营企业的何种“份额”，以便应用权益法。

### 优先股对享有经营成果份额的影响

<a id="s226-Para_31.41"></a>**31.41** 联营企业或合营企业可能发行优先股。优先股需分类为金融负债、权益工具或同时包含负债成分和权益成分的复合工具。分类基于合同安排的实质。若分类为权益工具，将对投资方的权益法核算产生影响。

[IAS 28 第37段]。

<a id="s226-Para_31.42"></a>**31.42** 对于由投资方以外的其他方持有的、分类为权益的优先股股利，无论该股利是否已宣告发放，投资方在计量其应享有联营企业或合营企业的损益份额时，均应从联营企业或合营企业的损益中予以扣除。在投资方未持有该优先股的范围内，其无权享有在名义上“用于”支付优先股股利的税后经营成果份额。

[IAS 28 第37段]。

<a id="s226-Para_31.43"></a>**31.43** 分类为负债的优先股股利列示为利息。投资方应享有联营企业经营成果的份额应在扣除优先股股利后确定，并仅基于投资方的权益份额。

[IAS 28 第37段]。

<a id="s226-chap_31_navPoint_26"></a>
### 期权、认股权证和可转换债券对享有经营成果份额的影响

 

<a id="s226-Para_31.44"></a>**31.44** 主体在联营企业或合营企业中持有的潜在表决权（例如认股权证、期权和可转换工具），在确定主体是否具有重大影响时应当予以考虑。但是，在确定投资方应享有联营企业或合营企业净资产和损益的比例时，不考虑这些潜在表决权，除非它们构成现时所有权权益。

[IAS 28 第12段]。

<a id="s226-Para_31.45"></a>**31.45** 投资方可能在实质上拥有联营企业或合营企业中的一项权益，使其能够获取与所有权权益相关的回报。分配给主体的经营成果份额应在考虑潜在表决权以及其他当前赋予主体获取回报权利的衍生工具的最终行权后予以确定。

[IAS 28 第13段]。

<a id="s226-Para_31.46"></a>**31.46** 如果投资方在其应享有的经营成果份额中计入了来自潜在表决权的回报，则产生这些权利的工具不再适用 IFRS 9（IAS 39）的要求。投资方已在权益法下计入了高于其现有股权持股比例的联营企业或合营企业经营成果份额。投资方不同时对持有的联营企业相关工具按公允价值计量以反映其市场价值的增加。行使潜在表决权的成本也应予以考虑，并就增持的股权计算任何名义商誉。

[IAS 28 第14段]。

### 向投资方发行的复合工具对享有经营成果份额的影响

### 调整联营企业或合营企业报告的“经营成果”

<a id="s226-chap_31_navPoint_30"></a>
### 一致的会计政策

<a id="s226-Para_31.49"></a>**31.49** 投资方应在适用时调整其联营企业或合营企业的经营成果，以使被投资方的会计政策与投资方自身的会计政策保持一致。非投资性主体但持有投资性主体联营企业或合营企业权益的，可以选择保留该联营企业或合营企业对其子公司权益采用的公允价值计量。该选择应针对每一家投资性主体联营企业或合营企业单独作出，并在以下日期中的最晚者作出：（a）初始确认该投资性主体联营企业或合营企业之日；（b）该联营企业或合营企业成为投资性主体之日；以及（c）该投资性主体联营企业或合营企业首次成为母公司之日。

### 投资方与其联营企业或合营企业之间的交易

<a id="s226-chap_31_navPoint_34"></a>
### 包含在资产中的利润和损失

 

<a id="s226-Para_31.53"></a>**31.53** 投资方可能向其联营企业或合营企业出售资产（即顺流交易）。联营企业或合营企业也可能向其投资方或投资方合并集团的其他成员出售资产（即逆流交易）。逆流交易和顺流交易产生的任何未实现利润和损失，均应按主体在联营企业中享有的权益份额予以抵销。逆流交易或顺流交易中已转售给第三方的任何资产均已实现，因此抵销仅涉及仍由投资方或被投资方持有的资产。

<a id="s226-chap_31_navPoint_35"></a>
### 未实现利得超过联营企业或合营企业的账面价值

 

<a id="s226-Para_31.54"></a>**31.54** 顺流交易中的未实现利得冲减对联营企业或合营企业的投资。如果顺流交易中的未实现利得超过该投资的账面价值，则将该投资的账面价值减记至零，且不对超出部分调整联营企业或合营企业的账面价值。

[IAS 28 第28段]。[IAS 28 第39段]。

<a id="s226-Para_31.54.1"></a>**31.54.1** 2013年1月，国际财务报告准则解释委员会（IFRS IC）审议了合营方与其合营企业之间的“顺流”交易中未实现利得超过主体对该合营企业投资账面价值的情形。IFRS IC 建议理事会对 IAS 28 进行窄范围修订以解决这一问题。

在2013年7月的讨论中，理事会考虑了对 IAS 28 作出如下修订：

（a）主体应按其在联营企业或合营企业中的权益份额抵销“顺流”交易产生的利得，即使应抵销的利得超过了主体对该联营企业或合营企业投资的账面价值；以及  
（b）超出主体对该联营企业或合营企业投资账面价值的剩余应抵销利得，应列报为递延利得。

然而，该项工作于2015年暂停，以待 IFRS 10、IFRS 11 和 IFRS 12 的实施后审议结果完成。由于对此类情形尚无明确指引，我们认为存在两种可接受的会计处理方法，详见下文[第31.55段](56.md#s226-Para_31.55)、第31.56.1段及[第31.56.2段](56.md#s226-Para_31.56.2)。

<a id="s226-Para_31.55"></a>**31.55** 投资方可能通过抵销未实现利得，将联营企业或合营企业的账面价值减记至零。如果未实现利得超过了投资的账面价值从而未被抵销，投资方在向联营企业或合营企业出售资产之日，对于超出的未实现利得的处理拥有会计政策选择权。投资方可以将超出的未实现利得立即计入损益（处理方法1）。

<a id="s226-Para_31.56"></a>**31.56** 或者，投资方可以将超过投资账面价值的未实现利得在资产负债表中作为递延利得进行会计处理。即使该抵销产生了并不代表负债的贷方余额，亦是如此（处理方法2）。

**31.56.1 处理方法1****–** IAS 28 第39段解释称，仅在存在义务时，才就联营企业或合营企业的权益法亏损确认负债。因此，从投资方的角度看，在不存在义务时，未实现利得的抵销以投资的账面价值为限。据此，投资方可以将超出的未实现利得立即计入损益。其后，投资方可以选择在权益法核算的利润超过先前冲减投资账面价值的未实现部分之前，不确认其应享有的利润份额（处理方法1(a)）。或者，投资方可以继续确认其应享有的利润份额，并仅在联营企业或合营企业处置该资产时，将先前抵销的利得计入损益（处理方法1(b)）。任何投资余额均继续适用 IAS 36 的减值考量。有关减值的进一步指引，请参见[第31.61段](56.md#s226-Para_31.61)。

<a id="s226-Para_31.56.2"></a>**31.56.2** **处理方法2** **–** 根据理事会2013年的讨论，投资方将超过投资账面价值的未实现利得在资产负债表中作为递延利得进行会计处理。其后，随着投资方按权益法确认其应享有的当年利润份额，对联营企业的投资将增加。随后该递延利得将在资产负债表中与该投资相抵销。在联营企业出售与该递延利得相关的资产之前，该递延利得不影响损益；在出售该资产时，与该资产相关的递延利得将释放计入损益。

[FAQ 31.56.1 – 顺流交易：未实现利得的会计处理](56.md#s228-FAQ_31.56.1)

<a id="s226-Para_31.57"></a>**31.57** 顺流交易可能提供所出售或投入资产可变现净值下降或发生减值损失的证据。投资方应当立即全额确认这些损失。

[IAS 28 第29段]。

 

<a id="s226-chap_31_navPoint_36"></a>
### 集团内部往来交易

 

<a id="s226-Para_31.58"></a>**31.58** 联营企业和合营企业不构成集团的组成部分。抵销集团内部余额、交易、收入和费用（包括租赁）的程序在权益法下并不适用。正常经营交易产生的未结算余额应作为流动资产或流动负债列示，不应予以抵销。

[IAS 28 第28段]。

[FAQ 31.58.1 – 集团内部往来交易的会计处理](56.md#s228-FAQ_31.58.1)

 

<a id="s226-chap_31_navPoint_37"></a>
### 来自联营企业或合营企业的分配

<a id="s226-Para_31.59"></a>**31.59** 从联营企业或合营企业收到的分配冲减投资方记录的投资账面价值。

[IAS 28 第10段]。

<a id="s226-Para_31.60"></a>**31.60** 联营企业或合营企业派发的股利可能大于投资方账面上该投资的账面价值。投资的账面价值减记至零，但不变为负数。如果主体没有代表联营企业或合营企业付款的法定义务或推定义务，则就剩余股利在损益中确认一项利得。如果联营企业或合营企业在后续年度实现盈利，投资方拥有会计政策选择权：可以采用“追回法（clawback）”，也可以将利润立即计入其利润表（参见[第31.55段](56.md#s226-Para_31.55)和[第31.56段](56.md#s226-Para_31.56)）。

[IAS 28 第39段]。

[FAQ 31.60.1 – 来自联营企业的分配超过投资账面价值](56.md#s228-FAQ_31.60.1)

<a id="s226-chap_31_navPoint_38"></a>
### 减值

 

<a id="s226-Para_31.61"></a>**31.61** 当存在减值迹象时，应对联营企业和合营企业投资进行减值评估。减值迹象如 IAS 28 第41A段至第41C段（原 IAS 39）所述（参见[第31.64段](56.md#s226-Para_31.64)）。联营企业或合营企业的可收回金额按照 IAS 36 确定。除非符合[第31.62段](56.md#s226-Para_31.62)所述的特殊情形，否则应对每一家联营企业和合营企业投资的可收回金额单独进行评估。

[IAS 28 第43段]。

<a id="s226-Para_31.62"></a>**31.62** 单项联营企业和合营企业通常产生很大程度上独立的现金流量，并按单项基础进行减值测试。在特殊情况下，如果某联营企业或合营企业不能产生很大程度上独立的现金流量且其公允价值无法轻易确定，则应针对该联营企业或合营企业所属的现金产出单元确定可收回金额。这种情形在实务中可能较为罕见。

[IAS 36 第22段]。

<a id="s226-Para_31.63"></a>**31.63** 联营企业或合营企业发生亏损会导致投资方账面价值的持续减少。然而，亏损本身也可能是需要确认进一步减值的迹象。

[IAS 28 第40段]。

<a id="s226-Para_31.64"></a>**31.64** 联营企业或合营企业所处的技术、市场、经济或法律环境发生重大不利变化，可能提供该联营企业或合营企业权益可能已发生减值的客观证据。联营企业或合营企业的公允价值大幅或持久下跌至低于其成本，同样属于减值的客观证据。准则还识别了若干潜在的减值迹象，包括：

- 严重财务困难；

- 违反合同，如违约或逾期；

- 因被投资方发生财务困难，投资方给予联营企业或合营企业其在其他情况下不会考虑的让步；

- 联营企业或合营企业很可能破产或进行其他财务重组；或

- 联营企业或合营企业股份的活跃市场消失。

[IAS 28 第41C段，原 IAS 39 第61段]。

<a id="s226-Para_31.65"></a>**31.65** 如果有迹象表明投资方在联营企业或合营企业中的权益可能发生减值：

- 对联营企业或合营企业的全部账面价值（包括任何名义商誉）适用 IAS 36 的计量规则，以确定任何减值损失的金额。[IAS 28 第42段]。

- 对不构成净投资组成部分的联营企业或合营企业的任何其他权益（例如应收账款或贷款）适用 IFRS 9（IAS 39）的计量规则，以确定任何减值损失的金额。[IAS 28 第41段]。

<a id="s226-Para_31.66"></a>**31.66** 对联营企业投资的全部账面价值应与其可收回金额（即使用价值与公允价值减去处置费用后的净额两者中的较高者）进行比较。
[FAQ 31.66.1 – 计算可收回金额时的实务考量](56.md#s228-FAQ_31.66.1)

<a id="s226-Para_31.67"></a>**31.67** 产生的任何减值损失均不分摊至名义商誉和收购对价分摊项目，而是冲减投资整体。IAS 36 中关于商誉减值的一般规则不适用于名义商誉，因此先前的任何减值损失均可转回。权益法核算的应享有经营成果份额，既可以继续反映基于资产原公允价值的折旧调整，也可以反映基于经减值调整后的“减值后”公允价值的折旧。附注中应对所选择的会计政策作出说明。

[IAS 28 第32段]。

<a id="s226-Para_31.68"></a>**31.68** 联营企业或合营企业可能在其自身财务报表中确认了减值费用。投资方应核算其应享有的该减值费用份额，并就名义（模拟）收购对价分摊产生的公允价值差异影响进行调整。联营企业或合营企业记录的减值费用构成减值迹象，投资方如尚未对该联营企业或合营企业进行减值复核，则应予以复核。

[IAS 28 第41A段；原 IAS 39 第59段]。

<a id="s226-Para_31.69"></a>**31.69** 投资方不将联营企业或合营企业的减值损失分摊至构成合营企业账面价值的某项特定资产（或多项资产）。因此，如果满足 IAS 36 的条件，全部减值损失均有可能转回。该减值损失的任何转回均在投资可收回金额增加的范围内确认为对联营企业或合营企业投资的调整（参见[第24章第150段](41.md#s159-Para_24.150)）。

[IAS 28 第42段]。

<a id="s226-Para_31.70"></a>**31.70** 关于与联营企业或合营企业相关的减值费用在损益中的列报位置，准则并无明确指引。减值费用并非采用权益法的结果，因此不构成应享有联营企业和合营企业经营成果份额的组成部分。IAS 1 要求单独披露采用权益法核算的联营企业和合营企业损益份额。任何重大减值损失均应在权益法下应享有联营企业或合营企业经营成果份额的邻近位置列报。

[IAS 28 第40段]。[IAS 1 第82段]。[IAS 1 第85段]。

### 处置

<a id="s226-chap_31_navPoint_40"></a>
### 丧失重大影响

 

<a id="s226-Para_31.71"></a>**31.71** 当丧失重大影响或共同控制时，停止采用权益法核算。投资方可能因绝对或相对持股比例的变动、联营企业受政府、法院管理人或监管机构控制，或因合同协议而丧失重大影响或共同控制。如果投资方丧失对一项投资的共同控制但仍保留重大影响，则属于部分处置，不对保留权益按公允价值重新计量。

[IAS 28 第9段]。[IAS 28 第24段]。

[FAQ 31.71.1 – 关于丧失重大影响的实务考量](56.md#s228-FAQ_31.71.1)

 

<a id="s226-chap_31_navPoint_41"></a>
### 联营企业转变为投资

 

<a id="s226-Para_31.72"></a>**31.72** 投资方可能丧失重大影响或共同控制，但保留对该主体的投资。任何保留投资均应按该投资不再作为联营企业或合营企业之日的公允价值计量。该公允价值即为其按照 IFRS 9（IAS 39）初始确认为金融资产时的公允价值。

投资方应在损益中确认以下两项之间的任何差额：

“（i）任何保留权益的公允价值以及处置联营企业或合营企业部分权益取得的任何价款；与  
 （ii）终止采用权益法之日该投资的账面价值。”

[IAS 28 第22段]。

<a id="s226-Para_31.73"></a>**31.73** 按公允价值重新计量要求投资方对先前就该联营企业或合营企业计入其他综合收益的所有金额，视同该联营企业直接处置了相关资产或负债一样进行会计处理。当投资方丧失对联营企业的重大影响时，先前因对联营企业或合营企业投资而计入其他综合收益的任何利得或损失，如果相关资产或负债处置时该利得或损失将重分类至损益，则应重分类至损益。

[IAS 28 第23段]。

[FAQ 31.73.1 – 联营企业权益减持至一般投资](56.md#s228-FAQ_31.73.1)

 

<a id="s226-chap_31_navPoint_42"></a>
### 稀释利得和损失

 

<a id="s226-Para_31.74"></a>**31.74** 联营企业可能向其他投资方发行股份，从而稀释投资方的权益。这构成对投资方在联营企业中权益的部分处置。该投资可能仍为联营企业，或者投资方可能丧失重大影响而持有金融资产。因在联营企业或合营企业中持股比例降低而产生的稀释利得或损失应计入利润表（有关分步处置的进一步指引，请参见[第31.34段](56.md#s225-Para_31.34)和[第31.72段](56.md#s226-Para_31.72)）。稀释产生的任何损失均属于减值迹象，投资方应对任何剩余权益进行减值测试（参见[第31.61段](56.md#s226-Para_31.61)）。

[IAS 28 第25段]。

[FAQ 31.74.1 – 主体在联营企业中的持股被稀释](56.md#s228-FAQ_31.74.1)

 

<a id="s226-chap_31_navPoint_43"></a>
### 所得税

 

<a id="s226-Para_31.75"></a>**31.75** 对联营企业或合营企业的投资所产生的所得税按照 IAS 12 进行会计处理。该投资在合并财务报表中的账面价值与其计税基础之间可能产生暂时性差异。计税基础通常为成本或经指数调整的成本。该暂时性差异被称为“外部计税基础差异”。与该投资相关的暂时性差异可能由多种原因引起。最常见的原因是被投资方存在未分配利润，导致母公司对该被投资方的投资账面价值高于其计税成本。投资方无法控制联营企业的分配，也可能无法控制合营企业的分配。因此，很可能需要就外部计税基础差异确认递延所得税负债。进一步指引请参见[第14章第124段](27.md#s99-Para_14.124)。

[IAS 12 第42段]。

## 列报与披露（第31.76段 - 第31.101段）

<a id="s227-chap_31_navPoint_45"></a>
### 综合收益表或单独列报的利润表

 

<a id="s227-Para_31.76"></a>**31.76** 投资方应单独披露其应享有联营企业和合营企业的损益份额。但是，准则并未规定主体的该项份额应列示在综合收益表或利润表的何处，也未规定该份额是扣除联营企业所得税及非控制性权益之前还是之后的金额。

[IFRS 12 附录B 第B16段]。

<a id="s227-Para_31.77"></a>**31.77** IAS 1 规定了综合收益表或利润表表内列报的最低限度单行项目。投资方应享有采用权益法核算的投资的损益份额，列示在财务费用项目之后、所得税费用项目之前。准则中还提供了综合收益表和利润表的示例。一项脚注解释称，投资方应享有的利润份额是扣除采用权益法核算的投资的所得税及非控制性权益之后的金额。关于主体应享有联营企业损益份额列报的更多内容，请参见[第4章第102段](10.md#s29-Para_4.102)。

[IAS 1 第82段]。

<a id="s227-Para_31.78"></a>**31.78** 收购联营企业或合营企业产生的任何廉价购买利得（应享有资产和负债公允价值净额的份额超过收购成本的部分），在取得该投资的当期计入应享有联营企业和合营企业税后经营成果的份额。

[IAS 28 第32段]。

<a id="s227-Para_31.79"></a>**31.79** 持有待售的联营企业或合营企业可能符合终止经营的条件。投资方应享有的此类联营企业或合营企业经营成果的份额，按照 IFRS 5 中关于终止经营的指引进行披露。

[IFRS 5 第33段]。

### 其他综合收益

 

<a id="s227-Para_31.81"></a>**31.81** 投资方还应确认其应享有联营企业或合营企业其他综合收益或损失的份额。该要求适用于例如主体应享有的联营企业及合营企业在其其他综合收益中报告的任何重估盈余或汇兑差额的份额。主体应享有联营企业或合营企业其他综合收益或损失的份额，应分别列示后续不能重分类至损益的金额以及在满足特定条件时后续将重分类至损益的金额。IAS 1 提供了综合收益表的示例。[IAS 1 第IG6段]。进一步指引请参见[第4章第130段](10.md#s29-Para_4.130)。

[IAS 28 第10段]。[IAS 1 第82A段]。

### 现金流量表

<a id="s227-Para_31.82"></a>**31.82** 准则对联营企业或合营企业经营成果在现金流量表中的列报没有具体要求。关于现金流量的一般指引见 IAS 7。参见第7章。

<a id="s227-chap_31_navPoint_49"></a>
### 披露

<a id="s227-chap_31_navPoint_50"></a>
### 目标

<a id="s227-Para_31.84"></a>**31.84** 旨在帮助使用者了解报告主体的披露要求规定在 IFRS 12 中。该准则的目标是要求主体披露有助于财务报表阅读者评估与主体在子公司、联营企业、合营安排和未纳入合并范围的结构化主体中的权益相关的性质、风险和财务影响的信息。

[IFRS 12 第1段]。

<a id="s227-Para_31.85"></a>**31.85** 主体应当披露以下信息：

- 其在确定在另一主体或安排中的权益性质时作出的重大判断和假设；以及

- 有关其在合营安排和联营企业中的权益的信息。

IFRS 12 明确，除汇总财务信息的披露外（参见[第31.95段](56.md#s227-Para_31.95)），IFRS 12 的要求适用于 IFRS 5 范围内的主体权益，包括分类为持有待售或终止经营（或包含在分类为持有待售或终止经营的处置组中）的权益。

[IFRS 12 第2段]。[IFRS 12 第5A段]。

<a id="s227-chap_31_navPoint_51"></a>
### 汇总

<a id="s227-Para_31.86"></a>**31.86** 主体可以汇总或分解信息以实现披露目标。所披露的信息应在避免使财务报表充斥过多不重要细节与避免因过度汇总而掩盖信息之间取得平衡。

[IFRS 12 第4段]。[IFRS 12 附录B 第B2段]。

<a id="s227-Para_31.87"></a>**31.87** 如果符合披露目标，可以汇总披露在类似主体中的权益。如果进行了此类汇总，主体应披露其汇总在类似主体中权益的方式。在考虑汇总哪些主体时，报告主体应考虑定量和定性信息，以评估各主体不同的风险和回报特征以及各主体对报告主体的重要性。主体不应将具有不同特征的项目进行汇总。

[IFRS 12 第4段]。[IFRS 12 附录B 第B3段]。[IFRS 12 附录B 第B5段]。

<a id="s227-Para_31.88"></a>**31.88** 主体应分别列报在子公司、合营企业、共同经营、联营企业和未纳入合并范围的结构化主体中的权益信息。

[IFRS 12 附录B 第B4段]。

<a id="s227-Para_31.89"></a>**31.89** 单项不重大且采用权益法核算的合营企业或联营企业的账面价值应予以汇总。对于合营企业存在单独的披露要求。

[IFRS 12 附录B 第B16段]。

<a id="s227-chap_31_navPoint_52"></a>
### 重大判断和假设

<a id="s227-Para_31.90"></a>**31.90** 主体应披露其在确定以下事项时作出的重大判断和假设：

- 对一项安排具有共同控制或对另一主体具有重大影响；以及

- 通过单独主体构建的安排属于共同经营还是合营企业。

[IFRS 12 第7段]。

<a id="s227-Para_31.91"></a>**31.91** 当报告期间事实和情况的变化导致结论发生改变时，主体也应披露重大判断和假设。

[IFRS 12 第8段]。

<a id="s227-chap_31_navPoint_53"></a>
### 在合营安排和联营企业中的权益

 

<a id="s227-Para_31.92"></a>**31.92** 投资方必须披露其在合营安排和联营企业中权益的性质、程度和财务影响。

[IFRS 12 第21段]。

 

<a id="s227-chap_31_navPoint_54"></a>
### 汇总财务信息

 

<a id="s227-Para_31.93"></a>**31.93** 除其他要求的披露外，投资方必须披露其重要合营企业和联营企业的汇总财务信息，以及收到的所有股利和分配。

[IFRS 12 附录B 第B12段]。

<a id="s227-Para_31.94"></a>**31.94** 汇总财务信息源自合营企业或联营企业的财务报表，而不仅仅是投资方应享有的份额。所报告的金额应包含投资方就名义（模拟）收购对价分摊所记录的调整，以及因会计政策差异所作的任何调整。投资方应将汇总财务信息调节至投资方在该合营企业或联营企业中权益的账面价值。

[IFRS 12 附录B 第B14段]。

<a id="s227-Para_31.95"></a>**31.95** 如果在合营企业或联营企业中的权益按照 IFRS 5 分类为持有待售（或包含在分类为持有待售的处置组中），则无需披露汇总财务信息。分类为持有待售的合营企业和联营企业在资产负债表中与其他资产分开列报，并适用 IFRS 5 的披露要求。（进一步内容请参见[第30章第49段](53.md#s218-Para_30.49)。）

[IFRS 12 附录B 第B17段]。[IFRS 5 第38段]。

<a id="s227-Para_31.96"></a>**31.96** 如果投资方按照 IAS 28 以公允价值计量其在合营企业或联营企业中的权益，且该合营企业或联营企业未编制 IFRS 财务报表，并且按 IFRS 基础编制不可行或将导致过度成本，则汇总财务信息可以以该合营企业或联营企业的财务报表为基础进行列报。投资方应披露编制该汇总信息所采用的基础。

[IFRS 12 附录B 第B15段]。

 

<a id="s227-chap_31_navPoint_55"></a>
### 重大限制

<a id="s227-Para_31.97"></a>**31.97** 应当披露对合营企业或联营企业以股利或偿还贷款或预付款形式向主体转移资金的能力构成重大限制的任何法定、借款或合同限制的性质和程度。

[IFRS 12 第22(a)段]。

<a id="s227-chap_31_navPoint_56"></a>
### 合营企业和联营企业财务报表的报告日

 

<a id="s227-Para_31.98"></a>**31.98** 当任何联营企业或合营企业的报告期末或报告期间长度与投资方合并财务报表不同时，也需要进行披露。应披露该合营企业或联营企业的报告日，以及采用不同日期或报告期间的原因。

[IFRS 12 第22(b)段]。

 

<a id="s227-chap_31_navPoint_57"></a>
### 未确认亏损

<a id="s227-Para_31.99"></a>**31.99** 已停止确认其应享有合营企业或联营企业亏损份额的投资方，必须披露其当期以及累计（包括以前期间）未确认的合营企业或联营企业净亏损份额。

[IFRS 12 第22(c)段]。

<a id="s227-chap_31_navPoint_58"></a>
### 合营企业的承诺

<a id="s227-Para_31.100"></a>**31.100** 当合营企业存在将在未来导致现金或其他资源流出的承诺，且在报告日尚未确认时，存在额外的披露要求。投资方应披露此类未确认承诺的总额。

### <a id="s228-FAQ_31.3.2"></a>FAQ 31.3.2 – 与“风险投资”机构相关的实务问题

准则索引：IAS 28 第18、19段  
正文索引：[31.3](56.md#s224-Para_31.3) 

  

  
1. “风险投资”机构具有哪些特征？

如果主体是某公认风险投资机构的成员，或者符合成为公认风险投资机构成员的条件，这将构成其满足 IAS 28 豁免条件的证据。

在不太明显的情况下，以下特征表明主体属于风险投资机构：

- 其主营业务是向非上市公司提供股权融资，并主要通过中长期资本利得获取回报。这些活动可能包括初创期及其他早期扩张、管理层收购（MBO）或外来管理层收购（MBI）投资，且包含“权益型”回报。

- 积极参与帮助其所投资公司的建设和发展。

- 在适当情况下，是公认监管机构的成员。

2. 如果主体同时从事风险投资和其他业务活动，是否可以适用该豁免？

在这种情况下，区分可能更为困难。该豁免适用于风险投资“机构”。该“机构”不必是独立的法律实体，但必须是与主体其他业务活动明确分离且独立管理的部门或分支机构（例如，该部门或分支机构可能拥有自己的管理团队）。该“机构”必须开展以赚取风险投资回报为目标进行管理的风险投资业务。

此类情形的示例请参见[FAQ 31.3.3](56.md#s228-FAQ_31.3.3)。

3. 如果“风险投资”机构持有的投资以公允价值计量且其变动计入其他综合收益，是否可以适用该豁免？

IFRS 9 – 不可以。为了在风险投资机构的经济利益财务报表或合并财务报表中适用 IAS 28 的范围豁免，风险投资机构不得在初始确认时作出 IFRS 9 允许的不可撤销选择（将公允价值变动列报于其他综合收益），因为 IAS 28 的范围豁免要求公允价值变动计入损益。

IAS 39 – 某风险投资机构持有投资的期限长达三至五年，并根据 IAS 39 将此类投资分类为可供出售金融资产。为了适用 IAS 28 的范围豁免，这些投资需要在初始确认时指定为以公允价值计量且其变动计入损益，而不能根据 IAS 39 分类为可供出售金融资产。分类为可供出售金融资产不会导致公允价值变动计入损益，而是计入其他综合收益。仅当此类投资满足 IAS 39 第9(b)(ii)段的原则时，主体才可将其指定为以公允价值计量且其变动计入损益。

4. 当“风险投资”机构是子公司时，该豁免是否适用？

如果该风险投资机构是纳入母公司合并财务报表的子公司，即使母公司本身不是风险投资机构，IAS 28 中的豁免仍然适用。

然而，该范围豁免不适用于母公司其他非风险投资机构的子公司或部门在同一被投资方中持有的投资。

此外，还需要考虑子公司风险投资机构对关联集团主体进行的投资是否属于风险投资，以及母公司（在其合并财务报表中）和子公司（在其自身财务报表中）是否应改用权益法核算该项投资。

<a id="s228-chap_31_navPoint_63"></a>
### <a id="s228-FAQ_31.3.3"></a>FAQ 31.3.3 – 同时从事风险投资和其他业务活动的风险投资机构

 

准则索引：IAS 28 第18、19段  
正文索引：[31.3](56.md#s224-Para_31.3) 

  

  
**示例 1 – 主体同时从事风险投资和其他业务活动**

某主体有意投资于高成长初创公司。其中部分投资的持股比例可能超过 20%。部分投资很可能符合 IAS 28 下联营企业的定义，但另一些则不符合。管理层希望在中期内持有这些投资，但一旦发生上市或出售机会即寻求退出。该主体本身在零售行业拥有成熟业务，但它将这些投资作为独立于主营业务的“孵化基金”进行管理。其有意投资的高成长初创主体通常不属于零售行业。该基金独立于零售业务进行管理，并拥有自己的管理团队。

该孵化基金是主体一项明确独立的业务，与零售业务分开独立管理。孵化基金的投资作为投资组合按公允价值基础进行管理，其收购目的是为了实现公允价值增长，且基金中各投资项的业务通常与报告主体的主营业务无关（即非零售业务）。此外，公允价值计量将为管理层和主体的投资者提供更相关的信息。因此，管理层对孵化基金中的投资采用 IAS 28 豁免是恰当的。

**示例 2 – 主体是兼营辅助性风险投资活动的专业顾问机构**

如果主体提供咨询和管理服务，并积极参与帮助其所投资主体的建设和发展，并不妨碍其成为风险投资机构。然而，当主体是一家专业顾问机构，且其风险投资活动附属于其企业咨询服务主营业务时，需要仔细审视具体情况以确定是否适用该豁免，如下例所示。

某主体向科技行业的初创及发展中主体提供企业咨询和管理服务。作为回报，该主体取得科技公司的股权，并打算在中长期内持有。其中部分股权比例可能达到 20% 或以上。部分或全部此类投资将符合 IAS 28 下联营企业的定义。

在这一特定情形下，可能会有观点认为：

- 主营业务是企业咨询服务；

- 投资活动附属于该主营业务；且

- 这并非主体一项明确分离的业务。

因此，该主体不应被视为风险投资机构。

在某些情形下，这种观点是正确的，特别是当主体大部分服务均收取现金，仅偶尔取得股权时（例如大型会计师事务所或律师事务所可能面临的情形）。

然而，如果主体几乎完全以取得股权作为对价，并像风险投资家一样将这些投资作为投资组合进行管理，则应将其视为符合 IAS 28 豁免的条件。

 

<a id="s228-chap_31_navPoint_64"></a>
### <a id="s228-FAQ_31.3.4"></a>FAQ 31.3.4 – 共同基金、单位信托以及类似主体（包括投资连结保险基金）具有哪些特征？

 

准则索引：IAS 28 第18、19段  
正文索引：[31.3](56.md#s224-Para_31.3) 

  

  
IAS 28 中免于采用权益法的豁免同样适用于共同基金、单位信托以及类似主体（包括投资连结保险基金）。

投资连结保险基金是指保单持有人直接参与该等投资风险和回报的保险结构。

单位信托、共同基金及类似基金通常就其负债支付回报，且该回报按合同与某项资产或一组资产的公允价值变动挂钩。适用该豁免可避免资产与负债计量之间的不匹配。

当信托或基金负债的回报变动按合同与联营企业投资或包含联营企业投资的资产池的公允价值挂钩时，此类主体可以适用该豁免。

 

<a id="s228-chap_31_navPoint_65"></a>
### <a id="s228-FAQ_31.3.5"></a>FAQ 31.3.5 – 意图变更应如何进行会计处理

 

准则索引：IAS 28 第18、19段  
正文索引：[31.3](56.md#s224-Para_31.3) 

  

  
对于原适用风险投资机构豁免但该豁免不再适用的联营企业，准则并未就其会计处理提供指引。主体可能改变其意图，不再计划在可预见的未来退出该项投资。

我们认为，此类意图变更应视同类似于“增持升级”为联营企业的情形。尽管投资在数量上并未发生实际增加，但意图变更导致其成为性质不同的投资，IFRS 9（IAS 39）下的会计处理不再相关。采用权益法核算的联营企业的初始成本可以采用[第31.30段](56.md#s225-Para_31.30)所述的两种方法之一确定。

### <a id="s228-FAQ_31.7.1"></a>FAQ 31.7.1 – 免于编制合并财务报表或经济利益财务报表的适用条件

 

准则索引：IAS 28 第17段  
正文索引：[31.7](56.md#s224-Para_31.7) 

  

  
当编制合并财务报表的最终母公司或中间母公司能够作出明确且无保留的符合国际财务报告准则（IFRS）的声明（参见[FAQ 26.13.1](46.md#s176-FAQ_26.13.1)），且该等合并财务报表可供公众使用时，可适用该豁免。

当地监管要求可能规定了编制合并财务报表或经济利益财务报表的要求，因此在此情形下也可能适用免于编制合并财务报表或经济利益财务报表的豁免。

允许主体不按 IFRS 编制合并财务报表的法律或法规的存在，并不能凌驾于 IAS 28 的要求之上。

除非适用 IAS 28 第17段的豁免，否则包含明确且无保留的符合 IFRS 声明的单独主体财务报表必须附带一套合并财务报表。

如果单独财务报表未包含上述合规声明（而是例如声明遵循“欧盟认可的国际财务报告准则”），则此类财务报表可以利用免除主体编制合并财务报表义务的监管豁免。

### <a id="s228-FAQ_31.7.2"></a>FAQ 31.7.2 – 该豁免是否适用于经济利益财务报表？

准则索引：IAS 28 第17段  
正文索引：[31.7](56.md#s224-Para_31.7) 

  

  
主体 A 是另一主体的持股 60% 的非上市子公司，该母公司按照 IFRS 编制可供公众使用的合并财务报表。主体 A 有一家联营企业，但没有子公司。主体 A 没有向公众发行股票或债券的计划。主体 A 的其他 40% 股东已获知主体 A 不编制“经济利益”财务报表的意图，且未提出异议。

主体 A 有权享有免于编制经济利益财务报表的豁免，因其满足 IAS 28 规定的全部豁免条件。但是，主体 A 必须编制单独财务报表。

假设事实与上述相同，但主体 A 在公认证券交易所上市。

在此情形下，由于主体 A 的股份已上市，其无权享有该豁免。

假设事实与原始情景相同，但母公司的合并财务报表是按照美国公认会计原则（US GAAP）编制的。

在此情形下，由于母公司的合并财务报表并非按照 IFRS 编制，该豁免不适用。

### <a id="s228-FAQ_31.10.1"></a>FAQ 31.10.1 – 什么是表决权的概念？

准则索引：IAS 28 第5段  
正文索引：[31.10](56.md#s225-Para_31.10) 

  

  
IAS 28 并未对表决权的含义给出定义或指引。我们认为，表决权是指股东在主体股东大会上就全部或实质上全部事项进行表决的权利。这不包括以受托人身份持有的表决权，也不包括作为名义持有人持有且仅在另一方同意下方可行使的表决权。

 

 

<a id="s228-chap_31_navPoint_71"></a>
### <a id="s228-FAQ_31.11.1"></a>FAQ 31.11.1 – 确定重大影响时的实务考量

 

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
1. 是否必须同时满足 IAS 28 第6段列举的所有示例才能证明存在重大影响？

不需要。上述示例中的任何一项均可能证明重大影响的存在；无需满足所有示例。

需要注意的是，关键在于拥有参与政策决策的权力，而不在于是否实际行使该权力。主体可能在被投资方董事会中拥有席位或有权拥有席位，但选择保持消极态度，不积极参会或在表决时弃权（尽管在实务中这可能难以证明）。重要的是董事会代表席位所赋予的权力，而非主体未实际参与政策制定过程这一事实。

2. 在初始收购一项投资时，应如何评估重大影响？

当一项投资刚刚完成时，在判断主体对该投资拥有的影响程度方面可能会出现实务难题。在这种情况下，实际的合作关系通常会在投资收购后很快明朗。关键在于拥有施加重大影响的权力。如果实际关系的发展情况有所不同，例如在实务中主体无法施加重大影响，则后续可能需要变更该投资的会计处理方式。

3. 对重大影响的积极抵制应如何进行会计处理？

如果主体未能成功获得董事会席位或未能及时从被投资方获取财务信息，或者被投资方积极抵制主体对其施加影响的企图，则重大影响的存在可能受到质疑。下例说明了这一点。

主体 A 拥有主体 B 20% 的表决权，并有权向由五名成员组成的董事会委派一名董事。其余 80% 的表决权由另外两个主体持有，每个主体均有权委派两名董事。

董事会作出决策需要四名董事达到法定人数并经出席董事的简单多数通过。其他股东经常在极短时间内通知召开董事会会议，并在主体 A 代表缺席的情况下作出决策。主体 A 曾要求主体 B 提供财务信息，但未获提供。主体 A 的代表曾出席董事会会议，但其要求列入议程的提议遭到忽视，且其他董事反对主体 A 提出的任何建议。

尽管主体 A 拥有 20% 的表决权并在董事会中派有代表，但持有大比例表决权的其他股东的存在阻碍了主体 A 施加重大影响。虽然表面上主体 A 应拥有参与财务和经营政策决策的权力，但其他股东阻碍了主体 A 的努力，使主体 A 实际上无法施加任何影响。

在此情形下，主体 B 不构成主体 A 的联营企业。

在上述示例中，其他主体通过共同行动能够获得多数表决票，从而得以积极抵制主体 A 施加影响的企图并剥夺了其权力。然而，准则指出：“……另一主体拥有实质性或多数所有权，并不必然排除主体具有重大影响。”[IAS 28 第5段]。因此，需要对每个案例的具体事实进行仔细审查。

 

<a id="s228-chap_31_navPoint_72"></a>
### <a id="s228-FAQ_31.11.2"></a>FAQ 31.11.2 – 关于董事会代表席位的实务考量

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
除非明确存在其他安排赋予主体参与政策制定决策的权力，否则在董事会中派有代表通常对于证明主体拥有参与财务和经营政策决策的权力（从而具有重大影响）至关重要。

董事会成员的提名以及拟议的决策流程（包括相关董事在会议上的表决权），均是确定主体是否具有重大影响的指标。

部分国家的某些主体要求设立监事会和管理委员会（执行董事会）。参与任一机构的权力均应予以考虑。监事会通常负责任免管理委员会，因此参与监事会的权力同样具有相关性。

主体 P 持有主体 A 10% 的有表决权股份。主体 A 的董事会由八名成员组成，其中两名成员由主体 P 委派。每位董事会成员在会议上享有一票表决权。

主体 A 是主体 P 的联营企业，因为在董事会中派有董事以及会议上的相对表决权证明了重大影响的存在。

当主体持有被投资方 20% 或以上表决权时，推定其具有重大影响；但并不要求在董事会中拥有 20% 的席位才能证明重大影响，因为这取决于所有事实和情况。即使某位董事会成员所代表的表决权低于 20%，一名董事会成员也可能代表存在重大影响。但是，由于此时不推定存在重大影响，为了确认存在重大影响，必须（基于具体事实和情况）证明确属如此。

<a id="s228-chap_31_navPoint_73"></a>
### <a id="s228-FAQ_31.11.3"></a>FAQ 31.11.3 – 关于参与政策制定过程的实务考量

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
如果能够证明主体通过参与涉及与其相关政策方面的决策（包括战略问题、股利及其他分配决策）而拥有参与被投资方发展方向的权力，则构成联营关系。

参与政策制定过程意味着参与战略决策，例如：

- 业务的扩张或收缩；

- 参与其他主体；

- 产品、市场和业务活动的变更；以及

- 确定股利分配与再投资之间的平衡。

此类参与的目的在于从主体的活动中获取经济利益，尽管主体也将面临这些活动可能发生亏损的风险。例如，这可以通过在董事会中派有代表来实现，因为在通常采用举手表决的决策过程中，董事拥有参与决策的权力。

例如，如果持有少于 20% 表决权的单一股东在董事会中派有代表，则其具有重大影响并拥有参与政策制定决策的权力。持有相同持股比例但未在董事会派有代表的股东则不具有同等的影响力或参与权。

无论持股比例如何，基金管理人可能具有重大影响，并需要根据具体事实和情况评估其是否具有重大影响。

<a id="s228-chap_31_navPoint_74"></a>
### <a id="s228-FAQ_31.11.4"></a>FAQ 31.11.4 – 关于主体与其被投资方之间重大交易的实务考量

 

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
主体 A 为一家领先的服装零售商生产服装。该零售商提供所有服装设计，并参与生产排期、时间和数量的确定。主体 A 的绝大部分（即 90%）销售额均销往该零售商。该零售商持有主体 A 10% 的股权，系多年前双方建立合作关系之初取得。

主体 A 的业务持续经营高度依赖该零售商。尽管该零售商仅持有主体 A 10% 的权益，但其具有重大影响。

 

<a id="s228-chap_31_navPoint_75"></a>
### <a id="s228-FAQ_31.11.5"></a>FAQ 31.11.5 – 关于管理人员互换的实务考量

 

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
当一方主体向另一方主体派驻管理人员时，前者可能拥有参与后者财务和经营政策及实务的权力。派驻人员的主体有权决定委派人选，因此能够委派维护派驻方利益的人员。如果能够证明管理人员的互换导致一方主体的管理层对另一方具有重大影响，则另一方将构成联营企业。

主体 A 和主体 B 在同一行业但不同地理区域经营。作为战略联盟的一部分，主体 A 收购了主体 B 10% 的股权。一项新的生产工艺是推动主体 B 战略方向发生根本变革的关键。联盟条款规定，主体 B 将在来自主体 A 的两名管理人员的监督下实施该新生产工艺。主体 A 派驻的管理人员（其中一人是主体 A 的董事会成员）将负责监督新员工的选拔与招聘、新设备的采购、员工培训以及新原材料采购合同的谈判。这两名管理人员将直接向主体 B 的董事会及主体 A 的董事会汇报。

主体 A 向主体 B 派驻一名董事会成员和一名高级管理人员，赋予了主体 A 对新生产工艺的一系列权力，这可能证明主体 A 对主体 B 具有重大影响。该评估考虑了主体 B 的关键财务和经营政策，以及该安排赋予主体 A 对这些政策的影响力。

### <a id="s228-FAQ_31.11.6"></a>FAQ 31.11.6 – 关于提供关键技术信息的实务考量

准则索引：IAS 28 第6段  
正文索引：[31.11](56.md#s225-Para_31.11) 

  

  
对源自投资方主体的技术的高度依赖，可能导致该投资方对被投资方具有重大影响。

主体 B 持有主体 A 15% 的权益。主体 A 使用由主体 B 研发的技术生产移动电话手机。主体 B 将该技术许可给主体 A，并定期更新新技术许可协议。该等手机由主体 A 销售，构成主体 A 绝大部分的销售额。

### <a id="s228-FAQ_31.14.2"></a>FAQ 31.14.2 – 权益法调整的类型

 

准则索引：IAS 28 第26段

可能需要的调整类型包括但不限于以下事项：

- 确认商誉及处理收购联营企业或合营企业时产生的公允价值调整。

- 统一会计政策。

- 抵销与联营企业或合营企业之间交易的影响。

- 集团内部往来交易。

- 向联营企业或合营企业提供的长期贷款。

- 来自联营企业或合营企业的分配。

- 对记账本位币与主体列报货币不同的联营企业或合营企业的经营成果进行外币折算。

### <a id="s228-FAQ_31.14.3"></a>FAQ 31.14.3 – 获取联营企业财务信息受限的影响

 

准则索引：IAS 28 第10段  
正文索引：[31.14](56.md#s225-Para_31.14) 

  

  
1. 获取财务信息受限的影响

联营企业权益与子公司权益之间的主要区别在于主体的影响力程度。主体控制其子公司，因此能够获取在收购时和合并时执行特定程序所需的信息；但其对联营企业仅施加重大影响，对合营企业仅实施共同控制。这可能意味着在收购联营企业或合营企业权益时确定公允价值所需的信息，或作出必要调整所需的信息获取受限。

准则并未就这些程序的范围提供指引。尽管可以使用估计，但这种限制本身可能使主体与其联营企业之间的关系受到质疑。如果可获取的信息极为有限，主体将需要重新评估其是否真正对该联营企业具有重大影响。

2. 关于联营企业信息披露监管规定的影响

准则未提及关于信息披露的监管规定，这些规定可能会限制主体财务报表中包含有关其联营企业信息的程度，除非此类信息能够同时向其他利益相关方披露。当联营企业本身为上市公司时，这一点尤为重要（进一步内容请参见[第31.7段](56.md#s224-Para_31.7)）。因此，主体应考虑如何满足适用于发布有关其联营企业股价敏感信息的任何监管规定。

 

<a id="s228-chap_31_navPoint_80"></a>
### <a id="s228-FAQ_31.14.4"></a>FAQ 31.14.4 – 联营企业或合营企业净资产其他变动的会计处理

 

准则索引：IAS 28 第10段  
正文索引：[31.14.1](56.md#s225-Para_31.14.1) 

  

  
对于联营企业或合营企业除计入其他综合收益以外的其他权益变动，IAS 28 未作明确规定。此类变动包括例如联营企业与其子公司的非控制性权益股东之间交易产生的利得和损失（在联营企业账簿中直接计入权益），以及联营企业或合营企业股份支付储备的变动。

在这些情况下，交易的影响计入联营企业的权益，但不计入损益和其他综合收益。

在缺乏关于主体如何列报此类交易的具体指引的情况下，报告主体需要制定并一贯应用一项最能反映这些交易实质的会计政策。

### <a id="s228-FAQ_31.15.1"></a>FAQ 31.15.1 – 母公司合并财务报表中的会计处理

准则索引：IAS 28 第19段  
正文索引：[31.15](56.md#s225-Para_31.15) 

  

  
某集团对一家联营企业拥有投资，且该投资由其多家子公司持有。其中一家子公司是投资连结保险基金（或共同基金、单位信托或风险投资机构），在其单独财务报表中，按照 IFRS 9（IAS 39）在初始确认时将该联营企业投资以公允价值计量且其变动计入损益。另一家子公司按照 IAS 28 核算其对该同一联营企业的投资，从而采用权益法核算。

在母公司的合并财务报表中，是否可以同时采用这两种计量基础？

当联营企业投资的一部分根据风险投资范围豁免在初始确认时指定为以公允价值计量且其变动计入损益时，可以对联营企业投资的不同部分采用不同的计量基础。集团需要确定其是否对该项投资具有重大影响（有关重大影响的进一步讨论见[第31.9段及后续段落](56.md#s225-Para_31.9)）；如果具有重大影响，集团应对适用风险投资范围豁免的那部分联营企业投资以公允价值计量且其变动计入损益，对其余联营企业投资采用权益法核算。[IAS 28 第19段]。

### <a id="s228-FAQ_31.17.1"></a>FAQ 31.17.1 – 取得股权的方式

- 主体增持对某企业的投资，使其表决权比例超过 20%（分步收购联营企业详见[第31.31段及后续段落](56.md#s225-Para_31.31)）。

### <a id="s228-FAQ_31.21.2"></a>FAQ 31.21.2 – 实质上构成净投资组成部分的长期权益的计量

 

准则索引：IAS 28 第14A段  
正文索引：[31.21](56.md#s225-Para_31.21) 

  

  
2017年10月，IASB 发布了对 IAS 28 的修订。该修订明确，IFRS 9 适用于对联营企业或合营企业的长期权益。长期权益是指实质上构成净投资组成部分、但未采用权益法核算的权益。

理事会在 IAS 28 中明确：

- 应在适用 IAS 28 的亏损分摊和减值要求之前，先对长期权益适用 IFRS 9 的要求；以及

- 主体在适用 IFRS 9 的要求时，不应考虑因适用 IAS 28 而对长期权益账面价值作出的任何调整。

IAS 28 修订的示例展示了一个综合情景，说明主体（投资方）如何对实质上构成主体对联营企业净投资组成部分的各类长期权益（长期权益）进行会计处理，即对其长期权益适用 IFRS 9 进行会计处理，并对其包含该等长期权益的对联营企业净投资适用 IAS 28。

该等修订自2019年1月1日起生效，允许提前采用，并须按照 IAS 8 追溯适用。对于在首次采用 IFRS 9 之后才采用该修订的主体，其过渡要求将类似于 IFRS 9 中关于分类和计量的规定。

问题 1：

某投资方拥有一家持股 20% 的联营企业，采用权益法核算。该投资方向该联营企业发放了一笔金额为 C100 的贷款，并确认了 C10 的预期信用损失（ECL）减值损失（即该贷款在投资方账簿中的账面净值为 C90）。投资方应如何在其财务报表中对该减值损失进行会计处理？

解答 1：

投资方应对该贷款适用 IFRS 9 的减值考量，不应对该减值损失作出任何（抵销）调整。

问题 2：

某投资方持有发行方主体 20% 的 A 类普通股（股权投资）以及 20% 的票面股息率为 10% 的优先股（构成一项义务）。该优先股享有与普通股相同的表决权，但具有固定回报。

从发行方的角度看，根据 IAS 32，该优先股属于债务工具。投资方应如何在其合并财务报表中对普通股和优先股投资进行会计处理？

解答 2：

对普通股的投资按照 IAS 28 进行会计处理。对优先股的投资按照 IFRS 9 进行会计处理并适用 IFRS 9 的预期信用损失（ECL）模型，但构成投资方对发行方净投资的组成部分，该净投资须按照 IAS 28 进行减值测试。

问题 3：

某投资方持有发行方主体 20% 的 A 类普通股，该股份赋予表决权和利润分配权。A 类普通股的条款要求发行方将其全部可供分配利润分配给 A 类股东。

投资方作为 20% 股份的持有人，有权获得 20% 的利润。

从发行方的角度看，由于存在支付股利的合同义务，根据 IAS 32，A 类股份属于债务工具。投资方应如何在其合并财务报表中对 A 类普通股投资进行会计处理？

解答 3：

由于 A 类普通股包含表决权并赋予获取与所有权权益相关回报的权利，因此对该 A 类普通股的投资应按照 IAS 28 的规定采用权益法核算。

 

<a id="s228-chap_31_navPoint_85"></a>
### <a id="s228-FAQ_31.21.3"></a>FAQ 31.21.3 – 长期投资中 IAS 28 与 IFRS 9 的交互作用

 

准则索引：IAS 28 第14段  
正文索引：[31.21](56.md#s225-Para_31.21) 

  

 

投资方可能持有被投资方除普通股以外的工具（即非普通股）。非普通股可能提供以下一种或多种权利的组合：表决权、股利参与权、清算优先权和/或赎回特征。如果确定该非普通股赋予投资方对被投资方的重大影响，则需进行单独分析，以确定该非普通股应按照 IAS 28《在联营企业和合营企业中的投资》还是 IFRS 9《金融工具》进行会计处理。应当注意的是，IAS 28 第14段规定，IFRS 9 不适用于采用权益法核算的对联营企业和合营企业的权益。该段进一步指出：

 

“当包含潜在表决权的工具在实质上当前赋予获取与联营企业或合营企业所有权权益相关回报的权利时，该等工具不适用 IFRS 9。在所有其他情况下，包含联营企业或合营企业潜在表决权的工具均应按照 IFRS 9 进行会计处理。”

 

投资方对某项工具的会计处理并不总是与被投资方对该工具的会计处理相对应（例如，如果被投资方将该工具分类为负债，这并不自动表明该工具对投资方而言属于 IFRS 9 的范围）。主体需要考虑该工具的特征，以确定应适用的恰当准则。在作出这一判断时，主体还应考虑被投资方发行此类工具的商业理由以及投资方投资该工具的商业理由。决定适用哪项准则将取决于与该工具相关的事实和情况，可能涉及判断，但并非一项会计政策选择。

 

例如，主体可以考虑非普通股在存续期内回报的变动性是否与普通股更为一致。这一事实可能表明对该非普通股采用权益法核算更为恰当。

 

**示例**

 

主体 A 投资于主体 B（一家单一项目矿业主体）的非普通股。该股份的特征包括享有相当于普通股 1.25 倍的表决权和股利分配权。在主体清算时（将在矿山完全开采完毕且主体仅剩名义价值时发生），该非普通股享有相当于普通股清算金额的 1.25 倍与非普通股初始投入资本金额两者孰低的名义优先权。如果确定主体 A 对主体 B 具有重大影响，则对该非普通股最恰当的适用准则很可能是 IAS 28，因为该非普通股似乎当前即赋予获取与该主体所有权权益相关回报的权利。

 

或者，假设该非普通股的特征包括与普通股类似的表决权，但享有 5% 的累积固定股息率且不进一步参与利润分配。在此情况下，对该非普通股最恰当的适用准则很可能是 IFRS 9，因为仅凭表决权本身无法提供获取与普通股类似回报的权利。

必须审查所有事实和情况，以确定适用于长期投资的恰当准则。

### <a id="s228-FAQ_31.24.1"></a>FAQ 31.24.1 – 联营企业投资成本的确定及或有对价的处理

准则索引：IAS 28 第32段  
正文索引：[31.24](56.md#s225-Para_31.24) 

  

  
IAS 28 并未就或有对价的会计处理提供具体指引。与收购费用类似，IAS 28 未专门处理或有对价的会计处理。在收购日，或有对价的估计金额通常计入收购成本的组成部分。对于或有对价的后续变动，存在不同的处理方法。以下两种方法被视为或有对价后续变动的可接受会计处理方法：

- 成本基础法。收购日后对或有对价估计的任何修订均按照 IAS 8 作为会计估计变更采用未来适用法处理。因修订现金流量导致的负债变动将调整资产成本，并按照 IAS 8 第37段确认为联营企业账面价值的组成部分，而非计入损益。

- 类比 IFRS 3。IFRS 3 下对或有对价的指引基于公允价值法。在该方法下，所有或有对价在收购日均按公允价值分类和计量。类比 IFRS 3 第58段，或有对价分类为负债或权益。分类为权益工具的或有对价不予重新计量。分类为资产或负债的或有对价按照 IFRS 9（IAS 39）进行会计处理。或有对价的任何变动均按照 IFRS 9（IAS 39）计入损益。有关公允价值计量资产的定义、计量和披露影响的进一步信息，请参见第5章。

<a id="s228-chap_31_navPoint_87"></a>
### <a id="s228-FAQ_31.29.1"></a>FAQ 31.29.1 – 设立联营企业或合营企业时或后续交换货币性资产和非货币性资产的会计处理

准则索引：IAS 28 第30、31段  
正文索引：[31.29](56.md#s225-Para_31.29) 

  

  
在确定主体收到的对价时，应考虑在设立联营企业或合营企业时或后续交换的任何货币性或非货币性资产。主体向联营企业或合营企业转让资产或业务，可能同时收到现金（直接来自联营企业或合营企业的其他投资方，或来自合营企业本身）以及股份。当现金系从其他投资方（而非联营企业或合营企业本身）收到时，就对价中的现金部分而言，盈利过程已经完成。

例如，某主体将一项公允价值为 C1,000、账面价值为 C900 的资产转让给其持股 40% 的联营企业或合营企业。作为交换，该主体从其他投资方收到 C250 的现金对价，并收到公允价值为 C750 的该联营企业或合营企业股份。对于从其他投资方以现金收到的对价部分，其利得应视为已实现。对于以股份收到的对价部分，其利得仅在另一方于该联营企业或合营企业中享有的份额范围内实现。因此，本例中的已实现利得为 C70（（C100 × 25%）+（C100 × 75% × 60%））。利得的未实现部分仅在联营企业或合营企业将该资产出售（例如出售给第三方）后才完全实现。

再如，母公司将一项不动产投入一家持股比例为 55/45 的合营企业以换取发行的股份。该不动产的账面价值为 C1,000，公允价值为 C1,200。由于无关联主体的权益比例为 45%，母公司将在合并损益中确认 C90（C200 × 45%）的利得。

<a id="s228-chap_31_navPoint_88"></a>
### <a id="s228-FAQ_31.29.2"></a>FAQ 31.29.2 – 因处置子公司而形成联营企业的方式

准则索引：IAS 28 第5段  
正文索引：[31.29](56.md#s225-Para_31.29) 

  

  
对子公司的投资可以通过多种方式转变为对联营企业的投资。以下列举若干示例：

- 主体出售子公司的部分股份，使其表决权比例降至 50% 以下，但主体保留了重大影响，因此该主体如今成为联营企业。

- 子公司向第三方发行股份，致使主体的持股比例降至表决权的 50% 以下，但仍保留重大影响。

- 主体不再拥有例如在 40% 持股水平下的主导权力，但继续具有重大影响。

<a id="s228-chap_31_navPoint_89"></a>
### <a id="s228-FAQ_31.30.1"></a>FAQ 31.30.1 – 确定分步收购联营企业的成本

 

准则索引：IAS 28 第10段  
正文索引：[31.30](56.md#s225-Para_31.30) 

  

  
当主体增持另一主体的股权，使一项原按公允价值计量的权益投资首次成为联营企业时，可以采用两种方法：

- “历次购买成本累积法”。分步收购联营企业的成本按最近一次购买的成本加上交易费用再加上起始成本之和计量。起始成本是指每次购买所支付的原始对价，加上截至其成为联营企业之日历次购买应享有的被投资方后续利润及其他权益变动（例如重估）的份额。初始投资公允价值与其起始成本之间的差额计入损益，即使公允价值的原始变动曾计入其他综合收益。该观点基于2019年1月国际财务报告准则解释委员会（IFRIC）的驳回决议：《按成本核算的对子公司的投资：分步收购》。

- “公允价值作为认定成本法”（类比 IFRS 3）。分步收购联营企业的成本按投资成为联营企业之日原持有权益的公允价值与新增转让对价的公允价值之和计量。原持有权益此前应已按照 IFRS 9 以公允价值计量，其公允价值变动计入损益或其他综合收益。根据 IFRS 9，已计入其他综合收益的公允价值变动不得重分类至损益，仍保留在其他综合收益中或可结转至留存收益（IFRS 9.4.1.4、5.7.5、B5.7.1）。由于该方法系类比 IFRS 3，任何与收购相关的费用均在发生当期费用化。这与初始确认时的收购相关费用不同；如[第31.22段](56.md#s225-Para_31.22)所述，该等费用构成联营企业账面价值的组成部分。该观点基于2009年7月 IFRIC 的驳回决议。

主体所选择的会计方法应对所有从投资组合投资增持为联营企业的类似交易一贯适用。有关分步实现企业合并的指引，请参见第29章第166段。

### <a id="s228-FAQ_31.34.1"></a>FAQ 31.34.1 – 部分处置联营企业且保留重大影响

- 按减少的比例终止确认联营企业的账面价值。

### <a id="s228-FAQ_31.36.1"></a>FAQ 31.36.1 – 涉及同一控制交易的联营企业

 

准则索引：IAS 28 第32段  
正文索引：[31.36](56.md#s225-Para_31.36) 

  

  
2013年初，IFRIC 讨论了一项请求，要求澄清从同一控制下的主体处收购联营企业或合营企业权益的会计处理。IFRIC 审议了将同一控制下企业合并的范围豁免类比适用于同一控制下收购联营企业或合营企业权益是否恰当。IFRIC 的结论是，该问题更适合在关于同一控制下企业合并及权益法会计的更广泛项目框架内予以考虑。根据现行准则文献，IFRS 3 中的同一控制豁免仅适用于企业合并（即母公司收购子公司）；IAS 28 中并无此类明确豁免。然而，IAS 28 第26段指出，用于核算收购子公司的程序所依据的概念同样适用于核算对联营企业或合营企业投资的收购。

我们认为，不应类比适用 IFRS 3 中的豁免，但鉴于该领域缺乏具体指引，实务中存在多样性。每当发生同一控制下收购联营企业或合营企业权益的交易时，均需仔细分析事实和情况，并考虑 IAS 1 中关于与所有者以其所有者身份进行的交易的要求。

### <a id="s228-FAQ_31.37.1"></a>FAQ 31.37.1 – 收购联营企业时暂估金额的使用

 

准则索引：IAS 28 第32段  
正文索引：31.37 

  

  
对于收购联营企业或合营企业时仅能获得暂估金额的情形，IAS 28 未作具体规定。

根据 IFRS 3，收购子公司时允许有一年的计量期间来最终确定收购会计中使用的公允价值，并且在报告期末可以使用暂估金额。当主体收购联营企业或合营企业时，如果有正当理由导致用于完成收购会计处理的信息在资产负债表日尚未最终确定，则可能需要使用暂估金额。

### <a id="s228-FAQ_31.39.1"></a>FAQ 31.39.1 – 收购后会计处理中的调整

 

准则索引：IAS 28 第32段  
正文索引：[31.39](56.md#s225-Para_31.39) 

  

  
1. 联营企业的资产

作为公允价值评估的一部分，主体可能在收购时对联营企业或合营企业的不动产、厂场和设备进行了减值调整。联营企业或合营企业后续确认的任何减值损失均需予以转回。

2. 联营企业收购前的商誉

用于计算收购产生的商誉的被投资方资产不应包含联营企业或合营企业资产负债表中列示的任何商誉。同样，作为公允价值评估的一部分，购买方仅在被购买方的无形资产于收购日符合 IFRS 3 第45段及第B31至B41段所定义的无形资产定义时才予以单独确认。联营企业或合营企业账簿中的商誉不属于可辨认资产，在确定收购该联营企业或合营企业产生的商誉时应予以忽略。联营企业或合营企业后续在其账簿中确认的任何商誉减值损失，在按权益法核算联营企业或合营企业利润时均应加回，因为联营企业或合营企业的商誉并非收购对价分摊中的可辨认资产。这将在主体层面构成减值触发迹象，因此应对该联营企业的总账面价值进行减值测试（参见[第31.61段](56.md#s226-Para_31.61)）。

 

<a id="s228-chap_31_navPoint_96"></a>
### <a id="s228-FAQ_31.39.2"></a>FAQ 31.39.2 – 联营企业确认的收购前商誉减值损失

 

准则索引：IAS 28 第27段  
正文索引：[31.39](56.md#s225-Para_31.39)  
 

  

  
如果某主体持有被投资方 25% 的权益，且被投资方当期利润为 C100（已扣除确认的商誉减值损失 C20），则主体当期应享有被投资方的利润份额为 C30（即 C120 的 25%）。被投资方确认的任何商誉减值损失份额均应从主体当期应享有被投资方的损益份额中剔除。

每当有迹象表明对被投资方的投资可能发生减值时，主体应按照 IAS 36 将对该被投资方投资的全部账面价值（包括收购该被投资方时产生的商誉）与其可收回金额进行比较，以进行减值测试。

### <a id="s228-FAQ_31.39.3"></a>FAQ 31.39.3 – 联营企业子公司产生的收购后商誉的处理

 

准则索引：IAS 28 第27段  
正文索引：[31.39](56.md#s225-Para_31.39)  

  

  
某主体持有若干年前收购的一家联营企业 25% 的权益。收购当时，该联营企业拥有一家子公司（S1），且该联营企业的合并财务报表中包含商誉。在本财务年度，该联营企业又收购了另一家子公司（S2），并在收购中产生了商誉。

在主体收购该联营企业时，联营企业账簿中因收购 S1 产生的商誉并非可辨认资产，而是并入投资方主体因收购该联营企业产生的商誉中。而在收购 S2 时，联营企业账簿中产生的商誉并非投资方主体的商誉，应计入归属于该主体的联营企业净资产份额中。

无论是收购联营企业本身产生的商誉，还是联营企业后续收购产生的商誉，均无需单独披露。

### <a id="s228-FAQ_31.40.1"></a>FAQ 31.40.1 – 集团份额或持股比例的确定

准则索引：IAS 28 第27段  
正文索引：[31.40](56.md#s226-Para_31.40)  
 

  

  
准则并未定义集团份额或持股比例的含义。当主体仅在联营企业或合营企业的普通股股本中拥有权益时，采用权益法核算的份额通常为所持股份数量占已发行普通股总数的百分比。该比例等同于主体享有股利和其他分配的权利。

当被投资方存在不同类别的权益股份，或者享有股利或清算时分配资本的权利各不相同时，情况会变得复杂。需要仔细考虑各类股份所附带的权利以及各项权利的实质，以确定纳入权益份额计算的恰当百分比。

在许多情况下，应予考虑的份额将源自持股比例；在其他情况下，经济利益比例可能与持股比例不同，但经济利益比例才是应予考虑的恰当份额。例如，联营企业的持股比例可能为 40:60，但各方按 30:70 的比例分享利润。在此情况下，按经济份额而非股权出资比例采用权益法核算更为恰当。

<a id="s228-chap_31_navPoint_99"></a>
### <a id="s228-FAQ_31.40.2"></a>FAQ 31.40.2 – 子公司持有对联营企业的投资

准则索引：IAS 28 第27段  
正文索引：[31.40](56.md#s226-Para_31.40)  
 

  

  
主体 A 持有主体 B 80% 的权益。主体 B 持有对一家联营企业 40% 的投资。

主体 A 的合并财务报表包含主体 B 合并财务报表（即按权益法核算基础包含该联营企业的财务报表）中 100% 的数字。这意味着，在计算计入集团合并利润表的应享有联营企业经营成果份额时，纳入集团合并财务报表的是直接的 40% 投资比例（而非 32%（80% × 40%））。这意味着，例如，如果该联营企业的权益为 C100（包含当期净利润 C20），则资产负债表中对联营企业的投资列示为 C40，应享有联营企业利润份额为 C8（20 × 40%）而非 C6.4（(20 × 40%) × 80%）。在综合收益表底部，差额 C1.6 归属于非控制性权益，C6.4 归属于母公司权益持有人。

### <a id="s228-FAQ_31.40.3"></a>FAQ 31.40.3 – 对联营企业的间接持股

准则索引：IAS 28 第27段  
正文索引：[31.40](56.md#s226-Para_31.40)  
 

  

  
集团 A 拥有两家联营企业：主体 B（22%）和主体 C（25%）。主体 B 还持有主体 C 1% 的权益。

在主体 B 的账簿中，对主体 C 的 1% 权益作为一般投资核算；而在合并财务报表中，该项投资在计算主体 B 的权益法核算金额时，作为主体 B 净资产的组成部分计入。

在对主体 C 采用权益法核算时，所考虑的主体 C 份额仅为对主体 C 的直接权益 25%。

<a id="s228-chap_31_navPoint_101"></a>
### <a id="s228-FAQ_31.46.1"></a>FAQ 31.46.1 – 现时所有权权益的确定

准则索引：IAS 28 第13、14段  
正文索引：[31.46](56.md#s226-Para_31.46)  
 

  

  
例如，当主体出售一项所有权权益的同时约定回购该权益，但并未丧失影响与该所有权权益相关回报的能力时，主体可能在实质上拥有现时所有权权益。在此情况下，确定主体应采用权益法核算的份额时，应考虑潜在表决权的最终行权；因为在实质上，该等权利当前即赋予主体影响与所有权权益相关回报的途径，被视为现时所有权权益。

主体可能向另一主体同时签出看跌期权并购入看涨期权，这些期权具有实质上相同的固定行权价格且在未来的同一日期可行权。在此情形下，几乎可以确定某一方将会行权，因为这样做符合其中一方的经济利益。如果股价跌破固定行权价格，另一方将行使看跌期权出售股份（即主体保留了承担风险的敞口）；或者，如果股价涨至固定行权价格之上，主体将行使看涨期权购买股份（即主体保留了获取收益的途径）。

要构成现时所有权权益，潜在表决权必须赋予获取与所有权权益相关的经济利益的途径。如果实际股东享有股利分配权，则很难主张潜在表决权产生了现时所有权权益。对于更有可能以股利形式支付给实际股份持有人而非潜在权利持有人的利润，采用权益法予以核算是不正确的。尽管潜在表决权本身不赋予现时所有权权益，但行权价格的设计可能使潜在表决权持有人实质上享有股利权益，这将表明潜在表决权持有人保留了该投资的经济利益。

<a id="s228-chap_31_navPoint_102"></a>
### <a id="s228-FAQ_31.46.2"></a>FAQ 31.46.2 – 关于联营企业和合营企业对称性看跌期权和看涨期权的会计处理

 

准则索引：IAS 28 第13、14段  
正文索引：[31.46](56.md#s226-Para_31.46)  
 

  

  
主体可能就其在联营企业或合营企业中的权益签出看跌期权或对称性看跌期权和看涨期权。当此类期权针对子公司权益中的非控制性权益签出时，集团应确认一项负债，如[第26章第204段](45.md#s174-Para_26.204)所述。

由此产生的问题是，管理层是否应对联营企业和合营企业的权益工具采用相同的会计处理。IAS 32 第23段要求就此类期权确认负债，是因为该段针对的是集团自身的权益工具。由于联营企业或合营企业不属于报告集团的组成部分，因此不能对涉及联营企业或合营企业权益的看跌期权采用相同的会计处理。报告集团的资产负债表上不应确认负债。

尽管不产生就全部义务确认金融负债的情形，但主体可能持有一项衍生金融工具，需要按照 IFRS 9（IAS 39）进行确认和计量。

### <a id="s228-FAQ_31.48.1"></a>FAQ 31.48.1 – 股份交叉持股的会计处理

准则索引：IAS 28 第27段  
正文索引：[31.48](56.md#s226-Para_31.48)  
 

  

  
一家公司（该主体）可能向另一家公司发行股份，以换取该另一家公司的股份。如果不作调整，当主体按权益法核算其应享有被投资方净资产（其中包括被投资方持有的该主体股份）的份额时，将会出现重复计算。这种交叉持股需要予以抵销，如下例所示。

主体 H 持有主体 A 25% 的股权，主体 A 的净资产为 C100 万。主体 A 股份的市场价值为 C150 万。净资产的账面价值与公允价值相同（即 C100 万）。主体 H 发行价值 C375,000 的股份以收购其权益。

如果主体 H 向主体 A 的所有者发行其自身股份以换取 25% 的权益，则主体 H 的股本和股本溢价将增加 C375,000，代表其对主体 A 投资的成本。在权益法核算时，对主体 A 的投资 C375,000 分摊为集团应享有其净资产公允价值的份额（即 C250,000）以及收购产生的名义商誉 C125,000（即 C375,000 – C250,000）。

现在假设发生股权互换，主体 H 向主体 A 发行价值 C500,000 的股份，作为主体 A 向主体 H 发行新股的对价。主体 A 的净资产增加 C500,000，即其持有主体 H 股份的成本。主体 A 的价值增至 C2,000,000，净资产为 C1,500,000。主体 H 应享有主体 A 增加后净资产的份额为 C500,000（即 C2,000,000 × 25%）。因此，表面上看来，在权益法核算下主体 H 在其联营企业中的权益价值似乎应为 C500,000（即 C2,000,000 × 25%），但主体 H 在主体 A 中的权益不应超过 C375,000（C2,000,000/25% 减去 C500,000/25%），即主体 A 的价值减去其收到的主体 H 股份权益。如果主体 H 将其份额确认为 C500,000，则会因确认了其自身内部产生的商誉/权益价值而虚增资产负债表。

为避免对自我投资的重复计算，必须抵销主体 H 对其自身的权益。将主体 H 在主体 A 净资产中的投资价值减少 C125,000 至 C375,000 是恰当的。其原理在于通过减少净资产来抵销交叉持股，这同时也确保对主体 A 的外购商誉按恰当价值记录。如果主体 A 随后出售其在主体 H 中的权益，则会产生一个问题——需要进行调整，以将主体 H 财务报表中对主体 A 的投资恢复至主体 A 增加后的净资产份额（即 C500,000）。

在主体 H 的利润表中，主体 H 应享有主体 A 经营成果的份额应剔除主体 A 向主体 H 支付的任何股利。

关于主体 H 向主体 A 支付的股利，主体 H 的利润表应剔除主体 H 向主体 A 支付的任何股利的相应份额。该方法可以通过类比投资方与其联营企业之间顺流交易利得/损失的会计处理获得支持——即抵销主体在联营企业利得/损失中的份额。[IAS 28 第28段]。

或者，主体 H 的利润表包含主体 H 向主体 A 支付的任何股利的份额也可能是可接受的。该方法的依据是，股利支付属于非互惠交易，结果使该股利成为主体 A 的一项实际资源。

如果存在更为复杂的交叉持股结构，通常可以使用联立方程来确定应采用权益法核算的金额。

### <a id="s228-FAQ_31.49.1"></a>FAQ 31.49.1 – 因会计政策不同而需进行调整的实务情形

准则索引：IAS 28 第35、36段  
正文索引：[31.49](56.md#s226-Para_31.49)  
 

  

  
如果主体按照 IFRS 编制财务报表，而其联营企业或合营企业按照当地公认会计原则（local GAAP）编制财务报表，则主体与其联营企业或合营企业的会计政策不一致。为符合 IAS 28 的要求，应对联营企业或合营企业的经营成果进行调整，以符合主体基于 IFRS 的会计政策。

### <a id="s228-FAQ_31.50.1"></a>FAQ 31.50.1 – 上市联营企业的报告期末早于或晚于主体报告期末超过三个月

准则索引：IAS 28 第33、34段  
正文索引：[31.50](56.md#s226-Para_31.50)  
 

  

  
20X3年10月1日，某集团收购了一家联营企业的权益。该集团的年度截止日为12月31日，而该联营企业的年度截止日为2月28日。该联营企业是一家上市公司，并发布截至8月31日的六个月中期财务报表。

对于使用早于主体年度截止日不超过三个月的日期的财务数据会泄露股价敏感信息的情形，IAS 28 并未规定“三个月规则”的例外。因此，根据 IAS 28，正确的做法是为该联营企业编制截至主体年度截止日（即12月31日）或截至10月1日（收购日，该日期同样早于主体年度截止日不超过三个月）的财务报表。后一种方法的优势在于能够提供收购日的资产负债表数据。为避免主体使用该信息导致股价敏感信息泄露，该联营企业有必要公开其截至10月1日编制的财务报表。

另一种选择是主体使用该联营企业截至其2月28日年度截止日编制的财务报表，因为这两个报告日之间仅相差两个月（符合 IAS 28 允许的不超过三个月的差异）。这种方法可以解决股价敏感信息的问题。然而，如果主体必须在联营企业发布其2月份财务报表之前公布自身业绩，这种方法可能不切实际。

这种情形似乎并不满足适用 IAS 1 中允许在特定情况下背离某项准则的条款的条件。IAS 1 要求，仅当遵循某项准则将产生极大的误导以致与《概念框架》中规定的财务报表目标相冲突，且相关监管框架要求或不禁止此类背离时，才可背离准则。在此情形下，背离 IAS 28 实际上将产生比遵循该准则更不可靠、更不相关的结果。

如果主体无法说服联营企业编制能使主体符合准则要求的财务报表，则该主体需要重新评估其是否处于具有重大影响的地位。

### <a id="s228-FAQ_31.51.1"></a>FAQ 31.51.1 – 联营企业报告期末与主体报告期末之间的异常交易

准则索引：IAS 28 第34段  
正文索引：[31.51](56.md#s226-Para_31.51)  
 

  

  
联营企业或合营企业可能在此期间向集团出售固定资产（反之亦然）。（因报告期末之间的重大交易而）作出的任何调整均需在后续年度予以转回，如下列示例所示。

**示例 1 – 联营企业报告期末与主体报告期末之间的重大交易**

主体 A 每年编制截至1月31日的财务报表。主体 A 的一家联营企业主体 Y 编制截至12月31日的财务报表，而不编制截至1月31日的财务报表。

20X2年1月30日，主体 Y 的一家工厂发生重大火灾。该事项在主体 Y 的财务报表中属于资产负债表日后非调整事项。

主体 Y 还在 20X1 年末发起了一项重大促销活动，导致 20X2 年 1 月的销售额和营业利润较上年同期高出 45%。该新增销售额对主体 A 的财务报表具有重大影响。

准则要求，当两个报告日相差在三个月以内且未编制更新日期的财务报表时，必须就间隔期间内发生的重大交易或事项进行调整。主体 A 应在其采用权益法核算主体 Y 的财务报表中，将主体 Y 工厂的火灾作为调整事项处理。该事项在主体 Y 截至 20X1年12月31日编制的财务报表中仍为非调整事项。

由于新增销售额的影响重大，主体 A 应计算主体 Y 新增销售额的影响，并对用于权益法核算主体 Y 经营成果的主体 Y 财务报表作出适当调整。

**示例 2 – 联营企业在其报告期末之后但主体报告期末之前派发股利**

某主体拥有多家联营企业。该主体合并财务报表的报告日为12月31日，而其中一家联营企业的报告日为9月30日，且集团纳入了该联营企业截至这一较早日期编制的财务报表。集团在9月30日至12月31日之间收到了该联营企业派发的股利。因此，当集团在主体年度截止日对该联营企业采用权益法核算时，就会出现不匹配，因为主体收到了股利，而该联营企业截至9月30日的财务报表中尚未反映该股利。

在这种情况下所需的合并调整分录为：借记集团利润表（以剔除母公司自身单独财务报表中列示的从联营企业收到的股利），贷记对联营企业的投资，以反映联营企业因支付股利而导致净资产减少的事实。

### <a id="s228-FAQ_31.51.2"></a>FAQ 31.51.2 – 投资方是否应就报告期间隔期（滞后期）内被投资方盈利的变动调整其权益法核算的收益？

 

准则索引：IAS 28 第33、34段  
正文索引：[31.51](56.md#s226-Para_31.51)  

  

 

由于正在发生的局部或全球性事件，许多主体正面临不利的经营条件，财务业绩受到影响。对于拥有采用权益法核算投资的主体而言，这可能会产生会计影响——可能包括其联营企业的经营业绩下滑、减值及其他相关影响。

 

当投资方对报告期间与投资方不同的被投资方拥有采用权益法核算的投资时，IAS 28 要求投资方就联营企业或合营企业年度截止日与投资方年度截止日之间发生的重大交易或事项，对被投资方的盈利进行调整。[IAS 28 第33段]。[IAS 28 第34段]。

 

投资方与联营企业或合营企业之间的报告期间差异通常被称为“报告期间隔期（滞后期）”。受持续事件的影响，被投资方在报告期间隔期（滞后期）内的经营成果可能已受到影响。

 

**问题**  
投资方是否应就报告期间隔期（滞后期）内被投资方盈利的变动调整其权益法核算的收益？

 

**解答**  
视情况而定。如果报告期间隔期（滞后期）内发生的交易或事项具有重大性，投资方应对报告期间隔期（滞后期）作出调整。确定报告期间隔期（滞后期）内的交易或事项是否重大需要运用判断。

 

这并不必然意味着必须在被投资方的账簿中按照 IFRS 记录单独的会计分录，才能将该交易或事项视为重大并在投资方账簿中进行调整。但是，确实需要存在一项重大事项，才能适用 IAS 28 第34段。确定是否发生了重大事项属于判断问题。仅将受持续事件影响而在该期间出现的相对较差的经营业绩本身视为重大事项是不充分的。表明已发生应当进行调整的重大事项的一项迹象是，投资方能够可靠计量仅由该事项对报告期间隔期（滞后期）内盈利产生的影响。

 

以下示例列举了该事件可能如何影响拥有非同期年度截止日联营企业的主体的财务报告。

 

**示例**

 

主体 A 每年编制截至 2020年3月31日 的年度财务报表。主体 A 的一家联营企业主体 Y 编制截至 2019年12月31日 的年度财务报表。

 

由于持续事件的影响，主体 Y 在 2019年12月31日 至 2020年3月31日 期间的经营业绩出现下滑。

 

示例 1 – 被投资方在报告期间隔期（滞后期）内确认了重大减值

 

发生了一项重大事项——即在报告期间隔期（滞后期）内，被投资方的一个现金产出单元发生了重大减值。如果该事项对投资方具有重大性，投资方应对报告期间隔期（滞后期）的会计处理作出调整。

 

示例 2 – 被投资方因整体经济下滑而出现业绩下降。

 

在报告期间隔期（滞后期）内并未发生重大事项。报告期间隔期（滞后期）内相对较差的经营业绩本身并不表明存在需要在报告期间隔期（滞后期）内进行调整的重大事项。

 

示例 3 – 被投资方因相关事件被政府法令强制关闭门店，但被投资方尚未确认减值或预计负债，且主体能够可靠计量停业对其经营成果的影响

 

发生了一项重大事项。被投资方因相关事件被要求关闭门店是一项具体且重大的事项。因此，如果该金额对投资方的财务报表具有重大性，投资方应对报告期间隔期（滞后期）的会计处理作出调整。

 

上述指引同样适用于经营业绩改善的情形。

 

如果评估持续事件是否构成重大事项涉及重大判断且影响重大，则应提供 IAS 1 第122段所要求的披露。

### <a id="s228-FAQ_31.52.1"></a>FAQ 31.52.1 – 联营企业为企业集团时的权益法应用

准则索引：IAS 28 第27段  
正文索引：[31.52](56.md#s226-Para_31.52)  
 

  

  
主体 X 拥有两家联营企业 A 和 B。联营企业 A 和 B 均持有另一主体 C 的股份。

准则规定，在确定主体 C 是否为主体 X 的联营企业时，主体 X 应忽略联营企业 A 和 B 的持股，因为主体 X 对这两家联营企业仅具有重大影响，而非控制。仅应考虑母公司及其子公司的直接和间接权益。主体 X 通过持有联营企业 A 和 B 而间接源自对主体 C 的权益，将在主体 X 按权益法核算其应享有 A 和 B 经营成果份额时予以考虑。主体 X 集团财务报表中就联营企业 A 和 B 对主体 C 持股所反映的金额，取决于联营企业 A 和 B 如何核算该等持股——即将其作为一般交易性投资（若主体 C 非其联营企业）、作为联营企业（若主体 C 为联营企业 A 和/或 B 的联营企业）还是作为子公司核算，因为准则要求在采用权益法核算时应计入的净资产和损益是联营企业财务报表（包括联营企业应享有其自身联营企业的份额）中确认的金额。（此类财务报表可以是合并财务报表（若该联营企业拥有子公司），也可以是经济利益财务报表（若该联营企业仅拥有联营企业）。）

### <a id="s228-FAQ_31.53.1"></a>FAQ 31.53.1 – 逆流交易的抵销

 

准则索引：IAS 28 第28段  
正文索引：[31.53](56.md#s226-Para_31.53)  

  

  
**示例 1 – 冲减联营企业的账面价值进行抵销**

某主体持有某联营企业 20% 的权益。该联营企业将成本为 C300 的存货以 C500 现金出售给该主体。在资产负债表日，该存货尚未出售给第三方。归属于该主体的利润必须从合并财务报表中予以抵销。该联营企业在该交易中记录了 C200 的利润，主体应享有的利润份额为 C40（C200 × 20%）。

主体将其应享有的利润份额冲减联营企业的账面价值。在通过向第三方转售使交易得以实现之前，主体在联营企业中的权益不因逆流销售产生的利润而增加。这与 IAS 28 第10段的要求一致，因为联营企业按成本加应享有留存利润份额的金额列示。

会计分录为：借记应享有联营企业利润份额（C40），贷记对联营企业的投资（C40）。

假设该主体在次年将该存货以 C500 出售给第三方，由于未实现利润现已通过对外转售得以实现，因此必须转回上年合并时作出的利润抵销分录。由此产生的会计处理与已实现交易的会计处理一致。总体而言，该交易实现了 C200 的利润，集团应享有的利润份额计入应享有联营企业经营成果的份额中。该主体因出售该存货而实现的任何额外利润将按常规方式计入营业利润。

**示例 2 – 冲减所转让资产进行抵销**

事实与示例 1 相同，但主体应享有的利润份额（C40）冲减所转让的资产。在这种情况下，在交易通过对外转售得以实现之前，主体在联营企业中的权益因逆流销售产生的利润而增加。这与 IAS 28 第3段的要求一致，因为联营企业按成本加应享有净资产变动份额的金额列示。联营企业已从该主体收到 C500 现金，因此该逆流交易并未减损联营企业投资的价值。

会计分录为：借记应享有联营企业利润份额（C40），贷记存货（C40）。

假设该主体在次年将该存货以 C500 出售给第三方，由于该利润现已通过向第三方转售得以实现，因此必须转回上年合并时作出的利润抵销分录。主体记录其应享有逆流交易产生的利润份额，并增加存货成本。由此产生的会计处理与已实现交易的会计处理一致。总体而言，该交易实现了 C200 的利润，集团应享有的利润份额计入应享有联营企业经营成果的份额中。该主体因出售该存货而实现的任何额外利润将按常规方式计入营业利润。

取决于所采用的备选会计处理方法，可能产生不同的递延所得税后果。当利得冲减联营企业或合营企业的账面价值时，通常在所转让资产或联营企业或合营企业上均不产生暂时性差异。当利得冲减所转让资产的账面价值时，主体需要考虑是否存在应予核算的暂时性差异。例如，如果该资产是不动产、厂场或设备，则存在两项暂时性差异，仅当主体所得适用的税率与来自联营企业或合营企业未分配利润适用的税率完全相同时，这两项差异才会相互抵销。

### <a id="s228-FAQ_31.53.2"></a>FAQ 31.53.2 – 顺流交易的抵销

准则索引：IAS 28 第28段  
正文索引：[31.53](56.md#s226-Para_31.53)  
 

  

  
由于所涉及的资产已转让给联营企业或合营企业，未实现利润应冲减联营企业或合营企业的账面价值。如果该交易提供了所转让资产发生减值的证据，则不应抵销未实现损失。

某主体持有某合营企业 20% 的权益。该主体将存货以 C500 出售给该合营企业。该存货的原始成本为 C300。在资产负债表日，该存货尚未出售给第三方。

该主体记录了 C200 的利润。然而，由于该销售系向合营企业作出，该利润的一部分属于未实现利润，应予抵销。未实现利润为 C40（20% × C200）。

主体账簿中需要作出的调整为：借记收入 C100（C500 × 20%），贷记销售成本 C60（C300 × 20%）（或者主体可借记应享有合营企业利润份额 C40），并贷记对合营企业的投资 C40。

当合营企业将该存货转售给第三方时，主体应转回上述调整。

### <a id="s228-FAQ_31.58.1"></a>FAQ 31.58.1 – 集团内部往来交易的会计处理

准则索引：IAS 28 第26段  
正文索引：[31.58](56.md#s226-Para_31.58)

在对联营企业采用权益法核算时，该主体将就这些项目列示 C10,000 的利息收入以及 C2,500 的应享有联营企业应付费用份额（作为整体应享有联营企业税后经营成果份额的组成部分）。该主体仅确认了 C7,500 的净收益，代表该主体向联营企业收取的净利息。

### <a id="s228-FAQ_31.60.1"></a>FAQ 31.60.1 – 来自联营企业的分配超过投资账面价值

准则索引：IAS 28 第39段  
正文索引：[31.60](56.md#s226-Para_31.60)  
 

  

  
主体 A 拥有一家联营企业主体 B。主体 A 对主体 B 投资的账面价值为 C2,000。主体 B 向主体 A 派发了 C2,400 的股利。该股利无任何限制，且主体 A 不会被要求退还该股利。

主体 A 应将主体 B 的账面价值减记至零，并在其合并财务报表或经济利益财务报表中将超出部分 C400 确认为一项利得。

主体 A 无义务退还该股利，且确认超出部分的收益不受任何限制。

在后续年度中，当主体 B 实现盈利时，主体 A 必须考虑如何核算其应享有主体 B 利润的份额。主体 A 可以按其应享有的后续利润份额增加对主体 B 投资的账面价值，然后评估该投资是否发生减值。另一方面，主体 A 也可能认为，在先前计入损益的利得被“追回（clawed back）”之前，不确认其应享有主体 B 的后续利润份额是恰当的。主体 A 应选择最能反映事实和情况的会计处理方法。例如，事实和情况可能表明，从投资方的角度看，联营企业向其投资方支付的款项在实质上代表资本返还。这种资本返还可能被视为在性质上不同于投资方将在后续期间通过权益法确认的被投资方未来利润。在这种情况下，就无需追回先前的资本返还。

<a id="s228-chap_31_navPoint_115"></a>
### <a id="s228-FAQ_31.66.1"></a>FAQ 31.66.1 – 计算可收回金额时的实务考量

准则索引：IAS 28 第43段  
正文索引：[31.66](56.md#s226-Para_31.66)  
 

  

  
对联营企业或合营企业投资的账面价值不会自动减记至当前股价。股价下跌是一项减值迹象，同时也确立了该联营企业或合营企业的“公允价值减去处置费用后的净额”。IAS 36 要求在记录减值损失之前，还应采用“使用价值”法计算可收回金额。如果使用价值高于该投资的账面价值，则无需确认减值。

计算联营企业或合营企业的使用价值可能需要从联营企业或合营企业的管理层处获取现金流量预测。来自对联营企业或合营企业投资的未来预期股利流也可用于计量联营企业或合营企业的使用价值。[IAS 28 第42段]。

<a id="s228-chap_31_navPoint_116"></a>
### <a id="s228-FAQ_31.71.1"></a>FAQ 31.71.1 – 关于丧失重大影响的实务考量

 

准则索引：IAS 28 第9段  
正文索引：[31.71](56.md#s226-Para_31.71) 

  

  
1. 投资方能否对在限制条件下经营的联营企业继续具有重大影响？

联营企业可能在以下限制条件下经营：

- 正在进行破产或接管程序

- 政府对资金汇出境外的限制。

- 对该国实施的重大国际制裁，且直接影响主体开展贸易和/或将利润汇出境外的能力。

- 重大政府监管。

在这些情况下，主体可能继续具有重大影响，也可能不再具有重大影响。

尽管联营企业向投资方主体转移资金的能力受到限制，投资方主体仍可能对该联营企业具有重大影响。在评估投资方主体对某主体施加重大影响的能力时，应考虑此类资金转移限制。但此类限制本身并不排除重大影响的存在。

2. 约定不干预联营企业日常业务的合同安排是否会导致丧失重大影响？

对联营企业具有重大影响的主体可能签订不干预联营企业日常业务的合同协议。需要仔细考虑事实和情况，以确定该合同安排是否意味着主体已丧失对该联营企业的重大影响。这将取决于例如合同的法律可执行性以及违约处罚的严厉程度。此外，合同系在股东之间签订还是在公司与股东之间签订，情况也可能有所不同。

 

<a id="s228-chap_31_navPoint_117"></a>
### <a id="s228-FAQ_31.73.1"></a>FAQ 31.73.1 – 联营企业权益减持至一般投资

准则索引：IAS 28 第22(b)段  
正文索引：[31.73](56.md#s226-Para_31.73) 

  

  
主体 A 持有主体 B 40% 的股权。主体 A 以 C750 万的对价出售了其所持股权的 75%（将其投资比例降至 10%）。部分处置日主体 B 的账面价值（含商誉）为 C900 万，且拥有 C50 万的外币折算储备。因此，主体 A 保留了主体 B 10% 的股权，公允价值为 C250 万。

处置时，主体 A 将其保留的主体 B 10% 股权按 C250 万的公允价值确认为金融资产，记录收到的对价 C750 万，终止确认账面价值为 C900 万的联营企业，并将主体 B 的外币折算储备 C50 万重分类至损益，作为处置利得或损失的组成部分。

由此产生的差额形成 C150 万的处置利得（(750万 + 250万 – 900万) + 50万）。

### <a id="s228-FAQ_31.74.1"></a>FAQ 31.74.1 – 主体在联营企业中的持股被稀释

准则索引：IAS 28 第22(b)、(c)段  
正文索引：[31.74](56.md#s226-Para_31.74) 

  

  
主体 A 拥有一家联营企业主体 B，主体 B 已发行 100 股，其中主体 A 持有 30 股。作出投资时，主体 B 净资产的公允价值为 C233，该投资的初始账面价值为 C100（包含 C30 的商誉）。

自作出投资以来，主体 B 产生了利润，该投资目前的账面价值为 C127。主体 B 目前的公允价值为 C600。

主体 B 以 C300（公允价值）向主体 A 以外的投资方发行了 50 股股份。主体 A 的持股比例现被稀释至 20%（30/150 股）。

由于持股比例从 30% 被稀释至 20%，此次稀释意味着主体 A “处置”了其在主体 B 中三分之一的权益。稀释利得或损失通过将所处置权益的账面价值（C127 × 1/3 = C42）与主体 A 应享有的新发股份募集资金份额（C300 × 20% = C60，体现为联营企业净资产的增加）进行比较来计算。因此，稀释利得为 C18。

联营企业账面价值的一部分（C42）予以终止确认，其中包括终止确认原商誉 C30 的三分之一即 C10。应享有的募集资金份额（C60）计入对联营企业投资的账面价值。该利得（C18）增加联营企业的账面价值并计入损益。

### <a id="s228-FAQ_31.79.1"></a>FAQ 31.79.1 – 综合收益表或利润表中的常见列报问题

准则索引：IAS 1 第82段  
正文索引：[31.79](56.md#s227-Para_31.79) 

  

  
1. 主体应享有联营企业或合营企业经营成果的份额能否列示在营业利润之前或邻近位置？

可以。当联营企业或合营企业是集团开展经营活动和实施战略不可或缺的载体时，可能适用此种列报方式。采用该列报方式时，联营企业的经营成果仍按税后金额列示。

2. 与联营企业或合营企业投资相关的减值费用应如何披露？

减值费用的列报应遵循主体应享有联营企业或合营企业经营成果份额的列报方式。减值费用应在应享有联营企业或合营企业经营成果份额的邻近位置作为单独单行项目列报，而不应包含在应享有联营企业或合营企业经营成果的份额之内。

3. 处置联营企业和合营企业的利得和损失应如何列报？

列报方式取决于事实和情况。这些利得和损失通常作为主体经营活动的组成部分列报。

在特定情况下，如果明确表明该处置属于一次性交易（即预计主体未来不会发生类似交易，且过去也没有发生过类似交易的历史），则将处置联营企业和合营企业的利得和损失确认在主体营业利润之外可能是恰当的。

主体的合并财务报表或经济利益财务报表还应包含充分披露，以帮助财务报表使用者理解。

4. 联营企业或合营企业的终止经营是否应包含在 IFRS 5 终止经营单行项目中？

不需要，准则并未要求将主体应享有其联营企业或合营企业终止经营的份额“剥离”出来并计入 IFRS 5 终止经营单行项目中。

### <a id="s228-FAQ_31.80.1"></a>FAQ 31.80.1 – 资产负债表中的常见列报问题

准则索引：IFRS 12 第21段  
正文索引：[31.80](56.md#s227-Para_31.80) 

  

  
1. 对联营企业或合营企业的投资能否进行重估？

一旦采用权益法确定了资产负债表中的权益金额，即使该主体为上市公司，也不允许将对联营企业或合营企业的投资重估至其市场价值。但是，对于存在公开市场报价的联营企业和合营企业投资，要求披露其公允价值。

2. 其他权益（例如向联营企业和合营企业提供的贷款）是否应包含在该单行项目中？

该问题已在[FAQ 31.21.1 – 向联营企业提供的长期贷款](56.md#s228-FAQ_31.21.1)中予以讨论。
