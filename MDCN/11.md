## 引言和范围（第5.1至5.7段）

 

<a id="s32-Para_5.1"></a>**5.1** 当其他国际财务报告准则（IFRS）要求或允许以公允价值计量时，IFRS 13是计量公允价值的单一指南来源。IFRS 13规范了如何计量公允价值，但并未规定何时可以或应当使用公允价值。

[IFRS 13 第1段]。

<a id="s32-Para_5.2"></a>**5.2** 公允价值是指在计量日，从持有资产或承担负债的市场参与者角度所确定的脱手价格。由于公允价值基于市场参与者的视角而非仅基于主体自身的视角，因此公允价值不受主体对所计量资产、负债或权益项目的意图的影响。公允价值是基于市场的计量，而非特定主体的计量。公允价值是指市场参与者在计量日发生的有序交易中，出售一项资产所能收到或者转移一项负债所需支付的价格。

[IFRS 13 第2段]。

<a id="s32-Para_5.3"></a>**5.3** 公允价值计量要求管理层确定以下四个要素：

- 作为计量对象的特定资产或负债（与其计量单元相一致）；

- 非金融资产的最佳用途；

- 主要市场（或不存在主要市场时的最有利市场）；以及

- 估值技术。

[IFRS 13 附录B 第B2段]。

 

<a id="s32-chap_05_navPoint_2"></a>
### 范围

 

<a id="s32-Para_5.4"></a>**5.4** IFRS 13适用于其他准则要求或允许的所有公允价值计量或披露，但以下各项除外：

- IFRS 2规范的股份支付；

- IFRS 16规范的租赁；以及

- 与公允价值类似（但并非公允价值）的计量，包括IAS 2中的可变现净值计量和IAS 36中的使用价值计量。

[IFRS 13 第6段]。

<a id="s32-Para_5.5"></a>**5.5** IFRS 13的计量要求适用于以下项目，但其披露要求不适用：

- 根据IAS 19以公允价值计量的设定受益计划资产；

- 根据IAS 26以公允价值计量的退休福利计划投资；以及

- 根据IAS 36采用公允价值减去处置费用后的净额进行减值测试的资产。

[IFRS 13 第7段]。

<a id="s32-Para_5.6"></a>**5.6** IFRS 13适用于公允价值的初始计量和后续计量。

[IFRS 13 第8段]。

<a id="s32-Para_5.7"></a>**5.7** 首次采用IFRS的主体不享有对IFRS 13的豁免。被要求或选择以公允价值计量资产和负债的首次采用者必须应用IFRS 13。

[IFRS 1 第10(d)段]。

## 计量（第5.8至5.113段）

<a id="s33-chap_05_navPoint_4"></a>
### 步骤1：确定所计量的资产或负债

<a id="s33-chap_05_navPoint_idp1689326264"></a>
#### 特征

<a id="s33-Para_5.9"></a>**5.9** 公允价值计量针对的是特定的资产或负债。因此，如果市场参与者在为该资产或负债定价时会考虑该资产或负债的特定特征，则公允价值计量应当纳入这些特征。这些特征可能包括计量日资产的状况和所在位置，以及对资产出售或使用的限制（如有）。

[IFRS 13 第11段]。

<a id="s33-Para_5.10"></a>**5.10** 各项特征对公允价值计量的影响方式，取决于市场参与者在追求自身最佳经济利益时将如何考虑每一项特征。

[IFRS 13 第22段]。

<a id="s33-chap_05_navPoint_idp1689335224"></a>
#### 计量单元

 

<a id="s33-Para_5.11"></a>**5.11** 视具体情况而定，公允价值计量可能适用于单项资产或负债（例如，一项权益性证券、一项投资性房地产、一项无形资产或一项质保负债），或者适用于一组相关资产和/或负债（例如，一项业务）。

[IFRS 13 第13段]。

<a id="s33-Para_5.12"></a>**5.12** 计量单元决定了公允价值计量的应用方式。计量单元是指根据适用于所计量特定资产或负债的IFRS要求，对资产或负债进行汇总或拆分的层级。对于金融工具而言，IFRS 9（IAS 39）下的计量单元通常为单项金融工具。因此，根据IFRS 9（IAS 39）对金融工具进行公允价值计量时，通常不允许针对作为报告主体持股特征的规模进行溢价或折价调整。参见[第5.87段](11.md#s33-Para_5.87)。

[IFRS 13 第14段]。

 

<a id="s33-chap_05_navPoint_idp1689362104"></a>
#### 市场风险或交易对手信用风险的抵销头寸

 

<a id="s33-Para_5.13"></a>**5.13** 如果主体以市场风险或信用风险（如IFRS 7所定义）的净敞口为基础管理一组金融资产和金融负债，则可选择以净头寸为基础计量该组合的公允价值。在该情况下，用于公允价值计量的计量基础是净头寸（尽管在此情形下净头寸并非计量单元——参见下文[第5.19段](11.md#s33-Para_5.19)），而非单项金融资产和金融负债。

[IFRS 13 第48段]。

<a id="s33-Para_5.14"></a>**5.14** 仅当主体满足以下全部条件时，才允许采用抵销头寸例外规定：

- 按照其形成书面文件的风险管理或投资策略，以市场风险/信用风险的净敞口为基础管理该金融资产/负债组合；

- 以净额为基础向IAS 24所定义的关键管理人员提供有关该金融资产/负债组合的信息；以及

- 在财务状况表中持续以公允价值计量该等金融资产和金融负债。

[IFRS 13 第49段]。

[FAQ 5.14.1 – 在得出净多头或净空头头寸时，应如何考虑市场风险敞口？](12.md#s35-FAQ_5.14.1)

[FAQ 5.14.2 – 采用风险价值（VaR）策略是否足以允许适用抵销头寸例外规定？](12.md#s35-FAQ_5.14.2)

[FAQ 5.14.3 – 应用抵销头寸例外规定所需的支持依据](12.md#s35-FAQ_5.14.3)

<a id="s33-Para_5.15"></a>**5.15** 抵销头寸例外规定仅适用于IFRS 9（IAS 39）范围内的金融资产、金融负债及其他合同。该指南适用于IFRS 9（IAS 39）范围内的所有合同，无论其是否符合金融资产或金融负债的定义。这包括可以现金或其他金融工具净额结算的买入或卖出非金融项目的合同。

[IFRS 13 第52段]。

<a id="s33-Para_5.16"></a>**5.16** 抵销头寸例外规定仅适用于属于IFRS 9范围内且面临相同（或至少实质上相似）市场风险的资产和负债。如果风险不完全相同，则在将组合的公允价值分摊至组成该组合的各项资产和负债时，应当考虑这些差异，如[第5.19段](11.md#s33-Para_5.19)所述。

[IFRS 13 第52段]。

<a id="s33-Para_5.17"></a>**5.17** 抵销头寸例外规定仅适用于期限相似的风险敞口。例如，主体使用一份12个月期的期货合同对冲一项5年期金融工具，则其应对12个月期的利率风险敞口按净额基础计量公允价值，而对剩余的利率风险敞口（即第2年至第5年）按总额基础计量。

[IFRS 13 第55段]。

[FAQ 5.17.1 – 错配示例](12.md#s35-FAQ_5.17.1)

<a id="s33-Para_5.18"></a>**5.18** 如果应用抵销头寸例外规定，净头寸的公允价值应按照IFRS 13的原则计量。例如：

- 对于市场风险，净头寸的公允价值为买卖价差中在主体所处环境下最能代表公允价值的价格。[IFRS 13 第53段]。

- 对于信用风险，此类组合的公允价值应当考虑信用增级（例如总互抵协议和担保品要求）以及市场参与者对这些信用增级在法律上可执行性的预期。[IFRS 13 第56段]。

<a id="s33-Para_5.19"></a>**5.19** 抵销头寸例外规定仅涉及计量，并不允许对组合内的资产和负债进行净额列报。列报问题由其他IFRS规范。在要求总额列报的情况下，应当以合理且一致的基础（例如，采用相对公允价值法）将组合的公允价值分摊至组合内的各项资产和负债。

[IFRS 13 第50段]。

<a id="s33-Para_5.20"></a>**5.20** 使用抵销头寸例外规定以及分摊买卖价差和信用调整的任何政策均被视为一项会计政策，应当针对特定组合各期一致应用。

[IFRS 13 第51段]。

### 步骤2：确定估值前提

<a id="s33-chap_05_navPoint_idp1689239608"></a>
#### 交易

 

<a id="s33-Para_5.21"></a>**5.21** 公允价值计量假定资产或负债是在计量日当前市场条件下，在市场参与者之间的有序交易中交换的。

[IFRS 13 第15段]。

<a id="s33-Para_5.22"></a>**5.22** 公允价值计量基于计量日可获得的信息。仅当合理且惯常的尽职调查能够在计量日识别出额外信息时，计量日之后才获知的信息才被纳入考量。

[IAS 10 第11段]。

[FAQ 9.5.6 – 影响以公允价值为计量基础的资产重新计量/减值计算的资产负债表日后调整事项应如何进行会计处理？](17.md#s57-FAQ_9.5.6)

 

<a id="s33-Para_5.23"></a>**5.23** 拟就某项资产或负债进行交易的市场参与者，预期会在计量时付出一切合理努力以了解该资产及相关风险。

 

[IFRS 13 第BC59段]。

 

<a id="s33-chap_05_navPoint_idp1689256120"></a>
#### 市场参与者

 

<a id="s33-Para_5.24"></a>**5.24** 公允价值计量应当基于市场参与者的假设，而不是特定主体的计量。

[IFRS 13 第22段]。

<a id="s33-Para_5.25"></a>**5.25** 市场参与者是指资产或负债的主要市场（或最有利市场）中具备以下特征的买方和卖方：

- 独立性。交易双方并非IAS 24所定义的关联方。但是，如果有证据表明关联方交易是按市场条款进行的，则并不排除将关联方交易价格用作估值输入值。

- 知情性。交易双方利用所有可获得的信息（包括通过常规和惯常的尽职调查可能获得的信息），对资产或负债以及交易有合理的了解。

- 有能力就该资产或负债进行交易。

- 有意愿就该资产或负债进行交易。交易双方具有交易动机，但并非被迫或以其他方式被强制进行交易。

[IFRS 13 附录A]。

<a id="s33-Para_5.26"></a>**5.26** 希望出售资产或转移负债的市场参与者，力求在资产或负债的主要市场（或最有利市场）的交易中，使资产的公允价值最大化或使负债的公允价值最小化。市场参与者被假定为按其最佳经济利益行事。

[IFRS 13 第22段]。

<a id="s33-Para_5.27"></a>**5.27** 主体无须识别特定的市场参与者，而是应当构建潜在市场参与者的特征画像。该特征画像应当考虑特定于该资产或负债的因素、该资产或负债的主要市场（或不存在主要市场时的最有利市场），以及主体在该市场中将与之进行交易的市场参与者。

[IFRS 13 第23段]。

<a id="s33-Para_5.28"></a>**5.28** 在不存在可观察市场的情况下，公允价值通过考虑将就该资产或负债进行假设交易的市场参与者的特征来确定。

[IFRS 13 第23(c)段]。

[FAQ 5.28.1 – 确定假设的市场参与者](12.md#s35-FAQ_5.28.1)

 

<a id="s33-chap_05_navPoint_idp1689277368"></a>
#### 进入价格与脱手价格

 

<a id="s33-Para_5.29"></a>**5.29** 公允价值基于脱手价格而非进入价格。脱手价格是指出售资产所能收到或转移负债所需支付的价格。进入价格是指取得资产所支付的价格或承担负债所收到的价格。从概念上讲，进入价格与脱手价格是不同的。脱手价格概念基于市场参与者视角下对出售或转移价格的当前预期。

[IFRS 13 第24段]。

[FAQ 5.29.1 – 信用风险对衍生工具公允价值的影响](12.md#s35-FAQ_5.29.1)

<a id="s33-Para_5.30"></a>**5.30** 如果对资产出售或使用的限制与该资产本身有关而非与资产持有者有关，且市场参与者在确定其愿意支付的价格时会考虑这些限制，则公允价值应当考虑对资产出售或使用的任何限制。

[IFRS 13 第11(b)段]。

#### 确定价格时的交易费用

 

<a id="s33-Para_5.31"></a>**5.31** 交易费用是指：

“在资产或负债的主要市场（或最有利市场）中出售资产或转移负债所发生的、可直接归属于资产处置或负债转移且同时满足以下两项标准的费用：a) 直接源自该交易且为该交易必不可少的费用；b) 如果主体未作出出售资产或转移负债的决定，则不会发生的费用（类似于IFRS 5中定义的出售费用）。”

[IFRS 13 附录A]。

<a id="s33-Para_5.32"></a>**5.32** 公允价值不应当针对交易费用进行调整，交易费用应当按照其他IFRS进行会计处理。尽管根据公允价值准则，交易费用不计入资产或负债的公允价值中，但在评估净交易所得以确定最有利市场时，应当包括这些金额。参见[第5.61段](11.md#s33-Para_5.61)。

[IFRS 13 第25段]。

 

<a id="s33-chap_05_navPoint_idp1695858472"></a>
#### 非金融资产的特定考量：最佳用途

 

<a id="s33-Para_5.33"></a>**5.33** 非金融资产的公允价值应当从市场参与者的角度，基于其最佳用途进行计量。该考量不适用于金融工具、负债或权益。

[IFRS 13 第27段]。

<a id="s33-Para_5.34"></a>**5.34** 最佳用途考虑以下资产用途：

- 实物上可能——考虑市场参与者会考虑的实物特征（例如，房地产的位置或面积）；

- 法律上允许——考虑市场参与者会考虑的对资产使用的法律限制（例如，规划或分区管制法规）；以及

- 财务上可行——考虑资产的使用是否能够产生足够的收益或现金流量，以实现市场参与者所要求的投资回报。这应当纳入将资产转换为该用途的成本。

[IFRS 13 第28段]。

[EX 5.34.1 – 成本与非金融资产的最佳用途](12.md#s35-EX5.34.1)  
[EX 5.34.2 – “最佳用途”方法](12.md#s35-EX5.34.2)

<a id="s33-Para_5.35"></a>**5.35** 房地产的最佳用途取决于其用途而非其分类。例如，如果主体对其总部房地产采用IAS 16中的重估价模式，则公允价值的确定将基于该房地产的最佳用途是作为办公楼还是其他用途，而不是基于该房地产是自用还是投资性房地产。参见[第5.116段](11.md#s34-Para_5.116)。

[IFRS 13 第29段]。

<a id="s33-Para_5.36"></a>**5.36** 除非市场或其他因素表明并非如此，否则管理层可以假定资产的当前用途即为最佳用途。力求使其资产价值最大化的主体会以最佳用途使用这些资产。仅当有证据表明资产的当前用途并非其最佳用途时，管理层才考虑这些资产的替代用途。资产的当前用途不是其最佳用途的情况不太可能发生。

[IFRS 13 第29段]。

<a id="s33-Para_5.37"></a>**5.37** 最佳用途从市场参与者的角度确定，与主体是否打算以不同方式使用该资产无关。例如，主体可能为了维护或提升自身品牌的竞争地位而对竞争对手品牌进行防御性收购，且不打算使用该品牌。尽管主体有此意图，其仍应假定市场参与者以最佳用途使用该竞争对手品牌来计量其公允价值。

[IFRS 13 第30段]。

<a id="s33-Para_5.3"></a>**5.38** 资产的最佳用途可能是单独使用，也可能通过与其他资产和/或负债组合使用而实现。在后一种情况下：

- 公允价值基于该资产在此类资产/负债组合中的用途。假定该资产将在该组合中使用，且其他资产和负债可供市场参与者获取。

- 该资产/负债组合不能包括用于为该资产/负债组合之外的资产提供融资的负债。

- 对于此类资产/负债组合中的所有非金融资产，关于最佳用途的假设应当保持一致。

[IFRS 13 第31段]。

<a id="s33-Para_5.39"></a>**5.39** 公允价值计量假定该资产是按照与计量单元一致的方式出售，而非作为资产组合整体出售，因为假定市场参与者已经拥有其他资产。

[IFRS 13 第32段]。

[FAQ 5.39.2 – 按单项基础还是按组合基础对资产估值——其他资产](12.md#s35-FAQ_5.39.2)

 

[FAQ 5.39.3 – 最佳用途概念的应用](12.md#s35-FAQ_5.39.3)

#### 负债和权益的特定考量

<a id="s33-chap_05_navPoint_idp1686814248"></a>
##### 负债的转移

 

<a id="s33-Para_5.41"></a>**5.41** 金融负债、非金融负债或主体自身权益工具的公允价值假定该工具在计量日转移给市场参与者，而非被清偿、取消或终止。无论在哪种情况下，均假定作为受让方的市场参与者承接与该工具相关的权利和义务。按清偿基础进行的计量可能与计量日的公允价值不同。可能的清偿时间、金额和概率将成为公允价值计量的输入值。

<a id="s33-chap_05_navPoint_idp1686826152"></a>
##### 其他方作为资产持有的负债和权益工具

 

<a id="s33-Para_5.42"></a>**5.42** 由于合同和法律对负债及权益转移存在限制，负债和权益的可观察活跃市场存在的可能性要小得多。即使是存在报价的债务或权益性证券，该市场也是作为交易对手证券持有者的退出机制，而非发行方的退出机制。因此，报价反映的是投资者的脱手价格而非发行方的脱手价格。当发行方无法获得转移报价，但该工具由另一方作为资产持有时，管理层应当从资产持有者的角度计量公允价值。

[IFRS 13 第37段]。

<a id="s33-Para_5.43"></a>**5.43** 该负债或权益工具的公允价值按以下方式确定：

- 使用由另一方作为资产持有的相同项目在活跃市场中的报价（例如，活跃报价的债务性证券价格）。

- 如果无法获得（a）项中的价格，则使用其他可观察输入值，例如由另一方作为资产持有的相同项目在非活跃市场中的报价（例如，在较不活跃市场中报价的债务性证券价格）。

- 如果无法获得（a）项和（b）项中的可观察输入值，则使用其他估值技术，例如：

- 收益法——该方法使用现值技术，考虑市场参与者预期因作为资产持有该负债或权益工具而收到的未来现金流出。

- 市场法——在这种方法下，公允价值使用其他方作为资产持有的类似负债或权益工具的报价来确定。

[IFRS 13 第38段]。

[FAQ 5.43.1 – 使用现值技术按公允价值计量的债务义务](12.md#s35-FAQ_5.43.1)

<a id="s33-Para_5.44"></a>**5.44** 仅当存在特定于该资产但不适用于该负债或权益工具公允价值计量的因素（例如，阻止该资产出售的限制）时，主体才应当对其他方作为资产持有的负债或权益工具的报价进行调整。在计量负债的公允价值时，不应当针对负债发行方转移负债的限制设置单独的输入值或对现有输入值进行调整。这与从资产持有者角度确定的公允价值形成对比，后者必须考虑对资产持有者转移资产的任何限制。参见[第5.30段](11.md#s33-Para_5.30)。

[IFRS 13 第39段]。[IFRS 13 第45段]。

<a id="s33-Para_5.45"></a>**5.45** 计量单元同样具有相关性（参见[第5.52段](11.md#s33-Para_5.52)）。例如，一项有报价的债务性证券可能由第三方担保提供保障。此类证券的报价将反映该担保的价值。如果发行方仅计量其自身负债的公允价值，且计量单元不包括该担保，则发行方应当从报价中剔除该担保的影响。如果管理层使用类似（但非相同）债务或权益工具的报价对其自身债务进行估值，则必须针对两项债务或权益工具之间的任何特征差异进行调整。用于计量相应负债或权益工具公允价值的资产价格，不应反映阻止该资产出售的限制的影响。表明应当对资产价格进行调整的因素包括：

- 报价涉及的是类似但非相同的资产；或

- 资产的计量单元与负债的计量单元不同。

[IFRS 13 第39段]。

<a id="s33-chap_05_navPoint_idp1686852008"></a>
##### 并非由其他方作为资产持有的负债

 

<a id="s33-Para_5.46"></a>**5.46** 某些负债并非由另一方作为资产持有（例如，弃置义务）。此类负债的公允价值从受让该负债的市场参与者的角度进行计量。如果该负债不存在实际市场，则需要使用估值技术计量该负债的公允价值。

[IFRS 13 第40段]。

<a id="s33-Para_5.47"></a>**5.47** 这些估值技术可包括考虑以下任一内容的现值技术：

- 市场参与者预期在履行该义务时将发生的未来现金流出，包括市场参与者因承担该义务而要求的补偿；或

- 市场参与者为签订或发行相同负债而收到的金额，同时采用市场参与者在主要市场（或不存在主要市场时的最有利市场）中为相同项目（例如，具有相同信用特征）定价时所使用的假设。

[IFRS 13 第41段]。

<a id="s33-Para_5.48"></a>**5.48** 现值计算应当反映市场参与者预期在履行该义务时将发生的未来现金流出。这些现金流出应当包括：

- 市场参与者对履行该义务所需成本的预期；以及

- 市场参与者所要求的补偿，其中应包括以下两方面的回报：

- 承担该项活动——由于市场参与者将为此消耗宝贵资源，因此其预期就履行该义务获得补偿；以及

- 承担与该义务相关的风险——因承担相关义务，市场参与者通常会要求风险溢价，以补偿实际现金流出可能与预期不同的风险。

[IFRS 13 附录B 第B31段]。

<a id="s33-Para_5.49"></a>**5.49** 用于补偿因承担义务所面临风险的风险溢价，可以通过调整现金流量或折现率来纳入。但不得同时调整现金流量和折现率而对同一风险进行重复计算。

[IFRS 13 附录B 第B33段]。

<a id="s33-Para_5.50"></a>**5.50** 非金融负债可能没有合同回报率或可观察的市场收益率。以公允价值计量此类负债时，各项回报组成部分可能难以区分（例如，采用第三方承包商按固定收费基础收取的价格时）。在其他情况下，各项组成部分可能需要分别估计（例如，采用第三方承包商按成本加成基础收取的价格时）。其目标是确定与主体具有相同信用风险的潜在市场参与者为承担该负债所要求的补偿。

[IFRS 13 附录B 第B32段]。

[FAQ 5.50.1 – 弃置义务](12.md#s35-FAQ_5.50.1)

##### 不履约风险

 

<a id="s33-Para_5.51"></a>**5.51** 负债的公允价值应当反映不履约风险的影响，即主体不履行义务的风险。不履约风险包括信用风险的影响，以及影响履行义务可能性的任何其他因素。这同时适用于金融负债和非金融负债。假定不履约风险在负债转移前后保持不变。这一概念假定该负债将转移给信用等级相当的主体。

[IFRS 13 第42段]。

<a id="s33-Para_5.52"></a>**5.52** 计入公允价值的不履约风险水平应当与计量单元相一致。例如，如果第三方信用增级与负债分开进行会计处理，则应当剔除该第三方信用增级的影响。

##### 股东权益

<a id="s33-chap_05_navPoint_6"></a>
### 步骤3：确定市场

<a id="s33-Para_5.55"></a>**5.55** 管理层基于将在主要市场（或在不存在主要市场时在最有利市场）发生的交易来确定公允价值。

[IFRS 13 第16段]。

<a id="s33-Para_5.56"></a>**5.56** 管理层应当评估各个不同市场的交易活跃程度。主体无需为识别主要市场或最有利市场而对所有可能市场进行穷尽式搜寻，但应当考虑所有易于获得的信息。在缺乏相反证据的情况下，主体通常进行交易的市场被假定为主要市场（或不存在主要市场时的最有利市场）。

[IFRS 13 第17段]。

<a id="s33-chap_05_navPoint_idp1687164216"></a>
#### 主要市场

 

<a id="s33-Para_5.57"></a>**5.57** 主要市场是指资产或负债交易量最大和交易活跃程度最高的市场（不一定是对特定报告主体而言交易量最大的市场）。

[IFRS 13 附录A]。

<a id="s33-Para_5.58"></a>**5.58** 如果存在主要市场，即使其他市场的价格更为有利，也必须使用该主要市场的价格。管理层在确定该市场价格时所参考的交易可以是实际交易，也可以是假设交易。

[IFRS 13 第18段]。

 

<a id="s33-chap_05_navPoint_idp1687175224"></a>
#### 最有利市场

<a id="s33-Para_5.59"></a>**5.59** 最有利市场是指在考虑交易费用和运输费用后，能够以最高金额出售资产或者以最低金额转移负债的市场。

[IFRS 13 附录A]。

[FAQ 5.59.1 – 可转换债券最有利市场的确定](12.md#s35-FAQ_5.59.1)  
[FAQ 5.59.2 – 主要市场或最有利市场](12.md#s35-FAQ_5.59.2)

<a id="s33-Para_5.60"></a>**5.60** 管理层评估其能够合理预期出售资产或转移负债的所有潜在市场，以确定最有利市场。对于非金融资产，识别潜在市场将从市场参与者的角度基于“最佳用途”的估值前提。为确定非金融资产的最佳用途（参见第5.33至5.40段），报告主体可能需要考虑多个市场。由于大多数非金融资产已处于其“最佳用途”中，因此该项要求并不像表面上看起来那样繁重。

#### 确定最有利市场时的交易费用

 

<a id="s33-Para_5.61"></a>**5.61** 公允价值不应当针对交易费用进行调整（[参见第5.32段](11.md#s33-Para_5.32)）。根据IFRS 13，交易费用不包括运输费用。如果位置是资产的一项特征（例如，某项大宗商品），则公允价值应当针对运输费用进行调整。交易费用仅在确定最有利市场时予以考虑。

[IFRS 13 第BC54段]。

[FAQ 5.61.2 – 确定公允价值时运输费用的影响](12.md#s35-FAQ_5.61.2)

 

<a id="s33-chap_05_navPoint_idp1687990680"></a>
#### 市场可进入性

 

<a id="s33-Para_5.62"></a>**5.62** 符合条件的市场仅限于主体在计量日能够进入的市场。由于不同的报告主体可能能够进入不同的市场，因此不同报告主体的主要市场或最有利市场可能各不相同。此外，同一主体可能开展多项不同业务，针对相同的资产或负债使用不同的市场。无需为整个主体识别单一的主要市场或最有利市场；主体内各个不同的业务单元可以拥有各自的主要市场或最有利市场。

[IFRS 13 第19段]。

[FAQ 5.62.1 – 可进入不同市场的经营单位](12.md#s35-FAQ_5.62.1)

<a id="s33-Para_5.63"></a>**5.63** 尽管主体必须能够进入该市场，但主体并不需要在计量日能够出售该特定资产或转移该特定负债，即可基于该市场的价格计量公允价值。

[IFRS 13 第20段]。

<a id="s33-Para_5.64"></a>**5.64** 某项资产或负债可能不存在已知的或可观察的市场。管理层应当首先识别潜在的市场参与者（例如，战略买方和财务买方），然后基于这些市场参与者的预期假设构建一个假设市场。

<a id="s33-chap_05_navPoint_7"></a>
### 步骤4：确定计量公允价值的估值技术

 

<a id="s33-Para_5.65"></a>**5.65** 计量资产和负债公允价值主要有三种方法：市场法、收益法和成本法。这些方法同时适用于金融工具和非金融项目。

[IFRS 13 第62段]。

 

<a id="s33-chap_05_navPoint_idp1688015256"></a>
#### 估值技术的选择

 

<a id="s33-Para_5.66"></a>**5.66** 所选择的估值技术应当：

- 在当前情况下适用；

- 有足够可利用的数据支持该技术；

- 优先使用相关可观察输入值，并尽量减少使用不可观察输入值。

[IFRS 13 第61段]。

[FAQ 5.66.1 – 输入值可观察的市场](12.md#s35-FAQ_5.66.1)  
[FAQ 5.66.2 – 信用风险对金融工具公允价值的影响](12.md#s35-FAQ_5.66.2)  
 [FAQ 5.66.3 – 基于组合的信用风险调整](12.md#s35-FAQ_5.66.3)

<a id="s33-Para_5.67"></a>**5.67** 估值技术应当与下述目标保持一致，即估计在计量日当前市场条件下市场参与者之间进行出售资产或转移负债的有序交易的价格。

[IFRS 13 第62段]。

<a id="s33-Para_5.68"></a>**5.68** 使用多种估值技术可能是适当的；在此情况下，需要评估各种计量技术结果的合理性。应当采用估值结果或价值区间内在该情况下最能代表公允价值的数值。如果交易价格即为初始确认时的公允价值，且后续期间将采用使用不可观察输入值的估值技术计量公允价值，则应当对该估值技术进行校准，以使估值技术在初始确认时的结果等于交易价格。校准可确保估值技术反映当前市场条件，并有助于主体确定是否需要对估值技术进行调整（例如，由于估值技术未能捕捉到的资产或负债的某项特征）。

[IFRS 13 第63段]。[IFRS 13 第64段]。

[FAQ 5.68.1 – 选择一种或多种估值技术时的若干考量因素](12.md#s35-FAQ_5.68.1)

<a id="s33-Para_5.69"></a>**5.69** 估值技术应当逐年一致应用，除非替代技术能提供同等或更具代表性的公允价值指示。这同样适用于可能对多种估值技术结果采用的权重。任何变更均被视为会计估计变更，但无需作出IAS 8的披露。

[IFRS 13 第66段]。

<a id="s33-Para_5.70"></a>**5.70** 以下事件可能需要变更估值技术或权重：

- 出现新市场；

- 可以取得新信息；

- 无法再取得以前使用的信息；

- 估值技术得到改进；或

- 市场条件发生变化。

[IFRS 13 第65段]。

 

<a id="s33-chap_05_navPoint_idp1688042520"></a>
#### 估值技术——市场法

<a id="s33-Para_5.71"></a>**5.71** 市场法是一种利用直接源自相关市场交易公开信息的价格及其他相关信息的估值技术。这些市场交易应当涉及相同或可比（即类似）的资产、负债或业务。市场法也可能适用于非金融资产，例如未上市权益或土地和建筑物。部分无报价的权益性证券可采用源自可比有报价权益性证券的每股收益乘数进行公允价值计量。土地和建筑物可参考可比房地产的销售成交价格进行公允价值计量。

[IFRS 13 附录A]。

<a id="s33-Para_5.72"></a>**5.72** 市场法的示例包括：

- 使用源自可比交易的市场乘数的估值技术。

- 矩阵定价——一种主要用于对某些类型金融工具（如债务性证券）进行估值的数学技术，其不单纯依赖特定证券的报价，而是依赖这些证券与其他基准有报价证券之间的关系。

[IFRS 13 附录B 第B6段]。[IFRS 13 附录B 第B7段]。

<a id="s33-chap_05_navPoint_idp1688241560"></a>
#### 估值技术——收益法

<a id="s33-Para_5.73"></a>**5.73** 收益法采用现金流量模型，将其折现为单一现值金额。该模型基于当前市场对这些未来现金流量的预期构建。

[IFRS 13 附录A]。

<a id="s33-Para_5.74"></a>**5.74** 收益法的示例包括：

- 现值技术（[参见第5.75段](11.md#s33-Para_5.75)至[第5.79段](11.md#s33-Para_5.79)）。

- 多期超额收益法（MEEM）（参见[第5.132段](11.md#s34-Para_5.132)）。

- 期权定价模型。其中包括布莱克-斯科尔斯-默顿（Black-Scholes-Merton）公式和二叉树模型，这些模型结合了现值技术，并同时反映了期权的时间价值和内在价值。

[IFRS 13 附录B 第B11段]。

<a id="s33-chap_05_navPoint_idp1688254104"></a>
#### 现金流量折现法的使用；现值技术

 

<a id="s33-Para_5.75"></a>**5.75** 现值技术是一种收益法，通过使用适当的折现率将未来金额（例如预期未来现金流量）与现值联系起来。主体通常确定与资产/负债相关的预期现金流量，并使用适当的折现率对这些现金流量进行调整。IFRS 13既未规定必须使用某一种特定的现值技术，也未限制使用现值技术计量公允价值，而是指出报告主体应当根据所计量资产或负债及其交易市场的特定事实和情况，使用适当的估值技术。

[IFRS 13 附录B 第B12段]。

<a id="s33-Para_5.76"></a>**5.76** 使用现值进行公允价值计量时，应当从市场参与者的角度捕捉以下关键要素：

- 对未来现金流量的估计；

- 对现金流量金额和时间可能发生变动的预期；

- 货币时间价值，基于到期日或久期与现金流量涵盖期间一致、且对持有者既无时间不确定性又无违约风险的货币性资产的无风险利率（即“无风险”利率）；

- 因不确定性和流动性不足产生的风险溢价；

- 市场参与者在当前情况下会考虑的其他因素；以及

- 对于负债而言，包括报告主体自身信用风险在内的不履约风险。

[IFRS 13 附录B 第B13段]。

<a id="s33-Para_5.77"></a>**5.77** 适用于所有现值技术的一般原则如下：

- 现金流量和折现率应当反映市场参与者在为资产或负债定价时会使用的假设。

- 现金流量和折现率应当仅考虑归属于所计量资产或负债的因素。

- 为避免重复计算或遗漏风险因素的影响，折现率应当反映与现金流量中隐含假设相一致的假设。例如，如果使用贷款的合同现金流量（即折现率调整法），则采用反映未来违约预期不确定性的折现率是适当的；但如果使用预期（即概率加权）现金流量（即期望现值法），则不应当使用相同的折现率，因为预期现金流量已经反映了对未来违约不确定性的假设；相反，应当使用与现金流量已进行风险调整这一事实相匹配的折现率。

- 关于现金流量和折现率的假设应当在内部保持一致。例如，包含通货膨胀影响的名义现金流量应当使用包含通货膨胀影响的折现率进行折现；名义无风险利率包含通货膨胀的影响。剔除通货膨胀影响的实际现金流量应当使用剔除通货膨胀影响的折现率进行折现。同样，税后现金流量应当使用税后折现率进行折现；税前现金流量应当使用与该等现金流量相一致的折现率进行折现。

- 折现率应当与现金流量计价货币的潜在经济因素保持一致。

[IFRS 13 附录B 第B14段]。

[FAQ 5.77.1 – 单一现金流量与概率加权现金流量](12.md#s35-FAQ_5.77.1)

[FAQ 5.77.2 – 金融工具公允价值计量中的现金流量不确定性](12.md#s35-FAQ_5.77.2)

[FAQ 5.77.3 – 第三层次公允价值计量中的现金流量不确定性与估值技术变更](12.md#s35-FAQ_5.77.3)

<a id="s33-Para_5.78"></a>**5.78** 预测现金流量同时面临特定风险（或非系统性风险）和系统性风险。不同的现值技术在如何针对风险进行调整以及所使用的现金流量类型方面存在差异。

[IFRS 13 附录B 第B17段]。

<a id="s33-Para_5.79"></a>**5.79** 特定风险是指仅针对单一主体或行业的风险，通常可以通过分散化予以消除或至少大幅降低。系统性风险是指源自总体市场、经济或政治风险的风险，无法通过分散化予以降低。调整现金流量以反映系统性风险通常较为困难。通常，应用于现金流量的折现率会纳入系统性或不可分散风险，以市场参与者所要求的加权平均资本成本表示。

[IFRS 13 附录B 第B24段]。

[FAQ 5.79.1 – 经济高度不确定时期第三层次公允价值计量所用折现率的额外考量](12.md#s35-FAQ_5.79.1)

 

<a id="s33-chap_05_navPoint_idp1688280216"></a>
#### 估值技术——成本法

 

<a id="s33-Para_5.80"></a>**5.80** 成本法通常被称为现行重置成本法。它是一种试图确定替代某项资产服务能力所需金额的估值技术。成本法假定公允价值为购置或建造具有可比效用的替代资产的成本，并针对陈旧贬值——包括实体性贬值、功能性（技术性）贬值和经济性贬值——进行调整。因此，在使用重置成本法时，报告主体需要考虑产品改进的影响。成本法通常适用于采用收益法或市场法无法得出合理结果的专用设施、建筑物或设备，或者用于印证另一种估值方法。在几乎没有或完全没有可比交易数据导致无法使用市场法的情况下，也可采用成本法。参见[第5.117段](11.md#s34-Para_5.117)。

[IFRS 13 附录B 第B9段]。

 

<a id="s33-chap_05_navPoint_idp1688293272"></a>
#### 基于买入价和卖出价的输入值

 

<a id="s33-Para_5.81"></a>**5.81** 买入价和卖出价在金融工具市场中十分常见。交易商随时准备按买入价买入，并按卖出价卖出。如果公允价值计量中的某项输入值基于买入价和卖出价，则应当使用买卖价差中在当前情况下最能代表公允价值的价格来计量公允价值。允许但不要求对多头头寸（资产）使用买入价，对空头头寸（负债）使用卖出价。当定价包含买卖价差时，负债的公允价值可能与相应资产的公允价值不同。资产和负债在买卖价差中最具代表性的公允价值可能存在差异。

[IFRS 13 第70段]。

<a id="s33-Para_5.82"></a>**5.82** 不排除将中间市场定价或市场参与者使用的其他定价惯例作为计量公允价值的实务权宜方法。

#### 关于使用中间市场定价惯例的政策变更

 

<a id="s33-Para_5.83"></a>**5.83** 报告主体必须制定并一致应用关于在买卖价差内进行定价的会计政策。报告主体需要考虑其可能选择的实务影响及其他影响。估计公允价值的方法通常应当保持一致应用。

### 步骤5：确定公允价值

<a id="s33-chap_05_navPoint_idp1688319640"></a>
#### 初始确认时的公允价值

 

<a id="s33-Para_5.84"></a>**5.84** 交易价格可能不等于公允价值。公允价值基于脱手价格概念。交易价格通常能够代表脱手价格，但并非总是如此。

[IFRS 13 第57段]。

<a id="s33-Para_5.85"></a>**5.85** 管理层在确定交易价格是否代表公允价值时，应当考虑特定于该交易以及该资产或负债的因素，并考虑第5.86段中的任何条件是否适用。

[IFRS 13 第59段]。

<a id="s33-Para_5.86"></a>**5.86** 如果存在以下任何一种情况，交易价格在初始确认时可能并不代表公允价值：

- 交易发生在关联方之间。但是，如果有证据表明该交易是按市场条款进行的，则可在公允价值计量中予以考虑。

- 交易是在被迫情况下发生的，或卖方被迫接受交易价格（例如，由于财务困难）。

- 交易的计量单元与拟按公允价值计量的资产或负债不同。例如：

- 拟按公允价值计量的资产或负债仅是该交易的组成部分之一（例如，在企业合并中）；

- 交易包含按照另一项IFRS单独计量的未明示权利和特权（例如财务担保）；或

- 交易价格包含交易费用。

- 交易并非发生在主要市场或最有利市场——例如，如果交易商的主要市场或最有利市场是交易商市场，则零售市场价格不能代表该交易商的公允价值。

<a id="s33-chap_05_navPoint_idp1688330392"></a>
#### 估值溢价和折价

<a id="s33-Para_5.87"></a>**5.87** 可能需要进行估值调整以反映所计量资产或负债的特定特征，例如控制权溢价或非控制性权益折价。纳入此类调整时需注意两项限制条件：

- 不允许纳入与所计量资产或负债的计量单元不一致的溢价或折价调整；以及

- 仅当调整反映资产或负债的特征（例如控制权溢价）时才允许进行调整。不允许针对反映主体持有规模特征的溢价或折价进行调整。具体而言，IFRS 13禁止针对大宗交易折价因素进行调整，即因市场正常日交易量不足以消化主体所持数量而对资产或负债的报价作出的调整。

如果资产或负债存在活跃市场中的报价（即第一层次输入值），管理层在计量公允价值时应当未经调整地使用该价格。

#### 公允价值层次

 

<a id="s33-Para_5.88"></a>**5.88** IFRS 13确立了与IFRS 7所确立层次等同的公允价值层次。第一层次输入值享有最高优先权，第三层次输入值享有最低优先权。

[IFRS 13 第72段]。

<a id="s33-Para_5.89"></a>**5.89** 公允价值计量整体上归类于对整个计量具有重要意义的最低层次输入值所属的公允价值层次。如果某项输入值可能导致显著不同的公允价值计量结果，则该输入值具有重要意义。应当考虑特定于该资产或负债的因素。确定某项特定输入值对公允价值计量的重要性需要运用判断。切入点是考虑纳入公允价值计量的各项输入值、每项输入值的相对重要性，以及这些输入值是可外部验证的还是通过内部估计得出的。不属于公允价值组成部分、但其他会计准则要求管理层纳入计量的调整（例如在公允价值减去处置费用后的净额估值中的处置费用），在确定公允价值层次时不予考虑。

[IFRS 13 第73段]。

[FAQ 5.89.2 – 主体在多大程度上可以使用其无法进入的市场中的报价？](12.md#s35-FAQ_5.89.2)

[FAQ 5.89.3 – 输入值分类的重新评估](12.md#s35-FAQ_5.89.3)

<a id="s33-Para_5.90"></a>**5.90** 公允价值层次根据输入值的类型对公允价值计量进行排序，而不取决于所使用的估值技术类型。

[IFRS 13 第74段]。

##### 第一层次

 

<a id="s33-Para_5.91"></a>**5.91** 第一层次输入值是主体在计量日能够进入的活跃市场中相同资产或负债未经调整的报价。

[IFRS 13 第76段]。

[FAQ 5.91.1 – 计量符合第一层次条件的金融工具示例](12.md#s35-FAQ_5.91.1)

<a id="s33-Para_5.92"></a>**5.92** IFRS 13将活跃市场定义为相关资产或负债的交易量和交易频率足以持续提供定价信息的市场。

[IFRS 13 附录A]。

<a id="s33-Para_5.93"></a>**5.93** 第一层次计量应当侧重于主要市场（如果不可得，则为最有利市场）。交易主体应当能够在计量日于所选市场中进行交易。

[IFRS 13 第78段]。

<a id="s33-Para_5.94"></a>**5.94** 只要报价可得，就应当未经调整地使用该报价，但以下情况除外：

- 对于存在活跃市场报价但报价不易获取的大量类似资产或负债（例如债务性证券），存在一种实务权宜方法。报告主体可以采用替代定价方法（例如矩阵定价）来计量公允价值，而无需获取每项单项证券的报价。如果将替代定价方法作为实务权宜方法使用，则由此得出的公允价值计量将归类于较低层次（通常为第二层次）。

- 当某市场收盘后但在计量日之前发生重大事件（例如，自营对自营交易、经纪交易和公告）时，市场报价可能不再代表计量日的公允价值。管理层应当制定并一致应用一项政策，以识别和纳入可能影响公允价值计量的事件。如果管理层对报价进行调整，则由此得出的计量结果将不再分类为第一层次，而是分类为较低层次的计量。

- 主体使用作为资产交易的相同项目的报价来计量其有报价的负债或权益工具的公允价值。如果使用该报价，这将属于第一层次计量。但是，该报价可能反映了不适用于该负债或权益工具的因素（参见[第5.44段](11.md#s33-Para_5.44)）。应当针对这些因素对公允价值进行调整，由此得出的公允价值计量将分类为较低层次。

[IFRS 13 第79段]。

##### 第二层次

<a id="s33-Para_5.95"></a>**5.95** 第二层次输入值是除第一层次输入值所包含报价之外，资产或负债直接或间接可观察的输入值。

[IFRS 13 第81段]。

<a id="s33-Para_5.96"></a>**5.96** 第二层次输入值包括：

- 活跃市场中类似资产或负债的报价。

- 非活跃市场中相同或类似资产或负债的报价。

- 除报价以外，资产或负债的其他可观察输入值，例如：

- 在通常报价间隔期内可观察的利率和收益率曲线。

- 隐含波动率。

- 信用利差。

- 市场印证的输入值。

[IFRS 13 第82段]。

[FAQ 5.96.1 – 第二层次输入值](12.md#s35-FAQ_5.96.1)

<a id="s33-Para_5.97"></a>**5.97** 如果资产或负债具有特定（合同）期限，则第二层次输入值必须在该资产或负债的几乎整个期限内均可观察。

[IFRS 13 第82段]。

<a id="s33-Para_5.98"></a>**5.98** 对第二层次输入值的调整应当包括诸如计量日资产或负债的状况和/或所在位置，以及观察到输入值的市场中的交易量和交易活跃程度等因素。在输入值并非完全涉及与所计量资产或负债可比的项目（包括[第5.44段](11.md#s33-Para_5.44)所述因素）的范围内，也需要进行调整。

[IFRS 13 第83段]。

[FAQ 5.98.1 – 类似但非相同金融工具的第二层次输入值](12.md#s35-FAQ_5.98.1)

<a id="s33-Para_5.99"></a>**5.99** 对公允价值计量具有重要意义的调整，可能使该计量归类于公允价值层次中的第三层次。

[IFRS 13 第84段]。

<a id="s33-Para_5.100"></a>**5.100** 通过外推法或插值法得出的某些输入值可能由可观察市场数据印证（例如，根据可观察的1年期和5年期利率收益率推导出3年期收益率），因而被视为第二层次输入值。

##### 第三层次

 

<a id="s33-Para_5.101"></a>**5.101** 第三层次输入值是资产或负债的不可观察输入值。

[IFRS 13 第86段]。

[FAQ 5.101.1 – 第三层次输入值](12.md#s35-FAQ_5.101.1)

[FAQ 5.101.2 – 计量符合第三层次条件的金融工具示例](12.md#s35-FAQ_5.101.2)

<a id="s33-Para_5.102"></a>**5.102** 仅当无法获得可观察输入值时，才应当使用第三层次输入值。公允价值计量目标保持不变，即从持有资产或承担负债的市场参与者角度，得出计量日的脱手价格。因此，公允价值计量应当反映市场参与者在为资产或负债定价时会使用的假设，包括关于风险的假设。

[IFRS 13 第87段]。

<a id="s33-Para_5.103"></a>**5.103** 在第三层次计量中，既应当考虑用于计量公允价值的特定估值技术（例如定价模型）所固有的风险，也应当考虑该估值技术所用输入值所固有的风险。

[IFRS 13 第88段]。

<a id="s33-Para_5.104"></a>**5.104** 第三层次输入值应当利用当前情况下可获得的最佳信息来确定，其中可能包括主体自身的数据。但是，如果有合理可获得的信息表明其他市场参与者会使用不同的数据，则应当对主体自身的数据进行调整。例如，主体不应当纳入市场参与者无法获得的特定主体的协同效应。主体无需为获取关于市场参与者假设的信息而付出穷尽式的努力。

[IFRS 13 第89段]。

<a id="s33-Para_5.105"></a>**5.105** IFRS 13允许使用第三方（例如定价服务机构和经纪商）提供的报价，但须满足以下要求：

- 报告主体应当确定这些价格是按照IFRS 13的要求形成的，包括关于交易量/交易活跃程度显著下降的相关要求。[IFRS 13 附录B 第B45段]。[IFRS 13 附录B 第B46段]。

- 对并非反映交易结果的报价应赋予较低权重。[IFRS 13 附录B 第B46段]。

- 应当考虑报价的性质（例如，是指示性价格还是具有约束力的要约）；对具有约束力的要约应赋予更高权重。[IFRS 13 附录B 第B47段]。

#### 非活跃市场与非有序交易

 

<a id="s33-Para_5.106"></a>**5.106** 下述流程图重点展示了在假定交易活跃程度下降前交易价格即为公允价值的前提下，确定对市场价格依赖程度时的考量因素：

![](assets/10.png)

  
 [IFRS 13 附录B 第B38段]。[IFRS 13 附录B 第B43段]。

<a id="s33-Para_5.107"></a>**5.107** 在确定交易量或交易活跃程度（相对于正常市场活动而言）是否显著下降时，应当考虑以下因素：

- 近期交易极少。

- 价格报价并非基于当前信息形成。

- 价格报价随时间推移或在不同做市商之间存在大幅波动（例如，某些经纪商市场）。

- 先前与资产或负债公允价值高度相关的指数，有证据表明与该资产或负债近期的公允价值指示不再相关。

- 在考虑有关该资产或负债的信用风险和其他不履约风险的所有可获得市场数据后，所观察到的交易或报价隐含的流动性风险溢价、收益率或业绩指标（例如拖欠率或损失严重程度）与主体对预期现金流量的估计相比显著上升。

- 买卖价差很宽或买卖价差显著扩大。

- 该资产或负债或类似资产或负债的新发行市场（即一级市场）活跃程度显著下降或缺失。

- 公开可获得的信息极少（例如，在自营对自营市场中发生的交易）。

[IFRS 13 附录B 第B37段]。

<a id="s33-Para_5.108"></a>**5.108** 如果交易量或交易活跃程度显著下降，则需要进行进一步分析。主体可能得出以下三项结论之一：

- 该交易价格或报价仍代表公允价值（假定其最初代表公允价值）。交易量/活跃程度下降本身，可能并不表明该报价不代表公允价值。

- 该交易价格或报价不再代表公允价值。在此情况下，如果存在以下情形，则需要进行调整：

- 这些价格仍被用作计量公允价值的基础，且调整对公允价值计量可能具有重要意义；以及

- 其他情况要求进行调整——例如，类似资产的价格需要进行重大调整才能与所计量资产具有可比性，或者该价格已经过时。

- 该交易并非有序交易。

[IFRS 13 附录B 第B38段]。

<a id="s33-Para_5.109"></a>**5.109** 当交易量/活跃程度下降需要进行调整时：

- 应当针对现金流量中固有的不确定性纳入适当的风险调整，即使此类调整难以确定。[IFRS 13 附录B 第B39段]。

- 变更估值技术或使用多种估值技术可能是适当的。当多种技术得出较宽的公允价值区间时，可能需要进行进一步分析。[IFRS 13 附录B 第B40段]。

- 公允价值计量的目标保持不变——即确定在计量日当前市场条件下，市场参与者之间在有序交易中出售资产所能收到或转移负债所需支付的价格。[IFRS 13 附录B 第B41段]。

但是，IFRS 13并未规定作出此类调整的具体方法。

<a id="s33-Para_5.110"></a>**5.110** 计量公允价值时不考虑主体持有资产或清偿负债的意图，因为公允价值是基于市场的计量，而非特定主体的计量。管理层的意图可能与市场参与者的预期不同。

[IFRS 13 附录B 第B42段]。

 

<a id="s33-chap_05_navPoint_idp1688221064"></a>
#### 识别非有序交易

 

<a id="s33-Para_5.111"></a>**5.111** 仅因交易量/交易活跃程度显著下降，就断定市场中的所有交易均非有序交易是不恰当的。表明交易非有序的迹象包括：

- 在计量日之前的一段时期内，资产或负债未充分暴露于市场，不足以开展在当前市场条件下涉及此类资产或负债的交易常规且惯常的营销活动。

- 虽然存在常规且惯常的营销期，但卖方仅向单一市场参与者推销该资产或负债。

- 卖方处于或濒临破产或接管状态（陷入财务困境）。

- 卖方被要求出售以满足监管或法律要求（如果卖方是被迫的；并非所有剥离要求都会导致被迫出售；许多剥离是在允许有充足时间和营销努力以实现有序处置的情况下进行的）。

- 与相同或类似资产或负债的其他近期交易相比，该交易价格属于异常值。

[IFRS 13 附录B 第B43段]。

[FAQ 5.111.1 – 确定交易是否有序](13.md#s36-FAQ_5.111.1)

<a id="s33-Para_5.112"></a>**5.112** 确定某项交易是否有序无需付出穷尽式的努力，但不应忽视合理可获得的信息。如果主体是某项交易的参与方，则假定其拥有足够的信息来判断该交易是否有序。

[IFRS 13 附录B 第B44段]。

<a id="s33-Para_5.113"></a>**5.113** 对于非有序交易，应当对其交易价格赋予极低权重（如有）。对有序交易价格赋予的权重大小，将取决于交易量、该交易与所计量资产或负债的可比性、交易日与计量日的接近程度以及其他事实和情况。如果没有足够信息判断某项交易是否有序，则应考虑该交易价格，但应赋予其低于其他有序交易价格的权重。IFRS 13所附《说明性示例》中的示例14对此亦作了说明。

[IFRS 13 附录B 第B44段]。

## IFRS要求或允许时将估值技术应用于非金融资产的常见领域（第5.114至5.144段）

<a id="s34-chap_05_navPoint_10"></a>
### 不动产、厂场和设备（包括投资性房地产）

 

<a id="s34-Para_5.114"></a>**5.114** 主体在以下情形下应用IFRS 13计量不动产、厂场和设备的公允价值：

- 选择采用IAS 16下的重估价模式（[IAS 16 第31段]）或IAS 40下的公允价值模式（[IAS 40 第40段]）；

- 在企业合并中取得不动产、厂场和设备（[IFRS 3 第18段]）；或

- 在向IFRS过渡时，选择采用IFRS 1中将公允价值作为认定成本的豁免（[IFRS 1 附录D 第D5段]）。

<a id="s34-Para_5.115"></a>**5.115** 土地和建筑物的公允价值通常采用市场法或收益法计量，因为通常可以获得土地和建筑物的销售和租赁市场数据。在这两种情况下，原则是相同的：确定市场参与者愿意为该资产支付的价格。

[IFRS 13 第62段]。

<a id="s34-Para_5.116"></a>**5.116** 公允价值将反映资产的最佳用途，通常为其现有用途，但也可能是其他用途（参见第5.33至5.40段）。例如，如果主体在市中心拥有一块建有仓库的土地，该地块可能具有住宅开发潜力。其市场价值可能显著高于其作为工业用地的价值，尽管主体为实现该价值将不得不承担搬迁或关闭成本等费用。

[IFRS 13 第29段]。

[EX 5.116.1 – 不动产、厂场和设备最佳用途的指南](13.md#s36-EX5.116.1)

<a id="s34-Para_5.117"></a>**5.117** 在罕见情况下，当主体对几乎没有或完全没有可比资产销售或租赁市场数据的建筑物进行估值时，可以采用折旧重置成本法计量公允价值。对于机器设备（如叉车），通常存在可获取市场价格信息的市场。对于几乎没有或完全没有市场数据的更专用设备，通常采用折旧重置成本法。

### 对联营企业、合营企业和子公司的投资

 

<a id="s34-Para_5.119"></a>**5.119** 风险投资机构及类似主体被允许选择以公允价值计量其对联营企业和合营企业的投资，而非采用权益法核算。参见[第31章第3段](56.md#s224-Para_31.3)。

[IAS 28 第18段]。

<a id="s34-Para_5.120"></a>**5.120** 符合IFRS 10下投资性主体条件的主体以公允价值计量几乎所有投资，包括子公司（提供投资相关服务的子公司除外）、联营企业和合营企业，而非将其纳入合并范围或采用权益法核算。参见[第27章第3段](48.md#s180-Para_27.3)。

[IFRS 10 第31段]。

<a id="s34-Para_5.121"></a>**5.121** 在上市市场交易的任何投资均可参考该市场价格进行估值，并与主体的方法保持一致，适当考虑任何潜在的控制权溢价（参见[FAQ 5.87.7](12.md#s35-FAQ_5.87.7)）。未上市投资采用市场法或收益法进行估值。方法的选择基于计量公允价值所需数据的可获得性。市场法可作为主要方法使用，也常用于交叉验证收益法得出的隐含估值乘数。

[IFRS 13 第61段]。

### 企业合并中的公允价值

<a id="s34-Para_5.123"></a>**5.123** 根据IFRS，企业合并会计的多个方面均要求进行公允价值计量。以下项目的计量要求或允许采用公允价值：

- 对价（包括或有对价）[IFRS 3 第37段]；

- 原持有的任何权益[IFRS 3 第42段]；

- 任何非控制性权益[IFRS 3 第19段]；以及

- 所取得的大多数可辨认资产和所承担的负债[IFRS 3 第18段]。

<a id="s34-chap_05_navPoint_idp1689348792"></a>
#### 对价

 

**5.124** 转移的对价是购买日所转移资产、购买方对被购买方原所有者承担的负债以及购买方向被购买方原所有者发行的权益的公允价值之和。转移对价的示例包括现金、或有对价、其他资产、购买方转移给卖方的一项业务、普通股或优先股权益工具、期权和认股权证。除现金以外的对价的公允价值必须按照IFRS 13确定。

[IFRS 3 第37段]。

<a id="s34-Para_5.125"></a>**5.125** 购买方在企业合并中发行的权益可能公开交易，也可能非公开持有。当股份公开交易时，公允价值将为购买日的股票报价乘以发行的股份数量。作为对价发行的未上市股份的公允价值使用估值技术（市场法或收益法）计量。

[IFRS 13 第69段]。

<a id="s34-Para_5.126"></a>**5.126** 按公允价值确认或有对价带来诸多计量挑战。主体在制定用于确定公允价值的假设时，需要考虑该安排的关键输入值和市场参与者假设。关键考量因素包括：

- 估计实现该安排相关里程碑的可能性和时间。

- 对每项潜在结果进行概率评估时运用判断。

- 考虑购买日该安排下应付的金额。该金额具有不确定性，应审慎考虑。

- 每项潜在结果的波动率，这是期权定价法下的关键假设。

分类为负债的或有对价的公允价值需要在购买日后的每个报告期间进行更新。

公允价值计量的变动应当考虑最新的概率估计和假设，包括因货币时间价值引起的变动。

[IFRS 13 第67段]。

[FAQ 5.126.2 – 分类为负债、以现金结算的或有对价的公允价值计量（1）](13.md#s36-FAQ_5.126.2)  
[FAQ 5.126.3 – 分类为负债、以现金结算的或有对价的公允价值计量（2）](13.md#s36-FAQ_5.126.3)

#### 原持有的权益

 

<a id="s34-Para_5.127"></a>**5.127** 对公开交易主体原持有的权益的公允价值应当基于可观察的市场报价。对非公开交易主体原持有的权益，需要使用估值技术（市场法或收益法）进行计量。实务中常用的一种方法，是从为取得控制权而转移对价的每股价值中推导出未上市原持有权益的价值（包括考虑是否需要针对非控制性权益折价进行调整）[IFRS 3 附录B 第B44段和第B45段]。对于非控制性比例权益，市场法或收益法在原持有权益与非控制性权益中的应用是类似的。

[IFRS 13 第69段]。

 

<a id="s34-chap_05_navPoint_idp1689425976"></a>
#### 非控制性权益

 

<a id="s34-Para_5.128"></a>**5.128** 主体可以选择采用按比例份额法或公允价值法对非控制性权益（NCI）进行估值。如果选择公允价值计量，计量方法将取决于非控制性权益是否仍公开交易。对于在收购后仍公开交易的非控制性权益，其公允价值应当采用该非控制性权益的市场报价确定。实务中常见的一种估计未上市非控制性权益公允价值的方法，是将控制性权益的公允价值还原至100%权益，并在适当时针对任何控制权溢价进行调整。公允价值法在控制性权益和非控制性权益中均反映了被购买方整体的商誉。应当考虑同时使用市场法和收益法，因为它们可能为非控制性权益的公允价值提供进一步支持。

[IFRS 3 附录B 第B44段]。

<a id="s34-Para_5.129"></a>**5.129** 计量未上市非控制性权益的公允价值时，主体需要考虑非控制性权益预期从企业合并协同效应中获益的程度，以及控制权溢价中所反映的任何其他潜在利益。为取得控制权而支付的价格通常包含反映购买方预期实现的协同效应的溢价。如果非控制性权益也将从这些协同效应中获益，则其公允价值计量将包含该溢价。但如果购买方能够设计交易结构，使得协同效应在其集团的另一部分实现，而非控制性权益不参与该部分，则非控制性权益股份的公允价值将不包含协同效应的价值。

### 非金融负债

 

<a id="s34-Para_5.133"></a>**5.133** 非金融负债通常按照IAS 37进行会计处理。IAS 37不要求也不允许采用公允价值计量。非金融负债仅在企业合并中承担时，才根据IFRS 13以公允价值计量。IFRS 13所附《说明性示例》中的示例11提供了关于对企业合并中承担的弃置义务进行公允价值计量的进一步指南和考量因素。

 

[IFRS 3 第18段]。

 

<a id="s34-Para_5.134"></a>**5.134** 非金融负债通常是一项经营义务或履约义务。履行履约义务可能需要使用经营资产或主体员工。履约义务可能仅随时间推移而到期（非或有），也可能取决于其他事件（或有）以确认该义务的金额或存在性。该履约义务在性质上可能是合同性的或非合同性的。这很可能影响该义务得以履行的风险，进而影响其公允价值。

 

[IFRS 13 第44段]。

### 存货

### 生物资产

### 非金融资产减值测试中的公允价值

 

<a id="s34-Para_5.140"></a>**5.140** 很少有资产在活跃市场中交易并因此属于第一层次计量。IAS 36范围内最有可能符合第一层次标准的资产是在活跃市场上市的对联营企业或子公司的投资，且仅限于主体未对计量进行调整以纳入控制权溢价的情况（关于是否纳入控制权溢价，实务中存在分歧——进一步指南参见[FAQ 5.87.7](12.md#s35-FAQ_5.87.7)）。在此情况下，这些资产的公允价值将参考报价和所持股份数量进行计量。

[IFRS 13 第63段]。

<a id="s34-Para_5.141"></a>**5.141** 对于并非参考报价计量的资产或现金产出单元（CGU），存在多种估值方法用于评估CGU或资产的价值。通常会采用不止一种方法，以确保估值得到交叉验证并结合所有适当的市场证据进行考量。重置成本法不适用于减值测试目的，因为它无法计量通过使用或处置可收回的经济利益。对于某些资产（特别是土地和建筑物），由于通常存在销售或租赁的市场数据，其公允价值可能采用市场法计量。然而，对于大多数资产和CGU而言，收益法将是适当的。

[IFRS 13 第62段]。

### 披露目标

 

<a id="s34-Para_5.142"></a>**5.142** IFRS 13要求披露充分的信息，以帮助财务报表使用者评估：

- 用于形成初始确认后以公允价值列报的资产和负债的持续性和非持续性计量的估值技术和输入值；以及

- 持续性第三层次公允价值计量对损益或其他综合收益的影响。

[IFRS 13 第91段]。

<a id="s34-Para_5.143"></a>**5.143** 为实现上述目标，可能需要在最低披露要求之外进行额外披露。报告主体还应当考虑：

- 所需的详细程度；

- 对各项要求的侧重程度；

- 汇总或拆分的程度；以及

- 是否需要额外信息以评估定量披露。

IFRS 13的披露要求涵盖在IFRS 13第91段至第99段中。

[IFRS 13 第92段]。
