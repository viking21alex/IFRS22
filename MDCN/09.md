## 引言和范围（第3.1-3.2段）

<a id="s19-Para_3.1"></a>**3.1** 本章阐述《国际会计准则第8号》（IAS 8）的要求，该准则规范会计政策、会计估计变更和差错的处理。

<a id="s19-chap_03_navPoint_2"></a>
### 目标和范围

<a id="s19-Para_3.2"></a>**3.2** IAS 8规定了选择和变更会计政策的标准，同时也规范了会计政策变更、会计估计变更以及前期差错更正的会计处理和披露要求。该准则旨在提高财务报表的相关性、可靠性和可比性。IAS 1还规定了关于会计政策的其他披露要求（参见[第4章第149段](10.md#s29-Para_4.149)）。

[IAS 8 第3段]。



<a id="s20"></a>

<a id="s20-chap_03_navPoint_3"></a>
## 会计政策（第3.3-3.23段）

<a id="s20-Para_3.3"></a>**3.3** 会计政策是指主体在编制和列报财务报表时所采用的具体原则、基础、惯例、规则和实务。主体应当按照国际会计准则理事会（理事会）依据《财务报告概念框架》（“概念框架”）制定并复核的国际财务报告准则（IFRS）来选择会计政策。除非某项准则未涉及相关交易或事项，否则主体不得自行制定会计政策。

[IAS 8 第5段]。

<a id="s20-chap_03_navPoint_4"></a>
### 准则和解释中包含的会计政策

<a id="s20-Para_3.4"></a>**3.4** 主体应当参照适用于某项交易、其他事项或情况的准则或解释的要求，确定适用于该项目的会计政策。若某项会计准则允许主体在备选会计处理方法中选择其一，主体应当明确指明所采用的备选方法。例如，IAS 16允许主体对选定类别的资产采用历史成本政策或重估价政策（参见[第22章第65段](39.md#s143-Para_22.65)）。

[IAS 8 第7段]。

<a id="s20-Para_3.5"></a>**3.5** 国际财务报告准则有时会附带指南，以协助主体应用相关要求。所有指南都会说明：（a）其是否构成国际财务报告准则不可分割的组成部分，因而具有强制性并构成准则或解释要求的一部分；或者（b）其并非准则的组成部分。非准则组成部分的指南仅在应用国际财务报告准则时提供参考，并不包含对财务报表的强制要求。

[IAS 8 第9段]。

<a id="s20-Para_3.6"></a>**3.6** 此外，准则中包含粗体段落和普通字体段落。这些段落具有同等权威性，但粗体段落用于指明主要原则。

[《国际财务报告准则前言》第13段]。

<a id="s20-chap_03_navPoint_5"></a>
### 准则和解释中未包含的会计政策

<a id="s20-Para_3.7"></a>**3.7** 如果没有专门适用于某项交易、其他事项或情况的准则或解释，主体应当运用职业判断制定并应用能够向使用者提供相关且可靠信息的会计政策。可靠性意味着财务报表应当：

- 如实反映主体的财务状况、财务业绩和现金流量；

- 反映交易、其他事项和情况的经济实质，而不仅仅是法律形式；

- 保持中立（即不偏不倚）；

- 保持审慎；以及

- 在所有重大方面均完整。

[IAS 8 第10段]。

<a id="s20-Para_3.8"></a>**3.8** 管理层还应考虑其他指南，以协助其运用职业判断制定和应用会计政策。管理层应当按以下降序依次参照下列来源并考虑其适用性：

- 国际财务报告准则和解释中涉及类似和相关问题的要求；

- 概念框架中关于资产、负债、收益和费用的定义、确认标准和计量概念。

[IAS 8 第11段]。

[FAQ 3.8.1 – 管理层类比国际财务报告准则制定会计政策时应考虑哪些因素？](09.md#s25-FAQ_3.8.1)

<a id="s20-Para_3.9"></a>**3.9** 该准则还建议（但未强制要求）管理层考虑使用与概念框架相类似概念框架的其他准则制定机构最新发布的公告、其他会计文献以及公认的行业实务。然而，这些来源不得与理事会的准则、解释及概念框架相冲突。

[IAS 8 第12段]。

<a id="s20-chap_03_navPoint_6"></a>
### 重要性

<a id="s20-Para_3.10"></a>**3.10** 当应用国际财务报告准则中包含的会计政策所产生的影响不重要时，主体无需应用这些政策。这与IAS 1中的规定相呼应，即如果国际财务报告准则要求披露的信息不重要，主体无需进行该项披露。

[IAS 8 第8段]。[IAS 1 第31段]。

<a id="s20-Para_3.11"></a>**3.11** 自2020年1月1日或以后日期开始的年度期间起，“重要性”的定义已作修订，从而使IAS 1第7段与IAS 8第5段保持一致。IAS 1和IAS 8规定，如果合理预期某项信息的遗漏、错报或掩盖会影响通用目的财务报表主要使用者基于该财务报表（该报表提供关于特定报告主体的财务信息）作出的决策，则该项信息具有“重要性”。

[IAS 1 第7段]。[IAS 8 第5段]。

**[下一段为3.13。]**

<a id="s20-Para_3.13"></a>**3.13** 除非判断应用某项准则的影响明显不重要，否则主体应当应用该准则。这一判断需要进行分析，并应综合考虑分类、确认、计量和披露问题。为了实现主体财务状况、财务业绩或现金流量的特定列报，而对未更正的不重要偏离国际财务报告准则的情形进行调整或不予调整，均是不恰当的。这表明此类调整合理预期会影响使用者的经济决策，因而具有重要性。此类偏离的例子包括：一项微小的未更正差错可能触发借款契约违约或员工股票期权授予条件。以应用某项准则不切实可行或金额无法确定为由，通常不能作为认定其影响不重要的理由；因为在未进行量化的情况下，一般无法判断重要性。

[IAS 8 第8段]。

<a id="s20-chap_03_navPoint_7"></a>
### 一贯性

<a id="s20-Para_3.14"></a>**3.14** 除非某项准则另有允许，主体应当一贯地应用其会计政策。某项准则可能允许或要求主体对不同类别的项目采用不同的会计政策。在此情况下，主体应当为每一类别选择恰当的会计政策，并在每一类别内一贯地应用这些政策。例如，IAS 16允许主体对某一类别的不动产、厂场和设备采用重估价政策，同时对另一类别按历史成本计量。在这种情况下，一贯性原则要求主体对每一类别所采用的政策应一贯地适用于该类别中的所有资产，并在各会计期间保持一贯。

[IAS 8 第13段]。

[FAQ 3.14.1 – 集团内个别主体是否应采用统一的会计政策？](09.md#s25-FAQ_3.14.1)

<a id="s20-chap_03_navPoint_8"></a>
### 会计政策变更

<a id="s20-Para_3.15"></a>**3.15** 主体仅在下列情况下方可变更会计政策：

- 某项准则或解释要求进行该项变更；或

- 该项变更将使财务报表就交易、其他事项或情况对主体财务状况、财务业绩或现金流量的影响提供可靠且更相关的信息。

[IAS 8 第14段]。

[EX 3.15.1 – 会计政策变更示例](09.md#s25-EX3.15.1)

<a id="s20-Para_3.16"></a>**3.16** 主体可能类比其他公认会计原则（GAAP）制定会计政策（参见[第3.9段](09.md#s20-Para_3.9)）。如果该准则或公告随后被修订，且主体为反映该修订而变更其会计政策，则属于自愿性会计政策变更。此时，主体必须证明该项变更将提供可靠且更相关的信息（参见[第3.15段](09.md#s20-Para_3.15)）。

[IAS 8 第21段]。

<a id="s20-Para_3.17"></a>**3.17** 除非会计政策变更满足IAS 8第14段规定的两项条件之一（参见[第3.15段](09.md#s20-Para_3.15)），否则主体应在各会计期间应用相同的会计政策。这是因为财务报表使用者需要能够跨期比较主体的财务报表，以了解其财务状况、财务业绩和现金流量的变化趋势（参见[第3.14段](09.md#s20-Para_3.14)中的一贯性原则）。

[IAS 8 第15段]。

<a id="s20-Para_3.18"></a>**3.18** 主体对与以前发生的交易或事项在实质上不同的交易或事项（即情况发生变化）引入新的会计政策，不属于会计政策变更。同样，对以前未发生或不重要的事项或交易采用某项会计政策，也不属于会计政策变更。

[IAS 8 第16段]。

[EX 3.18.1 – 不视为会计政策变更的情形](09.md#s25-EX3.18.1)

<a id="s20-chap_03_navPoint_9"></a>
### 会计政策变更的适用

<a id="s20-chap_03_navPoint_10"></a>
### 一般规则

<a id="s20-Para_3.19"></a>**3.19** 因首次应用某项国际财务报告准则或解释（包括提前采用）而引起的会计政策变更，如有特定的过渡性规定，应当按照该准则或解释的特定过渡性规定进行会计处理。新发布或修订后的国际财务报告准则通常包含特定过渡性规定，允许采用未来适用法而非追溯调整法（追溯适用）应用该准则。这有时是因为理事会认为获取重述比较信息所需的资料不切实可行或成本过高。提前采用新准则或解释不视为自愿性变更，因此应适用该新准则或解释中的任何特定过渡性规定。

[IAS 8 第19段]。

<a id="s20-Para_3.20"></a>**3.20** 对于自愿性会计政策变更，或无特定过渡性规定的新会计准则或解释（包括列报变更），除不切实可行的范围外（参见[第3.43段](09.md#s23-Para_3.43)及以后段落），主体应当采用追溯调整法（追溯适用）。主体应调整所有比较金额，以如同该项新会计政策一直被应用一样来列示前期的经营成果和财务状况。

[IAS 8 第19段]。[IAS 8 第22段]。

[FAQ 3.20.1 – 主体何时应根据国际财务报告准则解释委员会（IFRS IC）议程决定变更会计政策？](09.md#s25-FAQ_3.20.1)

<a id="s20-Para_3.21"></a>**3.21** “追溯调整法（追溯适用）”是指“将一项新会计政策应用于交易、其他事项和情况，如同该政策一直被应用一样”。主体应当将对所有早于所列报期间的调整，作为对所列报最早期间各项受影响权益组成部分（例如留存收益）期初余额的调整予以报告。例如，如果某项政策变更发生在20X7年，且主体列报截至20X7年12月31日止年度的财务报表以及截至20X6年12月31日止年度的比较信息，则主体应调整截至20X6年12月31日止年度的比较数据，并将20X6年之前各年度的累积调整金额计入20X6年1月1日的留存收益余额及任何受影响的其他权益组成部分。

[IAS 8 第5段]。

[FAQ 3.21.1 – 重述是否对财务报表批准报出日产生影响？](09.md#s25-FAQ_3.21.1)

<a id="s20-Para_3.22"></a>**3.22** 主体还应在切实可行的最早期间内，重述随财务报表一同列报的关于前期的任何其他信息（例如历史摘要）。

[IAS 8 第26段]。

### 一般规则的例外

## 差错（第3.33-3.41段）

<a id="s22-Para_3.33"></a>**3.33** 差错可能发生在财务报表要素的确认、计量、列报或披露过程中。如果财务报表包含重大差错，或者包含为实现主体财务状况、财务业绩或现金流量的特定列报而故意制造的不重要差错，则财务报表不符合国际财务报告准则。主体应在发现重大前期差错后批准报出的第一套财务报表中，通过修改比较信息并重述所列报最早期间的期初留存收益，采用追溯重述法更正重大前期差错（详见[第3.39段及以后段落](09.md#s22-Para_3.39)）。

[IAS 8 第41段]。

<a id="s22-chap_03_navPoint_16"></a>
### 识别前期差错

<a id="s22-Para_3.34"></a>**3.34** 管理层可能会发现涉及一个或多个已报出财务报表前期的重大差错。这些差错通过调整当期财务报表中包含的受影响前期的比较信息予以更正。

[IAS 8 第41段]。

<a id="s22-Para_3.35"></a>**3.35** “前期差错”一词是指：

“……由于未能使用或误用符合下列条件的可靠信息，而导致主体一个或多个前期财务报表出现的遗漏和错报：

- 在这些期间的财务报表批准报出时即可获得；且

- 在编制和列报这些财务报表时合理预期能够取得并加以考虑。

此类差错包括计算错误、应用会计政策错误、疏忽或曲解事实以及舞弊的影响。”

[IAS 8 第5段]。

<a id="s22-Para_3.36"></a>**3.36** 确定前期是否存在差错，需要考虑在发生差错时是否已存在可合理取得的可靠信息。概念框架将“如实反映”作为财务报表的基本质量特征之一，而IAS 8指出如实反映是“可靠性”的一项特征（参见[第3.7段](09.md#s20-Para_3.7)）。概念框架指出：

“如实反映并不意味着在所有方面都准确无误。无差错是指在对现象的描述中不存在差错或遗漏，且用于生成报告信息的流程在选择和应用过程中不存在差错。在此语境下，无差错并不意味着在所有方面都绝对精确。例如，对不可观察价格或价值的估计无法判定其准确与否。然而，如果该金额被清晰且准确地描述为一项估计，估计过程的性质和局限性已作说明，且在选择和应用恰当的估计流程时未出现差错，则对该估计的反映仍可以是如实反映。”

### 重要性的确定

<a id="s22-Para_3.38"></a>**3.38** 主体应评估某项前期差错是否具有重要性，从而需要追溯调整财务报表。如IAS 1第7段所述，如果合理预期某项信息的遗漏、错报或掩盖会影响通用目的财务报表主要使用者基于该财务报表作出的决策，则该项目的遗漏或错报具有重要性。故意错报或为实现特定结果而作出的错报也可能具有重要性（参见[第3.13段](09.md#s20-Para_3.13)）。

### 前期差错更正

<a id="s22-Para_3.39"></a>**3.39** 主体对重大前期差错的财务报表重述所采用的会计处理方式与会计政策变更类似。除不切实可行的情形外（参见[第3.43段](09.md#s23-Para_3.43)），主体应在发现差错后报出的第一套财务报表中采用追溯重述法更正重大前期差错。追溯重述法是指“更正财务报表要素金额的确认、计量和披露，如同前期差错从未发生过一样”。该追溯重述通过以下方式实现：

- 重述所列报发生差错的前期的比较金额；或

- 如果差错发生在财务报表所列报的最早前期之前，则重述所列报最早前期的资产、负债和权益的期初余额。

[IAS 8 第5段]。[IAS 8 第42段]。

<a id="s22-Para_3.40"></a>**3.40** 主体不应将重大前期差错的更正计入发现差错当期的利润表。但是，如果无法确定归属于前期的金额（例如，该金额同样可能与当期相关），则该部分更正应计入当期利润表。这意味着如IAS 8第47段所示，前期的资产、负债和权益可能仅作部分调整，但截至当期期末将得到完全调整和更正。

[IAS 8 第46段]。

<a id="s22-Para_3.41"></a>**3.41** 如果重述后的财务信息与其他以历史摘要形式列报的信息包含在同一份文件中（例如年度报告中的五年精选财务信息摘要），主体还应自切实可行的最早日期起对这些历史摘要信息进行重述。

[IAS 8 第46段]。

<a id="s23-chap_03_navPoint_20"></a>
## 前期调整与追溯适用（第3.42-3.50段）

<a id="s23-Para_3.42"></a>**3.42** 主体应应用IAS 12对前期差错更正和会计政策变更的所得税影响进行会计处理和披露（参见[第14章第9段](27.md#s97-Para_14.9)和第56段）。

[IAS 8 第4段]。

[FAQ 3.42.1 – 当会计政策变更需要追溯调整时，主体应如何对相关所得税进行会计处理？](09.md#s25-FAQ_3.42.1)

<a id="s23-chap_03_navPoint_21"></a>
### 追溯适用或追溯重述不切实可行及后见之明（事后判断）的运用

<a id="s23-Para_3.43"></a>**3.43** 在有限情况下，完全追溯适用或追溯重述可能不切实可行。如果确定会计政策变更或重大前期差错更正的特定期间影响或累积影响不切实可行，则在此范围内无需进行完全追溯适用或追溯重述。

[IAS 8 第23段]。[IAS 8 第43段]。

<a id="s23-Para_3.44"></a>**3.44** 在下列情况下，主体可能认为追溯适用会计政策变更或追溯重述前期差错不切实可行：

- 追溯适用或追溯重述的影响无法确定；

- 追溯适用或追溯重述需要对管理层在该期间的意图作出假设；或

- 追溯适用或追溯重述需要对金额作出重大估计，且无法客观地区分有关这些估计的信息与其他信息，而有关这些估计的信息需同时满足：

- 能够提供在应当确认、计量或披露这些金额的日期业已存在的情况的证据；以及

- 在该前期财务报表批准报出时即可获得。

[IAS 8 第5段]。

<a id="s23-Para_3.45"></a>**3.45** 如果主体在前期未收集相关数据，且无法切实可行地创建或重建这些信息，则调整比较信息可能不切实可行。

[IAS 8 第50段]。

<a id="s23-Para_3.46"></a>**3.46** 调整前期比较信息时通常需要进行估计（参见[第3.44段](09.md#s23-Para_3.44)）。这本身并不妨碍对比较信息进行可靠的调整或更正。所作估计应反映前期业已存在的情况。时间的推移或自受影响交易或事项发生以来出现的新情况，可能会增加评估受影响交易发生时所存在事项或情况的难度，但这并不意味着调整比较信息不切实可行。

[IAS 8 第51段]。

<a id="s23-Para_3.47"></a>**3.47** 如果无法切实可行地将在早期期间即可获得且重建该期间情况所需的特定信息与其他信息区分开来（参见[第3.44段](09.md#s23-Para_3.44)(c)），则追溯适用或追溯重述不切实可行。例如，采用重大不可观察输入值的公允价值计量就可能属于这种情况。因为此类估值具有高度主观性，无法可靠地重现管理层在早期期间作出估计时会考虑的主观因素。

[IAS 8 第52段]。

<a id="s23-Para_3.48"></a>**3.48** 在应用新会计政策或更正前期差错时，不得运用后见之明（事后判断），无论是用以事后揣测管理层在早期期间的意图，还是用于估计在前期确认、计量或披露的金额。例如，在更正持有至到期投资计量差错时，管理层不应考虑其在后续期间作出的不再将投资持有至到期的决定。同样，后期发生的异常严重流感疫情的信息，不应影响对前期员工医疗保健负债计算差错的更正。

[IAS 8 第53段]。

<a id="s23-Para_3.49"></a>**3.49** 如果确定某项变更的特定期间影响不切实可行，主体应对能够进行追溯适用或追溯重述的最早期间受影响的资产、负债和权益期初余额进行追溯适用或追溯重述。在极端情况下，如果主体无法确定对前期期初和期末资产负债表金额的累积影响，该最早期间可能是当期。如果其中任一余额未知，主体就无法确定对该前期利润表的影响（从而无法确定对期初或期末权益的影响）。

[IAS 8 第24段]。[IAS 8 第44段]。

[EX 3.49.1 – 确定会计政策变更的特定期间影响不切实可行](09.md#s25-EX3.49.1)

<a id="s23-Para_3.50"></a>**3.50** 如果确定追溯适用或追溯重述对所有前期的累积影响不切实可行，主体应自切实可行的最早日期起调整比较信息，即忽略该日期之前的累积调整部分。即使对任何前期进行追溯适用（即调整数据）均不切实可行，主体仍可变更会计政策。然而，主体自愿采用一项无法追溯适用的会计政策的情形较为罕见，因为缺乏可比性会降低信息的相关性。

[IAS 8 第25段]。[IAS 8 第45段]。

## 披露（第3.51-3.55段）

<a id="s24-chap_03_navPoint_23"></a>
### 会计政策变更、会计估计变更和前期差错更正

<a id="s24-Para_3.51"></a>**3.51** IAS 8规定了关于会计政策变更（包括首次应用某项准则及自愿性会计政策变更）、会计估计变更以及前期差错更正的披露要求。

[IAS 8 第28段]。[IAS 8 第29段]。[IAS 8 第39段]。[IAS 8 第40段]。[IAS 8 第49段]。

<a id="s24-Para_3.52"></a>**3.52** 主体无需在后续年度的财务报表中重复披露会计政策变更和前期差错更正的相关信息。

[IAS 8 第28段]。[IAS 8 第29段]。[IAS 8 第49段]。

<a id="s24-Para_3.53"></a>**3.53** 如果主体追溯适用了一项会计政策，或者对财务报表中的项目进行了追溯重述或重分类，且该事项对上一期间期初资产负债表中的信息产生了重大影响，则主体应列报该期初资产负债表。但是，主体无需披露与该额外资产负债表相关的附注。无论主体的财务报表是否列报更早期间的比较信息，均应列报截至上一期间期初的额外资产负债表。详见[第4章第48段](10.md#s28-Para_4.48)。

[IAS 1 第40A段]。

<a id="s24-Para_3.54"></a>**3.54** IAS 34规定了关于会计估计变更的一项额外披露要求。如果在本财政年度最后一个中期期间内，对先前中期期间报告的估计金额发生了重大变更，且主体未就该最后一个中期期间单独发布财务报告，则主体应在该财政年度的年度财务报表附注中披露该项会计估计变更的性质和金额。

[IAS 34 第26段]。

<a id="s24-chap_03_navPoint_24"></a>
### 尚未生效的新准则或修订后的会计准则

<a id="s24-Para_3.55"></a>**3.55** 如果某项新准则或解释已经发布但尚未生效，且主体尚未提前应用该准则或解释，则主体应作出特定披露。这些披露旨在使使用者能够评估新会计公告可能对主体财务报表产生的影响。管理层需要运用职业判断，确定新会计公告预计是否会产生需要披露的重大影响。评估重要性时，应同时考虑对以往交易和财务状况的影响，以及对合理可预见的未来交易的影响。某些新公告提供了可能对主体产生影响的备选方案，管理层应披露其对备选方案的使用预期。即使新会计公告是在资产负债表日之后、财务报表批准报出日之前发布的，主体也应考虑进行此类披露。详细披露要求见IAS 8第31段。

[IAS 8 第30段]。

## 示例说明

<a id="s25-chap_03_navPoint_26"></a>
### 选择和运用会计政策

<a id="s25-chap_03_navPoint_idp1688714056"></a>
#### <a id="s25-FAQ_3.8.1"></a>FAQ 3.8.1 – 管理层类比国际财务报告准则制定会计政策时应考虑哪些因素？

准则依据：IAS 8 第11段  
正文参见：[3.8](09.md#s20-Para_3.8)

**问题**

现有准则可能未对新出现的问题或交易提供具体指引，因此管理层可能需要参照现有准则的原则和指引来制定会计政策。管理层还可能参考征求意见稿中的建议以及尚未生效的新准则中的指引。

管理层在类比某项国际财务报告准则制定会计政策时应考虑哪些因素？

**解答**

管理层需要运用职业判断，确定在类比制定会计政策时应当考虑该项国际财务报告准则的哪些方面。如果该项国际财务报告准则中的所有要求均与拟适用该政策的交易或问题相关，则仅应用该准则的某一方面可能是不恰当的。

此外，如果管理层应用征求意见稿中的建议或尚未生效的新准则中的指引，则应考虑该等建议或指引是否允许提前采用。

<a id="s25-chap_03_navPoint_idp1688734024"></a>
#### <a id="s25-FAQ_3.14.1"></a>FAQ 3.14.1 – 集团内个别主体是否应采用统一的会计政策？

准则依据：IAS 8 第13段  
正文参见：[3.14](09.md#s20-Para_3.14)

**问题**

集团成员在其个别财务报表中可能采用了不同的会计政策。在编制合并财务报表时，主体应当作出适当的合并调整以实现会计政策的一致性。[IFRS 10 第19段]。[IFRS 10 附录B 第B87段]。

集团内个别主体是否应采用统一的会计政策？

**解答**

国际财务报告准则并未要求母公司及其子公司的个别财务报表所采用的会计政策与集团合并财务报表所采用的会计政策相同。每一主体均应按照IAS 8应用相同的会计政策选择流程并运用职业判断。采用不同政策的集团成员应当能够以充分的业务或商业理由予以说明。

主体管理层可能考虑的因素包括：

- 集团合并财务报表所采用的会计政策；

- 集团内各公司之间的可比性；

- 不同会计政策对子公司可供分配利润的影响；

- 非控制性权益的水平；以及

- 监管方面的考量。

<a id="s25-chap_03_navPoint_27"></a>
### 会计政策变更

<a id="s25-chap_03_navPoint_idp1688762312"></a>
#### <a id="s25-EX3.15.1"></a>EX 3.15.1 – 会计政策变更示例

准则依据：IAS 8 第14段  
正文参见：[3.15](09.md#s20-Para_3.15)

会计政策变更可按照财务报表编制过程中应用的三个基本环节进行分类：确认、计量基础和列报。各类别的示例如下：

确认政策的变更

- 变更关于销售商品和提供服务的收入确认政策。

- 变更是否将借款费用计入后续按公允价值计量的资产的取得成本（详见[第22章第43段](39.md#s142-Para_22.43)）。

与计量基础相关的政策变更

- 将某一类别的不动产、厂场和设备从按历史成本扣减折旧计量变更为定期重估价政策（请注意，此类变更应作为重估价采用未来适用法处理，而非追溯适用——参见[第3.23段](09.md#s20-Para_3.23)）。

列报政策的变更

- 变更资产负债表、利润表或现金流量表中某项目的分类，但因情况变化所驱动的变更除外（参见[第3.18段](09.md#s20-Para_3.18)）。

<a id="s25-chap_03_navPoint_idp1688778696"></a>
#### <a id="s25-EX3.18.1"></a>EX 3.18.1 – 不视为会计政策变更的情形

准则依据：IAS 8 第16段  
正文参见：[3.18](09.md#s20-Para_3.18)

记账本位币（功能货币）的变更

记账本位币（功能货币）的变更不属于会计政策变更，因为它源于主体基础交易、事项和情况的变化。[IAS 21 第35段至第37段]。因此，主体应采用未来适用法进行会计处理，即采用变更日的汇率将所有项目折算为新的记账本位币（功能货币）。详见[第49章第17段](80.md#s320-Para_49.17)。

现有资产用途的变更

A主体拥有一栋办公楼，此前一直用于自身行政管理目的。A主体将该办公楼分类为不动产、厂场和设备，并按历史成本扣减折旧计量。本年度内，管理层将员工迁至一栋新办公楼，并将旧办公楼出租给第三方。随后，A主体将旧办公楼重分类为投资性房地产，并按公允价值计量。

该项变动代表房地产用途的变更，因此不应对比较金额进行重述。[IAS 40 第61段]。由于A主体在两个年度中将该办公楼用于不同目的，因此在当期和前期对同一房地产应用不同的会计处理是恰当的。

<a id="s25-chap_03_navPoint_28"></a>
### 议程决定——采用时点

<a id="s25-chap_03_navPoint_idp1688794056"></a>
#### <a id="s25-FAQ_3.20.1"></a>FAQ 3.20.1 – 主体何时应根据国际财务报告准则解释委员会（IFRS IC）议程决定变更会计政策？

准则依据：IAS 8 第21段，IAS 8 第22段  
正文参见：[3.20](09.md#s20-Para_3.20)

**问题**

国际财务报告准则解释委员会（IFRS IC）经常处理新识别的财务报告问题，并可能发布议程决定：“发布议程决定的过程通常会产生解释性材料，提供原本无法获得且原本无法合理预期能够取得的新信息。”[摘自2019年3月《IFRIC更新》（IFRIC Update）]。关于议程决定的性质和地位的进一步说明，请参阅[FAQ 3.37.1](09.md#s25-FAQ_3.37.1)。

**解答**

主体应确定是否因已发布的议程决定而需要变更会计政策，以及应当在何时实施该项变更。国际财务报告准则解释委员会（IFRS IC）在2019年3月《IFRIC更新》中指出：“……主体可能确定其需要因某项议程决定而变更会计政策。理事会预期，主体有权获得充足的时间以作出该项确定并实施任何变更（例如，主体可能需要获取新信息或调整其系统以实施变更）。”

主体需要运用职业判断来确定此语境下的“充足的时间”有多长。我们认为，该时间应当刚好足够完成变更的实施。此项判断需结合主体具体情况进行评估，例如考虑是否需要收集额外信息以实施新政策或提供相关披露，以及是否需要修改流程和系统。我们预计，在许多情况下，“充足的时间”通常为数月，但不太可能超过一年。主体在评估时还应考虑任何相关证券监管机构的意见。

当管理层已得出结论认为需要因某项议程决定而变更会计政策，但尚未实施该项变更时，管理层应考虑参照IAS 8第30段和第31段关于即将生效准则的披露要求，提供类似的披露。

因议程决定而引起的会计政策变更通常属于自愿性会计政策变更，除非主体确定其涉及差错更正（进一步考量参见[FAQ 3.37.1](09.md#s25-FAQ_3.37.1)）。自愿性会计政策变更应采用追溯调整法（追溯适用），但以不切实可行的范围为限（参见[第3.43段至第3.50段](09.md#s23-Para_3.43)）。我们预计，仅在有限情况下，对自愿性会计政策变更进行追溯适用才是不切实可行的。确定追溯适用是否不切实可行需要运用职业判断。

<a id="s25-chap_03_navPoint_29"></a>
### 会计政策变更的适用

<a id="s25-chap_03_navPoint_idp1688834504"></a>
#### <a id="s25-FAQ_3.21.1"></a>FAQ 3.21.1 – 重述是否对财务报表批准报出日产生影响？

准则依据：IAS 8 第5段  
正文参见：[3.21](09.md#s20-Para_3.21)

**问题**

重述是否对财务报表批准报出日产生影响？

**解答**

通过前期调整对前期财务报表进行重述，并不一定意味着必须撤回并修改针对那些前期财政年度业已批准并报出的财务报表。但是，管理层仍需留意任何特定的监管要求。

<a id="s25-chap_03_navPoint_idp1688848584"></a>
#### <a id="s25-FAQ_3.23.1"></a>FAQ 3.23.1 – IAS 8中关于不动产、厂场和设备以及无形资产会计政策变更的例外规定是否也适用于投资性房地产？

准则依据：IAS 8 第17段  
正文参见：[3.23](09.md#s20-Para_3.23)

**问题**

IAS 8中关于不动产、厂场和设备以及无形资产会计政策变更的例外规定是否也适用于投资性房地产？

**解答**

不适用。IAS 8提供了具体指引，允许主体将不动产、厂场和设备以及无形资产的计量政策变更按照IAS 16或IAS 38作为重估价进行会计处理（即采用未来适用法）。这是一项针对一般原则的例外规定，不得类比适用于按照IAS 40核算的投资性房地产。主体将投资性房地产的计量模式从成本模式变更为公允价值模式时，应应用IAS 8的一般指引，即除不切实可行的范围外，采用追溯调整法（追溯适用）进行会计处理。[IAS 8 第23段]。

预计追溯适用不切实可行的情形极为罕见。这是因为按照IAS 40第79(e)段，采用成本模式计量投资性房地产的主体必须披露投资性房地产的公允价值，除非在极少数情况下主体无法可靠计量投资性房地产的公允价值。如果投资性房地产的公允价值无法可靠计量，则将政策变更为按公允价值计量投资性房地产本身就是不恰当的。

IAS 8第14段要求，自愿性会计政策变更必须使财务报表就交易、其他事项或情况对主体财务状况、财务业绩或现金流量的影响提供可靠且更相关的信息。

### 会计政策变更与会计估计变更的区分

<a id="s25-chap_03_navPoint_idp1688858312"></a>
#### <a id="s25-FAQ_3.24.1"></a>FAQ 3.24.1 – 投资性房地产的公允价值是否属于会计估计？

准则依据：IAS 8 示例4  
正文参见：[3.24](09.md#s21-Para_3.24)

自2023年1月1日或以后日期开始的年度期间生效的修订（取决于任何认可程序）：

**背景**

A主体拥有一项投资性房地产，并采用IAS 40中的公允价值模式对其进行会计处理。自取得该项投资性房地产以来，A主体一直采用与IFRS 13中所述收益法一致的估值技术来计量该投资性房地产的公允价值。

然而，由于自上一报告期末以来市场状况发生变化，A主体将其使用的估值技术变更为与IFRS 13中所述市场法一致的估值技术。A主体得出结论认为，变更后的计量结果更能代表当前报告期末存在的情况下该投资性房地产的公允价值，因此IFRS 13允许此类变更。A主体同时得出结论认为，估值技术的变更不属于前期差错更正。

**问题**

投资性房地产的公允价值是否属于会计估计？

**解答**

投资性房地产的公允价值属于会计估计，原因如下：

（a）投资性房地产的公允价值是财务报表中存在计量不确定性的货币金额。公允价值反映在市场参与者之间的假定出售或购买交易中将收到或支付的价格；因此，该价格无法直接观察，而必须进行估计；

（b）投资性房地产的公允价值是在应用会计政策（公允价值模式）时所使用的计量技术（估值技术）的输出结果；以及

（c）在作出投资性房地产公允价值的估计时，A主体运用了判断和假设，例如：

（i）选择计量技术——选择在当前情况下恰当的估值技术；以及

（ii）应用计量技术——确定市场参与者在应用该估值技术时会使用的输入值，例如涉及可比资产的市场交易所产生的信息。

在此事实情形下，估值技术的变更是用于估计投资性房地产公允价值的计量技术的变更。由于会计政策（即按公允价值计量投资性房地产）并未改变，该项变更的影响属于会计估计变更。

<a id="s25-chap_03_navPoint_idp1688911176"></a>
#### <a id="s25-FAQ_3.24.2"></a>FAQ 3.24.2 – 以现金结算的股份支付负债的公允价值是否属于会计估计？

准则依据：IAS 8 示例5  
正文参见：[3.24](09.md#s21-Para_3.24)

自2023年1月1日或以后日期开始的年度期间生效的修订（取决于任何认可程序）：

**背景**

20X0年1月1日，A主体向其每名员工授予100份股票增值权（SAR），前提是该员工在未来三年内继续受雇于该主体。股票增值权赋予员工在自20X0年1月1日起的三年等待期内，根据主体股价上涨幅度获取未来现金支付的权利。

A主体应用IFRS 2，将授予股票增值权作为以现金结算的股份支付交易进行会计处理——在此过程中，主体就股票增值权确认一项负债，并按其公允价值（按IFRS 2定义）计量该负债。A主体采用布莱克-斯科尔斯-默顿（Black-Scholes-Merton）公式（一种期权定价模型）计量20X0年1月1日及报告期末的股票增值权负债公允价值。

20X1年12月31日，由于自上一报告期末以来市场状况发生变化，A主体在估计该日股票增值权负债的公允价值时，变更了对预期股价波动率（即期权定价模型的一项输入值）的估计。A主体得出结论认为，该输入值的变更不属于前期差错更正。

**问题**

以现金结算的股份支付负债的公允价值是否属于会计估计？

**解答**

该负债的公允价值属于会计估计，原因如下：

- 该负债的公允价值是财务报表中存在计量不确定性的货币金额。该公允价值是在假定交易中清偿该负债所需的金额；因此，该金额无法直接观察，而必须进行估计；

- 该负债的公允价值是在应用会计政策（按公允价值计量以现金结算的股份支付负债）时所使用的计量技术（期权定价模型）的输出结果；以及

- 为估计该负债的公允价值，A主体运用了判断和假设，例如：

- 选择计量技术——选择期权定价模型；以及

- 应用计量技术——确定市场参与者在应用该期权定价模型时会使用的输入值，例如预期股价波动率和预期股利。

在此事实情形下，预期股价波动率的变更是用于计量20X1年12月31日股票增值权负债公允价值的输入值的变更。由于会计政策（即按公允价值计量该负债）并未改变，该项变更的影响属于会计估计变更。

<a id="s25-chap_03_navPoint_idp1687140280"></a>
#### <a id="s25-FAQ_3.24.3"></a>FAQ 3.24.3 – 变更存货成本计价公式是否构成会计估计变更？

准则依据：IAS 8 结论基础第BC53段  
正文参见：[3.24](09.md#s21-Para_3.24)

自2023年1月1日或以后日期开始的年度期间生效的修订（取决于任何认可程序）：

不构成。在应用IAS 2时，为通常可互换的存货选择成本计价公式（即先进先出法（FIFO）或加权平均成本法）构成选择会计政策，而非作出会计估计。尽管这一结论似乎与IAS 8中的定义不一致，但国际会计准则理事会（IASB）在IAS 8的结论基础中承认，IAS 2第36(a)段对此作出了专门规定，因此该专门规定应优先于IAS 8的一般要求。然而，IAS 2中的该项规定不得类比适用于其他国际财务报告准则。

### 会计估计变更的适用

<a id="s25-chap_03_navPoint_idp1687148088"></a>
#### <a id="s25-EX3.32.1"></a>EX 3.32.1 – 会计估计变更的其他情形

准则依据：IAS 8 第37段  
正文参见：[3.32](09.md#s21-Para_3.32)

影响资产、负债和利润表的估计变更

某主体原本对一项由保险覆盖的负债估计为C1百万，但随后将该估计修订为C1.5百万。初始时，主体确认了一项C1百万的负债和一项C1百万的补偿权资产。管理层将负债估计修订为C1.5百万，并将补偿权资产增加至C1.25百万，以等于上限为C1.25百万的保险赔付金额。负债估计增加至C1.25百万的部分引起补偿权估计的相应增加（借：补偿权 C0.25百万，贷：负债 C0.25百万）。负债增加的剩余部分（C0.25百万）计入利润表。

影响负债和其他综合收益的估计变更

某主体修订了就计入其他综合收益的外币折算差额所确认的应交税费估计。该修订将影响资产负债表上的应交税费负债以及其他综合收益中的外币折算利得/损失。

影响资产和其他综合收益的估计变更

某主体修订了对某项不动产、厂场和设备公允价值的估计。该修订将影响不动产、厂场和设备余额，相应调整计入其他综合收益中的重估利得/损失。

### 差错

<a id="s25-chap_03_navPoint_idp1687164600"></a>
#### <a id="s25-FAQ_3.36.1"></a>FAQ 3.36.1 – 管理层应如何确定在前期财务报表批准报出时是否已可获得可靠信息？

准则依据：概念框架 第QC15段  
正文参见：[3.36](09.md#s22-Para_3.36)

**问题**

管理层应如何确定在前期财务报表批准报出时是否已可获得可靠信息？

**解答**

确定前期是否存在差错，要求在发生差错时已存在且合理预期能够取得可靠信息。在某些情况下，可以明确判断是否已可获得可靠信息。例如，管理层可能忽略了发票或债权人对账单形式的现有证据，导致一项重大费用项目少计提。在其他情况下，判断可能更加困难，尤其是存在蓄意操纵业绩或舞弊的情形。这是因为管理层可能故意隐瞒或销毁可靠信息，或制造虚假和不可靠的信息以掩盖或粉饰错误的会计处理。

在这些情况下，即使管理层只能利用未来年度出现的相关信息才能对差错进行量化，并在该未来年度重建与早期期间相关的会计记录，这些差错通常仍构成前期差错。这是因为在许多情况下，可靠信息在前期本就存在，未参与制造差错的理性人士本应获取并使用该信息（或者在该信息业已存在的情况下，不会将其隐瞒或销毁）。

<a id="s25-chap_03_navPoint_idp1687169592"></a>
#### <a id="s25-FAQ_3.37.1"></a>FAQ 3.37.1 – 执行国际财务报告准则解释委员会（IFRS IC）议程决定时，应作为前期差错更正还是会计政策变更进行会计处理？

准则依据：IAS 8 第48段  
正文参见：[3.37](09.md#s22-Para_3.37)

**问题**

国际财务报告准则解释委员会（IFRS IC）经常收到与新识别财务报告问题相关的提交事项，并决定是否将该问题纳入议程。委员会可能出于各种原因拒绝将某问题纳入议程，原因之一是其认定国际财务报告准则中的要求已为主体得出结论提供了充分依据。

国际财务报告准则解释委员会（IFRS IC）议程决定不构成国际财务报告准则的一部分；但它们通常会提供澄清说明，且部分利益相关方期望报表编制者考虑国际财务报告准则解释委员会（IFRS IC）议程决定。国际财务报告准则解释委员会（IFRS IC）在2019年3月《IFRIC更新》中指出：“发布议程决定的过程通常会产生解释性材料，提供原本无法获得且原本无法合理预期能够取得的新信息。”因此，主体可能会在国际财务报告准则解释委员会（IFRS IC）发布议程决定后变更其先前的会计处理。

主体应将此类变更作为前期差错更正还是会计政策变更进行会计处理？

**解答**

管理层此前可能是基于当时可获得的国际财务报告准则指引，对相关准则作出合理解释后应用了某项会计政策。

如上所述，议程决定通常会提供解释性材料，提供“原本无法获得且原本无法合理预期能够取得的新信息”。因此，为响应议程决定而实施的变更由于源于“新信息”，通常导致按照IAS 8处理的自愿性会计政策变更。

主体应结合个案的具体事实，应用IAS 8确定变更的性质，并就变更原因提供充分披露。

主体可考虑采用以下表述来说明该会计处理变更：

“本集团此前采用[先前会计实务说明]进行会计处理。继国际财务报告准则解释委员会（IFRS IC）于[日期]就[主题事项]发布议程决定后，本集团重新审视了其会计处理。本集团已采用国际财务报告准则解释委员会（IFRS IC）议程决定中所述的处理方法[新处理方法说明]。该项会计处理变更已采用追溯调整法（追溯适用）进行会计处理，并已重述比较信息。[披露影响详情。]”

主体在评估和描述该项变更时，还应考虑相关监管机构的意见。

关于何时根据国际财务报告准则解释委员会（IFRS IC）议程决定实施会计政策变更的进一步指引，另请参见[FAQ 3.20.1](09.md#s25-FAQ_3.20.1)。

<a id="s25-chap_03_navPoint_idp1684192936"></a>
#### <a id="s25-FAQ_3.38.1"></a>FAQ 3.38.1 – 主体应如何对不重要的前期差错进行会计处理？

准则依据：IAS 8 第5段  
正文参见：[3.38](09.md#s22-Para_3.38)

**问题**

主体应如何对前期财务报表而言不重要的前期差错进行会计处理？

**解答**

对于就前期财务报表而言不重要的差错，在当期予以更正而非追溯更正可能是可以接受的。但是，管理层应综合考虑定性和定量因素，评估该做法是否会导致当期出现重大差错。如果在当期更正会导致当期财务报表发生重大错报，管理层通常应当重述比较金额。

<a id="s25-chap_03_navPoint_idp1684200744"></a>
#### <a id="s25-EX3.38.2"></a>EX 3.38.2 – 监管机构在会计差错更正方面对重要性的考量

准则依据：IAS 8 第5段  
正文参见：[3.38](09.md#s22-Para_3.38)

当管理层评估前期差错的影响时，除国际财务报告准则提供的指引外，还需注意任何特定的监管要求。例如，美国证券交易委员会（SEC）已表明，在美国上市的国际财务报告准则报表编制者如果不打算应用《会计实务公告第108号》（“SAB 108”），应首先向SEC工作人员咨询。SAB 108要求主体考虑两种评估差错的方法：（a）“铁幕法”（iron curtain）——通过当期利润表更正留在资产负债表上的差错累积影响；以及（b）“滚转法”（rollover）——利润表实际错报的金额。我们认为，SAB 108中的方法在国际财务报告准则下是确定差错是否具有重要性的可接受方法。

### 前期调整的所得税影响会计处理

<a id="s25-chap_03_navPoint_idp1684204840"></a>
#### <a id="s25-FAQ_3.42.1"></a>FAQ 3.42.1 – 当会计政策变更需要追溯调整时，主体应如何对相关所得税进行会计处理？

准则依据：IAS 8 第4段  
正文参见：[3.42](09.md#s23-Para_3.42)

**问题**

IAS 8在处理前期差错更正以及为应用会计政策变更而作出的追溯调整的所得税影响时，直接援引了IAS 12。当会计政策变更需要追溯调整时，主体应如何对相关所得税进行会计处理？

**解答**

当主体对会计政策变更采用追溯调整法（追溯适用）时，应将相关所得税影响作为前期调整的一部分。这可能影响当期所得税和/或递延所得税。该所得税影响属于对期初权益调整的一部分，不应计入当期的所得税费用。

同样的原则也适用于前期差错更正的所得税影响的会计处理。
