## 引言和范围（第15.1–15.44段）

 

<a id="s107-Para_15.1"></a>**15.1** IFRS 16 的目标是规定租赁的确认、计量、列报和披露原则。

[IFRS 16 第1段]。

<a id="s107-Para_15.2"></a>**15.2** 租赁被定义为“在一定期间内，出租人将资产（标的资产）的使用权让与承租人以获取对价的合同或合同的一部分”。

[IFRS 16 附录A]。

<a id="s107-Para_15.3"></a>**15.3** 本准则将下列各项排除在其适用范围之外：

- 勘探或使用矿产、石油、天然气及类似不可再生资源的租赁；

- 承租人持有的属于 IAS 41《农业》范围内的生物资产租赁；

- 属于 IFRIC 12《服务特许权安排》范围内的服务特许权安排；

- 出租人授予的属于 IFRS 15《与客户之间的合同产生的收入》范围内的知识产权许可；以及

- 承租人在属于 IAS 38《无形资产》范围内的许可协议下持有的权利，例如电影影片、录像制品、剧本、手稿、专利和版权等项目。

[IFRS 16 第3段]。

[FAQ 15.3.1 – 属于 IAS 19 范围内的公司汽车使用安排是否也可能属于 IFRS 16 的范围？](34.md#s113-FAQ_15.3.1)  
[FAQ 15.3.2 – 地下空间是否属于 IFRS 16 的范围？](34.md#s113-FAQ_15.3.2)

<a id="s107-Para_15.4"></a>**15.4** 除上述属于 IAS 38 范围内的无形资产外，承租人可以选择将 IFRS 16 应用于其他无形资产的租赁。如果承租人不将 IFRS 16 应用于无形资产租赁，则应用 IAS 38。出租人没有选择权，除上述属于 IFRS 15 范围内的项目外，必须将 IFRS 16 应用于无形资产的租赁。

[IFRS 16 第4段]。

 

<a id="s107-chap_15_navPoint_2"></a>
### 识别租赁

 

<a id="s107-Para_15.5"></a>**15.5** 如果存在已识别资产，且合同让与了在一定期间内控制该已识别资产使用的权利以换取对价，则该合同为租赁或包含租赁。

[IFRS 16 第9段]。

[FAQ 15.5.1 – 如何解释“对价”一词？](34.md#s113-FAQ_15.5.1)  
[FAQ 15.5.2 – 如何解释“一段期间”一词？](34.md#s113-FAQ_15.5.2)  
[FAQ 15.5.3 – 永久期间是否属于“一段期间”？](34.md#s113-FAQ_15.5.3)

<a id="s107-Para_15.6"></a>**15.6** 主体在合同开始日评估合同是否为租赁或包含租赁。合同开始日是指租赁协议日与各方就主要租赁条款和条件作出承诺日中的较早者。

[IFRS 16 第9段]。

<a id="s107-Para_15.7"></a>**15.7** 除非合同的条款和条件发生变化，否则主体不重新评估合同是否包含租赁。

[IFRS 16 第11段]。

<a id="s107-Para_15.9"></a>**15.9** 资产可以通过明示或隐含的方式予以识别。如果是明示识别，资产在合同中被明确指定（例如通过序列号或类似的识别标记）；如果是隐含识别，合同中未提及该资产，但在供应方向客户提供该资产时即被隐含指定。这两种情况都可能构成已识别资产。

[IFRS 16 附录B 第B13段]。

[FAQ 15.9.1 – 如果一项安排的履行依赖于某项资产的使用，是否存在已识别资产？](34.md#s113-FAQ_15.9.1)

<a id="s107-Para_15.10"></a>**15.10** 如果供应方在整个使用期间拥有对该资产的实质性替换权，则不存在已识别资产。如果供应方具有替换替代资产的实际能力，且通过替换该资产在经济上获益，则该替换权具有实质性。

[IFRS 16 附录B 第B14段]。

[FAQ 15.10.1 – 在评估出租人是否因替换资产而在经济上获益时，应考虑哪些因素？](34.md#s113-FAQ_15.10.1)

<a id="s107-Para_15.11"></a>**15.11** 当资产位于客户场所时，替换成本通常较高。在这种情况下，替换成本可能会超过其带来的利益。

[IFRS 16 附录B 第B17段]。

<a id="s107-Para_15.12"></a>**15.12** 评估替换权是否具有实质性取决于合同开始日的事实和情况，不考虑预计不太可能发生的情况。

[IFRS 16 附录B 第B16段]。

<a id="s107-Para_15.13"></a>**15.13** 在资产未能正常运行或需要技术升级时替换资产的权利，并不妨碍合同依赖于已识别资产。

[IFRS 16 附录B 第B18段]。

<a id="s107-Para_15.14"></a>**15.14** 供应方在特定日期或之后、或在特定事件发生时出于任何原因替换标的资产的权利或义务，并不妨碍合同依赖于已识别资产，因为供应方并非在整个使用期间都具有替换替代资产的实际能力。

[IFRS 16 附录B 第B15段]。

[FAQ 15.14.1 – 替换权是在特定时点还是在特定事件发生时予以考虑？](34.md#s113-FAQ_15.14.1)

<a id="s107-Para_15.15"></a>**15.15** 如果客户无法轻易确定供应方是否拥有实质性替换权，客户应推定该替换权不具有实质性。

[IFRS 16 附录B 第B19段]。

<a id="s107-Para_15.16"></a>**15.16** 已识别资产可以是较大资产中物理上可区分的部分，例如多层建筑中的某一楼层，或电缆中物理上可区分的暗光纤。产能部分（即较大资产中物理上不可区分的部分）不属于已识别资产，除非其代表了整个资产的几乎全部产能。光纤电缆中不代表该电缆几乎全部产能的产能部分，由于在物理上不可区分，因此不符合已识别资产的条件。

[IFRS 16 附录B 第B20段]。

<a id="s107-Para_15.17"></a>**15.17** 如果客户在整个使用期间同时拥有获取因使用已识别资产所产生的几乎全部经济利益的权利，以及主导该已识别资产使用的权利，则合同让与了控制已识别资产使用的权利。

[IFRS 16 附录B 第B9段]。

<a id="s107-Para_15.18"></a>**15.18** 主体可以直接或间接地获取经济利益（例如通过使用、持有或转租该资产）。经济利益包括在主体使用该资产的既定权利范围内产生的主产品和任何副产品（包括由此产生的潜在现金流量），以及与使用已识别资产相关的来自第三方的付款。与资产所有权相关的经济利益不予考虑。

[IFRS 16 附录B 第B21段]。[IFRS 16 附录B 第B22段]。

[FAQ 15.18.1 – 识别租赁时应考虑哪些经济利益？](34.md#s113-FAQ_15.18.1)

<a id="s107-Para_15.19"></a>**15.19** 主体必须确定哪一方（即客户或供应方）有权在整个使用期间主导已识别资产的使用方式和使用目的。

[IFRS 16 附录B 第B24段]。

<a id="s107-Para_15.20"></a>**15.20** 准则列举了若干相关决策权的示例：

- 改变产出类型的权利。

- 改变产出时间的权利。

- 改变产出地点的权利。

- 改变产出数量的权利。

[IFRS 16 附录B 第B26段]。

[FAQ 15.20.1 – 评估哪一方有权主导资产使用时，应考虑哪些决策？](34.md#s113-FAQ_15.20.1)

<a id="s107-Para_15.21"></a>**15.21** 各项决策权的相关性取决于所考虑的标的资产以及合同的条款和条件。如果双方均拥有决策权，主体应考虑与改变资产使用方式和使用目的最相关的权利。当决策权影响因使用该资产而产生的经济利益时，该决策权即具有相关性。

[IFRS 16 附录B 第B25段]。

<a id="s107-Para_15.22"></a>**15.22** 主体在评估时不考虑保护性权利。供应方可能会限制客户对资产的使用，以保护其人员或确保遵守相关法律法规。例如，租用船舶的客户被禁止将船舶驶入海盗高发海域或运输危险品。这些保护性权利不影响对合同哪一方有权主导已识别资产使用的评估。

[IFRS 16 附录B 第B30段]。

<a id="s107-Para_15.23"></a>**15.23** 关于维护和操作资产的决策并不赋予主导资产使用的权利。只有当关于资产使用方式和使用目的的决策已预先确定时，主体才考虑这些决策。

[IFRS 16 附录B 第B27段]。

<a id="s107-Para_15.24"></a>**15.24** 关于标的资产使用方式和使用目的的决策可能在租赁开始日之前已预先确定。在此情况下，如果满足下列条件之一，则客户有权主导资产的使用：

- 客户有权在整个使用期间操作该已识别资产，且供应方无权改变操作指令；或

- 客户设计了该已识别资产（或该资产的特定方面），从而预先确定了该资产在整个使用期间的使用方式和使用目的。

[IFRS 16 附录B 第B24段]。

[FAQ 15.24.1 – 分析在租赁开始日前已作出的决策时，应考虑哪些因素？](34.md#s113-FAQ_15.24.1)

<a id="s107-Para_15.25"></a>**15.25** 使用期间之前作出的决策不予考虑，除非该决策是在客户设计资产并预先确定其使用的背景下作出的。

[IFRS 16 附录B 第B29段]。

<a id="s107-chap_15_navPoint_3"></a>
### 分拆合同组成部分

 

<a id="s107-Para_15.28"></a>**15.28** 合同通常合并了供应方的不同类型义务，可能是多个租赁组成部分的组合，或是租赁组成部分与非租赁组成部分的组合。例如，工业区租赁可能包含土地、建筑物和设备的租赁，汽车租赁合同可能与维护服务结合在一起。在多要素安排中，主体必须（根据租赁定义的指引）识别每一项单独的租赁组成部分并单独对其进行会计处理。

[IFRS 16 第12段]。

<a id="s107-Para_15.29"></a>**15.29** 如果同时满足下列两项标准，则安排包含不止一个租赁组成部分：

- 承租人可从单独使用该资产或将其与承租人易于获得的其他资源一起使用中获利；以及

- 该标的资产与合同中的其他标的资产不存在高度依赖或高度关联关系。

[IFRS 16 附录B 第B32段]。

[FAQ 15.29.1 – 出租人如何根据 IFRS 16 和 IFRS 15 分拆合同组成部分？](34.md#s113-FAQ_15.29.1)

<a id="s107-Para_15.30"></a>**15.30** 在识别非租赁组成部分时，主体必须考虑是否向承租人转让了商品或服务。例如，如果承租人为资产使用权付款，同时也为行政管理工作付款，而这些行政管理工作并未向承租人转让商品或服务，则该行政管理工作不构成单独的非租赁组成部分。

[IFRS 16 附录B 第B33段]。

[FAQ 15.61.2 – 承租人应如何对保险费、房产税或维护费等成本进行会计处理？](34.md#s113-FAQ_15.61.2)

<a id="s107-Para_15.31"></a>**15.31** 如果分析得出存在单独组成部分的结论，则必须在各组成部分之间分摊对价（除非采用[第15.34段](33.md#s107-Para_15.34)中的实务权宜之计）。

[IFRS 16 第12段]。

<a id="s107-Para_15.32"></a>**15.32** 承租人按相对单独价格分摊对价。如果无法轻易获得可观察的单独价格，承租人应估计价格，并应最大限度地利用可观察信息。

[IFRS 16 第13段]。[IFRS 16 第14段]。

<a id="s107-Para_15.33"></a>**15.33** 出租人按照 IFRS 15 的规定，以相对单独售价为基础分摊对价。

[IFRS 16 第17段]。

[FAQ 15.33.1 – 如果出租人向承租人销售耗材，对价如何分摊？](34.md#s113-FAQ_15.33.1)

<a id="s107-Para_15.34"></a>**15.34** 作为一项实务权宜之计，承租人无需分拆租赁组成部分和非租赁组成部分。承租人可将每一租赁组成部分及其相关的任何非租赁组成部分合并为单一租赁组成部分进行会计处理。例如，承租人租赁了多台机器（每台机器均符合单独租赁组成部分的定义），同时从出租人处获得维护服务，承租人有两种选择：承租人可以分别对每一租赁组成部分和每一服务组成部分进行会计处理；或者决定将每台机器的租赁及与该租赁相关的维护服务合并，作为单一租赁组成部分进行会计处理。该实务权宜之计是一项按标的资产类别作出的会计政策选择。

[IFRS 16 第15段]。

 

<a id="s107-chap_15_navPoint_4"></a>
### 合同合并

 

<a id="s107-Para_15.35"></a>**15.35** 与同一交易对手方可能在同时或相近时间、且相互关联地订立多份合同。如果满足下列一项或多项条件，主体应将在同时或相近时间与同一交易对手方（或该交易对手方的关联方）订立的多份合同合并：

- 这些合同基于总体商业目的而作为一揽子交易进行谈判；

- 一份合同的对价金额取决于另一份合同的定价或履约情况；或

- 所涉及的资产构成单一租赁组成部分。

合同合并既影响对是否存在租赁的评估，也影响对潜在租赁的会计处理。

[IFRS 16 附录B 第B2段]。

[EX 15.35.1 – 基于单独合同提供的临时建筑解决方案的会计处理](34.md#s113-EX15.35.1)

 

<a id="s107-chap_15_navPoint_5"></a>
### 租赁期

 

<a id="s107-Para_15.36"></a>**15.36** 租赁期自出租人提供标的资产以供承租人使用的日期（租赁期开始日）起计算。

[IFRS 16 附录B 第B36段]。

<a id="s107-Para_15.37"></a>**15.37** 确定租赁期时应考虑以下术语：

- 租赁的不可撤销期间是指承租人无法终止合同的任何期间（IFRS 16 第B35段）。因此，任何不可撤销期间实际上设定了最短租赁期。

- 租赁的可执行期间是指承租人与出租人之间存在可执行权利和义务的期间。如 IFRS 16 第B34段所述：“在确定租赁期和评估租赁不可撤销期间的长度时，主体应适用合同的定义并确定合同可执行的期间。如果承租人和出租人双方均有权在未经另一方许可的情况下终止租赁，且支付的罚款不超过不重大金额，则该租赁不再具有可执行性。”要成为确定可执行期间的一部分，计入租赁期的任何选择权期间也必须是可执行的。因此，可执行期间实际上设定了最长租赁期。

- 租赁期是指租赁的不可撤销期间，加上承租人合理确定将使用的任何选择权期间（IFRS 16 第18段）。如果承租人合理确定将行使续租选择权，则续租选择权涵盖的期间应计入租赁期。同样的逻辑适用于终止选择权。如果承租人合理确定将不行使终止选择权，则终止选择权涵盖的期间应计入租赁期。租赁期不得超出可执行期间的结束日。

下图展示了这些概念。

![](assets/74.png)

此外，2019年11月的《国际财务报告解释委员会最新动态》（IFRIC Update）在考虑可执行期间时包含了以下内容：

“委员会指出，在应用第B34段并确定请求中所述租赁的可执行期间时，主体应考虑：

(a) 合同更广泛的经济实质，而不仅仅是合同约定的终止付款。例如，如果任何一方具有不终止租赁的经济激励，以致其在终止时将承担超过不重大金额的罚款，则合同在可终止日之后仍具有可执行性；以及

(b) 双方是否各自有权在未经另一方许可的情况下终止租赁，且支付的罚款不超过不重大金额。根据第B34段，只有当双方均拥有此项权利时，租赁才不再具有可执行性。因此，如果仅有一方有权在未经另一方许可且罚款不超过不重大金额的情况下终止租赁，则合同在该方可终止之日后仍具有可执行性。

如果主体得出结论认为合同在可撤销租赁的通知期（或可续约租赁的初始期间）之后仍具有可执行性，则主体随后应应用 IFRS 16 第19段及第B37–B40段，评估承租人是否合理确定将不行使终止租赁选择权。”

具体而言，国际财务报告准则解释委员会（IFRS IC）的议程决定提及承租人预计在合同可终止日之后继续使用不可移除的租赁改良支出，并预计承担放弃或拆除该等租赁改良支出成本的情形。在此情况下，应用 IFRS 16 第B34段，主体应考虑合同是否至少在租赁改良支出的预期效用期间内具有可执行性，因为如果主体终止租赁，可能会承担超过不重大金额的罚款。该议程决定还再次强调，主体在评估承租人是否合理确定将行使续租选择权、购买标的资产选择权或不行使终止租赁选择权时，应考虑在合同期内已实施（或预计将实施）的重大租赁改良支出。

[IFRS 16 第18段]。

[FAQ 15.37.2 – 如果一方拥有附带超过不重大罚款的终止选择权，如何确定租赁期？](34.md#s113-FAQ_15.37.2)  
[FAQ 15.37.3 – 含有双向终止选择权的永久租赁合同如何进行会计处理？](34.md#s113-FAQ_15.37.3)  
[FAQ 15.37.4 – 在 IFRS 16 第B34段的语境下如何解释“罚款”？](34.md#s113-FAQ_15.37.4)  
[EX 15.37.5 – 什么是可执行期间？](34.md#s113-EX15.37.5)

<a id="s107-Para_15.38"></a>**15.38** 主体应考虑为承租人行使续租选择权（或不行使终止选择权）创造经济激励的所有事实和情况，以评估行使（或不行使）是否合理确定。

[IFRS 16 第19段]。

<a id="s107-Para_15.39"></a>**15.39** 主体考虑的因素示例包括：

- 选择权期间的合同条款和条件与市场费率的比较：如果租赁付款额高于市场费率，承租人更可能不行使续租选择权。主体考虑的其他条款示例包括终止罚款或余值担保。

- 已实施（或预计将实施）的重大租赁改良支出：如果承租人投入重大资金对租赁资产进行改良或根据其特殊需求进行定制，承租人更可能行使续租选择权。

- 与终止租赁/签订替代租赁相关的成本：如果行使续租选择权可以避免谈判成本、搬迁成本、寻找另一项合适资产的成本、整合新资产的成本以及按合同约定状态或至合同约定地点归还原资产的成本，则承租人更可能行使续租选择权。

- 标的资产对承租人经营的重要性：如果标的资产具有专用性质或没有合适的替代资产，承租人更可能行使续租选择权。

- 与行使选择权相关的条件，以及这些条件存在的可能性。

[IFRS 16 附录B 第B37段]。

[FAQ 15.39.2 – 续租选择权如何影响租赁期？](34.md#s113-FAQ_15.39.2)  
[FAQ 15.39.3 – 应如何权衡合理确定性的不同指标？](34.md#s113-FAQ_15.39.3)  
[FAQ 15.39.4 – 评估承租人是否“合理确定”行使选择权时，是否包括非货币性经济激励？](34.md#s113-FAQ_15.39.4)  
  
[FAQ 15.39.5 – 应如何考虑超出书面合同范围的可执行性？](34.md#s113-FAQ_15.39.5)

<a id="s107-Para_15.40"></a>**15.40** 合同可能将选择权与其他特征结合在一起，从而无论承租人是否行使该选择权，承租人均向出租人担保实质上相同的最低或固定回报。续租选择权与余值担保的组合即为一例。在此情况下，主体应假定承租人合理确定将行使续租选择权。

[IFRS 16 附录B 第B38段]。

<a id="s107-Para_15.41"></a>**15.41** 承租人关于其通常使用特定类型资产的期间的过往惯例及其背后的经济原因，也可能提供有用信息。

[IFRS 16 附录B 第B40段]。

<a id="s107-Para_15.42"></a>**15.42** 对租赁期的评估是在租赁期开始日作出的（租赁期开始日的定义见[第15.36段](33.md#s107-Para_15.36)）。

[IFRS 16 附录B 第B41段]。

<a id="s107-Para_15.43"></a>**15.43** 仅当发生承租人可控范围内的重大事件或情况变化，且影响承租人是否合理确定将行使选择权时，承租人才重新评估续租选择权和终止选择权。出租人不重新评估选择权是否合理确定将被行使。

[IFRS 16 第20段]。

[EX 15.43.1 – 承租人可控范围内的哪些重大事件或情况变化会影响其是否合理确定行使选择权？](34.md#s113-EX15.43.1)

<a id="s107-Para_15.44"></a>**15.44** 不可撤销租赁期间的变化会导致承租人和出租人双方的租赁期发生变化。不可撤销租赁期间变化的示例包括：

- 承租人以不同于主体先前确定为合理确定的方式行使选择权；或

- 发生某一事件，在合同上要求承租人行使先前未计入租赁期确定的选择权（或禁止承租人行使先前已计入租赁期确定的选择权）。例如，如果某零售门店的收入首次超过特定金额，承租人在合同上可能有义务延长租赁期。

[IFRS 16 第21段]。

<a id="s108-chap_15_navPoint_6"></a>
## 确认和计量豁免（第15.45–15.55段）

 

<a id="s108-Para_15.45"></a>**15.45** IFRS 16 包含两项确认和计量豁免：短期租赁和标的资产为低价值的租赁。这两项豁免均属可选，且仅适用于承租人。

[IFRS 16 第5段]。

<a id="s108-Para_15.46"></a>**15.46** 采用其中一项或两项豁免的承租人，应按直线法或更能代表承租人受益模式的其他系统合理的方法将租赁付款额确认为费用。

[IFRS 16 第6段]。

 

<a id="s108-chap_15_navPoint_7"></a>
### 短期租赁

 

<a id="s108-Para_15.47"></a>**15.47** 短期租赁是指租赁期不超过12个月的租赁。如果承租人合理确定将行使续租选择权或不行使终止选择权，则租赁期还包括该续租选择权或终止选择权涵盖的期间。包含购买选择权的租赁不属于短期租赁。

[IFRS 16 附录A]。

[EX 15.47.1 – 包含终止选择权的永久租赁合同能否符合短期租赁的条件？](34.md#s113-EX15.47.1)  
  
[FAQ 15.47.2 – 如果存在非连续使用期间，租赁期如何确定？](34.md#s113-FAQ_15.47.2)

<a id="s108-Para_15.48"></a>**15.48** 短期租赁豁免必须按标的资产类别应用。

[IFRS 16 第8段]。

<a id="s108-Para_15.49"></a>**15.49** 如果已采用短期租赁豁免的租赁随后发生变更或租赁期发生变化，则应将其作为一项新租赁进行会计处理。

[IFRS 16 第7段]。

 

<a id="s108-chap_15_navPoint_8"></a>
### 低价值资产租赁

 

<a id="s108-Para_15.50"></a>**15.50** 承租人应基于标的资产全新时的价值评估该资产是否为低价值，而不论该资产的已使用年限。

[IFRS 16 附录B 第B3段]。

[FAQ 15.50.1 – IFRS 16 如何定义“低价值”一词？](34.md#s113-FAQ_15.50.1)

<a id="s108-Para_15.51"></a>**15.51** 低价值资产豁免可以按单项租赁逐项应用。

[IFRS 16 第8段]。

<a id="s108-Para_15.52"></a>**15.52** 对低价值资产租赁的分析不要求承租人确定低价值资产汇总后是否重大。即使低价值资产租赁的汇总价值对承租人而言重大，仍可采用该豁免。

[IFRS 16 附录B 第B4段]。

<a id="s108-Para_15.53"></a>**15.53** 标的资产只有在满足两项额外标准时才符合低价值资产豁免的条件。首先，承租人必须能够从单独使用该资产或将其与易于获得的其他资源一起使用中获利。其次，标的资产不得依赖于其他资产或与其他资产高度关联。

[IFRS 16 附录B 第B5段]。

[EX 15.53.1 – 承租人如何评估租赁资产是否符合低价值资产标准？](34.md#s113-EX15.53.1)

<a id="s108-Para_15.54"></a>**15.54** 如果承租人转租或预期转租租赁资产，则该租赁不符合低价值资产租赁的条件。

[IFRS 16 附录B 第B7段]。

 

<a id="s108-chap_15_navPoint_9"></a>
### 组合豁免

<a id="s108-Para_15.55"></a>**15.55** 如果承租人和出租人合理预期将 IFRS 16 应用于具有类似特征的租赁组合所产生的影响，与按单项租赁应用本准则不会产生重大差异，则承租人和出租人均可采用组合法应用 IFRS 16。

[IFRS 16 附录B 第B1段]。

<a id="s109-chap_15_navPoint_10"></a>
## 承租人会计处理（第15.56–15.104段）

<a id="s109-chap_15_navPoint_11"></a>
### 确认

<a id="s109-Para_15.56"></a>**15.56** 承租人对几乎所有租赁合同均确认一项使用权资产和一项相应的租赁负债。租赁合同实质上是以分期付款方式取得标的资产的使用权。承租人在租赁期开始日初始确认使用权资产和租赁负债。

[IFRS 16 第22段]。

<a id="s109-chap_15_navPoint_12"></a>
### 初始计量——租赁负债

 

<a id="s109-Para_15.57"></a>**15.57** 在租赁期开始日，承租人按照租赁期内尚未支付的租赁付款额的现值计量租赁负债。

[IFRS 16 第26段]。

<a id="s109-Para_15.58"></a>**15.58** 如果租赁内含利率能够容易确定，承租人应采用租赁内含利率作为折现率。租赁内含利率是指使（a）租赁付款额与（b）未担保余值的现值之和等于（i）标的资产的公允价值与（ii）出租人的初始直接费用之和的利率。

[IFRS 16 第26段]。
[FAQ 15.58.1 – 如果承租人采用 IFRS 16 第15段的实务权宜之计而不单独核算非租赁组成部分，应使用哪些租赁付款额来计算租赁内含利率？](34.md#s113-FAQ_15.58.1)

<a id="s109-Para_15.59"></a>**15.59** 如果租赁内含利率无法容易确定，承租人应采用其增量借款利率（IBR）。

[IFRS 16 第26段]。

[FAQ 15.59.1 – 如果租赁内含利率为负，承租人应使用哪个折现率？](34.md#s113-FAQ_15.59.1)

<a id="s109-Para_15.60"></a>**15.60** 增量借款利率是指承租人在类似经济环境下为获得与使用权资产价值接近的资产，在类似期间以类似抵押条件借入资金须支付的利率。

[IFRS 16 附录A]。

[FAQ 15.60.1 – 承租人在确定增量借款利率时应考虑哪些因素？](34.md#s113-FAQ_15.60.1)  
[FAQ 15.60.2 – 承租人在确定增量借款利率时是否必须反映租赁付款额的支付模式？](34.md#s113-FAQ_15.60.2)

<a id="s109-Para_15.61"></a>**15.61** 租赁付款额由以下各项组成：

- 固定付款额（包括实质固定付款额），扣除任何应收租赁激励；

- 取决于指数或比率的可变租赁付款额；

- 根据承租人提供的余值担保预计应支付的款项；

- 购买选择权的行权价格（前提是承租人合理确定将行使该选择权）；以及

- 行使终止租赁选择权需支付的款项（前提是租赁期反映出承租人将行使终止租赁选择权）。

[IFRS 16 第27段]。

[FAQ 15.61.1 – 承租人应如何对出租人就租赁改良支出给予的报销进行会计处理？](34.md#s113-FAQ_15.61.1)  
[FAQ 15.61.2 – 承租人应如何对保险费、房产税或维护费等成本进行会计处理？](34.md#s113-FAQ_15.61.2)  
[FAQ 15.61.3 – 承租人应如何对出租人看跌期权进行会计处理](34.md#s113-FAQ_15.61.3)

<a id="s109-Para_15.62"></a>**15.62** 为取得标的资产使用权而支付的款项，无论支付时间如何，均符合租赁付款额的条件。

[IFRS 16 附录B 第B44段]。

 

<a id="s109-chap_15_navPoint_idp1714674280"></a>
#### 可变租赁付款额

 

<a id="s109-Para_15.63"></a>**15.63** 根据基础变量的不同，或有付款额分为三种类型：

- 基于指数或比率的付款额；

- 不基于指数或比率的付款额；以及

- 实质固定付款额。

[IFRS 16 第27段]。

[FAQ 15.63.1 – 如何解释“指数或比率”一词？](34.md#s113-FAQ_15.63.1)  
[FAQ 15.63.2 – 承租人是否应将增值税计入租赁负债和使用权资产？](34.md#s113-FAQ_15.63.2)

<a id="s109-Para_15.64"></a>**15.64** 基于指数或比率的可变租赁付款额属于租赁负债的一部分。示例包括与消费者价格指数、基准利率或市场租金率挂钩的付款额。从承租人的角度来看，这些付款额是不可避免的，因为任何不确定性仅涉及负债的计量，而不涉及负债的存在。

[IFRS 16 第28段]。

<a id="s109-Para_15.65"></a>**15.65** 基于指数或比率的可变租赁付款额在初始计量时，采用租赁期开始日的指数或比率确定。主体不对指数或比率的未来变动进行预测；这些变动在租赁付款额发生变化时予以考虑。

[IFRS 16 第27段]。

[EX 15.65.1 – 取决于指数或比率的可变租赁付款额如何进行初始计量？](34.md#s113-EX15.65.1)  
 [FAQ 15.65.2 – 以外币计价的租赁付款额如何进行会计处理？](34.md#s113-FAQ_15.65.2)  
 [FAQ 15.65.3 – 完全取决于指数或比率的租赁付款额如何进行会计处理？](34.md#s113-FAQ_15.65.3)  
 [EX 15.65.4 – 如果存在按市场费率续租的选择权，租赁付款额如何确定？](34.md#s113-EX15.65.4)

<a id="s109-Para_15.66"></a>**15.66** 不基于指数或比率的可变租赁付款额不属于租赁负债的一部分，而是在触发该等付款额的事件或情况发生时计入利润表。例如，基于零售门店收入变动的可变租赁付款额在赚取该收入时予以确认。

[IFRS 16 第38段]。

[EX 15.66.1 – 不与指数或比率挂钩的可变付款额有哪些示例？](34.md#s113-EX15.66.1)  
[FAQ 15.66.2 – 取决于多个变量的可变租赁付款额如何进行会计处理？](34.md#s113-FAQ_15.66.2)  
[FAQ 15.66.3 – 房产税和保险费的可变付款额如何计量？](34.md#s113-FAQ_15.66.3)

<a id="s109-Para_15.67"></a>**15.67** 在形式上具有可变性但在实质上不可避免的租赁付款额被称为“实质固定付款额”，应计入租赁负债。例如，如果一项设计为可变付款额的租赁付款额不存在真正的可变性，则其属于实质固定付款额。示例包括：仅在证明资产能够运行时才须支付的款项，或仅在发生某项实际上不可能不发生的事件时才须支付的款项。

[IFRS 16 第27段]。[IFRS 16 附录B 第B42段]。

[FAQ 15.67.1 – 可变租赁付款额何时符合实质固定付款额的定义？](34.md#s113-FAQ_15.67.1)

<a id="s109-Para_15.68"></a>**15.68** 租赁协议中赋予承租人的选择权也可能导致实质固定付款额。例如，在初始租赁期结束后，承租人可能必须在延长租赁期或购买标的资产之间作出选择。假设两种选择均具有现实可能性，则折现现金流出最低的方案（无论是续租期间的折现租赁付款额，还是折现购买价格）即代表实质固定付款额。承租人不能主张其既不行使续租选择权也不行使购买选择权。如果承租人的选择中仅有一种具有现实可能性，则该选择产生的付款额计入租赁负债。

[IFRS 16 附录B 第B42段]。

#### 复原成本

<a id="s109-Para_15.72"></a>**15.72** 承租人可能有义务按特定状态将标的资产归还给出租人，或复原标的资产所在的场地。承租人应按照 IAS 37《准备、或有负债和或有资产》确认一项预计负债（准备），以反映该义务。

### 后续计量——使用权资产

 

<a id="s109-Para_15.79"></a>**15.79** 使用权资产后续按成本减去累计折旧和任何累计减值损失计量（除非采用[第15.86段](33.md#s109-Para_15.86)或[第15.87段](33.md#s109-Para_15.87)所述的模型）。基于[第15.77段](33.md#s109-Para_15.77)和[第15.78段](33.md#s109-Para_15.78)对租赁负债的任何重新计量，均应对使用权资产作出相应调整。该调整可能为正值，也可能为负值。

[IFRS 16 第30段]。

<a id="s109-Para_15.80"></a>**15.80** 使用权资产的账面价值不得为负。如果其账面价值已调减至零，承租人应将因租赁负债重新计量而产生的任何进一步调减金额计入利润表。

[IFRS 16 第39段]。

<a id="s109-Para_15.81"></a>**15.81** 承租人按照 IAS 16 的规定计算使用权资产的折旧。这将导致按直线法或更能代表主体预期消耗使用权资产模式的其他系统合理的方法计提折旧。更多信息见[第22章第79段](39.md#s143-Para_22.79)。

[IFRS 16 第31段]。

[FAQ 15.81.1 – 非连续使用期间的租赁何时确认费用？](35.md#s114-FAQ_15.81.1)

[FAQ 15.81.2 – 出租人行使提前终止选择权时承租人的会计处理](35.md#s114-FAQ_15.81.2)

<a id="s109-Para_15.82"></a>**15.82** 使用权资产应在租赁期与使用权资产使用寿命两者孰短的期间内计提折旧，除非租赁期届满时发生所有权转移或合理确定将行使购买选择权。如果租赁期届满时发生所有权转移或合理确定将行使购买选择权，承租人应在标的资产的使用寿命内对使用权资产计提折旧。

[IFRS 16 第32段]。

[FAQ 15.82.1 – 承租人应如何对顶手费（key money）进行会计处理？](35.md#s114-FAQ_15.82.1)

<a id="s109-Para_15.83"></a>**15.83** 承租人对使用权资产应用 IAS 36《资产减值》中的减值要求（更多信息见[第24章第6段](41.md#s154-Para_24.6)）。

[IFRS 16 第33段]。

<a id="s109-Para_15.84"></a>**15.84** 按照 IFRIC 1《现有弃置、复原及类似负债的变动》的要求，因修订预期复原成本估计而导致的复原预计负债（准备）的任何后续计量变动，应作为使用权资产的调整进行会计处理。

[IFRIC 1 第2段]。

<a id="s109-Para_15.85"></a>**15.85** 如果复原成本准备因例如预期成本估计修订而发生变化，应根据 IFRIC 1 调整使用权资产。使用权资产账面价值的变动额等于该准备账面价值的变动额。如果调整导致使用权资产增加，承租人应考虑这是否表明使用权资产的新账面价值可能无法全额收回（更多信息见[第22章第27段](39.md#s142-Para_22.27)）。

[IFRIC 1 第5段]。

### 租赁变更

 

<a id="s109-Para_15.88"></a>**15.88** 租赁变更是指原合同条款之外的租赁范围或租赁对价的变更。由原租赁合同中已有条款触发的任何变化（包括因市场租金复核条款或行使续租选择权而引起的变化），均属于重新评估（见[第15.77段](33.md#s109-Para_15.77)）而非租赁变更。

[IFRS 16 附录A]。

<a id="s109-Para_15.88.1"></a>**15.88.1** 2020年5月，国际会计准则理事会（IASB）发布了关于与新冠肺炎疫情相关租金减让的 IFRS 16 修订。作为一项实务权宜之计，承租人可以选择不评估与新冠肺炎疫情相关的租金减让是否构成租赁变更。作出此项选择的承租人应按如同该租金减让不属于租赁变更的方式，对租金减让导致的任何租赁付款额变动进行会计处理。该实务权宜之计仅适用于承租人。2020年5月修订中采用该实务权宜之计的合格条件之一是，租赁付款额的任何减免仅影响2021年6月30日或之前到期的付款额。2021年3月，IASB 对 IFRS 16 作出了进一步修订（“2021年3月修订”），将豁免范围的截止日期延长至涵盖2022年6月30日或之前到期的租赁付款额减免。更多详情见本所深度刊物《IFRS 16 新冠肺炎疫情相关租金减让修订》（In depth publication, 'IFRS 16 COVID-19-related Rent Concessions Amendment'）。

<a id="s109-Para_15."></a>**15.**<a id="s109-Para_88.3"></a>**88.3** 在银行间同业拆借利率（IBOR）改革背景下涉及承租人租赁变更的主体，应考虑对 IFRS 9、IAS 39、IFRS 7、IFRS 4 和 IFRS 16 的利率基准改革第二阶段修订。关于2020年8月发布的第二阶段修订，参见附录3第A3.39段。

<a id="s109-Para_15.89"></a>**15.89** 租赁变更的会计处理取决于合同的变更方式，共有四种不同情形：

- 变更缩小了租赁范围。

- 变更通过增加一项或多项标的资产的使用权扩大了租赁范围，且增加的租赁对价与扩大范围的单独价格按该特定合同情况调整后的金额相当。

- 变更扩大了租赁范围，但不符合上述标准（即范围扩大并非源于增加更多标的资产的使用权，或增加的租赁对价并不相当）。

- 租赁范围保持不变。

<a id="s109-chap_15_navPoint_idp1683662952"></a>
#### 缩小租赁范围

 

<a id="s109-Para_15.91"></a>**15.91** 如果租赁变更终止了一项或多项标的资产的使用权，或缩短了合同租赁期，则租赁范围缩小。例如，已承租一栋大楼三层楼面的承租人，可通过与出租人协商同意在剩余租赁期内减少一层楼面，从而缩小租赁范围。

[IFRS 16 第45段]。

<a id="s109-Para_15.92"></a>**15.92** 对于缩小租赁范围的变更，承租人在租赁变更生效日采用修订后的折现率重新计量租赁负债。修订后的折现率为剩余租赁期间的租赁内含利率；如果剩余租赁期间的租赁内含利率无法容易确定，承租人采用变更生效日的增量借款利率（IBR）。

[IFRS 16 第45段]。

<a id="s109-Para_15.93"></a>**15.93** 对于缩小租赁范围的变更，承租人应调减使用权资产的账面价值，以反映租赁的部分终止或完全终止。承租人将与部分终止或完全终止相关的任何利得或损失计入利润表。

[IFRS 16 第46段]。

[EX 15.93.1 – 承租人对缩小租赁范围的变更的会计处理](35.md#s114-EX15.93.1)

 

<a id="s109-chap_15_navPoint_idp1687756808"></a>
#### 扩大租赁范围

 

<a id="s109-Para_15.94"></a>**15.94** 如果租赁变更通过增加更多标的资产的使用权扩大了租赁范围，且增加的租赁对价相当，则该变更应作为一项单独租赁进行会计处理。所谓“相当”，并不要求增加的租赁对价必须等于扩大范围的单独价格。例如，如果承租人已承租一栋大楼内的若干楼层，变更增加了额外一层的使用权，则额外对价可能不同于单独价格，因为出租人可以避免寻找新承租人的成本（如营销成本）。

[IFRS 16 第44段]。

<a id="s109-Para_15.95"></a>**15.95** 如果租赁变更扩大了租赁范围，但并未增加更多标的资产的使用权，或者增加的租赁对价不相当，则该变更通过重新计量现有租赁进行会计处理。承租人在租赁变更生效日采用修订后的折现率重新计量租赁负债，并对使用权资产作出相应调整。修订后的折现率为剩余租赁期间的租赁内含利率；如果剩余租赁期间的租赁内含利率无法容易确定，承租人采用变更生效日的增量借款利率（IBR）。

[IFRS 16 第45段]。

[EX 15.95.1 – 扩大租赁范围但租赁对价未相应增加时如何进行会计处理？](35.md#s114-EX15.95.1)  
[EX 15.95.2 – 如果未作为单独租赁核算的租赁变更并非立即生效，应如何进行会计处理？](35.md#s114-EX15.95.2)

 

<a id="s109-chap_15_navPoint_idp1687771400"></a>
#### 租赁范围无变化

 

<a id="s109-Para_15.96"></a>**15.96** 在未扩大或缩小租赁范围的情况下变更租赁对价，会导致重新计量租赁负债并对使用权资产作出相应调整。承租人采用剩余租赁期间的租赁内含利率重新计量租赁负债，并对使用权资产作出相应调整。如果剩余租赁期间的租赁内含利率无法容易确定，承租人采用变更生效日的增量借款利率（IBR）。

[IFRS 16 第46段]

[FAQ 15.96.1 – 承租人应如何对出租人自愿豁免租赁付款额进行会计处理？](35.md#s114-FAQ_15.96.1)

<a id="s109-Para_15.97"></a>**15.97** 对于所有未作为单独租赁进行会计处理的租赁变更，承租人应将变更后合同中的对价在单独的租赁组成部分和非租赁组成部分之间进行分摊，并确定变更后租赁的租赁期。

### 列报

[IFRS 16 第47段]。

[IFRS 16 第49段]。

<a id="s109-Para_15.101"></a>**15.101** 租赁负债的利息费用金额必须在附注中单独披露。

[IFRS 16 第53(b)段]。

## 出租人会计处理（第15.105–15.145段）

<a id="s110-chap_15_navPoint_21"></a>
### 租赁分类

 

<a id="s110-Para_15.105"></a>**15.105** 出租人将所有租赁分类为融资租赁或经营租赁。

[IFRS 16 第61段]。

<a id="s110-Para_15.106"></a>**15.106** IFRS 16 下的租赁分类取决于与租赁资产所有权有关的风险和报酬是否归属于出租人。与资产相关的风险包括因产能闲置或技术过时而蒙受损失的可能性，以及因经济状况变化导致回报波动的可能性。报酬可能体现为在资产使用寿命内实现盈利经营的预期，以及资产余值增值带来的利得。

[IFRS 16 附录B 第B53段]。

<a id="s110-Para_15.107"></a>**15.107** 如果一项租赁实质上转移了与标的资产所有权有关的几乎全部风险和报酬，则分类为融资租赁。

[IFRS 16 第62段]。

<a id="s110-Para_15.108"></a>**15.108** 如果一项租赁实质上未转移与标的资产所有权有关的几乎全部风险和报酬，则分类为经营租赁。重大风险仍应由出租人承担。经营租赁的期间通常远短于资产的经济使用寿命。出租人将在租赁期届满后依靠出售资产的所得或继续出租该资产来收回其很大一部分投资。

[IFRS 16 第62段]。

<a id="s110-Para_15.109"></a>**15.109** 租赁分类在租赁开始日作出，且仅在发生租赁变更时才重新评估。估计变更（例如关于标的资产经济寿命或余值的估计变更）或情况变化（例如承租人违约）不会触发重新评估。

[IFRS 16 第66段]。

<a id="s110-Para_15.110"></a>**15.110** 租赁开始日是指租赁协议日与各方就主要租赁条款和条件作出承诺日中的较早者。

[IFRS 16 附录A]。

[FAQ 15.110.1 – 租赁开始日与租赁期开始日有什么区别？](35.md#s114-FAQ_15.110.1)

<a id="s110-Para_15.111"></a>**15.111** 某些租赁协议可能包含针对租赁开始日至租赁期开始日期间发生的变动而调整租赁付款额的条款。示例包括出租人建造标的资产的成本或为租赁融资的成本发生变化。就租赁分类而言，任何此类变动的影响均假定在租赁开始日即已发生。

[IFRS 16 附录B 第B54段]。

<a id="s110-Para_15.112"></a>**15.112** 转租出租人应基于原租赁产生的使用权资产（而非标的资产）对转租赁进行分类评估。

[IFRS 16 附录B 第B58段]。

<a id="s110-Para_15.113"></a>**15.113** 如果原租赁为短期租赁，且转租出租人对该短期租赁采用了确认豁免（见[第15.47段](33.md#s108-Para_15.47)），则转租赁应分类为经营租赁。

[IFRS 16 附录B 第B58段]。

### 分类迹象

 

<a id="s110-Para_15.114"></a>**15.114** 以下情形示例（单独或组合存在）通常会导致租赁被分类为融资租赁：

- 在租赁期届满时，标的资产的所有权转移给承租人。

- 承租人有购买标的资产的选择权，所订立的购买价款预计将远低于行使选择权时标的资产的公允价值，因而在租赁开始日就可以合理确定承租人将行使该选择权。

- 资产的所有权虽然不转移，但租赁期占标的资产经济寿命的大部分。

- 在租赁开始日，租赁付款额的现值几乎相当于标的资产的公允价值。

- 标的资产性质特殊，如果不作较大改造，只有承租人才能使用。

[IFRS 16 第63段]。

<a id="s110-Para_15.115"></a>**15.115** 资产的经济寿命是指预期该资产可由一个或多个使用者经济地使用的期间，或预期一个或多个使用者可从该资产获得的产量或类似计量单位的数量。

<a id="s110-Para_15.116"></a>**15.116** 以下情形（单独或组合存在）也可能导致融资租赁分类：

- 若承租人撤销租赁，撤销租赁对出租人造成的损失由承租人承担。

- 资产余值的公允价值波动所产生的利得或损失归属于承租人（例如，以相当于租赁期结束时大部分销售所得的租金返还形式）。

- 承租人有能力以远低于市场水平的租金继续租赁至下一期间。

[IFRS 16 第64段]。

<a id="s110-Para_15.117"></a>**15.117** 尽管存在[第15.114段](33.md#s110-Para_15.114)和[第15.116段](33.md#s110-Para_15.116)所述情形，租赁的其他特征仍可能导致其被分类为经营租赁（例如，出租人通过重大可变租赁付款额保留了与所有权有关的重大风险和报酬，或者标的资产在租赁期届满时按公允价值转让给承租人）。

[IFRS 16 第65段]。

<a id="s110-chap_15_navPoint_23"></a>
### 融资租赁的会计处理

<a id="s110-chap_15_navPoint_idp1695152488"></a>
#### 确认和初始计量

<a id="s110-Para_15.118"></a>**15.118** 出租人在租赁期开始日于其资产负债表中确认融资租赁下持有的资产，并按等于租赁投资净额的金额将其列报为应收款项。

[IFRS 16 第67段]。

<a id="s110-Para_15.119"></a>**15.119** 出租人的租赁投资净额是指按租赁内含利率折现的租赁投资总额。租赁投资总额等于出租人应收的租赁付款额加上归属于出租人的任何未担保余值。在租赁期内的任何时点，租赁投资净额代表剩余租赁付款额减去归属于未来毛收益（即利息）的租赁付款额部分以及未担保余值。未担保余值在融资租赁中通常较小，代表出租人预期在租赁期届满时从标的资产价值中收回的、未以任何方式由承租人或第三方担保的金额。

[IFRS 16 附录A]。

<a id="s110-Para_15.120"></a>**15.120** 出租人采用租赁内含利率计算租赁投资净额。租赁内含利率是指使租赁付款额与未担保余值的现值之和等于标的资产的公允价值与出租人的初始直接费用之和的利率。如果转租出租人无法确定转租赁的内含利率，可采用原租赁的折现率（根据与转租赁相关的任何初始直接费用进行调整）。

[IFRS 16 第68段]。

<a id="s110-Para_15.121"></a>**15.121** 出租人将以下在租赁期开始日尚未收到的租赁付款额计入租赁投资净额的计量：

- 固定付款额（包括实质固定付款额），扣除任何应付租赁激励；

- 取决于指数或比率的可变租赁付款额，初始计量时采用租赁期开始日的指数或比率确定；

- 由承租人、与承租人有关的一方或有能力履行担保义务的与出租人无关的第三方提供给出租人的余值担保；

- 购买选择权的行权价格（前提是承租人合理确定将行使该选择权）；以及

- 行使终止租赁选择权需支付的款项（前提是租赁期反映出承租人将行使终止租赁选择权）。

[IFRS 16 第70段]。

<a id="s110-Para_15.122"></a>**15.122** 未担保余值是指“……标的资产余值中，出租人能否实现未得到保证，或仅由与出租人有关的一方予以担保的部分”。未担保余值可能对出租人租赁交易的盈利能力产生重大影响。

[IFRS 16 附录A]。

[FAQ 15.122.1 – 估计的未担保余值取决于什么？](35.md#s114-FAQ_15.122.1)

<a id="s110-Para_15.123"></a>**15.123** 出租人在谈判和安排租赁时经常发生初始直接费用（关于初始直接费用定义的更多指引，见[第15.74段](33.md#s109-Para_15.74)）。IFRS 16 中的定义与 IFRS 15 中取得合同的增量成本的定义一致（更多信息见[第11章第274段](19.md#s71-Para_11.274)）。

[IFRS 16 附录A]。

<a id="s110-Para_15.124"></a>**15.124** 初始直接费用（生产商或经销商出租人发生的除外——见[第15.143段](33.md#s110-Para_15.143)）通过租赁内含利率的定义计入租赁投资净额的初始计量。该定义确保初始直接费用自动计入应收融资租赁款，无需单独加计。在租赁期内确认的收入金额将因初始直接费用的影响而减少。

[IFRS 16 第69段]。

#### 后续计量

 

<a id="s110-Para_15.125"></a>**15.125** 租金在租赁期内分摊为租赁投资净额的减少和融资收益。融资收益的确认基于反映出租人租赁投资净额固定周期性回报率的模式。

[IFRS 16 第75段]。

<a id="s110-Para_15.127"></a>**15.127** 出租人定期复核估计的未担保余值。如果估计的未担保余值减少，出租人应修订租赁期内的收益分摊，并立即确认与已计提金额相关的任何减少额。

#### 融资租赁的变更

<a id="s110-Para_15.128"></a>**15.128** 租赁变更的定义对承租人和出租人相同。关于租赁变更的定义，见[第15.88段](33.md#s109-Para_15.88)。

[IFRS 16 附录A]。

<a id="s110-Para_15.129"></a>**15.129** 如果同时满足下列条件，出租人应将融资租赁的变更作为一项单独租赁进行会计处理：

- 该变更通过增加一项或多项标的资产的使用权而扩大了租赁范围；以及

- 增加的租赁对价与扩大范围的单独价格按该特定合同情况调整后的金额相当。

关于作为单独租赁进行会计处理的变更的更多指引，见[第15.89段](33.md#s109-Para_15.89)。

[IFRS 16 第79段]。

<a id="s110-Para_15.130"></a>**15.130** 对于未形成单独租赁的变更，需作进一步分析。出租人应评估如果该变更在租赁开始日即生效，该租赁会被分类为经营租赁还是融资租赁：

- 如果该租赁原本会被分类为经营租赁，出租人应将该变更作为一项新（经营）租赁进行会计处理，并按租赁变更前夕原租赁的租赁投资净额计量应确认的标的资产账面价值。

- 如果该租赁原本会被分类为融资租赁，出租人应按照 IFRS 9 对该租赁变更进行会计处理（更多信息见[第44章第22段](68.md#s285-Para_44.22)）。

[IFRS 16 第80段]。

<a id="s110-chap_15_navPoint_25"></a>
### 生产商或经销商作为出租人

 

<a id="s110-Para_15.137"></a>**15.137** 生产商或经销商出租人有别于其他出租人。生产商或经销商出租人是指生产租赁资产或作为其经销活动一部分取得租赁资产的出租人。与普通出租人相比，其主要区别在于出租人取得租赁资产的成本：生产商或经销商按制造成本或批发价取得资产，其成本通常低于向其他客户销售的正常售价。

<a id="s110-Para_15.138"></a>**15.138** 准则针对生产商或经销商出租人在租赁期开始日是否确认损益以及确认多少损益提供了具体指引。

[IFRS 16 第71段]。

<a id="s110-Para_15.139"></a>**15.139** 订立经营租赁的生产商或经销商出租人不确认销售利润，因为与资产所有权相关的风险和报酬尚未转移给客户，该租赁不等同于销售。生产商或经销商应采用与其他经营租赁出租人相同的方式对该租赁进行会计处理。

[IFRS 16 第86段]。

<a id="s110-Para_15.140"></a>**15.140** 与客户订立融资租赁的生产商或经销商出租人按以下方式在损益中确认销售利得或损失：

- 收入为标的资产的公允价值与按市场利率折现的归属于出租人的租赁付款额现值两者中的较低者；

- 销售成本为标的资产的成本或账面价值（如不同）减去未担保余值的现值；以及

- 销售利得或损失为收入与销售成本之间的差额，按照主体适用于 IFRS 15 下直接销售的会计政策予以确认。

[IFRS 16 第71段]。

[EX 15.140.1 – 生产商出租人通过融资租赁销售资产](35.md#s114-EX15.140.1)  
[EX 15.140.2 – 生产商出租人销售资产且承租人预付定金](35.md#s114-EX15.140.2)

<a id="s110-Para_15.141"></a>**15.141** 无论出租人是否已按照 IFRS 15 出售标的资产，生产商或经销商出租人均应在租赁期开始日确认融资租赁的销售利得或损失。

[IFRS 16 第71段]。

<a id="s110-Para_15.142"></a>**15.142** 生产商或经销商出租人可能会报出人为压低的利率以吸引客户。此时，销售利润应限于按市场利率计息时所能产生的金额。

[IFRS 16 第73段]。

<a id="s110-Para_15.143"></a>**15.143** 生产商或经销商出租人应将安排融资租赁相关的初始直接费用在租赁期开始日确认为费用，因为这些费用主要与赚取销售利润相关。

[IFRS 16 第74段]。

 

<a id="s110-chap_15_navPoint_26"></a>
### 出租人披露

 

<a id="s110-Para_15.144"></a>**15.144** 出租人应披露能够使财务报表使用者评估租赁对出租人财务状况、财务业绩和现金流量影响的信息。出租人的披露要求载于 IFRS 16 第89至97段，其中包括针对租赁资产余值权益的风险管理策略。

<a id="s110-Para_15.145"></a>**15.145** 除嵌入衍生工具（见[第15.159段](33.md#s111-Para_15.159)）外，租赁下的权利披露不在 IAS 39 或 IFRS 9 的适用范围内；但是，该等权利属于金融工具，应纳入 IFRS 7 要求的披露中。

<a id="s111-chap_15_navPoint_27"></a>
## 实务应用（第15.146–15.159段）

 

<a id="s111-Para_15.146"></a>**15.146** 出租人在进行租赁分类时，应分别考虑土地和建筑物租赁中的土地部分和建筑物部分。租赁中单独的土地部分和建筑物部分应采用与其他资产租赁相同的方式分类为融资租赁或经营租赁。实质上转移了与资产所有权有关的几乎全部风险和报酬的租赁分类为融资租赁；所有其他租赁分类为经营租赁。

[IFRS 16 附录B 第B55段]。

<a id="s111-Para_15.147"></a>**15.147** 由于土地通常具有无限经济寿命，土地租赁通常分类为经营租赁（假设在租赁期届满时，土地所有权不会转移或预计不会通过行使购买选择权转移给承租人）。然而，极长期的租赁（例如999年租赁）可能构成融资租赁，因为在租赁期内与土地相关的重大风险和报酬已转移给承租人。999年租赁中的承租人在经济上处于与购买土地和建筑物的主体相似的地位，该物业余值的现值将微乎其微。

[IFRS 16 第BCZ243段]。

<a id="s111-Para_15.148"></a>**15.148** 如有需要，出租人应将租赁下的应付租金在两个组成部分之间进行拆分，以便将各组成部分分别分类为经营租赁或融资租赁，并在土地部分与建筑物部分的租赁分类不同时对租赁进行计量。

[IFRS 16 附录B 第B56段]。

[FAQ 15.148.1 – 能否在不详细分拆租金的情况下确定租赁分类？](35.md#s114-FAQ_15.148.1)  
[EX 15.148.2 – 使用定性标准进行租赁分类](35.md#s114-EX15.148.2)

<a id="s111-Para_15.149"></a>**15.149** 主体应按租赁开始日土地部分和建筑物部分租赁权益的相对公允价值比例，在土地和建筑物之间分摊租赁付款额（包括任何前期一次性付款）。权重应反映承租人在土地和建筑物中的租赁权益。

[IFRS 16 附录B 第B56段]。

[FAQ 15.149.1 – 为什么租赁付款额要按租赁权益的相对公允价值比例在土地和建筑物之间分摊？](35.md#s114-FAQ_15.149.1)  
[FAQ 15.149.2 – 承租人租赁权益的公允价值如何计算？](35.md#s114-FAQ_15.149.2)  
[EX 15.149.3 – 租金分摊](35.md#s114-EX15.149.3)

<a id="s111-Para_15.150"></a>**15.150** 通常可以对租赁租金进行合理拆分。然而，出租人可能无法在土地和建筑物之间可靠地分摊租赁付款额。在此情况下，出租人应将整项租赁分类为融资租赁，除非明确两个部分均属于经营租赁。

[IFRS 16 附录B 第B56段]。

<a id="s111-Para_15.151"></a>**15.151** 如果土地部分不重大，出租人在进行租赁分类时可以将土地部分和建筑物部分合并处理。在此情况下，就租赁分类而言，建筑物的经济寿命被视为整项租赁资产的经济寿命。

[IFRS 16 附录B 第B57段]。

 

<a id="s111-chap_15_navPoint_28"></a>
### 售后租回交易

 

<a id="s111-Para_15.152"></a>**15.152** 售后租回交易是指资产所有者将资产出售并从买方租回该资产的交易。卖方兼承租人必须确定该交易是符合确认收入条件的销售，还是属于抵押借款。

![](assets/77.png)

  
 [IFRS 16 第98段]。

<a id="s111-Para_15.153"></a>**15.153** 售后租回交易的会计处理取决于资产转让是否符合 IFRS 15 中的销售条件。潜在的卖方兼承租人应应用 IFRS 15 中确定履约义务何时履行的要求作出此项评估（更多信息见[第11章第188段](19.md#s69-Para_11.188)）。

[IFRS 16 第99段]。

[FAQ 15.153.1 – 售后租回在何种情况下不符合 IFRS 15 中的销售条件？](35.md#s114-FAQ_15.153.1)

<a id="s111-Para_15.154"></a>**15.154** 如果买方兼出租人取得了标的资产的控制权，则售后租回交易符合销售条件。卖方兼承租人应按原资产账面价值中与租回获得的使用权有关的部分，计量售后租回所形成的使用权资产。卖方兼承租人确认的利得（或损失）仅限于与转让至买方兼出租人的权利相关的总利得（或损失）部分。

[IFRS 16 第100段]。

<a id="s111-Para_15.155"></a>**15.155** 销售对价与资产公允价值之间的任何差额，应作为租赁付款额的预付款（如果购买价款低于市场条款）或额外融资（如果购买价款高于市场条款）进行会计处理。如果租赁付款额未按市场费率确定，适用同样的逻辑。

[IFRS 16 第101段]。

[EX 15.155.1 – 售后租回交易的会计处理](35.md#s114-EX15.155.1)  
[FAQ 15.155.2 – 当租赁付款额完全可变时，如何对售后租回交易进行初始会计处理？](35.md#s114-FAQ_15.155.2)

<a id="s111-Para_15.156"></a>**15.156** 买方兼出租人应按照适用的准则（例如，如果标的资产是不动产、厂场或设备，则适用 IAS 16）对资产购买进行会计处理，并按照 IFRS 16 对租回进行会计处理。

[IFRS 16 第100段]。

<a id="s111-Para_15.157"></a>**15.157** 如果资产转让不符合 IFRS 15 中的销售条件，卖方兼承租人不终止确认所转让的资产，而是将收到的现金确认为一项金融负债。买方兼出租人不确认所转让的资产，而是将支付的现金确认为一项金融资产（应收款项）。

[IFRS 16 第103段]。

<a id="s111-Para_15.158"></a>**15.158** 如果承租人在标的资产转让给出租人之前取得了该资产的控制权，承租人应将该交易作为售后租回交易进行会计处理。例如，生产商、出租人和承租人协商达成一项交易，由出租人向生产商购买资产并转租给承租人，而承租人在法定所有权转移给出租人之前即取得了该资产的控制权，则可能出现此种情况。

[IFRS 16 附录B 第B46段]。

## 过渡和生效日期（第15.160–15.172段）

 

<a id="s112-Para_15.160"></a>**15.160** IFRS 16 自2019年1月1日或之后开始的年度报告期间生效。允许提前采用 IFRS 16，但仅限于与 IFRS 15 同时采用。主体不得在采用 IFRS 15 之前采用 IFRS 16。

[IFRS 16 附录C 第C1段]。

<a id="s112-Para_15.161"></a>**15.161** 首次执行日是指主体首次采用 IFRS 16 的年度报告期间的期初。

[IFRS 16 附录C 第C2段]。

 

<a id="s112-chap_15_navPoint_31"></a>
### 定义

<a id="s112-Para_15.162"></a>**15.162** 主体在过渡时无需重新评估现有合同是否包含租赁。主体可以选择仅对在首次执行日或之后订立（或变更）的合同应用租赁定义指引。对于所有其他合同，主体可保留依据 IAS 17/IFRIC 4 作出的评估（即沿用原有评估）。

[IFRS 16 附录C 第C3段]。

<a id="s112-Para_15.163"></a>**15.163** 如果主体选择此项权宜之计，则必须将其应用于所有合同。

### 承租人

 

<a id="s112-Para_15.164"></a>**15.164** 承租人可以在按照 IAS 8《会计政策、会计估计变更和差错》完全追溯应用与“简化方法”之间作出选择。所选方法必须一致地应用于所有租赁。

[IFRS 16 附录C 第C5段]。[IFRS 16 附录C 第C6段]。

<a id="s112-Para_15.165"></a>**15.165** 在“简化方法”下，不重述比较信息。相反，首次执行本准则的累积影响在首次执行日确认为对留存收益（或其他适当权益组成部分）期初余额的调整。

### 出租人

 

<a id="s112-Para_15.168"></a>**15.168** 除在首次执行日重新评估现有经营转租赁外，出租人在过渡时无需作出任何调整。

[IFRS 16 附录C 第C14段]。

<a id="s112-Para_15.169"></a>**15.169** 出租人应基于原租赁和转租赁的剩余合同条款和条件重新评估经营转租赁。如果经营转租赁现被分类为融资租赁，出租人应将该转租赁作为在首次执行日订立的一项新融资租赁进行会计处理。

[IFRS 16 附录C 第C15段]。

<a id="s112-chap_15_navPoint_34"></a>
### 售后租回交易

 

<a id="s112-Para_15.170"></a>**15.170** 对于在首次执行日之前订立的售后租回交易，主体不重新评估其销售是否符合 IFRS 15 的条件。

[IFRS 16 附录C 第C16段]。

<a id="s112-Para_15.171"></a>**15.171** 对于融资租回，卖方兼承租人继续在租赁期内摊销任何销售利得。

[IFRS 16 附录C 第C17段]。

<a id="s112-Para_15.172"></a>**15.172** 对于经营租回，卖方兼承租人应将因非市场条款而产生的任何递延利得或损失作为对租回使用权资产的调整进行会计处理。

[IFRS 16 附录C 第C18段]。
