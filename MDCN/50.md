## 引言与范围（第29.1–29.44段）

 

<a id="s207-Para_29.1"></a>**29.1** 本章阐述国际财务报告准则对企业合并的要求，具体如下：

- 业务的定义。

- 取得的可辨认资产、承担的负债以及被购买方中任何非控制性权益的确认和计量。

- 商誉或廉价购买利得的确认和计量。

- 排除在企业合并之外的项目。

- 后续计量与会计处理。

- 披露。

这些要求受限于下文所述的范围豁免。

 

<a id="s207-chap_29_navPoint_2"></a>
### 范围

 

<a id="s207-Para_29.2"></a>**29.2** 企业合并被定义为“购买方取得一项或多项业务控制权的交易或其他事项”。

[IFRS 3 附录A]。

<a id="s207-Para_29.3"></a>**29.3** 被称为“真正合并”或“平等合并”的交易也属于企业合并。

[IFRS 3 附录A]。

<a id="s207-Para_29.4"></a>**29.4** 根据 IFRS 3，所有企业合并均采用购买法进行会计处理，包括被称为“真正合并”的交易。

[IFRS 3 第4段]。

<a id="s207-Para_29.5"></a>**29.5** 本准则不适用于：

- 收购不符合业务定义的资产或资产组（[参见 FAQ 29.5.1](51.md#s215-FAQ_29.5.1)）。

- 合营安排本身财务报表中对合营安排设立的会计处理。

- 同一控制下主体或业务的合并。

- 投资性主体收购被要求以公允价值计量且其变动计入当期损益的子公司投资（参见[第27章第3段](48.md#s180-Para_27.3)）。

### 业务的定义（第29.6–29.19段）

 

<a id="s207-Para_29.6"></a>**29.6** IFRS 3 将业务定义为“能够出于向客户提供商品或服务、产生投资收益（如股利或利息）或从日常活动中产生其他收益的目的而开展和管理的一组综合活动和资产”。

[IFRS 3 附录A]。

[FAQ 29.6.1 – 用于评估一组资产应作为业务还是资产组进行会计处理的业务定义“框架”是什么？](51.md#s215-FAQ_29.6.1)

<a id="s207-Para_29.7"></a>**29.7** 业务的三个组成要素是：投入、加工处理过程和产出。

[IFRS 3 附录B第B7段]。

<a id="s207-Para_29.8"></a>**29.8** 投入是指当对其应用一项或多项加工处理过程时，能够创造产出或有能力促成产出的经济资源。示例包括：

- 非流动资产（包括无形资产或使用非流动资产的权利）。

- 知识产权。

- 获取必要材料或权利的能力。

- 员工。

[IFRS 3 附录B第B7(a)段]。

<a id="s207-Para_29.9"></a>**29.9** 加工处理过程是指当应用于一项或多项投入时，能够创造产出或有能力促成产出的任何体系、标准、协议、惯例或规则。示例包括：

- 战略管理流程。

- 运营流程。

- 资源管理流程。

加工处理过程通常以书面形式记录。拥有遵循惯例的技能和经验的有组织劳动力的智力能力，也可能提供在应用于投入时能够创造产出的加工处理过程。

[IFRS 3 附录B第B7(b)段]。

<a id="s207-Para_29.10"></a>**29.10** 不用于创造产出的投入和加工处理过程，在确定所收购资产组是否构成业务时通常不被视为重大。例如，所收购资产组是否包含或排除某些行政管理或支持流程（如会计、薪酬和其他行政系统），通常不会影响对业务是否存在的判断。

[IFRS 3 附录B第B7(b)段]。

<a id="s207-Para_29.11"></a>**29.11** 产出是指投入以及应用于这些投入的加工处理过程所产生的结果，这些结果向客户提供商品或服务、产生投资收益（如利息或股利）或从日常活动中产生其他收益。

[IFRS 3 附录B第B7(c)段]。

<a id="s207-Para_29.12"></a>**29.12** 业务由投入以及应用于该投入、且有能力促成产出的加工处理过程组成。

[IFRS 3 附录B第B7段]。

<a id="s207-Para_29.13"></a>**29.13** 尽管业务通常具有产出，但一组综合活动和资产符合业务条件并不要求必须存在产出。出售方使用的所有投入及相关加工处理过程也无需全部转移才被视为业务。然而，一组综合活动和资产必须包含一项投入和一项实质性加工处理过程，且二者共同对创造产出的能力作出重大贡献。

[IFRS 3 附录B第B8段]。

<a id="s207-Para_29.14"></a>**29.14** 购买方还应考虑市场参与者是否有能力将该组活动和资产作为业务开展经营。出售方此前是否实际将其作为业务运营并不相关，购买方是否打算将其作为业务运营也不相关。

[IFRS 3 附录B第B11段]。

<a id="s207-Para_29.15"></a>**29.15** 几乎所有业务都既有资产也有负债。然而，业务的存在并不要求必须存在负债。反之，转移的一组活动和资产（即使包含负债）也可能不构成业务。

[IFRS 3 附录B第B9段]。

<a id="s207-Para_29.16"></a>**29.16** 投入、加工处理过程和产出会因行业、结构以及业务所处阶段的不同而有所差异。

[IFRS 3 附录B第B9段]。

### 识别企业合并（第29.20–29.26段）

 

<a id="s207-Para_29.20"></a>**29.20** 出于法律、税务或其他商业原因，企业合并可以采用多种方式构建。无论交易形式如何，IFRS 3 均适用于企业合并。可能的结构包括：

- 购买方取得一项或多项业务的权益，使其成为购买方的子公司。

- 一项或多项非公司制业务被购买方收购（未成为其子公司），或在法律上并入购买方。

- 所有参与合并的主体（或其所有者）将其权益份额或净资产转移至一个新设主体。

- 参与合并的某一主体的一组原所有者取得合并后主体的控制权。

 

[IFRS 3 附录B第B6段]。

 

<a id="s207-Para_29.21"></a>**29.21** 实施企业合并最常见的方法是购买具有控制权的股份。该购买可以通过支付现金、发行权益份额、承担负债（或上述方式的组合）实现，也可以不转移任何对价。母公司也可以通过其他方式收购子公司。以现金以外的资产（非货币性资产）进行交换，也可能导致收购一项业务。

[IFRS 3 附录B第B5段]。

[EX 29.21.1 – 被投资方回购股份](51.md#s215-EX29.21.1)

[EX 29.21.2 – 其他股东权利的变更](51.md#s215-EX29.21.2)

[EX 29.21.3 – 合同或其他安排](51.md#s215-EX29.21.3)

[EX 29.21.4 – 导致业务收购的资产交换](51.md#s215-EX29.21.4)

 

<a id="s207-Para_29.22"></a>**29.22** 当母公司出售一家子公司以换取另一家企业的股份时，也可能产生对子公司的收购，从而使该另一家企业成为出售方的子公司。此类交易在收购的同时发生了处置，相关会计处理见[第30章第92段](53.md#s220-Para_30.92)。

#### 购买法

<a id="s207-Para_29.26"></a>**29.26** 购买法的总体原则可概括为以下步骤：

- 识别购买方（参见[第29.27段](50.md#s207-Para_29.27)及以后段落）。

- 确定购买日（参见[第29.42段](50.md#s207-Para_29.42)及以后段落）。

- 确认和计量为被购买方转移的对价，包括收购时任何先前持有的权益以及非控制性权益（参见[第29.45段](50.md#s208-Para_29.45)及以后段落）。

- 确认和计量取得的可辨认资产、承担的负债以及非控制性权益（参见[第29.88段](50.md#s209-Para_29.88)及以后段落）。

- 确认和计量商誉或廉价购买利得（参见[第29.168段](50.md#s210-Para_29.168)及以后段落）。

[IFRS 3 第5段]。

<a id="s207-chap_29_navPoint_5"></a>
### 识别购买方（第29.27–29.44段）

 

<a id="s207-Para_29.27"></a>**29.27** 所有企业合并均须识别购买方。一项企业合并中只能有一个购买方。购买方是取得被购买方（即其他参与合并的一项或多项业务）控制权的参与合并主体。

[IFRS 3 第6段]。

<a id="s207-Para_29.28"></a>**29.28** IFRS 10 中的指引用于确定企业合并中哪一方是购买方：

“当投资方因涉入被投资方而享有可变回报的风险敞口或权利，并且有能力运用对被投资方的权力影响其回报金额时，投资方控制被投资方”。

IFRS 10 下对主体的控制权见[第26章第5段](45.md#s169-Para_26.5)。

[IFRS 10 第7段]。

<a id="s207-Para_29.29"></a>**29.29** 当哪一方为购买方不明确时，IFRS 3 提供了用于识别购买方的额外指引和指标。这些指标没有先后层级之分。某些指标在特定情况下可能更具相关性，但一般而言，应对每项企业合并综合运用所有相关指标以确定购买方。

[IFRS 3 附录B第B13段]。

<a id="s207-Para_29.30"></a>**29.30** 如果企业合并主要通过转移现金或其他资产，或者承担负债来实现，则转移现金或其他资产或承担负债的主体通常是购买方。当一个主体的权益被另一主体购买时，其原所有者退出参与。支付对价的主体很可能控制被购买主体。

[IFRS 3 附录B第B14段]。

<a id="s207-Para_29.31"></a>**29.31** 如果企业合并主要通过交换权益份额来实现，则发行权益工具的主体通常是购买方。

[IFRS 3 附录B第B15段]。

<a id="s207-Para_29.32"></a>**29.32** 在交换权益份额的情况下，识别购买方还应考虑以下其他指标：

- 合并后的相对表决权——购买方通常是其所有者在合并后主体中持有大多数表决权的主体。主体应考察所有事实和情况，包括不寻常或特殊的表决权安排以及任何期权、认股权证或可转换工具（关于评估控制权时潜在表决权的指引，另见[第26章第75段](45.md#s170-Para_26.75)）。

- 在没有其他所有者（或有组织的所有者群体）持有重大表决权份额的情况下，合并后主体中存在较大的少数表决权份额——购买方通常是在合并后主体中持有最大少数表决权份额的所有者。例如，新合并主体的所有权包括一名持有40%所有权的单一投资方，而其余60%的所有权由广泛分散的投资方持有。在合并后主体中拥有40%所有权的单一投资方被视为持有较大的少数表决权份额。

- 治理机构的组成——购买方通常是其所有者能够选举、任命或罢免合并后主体治理机构大多数成员的一方。这也是 IFRS 10 下控制权的指标。参见[第26章第51段](45.md#s170-Para_26.51)。

- 高级管理层的组成——购买方通常是其原管理层主导合并后主体的参与合并主体。

- 权益份额的交换条款——购买方通常是为另一参与合并主体支付超过其合并前公允价值的一方。

[IFRS 3 附录B第B15段]。

[FAQ 29.32.1 – 在捆绑安排中应如何识别购买方？](51.md#s215-FAQ_29.32.1)

<a id="s207-Para_29.33"></a>**29.33** 在不寻常的情况下，发行股份的主体可能并非购买方。在反向购买中，发行股份的主体（法律上的购买方）在会计上为被购买方，而其权益证券被收购的主体取得控制权（即会计上的购买方）。反向购买自[第29.37段](50.md#s207-Para_29.37)起进行讨论。

[IFRS 3 附录B第B19段]。

<a id="s207-Para_29.34"></a>**29.34** 按公允价值、资产、收入或利润衡量，购买方通常是参与合并主体中规模最大的一方。规模最大的主体很可能在合并后主体中获得最大比例的表决权，或能够主导治理机构，或以其他方式控制合并后主体。

[IFRS 3 附录B第B16段]。

<a id="s207-Para_29.35"></a>**29.35** 如果合并涉及两个以上主体，确定购买方时应考虑哪一方发起了合并以及各参与合并主体的相对规模。

[IFRS 3 附录B第B17段]。

[FAQ 29.35.1 – 识别购买方时还可以使用哪些其他考虑因素？](51.md#s215-FAQ_29.35.1)

 

<a id="s207-chap_29_navPoint_idm505134488"></a>
#### 未转移对价实现的企业合并

 

<a id="s207-Para_29.36"></a>**29.36** 购买方可能在未转移任何对价的情况下取得一项业务的控制权。

此类情况可能发生于：

- 被购买方回购了足够数量的自身股份，使现有投资方（购买方）得以取得控制权。

- 原本阻止购买方控制被购买方的其他（少数）股东权利失效。

- 购买方与被购买方通过合同合并业务，但未转移对价。在购买日或之前均未持有被购买方的权益份额。这可能通过捆绑交易或组建双重上市主体实现。

购买法适用于此类企业合并，并应按照[第29.28段](50.md#s207-Para_29.28)中的指引识别购买方。

[IFRS 3 第43段]。

#### 确定购买日

 

<a id="s207-Para_29.42"></a>**29.42** 购买日是指“购买方取得被购买方控制权的日期”。通常，这是购买方转移对价并取得被购买方资产和负债的日期。

[IFRS 3 第8段]。

<a id="s207-Para_29.43"></a>**29.43** 购买方取得控制权的日期可能早于或晚于交易在法律上交割或完成的日期。在评估购买方何时取得控制权时，应考虑与企业合并相关的所有事实和情况。控制权转移的日期是一个事实问题，不能追溯提前或人为改变。

[IFRS 3 第9段]。

## 转移的对价的确认和计量（第29.45–29.87段）

 

<a id="s208-Para_29.45"></a>**29.45** 转移的对价通常以公允价值计量。转移的对价包括购买方转移的资产、购买方对被购买方原所有者承担的负债，以及购买方为被购买方原所有者发行的权益份额。转移的对价的示例包括现金、其他资产、或有对价、转移给出售方的购买方子公司或业务、普通股或优先股权益工具、期权、认股权证以及互助主体的成员权益。

[IFRS 3 第37段]。

[EX 29.45.1 – 合并后股利作为购买对价的一部分处理](51.md#s215-EX29.45.1)

<a id="s208-Para_29.46"></a>**29.46** 购买方在企业合并过程中会支付各种款项。购买方必须确定哪些项目属于企业合并的组成部分，哪些不属于。不属于企业合并组成部分的项目应单独进行会计处理。此类项目的示例包括：

- 单独交易；

- 赔偿安排；以及

- 薪酬安排。

这些内容自[第29.183段](50.md#s211-Para_29.183)起阐述。

[IFRS 3 第51段]。

### 股份支付奖励

 

<a id="s208-Para_29.49"></a>**29.49** 购买方可能以其股份支付奖励（替代奖励）交换被购买方职工持有的奖励。股份支付奖励的全部或部分价值可能计入转移的对价的计量。

[IFRS 3 附录B第B56段]。

<a id="s208-Para_29.50"></a>**29.50** 股份支付奖励的替代应按照 IFRS 2 作为对被购买方现有股份支付奖励的修改进行会计处理。

[IFRS 3 附录B第B56段]。

<a id="s208-Para_29.51"></a>**29.51** 购买方应评估替代奖励的条款和规定，以识别可能计入对价的金额。

[IFRS 3 附录B第B56段]。

<a id="s208-Para_29.52"></a>**29.52** 对替代奖励条款和规定的评估既适用于分类为负债的股份支付交易，也适用于按照 IFRS 2 分类为以权益结算的交易。

[IFRS 3 附录B第B61段]。

<a id="s208-Para_29.53"></a>**29.53** 在购买日，被替代的被购买方奖励中与合并前服务相关的价值，是向职工以其作为业务所有者的身份支付的款项。该价值作为对价的一部分进行会计处理。奖励的计量自[第29.69段](50.md#s208-Para_29.69)起阐述。

[IFRS 3 附录B第B57段]。

### 反向购买中转移的对价

 

<a id="s208-Para_29.60"></a>**29.60** 在反向购买中，权益份额通常由会计上的被购买方（法律上的母公司）发行。会计上的购买方转移的对价价值，基于会计上的购买方（法律上的子公司）为使会计上的被购买方（法律上的母公司）的所有者在合并后主体中享有与反向购买所产生的相同比例权益份额，而假定需要向法律上母公司所有者发行的权益份额数量。

### 或有对价

 

<a id="s208-Para_29.62"></a>**29.62** 或有对价“通常是指购买方在特定未来事项发生或条件满足时，作为换取被购买方控制权交易的一部分，向被购买方原所有者转移额外资产或权益份额的义务”。或有对价也可以采取购买方有权从被收购业务出售方收回先前转移的资产或权益份额的形式。

[IFRS 3 附录A]。

<a id="s208-Para_29.63"></a>**29.63** 无论是否很可能发生支付，或有对价均按其购买日公允价值确认。购买方应根据 IAS 32 第11段中权益工具和金融负债的定义，将符合金融工具定义的支付或有对价的义务分类为金融负债或权益。购买方收取或有对价的权利（即或有可收回对价）应分类为资产。

[IFRS 3 第40段]。

### 要求持续雇佣的或有对价安排

<a id="s208-Para_29.64"></a>**29.64** 某些或有对价安排可能与被购买方职工的持续雇佣挂钩。此类安排通常在合并后期间确认为职工薪酬费用。关于这些安排的进一步讨论，[参见第29.48段](50.md#s208-Para_29.48)及以后段落。

[IFRS 3 第52(b)段]。

### 对价的计量

 

<a id="s208-Para_29.65"></a>**29.65** 转移的对价通常在购买日按公允价值计量（股份支付奖励的计量除外——[参见第29.69段](50.md#s208-Para_29.69)）。参见第5章第124段。

[IFRS 3 第37段]。

[IFRS 3 第37段]。

<a id="s208-Para_29.67"></a>**29.67** 如果部分对价的现金结算被递延，该递延部分的公允价值应通过将应付金额折现至交换日的现值来确定，同时考虑结算时可能发生的任何溢价或折价。

[IFRS 3 第37段]。

<a id="s208-Para_29.68"></a>**29.68** 或有对价在购买日按公允价值计量（参见[第5章第126段](11.md#s34-Para_5.126)）。

[IFRS 3 第39段]。

### 股份支付奖励的计量

 

<a id="s208-Para_29.69"></a>**29.69** 无论是否构成对价的一部分，股份支付奖励均应按照 IFRS 2 而非公允价值进行计量。

[IFRS 3 第30段]。

<a id="s208-Para_29.70"></a>**29.70** IFRS 2 的计量方法与公允价值的不同之处在于，非市场可行权条件不计入奖励的价值。相反，这些条件用于调整在计量任何已确认金额时所包含的权益工具数量。

[IFRS 2 第19段]。

<a id="s208-Para_29.71"></a>**29.71** 作为对价进行会计处理的金额，是被购买方奖励的 IFRS 2 计量金额乘以已完成服务期间与原总等待期或新总等待期二者中较长者之比。等待期和可行权条件在 IFRS 2 中定义（参见第13章）。

[IFRS 3 附录B第B58段]。

 

<a id="s208-chap_29_navPoint_15"></a>
### 包含购买方其他资产和负债的对价的计量

 

<a id="s208-Para_29.72"></a>**29.72** 在某些企业合并中，购买方的非货币性资产和负债（包括一项业务或合营企业）可能作为购买对价的一部分转移。这些其他资产或负债的公允价值与账面价值之间的差额，通常在购买日于购买方的财务报表中确认为利得或损失。

[IFRS 3 第38段]。

<a id="s208-Para_29.73"></a>**29.73** 转移的资产或负债在企业合并后可能仍保留在合并后主体内（例如，因为该资产或负债是转移给被购买方而非其原所有者）。购买方仍保留对它们的控制权。购买方应按紧接购买日之前的账面金额计量这些资产和负债。对于在企业合并前后均由其控制的资产或负债，购买方不在损益中确认利得或损失。所转移的资产将影响所确认的非控制性权益和商誉的金额。

[IFRS 3 第38段]。

[EX 29.73.1 – 包含非货币性购买对价的企业合并](51.md#s215-EX29.73.1)

[FAQ 29.73.2 – 公司应如何对以另一主体的股份换取控制性权益的收购进行会计处理？](51.md#s215-FAQ_29.73.2)

 

<a id="s208-chap_29_navPoint_16"></a>
### 发行的权益份额的计量

<a id="s208-Para_29.74"></a>**29.74** 购买方所发行权益份额的公允价值应确定为所收购业务的对价。对于公开交易的股份，公允价值为购买日的市场报价乘以发行的股份数量。非上市股份的公允价值应采用估值技术计量，通常采用市场法或收益法。参见[第5章第125段](11.md#s34-Para_5.125)。

[IFRS 13 第69段]。

<a id="s208-Para_29.75"></a>**29.75** 交换的对价可能仅为权益份额。被购买方权益份额的价值可能比购买方权益份额的价值更能可靠计量。例如，一家私营主体收购一家具有公开报价且市场价格可靠的上市主体时，就可能出现这种情况。在此情况下，购买方应使用被购买方权益份额在购买日的公允价值，而非所转移权益份额在购买日的公允价值。

[IFRS 3 第33段]。

<a id="s208-chap_29_navPoint_17"></a>
### 未转移对价

<a id="s208-Para_29.76"></a>**29.76** 企业合并可能在未转移对价的情况下实施。此时应使用购买方在被购买方中权益的公允价值作为对价的计量金额。

[IFRS 3 第33段]。

<a id="s208-chap_29_navPoint_18"></a>
### 对价的分类

<a id="s208-Para_29.77"></a>**29.77** 金融资产、金融负债和权益工具由 IAS 32 定义。权益工具是指证明拥有主体在扣除所有负债后的资产中剩余权益的合同。金融负债是指：

- 交付现金或其他金融工具，或在潜在不利条件下交换金融资产或金融负债的合同义务；或

- 将来须用或可用主体自身权益工具进行结算的合同，且该合同为：

- 导致主体有义务或可能有义务交付可变数量的自身权益股份的非衍生工具；或

- 以固定金额的现金或其他金融资产换取固定数量的自身权益工具以外的方式进行结算的衍生工具。

[IAS 32 第11段]。

<a id="s208-chap_29_navPoint_idm501909144"></a>
#### 递延对价的分类

 

<a id="s208-Para_29.78"></a>**29.78** 递延现金对价的公允价值由购买方作为金融负债进行会计处理。

[IAS 32 第9段]。

<a id="s208-Para_29.79"></a>**29.79** 购买日金额（公允价值）与应付总额之间的差额属于融资费用。该差额在负债存续期间内，作为利息费用计入购买方收购后的利润表。
[IAS 32 第35段]。

<a id="s208-Para_29.80"></a>**29.80** 递延对价首先应根据 IAS 32 分类为负债或权益。如果递延对价属于权益工具，其公允价值应直接计入股东权益。递延对价应在股本项下作为单独项目披露，例如列示为“待发行股份”。

[IAS 32 第22段]。

<a id="s208-Para_29.81"></a>**29.81** 如果应付递延对价的金额在购买日已固定，而为履行该对价所发行的股份数量随对价发行日股份的市场价格而变动，则该递延对价可能分类为负债。待发行股份应列示为金融负债，而非权益。负债与权益的分类在[第43章](67.md#s274-chap_43)中进一步阐述。

[IAS 32 第21段]。

[IFRS 3 第40段]。

<a id="s208-Para_29.84"></a>**29.84** 或有对价安排可能以主体自身的权益股份结算，但作为负债进行会计处理（例如，以可变数量的股份支付固定金额）。

[IFRS 3 第11段]。

<a id="s209-Para_29.91"></a>**29.91** 除或有负债外（[参见第29.145段](50.md#s209-Para_29.145)），准则并未明确要求资产或负债必须能够可靠计量。满足下列条件之一的资产即为可辨认资产：

- 能够分离（即能够从主体中分离或者划分出来，并能单独或者与相关合同、可辨认资产或负债一起，用于出售、转移、授予许可、租赁或者交换，无论主体是否打算这样做）；或者

- 源自合同性权利或其他法定权利，无论这些权利是否可以从主体或其他权利和义务中转移或者分离。

### 可辨认资产和负债的分类或指定

 

<a id="s209-Para_29.97"></a>**29.97** 购买方应根据购买日的情况，对被购买方的可辨认资产和负债作出分类、指定和评估决定。需考虑的情况包括合同条款、经济状况、购买方的经营和会计政策以及其他任何相关因素。分类可能影响购买日之后的确认和计量。

[IFRS 3 第15段]。

<a id="s209-Para_29.98"></a>**29.98** 购买日重新评估原则存在两项例外，分别适用于 IFRS 16 下被购买方作为出租人的租赁合同以及按照 IFRS 4 核算的保险合同。此类合同应根据原合同条款或任何后续修改进行分类（分别分类为经营租赁或融资租赁，以及保险合同），除非在购买日对其进行了修改，否则不在购买日重新评估。但这不适用于被购买主体先前作出的分类错误。如果被购买主体先前存在分类错误，则应对 IFRS 16 下被购买方作为出租人的租赁和保险合同进行重新评估。同样，如果被购买方此前未采用国际财务报告准则，购买方应在购买日对所有合同进行分类和指定。在采用 IFRS 17 之后，与保险合同分类相关的例外不再适用。

<a id="s209-Para_29.100"></a>**29.100** 计量原则为：“购买方应当按购买日公允价值计量取得的可辨认资产和承担的负债”。

### 计量要求的应用

<a id="s209-chap_29_navPoint_idm502582664"></a>
#### 购买方不打算使用的资产

 

<a id="s209-Para_29.103"></a>**29.103** 公允价值基于市场参与者作出的假设，而非特定主体的概念。在计量资产的公允价值时，购买方的特定意图并不相关。即使购买方打算将某项资产用于所能实现的价值低于公允价值的用途，或者完全不打算使用该资产，这也不会影响其在购买日的公允价值。然而，购买方的意图或对该资产的后续使用可能会影响该资产在购买日之后的使用寿命。

#### 资产估值备抵

 

<a id="s209-Para_29.104"></a>**29.104** 当资产按购买日公允价值计量时，不单独确认估值备抵（例如应收款项减值准备）。资产的公允价值已包含有关未来现金流量的概率和不确定性。购买方不得就在购买日被视为无法收回的合同现金流量单独确认估值备抵，也不得单独确认预期信用损失的损失准备。

#### 合同

 

<a id="s209-Para_29.105"></a>**29.105** 对于条款相对于当前市场条款有利或不利的特定合同，可能需确认无形资产或负债。应将合同条款与购买日的市场价格进行比较，以确定是否应确认无形资产或负债。如果所取得合同的条款相对于市场价格有利，则确认一项无形资产；如果所取得合同的条款相对于市场价格不利，则确认一项负债。[第29.153段](50.md#s209-Para_29.153)和[第29.155段](50.md#s209-Para_29.155)讨论了 IFRS 16 下被购买方作为有利或不利租赁的承租人，或作为有利或不利经营租赁的出租人的情形。

#### 无形资产

 

<a id="s209-Para_29.109"></a>**29.109** 无形资产是指没有实物形态的可辨认非货币性资产。

[IAS 38 第8段]。

<a id="s209-Para_29.110"></a>**29.110** 购买方在购买日确认被购买方的可辨认无形资产。如果资产源自合同性权利或法定权利，或能够从业务中分离，则该资产是可辨认的。企业合并中取得的无形资产的会计处理在[第21章第37段](38.md#s134-Para_21.37)中详细阐述。

[IFRS 3 附录B第B31段]。

<a id="s209-Para_29.111"></a>**29.111** 满足合同—法定标准的无形资产，无论其是否可分离，均属于可辨认资产并应予以确认。

[IFRS 3 附录B第B32段]。

[EX 29.111.1 – 不可分离的无形资产](51.md#s215-EX29.111.1)

<a id="s209-Para_29.112"></a>**29.112** 关于可分离性标准，有三点需要注意：

- 如果一项资产能够从被购买方中分离或划分出来，并能单独或者“与相关合同、可辨认资产或负债一起”用于出售、转移、授予许可、租赁或交换，则该资产是可分离的。一项资产无需能够单独出售即符合可分离性标准。

- 购买方的意图并不相关——只要一项资产能够被出售、转移等，即为可分离的。

- 交换交易提供了可分离性的证据。即使交换交易并不频繁，也不论购买方是否参与其中，交换交易的证据均可支持所取得的无形资产符合可分离性标准的结论。

[IFRS 3 附录B第B33段]。

[EX 29.112.1 – 仅可与另一项资产一同分离的无形资产](51.md#s215-EX29.112.1)

[EX 29.112.2 – 识别媒体和电信行业的无形资产](51.md#s215-EX29.112.2)

[EX 29.112.3 – 购买方的进行中研发项目](51.md#s215-EX29.112.3)

#### 估值与使用寿命

<a id="s209-Para_29.114"></a>**29.114** 公允价值是一个市场参与者概念。因此，它反映的是资产的经济寿命，这可能与合同期限不同。市场参与者可能会预期能够续展资产所包含的合同性或法定权利。公允价值反映市场参与者对资产固有权利续展可能性以及任何此类续展价值的看法。续展本身无需满足可辨认性标准。

[IFRS 3 附录B第B40段]。

<a id="s209-Para_29.115"></a>**29.115** 资产的使用寿命通常不应超过合同性或法定权利的期限。如果合同性或法定权利包含续展期，且有证据支持主体无需付出重大成本即可续展，则使用寿命应包含该续展期。重大的续展成本实质上代表在续展日取得一项新无形资产的成本。原无形资产的账面金额应在续展日之前全部摊销完毕，随后将续展成本资本化为一项新的无形资产。

[IAS 38 第94段]。

<a id="s209-chap_29_navPoint_idm502516232"></a>
#### 重新取得的权利

<a id="s209-Para_29.116"></a>**29.116** 购买方此前可能已授予被购买方使用购买方一项或多项已确认或未确认资产的权利。示例包括根据特许经营协议使用购买方商号的权利，或根据许可协议使用购买方技术的权利。购买方可能在收购被购买方时重新取得该权利。重新取得的权利通常属于可辨认无形资产，购买方应将其与商誉分开确认。

[IFRS 3 附录B第B35段]。

<a id="s209-Para_29.117"></a>**29.117** 对于包含特许权使用费或其他类型付款条款的重新取得的权利，应将其与当前市场交易的定价进行比较，以评估合同条款是否有利或不利。对于所识别的任何有利或不利合同条款，应在购买日单独确认并计量结算利得或损失。与重新取得的权利相关的结算利得或损失，应按照原有关系结算的指引进行计量（参见[第29.189段](50.md#s211-Para_29.189)）。任何结算利得或损失的金额均不应影响与重新取得的权利相关的无形资产公允价值的计量。

[IFRS 3 附录B第B36段]。

<a id="s209-chap_29_navPoint_idm502642824"></a>
#### 确定重新取得的权利的使用寿命

 

<a id="s209-Para_29.118"></a>**29.118** 重新取得的权利在合并后期间摊销的使用寿命应基于剩余合同期限，不考虑任何合同续展。如果在合并后期间将重新取得的权利重新授予第三方，与该重新取得的权利相关的任何剩余未摊销金额应计入确定重新授予利得或损失的计算中。

[IFRS 3 第55段]。

### 所得税

 

<a id="s209-Para_29.121"></a>**29.121** 递延所得税应按照 IAS 12 确认和计量。应对分配给可辨认资产和负债的价值与其计税基础之间产生的所有暂时性差异计提递延所得税。

[IFRS 3 第24段]。

<a id="s209-Para_29.122"></a>**29.122** 购买方应按照 IAS 12，对被购买方在购买日存在的或因企业合并而产生的暂时性差异及结转项目的潜在税务影响进行会计处理。

[IFRS 3 第25段]。

<a id="s209-Para_29.123"></a>**29.123** 对被购买主体的可辨认资产、负债和或有负债所作的公允价值调整可能产生暂时性差异，应对这些差异考虑税务影响并确认为递延所得税。企业合并中所得税的会计处理在[第14章第118段](27.md#s99-Para_14.118)中详细阐述。本章仅包含规则概述。

[IAS 12 第26(c)段]。

 

<a id="s209-chap_29_navPoint_idm500063752"></a>
#### 与结转亏损相关的递延所得税资产

<a id="s209-Para_29.124"></a>**29.124** 被购买主体可能因未能满足递延所得税资产的确认标准，而未就其过去的税务亏损或可抵扣暂时性差异确认递延所得税资产。购买方可能确定，集团内其他主体将有足够的未来应纳税所得额，在税法允许的情况下通过结转这些亏损来实现税收利益；或者，由于收购后的成本节约或其他协同效应，被购买方预计的未来应纳税所得额可能增加。该税收利益满足 IAS 12 第24段关于在购买日单独确认为被购买方一项可辨认资产的标准。归属于未弥补税务亏损的递延所得税资产在企业合并会计处理中确认为一项取得的资产。

[IAS 12 第24段]。

<a id="s209-Para_29.125"></a>**29.125** 购买方可能认为，由于企业合并，其很可能以被购买方的未来应纳税所得额来抵扣自身未弥补的税务亏损；或者，购买方可能认为，由于收购后的成本节约或其他协同利益，其自身的未来应纳税所得额很可能增加，从而能够弥补自身结转的未弥补税务亏损。此类递延所得税资产不在公允价值评估中确认。这些亏损并非被购买方的亏损，因此不符合 IFRS 3 第10段作为被购买方一项可辨认资产单独确认的标准。

[IAS 12 第67段]。

<a id="s209-chap_29_navPoint_idm500055432"></a>
#### 商誉

 

<a id="s209-Para_29.126"></a>**29.126** 商誉的账面金额与其为零的计税基础之间的任何差额都会产生应纳税暂时性差异，通常会导致确认递延所得税负债。但与商誉相关的递延所得税负债不予确认。商誉是作为剩余金额计量的，因此确认递延所得税负债会增加商誉的账面金额。当外购商誉在税务上不可抵扣时，其计税基础为零。在确定应纳税所得额时商誉减值不得作为税前扣除费用、且出售子公司时商誉成本不可抵扣的情况下，即属于此类情形。

[IAS 12 第21段]。

<a id="s209-Para_29.127"></a>**29.127** 在递延所得税负债本身未予确认的情况下，对于该暂时性差异的任何后续减少，均不得确认递延所得税收益。

[IAS 12 第21A段]。

[EX 29.127.1 – 未确认递延所得税负债时暂时性差异减少的影响](51.md#s215-EX29.127.1)

<a id="s209-Para_29.128"></a>**29.128** 当外购商誉的成本在税务上可通过若干年的税务摊销予以抵扣时，会产生应纳税暂时性差异。在企业合并日产生的任何应纳税暂时性差异均不导致确认递延所得税负债。

[IAS 12 第21段]。

<a id="s209-Para_29.129"></a>**29.129** 在企业合并之后产生的应纳税暂时性差异则会导致确认递延所得税负债。

[IAS 12 第21B段]。

[EX 29.129.1 – 企业合并日之后产生的暂时性差异](51.md#s215-EX29.129.1)

<a id="s209-Para_29.130"></a>**29.130** 如果商誉的账面金额小于其计税基础，企业合并可能产生可抵扣暂时性差异。如果很可能获得用来抵扣可抵扣暂时性差异的应纳税所得额，则应作为企业合并会计处理的一部分确认递延所得税资产（从而减少商誉）。

[IAS 12 第32A段]。

<a id="s209-Para_29.131"></a>**29.131** 第14章第118段阐述了企业合并的递延所得税影响，其中包括以下内容的详细指引：

- 公允价值调整。

- 税务可抵扣商誉。

- 收购时确认的额外资产和负债。

- 被购买方因 IAS 12 初始确认豁免而未确认的递延所得税资产和负债。

- 被购买方未确认税务亏损相关的递延所得税资产。

- 不确定的税务处理。

### 职工福利计划

 

<a id="s209-Para_29.134"></a>**29.134** 职工福利计划属于确认原则的例外情况。职工福利计划资产和义务应按照 IAS 19 的指引予以确认。

[IFRS 3 第26段]。

<a id="s209-Para_29.135"></a>**29.135** 职工福利净资产仅在购买方能够以从计划中获得退款或减少未来缴存额的形式予以利用的限度内确认。与最低注资要求相关的任何负债应按照 IAS 19 和 IFRIC 14 予以确认。进一步讨论参见[第12章第60段](23.md#s79-Para_12.60)。

[IAS 19 第64段]。

<a id="s209-Para_29.136"></a>**29.136** 购买方预期对被购买方计划进行的结算，在满足 IAS 19 的相关要求之前不予确认。只有在购买日之前已发生结算事项的情况下，才在计量计划福利义务时确认结算。结算是指主体订立一项交易，消除了设定受益计划下全部或部分福利的所有进一步法定义务或推定义务。仅基于很可能发生就确认结算是不恰当的。

[IAS 19 第111段]。

[IAS 19 第103段]。

<a id="s209-Para_29.138"></a>**29.138** 在购买日很可能发生的过去服务成本或缩减不予确认。

### 监管递延账户余额

 

<a id="s209-Para_29.139"></a>**29.139** 监管递延账户余额是指按照其他准则不会确认为资产或负债的金额。然而，由于费率监管机构在确定可向客户收取的费率时已将其纳入或预期将其纳入，因此根据 IFRS 14，该金额符合确认和递延的条件。

[IFRS 14 附录A]。

<a id="s209-Para_29.140"></a>**29.140** 仅当主体在首次采用国际财务报告准则时采用了 IFRS 14，该准则才适用。

[IFRS 14 第6段]。

<a id="s209-Para_29.141"></a>**29.141** IFRS 14 要求主体继续采用其先前公认会计原则的会计政策，对上述监管递延账户余额进行确认、计量、减值和终止确认。

[IFRS 14 第11段]。

<a id="s209-Para_29.142"></a>**29.142** 当主体收购包含监管递延账户余额的业务时，这些余额属于确认和计量原则的例外情况。购买方在其合并财务报表中，应采用其根据 IFRS 14 制定的会计政策，在购买日对被购买方的监管递延账户余额进行确认和计量。无论被购买方在其自身财务报表中是否确认了这些余额，被购买方的监管递延账户余额均应按照购买方的政策在购买方的合并财务报表中予以确认。

[IFRS 14 附录B第B18段]。

### 赔偿资产

 

<a id="s209-Para_29.146"></a>**29.146** 购买方可能从出售方获得赔偿。该赔偿可能与被购买主体的某项或有事项或不确定性相关，出售方同意在或有事项发生或不确定性解决时，向购买方支付全部或部分负债金额或资产价值减少的金额。例如：

- 出售方同意向购买方支付针对被购买方的未决诉讼的和解费用。

- 被购买主体存在不确定的税务处理，出售方同意在因调查产生任何费用时在上限范围内向被购买方作出补偿。

这些安排使购买方能够防范企业合并后可能产生的部分不确定现金流量风险。

[IFRS 3 第27段]。

<a id="s209-Para_29.151"></a>**29.151** 对于按照 IFRS 16 识别的、被购买方作为承租人的大多数租赁，购买方均应确认使用权资产和租赁负债。对于通常豁免适用 IFRS 16 的租赁，购买方无需确认使用权资产和租赁负债，例如：

<a id="s209-Para_29.152"></a>**29.152** 购买方应适用 IFRS 16 的初始计量规定，将取得的租赁负债视同在购买日新订立的租赁予以确认。购买方应遵循[第15章第57段](33.md#s109-Para_15.57)中讨论的计量要求，以及确定租赁期（包括对续租选择权的考虑）、租赁付款额和折现率的要求。

### 非控制性权益

<a id="s209-Para_29.158"></a>**29.158** 非控制性权益被定义为“子公司中不直接或间接归属于母公司的权益”。非控制性权益仅在购买方收购被购买方少于 100% 权益（即部分收购）时产生。

[IFRS 3 附录A]。

<a id="s209-chap_29_navPoint_idm505412264"></a>
#### 非控制性权益的计量

 

<a id="s209-Para_29.159"></a>**29.159** 被购买方中的非控制性权益，如果属于现时所有权份额且赋予其持有者在主体清算时按比例分享主体净资产的权利，则在企业合并中可以采用以下两种方式之一计量。该选择可按逐项企业合并交易作出。此类非控制性权益可按以下任一基础计量：

- 公允价值（“公允价值法”）；或

- 现时所有权份额在被购买方净可辨认资产中所占的比例份额（“比例份额法”）。

非控制性权益（NCI）的所有其他组成部分，包括不属于现时所有权份额的组成部分（例如认股权证），均应按公允价值计量，除非国际财务报告准则要求采用其他计量基础。例如，以权益结算的股份支付属于未来所有权份额，要求按照 IFRS 2 计量。关于非控制性权益的计量及其如何影响商誉（含示例）的进一步讨论，见[第29.173段](50.md#s210-Para_29.173)及以后段落。

[IFRS 3 第19段]。

##### 确定控制权对非控制性权益的影响

 

<a id="s209-Para_29.161"></a>**29.161** 为控制性权益支付的价格通常代表控制权基础上的转移的对价的公允价值。购买方权益与非控制性权益（NCI）的每股公允价值可能存在差异。主要差异可能是每股公允价值中的溢价或折价。市场参与者在为非控制性权益定价时，可能会在购买方所持被购买方权益的每股公允价值中考虑控制权溢价，或者相反，在非控制性权益的每股公允价值中考虑缺乏控制权折价。缺乏控制权折价也称为非控制性权益折价。

#### 与非控制性权益相关的看涨期权和看跌期权

### 分步实现的企业合并

 

<a id="s209-Para_29.166"></a>**29.166** 企业合并自购买日起进行会计处理。购买日是指购买方取得被购买方控制权的日期（进一步参见[第29.42段](50.md#s207-Para_29.42)）。许多最终成为子公司的投资最初只是对相关主体的较小权益。在它们实际成为子公司并采用购买法进行会计处理之前，其在集团财务报表中可能采用多种方式处理。例如，它们可能是对主体的少量持股，按照 IFRS 9（IAS 39）进行会计处理；或者，它们可能是较大的持股，赋予重大影响或共同控制，从而分别按照 IAS 28（参见[第31章第9段](56.md#s225-Para_31.9)）和 IFRS 11（参见[第32章第51段](57.md#s232-Para_32.51)）进行会计处理。如果购买方取得了先前按照上述准则之一进行会计处理的权益的控制权，则其实施了分步实现的企业合并（也称为“分步收购”）。分步实现的企业合并在购买日采用购买法进行会计处理。商誉仅在取得控制权之日计算一次。

[IFRS 3 第41段]。

<a id="s209-Para_29.167"></a>**29.167** IFRS 3 下企业合并的组成部分包括先前持有的权益（参见[第29.26段](50.md#s207-Para_29.26)）。先前持有的权益在购买日重新计量至公允价值，并将由此产生的利得或损失视情况计入当期损益或其他综合收益。从会计角度看，先前持有的权益被视同连同转移的对价一并处置，以换取对子公司的控制性权益。随后，先前持有权益的公允价值连同转移的对价和非控制性权益（NCI）一起，减去可辨认净资产的公允价值，构成用于计算商誉的组成部分之一。

[IFRS 3 第42段]。

[FAQ 29.167.1 – 购买方应如何对分步实现的企业合并进行会计处理？](52.md#s216-FAQ_29.167.1)

[EX 29.167.2 – 在分步实现的企业合并中取得控制权](52.md#s216-EX29.167.2)

## 商誉或廉价购买利得的确认和计量（第29.168–29.182段）

<a id="s210-chap_29_navPoint_43"></a>
### 商誉

 

<a id="s210-Para_29.168"></a>**29.168** 商誉被定义为“代表企业合并中取得的、不能单独辨认并单独确认的其他资产所产生的未来经济利益的资产”。当收购一家新子公司时，购买方集团的合并财务报表中可能产生商誉。当购买方主体购买另一主体的业务和资产时，购买方主体的单独财务报表中也可能产生商誉。

[IFRS 3 附录A]。

<a id="s210-Para_29.169"></a>**29.169** 商誉在购买日按以下第1项金额超过第2项金额的差额计量：

- 以下各项之和：

- 转移的对价的公允价值（参见[第29.45段](50.md#s208-Para_29.45)及以后段落）。

- 确认的任何非控制性权益的金额（参见[第29.159段](50.md#s209-Para_29.159)及以后段落）。

- 在分步实现的企业合并中，购买方先前持有的被购买方权益份额在购买日的公允价值（参见[第29.166段](50.md#s209-Para_29.166)及以后段落）。

- 按照 IFRS 3 确认和计量的资产和负债（参见[第29.88段](50.md#s209-Para_29.88)及以后段落）。

[IFRS 3 第32段]。

<a id="s210-Para_29.170"></a>**29.170** 集团需要详细记录所取得商誉总额的构成——即其归属于集团的哪些部分。商誉必须分摊至现金产出单元（CGU）或现金产出单元组，以便进行减值测试并对后续处置进行会计处理。参见[第24章第114段](41.md#s157-Para_24.114)。

[IAS 36 第80段]。

<a id="s210-Para_29.171"></a>**29.171** 必须披露构成商誉的因素说明。了解商誉的组成部分有助于主体出于减值测试目的将商誉分摊至现金产出单元（CGU）。进一步参见[第24章第114段](41.md#s157-Para_24.114)。

[IFRS 3 附录B第B64(e)段]。

[EX 29.171.1 – 构成商誉的组成部分](52.md#s216-EX29.171.1)

<a id="s210-Para_29.172"></a>**29.172** 收购境外经营产生的商誉应作为境外经营的资产处理，并以境外经营的功能货币表示。在初始确认时，按购买日的汇率计算。此后，出于合并目的，该外币商誉应按照 IAS 21 在每个报告期末按收盘汇率折算为集团的列报货币。参见[第49章第51段](80.md#s322-Para_49.51)。

[IAS 21 第47段]。

<a id="s210-Para_29.173"></a>**29.173** 非控制性权益计量基础的选择可能会影响所确认的商誉或廉价购买利得的金额。

[IFRS 3 第19段]。

[EX 29.173.1 – 确认的商誉取决于非控制性权益的计量方式](52.md#s216-EX29.173.1)

[EX 29.173.2 – 廉价购买利得取决于非控制性权益的计量方式](52.md#s216-EX29.173.2)

 

<a id="s210-chap_29_navPoint_44"></a>
### 廉价购买

 

<a id="s210-Para_29.174"></a>**29.174** 当转移的对价、非控制性权益和先前持有的权益之和小于可辨认净资产的价值时，会产生廉价购买利得。廉价购买利得由购买方立即计入当期损益。

[IFRS 3 第34段]。

<a id="s210-Para_29.175"></a>**29.175** 廉价购买可能发生在被迫出售、市场环境艰难的情况下，或者因为企业合并中的某些项目（参见[第29.89段](50.md#s209-Para_29.89)）并非按公允价值计量。

[IFRS 3 第35段]。

<a id="s210-Para_29.176"></a>**29.176** 购买方应确保其确实存在廉价购买利得，且已在购买日使用了所有可获得的证据并重新评估了企业合并的会计处理。购买方应重新评估对被购买方中可辨认资产和负债的识别和计量。

购买方应复核以下各项的计量：

- 可辨认资产和负债。

- 非控制性权益（如有）。

- 购买方先前持有的权益份额（如有）。

- 转移的对价。

[IFRS 3 第36段]。

[FAQ 29.176.1 – 在确认廉价购买利得之前，购买方应当做什么？](52.md#s216-FAQ_29.176.1)

 

<a id="s210-chap_29_navPoint_45"></a>
### 计量期间调整

 

<a id="s210-Para_29.177"></a>**29.177** 购买方拥有一段被称为“计量期间”的时间，以完成企业合并的最终会计处理。计量期间为主体提供了合理的时间来获取必要信息，以识别并确定以下各项的价值：

- 取得的可辨认资产、承担的负债以及被购买方中的任何非控制性权益。

- 为被购买方转移的对价或用于计量商誉的其他金额（例如，在未转移对价实现的企业合并中）。

- 购买方先前持有的被购买方权益份额。

- 确认的商誉或廉价购买利得。

[IFRS 3 第46段]。

<a id="s210-Para_29.178"></a>**29.178** 计量期间于购买方获得其所需信息（或确定无法获得该信息）之日与购买日起一年二者较早者结束。如果在发生企业合并的报告期末尚未完成企业合并的会计处理，应报告暂定金额并进行披露（参见[第29.241段](50.md#s214-Para_29.241)）。

[IFRS 3 第45段]。

<a id="s210-Para_29.179"></a>**29.179** 导致计量期间调整的新信息应当与购买日存在的事项或情况有关。在确定所获得的新信息是否导致计量期间调整时，应考虑的因素包括获得新信息的时间，以及购买方是否能够识别导致计量期间调整的原因。与几个月后收到的信息相比，在购买日后不久获得的信息更有可能反映购买日存在的事实和情况。

[IFRS 3 第47段]。

<a id="s210-Para_29.180"></a>**29.180** 如果识别出计量期间调整，购买方必须将该调整作为收购会计处理的一部分予以确认。购买方应增加或减少可辨认资产或负债的暂定金额，并通过增加或减少商誉来反映计量期间调整。在计量期间内获得的关于购买日存在事项或情况的新信息，可能导致对多项资产或负债的暂定金额进行调整。因某项暂定金额变动而对商誉进行的调整，可能被因另一项资产或负债暂定金额的相应调整而对商誉进行的另一项调整全部或部分抵销。

[IFRS 3 第48段]。

[EX 29.180.1 – 对商誉的抵销调整](52.md#s216-EX29.180.1)

<a id="s210-Para_29.181"></a>**29.181** 后续财务报表中包含的前期比较信息应予以修订，以反映计量期间调整的影响，视同企业合并的会计处理已于购买日完成。计量期间调整的影响可能会导致前期已确认的折旧、摊销或其他收益或费用发生变动。

[IFRS 3 第49段]。

<a id="s210-Para_29.182"></a>**29.182** 与购买日之后发生的事项相关的信息不属于计量期间调整。所有不符合计量期间调整条件的变动均计入当期损益。在计量期间结束后，购买方仅能为按照 IAS 8 更正差错而修订企业合并的会计处理。例如，因购买日后事项（如实现盈利目标或达到特定股价的可能性发生变化）导致的或有对价公允价值变动，不属于计量期间调整。在计量期间结束后，购买方仅能为按照 IAS 8 更正差错而修订企业合并的会计处理。

[IFRS 3 第50段]。

[EX 29.182.1 – 计量期间调整](52.md#s216-EX29.182.1)

## 评估哪些内容属于企业合并交易的组成部分（第29.183–29.203段）

 

<a id="s211-Para_29.183"></a>**29.183** 只有构成购买方与被购买方（或被购买方原所有者）在企业合并中所交换内容的金额，才纳入企业合并会计处理。这些项目必须是转移的对价，或者取得的可辨认资产和承担的负债，或者非控制性权益。不属于企业合并组成部分的项目应按照适用的国际财务报告准则单独进行会计处理。单独交易的示例包括原有关系的结算、订立竞业禁止协议以及关键职工薪酬计划。

[IFRS 3 第51段]。

<a id="s211-Para_29.184"></a>**29.184** 如果一项交易是由购买方或代表购买方订立的，或者是为购买方或合并后主体的利益而订立的，而非主要为企业合并前被购买方（或其原所有者）的利益而订立的，则该交易更有可能属于单独交易。

[IFRS 3 第52段]。

<a id="s211-Para_29.185"></a>**29.185** 判断交易是否属于企业合并组成部分的指标（既不互斥，也不单独具有决定性）包括：

- 交易的原因：为购买方（或合并后主体）的利益而非为企业合并前被购买方或其所有者的利益而安排的交易，不太可能属于企业合并的组成部分。

- 交易的发起方：由购买方发起的交易可能是为了购买方（或合并后主体）的利益，而对企业合并前的被购买方或其所有者几乎没有或完全没有利益。

- 交易的时间：在协商企业合并条款期间发生的交易，更有可能是为筹划合并以使购买方（或合并后主体）受益而订立的。除了作为合并后主体一部分所获得的利益外，合并前的被购买方或其原所有者不太可能从该交易中获得利益或仅获得极少利益。

[IFRS 3 附录B第B50段]。

 

<a id="s211-chap_29_navPoint_47"></a>
### 购买方与被购买方之间原有关系的结算

<a id="s211-Para_29.186"></a>**29.186** 企业合并中的购买方与被购买方在企业合并发生之前可能存在原有关系。企业合并实际上结算了该关系。当该关系变为“集团内部”关系并在收购时被抵销时，即发生结算。从外部角度来看，该关系被视为“已结算”。由于任何持续的关系均属于集团内部关系，该关系在收购后可能继续按相同条款存续。

[IFRS 3 第51段]。

<a id="s211-Para_29.187"></a>**29.187** 原有关系可以是合同性的（例如出售方与客户、许可方与被许可方），也可以是非合同性的（例如原告与被告）。有时，这些原有关系涉及重新取得的权利；相关内容自[第29.116段](50.md#s209-Para_29.116)起阐述。

[IFRS 3 第51段]。

<a id="s211-Para_29.188"></a>**29.188** 购买方应识别任何原有关系，并确定哪些原有关系已被实际结算。购买方支付的金额可能包含用于结算该关系的金额（正数或负数）。该金额不属于企业合并的组成部分，应单独进行会计处理。

[IFRS 3 第51段]。

<a id="s211-chap_29_navPoint_idm500549720"></a>
#### 计算原有关系结算产生的利得或损失

 

<a id="s211-Para_29.189"></a>**29.189** 购买方可能需要就原有关系的实际结算确认利得或损失。如果具有原有关系的当事方之间存在多项合同或协议，或存在多项原有关系，则应对每项合同和每项原有关系的结算分别进行评估。

[IFRS 3 附录B第B52段]。

<a id="s211-Para_29.190"></a>**29.190** 非合同关系产生的结算利得和损失按购买日的公允价值计量。

合同关系产生的结算利得和损失按以下两项金额中的较低者计量：

- 从购买方角度看，合同条款相对于相同或类似项目的当前市场交易定价而言有利或不利的金额。如果合同条款相对于当前市场交易有利，则确认结算利得；如果合同条款相对于当前市场交易不利，则确认结算损失。

- 合同中规定的、可供合同对其不利的交易对手方使用的任何结算条款金额。因违约或自愿终止而规定的任何结算条款金额，均用于确定结算利得或损失。针对不受交易对手方控制的事项（如控制权变更、破产或清算）提供补救措施的条款，在确定结算利得或损失时通常不被视为结算条款。

[IFRS 3 附录B第B52段]。

[FAQ 29.190.1 – 购买方应如何计算原有关系结算产生的利得或损失？](52.md#s216-FAQ_29.190.1)

<a id="s211-Para_29.191"></a>**29.191** 如果购买方此前已在财务报表中确认了与原有关系相关的金额，则与该原有关系相关的结算利得或损失应就此前已确认的金额进行调整（即增加或减少任何利得或损失）。由于任何资产将被视为已收回且任何负债将被视为已结算，该资产或负债将在合并时予以抵销。该抵销分录将影响结算利得或损失。

### 职工薪酬安排

 

<a id="s211-Para_29.194"></a>**29.194** 出售方股东可能是被购买方的关键职工，在收购规模较小或非上市主体时尤其如此。出售方股东在企业合并后可能继续留任为被收购业务的职工。包含或有对价的安排需要根据安排的性质进行评估，以确定应付金额是针对该业务的对价，还是针对合并后职工服务的薪酬。属于对价的付款构成企业合并的组成部分；属于职工服务的付款则构成合并后薪酬费用，应按照 IFRS 2 或 IAS 19 计入合并后集团的利润表。

[IFRS 3 第52(b)段]。

<a id="s211-Para_29.195"></a>**29.195** 评估向出售方股东支付的款项，需要了解协议中包含或有对价的原因、由哪一方（被购买方还是购买方）发起了该安排，以及当事方何时订立该安排。安排的性质决定了向成为合并后主体职工的出售方股东支付的或有付款是企业合并中的或有对价，还是单独交易。

[IFRS 3 附录B第B54段]。

<a id="s211-Para_29.196"></a>**29.196** 在分析这些付款时应考虑八项指标（这些标准适用于向成为合并后主体职工的出售方股东支付款项的所有安排，包括现金薪酬和股份支付薪酬）：

- 持续雇佣：雇佣条款可能载于买卖协议、雇佣协议或其他文件中。在任何情况下，如果雇佣关系终止时付款自动作废，则该安排属于对合并后服务的薪酬。反之，如果付款不受该人员是否受雇的影响，则可能表明该安排属于或有对价而非薪酬。

- 持续雇佣的期限：如果要求的雇佣期间等于或长于或有付款期间，则该或有付款更有可能属于薪酬。

- 薪酬水平：如果在剔除或有付款安排后，身为职工的出售方股东的薪酬与其他关键职工相比处于合理水平，则可能表明或有付款是针对该业务的额外对价。

- 向职工支付的增量款项：未成为职工的出售方股东（按每股计算）收到的或有付款可能低于成为合并后主体职工的出售方股东。这表明向成为职工的出售方股东支付的或有付款的增量部分属于薪酬而非对价。

- 持股数量：如果出售方股东持有被购买方几乎全部股份并成为职工，则或有付款安排更有可能是一项利润分享薪酬安排。反之，如果继续担任关键职工的出售方股东仅持有该业务的一小部分股份，且所有股东（按每股计算）收到相同的或有付款，则表明该付款属于对价而非薪酬。购买方还应考虑与继续担任关键职工的出售方股东相关的关联方（如其家庭成员）所持有的所有权份额。

- 与估值的关联：购买方和被购买方通常会在一定估值区间内进行谈判。如果在购买日转移的对价金额处于估值区间的低端，且需支付进一步的或有金额，则或有付款安排更有可能属于对价。另一方面，如果或有付款公式与企业合并前已与关键职工订立的利润分享安排一致，则表明该安排属于薪酬而非对价。

- 确定对价的公式：基于盈利倍数的公式更有可能属于或有对价，因为其旨在确定被收购业务的公允价值。相反，基于所赚取利润比例的公式表明该安排属于利润分享协议，是对合并后服务的薪酬。

- 其他协议：应付给出售方股东的金额可能既不是对价也不是职工薪酬，而是针对其他事项。例如，可能存在竞业禁止协议、待执行合同、咨询合同和资产租赁协议等其他安排。出售方股东可能拥有一项由被购买方租赁的物业，并作为企业合并的一部分订立了一项新租赁。如果该新租赁的租金低于市场费率，则可能表明或有付款安排在某种程度上是对该租赁的付款，应在购买方合并后的财务报表中单独确认。

## 一般计量原则的例外情况（第29.204–29.211段）

<a id="s212-chap_29_navPoint_56"></a>
### 重新取得的权利

<a id="s212-Para_29.204"></a>**29.204** 重新取得的权利被确定为公允价值计量原则的例外情况。为重新取得的权利确认的价值不基于市场参与者假设。即使市场参与者预期会续展，在确定公允价值时也不考虑合同续展。重新取得的权利的价值通常基于剩余合同期限内的估计现金流量确定。

### 所得税

## 后续计量与会计处理（第29.212–29.228段）

 

<a id="s213-Para_29.212"></a>**29.212** 购买方在企业合并后通常适用相关国际财务报告准则对资产、负债和交易进行会计处理。然而，IFRS 3 对企业合并后特定收购相关项目的后续计量和会计处理提供了具体指引。

[IFRS 3 第54段]。

 

<a id="s213-chap_29_navPoint_63"></a>
### 重新取得的权利

 

<a id="s213-Para_29.213"></a>**29.213** 重新取得的权利应按购买日的剩余合同期限摊销。这与此类权利的计量基础一致（参见[第29.204段](50.md#s212-Para_29.204)及以后段落）。如果该权利随后被出售或重新授予，应予以终止确认，其账面金额计入出售利得或损失。如果重新取得时的剩余合同期限不受限制，则重新取得的权利可以是永久性的。

[IFRS 3 第55段]。

<a id="s213-chap_29_navPoint_64"></a>
### 所得税

 

<a id="s213-Para_29.214"></a>**29.214** 被购买方未弥补税务亏损或其他递延所得税资产的潜在利益，在企业合并初始会计处理中可能不满足 IAS 12 的单独确认标准，但随后可能得以实现。如果可收回可能性的变动属于计量期间调整（参见[第29.177段](50.md#s210-Para_29.177)），则递延所得税资产应冲减商誉。如果商誉已减记至零，则任何进一步调整应作为廉价购买利得计入损益。不属于计量期间调整的递延所得税资产变动，应作为所得税项目计入损益（或按照 IAS 12 的要求计入损益以外）。

[IAS 12 第68段]。

[EX 29.214.1 – 收购后实现的递延所得税资产](52.md#s216-EX29.214.1)

### 或有负债

 

<a id="s213-Para_29.215"></a>**29.215** 在企业合并中确认的属于 IAS 37 范围内的或有负债，在未结算、未取消或未到期时，应按以下两项中的较高者计量：

- 按照 IAS 37 应确认的金额；以及

- 在企业合并中初始确认的金额，减去按照 IFRS 15 原则确认的累计收入金额（如适用）。

### 或有对价

 

<a id="s213-Para_29.218"></a>**29.218** 分类为负债的或有对价的公允价值变动，如果不属于计量期间调整，则反映在利润表中。因达成盈利目标、达到特定股价或实现研发项目里程碑等事项导致的公允价值变动不属于计量期间调整；相反，应按照 IFRS 3 第58(b)段计入损益（或者，如果或有对价属于 IFRS 9 范围，则按照 IFRS 9 计入损益）。

<a id="s213-Para_29.219"></a>**29.219** 分类为权益工具的或有对价不予重新计量，其后续结算在权益内进行会计处理。

<a id="s213-Para_29.221"></a>**29.221** 将以现金或其他金融资产结算的应付或有对价属于金融负债，并在每个报告日按公允价值计量。IAS 39/IFRS 9 已经修订，将“购买方在适用 IFRS 3 的企业合并中确认的或有对价”纳入以公允价值计量且其变动计入当期损益的金融资产或金融负债的定义中，以明确不得采用摊余成本计量。该负债公允价值的变动计入利润表。

### 被购买方作为出租人的经营租赁所涉及的资产

 

<a id="s213-Para_29.228"></a>**29.228** 在企业合并日之后，经营租赁中偏离市场条款的部分应作为该资产的一个单独组成部分处理，并在直至合同重新协商至市场条款的期间内计提折旧，该期间可能短于资产的使用寿命。

[IFRS 3 第BC148段]。

### 披露

 

<a id="s214-Para_29.232"></a>**29.232** IFRS 3 的披露要求十分广泛。对于报告期内发生的每项企业合并均需进行披露。

[IFRS 3 第63段]。

<a id="s214-Para_29.233"></a>**29.233** 购买方应披露相关信息，以使购买方财务报表的使用者能够评价在当期报告期内，或在报告期后但财务报表批准报出前发生的企业合并的性质和财务影响。

[IFRS 3 第59段]。

<a id="s214-Para_29.234"></a>**29.234** 购买方应披露相关信息，以使使用者能够评价在当期报告期内确认的、与当期及前期报告期内发生的企业合并相关的调整的财务影响。

[IFRS 3 第61段]。

<a id="s214-Para_29.235"></a>**29.235** 准则还包含一项“兜底”要求。详细披露要求载于 IFRS 3 第59至63段及第B64至B67段。如果 IFRS 3 要求披露的具体信息未能满足[第29.233段和第29.234段](50.md#s214-Para_29.233)中规定的目标，购买方必须披露为实现这些目标所需的任何额外信息。本章重点说明若干关键领域。

[IFRS 3 附录B第B64段]。[IFRS 3 附录B第B65段]。[IFRS 3 附录B第B66段]。[IFRS 3 附录B第B67段]。

<a id="s214-Para_29.236"></a>**29.236** IFRS 3 的披露要求除其他项目外，还包括：

- 在购买日为被购买方各类资产、负债和或有负债确认的金额（参见[第29.239段](50.md#s214-Para_29.239)）。

- 按类别列示的转移的对价总额的公允价值。

- 任何非控制性权益的金额及其计量方式的说明。

- 构成商誉的各项因素的定性说明（参见[第29.238段](50.md#s214-Para_29.238)）。

- 与企业合并分开确认的任何交易的说明。

- 因将先前持有的权益重新计量至公允价值而确认的利得或损失（参见[第29.240段](50.md#s214-Para_29.240)）。

[IFRS 3 附录B第B64段]。

<a id="s214-Para_29.237"></a>**29.237** IFRS 3 要求披露自购买日起计入购买方当期损益的被购买方收入和损益，以及假定当期所有企业合并的购买日均为该期间期初时合并后主体的当期收入和损益（除非披露不切实可行）。

[IFRS 3 附录B第B64段]。

[FAQ 29.237.1 – 编制备考信息有哪些指引？](52.md#s216-FAQ_29.237.1)

<a id="s214-Para_29.238"></a>**29.238** 必须披露构成商誉的因素的定性说明。构成商誉的因素的典型示例包括：被购买主体的劳动力；因成本节约和市场份额增加而产生的协同效应；以及不符合无形资产确认标准的非合同性客户关系。

[IFRS 3 附录B第B64(e)段]。

<a id="s214-Para_29.239"></a>**29.239** 购买方应对当期实施的每项企业合并（或对单项不重大的企业合并汇总）披露在购买日为被购买方各大类资产和负债确认的金额。IFRS 3 不要求披露被购买方财务报表中各大类资产和负债的账面价值，也不要求披露按照 IFRS 3 计量资产和负债（通常调整至公允价值）所作的调整。然而，购买方应按照 IFRS 3 第B64(h)段披露所取得应收款项的公允价值、合同总金额以及预计无法收回的合同现金流量估计数。在金融服务等行业中，此类披露通常也是满足其他监管披露要求所必需的。

[IFRS 3 附录B第B64(h)、(i)段]。

 

<a id="s214-chap_29_navPoint_75"></a>
### 分步实现的企业合并

<a id="s214-Para_29.240"></a>**29.240** 对于分步实现的企业合并，购买方应披露：

- 先前持有的被购买方权益份额在购买日的公允价值。

- 因将该权益份额重新计量至公允价值而确认的任何利得或损失的金额，以及该利得或损失在综合收益表中确认的列报项目。

[IFRS 3 附录B第B64(p)段]。

<a id="s214-chap_29_navPoint_76"></a>
### 初始企业合并会计处理中使用的暂定金额

<a id="s214-Para_29.241"></a>**29.241** 如果当期发生的企业合并的初始会计处理尚未完成，因而就任何资产、负债、非控制性权益或对价项目确认的金额为暂定金额（参见[第29.177段](50.md#s210-Para_29.177)及以后段落），则应对每项企业合并（或对单项不重大的企业合并汇总）披露以下信息：

- 初始会计处理尚未完成的原因。

- 会计处理尚未完成的资产、负债、权益份额或对价项目。

- 当期确认的计量期间调整的性质和金额。

[IFRS 3 附录B第B67(a)段]。

<a id="s214-chap_29_navPoint_77"></a>
### 现金流量表列报与披露

 

<a id="s214-Para_29.242"></a>**29.242** 当集团收购一项业务时，IAS 7 要求在现金流量表的“投资活动”项下单独报告与购买对价相关的现金流量。就取得或丧失子公司控制权的对价所支付或收到的现金及现金等价物金额，应在投资活动项下以扣除作为购买或出售组成部分而取得或处置的任何现金及现金等价物余额后的净额列示。

[IAS 7 第42段]。

[FAQ 29.242.1 – 在企业合并中，现金流量表的列报和披露要求是什么？](52.md#s216-FAQ_29.242.1)

<a id="s214-Para_29.243"></a>**29.243** 由于交易成本在发生时计入费用，因此在现金流量表中应分类为经营活动。只有在资产负债表中导致确认一项资产的支出才符合分类为投资活动的条件。投资活动产生的现金流量在[第7章第27段](15.md#s46-Para_7.27)中阐述，企业合并的收购成本在[FAQ 7.27.3](15.md#s48-FAQ_7.27.3)中专门讨论。

[IAS 7 第16段]。

### 资产负债表日后的企业合并

<a id="s214-Para_29.245"></a>**29.245** 在资产负债表日之后但财务报表批准报出之前发生的企业合并，属于非调整事项的示例。IAS 10 要求披露重大非调整事项的性质及其财务影响的估计。IFRS 3 对资产负债表日后发生的企业合并规定了具体的披露要求。

[IAS 10 第22段]。

<a id="s214-Para_29.246"></a>**29.246** IFRS 3 要求购买方对在资产负债表日后但财务报表批准报出前发生的每项企业合并（即存在购买日），披露本准则第B64段要求的详细信息，除非此类披露不切实可行。如果披露任何该等信息不切实可行，应披露这一事实并说明原因。要求披露的信息与报告期内发生的企业合并的要求类似。

### 资产收购

 

<a id="s214-Para_29.247"></a>**29.247** IFRS 3 为收购不构成业务的资产组提供了指引。对单项资产收购的会计处理适用相关的国际财务报告准则。当收购涉及一组资产和负债时，购买方必须识别并确认所取得的单项资产（包括根据 IAS 38 确认的无形资产）和负债。交易成本按照购买日的相对公允价值分摊至所取得的资产和所承担的负债。此类交易不产生商誉。
