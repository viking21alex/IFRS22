## 引言和范围（第22.1至22.15段）

 

<a id="s141-Para_22.1"></a>**22.1** 本章阐述国际财务报告准则（IFRS）对不动产、厂场和设备（PPE）的以下要求：

- 不动产、厂场和设备的初始确认和计量。

- 初始确认后的计量，包括成本模式和重估模式。

- 折旧。

- 终止确认。

- 披露。

不动产、厂场和设备的减值由IAS 36规范（参见[第24章第3段](41.md#s154-Para_24.3)）。公允价值由IFRS 13规范（[参见第5章第1段](11.md#s32-Para_5.1)）。

<a id="s141-Para_22.2"></a>**22.2** 初始确认和计量、后续计量（包括重估）、折旧和减值、终止确认以及披露均由IAS 16《不动产、厂场和设备》规范。

[IAS 16 第1段]。

<a id="s141-Para_22.3"></a>**22.3** 可直接归属于符合资本化条件的资产的购置、建造或生产的借款费用构成该资产成本的一部分。符合资本化条件的资产主要是不动产、厂场和设备。

[IAS 23 第1段]。

<a id="s141-Para_22.4"></a>**22.4** 因购置某项不动产、厂场和设备而产生的，或因在特定期间内出于非生产存货目的使用该资产而产生的弃置、复原或类似活动的成本初始估计，也计入该项不动产、厂场和设备的成本。IFRIC 1《现有弃置、复原和类似负债的变动》就弃置和复原准备变动的会计处理（包括估计成本的资本化）提供了指引。

[IFRIC 1 第2段]。

<a id="s141-Para_22.5"></a>**22.5** 作为机器或其他固定资产不可分割部分的计算机软件应作为不动产、厂场和设备处理，这包括计算机的操作系统。不构成相关硬件不可分割部分的软件应作为无形资产处理。

[IAS 38 第4段]。

 

<a id="s141-chap_22_navPoint_2"></a>
### 范围

 

<a id="s141-Para_22.6"></a>**22.6** 不动产、厂场和设备定义为：

“……指同时具有以下特征的有形项目：

- 为用于商品生产或劳务提供、出租给他人或行政管理目的而持有；以及

- 预计使用寿命超过一个会计期间。”

[IAS 16 第6段]。

<a id="s141-Para_22.7"></a>**22.7** 不动产、厂场和设备应按照IAS 16进行会计处理，除非其他国际财务报告准则要求或允许采用不同的会计处理方法。

[IAS 16 第2段]。

<a id="s141-Para_22.8"></a>**22.8** 本准则不适用于：

- 除生产性植物以外与农业活动相关的生物资产（[参见第33章第4段](58.md#s236-Para_33.4)）。

- 勘探和评价资产的确认和计量。

- 矿产权和矿产储量，如石油、天然气及类似的非再生资源。

- 按照IFRS 5划分为持有待售的不动产、厂场和设备。

然而，本准则适用于用于开发或维护上述（a）至（c）项所列资产的不动产、厂场和设备。

[IAS 16 第3段]。

<a id="s141-Para_22.9"></a>**22.9** 根据租赁取得的资产按照IFRS 16中的指引进行确认和计量。承租人在对使用权资产计提折旧时应适用IAS 16中的折旧要求。

[IFRS 16 第31段]。

<a id="s141-Para_22.10"></a>**22.10** 按照IAS 40对投资性房地产采用成本模式的主体应适用IAS 16。

[IAS 16 第5段]。

 

<a id="s141-chap_22_navPoint_3"></a>
### 初始确认

 

<a id="s141-Para_22.11"></a>**22.11** 某项不动产、厂场和设备在满足以下条件时应确认为一项资产：

- “与该项目有关的未来经济利益很可能流入主体；以及

- 该项目的成本能够可靠地计量。”

[IAS 16 第7段]。

<a id="s141-Para_22.12"></a>**22.12** 未来经济利益将流入主体的充分确定性通常只有在资产的风险和报酬转移给主体时才能实现。通常，当存在无条件且不可撤销的合同时，即假定风险和报酬已经转移。在实务中，风险和报酬的转移通常发生在资产交付之时。购置不动产、厂场和设备的合同承诺应予以披露，但在风险和报酬转移之前不确认该资产。购置的某些不动产、厂场和设备本身可能并不产生经济利益，但却是使其他资产产生经济利益所必需的。这可能包括为确保安全或遵守环保法规所必需的资产。由于这些资产使其他资产能够产生经济利益，因此应当将其确认为资产。应对这些资产的账面价值进行减值复核，以确保合并后的账面价值不超过其合并后的可收回金额（参见[第24章第6段](41.md#s154-Para_24.6)）。

[IAS 16 第11段]。[IAS 16 第74(c)段]。

<a id="s141-Para_22.13"></a>**22.13** 在确定计量单元（即如何识别单个项目以及将项目汇总的程度）时需要运用判断。这些判断可能包括是否将单个项目汇总，或是否应将大型项目确认为单独的组成部分。将单项金额不重大的不动产、厂场和设备项目（如模具、工具和冲模）进行汇总，并对汇总价值应用确认标准，可能是恰当的。

[IAS 16 第9段]。

<a id="s141-Para_22.14"></a>**22.14** 拆分或组成部分划分是指将一项资产分解为其重要组成部分。如果某项不动产、厂场和设备的某个组成部分相对于该项目总成本而言成本重大，且该组成部分的消耗方式或消耗期间与该资产其余部分不同，则该组成部分应当单独计提折旧。例如，飞机及其发动机通常会被评估为单独的组成部分并分别计提折旧。

[IAS 16 第43段]。

[EX 22.14.1 – 替换屋顶作为一个组成部分](39.md#s146-EX22.14.1)  
  
[EX 22.14.2 – 需要定期替换的资产的组成部分折旧](39.md#s146-EX22.14.2)

<a id="s141-Para_22.15"></a>**22.15** 备品备件和维修设备通常作为存货处理，并在消耗时计入当期费用。然而，如果重要备品备件和备用设备符合不动产、厂场和设备的定义，则应作为不动产、厂场和设备处理。

[IAS 16 第8段]。

<a id="s142-chap_22_navPoint_6"></a>
### 成本——购买不动产、厂场和设备时可变或或有对价的处理

 

<a id="s142-Para_22.32"></a>**22.32** 主体可能以一笔初始付款加上取决于未来事项或结果、或取决于所购资产最终售价高于某一门槛价格的额外付款来购置不动产、厂场和设备。通常，如果未来事项发生或条件满足，主体在合同或法律上有义务支付该额外款项。这通常被称为资产的“可变”或“或有”对价。

 

国际财务报告准则解释委员会（IFRS IC）曾讨论过购置资产时或有对价的会计处理。解释委员会认为该议题过于宽泛，未将其列入议程。特别是，解释委员会未能就主体（购买方）应当“在购买资产之日就取决于其未来活动的可变付款确认一项负债，还是仅在相关活动发生时确认该负债”达成共识。解释委员会也选择不通过议程决定来澄清不取决于购买方未来活动的可变付款的初始会计处理。解释委员会还指出，其未能就购买方如何计量此类可变付款的负债达成共识，且对于资产购买后可变付款的会计处理存在疑问。解释委员会建议国际会计准则理事会（IASB）全面解决这一问题。

 

[IFRIC议程决定——2016年3月]。

 

<a id="s142-Para_22.33"></a>**22.33** 需要仔细分析该安排，以确定未来付款是否与资产成本相关。与资产成本无关的付款应在发生时费用化。解释委员会决定不以解释公告或议程决定的形式提供指引来说明如何应用现行指引。因此，没有专门适用于该交易的国际财务报告准则。如果确定未来付款与资产成本相关，主体应遵循IAS 8《会计政策、会计估计变更和差错》，为购置不动产、厂场和设备的或有对价制定会计政策。在实务中，资产或有对价的会计处理存在多样性，有三种可能的方法。

 

1）金融负债模式  
不动产、厂场和设备在初始确认时包含未来或有付款的公允价值，并按相同的或有付款公允价值确认一项金融负债。后续，该金融负债按照IFRS 9的要求以摊余成本计量。每当现金流量估计发生修订时，主体应调整金融负债的账面价值以反映实际和更新后的估计现金流量。主体通过按金融工具的原实际利率（或如适用，按IFRS 9第B5.4.6段计算的修订后实际利率）计算估计未来现金流量的现值，重新计算该负债的账面价值。负债计量的后续变动与资产成本无关。因此，该调整作为收益或费用计入损益。

2）成本累积模式

不动产、厂场和设备在购置日按已支付的对价金额进行初始确认。[IAS 16 第16段]。取决于未来事项的可变付款在第1日不计入资产的账面价值，也不就此确认负债。主体不确认负债，是因为根据上述议程决定，在不确定性消除之前尚不清楚是否存在义务。解释委员会在2016年议程决定中也指出，后续付款的会计处理存在未决问题。因此，主体可以选择在支付可变付款时将其作为资产成本的一部分予以资本化，理由是这些付款代表购置的直接成本。这种处理通常仅在可变付款的变动是由资产效用引起的情况下才可接受。如果变动是由与资产无关的其他因素引起的，则该部分可变付款的会计处理通常应遵循国际财务报告准则中的适用指引。

3）IFRIC 1方法

不动产、厂场和设备在购置日进行初始确认，其中包括对未来预期可变成本的估计。同时确认一项负债。该负债后续以摊余成本计量，方式与上述方法1类似。然而，负债的后续变动将计入或扣减资产的成本。这种处理通常仅在可变付款的变动是由资产效用引起的情况下才可接受。如果变动是由与资产无关的其他因素引起的，则成本变动通常应遵循适用的国际财务报告准则指引。

 

在对可变或或有对价进行会计处理时，所有方法均可接受。这是一项会计政策选择，应对所有类似交易一贯应用并予以恰当披露。

 

[IFRIC 1 第4段]。[IFRIC 1 第5段]。

### 延期付款条款

 

<a id="s142-Para_22.34"></a>**22.34** 某项不动产、厂场和设备的成本是该资产确认日的等价现金价格。某项不动产、厂场和设备可能按超出正常信用条件的延期付款条款购置。在这些情况下，成本为折现后的金额，即等价现金价格。该金额与付款总额之间的差额应在信用期内作为应付利息处理，除非按照IAS 23的规定在建造期间予以资本化。

### 通过非现金交换取得的资产

 

<a id="s142-Para_22.37"></a>**22.37** 某项不动产、厂场和设备可能通过交换另一项非货币性资产或非货币性资产与货币性资产的组合而取得。所取得项目的成本按公允价值计量，除非该交易缺乏商业实质，或者换入资产和换出资产的公允价值均不能可靠计量。公允价值应按付出或收到的货币性资产金额进行调整。如果所取得项目未按公允价值计量，则按换出资产的账面价值计量。

[IAS 16 第24段]。

<a id="s142-Para_22.38"></a>**22.38** 如果主体的未来现金流量预计将因交易而发生变化，则该交易具有商业实质。交换交易通常具有商业目的，且交换非完全相同的资产很可能导致主体现金流量的变化。如果现金流量的预计差异重大，则该交换具有商业实质。

[IAS 16 第25段]。

[FAQ 22.38.1 – 资产交换何时具有商业实质？](39.md#s146-FAQ_22.38.1)

<a id="s142-Para_22.39"></a>**22.39** 商业实质通常显而易见，主体无需进行详细计算。在不同地点互换大宗商品或交换类似资产属于不符合现金流量变化测试的常见问题示例。

[IAS 16 第25段]。

[EX 22.39.1 – 缺乏商业实质的资产交换](39.md#s146-EX22.39.1)

<a id="s142-Para_22.40"></a>**22.40** 如果（a）某项资产合理公允价值计量范围的变动性并不重大，或（b）该范围内各种估计的概率能够合理评估并用于计量公允价值，则该资产的公允价值能够可靠计量。当换出资产的公允价值和换入资产的公允价值均能以同等可靠性进行估计时，应采用换出资产的公允价值计量换入资产的成本。然而，如果换入资产的公允价值能够更可靠地计量，则采用该公允价值。

**受赠资产的成本**

<a id="s142-Para_22.41"></a>**22.41** 在特殊情况下，主体可能通过无对价且不发行股份的捐赠或出资取得一项资产。国际财务报告准则对此类交易没有具体指引。主体应制定一项会计政策并一贯应用。实务中通常观察到两种方法：在主体取得资产控制权时按公允价值确认资产；或按零值确认。（参见[第17章第11段](37.md#s127-Para_17.11)。）

 

<a id="s142-chap_22_navPoint_10"></a>
### 借款费用的资本化

 

<a id="s142-Para_22.4"></a>**22.42** 可归属于符合资本化条件的资产的购置、建造或生产的借款费用应作为该资产成本的一部分予以资本化。所有其他借款费用均应在发生当期费用化。

[IAS 23 第8段]。

<a id="s142-Para_22.43"></a>**22.43** 主体可以选择（但不要求）将本准则应用于可直接归属于以下资产的购置、建造或生产的借款费用：

- 以公允价值计量的符合资本化条件的资产（例如生物资产）；或

- 大批量重复制造或生产的存货。

[IAS 23 第4段]。

<a id="s142-Para_22.44"></a>**22.44** 当同时满足以下所有条件时，借款费用应予以资本化：

- 主体拥有一项符合资本化条件的资产（即需要经过相当长时间才能达到预定可使用或者可销售状态的资产）；

- 已为该符合资本化条件的资产发生支出；

- 已发生借款费用；以及

- 为使资产达到预定可使用或者可销售状态所必要的活动已经开始。

[IAS 23 第17段]。

 

<a id="s142-chap_22_navPoint_idp1695656792"></a>
#### 符合资本化条件的资产

<a id="s142-Para_22.45"></a>**22.45** 符合资本化条件的资产定义为“需要经过相当长时间才能达到预定可使用或者可销售状态的资产”。

[IAS 23 第5段]。

<a id="s142-Para_22.46"></a>**22.46** 符合资本化条件的资产不仅限于不动产、厂场和设备，还包括需要经过“相当长时间”才能达到可销售状态的存货等资产。通常需要一年以上才能达到预定可使用状态的资产一般属于符合资本化条件的资产。管理层一旦选定标准和资产类别，应对这些类别的资产一贯应用。购置时即已达到预定可使用或者可销售状态的资产不属于符合资本化条件的资产。

[IAS 23 第7段]。

**22.47** 运营方确认无形资产的特许经营权安排也可能构成一项符合资本化条件的资产。如果运营方以建造服务换取并确认一项无形资产，其将在建造阶段资本化所发生的借款费用。

[IFRIC 12 第22段]。

<a id="s142-chap_22_navPoint_idp1695660120"></a>
#### 借款费用

 

<a id="s142-Para_22.48"></a>**22.48** 借款费用是指“主体因借入资金而发生的利息及其他费用”。

[IAS 23 第5段]。

<a id="s142-Para_22.49"></a>**22.49** 借款费用的例子包括：

- 采用实际利率法（如IAS 39所述）计算的利息费用。

- 根据IFRS 16确认的租赁相关融资费用。

- 因外币借款产生的汇兑差额，以其被视为对利息费用的调整为限。

[IAS 23 第6段]。

[FAQ 22.49.3 – 现金流量套期或公允价值套期关系对特定项目借款利息的影响是否应资本化计入不动产、厂场和设备的成本？](39.md#s146-FAQ_22.49.3)

<a id="s142-Para_22.50"></a>**22.50** 借款费用包括根据IAS 32分类为负债的优先股的融资费用，但不包括权益和未分类为负债的优先股的实际或估算成本（包括发行费用）。

<a id="s142-Para_22.51"></a>**22.51** 借款费用的资本化包括将与借款相关的外币汇兑差额在其被视为对利息费用调整的范围内予以资本化。作为利息费用调整的利得和损失包括：主体若以其记账本位币借入资金将发生的借款费用，与外币借款实际发生的借款费用之间的利差。不属于利息费用调整的其他差额可能包括因其他经济指标（如就业或生产率）变化或政府更迭导致的汇率变动。

<a id="s142-Para_22.52"></a>**22.52** 所有直接归属的借款费用均应予以资本化。“直接归属”是指如果未在资产上发生支出，本可以避免的借款费用（例如，通过避免额外借款，或利用支付于该资产的资金偿还现有借款）。一旦相关资产完工，专门借款在偿还前即转化为一般借款。

[IAS 23 第8段]。

<a id="s142-Para_22.53"></a>**22.53** 本准则区分一般借款和专门借款。所有非专门借款均属于一般借款。专门借款与一般借款的区分关系到资本化率的确定方式。专门借款的资本化率为该专门借款的实际利率。一般借款的资本化率为主体在当期尚未偿还的借款所适用的借款费用的加权平均值。但是，主体在计算时应剔除专门为获取符合资本化条件的资产而借入的借款费用，除非为使该符合资本化条件的资产达到预定可使用状态所需的几乎所有活动均已完成。符合资本化条件的费用通过将资本化率应用于符合资本化条件的资产支出来计算。符合资本化条件的借款费用金额始终不得超过当期实际发生的借款费用金额。

<a id="s142-Para_22.54"></a>**22.54** 母公司可能几乎没有借款，但子公司拥有符合资本化条件的资产。在这种情况下，子公司可以在其单独财务报表中根据集团内另一主体提供的借款将利息资本化。然而，在合并财务报表中，集团内部利息予以抵销，因为集团整体并未就这些借款发生利息。但是，如果集团内另一家公司向外部借款并转贷给拥有符合资本化条件的资产的主体，任何资本化的利息将在合并报表中保留，但须遵守总体上限，即资本化的借款费用不得超过合并层面实际发生的借款费用。

[IAS 23 第14段]。

**资本化期间**

<a id="s142-Para_22.55"></a>**22.55** 借款费用开始资本化前必须同时满足三项条件：

“开始资本化日是指主体首次同时满足以下所有条件的日期：

- 为资产发生支出；

- 发生借款费用；以及

- 为使资产达到预定可使用或者可销售状态所必要的活动已经开始。”

[IAS 23 第19段]。

<a id="s142-Para_22.57"></a>**22.57** 资产的建造可能跨越多个会计期间。前期就资产建造已资本化的借款费用计入该资产的总支出。当期的资本化率随后应用于该总支出。在计算下一期间适用资本化率的支出时，应包括以前期间已资本化的利息。

[IAS 23 第18段]。

<a id="s142-Para_22.58"></a>**22.58** 借款费用可能在使资产达到预定可使用状态所必要的活动发生较长期间中断的期间内发生。此类借款费用不符合资本化条件。然而，在进行大量技术和行政工作期间，资本化应继续进行。当暂时延误是使资产达到预定可使用状态过程中的必要组成部分时，资本化也应继续进行。

### 初始确认后发生的成本

 

<a id="s142-Para_22.61"></a>**22.61** 一旦某项不动产、厂场和设备达到管理层预定可使用状态所需的地点和条件，成本的确认即告停止。然而，主体可能在日后就该资产发生进一步成本。后续成本仅在满足资产确认条件时才应予以资本化。所有其他后续成本应在发生当期确认为费用。

<a id="s142-Para_22.62"></a>**22.62** 决定资本化还是费用化需要考虑该资产原预计的未来经济利益。仅用于维持原预计经济利益的后续成本被视为修理和维护费用，并确认为费用。只有当与该项目有关的额外未来经济利益很可能流入主体且该项目的成本能够可靠计量时，后续成本才计入资产的账面价值（或在适当时确认为一项单独资产）。额外的未来经济利益通常发生在后续成本导致生产能力提高、产生未来经济利益的能力增强或预计使用寿命延长的情况下。

<a id="s142-Para_22.63"></a>**22.63** 某项不动产、厂场和设备的日常维护成本不确认为资产，因为它们不会增加该项目的未来经济利益。这些成本旨在维持资产原购置时预期的产生未来经济利益的潜力。日常维护成本包括人工成本和易耗品成本，并可能包括小型替换部件的成本。此类支出通常被称为“修理和维护费用”。

[IAS 16 第12段]。

 

<a id="s142-chap_22_navPoint_idp1684312072"></a>
#### 重大定期检查或大修

 

<a id="s142-Para_22.64"></a>**22.64** “大修”一词常用于描述对资产进行检查和维护的过程。大修成本通常包括部件替换以及重大修理和维护。作为定期检查和大修组成部分且满足确认条件的重大修理和维护计划，很可能会符合确认为资产的条件。如果每次重大定期检查的成本符合准则中的资产确认条件，则应作为替换计入该项不动产、厂场和设备的账面价值。与先前检查相关的任何剩余账面价值应予以终止确认。先前检查的成本无需在购置或建造该项目时即单独识别并计提折旧。如果先前未单独识别，则可使用未来类似检查的估计成本作为需要终止确认的账面价值的替代值。

[IAS 16 第14段]。

## 初始确认后的计量（第22.65至22.102段）

 

<a id="s143-Para_22.65"></a>**22.65** 主体在初始确认后对不动产、厂场和设备采用成本模式或重估模式。该会计政策选择是按资产类别作出的，而不是按某一类别中的单项资产作出的。因此，主体可能对一个或多个类别的资产采用成本模式，而对其他类别的资产采用重估模式。

[IAS 16 第29段]。

<a id="s143-Para_22.66"></a>**22.66** 资产类别是指在主体经营中具有相似性质和用途的一组资产。重估必须应用于整个资产类别。如果某项不动产、厂场和设备被重估，则该项目所属的整个不动产、厂场和设备类别均应进行重估。这适用于合并财务报表，因此集团内不同主体中属于同一类别的不动产、厂场和设备需要按一致的基础进行会计处理。

[IAS 16 第37段]。

[EX 22.66.1 – 资产类别](39.md#s146-EX22.66.1)

<a id="s143-Para_22.67"></a>**22.67** 固定资产的定义不允许仅按地理区域划分资产类别，但在其他方面具有合理灵活性。主体可以采用适合其业务类型和所持资产的有意义的类别。然而，必须对每一类资产分别进行披露，并在财务报表附注的变动表中将每一类资产作为单独的类别列报。

[IAS 16 第73段]。

<a id="s143-Para_22.68"></a>**22.68** 采用成本模式的不动产、厂场和设备项目应按成本减去累计折旧和累计减值损失后的金额列账。

[IAS 16 第30段]。

<a id="s143-Para_22.69"></a>**22.69** 采用重估模式的不动产、厂场和设备项目应按重估日的公允价值减去任何后续累计折旧和任何后续累计减值损失后的金额列账。重估应当足够频繁地进行，以确保账面价值与报告期末采用公允价值确定的金额不存在重大差异。

[IAS 16 第31段]。

 

<a id="s143-chap_22_navPoint_13"></a>
### 重估模式的应用

 

<a id="s143-Para_22.70"></a>**22.70** 估值无需每年或每个报告期间都进行，但应当足够频繁地进行，以确保账面价值与报告期末的公允价值不存在重大差异。

[IAS 16 第31段]。

<a id="s143-Para_22.71"></a>**22.71** 同一类别内的不动产、厂场和设备应同时进行估值，以避免选择性地对资产进行重估。但是，如果某类资产的重估在较短时间内完成且重估保持最新，则可以按滚动方式对该类资产进行重估。

[IAS 16 第38段]。

[EX 22.71.1 – 为应用重估模式界定资产类别](39.md#s146-EX22.71.1)  
[FAQ 22.71.2 – 企业合并如何影响固定资产的定期重估？](39.md#s146-FAQ_22.71.2)

<a id="s143-Para_22.72"></a>**22.72** 当公允价值波动较大时（如土地和建筑物，或在恶性通货膨胀经济体中），可能需要频繁进行估值。当公允价值在较长时期内保持稳定时（如厂房和机器设备），估值频率可以较低。本准则建议，当价值出现重大且剧烈的变动时，可能需要每年重估。如果公允价值的变动不重大，则每三年或五年重估一次可能即已足够。

[IAS 16 第34段]。

<a id="s143-Para_22.73"></a>**22.73** 公允价值是指“市场参与者在计量日发生的有序交易中，出售一项资产所能收到或者转移一项负债所需支付的价格”。（[参见第5章第8段。](11.md#s33-Para_5.8)）IAS 16并未要求必须聘请第三方估值专家。

[IFRS 13 第9段]。

 

<a id="s143-chap_22_navPoint_14"></a>
### 重估模式下累计折旧的处理

 

<a id="s143-Para_22.74"></a>**22.74** 在重估时调整资产账面价值有两种方法：“总额法”和“净额法”。总额法重述资产的账面原值（折旧前）并同时重述累计折旧。净额法将累计折旧与资产的账面价值相抵销，然后对账面净值进行重估。两种方法下的净额应当相同，差异仅在于列报方式。

[IAS 16 第35段]。

#### 重估利得

<a id="s143-Para_22.75"></a>**22.75** 重估盈余应贷记其他综合收益（OCI），并在权益中以重估盈余项目累计。例外情况是，如果重估利得转回了同一资产先前确认为费用的重估减少（减值），则该利得应首先在转回先前计入利润表的损失的范围内贷记利润表。

[IAS 16 第39段]。

<a id="s143-Para_22.76"></a>**22.76** 计入权益的重估盈余可在盈余实现时（通常在资产终止确认时）直接结转至留存收益。该结转通过储备进行，而非通过利润表。重估盈余也可以在主体使用该资产的过程中逐步结转。结转金额为基于资产重估后账面价值计提的折旧与基于资产原始成本计提的折旧之间的差额。该金额可每年通过储备结转的方式从重估盈余转入留存收益。

### 折旧

 

<a id="s143-Para_22.79"></a>**22.79** 资产的可折旧金额应在其使用寿命内系统地分摊。所采用的折旧方法应反映主体消耗该资产未来经济利益的预期方式。

[IAS 16 第60段]。

<a id="s143-Para_22.80"></a>**22.80** 折旧适用于所有不动产、厂场和设备，无论其按历史成本还是重估金额持有，但有以下两项例外：

- 按照IAS 40以公允价值计量的投资性房地产，不计提折旧。

- 任何具有无限使用寿命的资产，例如土地。

[EX 22.80.1 – 复原义务与土地成本的折旧](39.md#s146-EX22.80.1)

<a id="s143-Para_22.81"></a>**22.81** 支出（例如修理和维护费用）并不消除计提折旧的必要性。

[IAS 16 第52段]。

 

<a id="s143-chap_22_navPoint_idp1718538488"></a>
#### 折旧的定义

 

<a id="s143-Para_22.82"></a>**22.82** 折旧定义为：“……在资产的使用寿命内，对资产可折旧金额的系统分摊”；可折旧金额定义为“资产的成本，或替代成本的其他金额，减去其残值”。

[IAS 16 第6段]。

<a id="s143-Para_22.83"></a>**22.83** 即使按成本减折旧持有的资产其公允价值高于账面价值，只要该资产的残值不超过其账面价值，仍应计提折旧。修理和维护并不消除对资产计提折旧的必要性。

[IAS 16 第52段]。

#### 组成部分的折旧

 

<a id="s143-Para_22.85"></a>**22.85** 一项资产可能包含若干不同的重要组成部分。每个组成部分应出于折旧目的单独处理，并在其各自的使用寿命内计提折旧。如果使用寿命和消耗方式相似，则可将组成部分合并计提折旧。当某个重要组成部分被替换或修复时，旧组成部分应予以终止确认，而新组成部分在其成本可收回的情况下予以资本化。

[IAS 16 第43段]。

<a id="s143-Para_22.86"></a>**22.86** 替换组成部分的成本若满足确认条件，应确认为一项资产。被替换部分的账面价值应予以终止确认；被替换部分的成本和累计折旧应予以冲销。如果无法识别被替换部分或组成部分的成本和折旧，则替换成本可作为被替换部分成本的合理替代值。

[IAS 16 第13段]。[IAS 16 第70段]。

<a id="s143-Para_22.87"></a>**22.87** 土地和建筑物出于折旧目的应作为单独资产处理。除采石场和垃圾填埋场等少数例外情况外，土地通常具有无限使用寿命，不计提折旧。然而，建筑物具有有限使用寿命，属于可折旧资产。土地价值的增加不影响建筑物可折旧金额的确定，也不消除对建筑物计提折旧的必要性。

[IAS 16 第58段]。

##### 确定使用寿命

 

<a id="s143-Para_22.88"></a>**22.88** 使用寿命定义为：

“a. ……主体预期可使用某项资产的期间；或  
  
 b. 主体预期从该资产获得的产量或类似计量单位数量。”

[IAS 16 第6段]。

<a id="s143-Para_22.89"></a>**22.89** 资产的使用寿命自购置日资产能够按照主体预定的方式运行时开始。使用寿命的定义包含“预期可供使用”一语。使用寿命是主体使用该资产的期间。有形固定资产的使用寿命可能短于该资产的总物理寿命。主体可能有在资产达到物理寿命终点之前对其进行替换的惯例。对资产使用寿命的估计是一个判断问题，基于对类似资产的经验。

[IAS 16 第57段]。

[EX 22.89.1 – 资产达到预定可使用状态时开始计提折旧](39.md#s146-EX22.89.1)

[EX 22.89.4 – 租赁改良支出的使用寿命](39.md#s146-EX22.89.4)

<a id="s143-Para_22.90"></a>**22.90** 当资产终止确认或根据IFRS 5划分为持有待售时，折旧停止计提。资产处于闲置状态时，折旧不一定停止。

[IAS 16 第55段]。

 

<a id="s143-chap_22_navPoint_idp1714681832"></a>
##### 确定残值

 

<a id="s143-Para_22.91"></a>**22.91** 资产的可折旧金额是在扣除其残值后确定的。残值是指假定该资产已达到其使用寿命预期终点时的车龄（或使用年限）和状态，主体目前从处置该资产中可获得的估计金额。残值考虑截至资产负债表日的价格变动，但不考虑未来的价格变动。在实务中，残值通常微不足道，因此对可折旧金额的计算并不重大。

[IAS 16 第53段]。

<a id="s143-Para_22.92"></a>**22.92** 资产的残值可能增加至等于或大于该资产的账面价值。如果出现这种情况，该资产的折旧费用为零，除非其残值随后降至低于资产的账面价值。

[IAS 16 第54段]。

<a id="s143-Para_22.92.1"></a>**22.92.1** 主体应选择最能密切反映该资产所包含的未来经济利益预期消耗方式的折旧方法。应用于某项资产的折旧方法至少应在每个财务年度终了进行复核。然而，除非未来经济利益的预期消耗方式发生变化，否则折旧方法应在各期间一贯应用。当主体采用直线法计提折旧时，其已确定该资产的经济利益是随时间推移（即按直线方式）消耗的。主体需要证明该资产不再随时间消耗，才能变更为工作量法，这种情况很少见。如果主体变更其折旧方法，该变更应按照IAS 8作为会计估计变更进行会计处理。如果主体确实变更了其折旧方法，在后续期间改回原折旧方法将极为罕见，因为只有伴随着预期消耗方式的变化，这种变更才是可接受的。

[IAS 16 第60段]。[IAS 16 第62段]。

### 折旧方法

 

<a id="s143-Para_22.93"></a>**22.93** 所采用的折旧方法应反映主体预期消耗该资产未来经济利益的方式。

[IAS 16 第60段]。

<a id="s143-Para_22.94"></a>**22.94** 最常见的折旧方法是在资产使用寿命内按直线法计提。这是一种基于时间的方法，但可作为使用情况和陈旧过时的替代指标。然而，对于某些资产，实际使用量可能是更可靠的计量标准。如果预期和实际的使用模式相似，基于时间的折旧方法是恰当的。

[IAS 16 第62段]。

<a id="s143-Para_22.94.1"></a>**22.94.1** 主体应选择最能密切反映该资产所包含的未来经济利益预期消耗方式的折旧方法。[IAS 16 第60段]。应用于某项资产的折旧方法至少应在每个财务年度终了进行复核。然而，除非未来经济利益的预期消耗方式发生变化，否则折旧方法应在各期间一贯应用。[IAS 16 第62段]。当主体采用直线法计提折旧时，其已确定该资产的经济利益是随时间推移（即按直线方式）消耗的。主体需要证明该资产不再随时间消耗，才能变更为工作量法，这种情况很少见。如果主体变更其折旧方法，该变更应按照IAS 8作为会计估计变更进行会计处理。如果主体确实变更了其折旧方法，在后续期间改回原折旧方法将极为罕见，因为只有伴随着预期消耗方式的变化，这种变更才是可接受的。

[EX 22.94.1 – 折旧方法的详细讨论](39.md#s146-EX22.94.1)  
[EX 22.94.2 - 主体可以变更为采用“工作量法”计算折旧吗？](39.md#s146-EX22.94.2)

 

<a id="s143-Para_22.95"></a>**22.95** 所采用的折旧方法至少应在每个财务年度终了进行复核；如果该资产所包含的未来经济利益的预期消耗方式发生重大变化，则应变更折旧方法以反映变化后的经济利益消耗方式。此类变更应按照IAS 8作为会计估计变更进行会计处理。[IAS 16 第61段]。

 

<a id="s143-Para_22.96"></a>**22.96** IAS 16列举了多种可接受的折旧方法。管理层应根据未来经济利益的预期消耗方式，选择被认为最恰当的方法，以便在资产的使用寿命内系统地分摊折旧。[IAS 16 第62段]。

<a id="s143-Para_22.97"></a>**22.97** 经济利益主要通过使用资产而消耗。然而，其他因素（例如技术陈旧过时以及闲置期间的磨损）可能会减少本可从该资产获得的经济利益。对该资产产出的需求下降或价格下跌可能是陈旧过时的迹象。[IAS 16 第56段]。

 

<a id="s143-Para_22.98"></a>**22.98** 在确定某项不动产、厂场和设备的经济利益消耗方式，进而确定其折旧方法和使用寿命时，应考虑以下因素：

 

- 主体对该资产的预期使用情况。这是主要因素，通常参照资产的预期产能或实物产量进行评估。

- 资产在使用和闲置期间因使用或时间推移而产生的预期有形损耗（即“磨损”）。这将取决于运营因素，例如资产使用的班次数量以及在其使用寿命内维护和修理的良好程度。

- 技术或商业陈旧过时。资产本身或该资产所生产的产品或提供的服务，可能因被更新或更先进的产品或生产技术所取代而出现商业或技术上的陈旧过时。同样，市场需求的变化（例如趋势变化或竞争对手的行动）可能导致资产在商业上陈旧过时。

- 对资产使用的法律或类似限制，例如专利、许可证或租赁的到期。

- 采用以收入为基础的折旧方法是不恰当的。

[IAS 16 第56段]。[IAS 16 第62A段]。

[EX 22.98.1 – 确定恰当的折旧方法](39.md#s146-EX22.98.1)

## 示例文本

<a id="s146-chap_22_navPoint_27"></a>
### <a id="s146-EX22.14.1"></a>EX 22.14.1 – 替换屋顶作为一个组成部分

 

准则参考：IAS 16 第43段  
正文参考：[22.14](39.md#s141-Para_22.14)  

  

  
主体购置一项资产时，其价格可能反映了使资产达到管理层预定可运行状态所需的地点和条件所必需的未来支出。例如，购置一栋需要重大翻新（如更换新屋顶）的建筑物。随后更换屋顶的成本应予以资本化，因为该成本满足准则中的资产确认条件：它增加了预期从该建筑物获得的未来经济利益，且能够可靠计量。

资产的组成部分不属于单独的资产类别，不在财务报表中单独披露。

 

<a id="s146-chap_22_navPoint_28"></a>
### <a id="s146-EX22.14.2"></a>EX 22.14.2 – 需要定期替换的资产的组成部分折旧

 

准则参考：IAS 16 第43段  
正文参考：[22.14](39.md#s141-Para_22.14) 

  

  
一家小型制造公司近期以C100万的成本购置了一座新厂房，残值为C100,000。该厂房有一个平屋顶，每十年需要更换一次，成本为C100,000。相对于厂房的总成本，屋顶的成本是重大的。

该公司正在考虑两种替代方案：

- 将该项目视为一项整体资产，因此在30年的经济使用寿命内对整座厂房计提折旧，每年计提C30,000。

- 将屋顶视为该项目的一个重要组成部分，将C100,000的屋顶成本按10年计提折旧，每年计提折旧费用C10,000；同时将厂房其余部分C900,000在30年内折旧至残值C100,000，每年计提折旧费用C26,667。

第二种方案是正确的。不动产、厂场和设备（PPE）项目的重要组成部分应当单独计提折旧。[IAS 16 第43段]。

第二种方案恰当地反映了厂房经济利益的消耗情况，在厂房30年的经济使用寿命内，每年均衡地向利润表计提C36,667的折旧费用。

 

<a id="s146-chap_22_navPoint_29"></a>
### <a id="s146-FAQ_22.18.1"></a>FAQ 22.18.1 - 主体在建造新建筑物期间应如何对租赁土地的折旧进行会计处理？

 

准则参考：IAS 16 第10段  
正文参考：22.18  
 

  

 

**背景**

 

某主体租赁了一块土地，并将在该土地上建造一栋自用办公楼。建造工作与租赁同时开始。该土地不用于任何其他目的。

**问题**

 

主体在建造新建筑物期间应如何对租赁土地的折旧进行会计处理？

 

**回答**

 

使用权资产的折旧应按照IAS 16进行会计处理[IFRS 16 第31段]。承租人通常应自租赁期开始日起，在使用权资产的使用寿命或租赁期两者较短的期间内对使用权资产计提折旧[IFRS 16 第32段]。

 

使用权资产的使用寿命本质上是由时间（即租赁期）驱动的。在本例中，出租人已将租赁土地提供给主体使用。建造建筑物正是管理层租赁该土地的原因之一。因此，建造建筑物不会改变使用权资产使用寿命的期限。故此，主体应在租赁期开始日即开始对租赁土地计提折旧，并在建造期间照常继续计提折旧。

IAS 16要求将使资产达到管理层预定可运行状态所需的地点和条件而发生的直接归属成本予以资本化[IAS 16 第16段]。使用权资产的折旧应当费用化还是资本化计入建筑物成本，可能需要结合所有相关事实和情况运用判断。在这一事实情形下，租赁土地的折旧被视为使资产达到管理层预定可运行状态所需条件的直接归属成本。因此，该折旧应资本化计入建筑物的成本[IAS 16 第10段]。

<a id="s146-chap_22_navPoint_30"></a>
### <a id="s146-FAQ_22.18.2"></a>FAQ 22.18.2 - 主体在进行初始租赁改良时，应如何对新租赁门店的折旧进行会计处理？

 

准则参考：IAS 16 第10段  
正文参考：22.18  
 

  

 

**背景**

 

某主体计划开设一家新零售门店，并为此租赁了一家现有零售门店。现有门店处于可供使用状态，但主体需要对其进行翻新装修，以符合品牌的整体装潢风格。主体花费六个月完成装修。在此期间，该新零售门店保持关闭状态。

 

**问题**

 

主体在进行初始租赁改良时，应如何对新租赁门店的折旧进行会计处理？

 

**回答**

 

使用权资产的使用寿命本质上是由时间（即租赁期）驱动的。在本例中，主体应在租赁期开始日即开始对租赁物业计提折旧。无论是否需要进行装修以使其符合管理层的意图，由于出租人已将该零售门店提供给主体使用，主体在零售门店装修的六个月期间内应继续计提折旧（参见[FAQ 22.18.1](39.md#s146-FAQ_22.18.1)）。

 

使用权资产的折旧应当费用化还是资本化计入另一项资产的成本，可能需要结合所有相关事实和情况运用判断。在这一进行门店首次装修的事实情形下，租赁改良的建造类似于在租赁土地上建造建筑物（参见[FAQ 22.18.1](39.md#s146-FAQ_22.18.1)）。因此，使用权资产的折旧被视为使物业达到管理层预定可运行状态所需条件的直接归属成本[IAS 16 第16段]。故此，该折旧应资本化计入租赁改良资产的成本[IAS 16 第10段]。对于已在运营中的门店进行装修，可能需要更多判断，包括评估所开展工程的程度以及门店在装修期间是关闭还是继续营业。

该成本不同于应在发生时费用化的开办费[IAS 16 第19段]。租赁物业的折旧是为特定租赁改良资产发生的成本，而开办费是不直接归属于特定资产的一般成本。在本例中，使用权资产的折旧被视为直接归属于使租赁改良资产按照管理层预定方式投入使用的成本。

<a id="s146-chap_22_navPoint_31"></a>
### <a id="s146-EX22.19.1"></a>EX 22.19.1 – 直接归属成本的资本化

 

准则参考：IAS 16 第16段  
正文参考：[22.19](39.md#s142-Para_22.19) 

  

  
经营大型连锁超市的A主体购置了一处新门店场所。该新场所需要重大的翻新支出。管理层预计翻新将持续三个月，期间超市将保持关闭。管理层编制了该期间的预算，包括与建造和改造成本相关的支出、开业前负责筹备门店的员工薪酬以及相关的水电费成本。

管理层应将超市的建造和改造成本予以资本化，因为这些成本是使门店达到管理层预定可运行状态所需条件所必需的。如果不发生改造支出，超市便无法开业，因此该支出应被视为资产成本的一部分。

然而，水电费和商品存储成本属于经营支出，并非使门店达到管理层预定可运行状态所需条件所必需的。这些成本应当费用化。但对于与建造和改造直接相关的员工薪酬成本，则应审慎考虑。

 

<a id="s146-chap_22_navPoint_32"></a>
### <a id="s146-FAQ_22.20.1"></a>FAQ 22.20.1 – 哪些职工薪酬费用可以作为自建资产成本的一部分予以资本化？

准则参考：IAS 16 第17段  
正文参考：[22.20](39.md#s142-Para_22.20) 

  

  
职工薪酬是指主体为换取职工提供的服务而给予的各种形式的对价。薪酬类型包括：

- 短期职工薪酬，如工资、薪金和社会保障缴款、带薪年休假和带薪病假、利润分享和年度奖金，以及非货币性福利（如医疗保健、汽车、住房和免费或补贴的商品或服务）。

- 离职后福利，如养老金、其他退休福利、离职后人寿保险和离职后医疗保健。

- 辞退福利。

- 以股份为基础的支付。

职工薪酬费用在资产自建的情况下最为相关，不过在调试阶段也可能有部分成本予以资本化。并非上述所有成本在该期间都符合条件或相关。例如，支付给已离职员工的辞退福利不具有相关性，因为这些员工不会参与资产的建造。

<a id="s146-chap_22_navPoint_33"></a>
### <a id="s146-FAQ_22.20.1.1"></a>FAQ 22.20.1.1 – 如何计量分配至不动产、厂场和设备（PPE）达到预定可使用状态前所产生产出的成本？

 

准则参考：IAS 16 对第17(e)段和第20A段的修订  
正文参考：22.20.1  

  

 

**问题**

 

当在某项不动产、厂场和设备（PPE）达到预定可使用状态前产生产出时，哪些成本应当资本化计入存货并在随后出售产出时结转费用？这些成本应如何计量？

 

**回答**

 

IAS 16要求，在某项不动产、厂场和设备（PPE）达到预定可使用状态之前（即该项PPE仍在开发中，尚未达到管理层预定的状态和地点）所产生产出的成本，应按照IAS 2的原则进行计量。

 

使存货达到目前场所和状态所发生的全部成本均应计入存货计量[IAS 2 第10段]。IAS 16第16(b)段要求，在某项PPE达到预定可使用状态之前，任何直接归属成本均应资本化计入PPE。理事会并未就成本是否或如何在开发中的PPE项目与存货之间进行分摊提供具体指引。理事会在结论基础中指出，IAS 2为计量成本设定了框架，而未作过于死板的规定[IAS 16 第BC16I段]。

 

因此，在开发阶段，所发生的成本需要以合理的基础在PPE与所产生产出之间进行分摊。主体可能需要运用判断以确定所采用的成本分摊方法。

 

如果所选定的分摊方法导致在试生产产出初始确认时即产生可变现净值（“NRV”）减记（即第1日减值），则可能需要重新考虑该分摊方法。当分摊方法导致分摊至产出的成本高于预期销售收入时，便可能出现此种情况。

 

采用增量成本法计量所产生产出的成本是不可接受的，因为这不符合IAS 2的计量要求[IAS 2 第10段]。

 

主体可能会认为，应用IAS 2第14段中的以下副产品指引是一种可接受的成本分摊方法；主体可以将试生产阶段生产的产出视为主产品/主要活动（即PPE的开发）的“副产品”：

 

“某一生产过程可能同时产生一种以上的产品。例如，生产联产品或同时产生主产品和副产品的情况。当每种产品的加工成本无法单独识别时，应以合理且一致的基础在各产品之间进行分摊。例如，分摊可以基于各产品在生产过程中变得可单独识别的阶段或生产完成时的相对销售价值。大多数副产品按其性质而言并不重大。在这种情况下，它们通常按可变现净值计量，并将该价值从主产品的成本中扣除。因此，主产品的账面价值与其成本没有重大差异。”

 

由此产生的会计处理将使分摊至产出的成本相当于其可变现净值（例如预计从其销售中实现的收入）。应用该方法的一项关键要求是，试生产产出按照国际财务报告准则的定义属于“不重大”。如果省略、错报或掩盖信息可合理预期会影响通用目的财务报表主要使用者基于提供特定报告主体财务信息的财务报表所作出的决策，则该信息具有重要性[IAS 1 第7段]。

 

主体应考虑其成本分摊方法是否构成一项重大判断，从而应按照IAS 1第122段予以披露。

 

<a id="s146-chap_22_navPoint_34"></a>
### <a id="s146-FAQ_22.20.2"></a>FAQ 22.20.2 – 对于外购或自建资产，哪些职工薪酬费用可以予以资本化？

准则参考：IAS 16 第17段  
正文参考：[22.20](39.md#s142-Para_22.20) 

  

  
只有与员工在建造或购置特定资产上所花费时间相关的直接归属人工成本（工资和职工薪酬）才应当予以资本化。花费在其他潜在收购或开发项目上的时间不能计入。例如，一名内部测量师可能对五处不同物业进行勘测，以帮助公司决定购买其中哪一处物业。这些勘测的成本不应作为随后所购物业成本的一部分予以资本化。然而，在决定购买某处物业之后进行的勘测（例如为了确认该决定）的成本可以予以资本化。只有与特定项目相关的员工成本比例才应予以资本化。如果一名现场工程师将其30%的时间用于某个特定开发项目，则只有其30%的员工成本应予以资本化。

<a id="s146-chap_22_navPoint_35"></a>
### <a id="s146-FAQ_22.20.3"></a>FAQ 22.20.3 – 哪些专业服务费可以予以资本化？

准则参考：IAS 16 第17段  
正文参考：[22.20](39.md#s142-Para_22.20) 

  

  
为寻找合适资产而发生、且该资产随后得以购置或建造的外部专业服务费可以予以资本化。外部专业服务费只有在与资产的购置或建造直接相关时，才能作为资产成本的一部分予以资本化。投机性项目的成本和中止计划的成本不应资本化。购置资产时发生的其他专业服务费（如律师费和印花税）应计入资产成本。

### <a id="s146-FAQ_22.20.3.1"></a>FAQ 22.20.3.1 – 在IAS 16修订生效之日（即2022年1月1日或之后开始的年度报告期间）需要进行哪些追溯调整？

 

准则参考：IAS 16 对第17(e)段和第20A段的修订  
正文参考：22.20.3  

  

 

根据IAS 16第80D段的指引，主体应追溯适用对IAS 16的修订，但仅适用于在主体首次应用该修订的财务报表所列报的最早期间期初或之后达到管理层预定可运行状态所需的地点和条件的不动产、厂场和设备（PPE）项目。主体应将首次应用该修订的累积影响确认为对该所列报的最早期间期初留存收益（或其他权益组成部分，如适用）期初余额的调整。

 

**问题**

 

在IAS 16修订生效之日（即2022年1月1日或之后开始的年度报告期间）需要进行哪些追溯调整？

 

**回答**

 

在过渡至IAS 16修订时，要求采用追溯适用法，但仅适用于在主体首次应用该修订的财务报表所列报的最早期间期初或之后达到管理层预定可运行状态所需的地点和条件的PPE项目[IAS 16 第80D段]。

 

例如，考虑一家财务年度截止日为2022年12月31日、并在其2022年度财务报表中列报2021年比较数据的主体。该主体有三个项目：项目A，于2020年达到预定可使用状态；项目B，于2021年年中达到预定可使用状态；以及项目C，于2022年达到预定可使用状态。

 

![](assets/82.png)

 

项目A：主体无需对项目A适用修订后的准则，因为它在2020年即已达到预定可使用状态，早于2022年度财务报表所列报的最早期间。

 

项目B：主体必须对项目B适用修订后的准则，因为它在上一年度（即2022年度财务报表所列报的最早期间）达到预定可使用状态。

 

项目C：主体必须对项目C适用修订后的准则，因为它在2022年（即修订生效的期间）达到预定可使用状态。

 

在2022年度财务报表中，2021年比较数据需要追溯调整以适用该修订。如果主体先前的政策与IAS 16修订不一致，则就项目B或项目C在2021年1月1日之前赚取的达到预定可使用状态前的销售收入而言，需要对2021年1月1日的留存收益和PPE期初余额进行调整。

 

该修订所要求的追溯适用应当应用于2022年发布的中期财务报表（其财务年度起始日为2022年1月1日或之后）。这也要求在中期财务报表中对比较金额进行调整。

### <a id="s146-FAQ_22.20.4"></a>FAQ 22.20.4 – 哪些直接归属的人工成本应当予以资本化？

准则参考：IAS 16 第16段  
正文参考：[22.20](39.md#s142-Para_22.20) 

  

  
A主体正在建造一项资产，并将使该资产达到工作状态所直接归属的人工成本予以资本化。对于按照IAS 16将人工成本予以资本化的员工，此类成本是否包括其社会保障缴款和养老金成本？

使资产达到管理层预定可运行状态所需的地点和条件而发生的直接归属成本应计入该资产的计量。自建资产的归属成本包括直接因建造该特定资产而产生的自有员工（例如现场工人、内部建筑师和测量师）的人工成本。雇主缴纳的社会保障缴款和养老金成本均属于员工成本的一部分，因此在此语境下属于人工成本的范畴。故此，它们应计入按照IAS 16资本化的金额中。

养老金成本按照IAS 19进行会计处理。按照IAS 2或IAS 16计入资产成本的任何离职后福利成本，应包括IAS 19下养老金成本各组成部分的恰当比例。

### <a id="s146-EX22.20.5"></a>EX 22.20.5 – 关于IAS 16修订的征求意见稿：达到预定可使用状态前的销售收入

 

准则参考：IAS 16 第17段  
正文参考：[22.20](39.md#s142-Para_22.20) 

  

  
2017年6月，IASB发布了关于达到预定可使用状态前的销售收入的IAS 16修订征求意见稿。该修订将禁止从某项不动产、厂场和设备的成本中扣除在使该资产达到管理层预定可运行状态所需的地点和条件的过程中销售所生产项目的任何收入。相反，主体应按照适用的准则将这些销售收入和生产这些项目的成本计入损益。

 

<a id="s146-chap_22_navPoint_39"></a>
### <a id="s146-FAQ_22.20.5"></a>FAQ 22.20.5 – 如果主体在开发阶段产生产出，在确定某项不动产、厂场和设备（PPE）何时达到预定可使用状态时应考虑哪些因素？

 

准则参考：IAS 16 对第17(e)段的修订

正文参考：[22.20](39.md#s142-Para_22.20)和[22.89](39.md#s143-Para_22.89)

  

 

在某项不动产、厂场和设备（PPE）（例如制造工厂）的开发阶段，处置资产达到预定可使用状态前生产的产出可能会产生附带收益。

 

IAS 16第17(e)段指出，测试资产是否正常发挥功能的成本（即评估资产的技术和物理性能是否使其达到预定可使用状态）被视为直接归属成本的例子。

 

鉴于与“测试”期间收入相关的要求，资产何时达到预定可使用状态这一时点可能会成为更受关注的领域。理事会决定在IAS 16第17(e)段中澄清，在测试资产是否正常发挥功能时，主体评估的是资产的技术和物理性能。此外，IAS 16第BC16R段指出，资产是否正常发挥功能并非对资产财务业绩的评估。评估资产财务业绩的一个例子是评估资产是否已达到管理层最初预期的营业利润率或盈利能力水平。

 

然而，对于确定资产何时达到预定可使用状态，并不存在明确的界限，管理层在作出这一判断时应运用判断。该评估可能受多种因素影响，但这些因素应聚焦于资产的技术和物理性能，而非财务业绩。

 

可能相关的一些因素包括：

 

- 资产的性质以及达到技术和性能门槛的复杂程度（例如，是新型加工厂还是基于标准设计的工厂）。

- 实际实现的吞吐量与设计吞吐量百分比（即所获得的产出与所需投入之比）相比，或与预期产能相比，是否已达到设计产能的既定百分比。

- 考虑是否由外部方代表主体建造资产，以及在整个建造过程中是否已达成任何里程碑或已签发合规证书以表明资产达到预定可使用状态。

- 产出是否达到管理层预期的足够质量，即使可能需要对资产进行微小调整才能生产出具有预期物理特性的产出。例如，产出是否具有管理层预期的化学成分或产品质量。

- 与资产相关的关键组成部分是否已建造完成。

- 截至目前已发生的资本支出水平与项目总成本估计的对比。

- 项目已在一段既定时间内持续产生产出（即使低于设计规格），未发生中断、复杂情况或需要重大临时改造。

- 项目已满足必要的监管要求（例如相关的排放标准）。

 

在实务中，该评估很可能会综合考虑多种因素，而非单一因素。为考虑情况的变化并避免未识别的减值或资产过晚投入使用，管理层需要持续重新评估其评估中所考虑初始因素的恰当性。

 

作为重新评估此类因素的示例，假设某项特定资产最初预计的计划平均产出水平为每月100个单位，主体认为达到计划平均产出水平的55%即表明该资产达到预定可使用状态。如果在建造过程中明显看出实际上仅能实现平均60个单位的产出，则主体继续依赖实现平均55个单位的产出（100的55%）作为该资产何时达到预定可使用状态的基准很可能是不恰当的。作为重新评估和综合考虑多种因素的一部分，主体可能会确定36个单位的产出（60的60%）现在即表明该资产达到预定可使用状态。

 

主体在确定资产何时达到预定可使用状态时，应考虑是否需要根据IAS 1第122段披露重大判断。

### <a id="s146-EX22.21.1"></a>EX 22.21.1 – 可行性研究成本的资本化

 

准则参考：IAS 16 第19段  
正文参考：[22.21](39.md#s142-Para_22.21) 

  

  
A主体正在开发一栋自用建筑物。其在获得规划许可之前发生了开发成本。该开发实际上分为两个阶段：可行性研究阶段，该阶段所有成本均应费用化；以及开发阶段，该阶段符合条件的成本予以资本化。主体在可行性研究阶段确定该物业是否能够按照其拟定规格建造，并符合相应的建筑规范和环保法规。此时建筑物的建造仍不确定，未来经济利益很可能流入主体的条件尚未满足。一旦可行性得以确立且开发商承诺建造该建筑物，即满足很可能流入的标准。开发阶段发生的成本将确认为不动产、厂场和设备成本的一部分。

获取规划许可可能归入上述任一类别，取决于其被视为可行性研究阶段的一部分还是开发阶段的一部分。在应用确认标准时运用的判断决定了其归类。如果成本不符合资产的定义，则属于费用，应在利润表中确认为费用。

 

<a id="s146-chap_22_navPoint_41"></a>
### <a id="s146-FAQ_22.21.2"></a>FAQ 22.21.2 – 开办费可以资本化吗？

 

准则参考：IAS 16 第19段  
正文参考：[22.21](39.md#s142-Para_22.21)

  

开办费及类似的试生产前成本不构成资产成本的一部分。在资产达到计划业绩之前发生的初始经营亏损应确认为费用，不得资本化。

### <a id="s146-FAQ_22.21.3"></a>FAQ 22.21.3 – 间接费用可以作为不动产、厂场和设备成本的一部分予以资本化吗？

准则参考：IAS 16 第19段

IAS 16禁止将一般及行政管理间接费用予以资本化。但是，系统分摊的固定和变动生产间接费用可能是允许资本化的。固定生产间接费用是生产的间接成本，包括厂房和设备的折旧与维护费用以及工厂管理和行政费用。相关间接费用的一定比例将计入成本。

### <a id="s146-EX22.22.1"></a>EX 22.22.1 – 启动期间发生的经营成本

 

准则参考：IAS 16 第20段  
正文参考：[22.22](39.md#s142-Para_22.22) 

  

  
一家游乐园向公众“试营业”，以试运行其游乐设施。在此期间门票按五折出售，运营产能为80%。游乐园的正式开业日定在三个月后。管理层声称试营业是使游乐园达到能够按预定方式运行的状态所必需的试运行。因此，管理层认为所发生的净经营成本应当予以资本化。

该净经营成本不应资本化，而应计入利润表。尽管游乐园以低于满负荷的运营产能运行（本例中为80%的运营产能），但已有充分证据表明其能够按照管理层预定的方式运行。因此，该期间的经营成本应在发生时费用化。

 

<a id="s146-chap_22_navPoint_44"></a>
### <a id="s146-FAQ_22.22.2"></a>FAQ 22.22.2 – 初始经营亏损可以资本化吗？

准则参考：IAS 16 第20段  
正文参考：[22.22](39.md#s142-Para_22.22) 

  

  
新酒店或书店在启动阶段的初始经营亏损不属于可以资本化的成本。同样，与为不动产、厂场和设备项目的服务创造需求相关的营销及类似成本也不能作为资产的一部分予以资本化。当工厂能够按正常水平运行但尚未如此运行时发生的费用应当费用化。

### <a id="s146-FAQ_22.22.3"></a>FAQ 22.22.3 – 临时搬迁成本

 

准则参考：IAS 16 第20段  
正文参考：[22.22](39.md#s142-Para_22.22)  

  

A主体拥有一处现有的永久业权厂房，拟将其拆除并重新开发。该主体将在重新开发期间把生产设施搬迁至另一处租赁的（临时）场地。A主体在搬迁至该临时地点的过程中发生了多项成本，包括：

- 租赁场地的使用权资产折旧；

- 生产设施的拆卸成本；

- 从旧地点到临时地点的运输成本；

- 在临时地点的安装成本；以及

- 建造完成后将生产设施搬回新建厂房时发生的类似成本。

这些成本可以资本化计入新建筑物的成本吗？

建造或购置新资产可能会产生如果未建造或购置该资产本可避免的增量成本。这些成本只有在直接归属于使资产达到管理层预定可运行状态所需的地点和条件时，才计入资产成本。上述成本与生产设施在临时地点的运营有关，并不直接归属于新厂房的建造。因此，这些成本不符合IAS 16的要求，应当费用化。

 

<a id="s146-chap_22_navPoint_46"></a>
### <a id="s146-FAQ_22.22.4"></a>FAQ 22.22.4 – 场地开发成本可以资本化吗？

准则参考：IAS 16 第20段   
正文参考：[22.22](39.md#s142-Para_22.22) 

  

  
B主体经营酒吧，并正通过开发新场地进行扩张。在考虑于某一特定区域扩张时，该主体通常会物色若干潜在场地，委托绘制图纸，与场地业主洽谈，并挑选其中一个场地进行开发。随后，该主体履行规划程序并开发该场地。包括选址在内的外部成本可以资本化吗？

直接归属于正在开发的特定场地的外部成本可以资本化。

场地平整属于直接归属成本。场地平整可以合理地包括识别最终得以开发的特定场地的外部成本。然而，与最终未选定场地相关的选址成本不能资本化，因为这些成本不直接归属于已开发的场地。主体在决定是否投资于某项资产或决定购置哪项资产之前，可能因开展可行性研究而发生支出。为可行性评估发生的费用应在发生时费用化，因为它们与特定的不动产、厂场和设备项目没有关联。但是，如果成本直接归属于特定资产，则予以资本化。例如，仅在物色到合适物业并予以购买时才需向经纪人或代理人支付的费用，应计入所购物业的成本。

<a id="s146-chap_22_navPoint_47"></a>
### <a id="s146-FAQ_22.22.5"></a>FAQ 22.22.5 – 在移动网络启动阶段，哪些成本可以资本化？

准则参考：IAS 16 第20段  
正文参考：[22.22](39.md#s142-Para_22.22) 

  

  
一家移动电话运营商可能正在新地区建立新网络，涉及网络系统（例如新的发射塔）的建造。与实体资产建造无关、而是与设立整体新业务相关的成本，即使是在新网络建造阶段发生的，也不符合作为资产成本一部分的条件。

<a id="s146-chap_22_navPoint_48"></a>
### <a id="s146-EX22.26.1"></a>EX 22.26.1 – 租赁的修复费用

 

准则参考：IAS 16 第16(c)段  
正文参考：[22.26](39.md#s142-Para_22.26) 

  

  
弃置或类似成本（例如失修赔偿支出）常与租赁和租赁改良相关。例如，一项租赁可能允许承租人根据自身特定需求改造物业，但要求承租人在租赁期满时将物业恢复原状归还。

承租人建造了内墙并对物业进行了其他外观改动。租赁期满时的修复需要拆除内墙。承租人产生了一项无法避免的拆除内墙的义务，因此必须按照IAS 37就该义务确认一项准备。承租人租赁改良的成本包括建造内墙的成本以及租赁期满时复原物业的成本。

这两项成本均在建造内墙时予以资本化，并将在资产的使用寿命（通常为预期租赁期）内作为折旧费用的一部分计入利润表。

 

<a id="s146-chap_22_navPoint_49"></a>
### <a id="s146-EX22.26.2"></a>EX 22.26.2 – 弃置义务与复原义务

 

准则参考：IAS 16 第16(c)段  
正文参考：[22.26](39.md#s142-Para_22.26) 

  

  
弃置成本通常出现在石油和天然气、采矿、电信和电力行业，在这些行业中，设施的建造和调试可能会造成环境损害。例如石油平台、移动电话信号塔和核电站。其他许多行业也会发生类似成本，例如垃圾填埋场的环境清理和复原成本。

 

<a id="s146-chap_22_navPoint_50"></a>
### <a id="s146-FAQ_22.28.1"></a>FAQ 22.28.1 – 如何确定作为资产资本化的弃置准备金额？

 

准则参考：IFRIC 1 第5段  
正文参考：[22.28](39.md#s142-Para_22.28) 

  

  
当产生弃置义务时，有两种方法可以确定作为资产资本化的准备金额。某项资产的使用寿命为30年，由于法律法规发生变化，十年后产生了与该资产安装相关的弃置成本义务。经计算并确认了一项C900,000的准备作为负债。这两种方法涉及可以将多少准备资本化为资产；要么：

- 将全部C900,000作为资产成本的一部分予以资本化，并在剩余20年的经济使用寿命内计提折旧（以可收回性为前提）；要么

- 仅将C600,000的准备予以资本化，并在剩余20年的经济使用寿命内计提折旧，因为该资产已使用完其使用寿命的三分之一。准备的其余部分（C300,000）——即如果该义务在资产使用寿命开始时即存在本应在前十年确认为折旧的金额——立即计入当年的损益表。

IAS 16和IFRIC 1均未强制规定采用哪一种方法。鉴于存在当前的法律变更且该变更源于新发展，第一种方法可能最能反映具体情况。

 

<a id="s146-chap_22_navPoint_51"></a>
### <a id="s146-EX22.28.2"></a>EX 22.28.2 – 资产使用寿命后期产生的弃置成本

 

准则参考：IFRIC 1 第5段  
正文参考：[22.28](39.md#s142-Para_22.28) 

  

  
弃置义务可能仅在资产使用寿命后期才显现出来。这可能是由于有关环境损害的法律法规发生变化所致。符合IAS 37下准备确认条件的成本，在其与资产的安装、建造或购置相关的范围内，应作为资产成本的一部分予以资本化。

在资产使用寿命期间因使用资产生产存货造成损害而产生的义务，属于该存货的生产成本，不予资本化。就租赁物业的磨损而产生的准备（根据租赁条款必须在租赁期满时予以修复）属于使用该物业的成本。这些成本在发生时费用化。

 

<a id="s146-chap_22_navPoint_52"></a>
### <a id="s146-EX22.37.1"></a>EX 22.37.1 – 同时包含非货币性资产和货币性资产的收到对价

 

准则参考：IAS 16 第24段  
正文参考：[22.37](39.md#s142-Para_22.37) 

  

  
A主体以账面价值为C100,000的多余土地换取C200,000现金及价值C250,000的厂房和机器设备。该交易具有商业实质。厂房和机器设备应按C250,000入账，相当于土地的公允价值C450,000减去收到的现金C200,000。

 

<a id="s146-chap_22_navPoint_54"></a>
### <a id="s146-FAQ_22.38.1"></a>FAQ 22.38.1 – 资产交换何时具有商业实质？

准则参考：IAS 16 第25段  
正文参考：[22.38](39.md#s142-Para_22.38) 

  

  
非现金资产交换在以下情况下具有商业实质：

- 换入资产的现金流量结构预计与换出资产的现金流量结构不同。“现金流量结构”是指现金流量的风险、时间和金额。以一座全面运营的工厂换取一块用于建造新工厂的绿地，显然满足“现金流量变化”测试。

- 受该交易影响的主体经营部分的特定主体价值因交换而发生变化。以一座正在运营的矿山及设备换取另一座矿山附近的铁路线，使主体能够以大幅降低的成本运输产品，便是主体经营活动现金流量变化的一个例子。

<a id="s146-chap_22_navPoint_55"></a>
### <a id="s146-EX22.39.1"></a>EX 22.39.1 – 缺乏商业实质的资产交换

 

准则参考：IAS 16 第25段  
正文参考：[22.39](39.md#s142-Para_22.39)  
 

  

  
A主体以账面价值为C13,000、公允价值为C13,250的汽车X，换取C150现金及公允价值为C13,100的汽车Y。该交易缺乏商业实质，因为主体的现金流量预计不会因交换而发生变化；换言之，主体处于与交易前相同的状态。

主体按汽车X的账面价值确认收到的资产。因此，其确认现金C150，并将汽车Y作为账面价值为C12,850的不动产、厂场和设备予以确认。

### <a id="s146-EX22.49.1"></a>EX 22.49.1 – 恶性通货膨胀下的资本化利息

 

准则参考：IAS 16 第21段  
正文参考：[22.49](39.md#s142-Para_22.49) 

  

  
采用IAS 29并对恶性通货膨胀进行会计处理的主体，需要区分属于通货膨胀补偿部分的借款费用并将其费用化。利率通常包含补偿通货膨胀的成分。既对由借款融资的资本支出进行重述，又将同一期间内补偿通货膨胀的那部分借款费用予以资本化，是不恰当的。借款费用中补偿通货膨胀的成分应在发生当期确认为费用。在通货膨胀率高于利率的经济体中，不应资本化任何借款费用。有关恶性通货膨胀会计处理，参见[第10章](18.md#s58-chap_10)。

 

<a id="s146-chap_22_navPoint_57"></a>
### <a id="s146-FAQ_22.49.2"></a>FAQ 22.49.2 – 将未根据IFRS 9或IAS 39指定为套期关系的衍生工具（例如利率互换和外币互换）的利得和损失作为借款费用资本化是否恰当？

 

准则参考：IAS 23 第6段  
正文参考：[22.49](39.md#s142-Para_22.49) 

  

  
 

不恰当。此类工具归入“以公允价值计量且其变动计入当期损益”的类别。此类衍生工具的利得和损失不被视为IAS 23定义的借款费用，因为它们并未通过IFRS 9（IAS 39）套期关系与主体的借款活动相关联。

 

<a id="s146-chap_22_navPoint_58"></a>
### <a id="s146-FAQ_22.49.3"></a>FAQ 22.49.3 – 现金流量套期或公允价值套期关系对特定项目借款利息的影响是否应资本化计入不动产、厂场和设备的成本？

 

准则参考：IAS 23 第6段  
正文参考：[22.49](39.md#s142-Para_22.49) 

  

是的，符合条件的套期关系的目的是改变主体与特定债务相关的借款费用。主体在考虑套期会计的影响后，应当将处于符合条件的套期关系中的借款利息予以资本化。此类套期关系的无效部分应继续计入利润表。

 

<a id="s146-chap_22_navPoint_59"></a>
### <a id="s146-FAQ_22.49.4"></a>FAQ 22.49.4 – 根据IAS 23，管理层是否必须将借款的修改利得或损失资本化计入不动产、厂场和设备？

 

准则参考：IAS 23 第6、8段  
正文参考：[22.49](39.md#s142-Para_22.49) 

  

  
某主体有一笔专门借款用于为其符合资本化条件的资产融资。借款费用按照IAS 23予以资本化。该专门借款被修改，但修改方式并未导致终止确认。主体通过按原实际利率对修改后的新现金流量进行折现，重新计算了该贷款的账面价值。

根据IAS 23，管理层是否必须将借款的修改利得或损失资本化计入不动产、厂场和设备？

视情况而定。对于根据IAS 23对与符合资本化条件的资产相关的专门借款的修改利得或损失进行会计处理，存在两种可获支持的有效观点：

1）不予资本化：IAS 23第6段明确指出，“借款费用”包括“采用IFRS 9所述的实际利率法计算的利息费用”。我们可以对此作严格解释，认为任何修改利得或损失均不符合该定义，因此应计入损益。这也与IFRS 9第5.4.3段一致，该段明确规定修改利得或损失应计入损益；尽管该段提及的是金融资产的修改，但IFRS 9第BC4.253段指出，该要求同样适用于金融负债的修改。

2）予以资本化：另一种观点将修改利得或损失视为使用原实际利率折现现金流量的结果，因此属于应用实际利率法的一部分。IAS 23第6段中列举的可能借款费用清单也并非穷尽性的，因此根据IAS 23第5段，修改利得/损失可以作为“主体因借入资金而发生的其他费用”计入借款费用。

两种观点均可接受，因此应作出会计政策选择。该会计政策选择应对所有用于为符合资本化条件的资产融资的专门借款的修改利得或损失一贯应用。

如果采用第二种观点，则仅将与购置、建造或生产期间相关的部分予以资本化，其余部分计入损益。

### <a id="s146-EX22.51.1"></a>EX 22.51.1 – 作为借款费用资本化的外币汇兑差额的计量

 

准则参考：IAS 23 第6(e)段  
正文参考：[22.51](39.md#s142-Para_22.51) 

  

  
有两种方法用于估计可计入借款费用的外币汇兑差额金额，具体如下：

- 外币汇率变动中可资本化的部分可以根据贷款初始日的远期汇率进行估计；或

- 外币汇率变动中可资本化的部分可以根据主体记账本位币中类似借款的利率进行估计。

无论采用何种方法，主体将外币汇率变动的一部分识别为借款费用予以资本化的金额，均不得超过实际发生的成本总额。也可能存在其他方法。管理层应运用判断来评估哪些外币汇兑差额可以资本化。用于确定作为借款费用调整的金额的方法属于一项会计政策选择。该方法应对外币汇兑差额一贯应用，无论其为利得还是损失。

### <a id="s146-EX22.53.1"></a>EX 22.53.1 – 专门借款费用的资本化

### <a id="s146-EX22.53.2"></a>EX 22.53.2 – 将借款费用资本化计入不动产、厂场和设备时如何处理杠杆率

 

准则参考：IAS 23 第10段  
正文参考：[22.53](39.md#s142-Para_22.53) 

  

  
某主体使用一般借款和经营活动产生的现金为其符合资本化条件的资产融资。其资本结构为20%权益和80%流动及非流动负债（包括来自一般借款的有息债务）。借款利率应用于符合资本化条件的资产的全部账面价值，直至不超过实际发生的借款费用总额。不能主张只有80%的符合资本化条件的资产由借款融资，从而仅对符合资本化条件的资产金额的80%应用资本化率。

IAS 23不涉及实际或估算的资本成本。

### <a id="s146-EX22.55.1"></a>EX 22.55.1 – 由第三方建造的符合资本化条件的资产

 

准则参考：IAS 23 第17段  
正文参考：[22.55](39.md#s142-Para_22.55)  
 

  

  
第三方可能代表主体建造一项符合资本化条件的资产。所发生的借款费用按照与主体自行建造资产发生的借款费用相同的基础予以资本化。当满足以下三项条件时，资本化开始：

- 发生支出；

- 发生借款费用；以及

- 为使资产达到预定可使用或者可销售状态所必要的活动正在进行中。

20X9年3月，A主体向一家制造商订购了四架飞机，将于20Y2年至20Y6年期间交付。每架飞机在签订合同时均需支付首付款。每架飞机的剩余付款时间表根据各自预计交付日期而有所不同。A主体全部采用银行借款为所有付款融资。

A主体收到制造商的通知，称第一架飞机的零部件生产已于20Y0年2月开始。制造商尚未就其余三架飞机的生产采取任何行动。

飞机属于符合资本化条件的资产，因为其建造需要相当长时间才能完成。因此，A主体发生的借款费用应予以资本化。A主体通过支付预付款为飞机发生了支出。由于取得了银行借款，A主体也发生了借款费用。

借款费用的资本化自制造商开始建造活动时开始。建造活动（零部件生产）于20Y0年2月开始，但仅涉及其中一架飞机。因此，与这一架飞机相关的借款费用可自20Y0年2月起予以资本化。就其余三架飞机支付的预付款所发生的借款费用，在建造过程开始之前应予费用化。

### <a id="s146-EX22.58.1"></a>EX 22.58.1 – 资本化期间

 

准则参考：IAS 23 第20段  
正文参考：[22.58](39.md#s142-Para_22.58) 

  

  
A主体购买了一块原用于农业用途的土地，以建造一座新工厂。A主体已向地方当局申请将该土地的用途从农业用地变更为工业用地。该审批过程预计持续六个月，但A主体管理层确信将获得批准，因为新工厂将为该地区带来1,000个新就业岗位。

A主体使用一笔期限为七年的银行贷款为购地融资。

向地方当局申请变更土地用途是使资产达到预定可使用状态所必要的活动。因此，A主体在等待地方当局批准期间，可以将用于为购地融资的贷款所发生的借款费用予以资本化。

该结论基于地方当局将批准土地用途变更的预期。如果A主体在审批过程中获知不太可能获得批准，则应停止借款费用的资本化，并对该资产进行减值测试。

 

<a id="s146-chap_22_navPoint_67"></a>
### <a id="s146-EX22.58.2"></a>EX 22.58.2 – 建造活动中断期间的资本化

 

准则参考：IAS 23 第20段  
正文参考：[22.58](39.md#s142-Para_22.58) 

  

  
通常情况下，当建造活动停止时，利息资本化也随之停止。然而，当建造活动中断，且该中断是使资产达到预定可使用工作状态过程中必要且可预见的组成部分时，资本化可以继续进行。在冬季月份通常会出现中断，或因周期性且可预测的洪水导致建造活动中断期间，利息可以继续予以资本化。

建筑工人的长期罢工通常不被视为必要且可预见的。在较长期间的罢工期间，借款费用的资本化应当停止。同样，在导致建造工程较长期间中断的政治动荡情况下，也应暂停借款费用的资本化。

 

<a id="s146-chap_22_navPoint_68"></a>
### <a id="s146-FAQ_22.58.3"></a>FAQ 22.58.3 – 就IAS 23中暂停借款费用资本化而言，什么被视为“较长期间”？

 

准则参考：IAS 23 第20段  
正文参考：[22.58](39.md#s142-Para_22.58) 

  

 

可归属于符合资本化条件的资产的购置、建造或生产的借款费用应作为该资产成本的一部分予以资本化[IAS 23 第8段]。

 

由于重大地区性或全球性事件，政府可能会对商业活动施加限制。例如，政府行动可能涉及封锁限制，禁止开展建造等非必要服务。在其他情况下，主体可能处于减产状态，或暂时搁置某些资本项目，从而影响符合资本化条件的资产的开发/建造活动。

 

主体在较长期间内暂停符合资本化条件的资产的积极开发活动的，应当暂停借款费用的资本化[IAS 23 第20段]。IAS 23并未就何为“较长期间”提供指引。

 

如IAS 23第21段所述，如果建造活动中断，但该中止是该过程中必要且可预见的组成部分，则可以继续资本化借款费用。

 

引发政府限制及其相关封锁和/或限制的事件，不被视为使资产达到预定可使用或可销售状态过程的必要组成部分。在资产建造期间发生的相关活动中止也不被视为必要的。然而，“活动”一词涵盖的范围超出了资产的实体建造。如果大量技术和行政工作仍在继续进行，即使实体建造已经停止，借款费用的资本化仍应继续[IAS 23 第21段]。

 

评估这些事件和限制是否导致符合资本化条件的资产的积极开发活动在较长期间内停止，是一个判断问题。

 

在作出判断时可以考虑以下因素（非穷尽清单）：

 

- 尽管事件或限制可能是活动停止的最初原因，但管理层可能会考虑更新后的预算和修订后的商业计划，这可能导致活动延误的时间长于限制期本身。

- 需要考虑的是整个暂停期间，而不仅仅是政府施加限制的期间。此外，如果报告日落在活动停止的期间内，管理层可能需要估计活动可能何时恢复，而这可能要到下一个报告期间。需要考虑从暂停开始到预计活动恢复之间的期间。在预测预计延误时长时应保持审慎。管理层应考虑IAS 10《报告期后事项》的要求，特别是最新进展是否提供了有关报告日已存在情况的更多信息。[参见FAQ 9.5.5 – 报告日后影响以公允价值以外基础计量的非金融资产减值计算的事项应如何进行会计处理？](17.md#s57-FAQ_9.5.5)

- 在事件期间及任何限制期间仍在开展的活动的性质——即如果在限制期间仍在继续进行大量技术和行政工作，即使实体建造可能已暂停，借款费用仍很可能会继续资本化[IAS 23 第21段]。

- 预计延误时长相对于该特定资产通常预期建造期间的比例。预计延误时长相对于整个项目越短，借款费用就越有可能应当继续资本化。

- 限制期延长的可能性，或采取分阶段措施以允许开展部分建造工作的可能性。分阶段解除限制可能意味着使资产达到预定可使用状态的准备活动能够比等待限制全面解除更早恢复。

### <a id="s146-FAQ_22.59.1"></a>FAQ 22.59.1 – 资产何时“达到预定可使用状态”？

准则参考：IAS 23 第22段  
正文参考：[22.59](39.md#s142-Para_22.59) 

  

  
管理层应评估资产在购置日是否已“达到预定可使用或可销售状态”。根据管理层打算如何使用该资产，该资产可能属于符合资本化条件的资产。例如，当购入的资产只能与更大的一组固定资产结合使用（或专门为建造某项特定符合资本化条件的资产而购置）时，应对所购资产是否属于符合资本化条件的资产进行合并评估。

示例1 – 基于管理层意图的符合资本化条件的资产

一家电信主体购置了一项3G牌照。该牌照本可以出售或授权给第三方。然而，管理层打算用它来运营无线网络。网络开发自购置牌照时开始。该牌照是专门为运营无线网络而购置的。尽管牌照所涵盖的频谱已“达到预定可使用状态”，但其购置意图是将其与固定资产网络相结合。购置牌照是开发网络这一更广泛投资项目的第一步。该网络投资符合IAS 23下符合资本化条件的资产的定义。在开发期间，应对牌照成本的利息予以资本化。

示例2 – 作为符合资本化条件的资产的许可证

某主体为获取建造用作当地总部的办公楼的许可证而发生了费用。该许可证专门针对正在建造的建筑物。它是更广泛投资项目的第一步，构成该办公楼建造成本的一部分，而该办公楼符合符合资本化条件的资产的定义。在建造阶段，应对许可证成本的利息予以资本化。

### <a id="s146-EX22.60.1"></a>EX 22.60.1 – 分阶段建造的资产的利息资本化

 

准则参考：IAS 23 第24段  
正文参考：[22.60](39.md#s142-Para_22.60) 

  

  
一家零售门店可能分三个阶段建造：第一阶段建造停车场；第二阶段建造主体建筑；最后阶段建造和安装内部装修及固定装置。第一阶段完工后，停车场即提供给附近的剧院用作备用停车场。尽管第二阶段和第三阶段尚未完工，但与第一阶段相关的借款费用资本化应在停车场投入使用时停止。第一阶段正用于其预定用途，即提供停车设施。

与每一部分相关的借款费用资本化应在每一部分能够使用时停止，即使该部分尚未投入使用。然而，这不适用于在其他部分完工之前无法投入使用的资产部分——例如，如果零售门店按如下方式建造：第一阶段建造主体建筑及紧邻门店的主停车场；第二阶段建造内部装修及固定装置；最后阶段完工备用停车场。第一阶段（即基础建筑和初始停车场）在内部门店装修及固定装置完工前无法作为门店使用，因此，与第一阶段和第二阶段相关的借款费用资本化应在两个阶段均完工时停止，但无需等待第三阶段完工。

 

<a id="s146-chap_22_navPoint_71"></a>
### <a id="s146-EX22.60.2"></a>EX 22.60.2 – 分阶段完工的资产的利息资本化

 

准则参考：IAS 23 第24段  
正文参考：[22.60](39.md#s142-Para_22.60)  
 

  

  
电信主体A正在铺设其3G网络。A主体计划在实现60%人口覆盖率后开始提供3G服务。在持续18个月的铺设期内，A主体完成了基站铺设，测试了基站以及基站与核心网络之间的租用线路和微波链路。对网络基站的测试持续进行，直至A主体实现60%的人口覆盖率。对所有基站的某些最终测试刚好在商业发布前完成，对于确认网络的运营就绪至关重要。

A主体将从铺设开始直至确认网络整体运营就绪期间发生的借款费用予以资本化。尽管网络的各个部分是逐步建成的，且大部分网络测试也在18个月的铺设期内完成，但网络运营就绪的最终测试和签收直到A主体准备发布网络前夕才完成。

在覆盖60%人口的最终网络测试完成之前，网络资产尚未“达到管理层预定可使用状态”。其余40%部分的资本化将在该40%部分的建造活动开始时启动。

 

<a id="s146-chap_22_navPoint_72"></a>
### <a id="s146-EX22.60.3"></a>EX 22.60.3 – 土地的借款费用

 

准则参考：IAS 23 第24段  
正文参考：[22.60](39.md#s142-Para_22.60)  
 

  

  
A主体购置并开发土地，随后在该土地上建造一栋建筑物。土地和建筑物均符合符合资本化条件的资产的定义，且A主体使用一般借款为土地支出和建筑物建造提供资金。A主体应当在开始建造建筑物时停止对土地支出发生的借款费用予以资本化，还是应当在建造建筑物期间继续对土地支出发生的借款费用予以资本化？

2018年6月，国际财务报告准则解释委员会（IFRS IC）讨论了这一问题。解释委员会指出，A主体应考虑土地的预定用途——例如，土地和建筑物是打算用于自用、出租/资本增值还是出售。根据IAS 23第24段，A主体应考虑在建筑物仍在继续建造期间，土地是否能够用于其预定目的。如果土地无法用于其预定目的，A主体应将土地和建筑物合并考虑，以评估何时停止对土地支出的借款费用资本化。在这种情况下，在使土地和建筑物同时达到预定可使用或可销售状态所必要的几乎所有活动均完成之前，土地尚未达到预定可使用或可销售状态。基于上述讨论，A主体在建造建筑物期间将继续对土地开发支出发生的借款费用予以资本化，直至土地和建筑物均达到预定可使用或可销售状态。解释委员会最终决定不将该议题列入其议程。

 

<a id="s146-chap_22_navPoint_73"></a>
### <a id="s146-FAQ_22.60.4"></a>FAQ 22.60.4 – 为建造被视为存货的公寓楼而专门借入资金时，该安排是否产生可资本化利息的符合资本化条件的资产？

 

准则参考：IAS 23 第24段  
正文参考：[22.60](39.md#s142-Para_22.60)  

  

房地产开发商A主体正在建造一栋建筑物，并将建筑物中的单个单元出售给客户。A主体在动工前已与客户签订了出售部分单元的合同。对于这些单元，经确定应用IFRS 15第35(c)段，每个单元的控制权在一段时间内转移。对于尚未售出的单元，A主体已将其挂牌出售，一旦与客户签订合同，便会将部分建成的单元的控制权转移给客户。A主体预计将在近期就未售出单元签订合同，且这些合同也将导致控制权在一段时间内转移。

在此安排下，就已售单元确认的任何应收款项或IFRS 15合同资产均不属于IAS 23范围内的符合资本化条件的资产。在建未售单元的任何存货（在产品）也不属于符合资本化条件的资产，因为这些单元在当前状态下已达到可销售状态（即主体一旦找到合适客户就打算出售部分建成的单元，并在与客户签订合同时将任何在产品的控制权转移给客户）。

在另一种情况下（例如，主体与客户签订在建造完工时转移控制权的合同），这些单元很可能符合符合资本化条件的资产的定义，因此利息将予以资本化。对于建筑物所在土地的成本是否可以资本化利息，需要根据具体事实和情况运用判断。主体在确定土地是否符合符合资本化条件的资产的定义时，应考虑土地控制权何时转移。

 

<a id="s146-chap_22_navPoint_74"></a>
### <a id="s146-EX22.61.1"></a>EX 22.61.1 - 因重大事件引发的政府法规导致开发不动产、厂场和设备及投资性房地产发生额外成本的资本化

 

准则参考：IAS 16 第16、22段  
正文参考：[22.62](39.md#s142-Para_22.62)

  

 

由于（本地或其他国家的）重大事件，政府应对措施可能对经营活动施加了限制，包括影响不动产、厂场和设备（PPE）及投资性房地产建造的限制。即使建造活动可能受限或暂停，主体仍可能继续发生与建造相关的成本。主体也可能继续建造，并因限制措施和/或健康与安全合规要求而发生额外成本。这些成本可能发生在内部（例如项目经理的薪酬）和/或外部（例如建筑合同允许的承包商转嫁费用）。

 

主体应如何对开发PPE和投资性房地产发生的这些额外成本进行会计处理？

 

IAS 16第16段和IAS 40第21段分别讨论了PPE和投资性房地产的成本构成。两项准则均要求主体将购买价款以及直接归属于资产购置/建造的支出予以资本化。主体应评估特定情况下发生成本的性质，以确定这些成本是否直接归属于资产。

 

IAS 16第22段和IAS 40第23段进一步要求主体将非正常浪费的材料、人工或其他资源在发生时费用化。国际财务报告准则对“非正常”没有具体定义。主体应评估所发生成本的性质、其运营所在地区以及与其他主体的比较，以确定这些成本是否属于非正常成本。评估所发生的额外成本是否属于非正常成本可能需要运用判断，尤其是对于人工和间接费用而言。对于支付给第三方建造商的成本，评估通常较不需要过多判断。这是因为这些成本很可能是各方在公平交易基础上协商一致的，因此不太可能代表客户不愿支付的浪费材料。

 

将这些原则应用于外购资产和自建资产时，主体可以资本化的成本包括但不限于：

 

- 与未受该事件影响的原计划活动相关的某些项目管理成本，前提是这些成本仍然直接归属于在建资产；以及

- 为遵守当地持续的健康与安全要求而发生的、为完成建造所必需的额外人工成本。

 

主体不应资本化的成本包括但不限于：

 

- 差错（例如设计错误）；

- 位于建筑工地的某些设备在事件期间建造暂停时继续发生的存储和租赁成本，因为它们不再属于直接归属成本；以及

- 管理层认定并非专门与资产建造相关、而是属于开展业务成本一部分（即行政管理费或其他一般间接费用）的、为遵守持续健康与安全要求而发生的额外间接人工成本。

 

[有关借款费用资本化的考虑因素详情，参见FAQ 22.58.3](39.md#s146-FAQ_22.58.3)。

 

以下三个示例进一步说明了上述原则的应用方式。

 

示例1 – 主体保留的闲置工人

 

某主体正在进行一座新总部大楼的建造项目。由于政府法规，该主体在法律上仅被允许在工地上安排有限数量的工人，少于正常运营条件下的数量。这导致部分工人处于闲置状态。主体预计相关要求将在近期放宽，因此决定不解雇闲置工人。

 

在这种情况下，闲置工人的人工成本应在发生时费用化，因为这些成本不符合直接归属的标准。

 

示例2 – 外包建造项目

 

某主体委托第三方代建一座新总部大楼。由于政府法规，第三方建筑公司在法律上仅被允许在工地上安排有限数量的工人，少于正常运营条件下的数量。由于预计工期将长于最初预期，建造项目的总成本有所增加。

 

因建造办公楼所需额外时间而产生的成本应当予以资本化，因为根据费用的性质，它们属于直接归属成本，而非非正常成本。

 

示例3 – 额外的健康与安全相关成本

 

某主体有一个正在进行的PPE建造项目。该主体运营所在地区的政府因政府法规强制要求采取额外的健康与安全措施。工地工作人员必须配备口罩和其他个人防护装备。

 

这些成本直接归属于建筑物的建造。在该地区开展类似建造项目的任何主体都会发生此类成本，因此它们不属于非正常成本。故此，这些成本应当予以资本化。

 

<a id="s146-chap_22_navPoint_75"></a>
### <a id="s146-EX22.62.1"></a>EX 22.62.1 – 安全或环保法规设备的初始成本

 

准则参考：IAS 16 第11段  
正文参考：[22.62](39.md#s142-Para_22.62)  
 

  

  
主体购置的某些不动产、厂场和设备项目本身可能不产生经济利益，但却是使其他资产产生经济利益所必需的。例如，为确保安全或遵守环保法规所必需的资产。由于这些资产使其他资产能够产生经济利益，因此予以确认。然而，应对这些资产及相关资产最终形成的账面价值进行减值复核，以确保合并后的账面价值不超过合并后的可收回金额。例如，一家化学品制造商为遵守环保要求必须安装新的化学品处理工艺设备。这些厂房改进支出在其可收回的范围内（与相关化工厂合并考虑时）予以资本化，因为没有它们，主体就无法生产和销售化学品。

 

<a id="s146-chap_22_navPoint_76"></a>
### <a id="s146-EX22.62.2"></a>EX 22.62.2 – 超市翻新成本的资本化

 

准则参考：IAS 16 第11段  
正文参考：[22.62](39.md#s142-Para_22.62) 

  

  
连锁超市A主体正在翻新其一家主要门店。翻新后，该门店将拥有更多可用于店内促销柜台的可用空间，并将增设一家餐厅。

管理层正在编制门店重新开业后一年的预算，其中包括改造成本，以及预计门店翻新将吸引新顾客从而带来销售额增长15%。

翻新门店的支出将创造未来经济利益（表现为销售额增长15%），且改造成本能够可靠计量，因此应当予以资本化。

 

<a id="s146-chap_22_navPoint_77"></a>
### <a id="s146-EX22.62.3"></a>EX 22.62.3 – 后续支出与很可能流入的未来经济利益

 

准则参考：IAS 16 第11段  
正文参考：[22.62](39.md#s142-Para_22.62) 

  

  
某些后续支出应当资本化还是费用化可能显而易见。例如，为酒店增建新翼楼的成本应当予以资本化。新增客房提高了酒店的创收能力，因此未来经济利益很可能流入，且成本能够可靠计量。相比之下，酒店的清洁费用是维护酒店的期间成本，应在发生时费用化。然而，有些支出介于这两个极端之间，需要运用判断以确定此类支出应予以资本化还是费用化。

 

<a id="s146-chap_22_navPoint_78"></a>
### <a id="s146-EX22.64.1"></a>EX 22.64.1 – 强制性重大定期检查和大修作为一个组成部分

 

准则参考：IAS 16 第14段  
正文参考：[22.64](39.md#s142-Para_22.64) 

  

  
法律可能要求飞机每三年进行一次重大定期检查/大修。如果相当于预期大修成本的那部分资产成本占该资产总成本的重大比例，则将其识别出来并在至下一次检查/大修的期间内计提折旧。随后，只要未来经济利益很可能流入主体且成本能够可靠计量，大修或检查的实际成本即予以资本化。该检查/大修成本随后在至下一次检查/大修的期间内计提折旧。一旦新的大修成本予以资本化，原归属于大修的成本和折旧即予以终止确认，以避免重复计算。在按期进行适当大修的基础上，资产的其余部分在资产的整个使用寿命内计提折旧。

<a id="s146-chap_22_navPoint_80"></a>
### <a id="s146-EX22.71.1"></a>EX 22.71.1 – 为应用重估模式界定资产类别

 

准则参考：IAS 16 第38段  
正文参考：[22.71](39.md#s143-Para_22.71) 

  

  
A主体是一家大型制造集团。它拥有若干工业建筑物（如工厂和仓库），以及位于多个首都城市的办公楼。工业建筑物位于工业区，而办公楼位于城市的中央商务区。A主体管理层希望对办公楼的后续计量采用IAS 16的重估模式，同时继续对工业建筑物采用历史成本模式。这在IAS 16下是否可以接受？

A主体可以仅对办公楼采用重估模式。办公楼在功能、性质和总体地理位置方面均可以与工业建筑物明确区分。IAS 16允许按类别对资产进行重估。这些建筑物的不同特征使其能够被划分为不同类别的不动产、厂场和设备。因此，可以对这些类别采用不同的后续计量模式。故此，办公楼类别内的所有物业均必须按重估金额列账，且必须对这两个类别分别进行披露。

 

<a id="s146-chap_22_navPoint_81"></a>
### <a id="s146-FAQ_22.71.2"></a>FAQ 22.71.2 – 企业合并如何影响固定资产的定期重估？

准则参考：IAS 16 第38段  
正文参考：[22.71](39.md#s143-Para_22.71) 

  

  
A主体正在收购B主体，B主体拥有与A主体已拥有的固定资产属于类似类别的固定资产。通常，当固定资产进行重估时，该类别的所有资产都必须重估。这是否意味着，当主体对被收购子公司的固定资产按公允价值计量时，它必须对其自身属于同一类别的固定资产进行重估？

收购日的公允价值对集团而言是所收购固定资产的成本，因此从集团角度来看并未发生重估。故此，集团持有的同一类别的现有有形固定资产无需进行重估。

### <a id="s146-EX22.80.1"></a>EX 22.80.1 – 复原义务与土地成本的折旧

垃圾填埋场在不再使用时需要进行复原。复原场地的义务成本应在向场地倾倒垃圾的期间内计提折旧。该场地本身对垃圾填埋场运营方而言具有有限使用寿命，其残值将远低于其原始成本。土地成本也应在该场地的使用寿命内折旧至其残值。

 

<a id="s146-chap_22_navPoint_86"></a>
### <a id="s146-EX22.83.1"></a>EX 22.83.1 – 某些资产不计提折旧的情况

 

准则参考：IAS 16 第52段  
正文参考：[22.83](39.md#s143-Para_22.83)  

  

  
一个颇具挑战性的问题是，对某些资产不计提年度折旧费用是否恰当。该问题最常出现在建筑物方面。当建筑物的残值超过其账面价值时，不记录折旧费用可能是恰当的。

一家公司于20X6年以C100万的成本购买了一处物业。该物业的预计总物理寿命为50年。然而，该公司认为很可能在20年后出售该物业。根据20X6年价格，20年后的估计残值为（a）C100万，或（b）C900,000。残值等于或接近原始成本的情况十分罕见，因为这假定20年后的潜在买方愿意为一处20年房龄的物业支付与新物业相近的金额。

在情形（a）中，公司认为基于资产负债表日现行价格的残值将等于成本。因此不存在可折旧金额，折旧正确地为零。

在情形（b）中，公司认为基于资产负债表日现行价格的残值将为C900,000；因此可折旧金额为C100,000。年度折旧（按直线法）将为C5,000（(1,000,000 − 900,000) / 20）。

 

<a id="s146-chap_22_navPoint_87"></a>
### <a id="s146-EX22.83.2"></a>EX 22.83.2 – 当重置支出等于年度折旧费用时的折旧

 

准则参考：IAS 16 第52段  
正文参考：[22.83](39.md#s143-Para_22.83)  
 

  

  
某主体经营多家酒店。酒店设备（如床上用品和餐具）的总账面价值年复一年保持稳定。所有设备每隔几年就会更换一次，以确保维持高标准。管理层推行了滚动更换计划，使得重置资产的成本每年保持在稳定水平。

管理层希望减少行政管理工作，提议不再对酒店设备计提折旧，而是每年将重置成本费用化。

主体应当将使用寿命超过一年的所有资产予以资本化，并在其使用寿命内计提折旧。出于效率考虑，管理层可以将成组的类似资产作为单项资产予以资本化，然后如同单项资产一样计算这些资产的折旧。

拟议的将年内购买的所有重置资产费用化、且不对已资本化资产计提折旧的政策是不恰当的。

 

<a id="s146-chap_22_navPoint_88"></a>
### <a id="s146-EX22.84.1"></a>EX 22.84.1 – 折旧资本化计入另一项资产的成本

 

准则参考：IAS 16 第49段  
正文参考：[22.84](39.md#s143-Para_22.84) 

  

  
一家矿业公司为挖掘新矿山而购置了土方设备。因此，该设备的折旧是挖掘该矿山的直接归属成本。该设备的折旧费用应当作为矿山成本的一部分予以资本化。用于开发活动的设备的折旧可根据IAS 38计入无形资产的成本。

 

<a id="s146-chap_22_navPoint_89"></a>
### <a id="s146-EX22.84.2"></a>EX 22.84.2 – 计入另一项资产生产成本的折旧费用

 

准则参考：IAS 16 第49段  
正文参考：[22.84](39.md#s143-Para_22.84) 

  

  
A主体为汽车行业制造汽车零部件，并在其生产过程中使用部分自制模具工具。A主体的客户（汽车制造商）不断推出新车型或重新设计现有车型。因此，A主体必须不断开发新工具用于其生产过程。

这些工具的成本予以资本化，并在三年（即工具的预计使用寿命）内计提折旧。

A主体拥有一座厂房，所有生产均在该厂房内进行。该厂房的10%用于开发和制造工具。该建筑物采用直线法计提折旧。

主体应将厂房折旧费用的10%计入工具的成本，并予以资本化和计提折旧。厂房的折旧费用构成生产工具成本的一部分。

### <a id="s146-EX22.87.1"></a>EX 22.87.1 – 土地的可折旧组成部分

 

准则参考：IAS 16 第58段  
正文参考：[22.87](39.md#s143-Para_22.87) 

  

  
土地资产的账面价值可能包括场地拆卸、移除和复原成本。复原成本组成部分应在从该土地获取经济利益的期间内计提折旧。土地本身在某些情况下可能具有有限使用寿命，在此情况下应在该使用寿命内计提折旧。一个例子是需要复原的垃圾填埋场。复原场地的义务成本可以在向场地倾倒垃圾的期间内计提折旧。场地本身对垃圾填埋场运营方而言可能具有有限使用寿命，其残值可能远低于原始成本。土地成本也应在该场地的使用寿命内折旧至其残值。

### <a id="s146-EX22.89.1"></a>EX 22.89.1 – 资产达到预定可使用状态时开始计提折旧

 

准则参考：IAS 16 第57段  
正文参考：[22.89](39.md#s143-Para_22.89) 

  

  
B主体自建了一台自用机器。建造工作于20X6年11月1日完成，但主体直到20X7年3月1日才开始使用该机器。

主体应自机器达到预定可使用状态之日（即20X6年11月1日）起开始计提折旧。机器在达到预定可使用状态后有一段时间未被使用，这一事实在考虑何时开始计提折旧时不具有相关性。

 

<a id="s146-chap_22_navPoint_92"></a>
### <a id="s146-EX22.89.2"></a>EX 22.89.2 – 资产处于使用中时的折旧

 

准则参考：IAS 16 第57段  
正文参考：[22.89](39.md#s143-Para_22.89) 

  

  
C主体于20X1年6月以C10,000万（C100m）的原始成本购置了一座厂房，预计使用寿命为20年，残值为零。20X6年6月，由于产品需求下滑，账面净值为C7,500万（C75m）的该厂房被关闭。C主体根据已制定的出售计划，确定该厂房符合IFRS 5划分为持有待售的标准。20X6年确认了C5,000万（C50m）的减值费用，将厂房减记至公允价值减去出售费用后的净额C2,500万（C25m），并停止计提折旧。然而，20X6年12月，需求意外上升并超过了当前产能。管理层决定放弃出售计划并重新启用该厂房。预计未来现金流量足以证明转回原C5,000万（C50m）的全部减值是合理的。重新启用预计耗时六个月，至20X7年6月完成。

主体将转回先前的减值C5,000万（C50m），并扣除20X6年6月至20X7年6月资产闲置期间本应计提的折旧C500万（C5m）。厂房的账面净值C7,000万（C70m，即C25m + C50m − C5m）将在其剩余14年的预计使用寿命内计提折旧。

 

<a id="s146-chap_22_navPoint_93"></a>
### <a id="s146-EX22.89.3"></a>EX 22.89.3 – 折旧期间

 

准则参考：IAS 16 第43段  
正文参考：[22.89](39.md#s143-Para_22.89) 

  

  
A主体正在考虑采用一项政策：对当年资本化的不动产、厂场和设备在次年才开始计提折旧，但在资产处置当年计提全年折旧。这是否可以接受？

有形固定资产的可折旧金额应在其使用寿命内系统地分摊。折旧方法应反映主体预期消耗该资产未来经济利益的方式。“使用寿命”是指主体预期可使用该资产的期间。折旧应在资产购置并可供使用时立即开始。A主体应在使用期间内对资产计提折旧。

 

<a id="s146-chap_22_navPoint_94"></a>
### <a id="s146-EX22.89.4"></a>EX 22.89.4 – 租赁改良支出的使用寿命

 

准则参考：IAS 16 第56(d)、57段    
正文参考：[22.89](39.md#s143-Para_22.89) 

  

  
A主体签订了一份为期九年的租赁协议，并拥有再续租六年的权利。在租赁期开始日，A主体并未合理确定将行使续租选择权，因此确定租赁期为九年。A主体将进行重大租赁改良以符合其品牌标准。这些租赁改良的预计使用寿命为10年。

IAS 16第56(d)段规定，在确定资产的使用寿命时，应考虑对资产使用的法律或类似限制，例如相关租赁的到期日。因此，通常预期租赁改良的使用寿命（即折旧期间）与IFRS 16下的租赁期相同。但是，在某些情况下，租赁改良的使用寿命可能超过经评估的租赁期（例如，管理层将在租赁期满时拆除并重新部署该租赁改良）。

2019年11月发布的国际财务报告准则解释委员会（IFRS IC）议程决定探讨了任何相关的不可移除租赁改良的使用寿命是否受限于应用IFRS 16确定的租赁期这一问题。IFRIC议程决定确认，报告主体在确定不可移除租赁改良的使用寿命时应适用IAS 16第56至57段。如果相关租赁的租赁期短于这些租赁改良的经济寿命，报告主体应考虑其是否预期在租赁期之后继续使用该租赁改良；如果不是，则根据IAS 16第57段，不可移除租赁改良的使用寿命应被视为与租赁期相同。委员会指出，应用IAS 16第56至57段，对于主体仅在使用租赁标的资产期间方能使用并从中获益的租赁改良，主体通常会得出这一结论。

有关该议程决定就租赁期与租赁改良使用寿命之间相互作用所提供的指引，参见[第15.37段](33.md#s107-Para_15.37)。

 

<a id="s146-chap_22_navPoint_95"></a>
### <a id="s146-FAQ_22.92.1"></a>FAQ 22.92.1 – 如果资产处于闲置状态，主体可以停止计提折旧吗？

 

准则参考：IAS 16 第55段  
正文参考：[22.92](39.md#s143-Para_22.92)  

  

 

不可以，当资产处于闲置状态时，折旧并不停止[IAS 16 第55段]。如果某项资产按直线法计提折旧，在其闲置期间仍将继续计提折旧。如果某项资产采用工作量法计提折旧，则在没有生产时，折旧费用可以为零。

 

<a id="s146-chap_22_navPoint_96"></a>
### <a id="s146-EX22.94.1"></a>EX 22.94.1 – 折旧方法

 

准则参考：IAS 16 第62段  
正文参考：[22.94](39.md#s143-Para_22.94) 

  

  
直线法是实务中最常用的方法，因为参照时间期间评估使用寿命可能更容易。然而，使用量可能是更可靠的计量形式。成本或重估金额减去估计残值后在使用寿命内分摊，从而在资产的使用寿命内系统地计入每个会计期间。

除直线法外，还有多种不同的折旧确定方法。这些方法可能基于使用量分摊可折旧金额（如工作量法），或旨在资产使用早期计提较高的折旧金额。常见方法包括余额递减法、工作量法、年数总和法和数字总和法。当资产在其使用寿命早期消耗经济利益更快时，采用加速折旧法是恰当的。资产可能会变得不那么可靠且更容易发生故障、生产高质量产品的能力下降或技术在逐渐落后。资产产出价格下跌是需要考虑的一个因素，但其本身并不要求必须采用加速折旧法。本示例将讨论其中若干种方法。

**逆向余额递减法：** 逆向余额递减法并非常用的折旧方法。它会导致折旧费用随时间推移而增加。当资产主要通过耗用被消耗，且初期产量处于较低水平但随时间逐步攀升时，该方法可能是恰当的。然而，此类情况较为罕见，采用工作量法计提折旧可能更为恰当，因为它反映了资产经济利益的消耗情况。

**年数总和法（数字总和法）**：该方法在效果上与余额递减法相似，尽管计算机制不同。如果某项资产预计可使用（例如）12个期间（年、月等），则将数字1至12相加（合计78）；第1期计提12/78，下一期计提11/78，依此类推。

**工作量法（或产量法）：** 该方法将折旧与资产的估计使用量或产出挂钩。每小时使用量或每单位产出的折旧率通过将可折旧金额除以资产的估计总服务能力（按小时或单位计量）得出。当资产的使用量在各期间差异很大时，有时会采用该方法，以更好地计量经济利益的消耗。常采用这种方式计提折旧的资产类型示例包括：按小时计费率的航空发动机；以及按产量计提的垃圾填埋场和自然资源。

**示例——基于工作量法计提的折旧**

一台机器的成本为C100,000，预计残值为C10,000。该机器的预计总使用时间为500,000小时。因此，每小时使用量的折旧率为C0.18（(C100,000 − C10,000) 除以 500,000）。

**示例——基于估计使用量计提的折旧**

购置一处垃圾填埋场发生C500万的成本。该垃圾填埋场拥有200万立方米的空间。适用于该场地成本的折旧率计算为每使用1立方米空间C2.5。第一年使用了200,000立方米，按每立方米C2.5计提的折旧为C500,000。

 

<a id="s146-chap_22_navPoint_97"></a>
### <a id="s146-EX22.94.2"></a>EX 22.94.2 – 主体可以变更为采用“工作量法”计算折旧吗？

 

示例A

 

A主体拥有并运营一家地方航空公司。飞机发动机在必须更换之前可飞行5,000个飞行小时。该主体计划在更换前充分利用发动机固有的5,000个小时。飞机每年的飞行里程保持一致。A主体确定按飞行小时（工作量法）对发动机计提折旧最恰当地反映了经济利益的消耗方式。然而，由于每年的飞行小时数基本一致，A主体采用直线法折旧作为飞行小时的替代方法。

 

在某一季度，由于实施了旅行限制，A主体的机队停飞。目前尚不清楚这些限制何时解除。A主体在季度末重新评估折旧方法，并确定直线法现在不再是工作量法的合理替代方法。此外，A主体确定直线法不再反映资产所包含经济利益的消耗。因此，管理层将其折旧方法变更为工作量法，并遵循IAS 8中关于会计估计变更的要求。

 

一旦封锁结束，A主体不太可能就这些资产将其折旧方法改回直线法。这是因为工作量法将继续反映发动机所包含经济利益的预期消耗方式。

 

示例B

 

B主体拥有并运营一家地方航空公司。飞机发动机在必须更换之前可飞行5,000个飞行小时，这足以覆盖七年的飞行航线。然而，该主体的政策是无论飞行小时数多少，每五年更换一次发动机。因此，B主体确定发动机的经济利益受时间限制，直线法折旧是最恰当的折旧方法。

 

在某一季度，由于实施了旅行限制，B主体的机队停飞。目前尚不清楚这些限制何时解除。遵循其每五年更换一次发动机的政策，B主体仍认为发动机的使用寿命为五年。鉴于B主体已确定发动机的经济利益受时间限制，变更为工作量法计提折旧是不恰当的。B主体应在飞机停飞期间继续计提折旧。

 

示例C

 

政府实施了封锁措施，因此承租人C无法开业其租赁门店。此外，进入该门店受到极大限制，承租人C不被允许在门店内进行任何翻新工作，也不被允许将该门店用作线上销售的仓库；但承租人C的商品仍存放在该场所内。承租人C在租赁期内按直线法对其使用权资产计提折旧，因为该方法最密切地反映了租赁资产所包含的未来经济利益的预期消耗方式；对于该使用权资产，主要的限制因素是承租人在租赁期内享有使用标的资产的合同权利的时间期限。  

 

在封锁期间，承租人C停止对该资产计提折旧或变更其折旧方法都是不恰当的。这是因为在直线法折旧下，资产闲置时折旧并不停止[IAS 16 第55段]。 

 

<a id="s146-chap_22_navPoint_98"></a>
### <a id="s146-EX22.98.1"></a>EX 22.98.1 – 确定恰当的折旧方法

 

准则参考：IAS 16 第56段  
正文参考：[22.98](39.md#s143-Para_22.98) 

  

  
B主体制造工业化学品，并在生产过程中使用混合机。混合机的产量年复一年保持稳定，且该机器可用于生产不同产品。然而，维护成本逐年增加，而且每隔五年就会推出新一代机器（较现有机器有重大改进）。

管理层应根据产量确定折旧方法。由于产量年复一年保持稳定，直线法折旧可能是基于使用量方法的合理替代方法。

在确定混合机的使用寿命时，应考虑维护成本或技术陈旧过时等因素。

 

<a id="s146-chap_22_navPoint_99"></a>
### <a id="s146-EX22.99.1"></a>EX 22.99.1 – 重估资产的折旧基础

 

准则参考：IAS 16 第48段  
正文参考：[22.99](39.md#s143-Para_22.99) 

  

  
本准则未规定应以何种资产价值作为计算年度折旧费用的基础。年度平均值可能是最佳计量方式，但在实务中，只要在每个期间一贯使用，期初余额或期末余额均可使用。在确定当年的折旧费用时，最常用的是期初余额加上后续新增资产的成本。这避免了重新计算年初已计提并已用于（例如）中期报告的折旧。然而，如果年末重估导致价值发生重大变动，则可能会产生问题。

 

<a id="s146-chap_22_navPoint_100"></a>
### <a id="s146-EX22.100.1"></a>EX 22.100.1 – 使用寿命估计的变更

 

准则参考：IAS 16 第51段  
正文参考：[22.100](39.md#s143-Para_22.100) 

  

  
A主体于20X0年1月1日以C100,000购买了一项资产，该资产的预计使用寿命为10年，残值为零。该主体一直采用直线法按每年C10,000计提折旧。20X4年1月1日，当该资产的账面净值为C60,000时，董事们复核了预计使用寿命，并认为该资产可能还能再使用四年，从而将总使用寿命修订为八年。该主体应修订年度折旧计提额，将未摊销成本（即C60,000）在修订后的剩余四年使用寿命内分摊。因此，未来四年应按每年C15,000计提折旧。

或者，假设使用寿命仍为10年，该主体可能决定自20X4年1月1日起，采用年数总和法（数字总和法）计算将比直线法更公允地列报。如果是这样，由于该资产仍有六年的剩余使用寿命，20X4年的折旧费用将为C17,143（即C60,000 × 6 / (6 + 5 + 4 + 3 + 2 + 1)）。

 

<a id="s146-chap_22_navPoint_101"></a>
### <a id="s146-EX22.100.2"></a>EX 22.100.2 – 购入固定资产使用寿命的缩短

 

准则参考：IAS 16 第51段  
正文参考：[22.100](39.md#s143-Para_22.100) 

  

  
A主体在年内进行了一项收购。被收购主体拥有一套大型计算机系统，收购方现在打算在几年后将其更换。该计算机设备的公允价值在收购日已确定，而决定更换它属于收购后事项。管理层希望立即计提额外折旧，并将其列报为与该收购相关的特殊项目。这是否恰当？

更换计算机系统的决定属于收购后决策。它不影响在购买对价分摊中所分配的公允价值。即使在作出该决定后，也不会立即产生减值，因为现金产出单元的未来现金流量能够支持其资产的账面价值。然而，由于已决定在几年后报废该设备，其账面价值现在应在修订后较短的使用寿命内计提折旧。残值和使用寿命至少必须在每个财务年度终了进行复核。如果任一项被修订，该变更应作为会计估计变更采用未来适用法进行会计处理。

 

<a id="s146-chap_22_navPoint_102"></a>
### <a id="s146-FAQ_22.100.3"></a>FAQ 22.100.3 – 气候相关因素如何影响资产的使用寿命和残值？

 

准则参考：IAS 16 第51段  
正文参考：[22.100](39.md#s143-Para_22.100)  

  

 

由于气候变化（无论是自然气候事件还是政府行动的结果），可能需要重新评估厂场和设备的使用寿命和残值。例如，消费者行为的变化或碳排放相关法规的出台，可能会影响IAS 16范围内多项资产的使用寿命和/或残值。气候影响可能导致资产提前陈旧过时、对其使用施加法律限制，或导致资产无法使用。以下示例说明了气候变化的可能影响。

 

 

  

全球邮轮航运公司ABC plc.正在考虑环保法规变化对其业务的影响。相当数量的港口已经禁止较旧及高排放的邮轮入港，且该公司预计未来此类港口的数量将会增加。事实上，该公司预计欧洲和北美等整个地区将在未来十年内禁止使用船用重油的邮轮进入其港口。

为了继续在这些地区开展业务，该公司被迫在未来十年内以污染更低的船舶替换现有船队。

由于即将出台的法规和船队替换计划，该公司可能需要缩短其船舶的使用寿命并降低其残值，因为该公司预计较旧及高排放船舶在二手市场上的价格将会下跌。

  

 

在重新评估厂场和设备的使用寿命和残值时，主体可能会考虑气候相关因素，例如：

 

- 行业法规的（潜在）变化；

- 公司、同行群体及整个行业作出的排放承诺；

- 消费者行为的（潜在）变化；

- 技术的（潜在）变化（例如新能源的使用）；以及

- 厂场和设备在其使用寿命结束时的役龄，以及它们对其他公司是否仍可能具有经济利益。

 

主体还应考虑资产使用寿命或残值的变化是否导致该资产所属现金产出单元出现减值迹象（参见IAS 36 第12段）。

 

**披露要求**

 

资产使用寿命和/或残值的变更属于会计估计变更，需要按照IAS 16和IAS 8的要求采用未来适用法处理。会计估计变更需要按照IAS 8第39段予以披露。披露内容应包括作出变更的原因以及会计估计变更的性质和金额（参见[第3.30段](09.md#s21-Para_3.30)及后续段落）。

 

如果存在重大估计不确定性，主体应按照IAS 1第125段和第129段披露重新评估使用寿命/残值所依据假设的性质详情，包括估计不确定性的来源和敏感性分析（参见[第4.155段](10.md#s29-Para_4.155)及后续段落）。

 

<a id="s146-chap_22_navPoint_103"></a>
### <a id="s146-EX22.101.1"></a>EX 22.101.1 – 修订资产的残值

 

准则参考：IAS 16 第54段  
正文参考：[22.101](39.md#s143-Para_22.101)   

  

20X1年1月1日，一家财务年度截止日为12月31日的主体以C1,000购买了一项资产，预计使用寿命为六年。该资产在购置日的估计残值为C100，截至第2年末该估计未发生变化。由于技术的突破性进步，残值有所下降；截至20X3年10月31日，估计残值为C81。经开展减值评估，未发现减值。

在就修订后的残值作出任何调整之前，20X3年10月31日的账面价值为C575（即34个月内每月计提折旧C12.50）。从账面价值中扣除修订后的残值后，剩余C494（即C575 − C81）将在剩余三年零两个月的使用寿命内计提折旧。因此，20X3年最后两个月的折旧为C26，20X3年末的账面价值为C549。

当对残值作出新估计时，这可能会对当年及未来年度的折旧费用产生影响[IAS 8 第38段]。如果重新估计并非由特定事件驱动而是在年末进行的（这是最低要求），则需要运用判断以确定年内是否存在残值发生变化的更早时点。

在某个时点，修订后的残值可能会超过账面价值。在这种情况下，折旧费用调整为零，且任何超出部分不予转回。如果在处置时销售收入超过当时的账面价值，则可能确认处置利得。

 

<a id="s146-chap_22_navPoint_104"></a>
### <a id="s146-EX22.104.1"></a>EX 22.104.1 – 投保资产重置产生的利得

 

准则参考：IAS 16 第65段  
正文参考：[22.104](39.md#s144-Para_22.104) 

  

  
A主体账面列示的厂房和机器设备价值为C200,000。这些厂房和机器设备在火灾中被毁。这些资产投保了“以新换旧”险，保险公司用成本为C200万的新机器予以替换。替换机器由保险公司采购，主体并未收到C200万的现金赔偿。

A主体在终止确认厂房和机器设备的账面价值时将损失计入利润表。一旦收款基本确定，A主体应按照IAS 37在利润表中单独确认一项应收款项以及由保险赔偿产生的利得。该应收款项应按保险人将提供的资产的公允价值计量。

 

<a id="s146-chap_22_navPoint_105"></a>
### <a id="s146-EX22.105.1"></a>EX 22.105.1 – 保险赔偿的不确定性

 

准则参考：IAS 16 第65段  
正文参考：[22.105](39.md#s144-Para_22.105) 

  

  
一项资产在火灾中被毁并已提出保险索赔。对于该资产的损失是否在保险单承保范围内存在不确定性。该补偿属于一项或有资产。然而，如果保险公司接受索赔并同意支付赔偿，则该资产不再是或有资产，该补偿应计入利润表。
