## 引言与适用范围（第51.1至51.4段）

<a id="s349-chap_51_navPoint_2"></a>
### 引言与适用范围

<a id="s349-Para_51.1"></a>**51.1** 本章涵盖股本、储备和库存股的一般会计处理与披露要求。国际财务报告准则在某些领域提供的指引有限。相反，在某些司法管辖区，当地法律要求可能决定了具体的会计处理与披露要求。

<a id="s349-Para_51.2"></a>**51.2** 资产、负债和权益是用于计量财务状况的三个要素。“权益”是指扣除主体所有负债后在主体资产中的剩余权益，等于其净资产。

[IAS 32 第11段]。

<a id="s349-Para_51.3"></a>**51.3** IAS 32 对权益的初始确认和计量没有具体规定。在许多情况下，权益按发行所得款项扣除交易费用后的净额入账，且后续不再重新计量。

<a id="s349-chap_51_navPoint_3"></a>
### 权益的性质与特征

<a id="s349-chap_51_navPoint_4"></a>
### 股本与储备的类型

<a id="s349-Para_51.4"></a>**51.4** IAS 32 就股份分类为权益或债务提供了指引。会计结论可能与股份的法律形式不同，因为法律形式可能是依据当地法规确定的。关于在 IAS 32 和 IFRIC 2 下将股份分类为债务或权益及其会计处理的指引，详见[第43章第3段](67.md#s275-Para_43.3)。

[IAS 32 第2段]。

## 与股东交易产生的权益（第51.5至51.39段）

<a id="s350-chap_51_navPoint_6"></a>
### 作为权益核算的股本

<a id="s350-Para_51.5"></a>**51.5** IAS 32 未就权益的初始确认或计量提供指引。发行权益股份导致的权益增加，通常记录为对股份发行所产生的资产或负债进行确认或终止确认后的剩余金额（即发行所得款项），并扣除直接归属于该交易的交易费用。

[IAS 32 第2段]。

<a id="s350-Para_51.6"></a>**51.6** 权益工具的交易费用计入权益。

[IAS 32 第35段]。

<a id="s350-Para_51.7"></a>**51.7** 与交易费用或与股份的任何分配相关的所得税，按照 IAS 12 进行会计处理。

[IAS 32 第35A段]。

[FAQ 51.7.1 – 关于股本还有哪些其他要求？](85.md#s354-FAQ_51.7.1)

<a id="s350-chap_51_navPoint_8"></a>
### 作为负债核算的股本

<a id="s350-Para_51.8"></a>**51.8** 某些股份发行可能不符合权益的定义，因而列报为金融负债。这一点将在[第43章第12段](67.md#s276-Para_43.12)进一步讨论。当地法律要求可能要求披露分类为金融负债的股份的法定资本及任何溢价。

[IAS 32 第16段]。

<a id="s350-chap_51_navPoint_9"></a>
### 复合工具

<a id="s350-Para_51.9"></a>**51.9** 同时包含权益成分和负债成分的工具（如可转换债券）应当分拆为这两个成分，并分别进行会计处理。这一点将在[第43章第51段](67.md#s278-Para_43.51)进一步讨论。

[IAS 32 第28段]。

<a id="s350-chap_51_navPoint_10"></a>
### 部分实缴权益股份

<a id="s350-Para_51.10"></a>**51.10** 股份可以全额实缴发行，也可以部分实缴发行。国际财务报告准则未就此类股份的会计处理提供指引。

[IAS 32 第2段]。

[FAQ 51.10.1 – 部分实缴股份应如何进行会计处理？](85.md#s354-FAQ_51.10.1)

<a id="s350-chap_51_navPoint_12"></a>
### 待发行股份

<a id="s350-Para_51.11"></a>**51.11** 公司可能在股份发行之前即收到股份对价。国际财务报告准则未就此类交易的会计处理提供指引。

[IAS 32 第2段]。

[FAQ 51.11.1 – 待发行股份应如何进行会计处理？](85.md#s354-FAQ_51.11.1)

<a id="s350-chap_51_navPoint_13"></a>
### 以非现金对价配发股份

<a id="s350-Para_51.12"></a>**51.12** 公司可以以货币或以其他可用货币计价的项目（如固定资产或知识产权）为对价配发股份（包括任何溢价）。国际财务报告准则未就此类交易的会计处理提供指引。

[IAS 32 第2段]。

[FAQ 51.12.1 – 以非现金对价发行的股份应如何进行会计处理？](85.md#s354-FAQ_51.12.1)

<a id="s350-chap_51_navPoint_15"></a>
### 多币种股本

<a id="s350-Para_51.13"></a>**51.13** 公司可能发行以其功能货币以外的货币计价的股本。此类交易的会计影响详见[第49章](80.md#s318-chap_49) [EX 49.46.2](80.md#s324-EX49.46.2)。

[IAS 21 第23(c)段]。

<a id="s350-chap_51_navPoint_17"></a>
### 发行费用

<a id="s350-Para_51.14"></a>**51.14** 根据 IAS 1，“权益资本和储备分解为不同类别，例如实收资本、股本溢价和储备”，可在资产负债表表内或附注中列报。在某些司法管辖区，法定资本维持要求规范股本溢价账户的设立和使用。

[IAS 1 第78(e)段]。

<a id="s350-Para_51.15"></a>**51.15** 只有成功发行的费用才能直接在权益中冲销。关于权益工具交易费用处理的进一步指引，请参见[第43章第89段](67.md#s280-Para_43.89)。

[IAS 32 第35段]。

<a id="s350-Para_51.16"></a>**51.16** 认股权证在 IAS 32 下通常属于权益工具，因此任何发行费用均计入权益。

[IAS 32 第22段]。

<a id="s350-chap_51_navPoint_19"></a>
### 资本赎回储备

<a id="s350-Para_51.17"></a>**51.17** 某些司法管辖区的国家法律要求为资本维持目的设立储备，但国际财务报告准则未涵盖其会计处理。

[IAS 32 第2段]。

[FAQ 51.17.1 – 为何可能需要设立资本赎回储备？](85.md#s354-FAQ_51.17.1)

<a id="s350-chap_51_navPoint_21"></a>
### 资本投入（股东投入）

<a id="s350-Para_51.18"></a>**51.18** 资本投入（股东投入）在性质上是非互惠的（即以赠与方式进行）。国际财务报告准则未就资本投入（股东投入）的会计处理提供指引。当与关联方进行非公平交易或按不反映公允价值的价格进行交易时，主体应当考虑是否发生了资本投入（股东投入）或分配。

[IAS 32 第2段]。

[FAQ 51.18.1 – 资本投入（股东投入）应如何进行会计处理？](85.md#s354-FAQ_51.18.1)

<a id="s350-chap_51_navPoint_22"></a>
### 分配/股利

<a id="s350-Para_51.19"></a>**51.19** 分配包括权益股份的股利以及分类为权益的其他工具的票息。向权益工具持有人作出的分配直接借记权益。

[IAS 32 第35段]。

<a id="s350-Para_51.20"></a>**51.20** 若立即支付，则对应分录记入现金；若于未来日期结算，则确认为一项负债。不可回售普通股的发行人在正式作出分配行为并对股东负有法律义务时，确认一项负债。

[IAS 32 第AG13段]。

<a id="s350-Para_51.21"></a>**51.21** 如果在资产负债表日不存在义务，则不确认负债。以往支付股利的历史并不构成合同义务或推定义务。进一步详情请参见[第9章第16段](17.md#s56-Para_9.16)。

[IAS 37 第14段]。

<a id="s350-Para_51.22"></a>**51.22** 作为金融负债核算的股份的应付股利在利润表中确认为费用，在结算时作为负债的偿还处理。分拆为负债成分和权益成分的复合金融工具，会对确认为利息费用和分配的金额产生相应影响。进一步详情请参见[第43章第87段](67.md#s280-Para_43.87)。

[IAS 32 第35段]。

[FAQ 51.22.1 – 分配可以采取何种形式？](85.md#s354-FAQ_51.22.1)  
[FAQ 51.22.2 – 股利应于何时确认？](85.md#s354-FAQ_51.22.2)  
[FAQ 51.22.3 – 以股代息（股票股利）应如何进行会计处理？](85.md#s354-FAQ_51.22.3)

<a id="s350-chap_51_navPoint_idp1689304232"></a>
#### 非法股利

<a id="s350-Para_51.23"></a>**51.23** 股利的合法性由国家法律而非国际财务报告准则决定。如果接收方在合同上有义务退还被认定为非法的股利（例如，在已派发股利所对应的股份工具条款中有明确规定），则支付方应确认一项金融资产，并按公允价值初始计量。原始交易不予冲回。如果不存在要求接收方退还股利的合同义务，则支付方应在几乎确定能收到款项的期间确认一项或有资产。在收款达到几乎确定之前，如果很可能收到款项，支付方应当披露该或有资产的存在。

[IFRS 9 第5.1段 (IAS 39 第43段)]。[IAS 37 第31段]。[IAS 37 第32段]。[IAS 37 第33段]。[IAS 37 第34段]。[IAS 37 第35段]。

<a id="s350-chap_51_navPoint_idp1689321768"></a>
#### 实物分配（非现金分配）的会计处理

<a id="s350-Para_51.24"></a>**51.24** 主体可能分配非现金资产。主体应将分配借记权益。

[IAS 32 第35段]。

<a id="s350-Para_51.25"></a>**51.25** IAS 32 未规定借记金额，也未规定相关资产应按转移资产的账面价值还是公允价值核算。IFRIC 17 专门就这些事项提供了指引。进一步指引请参见[第30章第58段](53.md#s219-Para_30.58)。

[IFRIC 17 第3段]。

<a id="s350-chap_51_navPoint_23"></a>
### 库存股

<a id="s350-Para_51.26"></a>**51.26** 库存股定义为重新购回的自身权益工具。该定义比权益股份更宽泛，包括股票期权。国家法律可能决定主体能否回购其股份并将其作为库存股持有。管理层还应考虑任何成文法和普通法关于资本维持和分配的规则所带来的后果。

[IAS 32 第33段]。

<a id="s350-chap_51_navPoint_25"></a>
### 回购自身股份（包括库存股）的会计处理

<a id="s350-Para_51.27"></a>**51.27** 如果主体重新购回其自身权益工具，该等工具应当从权益中扣除。除下一段规定外，具体会计处理如下：

- 回购、出售、发行或注销主体自身权益工具时，不得在损益中确认任何利得或损失。

- 回购或出售主体自身权益工具所支付或收取的对价，应当直接计入权益。

[IAS 32 第33段]。

<a id="s350-Para_51.28"></a>**51.28** 为回购工具而支付的金额从权益中扣除。当购回权益股份用于注销时，国家法律和/或公司章程可能规定该扣减应冲减实收资本还是可分配利润。因此，会计处理应当反映国家法律的相关资本维持要求。同样，对于购回作为库存股持有的权益股份，国家法律可能要求将该金额从可分配利润中扣除。在没有任何法律要求的情况下，该金额既可以借记权益的一个单独组成部分，也可以冲减留存收益。实收资本不予减少。

[IAS 32 第33段]。

<a id="s350-Para_51.29"></a>**51.29** 通常，主体会与经纪商或银行签订合同，委托其代为回购自身股份。包含主体以现金或其他金融资产回购自身权益工具义务的合同，必须确认一项金融负债。该金融负债应当按赎回金额的现值进行初始计量（例如，远期回购价格、期权行权价格或其他赎回金额的现值）。确认该负债时，对应的借方计入权益。

[IAS 32 第23段]。

<a id="s350-Para_51.30"></a>**51.30** 后续期间，该金融负债应当按照 IFRS 9（IAS 39）进行计量，这很可能导致在利润表中确认利得或损失。

[IFRS 9 附录B 第B5.4.6段 (IAS 39 第AG8段)]。

<a id="s350-Para_51.31"></a>**51.31** 主体应在合同开始时（而非支付股份款项时）对“库存股”的购回进行会计处理。

[IFRS 9 第3.1.1段 (IAS 39 第14段)]。

<a id="s350-Para_51.32"></a>**51.32** 如果合同到期而未交割或未全部交割，则归属于未交割股份的金融负债金额应重分类至权益，冲回原始分录。

[IAS 32 第23段]。

<a id="s350-Para_51.33"></a>**51.33** 即使购买、重新购回或赎回自身权益工具的义务取决于交易对手行使其权利（例如，签出一项赋予交易对手以固定价格向主体出售主体自身权益工具的看跌期权），主体仍负有购买自身权益工具的合同义务。主体应当按购买、重新购回或赎回金额的现值确认一项金融负债。

[IAS 32 第23段]。

[FAQ 51.33.1 – 回购自身股份产生的负债应如何计量？](85.md#s354-FAQ_51.33.1)

<a id="s350-Para_51.34"></a>**51.34** 与回购库存股直接相关的费用作为总体回购成本的一部分处理，与回购成本一样从权益中扣除。关于权益工具交易费用的处理，请参见[第43章第79段](67.md#s280-Para_43.79)。

[IAS 32 第37段]。

<a id="s350-Para_51.35"></a>**51.35** 自身权益工具可由主体自身或合并集团的其他成员购回并作为库存股持有。在合并财务报表中，子公司持有的母公司权益工具的权益应当从权益中扣除。这适用于所有此类持股，包括从事证券交易业务的子公司所持有的股份。

[IAS 32 第33段]。

<a id="s350-Para_51.36"></a>**51.36** 上述关于库存股的指引同样适用于与雇员股票期权计划、雇员购股计划以及所有其他股份支付安排相关的库存股的出售、发行或注销。这些计划将在[第13章](24.md#s85-chap_13)讨论。

[IAS 32 第4(f)(ii)段]。

<a id="s350-Para_51.37"></a>**51.37** 当分类为金融负债的股份被重新购回时，如果满足终止确认条件，则移除该金融负债（参见[第44章第105段](68.md#s286-Para_44.105)）。股份回购可能适用当地法定资本维持要求并产生相应的会计影响。

[IFRS 9 第3.3.1段 (IAS 39 第39段)]。

[FAQ 51.37.1 – 持有集团企业的股份在单独财务报表中应如何处理？](85.md#s354-FAQ_51.37.1)

<a id="s350-Para_51.38"></a>**51.38** 在合并财务报表中，非控制性权益作为权益的一个组成部分单独列报，与母公司所有者的权益分开。非控制性权益是指子公司中不直接或间接归属于母公司的权益。第26章第183段讨论了非控制性权益的会计处理。

## 因利得和损失列报而产生的储备（第51.40至51.45段）

<a id="s351-Para_51.40"></a>**51.40** 储备与权益股本及其他自身权益工具共同构成主体资产负债表的股东权益部分。国际会计准则理事会《概念框架》指出，权益是指扣除主体所有负债后在主体资产中的剩余权益。权益要求权是对扣除主体所有负债后主体资产剩余权益的要求权。此类要求权可通过合同、法规或类似方式确立，包括主体发行的各类股份以及主体发行另一项权益要求权的某些义务（以其不符合负债定义为限）。不同类别的权益要求权可赋予其持有人不同的权利（例如收取股利的权利或清算时的权利）。有时，法律、监管或其他要求会影响权益的特定组成部分，例如股本或留存收益。国际会计准则理事会《概念框架》指出，为提供有用的信息，如果权益的某些组成部分受特定法律、监管或其他要求的约束，则可能有必要将权益的各个组成部分分开分类。例如，在某些司法管辖区，主体仅在拥有足够被指定为可分配的储备时，才获准向权益要求权持有人作出分配。将这些储备单独分类可能提供有用的信息，尤其是在它们表明主体在分配或以其他方式使用其权益方面受到法律或其他限制的情况下。它们还可能反映出在主体中拥有所有权权益的各方在收取股利或偿还投入权益方面享有不同的权利。储备通常被称为权益的组成部分。

[《概念框架》第4.63至4.67段]。[《概念框架》第7.12段]。[《概念框架》第7.13段]。

<a id="s351-chap_51_navPoint_30"></a>
### 重估储备（重估盈余）

<a id="s351-Para_51.41"></a>**51.41** 根据 IFRS 16、IAS 16 和 IAS 38，主体可以按重估金额核算某些资产。重估盈余确认为其他综合收益，并在权益中以“重估盈余”或“重估储备”项目累计（IFRS 16 参见第15章第87段，IAS 38 参见第21章第91段，IAS 16 参见第22章第76段）。

[IFRS 16 第35段]。[IAS 16 第39段]。[IAS 38 第85段]。

<a id="s351-chap_51_navPoint_31"></a>
### 公允价值储备

<a id="s351-Para_51.42"></a>**51.42** 国际财务报告准则要求某些金融资产重新计量产生的利得和损失直接计入其他综合收益（在“以收取合同现金流量和出售为目标”的业务模式下持有且合同现金流量仅为对本金和利息的支付的债务工具，以及不可撤销地选择将公允价值变动列报于其他综合收益的权益股份）（IAS 39 下分类为可供出售的金融资产），但未指定用于累计这些利得和损失的具体储备项目。然而，国家法律可能包含此类规定。实务惯例是将其贷记入“公允价值”储备。

[IFRS 9 第4.1.2A段 (IAS 39 第9段)]。[IFRS 9 第5.7.5段]。[IFRS 9 第5.7.10段 (IAS 39 第55(b)段)]。

<a id="s351-chap_51_navPoint_32"></a>
### 套期储备

<a id="s351-Para_51.43"></a>**51.43** 指定为现金流量套期中套期工具的金融工具因重新计量而产生的利得或损失的有效部分，确认为其他综合收益。进一步详情请参见[第46章第15段](74.md#s296-Para_46.15)和第6.8A章第128段。

[IFRS 9 第6.5.11段 (IAS 39 第95段)]。

<a id="s351-chap_51_navPoint_33"></a>
### 外币折算储备

<a id="s351-Para_51.44"></a>**51.44** 折算境外经营产生的汇兑差额确认为其他综合收益，并作为权益的一个单独组成部分累计。对境外经营净资产所面临汇率变动影响构成有效套期（“净投资套期”）的套期工具所产生的利得或损失，计入合并外币折算储备。

[IAS 21 第32段]。

<a id="s351-Para_51.45"></a>**51.45** IAS 1 未对留存收益的含义作出定义。

[IAS 1 第7段]。

## 示例与实务问答

<a id="s354-chap_51_navPoint_45"></a>
### 权益的性质与特征

<a id="s354-chap_51_navPoint_idp1689335080"></a>
#### <a id="s354-FAQ_51.4.1"></a>FAQ 51.4.1 – 可能存在哪些不同类别的股本？

准则索引：IAS 32 第2段  
正文索引：[51.4](85.md#s349-Para_51.4)

股份有多种类型，包括普通股、优先股、无表决权股和可赎回股份。

<a id="s354-chap_51_navPoint_idp1689397672"></a>
#### <a id="s354-FAQ_51.4.2"></a>FAQ 51.4.2 – 典型的储备类型有哪些？

准则索引：IAS 32 第2段  
正文索引：[51.4](85.md#s349-Para_51.4)

国际财务报告准则未对储备作出定义。部分储备源于会计要求（例如公允价值储备和外币折算储备），旨在将某些计量变动反映在其他综合收益中而非利润表中。这些单独的储备通常在相关资产和负债终止确认或发生减值时，从其他综合收益重分类（“转出”）至利润表。其他储备则源于司法管辖区的法定要求。

典型的储备包括：

- 股本溢价账户。

- 资本赎回储备（参见[第51.17段](85.md#s350-Para_51.17)）。

- 重估储备（重估盈余）（参见[第51.41段](85.md#s351-Para_51.41)）。

- 公允价值储备（参见[第51.42段](85.md#s351-Para_51.42)）。

- 套期储备（参见[第51.43段](85.md#s351-Para_51.43)）。

- 外币折算储备（参见[第51.44段](85.md#s351-Para_51.44)）。

- 资本储备。

- 留存利润（参见[第51.45段](85.md#s351-Para_51.45)）。

- 其他储备，包括因当地法定要求而产生的储备。

<a id="s354-chap_51_navPoint_46"></a>
### 与股东交易产生的权益——确认与计量

<a id="s354-chap_51_navPoint_idp1689417384"></a>
#### <a id="s354-FAQ_51.7.1"></a>FAQ 51.7.1 – 关于股本还有哪些其他要求？

准则索引：IAS 32 第2段  
正文索引：[51.7](85.md#s350-Para_51.7)

当地法律要求可能决定股份是否具有名义价值（面值），以及任何溢价是否必须贷记法定储备或其他储备。当地要求还将决定这些储备是否可供使用（例如用于支付发行费用）。

公司可以按其设立所在国法律允许的任何金额和类型的对价发行股份。权益股份公允价值（市场价值）的变动不影响其在财务报表中的列示金额。其在初始确认后不再重新计量。

<a id="s354-chap_51_navPoint_idp1689432616"></a>
#### 部分实缴权益股份

<a id="s354-chap_51_navPoint_idp1689429800"></a>
##### <a id="s354-FAQ_51.10.1"></a>FAQ 51.10.1 – 部分实缴股份应如何进行会计处理？

准则索引：IAS 32 第2段  
正文索引：[51.10](85.md#s350-Para_51.10)

对于全额实缴权益股份，在权益中确认的金额等于发行人收到的发行所得款项。部分实缴股份的会计处理取决于股份发行的条款和条件，并可能取决于公司章程。权益股份发行人至少将就部分实缴股份收到的所得款项（扣除直接归属于该交易的交易费用）贷记权益。发行人是否将股份尚未缴付的余额确认为一项应收款项并相应贷记权益，取决于发行人是否拥有收取该对价的现时权利。

例如，某公司发行部分实缴股份。股份协议规定了明确的固定催缴日期时间表，股东必须在这些日期分期缴付股份的未付金额。股东无法避免催缴。公司章程或国家法律决定了该催缴时间表是否在法律上使股东负有按期付款的义务。

如果股东在合同上有义务付款，发行人应在股份发行日就未来尚未收取的款项（若重大则予以折现）确认一项应收款项，并相应增加权益（根据当地法律要求计入股本/股本溢价）。

该应收款项是一项金融资产，因为发行人拥有向股东收取现金的合同权利（同样，股东负有向发行人付款的金融负债）。该应收款项在初始确认时按公允价值计量，后续按照 IFRS 9 进行会计处理，详见[第42章](63.md#s263-chap_42)（在 IAS 39 下参见第6.7A章）。

然而，如果股东可以避免对部分实缴股份的催缴，则这不构成金融资产，且在股东付款或作出不可撤销的催缴承诺之前不确认权益。

有关由公司提供资金支持雇员购买股份的会计处理，详见[第13章](24.md#s85-chap_13)。

<a id="s354-chap_51_navPoint_idp1689450536"></a>
#### 待发行股份

<a id="s354-chap_51_navPoint_idp1689465256"></a>
##### <a id="s354-FAQ_51.11.1"></a>FAQ 51.11.1 – 待发行股份应如何进行会计处理？

准则索引：IAS 32 第2段  
正文索引：[51.11](85.md#s350-Para_51.11)

股份是否已发行属于法律事项。如果公司认为股东在法律上有权享有该等股份（例如有权获得股利），则无论是否已签发股票证书，收到的对价均应贷记实收资本（股本/股本溢价）。如果股份在法律上尚未发行，则收到的对价应贷记“待发行股份”。

#### 以非现金对价配发股份

<a id="s354-chap_51_navPoint_idp1689467816"></a>
##### <a id="s354-FAQ_51.12.1"></a>FAQ 51.12.1 – 以非现金对价发行的股份应如何进行会计处理？

准则索引：IAS 32 第2段  
正文索引：[51.12](85.md#s350-Para_51.12)

公司可以以货币或以其他可用货币计价的项目（如固定资产或知识产权）为对价配发股份（包括任何溢价）。在此情况下，可能要求对非现金对价进行估值，以确定确认为实收资本的金额。当国家法律要求时，该金额在股份面值与股本溢价之间进行拆分。在某些情况下，当地法律的估值要求可能与所收到对价的会计价值不同。在此情况下，可能需要在权益中记录一笔平衡贷方或借方。该借方或贷方的法律意义将取决于当地要求。

#### 资本赎回储备

<a id="s354-chap_51_navPoint_idp1689217448"></a>
##### <a id="s354-FAQ_51.17.1"></a>FAQ 51.17.1 – 为何可能需要设立资本赎回储备？

准则索引：IAS 32 第2段  
正文索引：[51.17](85.md#s350-Para_51.17)

在某些司法管辖区，在赎回或购回自身股份等情形下，可能需要为资本维持目的设立储备。这些司法管辖区的公司将购回或注销的股份（包括注销库存股）的名义价值（面值）转入资本赎回储备。

#### 资本投入（股东投入）

<a id="s354-chap_51_navPoint_idp1689222952"></a>
##### <a id="s354-FAQ_51.18.1"></a>FAQ 51.18.1 – 资本投入（股东投入）应如何进行会计处理？

准则索引：IAS 32 第2段  
正文索引：[51.18](85.md#s350-Para_51.18)

所有者以主体所有者身份作出的投入，应与正常经营过程中因贸易活动产生的转移区分开来。所有者的投入在性质上是非互惠的。实质上，由于不存在偿还的合同义务，它们属于赠与。它们可以是赠与的资产或服务，或是豁免的负债，而受让方无义务提供任何利益作为交换。

此类投入构成权益的增加。通常，此类金额记录在一个单独的储备中，常被称为“资本储备”。

#### 分配/股利

<a id="s354-chap_51_navPoint_idp1689228840"></a>
##### <a id="s354-FAQ_51.22.1"></a>FAQ 51.22.1 – 分配可以采取何种形式？

准则索引：IAS 32 第35段  
正文索引：[51.22](85.md#s350-Para_51.22)

主体向其权益工具持有人作出的分配通常是股利或资本返还（例如股份回购），但也可能采取其他形式。分配由主体董事会酌情决定，通常需经股东批准。

与资本投入（股东投入）类似，分配属于非互惠转移。分配也可以以非现金对价进行。例如，子公司向母公司转移业务和资产在实质上可能构成一项实物分配（非现金分配）（实物股利——参见上文[第51.24段](85.md#s350-Para_51.24)）。

<a id="s354-chap_51_navPoint_idp1689238184"></a>
##### <a id="s354-FAQ_51.22.2"></a>FAQ 51.22.2 – 股利应于何时确认？

准则索引：IAS 32 第2段  
正文索引：[51.22](85.md#s350-Para_51.22)

关于何时将股利确认为已获适当授权且不再由主体自行决定的判断，取决于主体章程和/或其设立所在地的国家法律。在某些司法管辖区，取消股利需要成员决议，因此董事会宣告股利即对公司形成一项负债。决定不支付股利的酌情权在于成员而非管理层。在其他司法管辖区，成员在股东大会上批准董事提议的股利。在获得成员批准之前，不存在支付义务。

<a id="s354-chap_51_navPoint_idp1689250600"></a>
##### <a id="s354-FAQ_51.22.3"></a>FAQ 51.22.3 – 以股代息（股票股利）应如何进行会计处理？

准则索引：IAS 32 第2段  
正文索引：[51.22](85.md#s350-Para_51.22)

许多上市公司作出安排，允许普通股股东选择以增发普通股而非现金的方式收取股利——即以股代息（股票股利）。这种安排的一个短期优势是改善公司的现金状况。此类股利在财务报表中按现金替代方案的金额确认。财务报表附注应当就该情况作出充分完整的说明，解释以股代息（股票股利）的性质以及以股份支付的金额。

<a id="s354-chap_51_navPoint_idp1689264424"></a>
#### 库存股

<a id="s354-chap_51_navPoint_idp1689263656"></a>
##### <a id="s354-FAQ_51.33.1"></a>FAQ 51.33.1 – 回购自身股份产生的负债应如何计量？

准则索引：IAS 32 第23段；IFRS 9 第B5.4.6段，(IAS 39 第AG8段)  
正文索引：[51.33](85.md#s350-Para_51.33)

如果合同规定了待回购股份的数量而非价值，则金融负债按主体将需支付的估计股价进行初始计量。应当采用合同项下待回购的最大股份数量，因为公司无法避免就该最大数量股份交付现金。股价的最佳估计是合同开始日的股价。该金融负债后续根据股价变动进行调整。因此，损益中将确认利得或损失，因为 IFRS 9 第B5.4.6段（IAS 39 第AG8段）要求就该负债计量的变动通过利润表调整金融负债的账面价值。但是，如果实际回购的股份总数少于最大数量，差额应与到期未行权的期权一样进行会计处理，即将差额从负债重分类至权益。

如果合同设定了可支出金额的上限，则金融负债按该最高金额计量，并就合同开始日至付款日之间的期间按货币时间价值进行折现。在此情况下，对损益的影响可能仅限于折现的转回（利息费用）。如果实际支出金额少于最高金额，差额应按到期未行权的期权处理，从负债重分类至权益。

<a id="s354-chap_51_navPoint_idp1689329576"></a>
##### <a id="s354-FAQ_51.37.1"></a>FAQ 51.37.1 – 持有集团企业的股份在单独财务报表中应如何处理？

准则索引：IAS 32 第2段  
正文索引：[51.37](85.md#s350-Para_51.37)

在持有母公司股份的子公司的单独财务报表中，此类股份按照 IFRS 9（IAS 39）作为金融资产进行会计处理。不适用“库存股”会计处理，因为对子公司而言这些股份并非“自身股份”。

#### 储备

<a id="s354-chap_51_navPoint_idp1702209560"></a>
##### <a id="s354-FAQ_51.45.1"></a>FAQ 51.45.1 – 留存收益通常包含哪些内容？

准则索引：IAS 32 第7段  
正文索引：[51.45](85.md#s351-Para_51.45)

对于 IAS 1 称为“留存收益”的项目，公司使用了多种术语。“损益账户”、“收益储备”、“留存收益”和“留存利润”等术语均被普遍接受且含义相同。

#### 披露要求

<a id="s354-chap_51_navPoint_idp1702216600"></a>
##### <a id="s354-FAQ_51.48.1"></a>FAQ 51.48.1 – 披露要求是否仅适用于作为权益核算的股本？

准则索引：IAS 1 第79、80段  
正文索引：[51.48](85.md#s352-Para_51.48)

IAS 1 对股本有具体的披露要求。IAS 1 第79段未说明这些披露要求是仅适用于作为权益核算的股本，还是同样适用于确认为金融负债的股本。我们认为，这些披露仅涉及分类为权益的股份。这是因为资产负债表表内确认的单列项目包括“归属于母公司所有者的已发行资本和储备”和“金融负债”。金融负债的披露由 IFRS 7 规范。

此外，对无股本主体适用同等披露要求的 IAS 1 第80段要求此类主体披露有关“每一类权益利益”的信息。然而，管理层可能将分类为金融负债的股份视为构成主体资本的一部分。IAS 1 要求对资本作出额外披露。就非权益股本提供类似详情以呈现平衡的图景可能是适当的。

<a id="s354-chap_51_navPoint_idp1702239640"></a>
##### <a id="s354-FAQ_51.48.2"></a>FAQ 51.48.2 – 如果主体（如合伙企业或信托）没有股本，有何披露要求？

准则索引：IAS 1 第80段  
正文索引：[51.48](85.md#s352-Para_51.48)

当合伙企业或信托等主体没有股本时，其应当就每一类权益利益披露与第79(a)段要求同等的信息。[参见第51.48段](85.md#s352-Para_51.48)。

<a id="s354-chap_51_navPoint_idp1702246552"></a>
##### <a id="s354-FAQ_51.53.1"></a>FAQ 51.53.1 – 储备调节表通常包含哪些内容？

准则索引：IAS 1 第106段  
正文索引：[51.53](85.md#s352-Para_51.53)

对于每一组成部分（例如留存收益余额，即累计损益），应分别细分列示不同类型的变动。所有者权益变动表还列示权益不同组成部分之间的结转。例如，该表列示与不动产、厂场和设备以前的重估盈余于本年度通过折旧或出售实现相关的重估储备（重估盈余）与留存利润储备之间的变动。

<a id="s354-chap_51_navPoint_idp1702251544"></a>
##### <a id="s354-FAQ_51.53.2"></a>FAQ 51.53.2 – 关于可分配储备需要披露哪些信息？

准则索引：IAS 1 第106段  
正文索引：[51.53](85.md#s352-Para_51.53)

根据国际财务报告准则，储备无需区分已实现或未实现进行披露。如果留存利润储备的余额与法律上可分配的金额之间存在重大差异，管理层可能认为在财务报表中分别披露可分配储备和不可分配储备的金额是适当的。

<a id="s354-chap_51_navPoint_idp1702259352"></a>
##### <a id="s354-FAQ_51.58.1"></a>FAQ 51.58.1 – 资本是如何定义的？

准则索引：IAS 1 第134段  
正文索引：[51.58](85.md#s352-Para_51.58)

国际财务报告准则未对“资本”作出定义。如[第51.57段](85.md#s352-Para_51.57)所述，主体必须基于内部提供给关键管理人员的信息，说明其作为资本进行管理的内容。尽管就此项披露而言资本通常等同于权益，但也可能包含部分金融负债或剔除权益的某些组成部分。例如，IAS 1 第135(b)段指出，某些主体将某些形式的次级债务视为资本的一部分，而另一些主体则剔除现金流量套期储备。（这可能是因为递延于其中的金额不会永久保留在权益中。与净投资套期和公允价值储备相关的金额更有可能被视为资本，因为它们涉及已确认的资产和负债，且仅在出售时才重分类至利润表。）在实务中，某些主体也将计息债务作为资本的一部分。

<a id="s354-chap_51_navPoint_idp1702202776"></a>
##### <a id="s354-FAQ_51.58.2"></a>FAQ 51.58.2 – 这些要求是否适用于所有主体？

准则索引：IAS 1 第134段  
正文索引：[51.58](85.md#s352-Para_51.58)

IAS 1 的《结论基础》部分明确指出，资本披露适用于所有主体，而不仅仅适用于受外部监管的主体。[IAS 1 结论基础第BC87段]。这意味着“外部施加的资本要求”的范围非常广泛，不仅包括保险或银行监管机构设定的偿付能力比率，还包括其他机构设定的以及通过特定合同关系确立的资本要求/限制。例如，如果某项贷款本身包含在主体对资本的定义中，则违反特定标准（“限制性条款”）时要求加速偿还该贷款的规定即构成外部施加的资本要求。此处涉及的要求并非标准本身包含资本组成部分（例如维持特定的债务/权益比率），而是将这些标准应用于包含在主体资本定义中的贷款。因此，尽管限制性条款测试可能是参照“资本比率”（如债务/权益比率）计算的，但除非该限制性条款所涉及的贷款构成主体资本的一部分，否则其本身并不代表外部施加的资本要求。关于未包含在主体资本中的贷款限制性条款的披露要求载于 IFRS 7，并在[第47章第10段](78.md#s307-Para_47.10)和第6.9A章第15段中作进一步讨论。
