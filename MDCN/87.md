## 引言

 

<a id="s363-Para_A2.1"></a>**A2.1** 世界各地的监管机构通常要求债务证券或权益证券的发行人提供合并财务报表。这些要求通常通过列报按照 IFRS 或当地公认会计原则（GAAP）编制的合并财务报表来满足。

<a id="s363-Para_A2.2"></a>**A2.2** 在某些情况下，可能需要提供集团某一部分或若干部分的财务信息。这通常与某种性质的交易有关——处置、分配、企业合并、分拆以及首次公开募股（IPO）均是需要提供特定类型财务信息的交易示例。

<a id="s363-Para_A2.3"></a>**A2.3** 可能需要为受同一控制但不属于法律次级集团（在此情况下编制合并财务报表才适当）的集团组成部分提供财务信息。受同一控制主体的财务报表主要是为交易目的而编制的，最常被称为“汇总财务报表（联合财务报表）”或“剥离财务报表”。

<a id="s363-Para_A2.4"></a>**A2.4** “汇总财务报表（联合财务报表）”是指包含受同一控制结合在一起、但不构成法律集团的经济活动的财务信息。此类报表通常通过汇总分部、独立主体或不符合 IFRS 10 中“集团”定义的集团组成部分的财务报表编制而成。

<a id="s363-Para_A2.5"></a>**A2.5** “剥离财务报表”是指较大主体的某一部门或较小业务组成部分的财务报表；该术语通常用于指代股权剥离、分拆及股权置换式分立。例如，如果将来自不同法律次级集团的组成部分的财务信息予以汇总，剥离财务报表也可能同时属于汇总财务报表。

<a id="s363-Para_A2.6"></a>**A2.6** “新报告主体”一词用于描述构成汇总财务报表基础的经济活动（通常是现有集团的一部分）。

<a id="s363-Para_A2.7"></a>**A2.7** 编制汇总财务报表可能需要运用大量判断。每项交易各不相同，每套汇总财务报表都会带来独特的挑战。交易的性质、报告主体的边界、会计记录的质量、母公司过往的实务和政策以及相关监管机构的观点都至关重要。

<a id="s363-Para_A2.8"></a>**A2.8** 尽管《概念框架》和其他准则包含了编制汇总财务报表的相关信息，但 IFRS 并未就汇总财务报表的编制提供专门指引。然而，实务中普遍认可，在某些情况下汇总财务报表可以声明其系按照 IFRS 编制。

<a id="s363-Para_A2.9"></a>**A2.9** 并不存在一套固定方法可以确保编制出符合 IFRS 的汇总财务报表，但有一系列共同需要回答的问题；这些问题的答案将决定能否编制符合 IFRS 的汇总财务报表、如何完成编制，以及可能需要作出哪些披露。

<a id="s363-Para_A2.10"></a>**A2.10** 本指引旨在协助编制汇总财务报表。每套汇总财务报表都会提出独特的问题和挑战。本指引中的任何内容均不应被解读为凌驾于会计准则或相关监管要求之上。

<a id="s363-Para_A2.11"></a>**A2.11** 本指引列明了相关问题，并阐述了在 IFRS 下编制汇总财务报表时所遵循的一些常见实务。

<a id="s363-Para_A2.12"></a>**A2.12** 本指引不涉及现任母公司或最终控制方层面可能产生的会计问题。

<a id="s363-Para_A2.13"></a>**A2.13** 编制汇总财务报表（特别是用于资本市场交易的汇总财务报表）总会面临一系列独特的问题。管理层应确保已咨询其审计师和专业顾问，并了解相关监管机构的观点和要求。

## 步骤 1：确定汇总财务报表的目的并了解相关监管要求

<a id="s364-Para_A2.15"></a>**A2.15** 合并财务报表和汇总财务报表均列报历史财务信息。合并财务报表要求将母公司及其全部子公司纳入合并范围；汇总财务报表则列报特定经济活动的历史财务信息。

<a id="s364-Para_A2.16"></a>**A2.16** 编制汇总财务报表的一项关键前提假设是，在整个期间内存在将这些经济活动结合在一起的纽带要素（进一步指引参见[第A2.42段](87.md#s365-Para_A2.42)）。该纽带要素未必是直接法律所有权，尽管同一控制几乎总是存在的。纽带要素是指使各项经济活动在整个期间内“结合”在一起的特征（例如法律所有权或同一控制）。

<a id="s364-Para_A2.17"></a>**A2.17** “剥离财务报表”是指较大主体的某一部门或较小业务组成部分的财务报表。之所以使用“剥离”一词，是因为该业务单元的财务报表被视为从较大的合并财务报表中“剥离”出来的。会计上对剥离交易没有专门定义；该术语通常用于指代股权剥离、分拆及股权置换式分立。

<a id="s364-chap_Appendix_2_navPoint_3"></a>
### 汇总财务报表的目标是什么？

 

<a id="s364-Para_A2.18"></a>**A2.18** 汇总财务报表通常是为配合拟议交易而编制的，例如通过分拆某一部门或主要业务线进行首次公开募股（IPO），或配合计划中的向股东分配。或者，汇总财务报表也可能作为并购交易中最终购买价格谈判的基础。

<a id="s364-Para_A2.19"></a>**A2.19** 汇总财务报表的目的和使用者可能会影响财务信息的编制和列报方式。本指引的工作假设是需要编制符合 IFRS 的非标准财务报表。

<a id="s364-Para_A2.20"></a>**A2.20** 很少有国家就非标准财务报表的编制制定专门的监管要求。关于汇总财务信息监管要求的示例，参见[FAQ A2.20.1](87.md#s369-FAQ_A2.20.1)。

[FAQ A2.20.1 – 汇总财务报表有哪些监管信息来源？](87.md#s369-FAQ_A2.20.1)

<a id="s364-Para_A2.21"></a>**A2.21** 如果存在专门的监管要求，则必须予以遵循。由此生成的财务信息可能符合也可能不符合 IFRS。例如，受美国证券交易委员会（SEC）监管的报告主体在按照 IFRS 编制汇总财务报表时，须遵循 SEC 的指引，且该汇总财务报表通常也将符合 IFRS。依据英国《投资报告准则》（SIR）2000《适用于历史财务信息公开报告业务的投资报告准则》指引编制的财务信息，可以表述为符合 IFRS。编制基础应包含符合 IFRS 的声明，但同时也应修订以涵盖符合（SIR）2000 的声明。

<a id="s364-Para_A2.22"></a>**A2.22** 许多其他国家认为其他监管机构的现有指引很有参考价值，但其监管机构总体上期望获得按照 IFRS 编制的汇总财务报表。大多数汇总财务报表均系着眼于资本市场交易而编制。即使相关监管机构尚未发布关于编制汇总财务报表的全面指南，管理层也应在早期阶段了解其观点。监管机构的观点可能从已发生的类似交易、公开声明、公司法及类似来源中清晰体现。

<a id="s364-Para_A2.23"></a>**A2.23** 不同监管机构可能持不同观点，这可能对汇总财务报表的性质、范围甚至可接受性产生深远影响。

  
<a id="s364-Para_A2.24"></a>**A2.24** 汇总财务报表可能在没有专门指引的司法管辖区编制，或者为其他目的（例如提供给贷款人、供应商或交易对手）编制。自愿遵循一套监管指引可能会有所帮助，因为这更易于被使用者理解。

<a id="s364-Para_A2.25"></a>**A2.25** 财务报告的基本目标是提供有助于评估管理层受托责任的信息，并使使用者能够评估报告主体产生现金流量的能力。在编制汇总财务报表时，这些目标依然适用。

<a id="s364-Para_A2.26"></a>**A2.26** 汇总财务报表本质上是一项“临时性”措施。它们是在特定时点为特定目标就指定数量的报告期间而编制的。在多个连续期间持续编制汇总财务报表的情况并不常见。经过一段时间后，随着交易或重组的完成，报告主体要么将具备编制合并财务报表的条件，要么将被并入更大的集团。

 

<a id="s364-chap_Appendix_2_navPoint_4"></a>
### 汇总财务报表能否实现“公允列报”或“真实和公允的反映”？

<a id="s364-Para_A2.27"></a>**A2.27** 报告目的和相关监管机构均可能要求对汇总财务报表出具“无保留”审计意见（即“公允列报”或“真实和公允的反映”意见）。该要求可能会决定财务信息的编制方式。

<a id="s364-Para_A2.28"></a>**A2.28** 实务中存在大量新报告主体声明符合 IFRS 的汇总财务报表接受常规审计的案例。审计意见可能提及“真实和公允”或“按照 IFRS 公允列报”。

<a id="s364-Para_A2.29"></a>**A2.29** 交易前架构越复杂、编制过程中作出的调整和分摊越多，所编制的汇总财务报表就越难以提供“真实和公允的反映”。

<a id="s364-Para_A2.30"></a>**A2.30** 然而，在某些情况下，汇总财务报表应表述为“按照附注 X 所述的编制基础编制”；这些“按编制基础编制”的汇总财务报表不属于按照 IFRS 编制的通用目的财务报表。

<a id="s364-Para_A2.31"></a>**A2.31** 交易前架构越复杂、必须作出的调整和分摊越多，财务信息就会越倾向于“按编制基础编制”而非“按照 IFRS 编制”。因此，所提供的鉴证意见将提及遵循既定的编制基础。

<a id="s364-Para_A2.32"></a>**A2.32** 审计意见的性质主要取决于当地监管规定和财务信息的性质。部分监管机构接受“编制基础”意见，而其他监管机构（例如香港联合交易所）则要求审计意见明确表明完全符合 IFRS。

<a id="s364-Para_A2.33"></a>**A2.33** 在针对按照 IFRS 编制的汇总财务报表出具的审计意见中，也常使用“强调事项”段。例如，“强调事项”段可能说明新报告主体此前并未作为独立主体运营，或者说明汇总财务报表未必能反映该业务在所列报期间作为独立单体主体运营时本会取得的经营成果。

## 步骤 2：确定新的报告主体

 

<a id="s365-Para_A2.34"></a>**A2.34** 在典型的资本市场交易中，报告主体是以一家法律主体为首的集团。然而，当需要编制汇总财务报表时，法律架构很少在整个业绩记录期间内均已存在：法律集团可能直到交易执行时才设立；或者交易前可能发生集团重组，致使报告主体的历史包含同一控制下收购或在法律上并无关联的主体之间的合并。界定新报告主体的“边界”是财务报告的基础。这一过程可能颇具挑战性，且需要运用判断。

<a id="s365-Para_A2.35"></a>**A2.35** 当控制权归属于同一最终控制方或受合同约束的相同的多方时，即存在“同一控制”。

<a id="s365-Para_A2.36"></a>**A2.36** 《国际财务报告准则概念框架》（IFRS Framework）对报告主体的定义如下：“报告主体是指被要求或选择编制财务报表的主体。报告主体可以是一个单一主体、一个主体的某一部分，也可以包含不止一个主体。报告主体不一定是法律主体。”

[《概念框架》第3.10段]。

<a id="s365-Para_A2.37"></a>**A2.37** 在适当情况下，较大集团的一个经营分部、在法律上无关联但在同一控制下共同运营以实现单一业务目标的一组主体，或通过合同结合在一起的主体，均可成为报告主体。《概念框架》指出：“如果报告主体包含两个或两个以上并非全部通过母子公司关系相联系的主体，则该报告主体的财务报表称为‘汇总财务报表’。”

[《概念框架》第3.12段]。

<a id="s365-Para_A2.38"></a>**A2.38** 《概念框架》承认，确定报告主体的适当边界可能存在困难。当报告主体并非法律主体，且并非仅由通过母子公司关系相联系的法律主体组成时，便可能出现这种情况。《概念框架》指出，在确定适当边界时应考虑报告主体主要使用者的信息需求。使用者需要如实反映的信息。因此，根据《概念框架》，所列报的信息要求：

- “报告主体的边界不包含任意或不完整的一组经济活动；

- 将该组经济活动纳入报告主体的边界内能够产生中立的信息；并且

- 说明报告主体的边界是如何确定的，以及报告主体由什么构成。”

[《概念框架》第3.13段和第[3.14](09.md#s20-Para_3.14)段]。

 

<a id="s365-chap_Appendix_2_navPoint_6"></a>
### 不具备法律边界的“业务”能否成为报告主体？

<a id="s365-Para_A2.39"></a>**A2.39** 报告主体不必是法律主体。如果一个并非法律主体且不具有独立法律“人格”的单独载体属于可单独识别的财务架构（例如某种类型的合伙企业、分支机构或分部），则其有潜力成为报告主体。

<a id="s365-Para_A2.40"></a>**A2.40** 因此，报告主体不限于以法律主体形式设立的主体。它可以包含一个主体的某一部分，也可以包含两个或两个以上主体。

<a id="s365-Para_A2.41"></a>**A2.41** 非法律主体的报告主体的边界应当以使依赖财务报表的使用者能够获取相关财务信息的方式来界定。财务报表应当如实反映主体的经济活动（参见上文[第A2.38段](87.md#s365-Para_A2.38)）。

<a id="s365-chap_Appendix_2_navPoint_7"></a>
### 哪些因素表明经济活动结合在一起并构成一个报告主体？

 

<a id="s365-Para_A2.42"></a>**A2.42** 在评估是否存在作为编制汇总财务报表基础的报告主体时，通常需要评估两项关键考量：

- 资产和负债是否受同一控制或共同管理（通常伴有同一控制，参见下文[第A2.43段](87.md#s365-Para_A2.43)至[第A2.48段](87.md#s365-Para_A2.48)）；以及

- 报告主体的经济活动是否已经或将为某一目的结合在一起，例如通过：

- 在报告日之后但在财务报表发布之前发生的集团法律重组；

- 将为配合拟议 IPO、处置或类似交易而发生的法律重组；或

- 在汇总财务报表所涵盖的全部期间内均已签署并生效的协议。

 

<a id="s365-chap_Appendix_2_navPoint_8"></a>
### 构成报告主体是否必须存在同一控制？

<a id="s365-Para_A2.43"></a>**A2.43** 在缺乏同一控制的情况下识别出报告主体的情形极为罕见。

<a id="s365-Para_A2.44"></a>**A2.44** 当各主体或业务处于同一控制之下时，该报告主体将拥有一个治理相关活动的单一治理机构。如果各主体一直处于同一控制之下，使用者便能够评估该治理机构是否高效且有效地运用了资源。

<a id="s365-Para_A2.45"></a>**A2.45** 汇总财务报表仅能就各主体处于同一控制之下的期间编制。如果主体在汇总财务报表的业绩记录期间内从第三方收购了另一主体，则应自取得控制权之日起采用购买法。

<a id="s365-chap_Appendix_2_navPoint_9"></a>
### 如果拟议报告主体的经济活动不受同一控制，主体能否编制汇总财务报表？

 

<a id="s365-Para_A2.46"></a>**A2.46** 如果经济活动仅处于共同管理之下而不同时受同一控制，则很少适合编制汇总财务报表。

<a id="s365-Para_A2.47"></a>**A2.47** 若无合同安排或同一控制的支持，共同管理本身很少足以确立一个报告主体。

[FAQ A2.47.1 – 共同管理能否作为同一控制的基础？](87.md#s369-FAQ_A2.47.1)

  
<a id="s365-Para_A2.48"></a>**A2.48** 共同的业务本身也很少足以确立一个报告主体。私募股权基金可能决定在短期内收购同一行业的多项业务，随后将其整合为一个集团以实现规模经济和协同效应。收购每一项独立业务均构成企业合并，必须采用购买法。尽管所收购的各主体具有共同业务，且将若干年度的财务信息汇总可能对投资者有用，但为被收购业务与购买方编制汇总财务报表，将与排除被购买方购买前财务信息的要求相冲突。

<a id="s365-chap_Appendix_2_navPoint_11"></a>
### 编制报告主体的汇总财务报表时是否适用合并会计原则？

<a id="s365-Para_A2.50"></a>**A2.50** 汇总财务报表必须遵循 IFRS 的所有确认、计量和披露要求，方可声明符合 IFRS。财务报告的基本目标应当适用，即提供有助于以下方面的有用信息：

- 评估管理层受托责任；

- 使使用者能够评估报告主体产生现金流量的能力；以及

- 实现跨期可比性。

<a id="s365-Para_A2.51"></a>**A2.51** 实务中常通过重组形成新报告主体。可能会设立一家新主体，仅收购现有法律集团的一部分作为拟上市业务。

<a id="s365-Para_A2.52"></a>**A2.52** 关于汇总财务报表是否列报非控制性权益，实务做法不尽相同。这是一个复杂领域，取决于多种因素，包括非控制性权益在计划交易后是否继续存续。管理层应考虑何种处理方式既能提供有用信息又能符合 IFRS。

<a id="s365-chap_Appendix_2_navPoint_12"></a>
### 什么是处置组法？何时适用于汇总财务报表？

<a id="s365-Para_A2.53"></a>**A2.53** 新报告主体在为交易编制汇总财务报表时，可能包含在业绩记录期间法律上属于报告主体、但今后不再属于新报告主体的业务。重组在交易时点或临近交易时点实施，使得仅有持续经营业务（新报告主体）构成新的法律集团。管理层需要决定如何在汇总财务报表中列报报告主体的经营成果和财务状况，尤其是在重组涉及处置新报告主体部分组成部分的情况下。

<a id="s365-Para_A2.54"></a>**A2.54** 实务中常见的两种方法是：

- 将今后不会构成新法律集团组成部分的所有业务和活动全部排除在汇总财务报表之外（剥离基础）；或

- 将该等业务和活动纳入汇总财务报表，并将其列报为处置组或终止经营（处置组基础）。

<a id="s365-Para_A2.55"></a>**A2.55** 监管机构可能偏好某一种列报方式；例如，美国监管机构通常期望采用处置组基础。所选择的方法取决于若干因素，且需要运用判断。

<a id="s365-Para_A2.56"></a>**A2.56** 使用者通常更倾向于仅获取与持续经营业务相关的信息；因此，在可行的情况下，管理层可能会寻求在汇总财务报表中采用剥离法。仅当满足特定标准时，采用剥离法才是合理的。IFRS 未定义这些标准，但部分司法管辖区（例如英国和美国）的监管机构制定了更为明确的指引，且这些指引通常具有相似的理念，包括：

- 拟处置的业务与新报告主体的其余部分存在显著差异；

- 拟处置的业务一直由独立管理层分别管理；以及

- 拟处置的业务存在独立的历史账簿和记录。

<a id="s365-Para_A2.57"></a>**A2.57** 处置组法是列报新报告主体汇总财务报表的另一种基础。在无法或不适合采用剥离法的情况下，处置组法在业绩记录期间内同时包含拟上市业务和非拟上市业务（以 IPO 为例）。处置组法将所有拟处置业务合并至处置日或终止经营日。

<a id="s365-Para_A2.58"></a>**A2.58** 所处置业务或终止经营的财务信息在新报告主体中纳入至该日期为止，并作为处置组与持续经营业务分开列报。

<a id="s365-Para_A2.59"></a>**A2.59** 在编制汇总财务报表的语境下，“处置组”的概念类似于 IFRS 5 中对处置组的定义：“在单项交易中拟通过出售或其他方式一并处置的一组资产，以及在该交易中将一并转移的与这些资产直接相关的负债”。

<a id="s365-Para_A2.60"></a>**A2.60** 处置组未必需要符合 IFRS 5 中“终止经营”的定义。仅对截至资产负债表日已满足 IFRS 5 要求的资产负债表适用处置组会计处理。

<a id="s365-Para_A2.61"></a>**A2.61** 当新报告主体包含在重组中不会被转让的主体时，通常采用处置组法。

<a id="s365-Para_A2.62"></a>**A2.62** 管理层应结合每个具体案例的特定事实予以考量。

<a id="s366-chap_Appendix_2_navPoint_13"></a>
## 步骤 3：考虑汇总财务报表能否符合 IFRS

<a id="s366-Para_A2.63"></a>**A2.63** 汇总财务报表是指管理层旨在声明符合 IFRS 且基于历史数据编制的财务报表。历史财务信息是指按照法定要求和相关会计准则编制的过往信息。其核心前提假设是，历史财务信息提取自独立或分开的会计记录，且该信息能够接受审计。

<a id="s366-Para_A2.64"></a>**A2.64** 另一方面，“备考财务信息”是指旨在以“假定（as-if）”为基础说明特定结果或情景的假设性信息。此类财务信息包含未曾发生的事项或交易（非历史性），或者发生时间早于或晚于财务报表确认日的事项或交易的影响。该术语在不同司法管辖区的使用方式有所不同。

<a id="s366-chap_Appendix_2_navPoint_14"></a>
### 历史信息还是备考信息？

 

<a id="s366-Para_A2.65"></a>**A2.65** 为交易而筹备的新报告主体很少是一个规整的次级集团——即已编制出仅包含且完整涵盖新报告主体全部经济活动和交易（包括债务、税项、股份支付、集团层面资产份额、管理服务及费用）的合并财务报表。若确实如此，该报告主体便可直接编制和列报合并财务报表。

<a id="s366-Para_A2.66"></a>**A2.66** 大多数为交易而筹备的新报告主体并不具备[第A2.65段](87.md#s366-Para_A2.65)所述形式和性质的财务信息。管理层可能需要作出调整，包括分摊与新报告主体相关但尚未在报告主体边界内的法律主体账簿中核算的特定资产、负债和费用。

<a id="s366-Para_A2.67"></a>**A2.67** 按照 IFRS 编制的汇总财务报表通常会包含调整或分摊，以反映[第A2.65段](87.md#s366-Para_A2.65)所述的项目。确定哪些内容适合作为历史财务信息纳入，是编制汇总财务报表时的关键判断领域。汇总财务报表应避免“假定（as-if）”调整，但关于应调整什么以及如何调整的指引有限。目标是避免产生“假定”或“备考”财务信息。“备考”一词的含义和解释可能因司法管辖区而异，备考财务信息的编制方式也可能存在差异。然而，备考财务信息不符合 IFRS。

[EX A2.67.1 – 按照 IFRS 编制的历史信息](87.md#s369-EXA2.67.1)  
[EX A2.67.2 – 包含重大调整的财务报表](87.md#s369-EXA2.67.2)

<a id="s366-Para_A2.68"></a>**A2.68** 部分司法管辖区将较大集团所发生的历史费用分摊至报告主体的做法视为历史信息，因为该分摊是基于较大集团过去实际发生的费用，并按合理基础分摊至报告主体的。

<a id="s366-Para_A2.69"></a>**A2.69** 其他司法管辖区可能将任何分摊均视为备考调整。[EX A2.67.2](87.md#s369-EXA2.67.2)列示了一套备考财务报表的编制基础示例。

<a id="s367-chap_Appendix_2_navPoint_15"></a>
## 步骤 4：处理编制过程中的实务问题

<a id="s367-chap_Appendix_2_navPoint_16"></a>
### 按照 IFRS 编制的汇总财务报表应采用哪些会计政策？

<a id="s367-Para_A2.70"></a>**A2.70** 所采用的会计政策应当适合汇总财务报表的目的。

<a id="s367-Para_A2.71"></a>**A2.71** 先前就所界定范围内的经济活动记录的会计信息，将构成编制汇总财务报表的基础。随后可能需要作出调整，以便按照所选定的会计政策列报汇总财务报表。

<a id="s367-Para_A2.72"></a>**A2.72** 在不同情形下采用不同的方法：

- 采用相关经济活动所属集团（现任母公司）合并财务报表所遵循的会计政策。当卖方编制信息以向其现有投资者或潜在买方列报（例如拟出售的法律集团某一部分的信息）时，通常采用该方法。

- 采用相关经济活动将归属的新报告主体财务报表所要应用的会计政策。当某项业务正从现有集团分立至一家新的独立法律主体时，该方法通常较为适当。汇总财务报表旨在反映构成该新报告主体一部分的经济活动的财务业绩。

- 在为拟议收购编制目标公司汇总财务报表时，采用购买方的会计政策，以便在购买方的会计政策下列报被购买方的财务业绩。包括英国在内的部分司法管辖区要求采用该方法。

<a id="s367-Para_A2.73"></a>**A2.73** 会计政策的选择取决于财务信息的预期使用者和报告目的。采用不同会计政策本身并不会导致符合 IFRS 方面的问题；IFRS 要求管理层选择能够提供相关且可靠信息的适当会计政策。

<a id="s367-chap_Appendix_2_navPoint_17"></a>
### 源自先前交易的购买会计调整

 

<a id="s367-Para_A2.74"></a>**A2.74** 新报告主体可能包含此前由现任母公司收购的业务或主体。现任母公司所确认的与新报告主体相关的购买价格调整和商誉的处理方式可能有所不同。

 

<a id="s367-Para_A2.75"></a>**A2.75** 同一控制下企业合并和重组的账面价值法（前任会计法）通常采用同一控制最高层级的账面价值（参见附录 1 [第A1.19段至第A1.21段](86.md#s358-Para_A1.19)）。现任母公司不太可能构成新报告主体的一部分。由此产生的问题是：是否应对新报告主体的汇总财务报表作出调整，以反映现任母公司的账面价值？此类分摊的示例包括现任母公司记录的与新报告主体相关的任何商誉及相关购买价格调整。

 

<a id="s367-Para_A2.76"></a>**A2.76** 母公司在单独财务报表中采用 IFRS 时，很少分摊商誉和购买价格调整。IFRS 下不存在“下推会计”的要求，且许多司法管辖区的公司法会使下推会计难以实施。

 

<a id="s367-Para_A2.77"></a>**A2.77** “下推会计”是指在收购完成后，在被收购业务的单独财务报表中确立新的会计基础；实质上是将母公司的商誉和购买会计调整纳入该单独财务报表中。

 

<a id="s367-Para_A2.78"></a>**A2.78** 商誉及相关购买价格调整可以纳入新报告主体的汇总财务报表。如果新报告主体的历史财务业绩记录未能反映现任母公司取得该业务的成本，许多使用者和监管机构会认为该记录是不完整的。本质上，商誉和购买会计调整不应滞留在现任母公司中，而应随其所对应的业务一并转移。

 

[EX A2.78.1 – 商誉的分摊](87.md#s369-EXA2.78.1)

 

<a id="s367-chap_Appendix_2_navPoint_18"></a>
### 有形资产和无形资产

 

<a id="s367-Para_A2.79"></a>**A2.79** 新报告主体将在汇总财务报表中确认其组成主体所控制的全部资产。当新报告主体使用了集团层面资产（如品牌或专利），而这些资产可能转移也可能不转移给新报告主体时，可能会出现挑战。同样，报告主体历史上可能控制了某些资产，但这些资产在交易中不会转移给新报告主体。

 

<a id="s367-Para_A2.80"></a>**A2.80** 资产可根据法律所有权、使用情况或集团内部共享安排（如经营协议或租赁协议）归属于新报告主体。资产归属应反映整个业绩记录期间内实际存在的安排的法律实质。

 

<a id="s367-Para_A2.81"></a>**A2.81** 在业绩记录期间由新报告主体某一部分控制的资产，可能不会作为交易的一部分转移至新报告主体。与关于处置组的讨论类似（参见[第A2.55段](87.md#s365-Para_A2.55)），实务中存在两种方法，相关监管机构可能偏好其中之一，或在特定情况下其中一种方法更为适当。这两种方法是：将该资产纳入汇总财务报表直至交易日并明确披露其不会转移；或在业绩记录期间将该资产排除在汇总财务报表之外，并同样作出明确披露。

 

[FAQ A2.81.1 – 汇总财务报表中如何分摊无形资产？](87.md#s369-FAQ_A2.81.1)

 

<a id="s367-chap_Appendix_2_navPoint_19"></a>
### 债务

<a id="s367-Para_A2.82"></a>**A2.82** 新报告主体可能负有法律偿付义务的债务，该等债务将纳入其汇总财务报表。这包括由构成新报告主体的法律主体直接发行的第三方债务。

<a id="s367-Para_A2.83"></a>**A2.83** 现任母公司的第三方债务也可能转让给新报告主体或由新报告主体依法承担。该债务应在债务存续的全部期间内纳入新报告主体的汇总财务报表。

<a id="s367-Para_A2.84"></a>**A2.84** 租赁负债应随相关的使用权资产一并归属。利息收入和利息费用的分摊应遵循相关债务和债务工具的分摊方式。

<a id="s367-Para_A2.85"></a>**A2.85** 可能还存在其他应将债务纳入新报告主体汇总财务报表的情形。管理层应审慎考虑对汇总财务报表使用者最有意义的列报方式。例如，如果新报告主体将对现任母公司负有计息义务，则应将其列报为债务融资。分摊基础应与相关交易、分立或处置协议的条款保持一致。

<a id="s367-chap_Appendix_2_navPoint_20"></a>
### 新报告主体的汇总财务报表应包含哪些收益和费用？

 

<a id="s367-Para_A2.86"></a>**A2.86** 新报告主体的汇总财务报表应包含其业务产生的全部经济活动。曾作为较大集团一部分的新报告主体，很少拥有独立的财务业绩记录。

<a id="s367-Para_A2.87"></a>**A2.87** 其经济活动产生的收益和费用可能记录在集团其他地方，可能需要分摊至新报告主体，以使其汇总财务报表能够声明按照 IFRS 编制。只要能够建立合理的分摊基础，所有相关费用均应纳入新报告主体的汇总财务报表。

<a id="s367-Para_A2.88"></a>**A2.88** 在集团总部层面发生的费用，可能是向第三方支付的、由集团总部层面为下属主体提供服务的费用。这些费用可能包括薪资发放、会计核算、集中采购、市场营销、高管管理、租赁费用、广告、法律、保险、销售及管理费用。部分费用——如养老金和其他职工薪酬——可能仅在母公司或集团总部层面记录。

<a id="s367-Para_A2.89"></a>**A2.89** 汇总财务报表应反映来自母公司或集团其他提供服务单位的合理费用分摊。分摊方法可以是具体识别、依据法律义务，或采用最能反映费用发生性质的方式（如员工人数和工时使用情况）。

<a id="s367-Para_A2.90"></a>**A2.90** 集团总部管理费用的分摊涉及判断，但应反映为服务新报告主体而发生的增量成本。在合并财务报表中已被抵销的集团内部交易（如采购和销售），应在汇总财务报表中予以恢复。

<a id="s367-Para_A2.91"></a>**A2.91** 对先前未分摊至报告主体的交易进行估计和分摊，不同于凭空创造从未发生过的交易（类似“备考”信息）。只要存在适当的基础，并在汇总财务报表中清晰披露该基础，分摊就是可接受的。披露内容应包括如何识别分摊项目、分摊方法及分摊影响。

<a id="s367-Para_A2.92"></a>**A2.92** 分摊应使用高质量的信息进行。如果不存在作出合理且有依据的估计所需的信息，则不应进行分摊。相反，管理层应在附注中提供充分披露，使汇总财务报表阅读者能够了解未纳入新报告主体的费用的性质。

<a id="s367-Para_A2.93"></a>**A2.93** 在汇总财务报表附注中作出清晰且有意义的披露，对于正确理解财务报表至关重要。

[EX A2.93.1 – 汇总财务报表中的分摊](87.md#s369-EXA2.93.1)

<a id="s367-Para_A2.94"></a>**A2.94** 英国的 SIR 2000 和美国 SEC 的指引（参见[FAQ A2.20.1](87.md#s369-FAQ_A2.20.1)）在确定如何向新报告主体分摊费用时可能具有参考价值。进行分摊时通常考虑的因素包括：

- 相关资产和负债是否将成为新报告主体的一部分；

- 母公司与新报告主体之间是否存在集团内部费用再分摊（例如法律、会计、财务或职工薪酬费用）；以及

- 再分摊的金额是否代表实际发生的金额，以及再分摊的基础是如何确定的。

<a id="s367-Para_A2.95"></a>**A2.95** 在若干领域中，监管机构发布了专门指引。下文[第A2.96段](87.md#s367-Para_A2.96)及之后段落对此进行讨论。

 

<a id="s367-chap_Appendix_2_navPoint_21"></a>
### 所得税

 

<a id="s367-Para_A2.96"></a>**A2.96** 在汇总财务报表中核算所得税几乎总是充满挑战。理想情况是，新报告主体原本即是一个提交集团纳税申报表或单独纳税申报表的法律次级集团，且在交易后继续适用相同的税务制度。这种情况在实务中很少发生。然而，新报告主体在编制汇总财务报表时仍需应用 IAS 12 的要求。

<a id="s367-Para_A2.97"></a>**A2.97** 为核算所得税，管理层需要分析新报告主体的税务情况，包括其在交易后的法律地位。实务中，在将 IAS 12 应用于新报告主体汇总财务报表时，广泛采用两种方法：单独纳税申报法（separate tax return method）和实际税负法（tax incurred method）。

<a id="s367-Para_A2.98"></a>**A2.98** 单独纳税申报法将新报告主体内各个独立主体的税务状况予以汇总。构成新报告主体且此前单独提交纳税申报表的法律主体具有清晰的税务状况。当期所得税费用以及所得税资产和负债按照纳税申报表进行核算，递延所得税资产和负债则产生于各主体的账面价值与计税基础差异。

<a id="s367-Para_A2.99"></a>**A2.99** 然而，部分集团编制包含集团所有主体的合并纳税申报表，并依据集团内部安排或税务分摊协议分摊所得税费用。

<a id="s367-Para_A2.100"></a>**A2.100** 如果管理层选择采用单独纳税申报法确定业绩记录期间的当期所得税费用，则在（单独纳税申报基础下的）所得税费用或收益与根据法定税务分摊协议实际支付或收到的税款之间会产生差额。这些差额通常被视为母公司作出的资本投入或向母公司作出的资本分配，并纳入各期间投入资本的调节表中。

<a id="s367-Para_A2.101"></a>**A2.101** 管理层需要审慎考虑可结转的税务亏损，并在确认递延所得税资产之前确保这些税务亏损可供新报告主体使用。

<a id="s367-Para_A2.102"></a>**A2.102** 如果母公司向将构成新报告主体的各主体再分摊了税款，则采用实际税负法确定所得税费用可能是适当的。

<a id="s367-Para_A2.103"></a>**A2.103** 管理层应按常规方式，使用新报告主体所有列报期间的财务业绩评估递延所得税资产的可收回性。然而，在评估递延所得税资产的可实现性以及确定不确定税务处理时所作的假设，应反映历史日期存在的事实，不应包含事后之明。

[EX A2.103.1 – 所得税费用的分摊](87.md#s369-EXA2.103.1)

 

<a id="s367-chap_Appendix_2_navPoint_22"></a>
### 利息费用

 

<a id="s367-Para_A2.104"></a>**A2.104** 如果存在以下任一情形，则应将利息费用纳入新报告主体的汇总财务报表：

- 剥离主体历史上曾被分摊利息费用；

- 新报告主体将承担与该利息费用相关的债务；

- 该债务将由新报告主体使用证券发行所得款项予以偿还；或

- 母公司账簿上的债务专门与新报告主体的活动相关。

<a id="s367-Para_A2.105"></a>**A2.105** 在涉及需编制汇总财务报表的新报告主体的交易中，资本结构通常较为复杂。监管机构可能并不强制要求纳入利息费用；但是，只要能够对利息进行合理分摊，无论此前是否曾向新报告主体收取利息，监管机构通常都允许纳入利息费用。

[EX A2.105.1 – 利息收入和利息费用的分摊](87.md#s369-EXA2.105.1)

 

<a id="s367-chap_Appendix_2_navPoint_23"></a>
### 养老金计划

 

<a id="s367-Para_A2.106"></a>**A2.106** 新报告主体的员工可能曾经参与和/或继续参与母公司的职工薪酬计划。在交易时，新报告主体极少拥有自身的设定受益计划，也极少在法律上承接其自身员工的养老金负债。

<a id="s367-Para_A2.107"></a>**A2.107** 汇总财务报表中对职工薪酬计划的适当会计处理取决于若干因素，其中最重要的是交易后该计划的性质。实务中常见两种方法，如[第A2.108段](87.md#s367-Para_A2.108)和[第A2.109段](87.md#s367-Para_A2.109)所述。

<a id="s367-Para_A2.108"></a>**A2.108** 母公司的职工薪酬计划在实质上可能成为多雇主计划，新报告主体的员工为该多雇主计划的参与者。向该计划缴纳的供款计入新报告主体的损益表，或者向新报告主体分摊职工薪酬费用也可能是适当的。

<a id="s367-Para_A2.109"></a>**A2.109** 另一种情形是，将一部分养老金资产划拨给新报告主体，并由其承担转移至该主体的员工的全部现有义务，从而实质上为新报告主体设立了一项新的设定受益计划。尽管此事可能已经宣布或与员工达成一致，但很少在交易日之前完成实施。在作出适当披露的前提下，在汇总财务报表中反映养老金资产和负债可能是适当的。在此类情形下计算养老金资产和负债十分复杂，可能需要精算师参与。

 

<a id="s367-chap_Appendix_2_navPoint_24"></a>
### 减值

<a id="s367-Para_A2.110"></a>**A2.110** 新报告主体的母公司可能已就将纳入新报告主体的非金融资产确认了减值损失。同样，母公司也可能因更广泛集团内的协同效应（该协同效应在交易后将不复存在）而未确认减值。

<a id="s367-Para_A2.111"></a>**A2.111** 新报告主体需要确定用于非流动资产减值测试的现金产出单元（CGU），以及用于商誉和惠及多个现金产出单元的资产减值测试的现金产出单元组合。

<a id="s367-Para_A2.112"></a>**A2.112** 管理层需要对商誉及其他使用寿命不确定的非流动资产进行减值测试，并需就汇总财务报表所涵盖的每一期间单独评估独立运营业务是否发生了触发非金融资产减值测试的事项。此项评估不应借助事后之明。

<a id="s367-Para_A2.113"></a>**A2.113** 非金融资产减值不应按比例分摊给剥离主体，而应基于实际分配给剥离主体的资产以及剥离主体的独立经营成果来确定。

<a id="s367-chap_Appendix_2_navPoint_25"></a>
### 股份支付

<a id="s367-Para_A2.114"></a>**A2.114** 关联方或新报告主体经济利益的其他持有者（即母公司、集团其他公司或股东）向新报告主体员工授予的、作为向该主体提供服务的报酬的股份支付，应遵循 IFRS 2 的指引作为股份支付交易进行会计处理。这是 IFRS 下的强制要求，除非该转让明确系出于向报告主体提供服务的报酬以外的目的，例如清偿与雇佣无关的对员工的义务。

<a id="s367-chap_Appendix_2_navPoint_26"></a>
### 集团内部交易和余额

 

<a id="s367-Para_A2.115"></a>**A2.115** 新报告主体与集团内其他主体之间先前的往来交易应重新评估分类；在汇总财务报表中，它们很可能构成“第三方”交易。

<a id="s367-Para_A2.116"></a>**A2.116** 原集团内的主体在业绩记录期间内通常会被视为关联方，因此应适用 IAS 24 的要求。

<a id="s367-Para_A2.117"></a>**A2.117** 除 IAS 24 的额外披露要求外，还可能出现若干实务问题：

- 先前的往来余额可能同时包含经营性和融资性成分，在新报告主体的资产负债表中应予以拆分。

- 非流动项目的分类可能会发生变化。

- 由于母公司担保失效，应收关联方款项可能无法收回。

- 与原集团分离时，可能会产生额外负债。

[EX A2.117.1 – 管理费及其他费用的分摊](87.md#s369-EXA2.117.1)

 

<a id="s367-chap_Appendix_2_navPoint_27"></a>
### 交易费用

<a id="s367-Para_A2.118"></a>**A2.118** 汇总财务报表通常是为配合某种交易而编制的，因此交易费用问题经常出现。

<a id="s367-Para_A2.119"></a>**A2.119** 实务中关于交易费用主要有三个问题：

- 哪些 IPO 费用符合资本化条件；

- 如何在现有股东与投入新资金的股东之间分摊 IPO 费用；以及

- 为预期进行的 IPO 而发生的交易费用能否递延。

<a id="s367-Para_A2.120"></a>**A2.120** 新报告主体股份的 IPO 通常紧随集团重组之后进行。管理层应明确区分集团重组费用与 IPO 费用。后者仅指增量权益发行费用，不包括重组费用（例如员工裁员费用、搬迁费用、法律费用和税务成本）。重组或架构调整费用应在发生时计入当期损益。

<a id="s367-Para_A2.121"></a>**A2.121** 在 IPO 中，主体向投资者发行新股以筹集额外资本，并连同现有股份一并在证券交易所上市。使现有股份在证券交易所上市所发生的费用不属于与发行权益工具相关的交易费用。这些费用系为提高现有股份的流动性而发生，与筹集新资本无关。

<a id="s367-Para_A2.122"></a>**A2.122** 在 IPO 中发行新股筹集资本（“首次公开发行新股”）所发生的费用属于权益工具的交易费用，应从权益中扣减。

<a id="s367-Para_A2.123"></a>**A2.123** 同时为筹集资本和现有股份上市而发生的费用，应按合理基础在新股与现有股份之间进行分摊。为使现有股份上市或为使分立产生的新股上市而发生的任何费用，均不属于权益交易费用，应计入利润表。

<a id="s367-Para_A2.124"></a>**A2.124** 为预期发行权益股份而发生的符合条件的交易费用，可在交易发生前在资产负债表中予以递延，或列示为权益的扣减项。如果该交易不被评估为很可能发生，则相关费用必须计入损益。先前已冲销的费用不得转回。

<a id="s367-chap_Appendix_2_navPoint_28"></a>
### 权益的列报

<a id="s367-Para_A2.125"></a>**A2.125** 新报告主体在整个业绩记录期间很少是独立的法律主体，因此其自身并不具备独立的股本和储备。如果与原集团的分离尚未完成，任何权益均代表母公司在新报告主体中的净投资。在汇总财务报表中，该项目通常标示为“投入资本”或“母公司投资”。

<a id="s367-Para_A2.126"></a>**A2.126** 如果存在法定股本，则应在权益中单独列示（在此情况下，列报每股收益也具有意义——参见[第A2.129段](87.md#s367-Para_A2.129)）。

<a id="s367-Para_A2.127"></a>**A2.127** 无论是否列示法定账户（如股本或股本溢价），其他 IFRS 要求单独披露的“可重分类”余额（例如套期储备）均应单独披露。

<a id="s367-Para_A2.128"></a>**A2.128** 应特别关注新报告主体与其母公司之间仍然存在的未结清余额。不具备债务特征的余额应作为投入资本的一部分予以列报。

<a id="s367-chap_Appendix_2_navPoint_29"></a>
### 每股收益的列报

 

<a id="s367-Para_A2.129"></a>**A2.129** IAS 33 要求“为在公开市场发行普通股而向证券委员会或其他监管机构报送或正在报送财务报表”的主体列报每股收益（EPS）。

<a id="s367-Para_A2.130"></a>**A2.130** 由于汇总财务报表不太可能具有法定股本（参见[第A2.125段](87.md#s367-Para_A2.125)），列报每股收益往往意义不大。部分监管机构在此情况下接受省略该披露。一旦发行了股份，每股收益数据对资本市场即具有意义，因此应进行追溯调整。部分监管机构（尤其是美国 SEC）要求在计算历史每股收益时，以组建汇总主体法律架构时向现有投资者发行的股份数量作为分母。

[EX A2.130.1 – 不列报每股收益](87.md#s369-EXA2.130.1)

<a id="s367-Para_A2.131"></a>**A2.131** 如果新报告主体的投入资本在业绩记录期间因现金增发股份或管理层收购等原因出现大幅波动，则应谨慎处理。在切实可行的情况下，管理层应说明此类交易对用于计算每股收益数据的股份数量的影响。

 

<a id="s367-chap_Appendix_2_navPoint_30"></a>
### 事后之明的应用

 

<a id="s367-Para_A2.132"></a>**A2.132** 不运用事后之明以及按管理层当时实际经营情况列报业务的一般原则，意味着应当保持比较期间处于已结账状态。例如，如果在编制汇总财务报表时某项诉讼已达成和解，则不应将业绩记录期间已计提的预计负债“追溯调整”为实际和解金额。

 

<a id="s367-chap_Appendix_2_navPoint_31"></a>
### 现金流量

 

<a id="s367-Para_A2.133"></a>**A2.133** 列报剥离主体的现金流量表可能颇具挑战性。例如，在母公司合并现金流量表中未予反映的集团内部交易，应在剥离主体层面的现金流量表中予以反映。这些集团内部交易需要在汇总财务报表中进行恰当分类。

 

<a id="s367-chap_Appendix_2_navPoint_32"></a>
### 向 IFRS 过渡
<a id="s367-Para_A2.134"></a>**A2.134** 为新报告主体编制财务报表时，应当适用 IFRS 1 的要求。本指引侧重于与编制汇总财务报表相关的特定问题，不涉及适用于所有首次采用者的 IFRS 1 的一般要求。

对于晚于其母公司（或对其具有重大影响或共同控制的主体）所领导集团采用 IFRS 的子公司（包括剥离主体），IFRS 1 第D16段提供了两种选择。其可以按以下任一金额计量资产和负债：

- 基于母公司向 IFRS 过渡的日期，本应纳入母公司合并财务报表的账面金额……；或

- 基于子公司向 IFRS 过渡的日期，IFRS 1 所要求的账面金额。

[IFRS 1 第D16段]。

<a id="s367-chap_Appendix_2_navPoint_33"></a>
### 调节表

<a id="s367-Para_A2.135"></a>**A2.135** IFRS 1 要求编制原公认会计原则（GAAP）与 IFRS 之间的调节表，说明过渡如何影响报告主体的财务状况和财务业绩。新报告主体此前不太可能编制过财务报表，因此无法编制调节表。

<a id="s367-Para_A2.136"></a>**A2.136** 从现有 IFRS 报告主体分拆出来的新报告主体不会存在任何调节项目，因为其可以适用可供在母公司过渡之后过渡的子公司使用的同一项豁免。

<a id="s367-chap_Appendix_2_navPoint_34"></a>
### 期初资产负债表

<a id="s367-Para_A2.137"></a>**A2.137** IFRS 1 要求编制并列报期初资产负债表作为财务报表的起点。该要求同样适用于汇总财务报表。

<a id="s367-chap_Appendix_2_navPoint_35"></a>
### 其他复杂领域

<a id="s367-Para_A2.138"></a>**A2.138** 本指引不涉及很大程度上取决于具体事实和情况或受当地法规管辖的复杂会计领域（例如非控制性权益或外币折算差额的计算与列报）。

<a id="s368-chap_Appendix_2_navPoint_36"></a>
## 步骤 5：作出清晰披露

 

<a id="s368-Para_A2.139"></a>**A2.139** 清晰、透明的披露对于理解汇总财务报表和剥离财务报表至关重要。此类财务信息通常是为反映特定情形而编制的，且往往受当地监管要求的约束。

<a id="s368-Para_A2.140"></a>**A2.140** 披露附注应至少涵盖以下内容：

- 编制汇总财务报表的目的；

- 如何识别新报告主体以及所作出的重大判断；应在编制基础中清晰描述新报告主体的边界，包括说明哪些主体被纳入汇总财务报表；

- 参与汇总的主体清单；

- 汇总财务报表是按照 IFRS 编制还是按照特定编制基础编制；

- 编制汇总财务报表所遵循的主要会计政策；

- 资产、负债、收益和费用的分摊方式；

- 集团内部交易在汇总财务报表中的反映方式；

- 每股收益的计算方法（如适用）；

- 编制汇总财务报表所涉及的关键判断和估计；以及

- 如果汇总财务报表声明符合 IFRS，则应涵盖所有适用 IFRS 的披露要求。

### <a id="s369-FAQ_A2.47.1"></a>FAQ A2.47.1 – 共同管理能否作为同一控制的基础？

 

准则索引：[A2.47](87.md#s365-Para_A2.47)  
正文索引：   

  

 

基金管理人可能负责管理不同基金的投资组合，但通常并不持有这些基金的受益权益。决策程序要求基金管理人就重大决策征求基金份额持有人的批准。这些基金处于共同管理之下，但不存在将由同一基金管理人管理的所有基金予以汇总的基础。

 

汇总后的基金并不构成一个报告主体；某一基金的份额持有人或债权人无权追索其他基金的资产，也不可能持有全部基金整体的剩余权益。

### <a id="s369-FAQ_A2.49.1"></a>FAQ A2.49.1 – 如何由将通过重组在法律上结合在一起的主体确立报告主体？

 

准则索引：[A2.49](87.md#s365-Para_A2.49)  
正文索引：   

  

 

![](assets/226.png)

 

在自然人 X 的同一控制下，A 主体和 B 主体构成一项单一业务，并独立于 C 主体运营。这些主体在法律上并无关联，但在 IPO 之前将通过置入一家新设公司（NewCo）组建一个新的法律集团。尽管 A 主体和 B 主体在重组前在法律上并无关联，但仍有可能为该新报告主体编制汇总财务报表。它们在整个历史业绩记录期间均处于同一控制之下，代表一个经济活动领域，且将在拟议 IPO 之前在法律上结合在一起。

 

<a id="s369-chap_Appendix_2_navPoint_41"></a>
### <a id="s369-FAQ_A2.49.2"></a>FAQ A2.49.2 – 如何由根据合同安排已在法律上结合在一起的主体确立报告主体？

 

准则索引：[A2.49](87.md#s365-Para_A2.49)  
正文索引：   

  

 

![](assets/227.png)

 

A 主体和 B 主体是独立业务，但根据母公司与两名非控制性权益（NCI）股东之间订立的单一合同安排共同管理。通过共同管理两项业务可实现协同效应，而由于两名非控制性权益股东在各自业务中持有不同的经济利益，因此需要订立合同安排。由于 A 主体和 B 主体处于同一控制之下，且在整个业绩记录期间根据合同安排在法律上结合在一起，因此可以为 A 主体和 B 主体编制汇总财务报表。

 

<a id="s369-chap_Appendix_2_navPoint_42"></a>
### <a id="s369-FAQ_A2.49.3"></a>FAQ A2.49.3 – 如何由作为单一经济实体共同管理的独立主体确立报告主体？

 

准则索引：[A2.49](87.md#s365-Para_A2.49)  
正文索引：   

  

 

![](assets/228.png)

 

母公司的首席经营决策者根据集团的三个业务分部监控集团业绩：A 主体和 B 主体共同构成一个经营分部；C 主体和 D 主体各自构成一个经营分部。每个经营分部都有各自的管理团队，负责经营活动、财务预测和业绩表现。

 

A 主体和 B 主体处于同一控制之下，且在整个业绩记录期间由同一分部管理团队作为单一经济实体共同管理。因此，由于 A 主体和 B 主体可视为一个报告主体，可以为 A 主体和 B 主体编制汇总财务报表。

### <a id="s369-EXA2.67.1"></a>EX A2.67.1 – 按照 IFRS 编制的历史信息

 

准则索引：[A2.67](87.md#s366-Para_A2.67)  
正文索引：   

  

 

**示例**

 

X 集团拟处置其次级集团 Y 以及 X 集团的另一家直接持股子公司 Z。管理层为次级集团 Y 和子公司 Z 编制汇总财务报表。

 

X 集团在四年前收购了次级集团 Y，并进行了购买价格分摊（PPA），从而按照 IFRS 在 X 集团的合并财务报表中就该收购确认了商誉。

 

**分析**

 

管理层使用 X 集团合并财务报表中次级集团 Y 和子公司 Z 的金额编制汇总财务报表。X 集团合并财务报表中反映的商誉及其他购买价格分摊调整均纳入该次级集团的财务报表中。

 

该汇总财务报表所依据的财务报表仅使用历史信息编制，因此可能可以声明符合 IFRS。

 

<a id="s369-chap_Appendix_2_navPoint_45"></a>
### <a id="s369-EXA2.67.2"></a>EX A2.67.2 – 包含重大调整的财务报表

 

准则索引：[A2.67](87.md#s366-Para_A2.67)  
正文索引：   

  

 

**示例**

 

X 集团拥有两大主要业务板块——金属和煤炭。管理层计划实施分立，将金属业务分拆至一个新的次级集团，并组建两家新的上市主体：A 金属公司（A Metals）和 A 煤炭公司（A Coal）。

 

每位股东在 X 集团中的投资将被拆分为对 A 金属公司和 A 煤炭公司的独立投资。

 

**分析**

 

X 集团已根据从 X 集团经审计财务报表及底层会计记录中提取的与 A 金属公司相关的历史信息，编制了 A 金属公司的汇总财务报表。

 

A 金属公司的利润表和现金流量表已基于以下前提列报：假定分立已经发生，且 A 金属公司在上市监管机构要求的三年业绩记录期间内一直作为独立集团存在。该财务信息的编制纳入了以下调整：

 

- 排除了在部分司法管辖区与金属业务处于同一法律主体内的煤炭业务活动；

- 将业绩记录期间已确认的资产减值予以转回，作为对期初留存收益的调整；以及

- 额外记录了费用，以使 A 金属公司列报为如同其一直作为独立上市主体而非 X 集团的一部分运营，而未考虑 X 集团实际发生的费用。

 

这些调整导致信息系按备考基础编制，不符合 IFRS。

### <a id="s369-FAQ_A2.81.1"></a>FAQ A2.81.1 – 汇总财务报表中如何分摊无形资产？

 

准则索引：[A2.81](87.md#s367-Para_A2.81)  
正文索引：   

  

 

某新报告主体（拟出售的业务单元）与同一集团的若干其他业务单元共同使用母公司拥有的一个品牌名称。该品牌名称已注册专利，且在法律上归母公司所有。该品牌名称是否应纳入按照 IFRS 编制的汇总财务报表中？

 

情形 1 – 买方不收购该品牌名称

 

由于该品牌不会出售给买方，将其作为资产纳入新报告主体的资产负债表是不适当的。如果母公司此前曾就使用该品牌名称向相关业务单元收取特许权使用费，则汇总财务报表应包含该项费用。然而，如果母公司此前未向相关业务收取特许权使用费，则应披露该事实，但不应作出“假定（as-if）”调整；同时还应考虑是否需要将母公司层面该品牌的任何摊销分摊至新报告主体。

 

情形 2 – 买方收购该品牌名称

 

如果新买方随新报告主体一并收购该品牌名称，则将母公司对该品牌名称资产的历史成本纳入新报告主体的汇总财务报表是适当的。利润表应包含该品牌名称的相关摊销费用；然而，无形资产的账面价值通常为零。

### <a id="s369-EXA2.117.1"></a>EX A2.117.1 – 管理费及其他费用的分摊

 

准则索引：[A2.117](87.md#s367-Para_A2.117)  
正文索引：   

  

 

摘自 Delta 分立时的汇总财务报表 – 20X6年12月31日

 

本汇总财务报表系以“剥离”基础从 Delta PLC（“Delta”）的合并财务报表中编制而成，旨在按独立基础列报 Epsilon 的财务状况、经营成果和现金流量。Epsilon 的汇总财务报表反映了直接归属于 Express 的资产、负债、收入和费用，包括按历史基础在 Delta 的法律主体会计记录中确认的管理费分摊。尽管无法估计若由独立第三方提供 Delta 所执行的该等服务本会发生的实际成本，但 Delta 的董事及 Epsilon 的管理层认为这些分摊是合理的。然而，Epsilon 的财务状况、经营成果和现金流量未必能代表或反映 Epsilon 若自主运营或作为独立于 Delta 的主体运营时本会实现的结果。

 

**管理费**

 

Delta 采用成本回收机制，收回其在集团总部层面发生的若干中央管理费用及其他类似成本。汇总财务报表中反映的管理费基于历史应付金额，并已根据合同成本回收机制计入 Epsilon 内各独立法律主体的账目中。Delta 与 Epsilon 相关人员薪酬（包括其薪金和养老金成本）的适当比例已包含在这些管理费中。这些管理费要么直接归属于 Epsilon 的各项独立业务，要么就中央层面发生的成本按公平交易基础在相关 Delta 业务与 Epsilon 业务之间进行分摊。关于 Epsilon 与 Delta 及其他 Delta 主体之间关系的完整讨论（包括历史上向 Epsilon 收取的费用的说明），载于本汇总财务报表附注 X。

 

**养老金及离职后成本**

 

Epsilon 在全球运营若干养老金计划。Delta 是其中两项养老金计划的发起雇主，因此根据 IAS 19 第34(a)段，这两项养老金计划对 Epsilon 而言构成集团计划。鉴于其符合集团计划的条件，Epsilon 在汇总财务报表中按当期应付供款确认费用。

 

**利息**

 

汇总财务报表中反映的利息费用，系基于纳入 Epsilon 的各主体就特定外部借款或由其他 Delta 公司提供的融资在历史上实际发生的利息费用。

 

**税项**

 

归属于 Epsilon 的所得税费用，系按单独纳税申报基础，根据各相关独立税务管辖区内各独立主体或 Delta 主体组应负担的所得税费用确定。在特定国家因 Epsilon 业务从 Delta 税务集团分离而可能产生的任何税务负债，均未在本汇总财务报表中反映。

 

**商誉**

 

在 Delta 合并层面记录的、因先前与 Delta 公司集团以外的第三方进行的企业合并而归属于 Epsilon 的商誉，已记录在本汇总财务报表中。

 

**股份支付**

 

Epsilon 的若干员工参与了 Delta 的绩效股份计划。为编制本汇总财务报表之目的，将 Delta 的权益工具转让给 Epsilon 员工的交易已作为以权益结算的股份支付交易予以反映。
